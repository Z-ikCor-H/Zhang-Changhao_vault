# 电源模块负载测试笔记

> 测试日期：2026-07-16（推断）
> 板卡：Power Supply Design（Altium Designer 24）
> 测试对象：TPS5430 Buck → SPX29302 LDO → MT3608 Boost 三级电源链

---

## 1. 系统架构

```
P1 (DC 3.5×1.3, 12V) ─┐
                        ├─→ F1(1206/0.5A) → Q1(HY19P03D) → VBAT+
P2 (USB-C, 5V) ────────┘      反接/电源选择

VBAT+ ──→ U1(TPS5430) ──→ VCC5V ──→ U2(SPX29302) ──→ 3.3V ──→ U3(MT3608) ──→ +5V
             Buck              │         LDO                    Boost
           12V→5V              │       5V→3.3V                3.3V→5V
                               │
                          JP1 (VCC5V输出端子)
                          JP2 (3.3V输出端子)
                          JP3 (+5V输出端子)
```

**关键网络：**
- `VBAT+`：公共输入总线（12V DC 或 5V USB-C）
- `VCC5V`：Buck 降压输出（目标 5V）
- `3.3V`：LDO 稳压输出
- `+5V`：Boost 升压输出（独立于 VCC5V）

## 3. 测试过程与故障排查

### 3.1 第一阶段：上电异常

**现象：** 12V DC 输入，BUCK 输出 10.9V（预期 5V）

**排查过程：**

| 步骤 | 测量点 | 方法 | 结果 | 判断 |
|------|--------|------|------|------|
| 1 | VOUT → VSENSE(Pin4) 电阻 | 断电，电阻档 | **6.68KΩ** | R3 完好，非开路 ✓ |
| 2 | VSENSE → GND 电阻 | 断电，电阻档 | **2.17KΩ** | R4 完好 ✓ |
| 3 | VSENSE 对 GND 电压 | 上电，电压档 | **1.222V** | 反馈信号正确抵达芯片 ✓ |
| 4 | VOUT 对 GND 电压 | 上电，电压档 | **10.9V** | 芯片不理睬反馈信号 ✗ |

**逻辑推导：**

```
反馈信号正常(1.222V) + 输出异常(10.9V) = 芯片内部控制失效
→ 初步怀疑 TPS5430 损坏
```

**实际根因：用户进一步排查发现 TPS5430 的 GND 引脚（Pin6）和 PowerPAD 虚焊。**

**故障机制：** 芯片无可靠地参考 → 内部误差放大器、PWM 比较器、栅极驱动电路全部无法正常工作 → 高侧 MOSFET 不受控导通 → VOUT 接近 VIN。

### 3.2 第二阶段：MT3608 Boost 输出异常

**现象：** Boost 输出 3.07V（预期 5V）

**定位：** 3.07V ≈ 3.3V − 0.23V（SS54 正向压降），说明电流仅通过电感和二极管的直流通路传输，芯片完全未开关。

**根因：** MT3608 GND 引脚（Pin2）虚焊——与 TPS5430 同类型故障。

**修复：** 重新焊接 MT3608 GND 引脚后恢复正常。

### 3.3 第三阶段：电流测量操作纠正

**错误操作：** 万用表电流档，表笔并联在输出端两端 → 等效于将电源输出短路 → TPS5430 触发峰值限流 → 电感 L1 承受 4A 级冲击电流 → 短暂异常发热。

**正确操作：** 万用表电流档，表笔**串联**在输出与负载之间：

```
正确接法：VOUT(+) → 万用表A孔(红) → 万用表COM(黑) → 负载(+) → 负载(−) → GND
错误接法：万用表(电流档) 直接并联在 VOUT(+) 和 GND(−) 两端 → 短路！
```

**教训：** 电流测量后应立即将红表笔从 A 孔插回 VΩ 孔，防止下次误用电压档测电源导致短路。

## 4. 负载测试数据

### 4.1 测试条件

- 负载：4W 小灯泡（实际在 5V 下约 0.6W）
- 仪表：数字万用表（电压档/电流档）
- 环境：室温，PCB 裸板

### 4.2 测试结果

| 输入源 | 模块 | 空载电压 | 带载电压 | 输出电流 | 输出功率 | 压降 |
|--------|------|---------|---------|---------|---------|------|
| **DC 12V** | BUCK5V | 4.98V | 4.98V | 0.12A | 0.60W | **0V (0%)** |
| | LDO3.3V | 3.29V | 3.29V | 0.08A | 0.26W | **0V (0%)** |

### 4.3 各路详细分析

#### BUCK5V（TPS5430）

```
DC 12V 输入：
  负载调整率 = 0%，近乎完美
  实测 4.98V vs 理论 4.995V → 误差 −0.3%（含万用表误差、电阻精度）

USB-C 5V 输入：
  4.81V ≠ 故障，是 Buck 拓扑在 Vin≈Vout 时的物理限制
  Vin=5V → 占空比约 98% → Vout = 5V − 0.19V(各种压降) = 4.81V
  此时 TPS5430 处于压差模式（dropout），属正常行为
```

#### LDO3.3V（SPX29302）

```
3.29V 是 R7(3.3KΩ)/R6(2KΩ) 配比 + Vref(1.240V) 的必然结果
误差 = (3.29 − 3.30) / 3.30 = −0.3%，远优于 ±2% 的典型 LDO 精度要求
若需严格 3.30V：将 R6 换为 1.96KΩ 或将 R7 换为 3.33KΩ
```

#### BOOST5V（MT3608）

```
空载 5.01V（优良），带载 4.86V（−3.0%）
压降来源可能为：
  1. MT3608 固有负载调整率（升压拓扑天然劣于 Buck）
  2. PCB 走线压降（反馈取样点与输出端子不在同一位置）
  3. 在 4.75V~5.25V（±5%）范围内，当前 4.86V 可正常使用
```

## 5. 发现的设计问题与改进建议

### 5.1 D2（SS14）额定电流不足 ⚠ 未修复

| 对比项  | 当前设计     | 设计要求        | 风险                |
| ---- | -------- | ----------- | ----------------- |
| 型号   | **SS14** | SS34 或 SS54 | 负载 > 1A 时过热烧毁     |
| 额定电流 | **1A**   | ≥ 3A        | 开路后 TPS5430 无续流路径 |
| 额定电压 | 40V      | ≥ 40V       | —                 |
| 封装   | SMA      | SMA（兼容）     | 可直接替换             |

**建议：** 在首次满载（≥1A）测试前将 D2 更换为 **SS34**（3A/40V）或 **SS54**（5A/40V）。SMA 封装兼容，可直接替换，无需改 PCB。

### 5.2 USB-C 5V 供电时 VCC5V = 4.81V

**原因：** TPS5430 是纯 Buck 拓扑，无法升压。USB-C 5V 经过 MOSFET 和电感后自然低于 5V。

**影响：** 仅影响 USB-C 供电场景。VCC5V 排针（JP1）上的外部设备若需要严格 5V 供电会受影响。LDO 和 Boost 的级联输出不受影响（LDO 输入 4.81V 仍可输出 3.29V，Boost 输入 3.29V 仍可输出 +5V）。

**改进方向（如需）：** USB-C 5V 通过额外 PMOS 直接旁路到 VCC5V，跳过 TPS5430。无需本次修改。

### 5.3 BOOST5V 带载压降偏大（−3%@0.12A）

- 当前不影响使用，但在较重负载下压降可能进一步增大
- 如需改善：将反馈采样点（R9/R10 分压点）物理靠近输出端子，补偿走线压降

## 7. 经验总结

### 焊接质量

- **SOP-8 PowerPAD 和 SOT23-6 的 GND 引脚是最高优先级的焊接点**——GND 虚焊不会导致完全不输出，而是导致芯片行为完全不可预测
- 本次 TPS5430 和 MT3608 均为 GND 虚焊，症状分别是"输出接近输入电压"和"输出=输入−二极管压降"，均非"无输出"，容易误判为芯片损坏
- PowerPAD 封装需要足够量的焊锡膏和适当回流温度，手工焊接时建议先用烙铁给焊盘预上锡

### 测量操作

- **万用表电流档永远串联在回路中，绝不可并联在电源两端**
- 测完电流后立即将红表笔从 A 孔插回 VΩ 孔，养成肌肉记忆
- 怀疑芯片损坏前，先完成所有焊接检查（断电测各引脚对 GND 电阻、邻脚间是否桥接）

### 测试流程

- 先空载测电压，确认各路输出正确后再带载
- 首次带载使用小负载（< 0.5A），确认无异常后再逐步加大
- 电感、芯片、二极管是主要发热元件，带载后用手指背轻触检查温度
