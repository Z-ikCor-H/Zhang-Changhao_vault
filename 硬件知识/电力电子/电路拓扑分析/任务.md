一、统一符号体系

每篇文档开头必须建立“符号约定表”。

明确：
- Vin / Vg：输入电压
- Vo / V：输出电压
- Ts：开关周期
- fs：开关频率
- D：占空比
- Deff：有效占空比
- n：必须明确是 Ns/Np 还是 Np/Ns
- Lm：励磁电感
- L：输出滤波电感或 Boost 储能电感
- Cr/Lr：谐振元件

同一个符号在全文中不得改变定义。

如果不同拓扑使用不同的占空比定义，必须明确说明，不能强行统一。

三、模态分析必须可视化思维

每个模态都必须明确列出：

| 元件 | 状态 |
|---|---|
| Q1 | ON/OFF |
| Q2 | ON/OFF |
| D1 | ON/OFF |
| D2 | ON/OFF |
| 其他二极管 | ON/OFF |
| L | 储能/放能 |
| C | 充电/放电 |
| 变压器 | 正向励磁/复位 |

然后解释：

- 电流从哪里流到哪里
- 每个节点电压是多少
- 每个器件两端电压极性
- 哪个器件承担电压
- 能量从哪里到哪里
- 电感电流上升还是下降
- 磁通增加还是减少

不要只描述“D1导通、D2截止”，必须解释为什么。

四、禁止错误的“箭头”表述

二极管统一使用：

Anode（阳极）→ Cathode（阴极）

作为正向电流方向。

不要使用“二极管箭头方向”描述。

五、明确区分同步开关与同步整流

例如两个主开关同时导通/关断时，使用：

“同相驱动”或“同时导通/同时关断”。

不要把它写成“同步整流”。

六、双管正激重点

对于双管正激，必须重点解释：

- Q1/Q2 为什么同时导通
- Q1/Q2 为什么同时关断
- D1/D2 在关断阶段如何完成磁芯复位
- 励磁能量如何回馈输入
- 为什么 MOSFET 理论耐压约为 Vin，而不是 2Vin
- 为什么最大占空比受限于 50%
- 为什么需要完整的复位时间
- D1/D2 与输出侧 D3/D4 的功能完全不同
- 正激与反激的本质区别

必须通过伏秒平衡解释 Dmax≤0.5，而不是只给结论。

七、公式推导必须完整

不要直接给最终公式。

必须：

1. 写出模态1的电感电压
2. 写出模态2的电感电压
3. 进行伏秒平衡
4. 展开计算
5. 得到最终传输函数
6. 说明变量定义和适用条件

所有公式必须说明适用条件，例如：

- CCM
- 理想器件
- 忽略二极管压降
- 忽略漏感
- 稳态
- 小纹波近似等

→ 寄生参数/漏感/反向恢复产生的额外应力
→ 安全裕量
→ 器件额定参数
