# 半桥串联谐振变换器（Half-Bridge Series Resonant Converter, SRC）

> 本笔记遵循 [00-统一规范](00-统一规范.md)。原理图（`拓扑图/Half-Bridge Series Resonant Converter.png`）为最高依据。
>
> **⚠️ 符号勘误**：原版笔记的匝比定义为 $n=N_p/N_s$ ，与全库统一口径 $n=N_s/N_p$ **相反**，导致 $V_o$ 与 $R_{ac}$ 公式的 $n$ 次幂方向相反。**本笔记已统一为 $n=N_s/N_p$**，并给出与原版的换算说明（§21.2）。

## 一、拓扑概述

### 1.1 拓扑名称与归类

**半桥串联谐振变换器（SRC）**，属于**谐振变换器**家族，是 LLC 的"简化版"（无功谐振腔，只有两个谐振元件）。

| 归类维度 | 结论 |
|---|---|
| 家族 | **谐振变换器**（串联谐振） |
| 馈电方式 | 电压馈电（半桥斩波 + 串联谐振腔） |
| 控制变量 | **开关频率**（不是占空比！） |
| 开关管数量 | 2 |
| 主开关占空比 | **固定 50%**（互补） |
| 整流结构 | 副边全桥整流 + 电容滤波 |

> **★ 最重要的认知**：SRC **没有占空比这个控制变量**。它靠**改变开关频率**来调节输出——谐振腔的阻抗随频率变化，从而改变分压比。
>
> 因此本笔记中**不出现 $D$**（主开关恒为 50% 互补），所有公式用谐振参数 $F$ 、 $Q$ 、 $Z_0$ 表达。

### 1.2 原理图解读

![](拓扑图/Half-Bridge%20Series%20Resonant%20Converter.png)

| 位置 | 连接 |
|---|---|
| 直流输入 | 由两只等值分压电容构成的**分裂直流母线**（图中两个 $V_s$ 源等效），中点记为 X |
| 半桥 | $Q_1$ （上）+ $D_1$ （体二极管）； $Q_2$ （下）+ $D_2$ ；中点记为 Z |
| **谐振腔** | $C_r$ （谐振电容）+ $L_r$ （谐振电感）**串联**，接在半桥中点与变压器原边之间 |
| 变压器 | 简单原边 $1:n$ （**非中心抽头**，绕制简单） |
| 副边整流 | **全桥整流**（4 只二极管）+ 输出电容 $C_F$ |
| 负载 | $R_{load}$ |

> **三个必须看清的点**
> 1. **谐振腔是"串联"的**——$C_r$ 与 $L_r$ 串联后**再串入变压器原边**。这决定了 SRC 的根本特性：谐振腔对直流呈现开路（ $C_r$ 隔直），因此**天然隔直、无偏磁** ✓；
> 2. **半桥中点 Z 输出的是 $\pm V_s$ 方波**（相对分裂母线中点 X）；
> 3. **副边是全桥整流 + 电容滤波**——注意这与前面几个拓扑的"中心抽头 + 电感滤波"完全不同：SRC 副边**没有滤波电感**，靠电容平滑。

### 1.3 宏观工作机理

| 环节 | 功能 |
|---|---|
| ① 分压电容（ $C_1$ 、 $C_2$ ） | 构成分裂母线，中点提供 0V 参考；同时起隔直作用 |
| ② 半桥（ $Q_1$ 、 $Q_2$ ） | **50% 互补驱动**，中点输出 $\pm V_s$ 方波 |
| ③ **串联谐振腔**（ $C_r$ 、 $L_r$ ） | **核心**：其阻抗随频率变化，实现调压；同时实现软开关 |
| ④ 变压器 | 电压变换 + 隔离（**只做隔离与变压，不参与谐振**） |
| ⑤ 全桥整流 + $C_F$ | 整流滤波 |

**控制逻辑**：

- **固定 50% 占空比 + 变频控制**——改变 $f_s$ （即归一化频率 $F=f_s/f_r$ ）来调节输出
- **$f_s$ 升高 → 谐振腔阻抗升高 → 输出电压下降**（见 §六）
- 负载越轻， $Q$ 越小，增益曲线越平坦

> **与 PWM 拓扑的根本区别**：SRC 不"斩波"能量，而是让能量**以正弦形式流过谐振腔**。输出电压由"谐振腔分压比"决定。

### 1.4 优点

1. **软开关**——感性区（ $F>1$ ）可实现 **ZVS 开通**，开关损耗极低
2. **副边二极管自然换流**——在 ZVS 区，二极管电流在换向前自然过零，**反向恢复问题小**
3. **天然隔直**——$C_r$ 串联在原边回路中，**无偏磁风险** ✓
4. **开关频率高**——软开关使频率可以做到数百 kHz~MHz → 磁性元件与电容体积小
5. **EMI 相对好**——正弦化的谐振电流 di/dt 低
6. **变压器简单**——非中心抽头，绕制方便

### 1.5 缺点

1. **调压范围受限**——SRC 增益 $M\le1$ ，**只能降压**（相对 $nV_s$ ）；宽输入范围场合困难
2. **轻载调压困难**——轻载时 $Q$ 小，增益曲线平坦，需要极宽的频率范围
3. **频率变化范围大**——从满载到轻载， $f_s$ 可能变化 2~3 倍；**EMI 滤波器需按全频段设计**
4. **谐振腔电流应力大**——即使轻载，谐振腔仍有环流（比 PWM 拓扑的损耗曲线更"陡"）
5. **无法空载工作**——无负载时增益失控（LLC 通过励磁电感解决了这个问题）
6. **设计复杂**——谐振参数（ $L_r$ 、 $C_r$ 、 $f_r$ 、 $Q$ ）互相耦合，需迭代

### 1.6 适用场景

| 场景 | 是否合适 | 原因 |
|---|:---:|---|
| 需要高功率密度 + 高频 | ✅ | 软开关使频率可做很高 |
| 输入范围较窄的场合 | ✅ 最佳 | 调压范围要求不高时 SRC 最合适 |
| LED 驱动、电子镇流器 | ✅ | 恒流特性好 |
| 小功率适配器 | △ | LLC 更适合（宽范围 + 可空载） |
| 宽输入范围（如 85~265VAC） | ❌ | SRC 增益不能升压，宽范围困难 → 用 LLC |
| 需要升压输出 | ❌ | SRC 只能降压 |

> **SRC vs LLC 一句话**：**SRC 的谐振腔在变压器之前（串联），LLC 的励磁电感也参与谐振**。LLC 因此获得"可升可降 + 可空载"的能力，是 SRC 的超集。**掌握 SRC 是理解 LLC 的基础。**

## 二、统一符号定义

### 2.1 通用符号

| 符号 | 含义 | 本笔记取值示例 |
|---|---|---|
| $V_{bus}$ | 直流母线电压（分裂母线总压） | 400V |
| $V_s$ | **分裂母线半压** $=V_{bus}/2$ | 200V |
| $V_o$ | 输出电压 | 48V |
| $I_o$ | 输出电流 | 4.17A |
| $P_o$ | 输出功率 | 200W |
| $R_{load}$ | 负载电阻 $=V_o/I_o$ | 11.5Ω |

### 2.2 ★ 控制变量：没有占空比

| 项目 | 说明 |
|---|---|
| 主开关占空比 | **固定 50%**（ $Q_1$ 、 $Q_2$ 互补，中间留死区 $t_{dead}$ ） |
| **控制变量** | **开关频率 $f_s$**（或归一化频率 $F$ ） |
| 死区 | $t_{dead}$ ，用于 ZVS 换流（典型 100~500ns） |

> **规范要求**：本笔记**不出现 $D$**。凡需描述"占空比"处，一律说明"主开关恒为 50%"。

### 2.3 谐振腔参数

| 符号 | 定义 | 公式 |
|---|---|---|
| $\omega_r$ | 谐振角频率 | $\omega_r=\dfrac{1}{\sqrt{L_rC_r}}$ |
| $f_r$ | 谐振频率 | $f_r=\dfrac{1}{2\pi\sqrt{L_rC_r}}$ |
| $Z_0$ | 特征阻抗 | $Z_0=\sqrt{\dfrac{L_r}{C_r}}$ |
| $F$ | 归一化频率 | $F=\dfrac{f_s}{f_r}$ |
| $Q$ | 品质因数 | $Q=\dfrac{Z_0}{R_{ac}}$ |
| $R_{ac}$ | **折算到原边的等效交流负载** | $R_{ac}=\dfrac{8}{\pi^2}\cdot\dfrac{R_{load}}{n^2}$ |
| $M$ | 归一化电压增益（FHA） | $M=\dfrac{1}{\sqrt{1+Q^2\left(F-\frac1F\right)^2}}$ |

### 2.4 匝比定义

$$n=\frac{N_s}{N_p}\qquad(N_p\text{＝原边匝数，}N_s\text{＝副边匝数，均为整个绕组})$$

> **★ 与原版笔记的换算**：原版用 $n'=N_p/N_s$ （即 $n'=1/n$ ）。原文的公式为 $V_o=\dfrac{V_s}{n'}M$ 、 $R_{ac}=\dfrac{8}{\pi^2}n'^2R_{load}$ ，**两者数值等价**（代入 $n'=1/n$ 即得本笔记的公式）。本笔记统一用 $n=N_s/N_p$ 。

### 2.5 分析假设

- [x] **连续谐振电流**（CCM：谐振电流在整个半周期内连续）
- [x] **基波近似（FHA, First Harmonic Approximation）**——只考虑方波的基波分量
- [x] 理想器件（忽略 $R_{DS(on)}$ 、 $V_F$ 、反向恢复）
- [x] 忽略线路寄生参数（除 $C_{oss}$ 外）
- [x] 输出电容 $C_F$ 足够大， $V_o$ 恒定
- [x] 理想变压器，励磁电感 $L_m$ **不参与谐振**（ $L_m$ 足够大）

> **FHA 的适用条件与误差**：FHA 假定谐振腔只响应方波的基波分量，忽略了高次谐波。在 $f_s$ 接近 $f_r$ 时误差最小（±10% 内）；远离 $f_r$ 时误差增大。**工程上 FHA 用于初版设计，最终需仿真或实测校正。**

## 三、电路结构完整拆解

### 3.1 输入侧

| 元件 | 功能 | 关键说明 |
|---|---|---|
| $C_1$ 、 $C_2$ | 分裂母线电容 | 等值串联，中点 X 提供 0V 参考；**同时隔直** |
| $Q_1$ 、 $Q_2$ | 半桥 | 50% 互补；中点 Z 输出 $\pm V_s$ |
| $D_1$ 、 $D_2$ | $Q_1$ 、 $Q_2$ 的**体二极管** | **ZVS 换流的关键**——死区期间为谐振电流提供续流通路 |

**关键认知**：谐振腔接在**中点 Z 与中点 X 之间**（X 是分裂母线中点，即"原边地"）。因此加在谐振腔输入端的电压是：

$$v_{SW}=+V_s\ (\text{$Q_1$ 导通})\quad\text{或}\quad v_{SW}=-V_s\ (\text{$Q_2$ 导通})$$

### 3.2 谐振腔（核心）

| 元件 | 功能 |
|---|---|
| $C_r$ | 谐振电容。**同时承担隔直作用**——原边电流必经 $C_r$ ，故无直流分量 |
| $L_r$ | 谐振电感。可以是独立电感，也可以**用变压器漏感充当（磁集成）** |

**串联谐振腔的阻抗**：

$$Z_{tank}(\omega)=j\omega L_r+\frac{1}{j\omega C_r}+R_{ac}=R_{ac}+jZ_0\left(F-\frac1F\right)$$

- **在 $F=1$ （谐振点）**： $Z_{tank}=R_{ac}$ （纯阻性）→ 全压加在负载上 → $M=1$
- **$F<1$ （容性区）**： $\omega L_r<1/(\omega C_r)$ ，阻抗呈容性
- **$F>1$ （感性区）**： $\omega L_r>1/(\omega C_r)$ ，阻抗呈感性 ← **推荐工作区**

### 3.3 副边

| 元件 | 功能 |
|---|---|
| 全桥整流（4 只二极管） | 副边交流 → 单向脉动 |
| $C_F$ | 输出滤波电容（**没有滤波电感**） |
| $R_{load}$ | 负载 |

> **注意**：SRC 的副边是**全桥整流**（不是中心抽头），因此二极管耐压只需 $V_o$ （而中心抽头需要 $2V_o$ ）——但代价是每时刻有 2 只二极管串联导通，压降翻倍。

## 四、一个完整开关周期的工作过程

**总览**：主开关 50% 互补，一个周期分 4 段（受**谐振电流相位**影响，实际分界与死区有关）

| 阶段 | 开关 | 说明 |
|---|---|---|
| 模态 1 | $Q_1$ 导通 | 正向功率传输 |
| 模态 2 | 死区（ $Q_1$ 已关、 $Q_2$ 未开） | 谐振电流经 $D_2$ 续流 → **ZVS 准备** |
| 模态 3 | $Q_2$ 导通 | 反向功率传输 |
| 模态 4 | 死区（ $Q_2$ 已关、 $Q_1$ 未开） | 谐振电流经 $D_1$ 续流 → **ZVS 准备** |

> **注意**：模态 2/4 在**感性区（ $F>1$ ）**的形态是"电流**仍沿原方向**续流"（这就是 ZVS 的来源）；而在**容性区（ $F<1$ ）**电流已反向，形态不同。详见 §四 的 ZVS/ZCS 专题。

---

### 4.1 模态 1： $Q_1$ 导通（正向功率传输）

#### （1）状态表

| 元件 | 状态 |
|---|---|
| $Q_1$ | **ON** |
| $Q_2$ | OFF |
| $D_1$ | OFF（ $Q_1$ 导通，体二极管被旁路） |
| $D_2$ | OFF（被 $V_s$ 反偏） |
| 谐振腔 | $L_r$ 、 $C_r$ 交换能量，电流近似正弦 |
| 变压器 | 正向励磁 |
| $C_F$ | 充电（同时向负载供电） |

#### （2）电压与电流

$$v_{SW}=+V_s$$

谐振电流 $i_{Lr}$ 近似正弦（在 $F$ 接近 1 时接近纯正弦）：

- **感性区**： $v_{SW}$ 跃升到 $+V_s$ 时， $i_{Lr}$ 可能仍为**负值**（电流滞后电压），随后过零转正、升至峰值、再下降
- $v_{Cr}$ 按正弦规律变化（ $C_r$ 被充放电）

**电流路径**：

$$\text{分裂母线中点 X}\to C_r\to L_r\to\text{变压器原边}\to Q_1(?\ \text{见下})\to V_s(+)$$

> **精确路径**： $V_s(+)\to Q_1(\text{漏}\to\text{源})\to\text{原边绕组}\to L_r\to C_r\to$ 中点 X。谐振电流经 $C_r$ 流过，因此**不存在直流分量** ✓

#### （3）副边

- 原边电压为正 → 副边电压为正 → 全桥整流中对应的一对二极管导通 → 向 $C_F$ 与负载供能
- 副边电压被 $C_F$ 钳定为 $\pm V_o$ ，折算到原边为 $\pm V_o/n$

---

### 4.2 模态 2：死区（ $Q_1$ 关断、 $Q_2$ 未导通）

**这是 ZVS 实现的关键阶段**（以感性区 $F>1$ 为例）：

1. $Q_1$ 关断瞬间， $i_{Lr}$ 为**正值**（感性电流滞后，关断时电流仍沿原方向）
2. $i_{Lr}$ **不能突变**，它给 $Q_1$ 的 $C_{oss1}$ **充电**（ $V_{DS1}$ 上升）、给 $Q_2$ 的 $C_{oss2}$ **放电**（ $V_{DS2}$ 下降）
3. 当 $V_{DS2}$ 降到 0 时，**$D_2$ （ $Q_2$ 体二极管）正向导通**， $v_{SW}$ 被钳到 $-V_s$
4. 此时若开通 $Q_2$ ，即实现 **ZVS（零电压开通）**

**状态表**：

| 元件 | 状态 |
|---|---|
| $Q_1$ 、 $Q_2$ | 全 OFF |
| $D_2$ | **ON**（续流，把 $v_{SW}$ 钳到 $-V_s$ ） |
| $C_{oss1}$/$C_{oss2}$ | 充/放电（换流瞬间） |
| 谐振腔 | 继续谐振，电流从正值减小 |

**能量流向**：谐振电感储能经 $D_2$ **回馈到分裂母线**（向 $V_s$ 侧充电）；副边依靠 $C_F$ 供电。

> **★ ZVS 的本质**：**谐振电流充当给 $C_{oss}$ 充放电的"恒流源"**，把 $Q_1$ 关断时结电容中的能量转移到对侧，使待开通管的 $V_{DS}$ 先降到零。**这是"电感里的电流"换来了"开关管的零电压开通"。**

---

### 4.3 模态 3 / 模态 4

与模态 1 / 模态 2 完全对称、极性反转：

- 模态 3： $Q_2$ 导通 → $v_{SW}=-V_s$ ；谐振电流反向；副边换向（全桥整流自动换向导通，输出极性不变）
- 模态 4：死区， $i_{Lr}$ 为负值 → 给 $C_{oss2}$ 充电、 $C_{oss1}$ 放电 → $D_1$ 导通 → 为 $Q_1$ 的 ZVS 做准备

---

### 4.4 ★ ZVS 与 ZCS 专题（SRC 的精髓）

#### （1）三个工作区域的划分

| 频率条件 | 谐振腔阻抗 | $\varphi$ （电流 vs 电压） | 原边开关管 | 副边二极管 | 评价 |
|---|---|---|---|---|---|
| $F>1$ （**感性区**） | 感性（阻抗角 >0） | 电流**滞后**电压 | **ZVS 开通**；关断为硬关断 | 自然换流，反向恢复轻 | ✅ **推荐工作区** |
| $F=1$ （谐振点） | 纯阻性 | 同相 | 硬开通、硬关断 | 硬开关换流 | 一般不工作于此 |
| $F<1$ （**容性区**） | 容性（阻抗角 <0） | 电流**超前**电压 | **ZCS 关断**；开通为硬开通 | 反向恢复严重 | ❌ **不推荐** |

#### （2）感性区 ZVS 开通的物理过程（ $F>1$ ）

见 §4.2 的四步。要点：

- **前提**： $i_{Lr}$ 必须**滞后**于 $v_{SW}$ （感性）
- **条件**：死区时间 $t_{dead}$ 内， $i_{Lr}$ 必须能把 $C_{oss}$ 完全充放电，且**体二极管持续导通**
- **判据**：死区结束时刻 $i_{Lr}$ 的极性必须**有利于** $C_{oss}$ 换向

$$t_{dead}\ge\frac{2C_{oss}V_s}{I_{Lr}(\text{换流时刻})}$$

> **轻载时 ZVS 会丢失**： $i_{Lr}$ 幅值随负载下降，可能不足以在死区内完成 $C_{oss}$ 充放电 → ZVS 丢失 → 开关损耗上升、效率在轻载时恶化。这是 SRC 的固有痛点，也是 LLC 用励磁电流辅助 ZVS 的原因之一。

#### （3）容性区 ZCS 关断（ $F<1$ ）——为什么不推荐

- $i_{Lr}$ **超前** $v_{SW}$ ，关断时电流已经反向 → 二极管先导通 → 实现 ZCS 关断
- **但**： $Q_1$ 开通时， $C_{oss}$ 中的能量被**直接短路泄放**（容性开通）→ 开通损耗极大、EMI 恶化
- **且**：副边二极管在反向恢复期间被硬关断 → 反向恢复电流尖峰严重

> **结论**：**SRC 必须工作在感性区（ $F>1$ ）**。设计时保证整个负载范围内 $f_s>f_r$ 。

#### （4）ZVS 与 ZCS 综合对比

| 项目 | ZVS（感性区） | ZCS（容性区） |
|---|---|---|
| 频率 | $F>1$ | $F<1$ |
| 电流相位 | 滞后 | 超前 |
| 开通损耗 | **≈0**（零电压开通） | 大（ $C_{oss}$ 能量泄放） |
| 关断损耗 | 硬关断（但有 $C_{oss}$ 缓冲） | **≈0**（零电流关断） |
| 二极管反向恢复 | 轻 | **严重** |
| EMI | 好 | 差 |
| 推荐度 | ✅ **推荐** | ❌ 避免 |

## 五、关键波形

### 5.1 感性区（ $F>1$ ，ZVS）关键波形

```
             模态1        模态2        模态3        模态4
            Q1导通       死区        Q2导通       死区
            ← Ts/2 →    ← tdead→    ← Ts/2 →    ← tdead→
            (50%)        (小)        (50%)        (小)

 v_g(Q1)   ████████████████▌              ████████████████▌
 v_g(Q2)                   ████████████████▌              ██████
                           ↑ Q2 ZVS 开通（D2 先导通）

 v_SW     +Vs   │  -Vs  │  -Vs   │  +Vs     ← 死区内已翻转
         ───────┼───────┼────────┼────────

 i_Lr    正弦（滞后）      ← 关断时 i>0，死区内给 Coss 换向
               ╱‾‾╲              ╱‾‾╲
         ────╱      ╲──────────╱      ╲────
                      ╲        ╱
                       ╲______╱

 v_Cr     正弦（相位滞后于 i）
              ╱‾‾╲              ╱‾‾╲
         ───╱      ╲──────────╱      ╲────

 V_DS(Q1)   0    │  2Vs   │  2Vs  │   0
         ────────┼────────┼───────┼──────
                    ↑ 关断后升到 2Vs（=母线电压）

 V_DS(Q2)  2Vs   │   0    │   0   │  2Vs
         ────────┼────────┼───────┼──────
                  ↑ 死区内先降到 0（ZVS 条件）
```

### 5.2 波形要点解读

| 观察 | 物理原因 |
|---|---|
| $i_{Lr}$ 近似正弦 | 串联谐振腔的带通特性——只有基波附近的分量能通过 |
| $i_{Lr}$ 滞后 $v_{SW}$ （感性区） | $F>1$ 时 $\omega L_r>1/(\omega C_r)$ |
| 死区内 $v_{SW}$ 已翻转 | 谐振电流给 $C_{oss}$ 换向，体二极管先导通 |
| $V_{DS}$ 最大 = $2V_s$ = 母线电压 | 半桥结构的必然（与半桥 Buck 相同） |
| 副边整流波形无滤波电感 | 副边是"电容滤波"，电流是脉冲形式 |

## 六、稳态电压传输关系

### 6.1 推导思路（FHA 法）

1. 把半桥输出的方波 $v_{SW}$ 用**基波**代替
2. 把副边"全桥整流 + 电容滤波 + 负载"用**等效交流电阻** $R_{ac}$ 代替
3. 分析谐振腔的**基波分压比** $M$
4. 由 $M$ 反推直流输出 $V_o$

### 6.2 步骤一：方波的基波分量

$v_{SW}$ 是幅值 $\pm V_s$ 、占空比 50% 的方波，其基波有效值为：

$$\boxed{V_{SW,1}=\frac{2\sqrt2}{\pi}V_s\approx0.900\,V_s}$$

### 6.3 步骤二：副边整流的等效交流电阻

副边"全桥整流 + 电容滤波"折算到原边的等效交流电阻：

$$\boxed{R_{ac}=\frac{8}{\pi^2}\cdot\frac{R_{load}}{n^2}=\frac{8}{\pi^2}\cdot\frac{V_o}{I_o\,n^2}\approx0.810\,\frac{R_{load}}{n^2}}$$

**推导要点**：全桥整流 + 电容滤波时，交流侧电压为方波、电流为脉冲，由功率守恒与波形关系可得二次侧等效电阻 $=\dfrac{8}{\pi^2}R_{load}$ ；再按匝比平方折算到原边（乘以 $1/n^2$ ）。

> **物理理解**： $\frac{8}{\pi^2}\approx0.81$ 是"方波基波有效值/直流值"与"脉冲电流"这两个波形因子共同作用的结果。

### 6.4 步骤三：谐振腔增益 $M$

谐振腔是 $R_{ac}$ 与 $L_r$ 、 $C_r$ 的串联分压网络：

$$M=\left|\frac{R_{ac}}{R_{ac}+j\left(\omega L_r-\dfrac{1}{\omega C_r}\right)}\right|$$

分子分母同除 $R_{ac}$ ，并代入 $Z_0=\sqrt{L_r/C_r}$ 、 $Q=Z_0/R_{ac}$ 、 $F=f_s/f_r$ ：

$$\boxed{M(F,Q)=\frac{1}{\sqrt{1+Q^2\left(F-\dfrac1F\right)^2}}}$$

**性质**：

- $F=1$ ： $M=1$ （**最大增益**，纯阻性， $Z_{in}=R_{ac}$ ）
- $F\neq1$ ： $M<1$ → **SRC 是降压型，增益恒 ≤1**
- $Q$ 越大（重载），曲线越尖锐、 $F$ 偏离 1 时下降越快

### 6.5 步骤四：直流输出

副边电压折算到原边为 $V_o/n$ ，其基波有效值 $=\dfrac{2\sqrt2}{\pi}\dfrac{V_o}{n}$ ；该基波就是谐振腔的输出：

$$\frac{2\sqrt2}{\pi}\cdot\frac{V_o}{n}=M\cdot\frac{2\sqrt2}{\pi}V_s$$

$$\boxed{V_o=n\,V_s\,M(F,Q)=\frac{n\,V_s}{\sqrt{1+Q^2\left(F-\dfrac1F\right)^2}}}$$

### 6.6 变量定义与适用条件

| 符号 | 含义 | 范围 |
|---|---|---|
| $V_s$ | 分裂母线半压 $=V_{bus}/2$ | — |
| $n$ | 匝比 $N_s/N_p$ | — |
| $F$ | 归一化频率 $=f_s/f_r$ | $F>1$ （感性区） |
| $Q$ | 品质因数 $=Z_0/R_{ac}$ | 取决于负载 |
| $M$ | 归一化增益 | $0<M\le1$ |

**适用条件**：CCM（连续谐振电流）· **FHA 基波近似** · 理想器件 · 稳态 · $L_m$ 足够大不参与谐振。

### 6.7 调压特性与设计含义

| 调节方式 | 说明 |
|---|---|
| $f_s\uparrow$ （ $F\uparrow$ ） | $M\downarrow$ → $V_o\downarrow$ |
| $f_s\downarrow$ → $f_r$ | $M\to1$ → $V_o\to nV_s$ （**最大输出**） |
| $f_s<f_r$ （容性区） | **禁止**——ZCS 区，损耗与 EMI 恶化 |

**两个硬约束**：

1. **$V_o\le nV_s$**——SRC 无法升压。设计时必须保证**最低输入电压**下仍有 $V_o\le nV_{s,min}$
2. **全负载范围必须 $F>1$**——轻载时 $Q$ 小、曲线平坦，需要更高的 $f_s$ ，要校核最高频率是否超出驱动与 EMI 设计范围

### 6.8 与 LLC、Buck 型半桥的对比

| 对比 | 半桥 SRC | 半桥 LLC | 半桥 Buck |
|---|---|---|---|
| 电压关系 | $V_o=nV_sM(F,Q)$ | $V_o=nV_sM_{LLC}(F)$ | $V_o=ndV_g$ |
| 增益范围 | **≤1（只降压）** | **可升可降** | ≤1 |
| 调节变量 | **频率** | 频率 | 占空比 |
| 软开关 | ZVS（感性区） | ZVS（宽范围） | 硬开关为主 |
| 轻载/空载 | **困难**（ZVS 丢失、增益失控） | 可（ $L_m$ 参与谐振） | 可 |
| 变压器结构 | 简单 | 简单 | 简单 |
| 副边整流 | 全桥 | 全桥/中心抽头 | 中心抽头/全桥 |

> **LLC 相对 SRC 的关键改进**：**让励磁电感 $L_m$ 也参与谐振**——这带来两个好处：① 增益可以**大于 1**（可升压）；② 轻载时励磁电流仍能保证 ZVS，**可空载**。

## 七、稳态电流关系

### 7.1 原边谐振腔电流

**由功率守恒**（谐振腔内 $R_{ac}$ 上的功率就是输出功率）：

$$P_o=I_{pri,rms}^2\cdot R_{ac}\quad\Rightarrow\quad\boxed{I_{pri,rms}=\sqrt{\frac{P_o}{R_{ac}}}=\frac{V_{pri,1,rms}}{R_{ac}}}$$

其中 $V_{pri,1,rms}=\dfrac{2\sqrt2}{\pi}\cdot\dfrac{V_o}{n}$ 。

**峰值电流**（近似正弦）：

$$I_{pri,pk}\approx\sqrt2\,I_{pri,rms}$$

> **注意**：谐振腔电流与负载**不是线性关系**（ $I\propto\sqrt{P_o}$ ），且轻载时仍有环流。

### 7.2 开关管电流

谐振电流近似正弦， $Q_1$ 在正半周导通、 $Q_2$ 在负半周导通，各承担**半个正弦**：

$$I_{Q,rms}=\frac{I_{pri,pk}}{2}=\frac{I_{pri,rms}}{\sqrt2}$$

> **推导**：正弦 $i=I_{pk}\sin\omega t$ 的半周有效值 $=\dfrac{I_{pk}}{2}$ ；而全波有效值 $=\dfrac{I_{pk}}{\sqrt2}$ 。故半周值 = 全波值 $/\sqrt2$ 。

$$I_{Q,avg}=0\quad(\text{半周正、半周负，平均为零})$$

### 7.3 副边整流二极管

| 量 | 公式 | 说明 |
|---|---|---|
| 副边电流有效值 | $I_{sec,rms}=\dfrac{I_{pri,rms}}{n}$ | 按匝比折算 |
| 每只二极管平均电流 | $I_{D,avg}=\dfrac{I_o}{2}$ | 全桥整流，两对交替 |
| 每只二极管有效值 | $I_{D,rms}\approx\dfrac{I_{sec,rms}}{\sqrt2}$ | 每对导通半周 |
| 峰值 | $I_{D,pk}\approx\dfrac{I_{pri,pk}}{n}$ | — |

> **与中心抽头整流的对比**：全桥整流的**二极管耐压只需 $V_o$**（中心抽头需 $2V_o$ ），但每时刻有 **2 只串联导通**（压降翻倍）。

### 7.4 电容电流

**输出电容 $C_F$**：副边整流电流是脉冲式的， $C_F$ 需吸收纹波：

$$I_{C_F,rms}\approx\sqrt{I_{sec,rms}^2-I_o^2}$$

**分裂母线电容 $C_1$ 、 $C_2$**：流过半个谐振电流

$$I_{C_1,rms}=I_{C_2,rms}\approx\frac{I_{pri,rms}}{\sqrt2}$$

## 八、磁芯复位原理

### 8.1 SRC 天然无偏磁

**机制**：谐振电容 $C_r$ **串联在原边电流的必经通路上**：

- 电容不能通过直流 → 原边电流**必然无直流分量**
- 因此变压器磁通**自动双向对称**，不可能单向偏磁

$$\boxed{\text{SRC 的 }C_r\text{ 天然隔直} \Longrightarrow \text{无偏磁风险}}$$

> **这是谐振拓扑相对 PWM 隔离拓扑的重大优势**。前面五个拓扑中：半桥靠分压电容隔直、全桥需外串隔直电容、推挽完全没有隔直机制——而 **SRC 与 LLC 靠谐振电容天然隔直**，从原理上消除了偏磁问题。

### 8.2 分裂母线电容的辅助作用

$C_1$ 、 $C_2$ 也串在原边回路中（中点 X 侧），进一步保证原边无直流。

### 8.3 磁通摆幅

SRC 的磁通摆幅由**谐振腔输出到原边的电压**决定：

$$\Delta B\approx\frac{V_{pri,1}\cdot (T_s/2)}{N_pA_e}\quad(\text{近似，以基波计})$$

> 精确计算需考虑实际波形（含高次谐波）。工程上可用 FHA 结果初选磁芯，再仿真校正。

## 九、器件电压应力

### 9.1 理论最大应力

| 器件 | 应力 | 表达式 | 本案例（ $V_{bus}=400\text{V}$ ） |
|---|---|---|---|
| $Q_1$ / $Q_2$ | $V_{DS}$ | $\boxed{V_{bus}=2V_s}$ | **400V** |
| 整流二极管 | $V_{RR}$ | $\boxed{V_o}$ | **48V** |
| 谐振电容 $C_r$ | $V_{Cr,pk}$ | $\approx\dfrac{Q\cdot V_o}{n}\cdot\dfrac{\pi}{2}$ 量级 | 需按仿真确定 |

> **注意 $V_{DS}=V_{bus}$ （不是 $V_s$ ）**：半桥结构与半桥 Buck 相同——一只管子导通时，另一只承受整个母线电压。

> **$C_r$ 的电压应力容易被忽略**：谐振电容上的电压可以**远高于输入电压**（是 $Q$ 倍量级），必须按仿真峰值选型。

### 9.2 寄生参数附加应力

| 来源 | 说明 |
|---|---|
| 换流振铃 | 较小（软开关， $C_{oss}$ 参与换流） |
| 整流二极管反向恢复 | 感性区自然换流，反向恢复**轻**（这是 SRC 的优点） |

### 9.3 安全裕量与额定值

$$V_{DS,rated}\ge V_{bus}\times1.5$$

本案例： $400\times1.5=600\text{V}$ → 选 **600V/650V** 等级。

> 谐振拓扑的换流是"软"的，尖峰远小于硬开关 PWM 拓扑，因此裕量可以略小（但仍需实测确认）。

## 十、器件电流应力

### 10.1 理论电流（本案例）

**设计参数**： $V_{bus}=400\text{V}$ （ $V_s=200\text{V}$ ）→ $V_o=48\text{V}$/200W， $n=0.25$ ， $f_r=100\text{kHz}$ ， $Q=1$

$$R_{ac}=\frac{8}{\pi^2}\cdot\frac{R_{load}}{n^2}=0.810\times\frac{11.5}{0.0625}=149.2\Omega$$

$$V_{pri,1,rms}=\frac{2\sqrt2}{\pi}\cdot\frac{V_o}{n}=0.900\times\frac{48}{0.25}=172.8\text{V}$$

| 器件 | 电流 |
|---|---|
| 谐振腔 $I_{pri,rms}$ | $\dfrac{172.8}{149.2}=1.16\text{A}$ （峰值 $\approx1.64\text{A}$ ） |
| $Q_1$/$Q_2$ （每只） | $I_{Q,rms}=\dfrac{1.16}{\sqrt2}=0.82\text{A}$ |
| 副边 $I_{sec,rms}$ | $\dfrac{1.16}{0.25}=4.64\text{A}$ |
| 整流二极管（每只） | $I_{D,avg}=\dfrac{I_o}{2}=2.08\text{A}$ ； $I_{D,rms}=\dfrac{4.64}{\sqrt2}=3.28\text{A}$ |
| $C_1$/$C_2$ | $\approx0.82\text{A}$ |
| 输出电容 $C_F$ | $\sqrt{4.64^2-4.17^2}=2.04\text{A}$ |

> **注意 SRC 的电流特征**：**开关管电流很小**（软开关 + 电流近似正弦，无尖峰），但**副边电流较大**（电容滤波的脉冲电流）。

### 10.2 器件损耗

**MOSFET**

$$P_{Q,cond}=2I_{Q,rms}^2R_{DS(on)}(T_j)$$
$$P_{Q,sw}\approx\underbrace{0}_{\text{ZVS 开通}}+\underbrace{\frac12C_{oss}V_{bus}^2f_s}_{\text{关断}}$$

> **ZVS 开通损耗≈0 是 SRC 的核心价值**。关断损耗受 $C_{oss}$ 缓冲限制（ $V_{DS}$ 上升慢、电流下降快）。

**整流二极管**：

$$P_D=4\left(V_FI_{D,avg}+\tfrac12V_{RR}Q_{rr}f_s\right)$$

> 感性区反向恢复轻，第二项较小；用肖特基（ $V_{RR}=48\text{V}$ 可用）可降为零。

## 十一、谐振腔与变压器设计

### 11.1 匝数比 $n$

**约束**：SRC 增益 $M\le1$ ，且 $F>1$ 时 $M<1$ ，因此必须留出调压余量：

$$\boxed{n=\frac{V_o}{V_{s,min}\cdot M_{nom}}}$$

其中 $M_{nom}$ 取 0.8~0.95（留调压余量）。

本案例：取 $M_{nom}=0.96$ 、 $V_{s}=200\text{V}$ ：

$$n=\frac{48}{200\times0.96}=0.25$$

### 11.2 谐振腔参数 $L_r$ 、 $C_r$

**设计步骤**：

1. **选 $f_r$**（通常取略低于额定开关频率，使额定工作点在感性区）： $f_r=100\text{kHz}$
2. **算 $R_{ac}$**： $R_{ac}=\dfrac{8}{\pi^2}\dfrac{R_{load}}{n^2}=149.2\Omega$
3. **选 $Q$**： $Q=1$ （工程常用 0.5~2； $Q$ 大 → 曲线陡、调频范围窄； $Q$ 小 → 曲线平、轻载调压难）
4. **算 $Z_0$**： $Z_0=Q\cdot R_{ac}=149.2\Omega$
5. **算 $L_r$ 、 $C_r$**：

$$\boxed{L_r=\frac{Z_0}{2\pi f_r}=\frac{149.2}{6.28\times10^5}=237\mu H},\qquad \boxed{C_r=\frac{1}{2\pi f_rZ_0}=10.7nF}$$

**校验**： $f_r=\dfrac{1}{2\pi\sqrt{L_rC_r}}=100\text{kHz}$ ✓

### 11.3 磁集成：用漏感充当 $L_r$

**谐振电感可以集成到变压器里**——用变压器的**漏感**充当 $L_r$ ：

| 优点 | 代价 |
|---|---|
| 省一个独立电感 | 漏感不易精确控制（±10~20%） |
| 降低成本与体积 | 漏感随温度、频率变化 |
| 大功率下节省可观 | 需与变压器厂协同设计 |

> **重要提醒（来自本文件夹的漏感专题）**：电桥"副边短路"测出来的漏感，**正是 LLC/SRC 所看到的那个等效电感**（它包含原边漏感 + 副边漏感折算值），因此**磁集成设计时应当用电桥副边短路法测量**——这与需要"原边自身漏感"的场合是不同的口径。

**设计流程**：先按计算确定目标 $L_r$ ，再通过调整绕组结构（绝缘厚度、绕法）把变压器漏感做到该值。

### 11.4 分压电容 $C_1$ 、 $C_2$

- 容值：需足够大，使中点在半个周期内电压基本不变

$$C_1=C_2\ge\frac{I_{pri,pk}\cdot T_s}{2\Delta V_{mid}}\quad(\Delta V_{mid}\text{ 取 }5\%\cdot V_s)$$

- 需并联**均压电阻**（47kΩ~100kΩ）保证静态均压
- **注意**：与半桥 Buck 不同，SRC 的分压电容电流较小（ $I\approx I_{Q,rms}$ ，本案例 0.82A），**不是选型瓶颈** ✓——这是谐振拓扑相对 PWM 半桥的一个实际优势

### 11.5 变压器设计

- 匝比 $n=0.25$ → 取 $N_p=16$ 、 $N_s=4$
- 磁芯：双向励磁， $\Delta B$ 按 FHA 初选，仿真校正
- 绕组：原边 1.16A、副边 4.64A → 常规线径即可
- **不需要气隙**（传能型），但为了控制漏感一致性，有时需微调

## 十二、输出电容与整流设计

### 12.1 输出电容 $C_F$

SRC 副边是**全桥整流 + 电容滤波**（无滤波电感）， $C_F$ 需吸收脉冲电流：

$$\Delta V_o\approx\frac{I_o\cdot(1-D_{cond})T_s}{C_F}\quad\text{或按 }ESR\text{ 估算}$$

工程上常用：

$$C_F\ge\frac{I_o}{2f_s\Delta V_o}\cdot k\quad(k\approx0.5\sim1)$$

本案例（ $\Delta V_o\le1\%\times48\text{V}=0.48\text{V}$ ）： $C_F\ge200\sim400\mu F$ → 取 470µF/63V。

**ESR 约束**： $\Delta V_{ESR}\approx I_{D,pk}\cdot ESR$ → 需低 ESR 电容。

### 12.2 整流二极管

| 参数 | 值 | 选型要求 |
|---|---|---|
| $V_{RR}$ | $V_o=48\text{V}$ | $\ge100\text{V}$ （1.5~2 倍裕量） |
| $I_{D,avg}$ | 2.08A | $\ge4\text{A}@T_c=100°C$ |
| $I_{D,rms}$ | 3.28A | — |
| $I_{D,pk}$ | $\approx6.6\text{A}$ | — |

> **推荐肖特基**： $V_{RR}=48\text{V}$ 完全在肖特基范围内，且**零反向恢复**——在谐振拓扑中尤其有价值（虽然感性区反向恢复已较轻，但肖特基可完全消除）。或用同步整流进一步降损。

## 十三、关键工程问题

### 13.1 轻载时 ZVS 丢失

**问题**： $i_{Lr}$ 幅值随负载下降 → 死区内不足以完成 $C_{oss}$ 充放电 → ZVS 丢失 → 开关损耗上升、效率恶化、EMI 变差。

**对策**：
1. **适当增大 $L_m$ 的励磁电流**（但 SRC 的 $L_m$ 不参与谐振，此法受限——**这正是 LLC 的解决思路**）
2. 增大死区时间（但会压缩有效导通时间）
3. 轻载降频 / 跳周期（burst mode）
4. 选 $C_{oss}$ 更小的器件

### 13.2 频率范围与 EMI

**问题**：负载从满载到轻载， $f_s$ 可能变化 2~3 倍。EMI 滤波器必须按**最低频率**设计（否则低频谐波超标），而磁性元件按**最高频率**设计。

**对策**：
1. 合理选择 $Q$ （ $Q$ 大 → 曲线陡 → 频率范围窄）
2. 限制最小负载（假负载）
3. EMI 滤波器按全频段设计，留足裕量

### 13.3 启动与短路保护

| 问题 | 对策 |
|---|---|
| **启动冲击**（输出电容未充电，等效短路） | 从**高频**启动（ $f_s\gg f_r$ ，增益低），再逐渐降低频率 |
| **短路** | 检测后立即升频到最高（增益最低）；或用逐周期限流 |
| **谐振电容 $C_r$ 承受高压** | 按仿真峰值选型（可远高于 $V_{bus}$ ） |

### 13.4 谐振参数容差

$L_r$ 、 $C_r$ 的容差（尤其磁集成时漏感的容差 ±10~20%）会直接影响 $f_r$ 与 $Q$ ：

- $f_r$ 偏移 → 工作点偏移 → 增益偏差
- 对策：**用谐振电容的容差补偿电感的容差**（电容精度高，可用它来微调 $f_r$ ）；设计时留足增益余量

### 13.5 PCB 布局

| 要求 | 原因 |
|---|---|
| 谐振腔回路面积最小 | 谐振电流是高频正弦，回路面积影响 EMI 与损耗 |
| 分压电容紧贴半桥 | 换流回路最短 |
| 两管驱动等长 | 保证 50% 互补对称 |
| 高边驱动隔离/自举 | $Q_1$ 源极浮动 |
| **整流回路面积最小** | 副边脉冲电流 di/dt 大 |

### 13.6 热设计

- 2 管软开关，损耗小且分散
- 谐振电感（若非磁集成）是独立热源
- 整流二极管是主要热源之一

## 十四、损耗与效率估算

### 14.1 损耗构成（本案例）

| 损耗项 | 公式 | 估算 |
|---|---|---|
| $Q$ 导通 | $2I_{Q,rms}^2R_{DS(on)}\times1.5$ | $2\times0.82^2\times0.5\times1.5=1.0\text{W}$ |
| $Q$ 关断（ZVS 开通，无开通损耗） | $2\times\tfrac12C_{oss}V_{bus}^2f_s$ | $2\times0.5\times200p\times400^2\times1.2\times10^5=3.8\text{W}$ |
| $Q$ 驱动 | $2Q_gV_{gs}f_s$ | ≈0.2W |
| 整流二极管 | $4V_FI_{D,avg}$ （肖特基 $V_F=0.5\text{V}$ ） | $4\times0.5\times2.08=4.2\text{W}$ |
| 铜损（原/副边 + 谐振电感） | $I^2R_{dc}$ | ≈3.5W |
| 磁芯损耗 | Steinmetz（高频下显著） | ≈2.5W |
| 谐振电容 ESR | $I_{pri,rms}^2ESR_{Cr}$ | ≈0.3W |
| 其他 | — | ≈1.0W |
| **合计** | | **≈16.5W** |
| **效率** | | **≈92.4%** |

> **SRC 的效率特征**：**满载效率高且平坦**（软开关），但**轻载效率下降快**（ZVS 丢失 + 谐振腔环流不变）。这与 PWM 拓扑的"满载难做高效率"正好相反。

### 14.2 效率优化优先级

1. **关断损耗**（ $C_{oss}$ 越大越差）→ 选低 $C_{oss}$ 器件
2. **整流损耗** → 肖特基/同步整流
3. **磁芯损耗**（高频下显著）→ 低损材质（PC95 等）、优化 $\Delta B$
4. **铜损** → 优化绕组结构（含谐振电感）

## 十七、优缺点与适用场景

### 17.1 优点

1. **软开关（ZVS）**——开关损耗极低，可做高频高密度
2. **天然隔直、无偏磁**——$C_r$ 串联在原边回路
3. **副边二极管反向恢复轻**——感性区自然换流
4. **EMI 相对好**——谐振电流正弦化，di/dt 低
5. **变压器简单**——非中心抽头
6. **分压电容负担小**——与半桥 Buck 相比，SRC 的分压电容电流小得多

### 17.2 缺点

1. **只能降压**（ $M\le1$ ）——宽输入范围困难
2. **轻载调压困难、ZVS 易丢失**
3. **频率变化范围大**——EMI 与驱动设计复杂
4. **无法空载**——需假负载
5. **谐振腔环流**——轻载时仍有环流损耗
6. **设计复杂**——谐振参数耦合，需迭代 + 仿真

### 17.3 适用场景结论

> **在"输入范围较窄 + 需要高频高功率密度 + 输出电流较大"的条件下，SRC 更合适**——它的软开关与天然隔直是 PWM 隔离拓扑难以企及的。
>
> **但如果输入范围宽（如 85~265VAC）或需要空载/升压，就必须改用 LLC**——LLC 通过让励磁电感参与谐振，把 SRC 的三个短板（不能升压、轻载困难、不能空载）全部补上了。

| 设计条件 | 更合适的拓扑 | 原因 |

## 十九、公式速查

### 19.1 谐振参数与控制

| 参数 | 公式 |
|---|---|
| 谐振频率 | $f_r=\dfrac{1}{2\pi\sqrt{L_rC_r}}$ |
| 特征阻抗 | $Z_0=\sqrt{\dfrac{L_r}{C_r}}$ |
| 归一化频率 | $F=\dfrac{f_s}{f_r}$ |
| 品质因数 | $Q=\dfrac{Z_0}{R_{ac}}$ |
| 等效交流电阻 | $R_{ac}=\dfrac{8}{\pi^2}\cdot\dfrac{R_{load}}{n^2}$ |

### 19.2 增益与传输比

| 参数 | 公式 |
|---|---|
| 谐振腔增益 | $M(F,Q)=\dfrac{1}{\sqrt{1+Q^2\left(F-\frac1F\right)^2}}$ ， $M\le1$ |
| 直流输出 | $V_o=nV_sM(F,Q)$ |
| 方波基波有效值 | $V_{SW,1}=\dfrac{2\sqrt2}{\pi}V_s\approx0.9V_s$ |
| 最大输出 | $V_{o,max}=nV_s$ （ $F=1$ ） |

### 19.3 电压应力

| 器件 | 公式 |
|---|---|
| MOSFET | $V_{DS}=V_{bus}=2V_s$ |
| 整流二极管 | $V_{RR}=V_o$ |
| 谐振电容 | $V_{Cr,pk}$ 按仿真（可达 $Q\cdot V_o/n$ 量级）★ |

### 19.4 电流应力

| 器件 | 公式 |
|---|---|
| 谐振腔 | $I_{pri,rms}=\sqrt{\dfrac{P_o}{R_{ac}}}=\dfrac{V_{pri,1,rms}}{R_{ac}}$ ， $I_{pri,pk}=\sqrt2I_{pri,rms}$ |
| MOSFET（每只） | $I_{Q,rms}=\dfrac{I_{pri,pk}}{2}=\dfrac{I_{pri,rms}}{\sqrt2}$ |
| 副边 | $I_{sec,rms}=\dfrac{I_{pri,rms}}{n}$ |
| 整流二极管（每只） | $I_{D,avg}=\dfrac{I_o}{2}$ ， $I_{D,rms}\approx\dfrac{I_{sec,rms}}{\sqrt2}$ |

### 19.5 谐振腔设计

| 参数 | 公式 |
|---|---|
| 匝比 | $n=\dfrac{V_o}{V_{s,min}M_{nom}}$ ， $M_{nom}=0.8\sim0.95$ |
| 谐振电感 | $L_r=\dfrac{Z_0}{2\pi f_r}=\dfrac{Q R_{ac}}{2\pi f_r}$ |
| 谐振电容 | $C_r=\dfrac{1}{2\pi f_rZ_0}=\dfrac{1}{2\pi f_rQR_{ac}}$ |
| ZVS 死区条件 | $t_{dead}\ge\dfrac{2C_{oss}V_s}{I_{Lr}(\text{换流时刻})}$ |

## 二十、学习总结

### 20.1 一句话记住这个拓扑

> **半桥 SRC = 半桥斩波 + 串联 LC 谐振腔 + 变压器 + 全桥整流。**
> **固定 50% 占空比，靠变频调压**；谐振腔阻抗随频率变化 → 增益 $M\le1$ ；感性区实现 ZVS。

### 20.2 五个必须刻在脑子里的数

| 数 | 值 | 来源 |
|---|---|---|
| 主开关占空比 | **固定 50%** | 互补驱动，无占空比控制 |
| 控制变量 | **$f_s$ （频率）** | 谐振腔阻抗随频率变化 |
| 增益上限 | **$M\le1$** | 串联谐振腔只能分压，不能升压 |
| ZVS 条件 | **$F>1$ （感性区）** | 电流滞后电压 |
| 天然隔直 | **$C_r$ 串联在原边通路** | 无偏磁风险 |

### 20.3 三个"为什么"

**Q1：为什么 SRC 没有占空比？**
A：因为主开关**必须固定 50% 互补**——只有这样，半桥中点输出的方波才对称，谐振腔才能得到纯交流激励。调压靠改变**开关频率**： $f_s$ 升高 → 谐振腔阻抗升高 → 分压比下降 → 输出降低。

**Q2：为什么 SRC 只能降压，而 LLC 可以升压？**
A：因为 SRC 的谐振腔是**串联**的——谐振腔与负载构成分压网络， $M=R_{ac}/|Z_{tank}|$ ，在谐振点达到最大 $M=1$ ，无法超过。LLC 让**励磁电感 $L_m$ 也参与谐振**，构成"串并联"双谐振腔——在第二个谐振点附近， $L_m$ 与 $C_r$ 谐振会产生"电压泵升"效应，从而实现 $M>1$ 。

**Q3：为什么必须工作在感性区（ $F>1$ ）？**
A：感性区电流**滞后**电压 → 关断时电流仍沿原方向 → 死区内该电流给待开通管的 $C_{oss}$ 放电、使其 $V_{DS}$ 降到零 → **ZVS 开通**。若进入容性区（ $F<1$ ），电流超前，关断时电流已反向 → 开通时 $C_{oss}$ 上的电荷被**直接短路泄放** → 开通损耗极大、EMI 恶化，且副边二极管反向恢复严重。

### 20.4 学完之后你应该能

- [ ] 看到"半桥 + 串联 LC + 全桥整流"立刻判断是 SRC，并说出"50% 固定占空比 + 变频控制"
- [ ] 画出 4 个模态（含两个死区）的电流路径与状态表
- [ ] 独立完成 FHA 推导 $M(F,Q)$ 与 $V_o=nV_sM$
- [ ] 说清 ZVS 的物理机理与感性区/容性区的区别
- [ ] 正确计算 $R_{ac}=(8/\pi^2)R_{load}/n^2$ （注意 $n$ 的方向）
- [ ] 解释 SRC 的三个短板（不能升压、轻载难、不能空载）以及 LLC 如何补齐
- [ ] 按流程设计谐振腔 $L_r$ 、 $C_r$

## 二十一、勘误说明（相对原版笔记）

| # | 原版说法 | 本笔记修正 | 性质 |
|---|---|---|---|
| 1 | $n=N_p/N_s$ （原文虽未显式写出，但从 $V_O=\frac{V_s}{n}M$ 与 $R_{ac}\propto n^2$ 可反推） | **统一为 $n=N_s/N_p$**；相应公式改为 $V_o=nV_sM$ 、 $R_{ac}=\frac{8}{\pi^2}\frac{R_{load}}{n^2}$ | **符号口径不一致**——与全库其余五篇相反，横向比较时极易出错 |
| 2 | 未明确"SRC 没有占空比" | 显式声明：**主开关固定 50% 互补，控制变量是频率** | 缺失关键概念（任务书要求明确区分） |
| 3 | "SRC 的副边是全桥整流"（未与其它拓扑统一说明） | 补充：全桥整流的**二极管耐压只需 $V_o$**（中心抽头需 $2V_o$ ），但**压降翻倍** | 补充对比 |
| 4 | 未提 $C_r$ 的电压应力 | 补充：**$C_r$ 承受的电压可远高于 $V_{bus}$**，必须按仿真峰值选型 | 缺失关键选型项 |
| 5 | 未提分压电容在 SRC 中的角色 | 补充：SRC 的分压电容电流**很小**（ $I_{Q,rms}$ 量级），**不是选型瓶颈**——与半桥 Buck 形成鲜明对比 | 补充对比 |
| 6 | 未提 FHA 的适用条件与误差 | 补充：FHA 仅在 $f_s$ 接近 $f_r$ 时准确（±10%），**最终需仿真/实测校正** | 缺失适用条件 |

> **根因分析**：原版的 $n$ 定义与其它五篇相反，是因为它是从另一套资料整理的。**教训：跨文档整理时，第一件事是核对符号口径——尤其是匝比这种"方向性"符号。**
