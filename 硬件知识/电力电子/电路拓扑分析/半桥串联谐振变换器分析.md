# 半桥串联谐振变换器——拓扑、模态与选型分析

---

## 一、拓扑概述

### 1.1 拓扑名称

**半桥串联谐振变换器**（Half-Bridge Series Resonant Converter，简称 **Half-bridge SRC**）。

### 1.2 电路结构与宏观工作机理

| 环节 | 功能 |
|------|------|
| ① 分压网络（ $C_1$ 、 $C_2$ ）| 将 $V_{in}$ 一分为二，中点提供 $V_s$ 直流电位，作为变压器原边一端 |
| ② 半桥逆变（ $Q_1$ 、 $Q_2$ ）| 互补 50% 占空比 + 死区，开关节点输出 $\pm V_s$ 方波 |
| ③ 串联谐振腔（ $L_r$ 、 $C_r$ ）| **唯一储能网络**， $L_r$ 与 $C_r$ 串联，决定谐振频率与电流波形 |
| ④ 高频变压器（ $n:1$ ）| 电压变换 + 电气隔离；励磁电感 $L_m$ 不参与谐振 |
| ⑤ 全桥整流（ $D_3$~$D_6$ ）| 双极性→单向脉动，输出由 $C_F$ 平滑 |

**控制逻辑**： $Q_1$ 、 $Q_2$ 互补导通（各 50% 占空比、留死区），通过调节开关频率 $f_s$ （相对谐振频率 $f_r$ ）控制输出电压——**变频调压**，这是 SRC 与 Buck 型拓扑（调占空比）的本质区别。

> **▎为什么半桥输出是 $\pm V_s$ 而非 $\pm V_{in}$ ？**
>
> 两路电压源 $V_s$ 正向串联构成母线 $V_{in} = 2V_s$ ，中点作为参考。 $Q_1$ 导通时开关节点接到 $+V_{in}$ 端（对中点 $+V_s$ ）， $Q_2$ 导通时接到 $V_{in}^-$ 端（对中点 $-V_s$ ），因此变压器原边看到的方波幅值为 $\pm V_s$ ，是全桥（ $\pm V_{in}$ ）的一半。
>
> 物理实现上，单路 $V_{in}$ 母线由两只等值分压电容 $C_1 = C_2$ 串联实现（并联均压电阻），结构与 [半桥隔离Buck变换器分析](半桥隔离Buck变换器分析.md) 的分压电容完全一致。

**与 LLC 拓扑的核心差异**：本拓扑为**纯串联谐振**，谐振腔仅由 $L_r$ 与 $C_r$ 串联构成，变压器励磁电感 $L_m$ **仅作为激磁元件存在，不参与谐振过程**，谐振腔负载经整流折算为纯阻性。LLC 中 $L_m$ 与 $L_r$ 、 $C_r$ 共同参与谐振，产生两个谐振频率，且 $L_m$ 在周期内参与能量交换——两者本质不同。**本解析全程不引入 LLC 概念， $L_m$ 不参与任何谐振分析。**

### 1.3 优点

1. **结构简洁**——较全桥 SRC 减少一半开关管及对应驱动电路，成本降低
2. **可实现 ZVS 软开关**——感性区（ $F>1$ ）可显著降低开通损耗，提升效率
3. **EMI 性能良好**——谐振网络对电流波形有滤波作用，谐波含量低
4. **固有短路保护能力**——串联谐振电容隔直，谐振网络阻抗限制短路电流
5. **窄调频范围**——变频即可覆盖额定工况，控制相对简单
6. **副边二极管自然换流**——感性区整流二极管反向恢复应力小

### 1.4 缺点

1. **功率等级受限**——半桥结构原边电压利用率仅为全桥的一半，适合中功率场景
2. **ZVS 范围有限**——轻载下 ZVS 容易丢失，需要辅助措施或变频/突发控制策略
3. **关断为硬关断**——感性区虽实现 ZVS 开通，但关断损耗依然存在
4. **谐振电容电压应力较高**——串联谐振电容承受较大谐振电压摆幅
5. **增益 ≤ 1（降压型）**——无法靠拓扑本身升压，需变压器匝比承担大部分降压
6. **宽调压能力弱于 LLC**——增益曲线扁平，宽电压范围需配合移相或混合控制

### 1.5 适用场景

| 场景 | 是否适合 | 原因 |
|------|:---:|------|
| 电动汽车车载充电机（OBC）前端 DC/DC | ✅ 最佳 | 400V 母线→电池，隔离 + 高效率 + 定频/窄调频 ZVS |
| 服务器电源（400V→48V/12V）| ✅ | 中高功率，窄调频控制即可，无需复杂 LLC 控制 |
| 通信电源（48V→12V）| △ | 低压半桥 SRC 应用较少，Buck 型更常见 |
| 大功率（>10kW）| △ | 半桥电压利用率低，倾向全桥 LLC |
| 宽调压范围（电池全电压段充电）| △ | 增益 ≤1 且曲线扁平，LLC 的宽增益更灵活 |

## 二、高频开关周期模态分析

> **分析假设**（全文适用）：
> ① 电路工作于 **CCM 连续导通模式**，谐振电流连续；
> ② 忽略所有器件导通压降（MOS 管导通电阻、二极管正向压降）；
> ③ 忽略线路寄生电阻、电容、电感（除 MOS 管 $C_{oss}$ 外）；
> ④ 输出滤波电容 $C_F$ 足够大，输出电压纹波忽略；
> ⑤ 理想变压器，励磁电感 $L_m$ 不参与能量传输与谐振。

本章仅分析电路基础运行过程，聚焦能量传递路径，ZVS/ZCS 软开关机制留待第四章。电路具有**半周期对称性**，分析前半周期（ $Q_1$ 导通）与后半周期（ $Q_2$ 导通）即可完整描述。

### 2.1 模态 1： $Q_1$ 导通、 $Q_2$ 关断（正向功率传输）——$[t_0, t_1]$

- **开关管状态**： $Q_1$ 导通， $Q_2$ 关断；
- **半桥输出电压**： $V_{SW} = +V_s$ （开关节点对中点电位）；
- **谐振腔状态**：
  - $i_{Lr}$ 从负值或零开始正向增加（或继续正向流动），呈近似正弦上升趋势；
  - $v_{Cr}$ 被谐振电流充放电，按正弦规律变化；
- **能量流向**：
  1. 输入源 $+V_s$ 经 $Q_1$ 向谐振腔注入能量；
  2. 谐振腔中 $L_r$ 与 $C_r$ 互相交换能量，同时将部分能量传递至变压器原边；
  3. 变压器副边通过全桥整流向输出滤波电容 $C_F$ 和负载 $R_{load}$ 提供能量；
  4. 输出端 $C_F$ 处于充电状态，同时向负载放电。

### 2.2 模态 2： $Q_1$ 关断、 $Q_2$ 未导通（死区，正向电流续流）——$[t_1, t_2]$

- **开关管状态**： $Q_1$ 、 $Q_2$ 均关断（处于死区）；
- **半桥输出电压**： $V_{SW}$ 由谐振电流方向决定。此时 $i_{Lr} > 0$ （正向），电流通过 $Q_2$ 的体二极管 $D_2$ 续流， $V_{SW}$ 被钳位至 $-V_s$ ；
- **谐振腔状态**：
  - $i_{Lr}$ 继续正向流动但幅值开始下降；
  - $v_{Cr}$ 继续按谐振规律变化；
- **能量流向**：谐振电感储能通过体二极管 $D_2$ 回馈至下侧电源 $-V_s$ ；输出端依靠 $C_F$ 放电维持负载供电。

### 2.3 模态 3： $Q_2$ 导通、 $Q_1$ 关断（负向功率传输）——$[t_2, t_3]$

- **开关管状态**： $Q_2$ 导通， $Q_1$ 关断；
- **半桥输出电压**： $V_{SW} = -V_s$ ；
- **谐振腔状态**：
  - $i_{Lr}$ 从正向过零后变为负向流动，呈近似正弦负向增长；
  - $v_{Cr}$ 继续按正弦规律变化，极性反转；
- **能量流向**：
  1. 输入源 $-V_s$ （即下侧电源）经 $Q_2$ 向谐振腔注入能量；
  2. 谐振腔储能通过变压器传递至副边；
  3. 副边全桥整流输出仍为正向（因变压器副边电压反向，但整流桥自动换向导通）；
  4. 输出电容 $C_F$ 继续充电并向负载供电。

### 2.4 模态 4： $Q_2$ 关断、 $Q_1$ 未导通（死区，负向电流续流）——$[t_3, t_4]$

与模态 2 对称。 $i_{Lr} < 0$ （负向），电流通过 $Q_1$ 的体二极管 $D_1$ 续流， $V_{SW}$ 被钳位至 $+V_s$ 。谐振电感释放磁储能至上侧输入源 $+V_s$ ；输出端由 $C_F$ 供电。

### 2.5 关键波形汇总（一个周期）

```
         模态1      模态2      模态3      模态4
          Q1导通     死区       Q2导通     死区
VSW:     +Vs   →   -Vs        -Vs   →   +Vs
iLr:    正弦正半周  正向续流   正弦负半周  负向续流
vCr:    正弦充/放  继续谐振    反相充/放  继续谐振
 i:     过零后上升  逐渐下降    反向过零   反向减小
```

**关键**： $i_{Lr}$ 过零点的位置由工作频率与谐振频率的相对关系决定，这也是第四章 ZVS/ZCS 区分的物理依据。

## 三、输入-输出电压关系推导

### 3.1 谐振参数定义

谐振频率（角频率与频率）：

$$\omega_r = \frac{1}{\sqrt{L_r C_r}}, \qquad f_r = \frac{\omega_r}{2\pi} = \frac{1}{2\pi\sqrt{L_r C_r}}$$

特征阻抗：

$$Z_0 = \sqrt{\frac{L_r}{C_r}}$$

归一化频率： $F = f_s / f_r$ ，开关角频率 $\omega_s = 2\pi f_s$ 。

品质因数（反映负载对谐振腔的影响）：

$$Q = \frac{Z_0}{R_{ac}}$$

其中 $R_{ac}$ 为从原边看入的等效交流负载。副边全桥整流加电容滤波的等效交流电阻：

$$R_{ac} = \frac{8}{\pi^2}\cdot\frac{n^2 V_O}{I_O} = \frac{8n^2}{\pi^2}R_{load}$$

### 3.2 谐振网络 FHA 等效与归一化增益

采用基波近似（FHA）。半桥开关节点方波 $\pm V_s$ 的基波有效值：

$$V_{s,\text{fund}} = \frac{2\sqrt{2}}{\pi}V_s \approx 0.9\,V_s$$

谐振腔（ $L_r$ 、 $C_r$ 串联）与 $R_{ac}$ 构成串联谐振网络。以 $R_{ac}$ 归一化的输入阻抗：

$$Z_n = 1 + jQ\left(F - \frac{1}{F}\right)$$

谐振网络电压增益（输出基波 / 输入基波）：

$$\boxed{M(F,Q) = \frac{1}{\sqrt{1 + Q^2\left(F - \dfrac{1}{F}\right)^2}}}$$

- $F = 1$ ： $M = 1$ （**最大增益**，纯阻性， $Z_{in} = R_{ac}$ ）
- $F \neq 1$ ： $M < 1$ → **SRC 为降压型**，增益恒 ≤ 1

### 3.3 输出电压与开关频率的关系

$$V_O = \frac{V_s}{n}\cdot M(F,Q)$$

$$\boxed{V_O = \frac{V_s}{n}\cdot\frac{1}{\sqrt{1 + Q^2\left(F - \dfrac{1}{F}\right)^2}}}$$

**调节方式**：改变 $f_s$ （即 $F$ ）调节输出——$f_s$ 升高 → $M$ 下降 → $V_O$ 下降。这与 Buck 型"调占空比"、Boost 型"占空比反比"均不同，SRC 靠的是**谐振网络阻抗随频率变化**。

### 3.4 与 LLC、Buck 型半桥的关键对比

| 对比 | 半桥 SRC | 半桥 LLC | 半桥 Buck |
|------|:---:|:---:|:---:|
| 电压关系 | $V_O = \dfrac{V_s}{n}M(F,Q)$ | $V_O = \dfrac{V_s}{n}M_{LLC}(F)$ | $V_O = nDV_{in}/2$ |
| 增益范围 | ≤ 1（降压型）| 可升可降 | ≤ 1 |
| 调节变量 | 频率 | 频率 | 占空比 |
| 软开关 | ZVS（感性区）| ZVS（宽范围）| 硬开关为主 |

## 四、SRC 软开关专题：ZVS 与 ZCS

### 4.1 工作区域总体划分

| 频率条件 | 谐振腔阻抗特性 | $i_{Lr}$ 与 $V_{SW}$ 相位关系 | 原边开关管特性 | 副边整流二极管特性 | 工程评价 |
|---|---|---|---|---|---|
| $F > 1$ （感性区）| 感性（ $Z_{in}$ 阻抗角 $>0$ ）| 电流滞后电压，关断后电流维持原方向 | 可实现 **ZVS 开通**；关断为硬关断 | 自然换流，反向恢复较轻 | **推荐工作区** |
| $F = 1$ （谐振点）| 纯阻性（ $Z_{in}=R_{ac}$ ）| 电流与电压同相 | 硬开通、硬关断 | 硬开关换流 | 一般不工作于该点 |
| $F < 1$ （容性区）| 容性（ $Z_{in}$ 阻抗角 $<0$ ）| 电流超前电压，关断前电流已反向 | 可实现 **ZCS 关断**；开通为硬开通 | 反向恢复严重 | **不推荐使用** |

### 4.2 感性区 $F > 1$ ，ZVS 开通工作模态分析

开关频率高于谐振频率（ $f_s > f_r$ ），谐振腔输入阻抗呈感性， $i_{Lr}$ 相位滞后于 $V_{SW}$ 基波分量。以 $Q_1$ 导通半周期为起点分析半个开关周期（ $T_s/2$ ）。

#### 模态 ZVS-1： $Q_1$ 导通，正向功率传输——$[t_0, t_1]$

- **$Q_1/Q_2$ 状态**： $Q_1$ 导通， $Q_2$ 关断；
- **半桥输出电压**： $V_{SW} = +V_s$ ；
- **$i_{Lr}$ 状态**：感性区 $i_{Lr}$ 滞后于 $V_{SW}$ ， $V_{SW}$ 跃变为 $+V_s$ 时 $i_{Lr}$ 仍为负值，随后穿越零点、正向增长至最大值后下降；
- **$v_{Cr}$ 状态**：随谐振电流呈正弦变化；
- **$V_{DS}$ 状态**： $Q_1$ 导通时 $V_{DS1} \approx 0$ ， $Q_2$ 关断时 $V_{DS2} \approx 2V_s$ （下管承受母线电压）；
- **$C_{oss}$ 状态**： $Q_2$ 的 $C_{oss2}$ 在 $2V_s$ 电压下充电完成。

> **关键**：因 $i_{Lr}$ 滞后， $Q_1$ 导通末期（准备关断时） $i_{Lr}$ 仍为**正向正值**，即关断时刻的电流。

#### 模态 ZVS-2： $Q_1$ 关断，进入死区 $t_{dead}$——$[t_1, t_2]$

- **$Q_1/Q_2$ 状态**：两者均关断，处于死区；
- **$V_{SW}$ 状态**： $Q_1$ 关断瞬间 $i_{Lr}$ 为正值、无法突变，强迫电流在上下管 $C_{oss}$ 之间分配——对 $Q_1$ 的 $C_{oss1}$ 充电，同时对 $Q_2$ 的 $C_{oss2}$ 放电；
- **$V_{DS}$ 变化**： $V_{DS1}$ 从 0 开始上升（ $C_{oss1}$ 充电）， $V_{DS2}$ 从 $2V_s$ 开始下降（ $C_{oss2}$ 放电）；
- **体二极管状态**： $C_{oss2}$ 放电至零后， $V_{DS2}$ 变负， $Q_2$ 的体二极管 $D_2$ **正向导通**，续流 $i_{Lr}$ ；
- **$i_{Lr}$ 状态**：从正值逐渐减小，但保持正向。

> **关键物理过程**： $i_{Lr}$ 充当给 $C_{oss}$ 充放电的"恒流源"，将 $Q_1$ 关断时结电容中的能量转移。

#### 模态 ZVS-3：体二极管 $D_2$ 导通，ZVS 开通条件成熟——$[t_2, t_3]$

- **$Q_1/Q_2$ 状态**：两管仍均关断，但体二极管 $D_2$ 已导通；
- **$V_{SW}$ 状态**： $D_2$ 导通将 $V_{SW}$ 钳位至 $-V_s$ （忽略二极管压降）；
- **$V_{DS}$ 状态**： $V_{DS1} = V_{in} = 2V_s$ （ $Q_1$ 完全关断）， $V_{DS2} \approx 0$ （被体二极管钳位）；
- **$i_{Lr}$ 状态**：正向电流经 $D_2$ 续流，逐渐减小并接近零点；
- **体二极管状态**： $D_2$ 持续导通，为谐振电流提供续流通路，**同时将 $Q_2$ 的 $V_{DS}$ 钳位到近乎零伏**。

> **ZVS 开通条件**：死区内 $i_{Lr}$ 必须在 $D_2$ 导通期间将 $C_{oss2}$ 完全放电且 $D_2$ 持续导通，此时驱动 $Q_2$ 即可实现**零电压开通**（ $V_{DS2}\approx0$ 时开通）。

#### 模态 ZVS-4： $Q_2$ ZVS 开通，负向功率传输——$[t_3, t_4]$

- **$Q_1/Q_2$ 状态**： $Q_1$ 关断， $Q_2$ 导通（ $D_2$ 导通后施加驱动，实现 ZVS）；
- **$V_{SW}$ 状态**： $V_{SW} = -V_s$ ；
- **$i_{Lr}$ 状态**： $V_{SW}$ 跳变为 $-V_s$ 后， $i_{Lr}$ 仍为正方向流动一段时间（感性电流滞后），随后过零进入负向；
- **$V_{DS}$ 状态**： $Q_2$ 导通后 $V_{DS2} \approx 0$ ， $Q_1$ 的 $V_{DS1} = 2V_s$ 。

**至此完成半个周期的 ZVS 过程；另外半周期 $Q_1$ 的 ZVS 开通同理，由负向电流通过 $D_1$ 完成 $C_{oss1}$ 放电。**

**ZVS 物理本质**：半桥 SRC 的 ZVS 依赖**谐振电流滞后于半桥输出电压**。关断时谐振电流方向与原导通管电流方向一致，该电流在死区内对另一管的 $C_{oss}$ 放电、对当前管的 $C_{oss}$ 充电，使待开通管 $V_{DS}$ 降至零、体二极管导通，从而实现零电压开通。

### 4.3 容性区 $F < 1$ ，ZCS 关断工作模态分析

开关频率低于谐振频率（ $f_s < f_r$ ），谐振腔输入阻抗呈容性， $i_{Lr}$ 相位超前于 $V_{SW}$ 基波分量。

#### 模态 ZCS-1： $Q_1$ 导通，正向功率传输

- **$i_{Lr}$ 状态**：电流超前， $V_{SW}$ 跃变为 $+V_s$ 时 $i_{Lr}$ 已为正，导通期间先增大后减小，**在 $Q_1$ 关断前已过零并变为负值**；
- **$v_{Cr}$ 状态**：容性区 $v_{Cr}$ 变化幅度大于感性区；
- **$V_{DS}$ 状态**： $Q_1$ 导通 $V_{DS1}\approx0$ ， $Q_2$ 的 $V_{DS2}\approx2V_s$ 。

#### 模态 ZCS-2： $Q_1$ 关断（电流已反向）

- **$i_{Lr}$ 状态**： $Q_1$ 关断瞬间 $i_{Lr}$ 已经反向（负值），电流从半桥节点流出的方向已改变；
- **$V_{SW}$ 状态**：负向电流通过 $Q_1$ 、 $Q_2$ 的 $C_{oss}$ 流通，对 $C_{oss1}$ 放电、对 $C_{oss2}$ 充电。

> **ZCS 关断实现机理**：电流超前使 $Q_1$ 关断时 $i_{Lr}$ 已接近零或幅值很小，满足"关断时电流小"的条件，可实现**近似零电流关断**（ZCS）。

#### 模态 ZCS-3：体二极管导通与硬开通问题

- **$V_{SW}$ 状态**：负向电流最终使 $Q_1$ 的体二极管 $D_1$ 导通（而非 $Q_2$ 的 $D_2$ ），将 $V_{SW}$ 钳位至 $+V_s$——**与感性区死区行为截然相反，待开通的 $Q_2$ 体二极管未导通**。

> ⚠️ **致命缺陷一：硬开通问题**
>
> 容性区 $Q_1$ 关断后谐振电流已反向，负向电流将 $C_{oss1}$ 放电、 $C_{oss2}$ 充电。最终导通的是**$Q_1$ 的体二极管 $D_1$**（与已关断的 $Q_1$ 同管），而待开通的 $Q_2$ 的 $V_{DS2}$ 不仅未放电至零，反而被充电到更高的 $2V_s$ 。死区结束、 $Q_2$ 被驱动开通时 $V_{DS2}\approx2V_s$ ，产生**巨大硬开通损耗**。

> ⚠️ **致命缺陷二：体二极管反向恢复**
>
> 电流超前使开关管开通时体二极管可能处于反向恢复状态。例如 $Q_2$ 开通时若其体二极管 $D_2$ 之前导通并储存了大量少数载流子， $Q_2$ 开通瞬间 $D_2$ 反向恢复电流叠加在谐振电流上，产生极大的电流尖峰和反向恢复损耗，严重时可损坏开关管。

**副边整流二极管状态**：容性区副边整流二极管换流时存在反向恢复问题，因谐振电流过零时 $di/dt$ 较大，二极管反向恢复电流增大，进一步增加损耗和噪声。

### 4.4 谐振点 $F = 1$ 工况

当 $f_s = f_r$ 时，谐振腔输入阻抗为纯阻性， $i_{Lr}$ 与 $V_{SW}$ 基波同相。

- 开关管关断时电流不为零 → **硬关断**；
- 开关管开通时 $V_{DS}$ 不为零 → **硬开通**；
- 副边二极管换流为**硬换流**，反向恢复问题明显；
- 虽然谐振点无功环流最小、理论效率较高，但全部开关器件硬开关，开关损耗显著增大。

因此 SRC 一般不工作在精确谐振点，而是选择略高于谐振频率的感性区（ $F$ 略大于 1），在效率与软开关之间折中。

### 4.5 ZVS 实现约束与轻载丢失

**死区时间条件**： $t_{dead}$ 必须足够长，使谐振电流在死区内完成对另一管 $C_{oss}$ 的完全放电：

$$t_{dead} \geq \frac{2C_{oss}V_s}{\left|i_{Lr}(t_{off})\right|}$$

其中 $i_{Lr}(t_{off})$ 为关断时刻的谐振电流瞬时值。但 $t_{dead}$ 也不宜过长，否则体二极管导通时间过长、导通损耗增加。

**最小谐振电流幅值条件**：关断时刻电流必须足够大，以确保死区内完成 $C_{oss}$ 充放电：

$$\boxed{\left|i_{Lr}(t_{off})\right| \geq \frac{2C_{oss}V_s}{t_{dead}}}$$

该式是 ZVS 实现的**核心工程约束**。

**轻载下 ZVS 丢失机理**：负载减小时 $R_{ac}$ 增大（ $Q = Z_0/R_{ac}$ 减小），谐振电流幅值 $|i_{Lr}|$ 随之下降。轻载下：

- 关断时刻的 $i_{Lr}(t_{off})$ 不足以在固定死区内完成 $C_{oss}$ 的完全充放电；
- 死区结束时待开通管的 $V_{DS}$ 尚未降至零，体二极管未导通；
- 此时施加驱动信号将导致**硬开通**，产生开关损耗和 EMI 噪声。

因此半桥 SRC 的 ZVS 范围受负载条件限制，轻载时必须通过变频、调脉宽或 **burst 控制**等手段维持足够的谐振电流。

### 4.6 ZVS / ZCS 关键波形特征

**ZVS 工况（ $F > 1$ ）**

| 波形 | 特征描述 |
|---|---|
| $V_{SW}$ 方波 | 幅值 $\pm V_s$ ，50% 占空比，上升/下降沿之间插入死区 |
| $i_{Lr}$ | 近似正弦，相位**滞后**于 $V_{SW}$ 基波； $V_{SW}$ 跃变时仍维持原方向，随后缓慢过零；波形光滑连续 |
| 开关管 $V_{DS}$ | 关断时从 0 上升到 $2V_s$ （硬关断）；开通前已降至 0（体二极管钳位），实现 ZVS |
| 体二极管导通区间 | 死区后半段，待开通管体二极管短时导通，对应 $V_{DS}=0$ 的平台区间 |

**关键特征**： $i_{Lr}$ 过零点始终位于 $V_{SW}$ 电平跳变点之后，死区内体二极管导通是 ZVS 的标志。

**ZCS 工况（ $F < 1$ ）**

| 波形 | 特征描述 |
|---|---|
| $V_{SW}$ 方波 | 幅值 $\pm V_s$ ，50% 占空比，波形与 ZVS 相同 |
| $i_{Lr}$ | 近似正弦，相位**超前**于 $V_{SW}$ 基波；关断时 $i_{Lr}$ 接近零 |
| 开关管 $V_{DS}$ | 关断时已接近零（ZCS 关断）；开通时仍为高电压（硬开通），产生尖峰 |
| 体二极管导通区间 | 开通瞬间体二极管反向恢复产生电流尖峰，而非提供 ZVS 续流 |

**关键差异**：ZCS 工况下 $i_{Lr}$ 过零点在 $V_{SW}$ 跳变点之前，死区行为相反，开通瞬间存在明显的 $V_{DS}$ 尖峰和电流尖峰。

## 五、ZVS 与 ZCS 综合对比与工程误区澄清

### 5.1 综合对比表

| 对比项 | 感性区（ $F > 1$ ）ZVS 模式 | 容性区（ $F < 1$ ）ZCS 模式 |
|---|---|---|
| **开通特性** | **ZVS 开通**，开通损耗近似为零 | 硬开通，开通损耗大，体二极管反向恢复严重 |
| **关断特性** | 硬关断，关断损耗取决于关断电流 | **ZCS 关断**，关断损耗小 |
| **谐振电流相位** | 滞后于 $V_{SW}$ | 超前于 $V_{SW}$ |
| **死区行为** | 待开通管 $C_{oss}$ 被放电，体二极管导通 | 待开通管 $C_{oss}$ 被充电，体二极管不导通 |
| **副边二极管** | 自然换流，反向恢复较轻 | 硬换流，反向恢复严重 |
| **轻载表现** | ZVS 易丢失，进入硬开关 | ZCS 仍可维持，但硬开通主导损耗 |
| **工程实用性** | **高**——广泛采用 | **极低**——不推荐使用 |

### 5.2 关键误区澄清

**误区一：半桥 SRC 可以同时实现开关管 ZVS + ZCS**

**澄清**：**不可以。** 谐振腔在感性区和容性区呈现截然相反的相位特性：

- 感性区（ $F>1$ ）实现的是开通时的 **ZVS**，关断为硬关断；
- 容性区（ $F<1$ ）实现的是关断时的 **ZCS**，开通为硬开通；
- 谐振点（ $F=1$ ）两者均无法实现。

这是因为 ZVS 要求关断时刻电流足够大（在死区内完成 $C_{oss}$ 充放电），ZCS 要求关断时刻电流足够小，两者物理上互斥，无法在同一工作点同时实现。

**误区二：ZCS 比 ZVS 更好，因为关断损耗占比更大**

**澄清**：在高压 MOSFET 中，开通损耗通常大于关断损耗，且体二极管反向恢复是主要的损耗和可靠性威胁。ZCS 带来的关断损耗减小远无法抵消硬开通和反向恢复带来的巨大损耗。因此工程上 SRC 几乎**统一运行在 $F>1$ 的感性 ZVS 区域**，容性 ZCS 区被视为禁区。

**误区三：谐振点 $F=1$ 效率最高，应该工作在该点**

**澄清**：虽然谐振点无功环流最小，但所有开关管和二极管均为硬开关，开关损耗显著增加。尤其高频应用中硬开关损耗占总损耗比例很大，实际效率反而低于感性区 ZVS 工况。SRC 通常设计为满载额定点 $F = 1.05 \sim 1.2$ 工作，以换取 ZVS 软开关优势。

## 六、元件选型依据与计算

> **▎为什么选这个场景？**
>
> 以下选用 **车载充电机（OBC）前端 DC/DC** 作为设计场景——这是半桥 SRC 最典型的落地应用：
>
> - **400V 母线**来自 PFC 前端（范围 390~410V），半桥分压后 $V_s = 200\text{V}$ ；
> - **48V 输出**对应动力电池/低压母线，3.3kW 是 OBC 常见功率等级；
> - SRC 增益 ≤1，变压器匝比承担绝大部分降压（400V→48V），谐振网络只做窄调频（ $F=1.12\sim1.26$ ）——这正是 SRC"定频/窄调频"优势的体现。
>
> 所有公式保留符号形式，可直接代入其他设计指标复用。

| 输出电压 | $V_O$ | 48V |

| 效率目标 | $\eta$ | ≥ 95% |

### 6.2 公式速查卡

| 元件 | 核心公式 | 关键决定因素 |
|------|----------|-------------|
| 变压器匝比 | $n = \dfrac{V_s M_{nom}}{V_O}$ （ $M_{nom}$ 满载额定增益）| 最低输入 + 额定增益 ≤ 1 |
| 谐振电感 | $L_r = \dfrac{Z_0}{\omega_r}$ | 由 $Q$ 、 $R_{ac}$ 定 $Z_0$ |
| 谐振电容 | $C_r = \dfrac{1}{\omega_r Z_0}$ | 谐振电压摆幅 + 纹波电流 |
| 分压电容 | $C_1 = C_2 \geq (10\sim100)\,C_r$ | 谐振电流 ~13A RMS |
| MOS 管 | $V_{DS} \geq 1.3\,V_{in,max}$ | $C_{oss}$ 直接决定 ZVS |
| 副边整流 | $V_{RRM} \geq 1.5\,V_O$ | 48V/68A → 同步整流 |
| 输出电容 | $I_{C,rms} \approx 0.48\,I_O$ | ESR + 纹波电流是瓶颈 |

### 6.3 变压器匝比 $n$

> **功率流位置**：谐振腔之后、整流之前——电压变换 + 隔离的核心。

SRC 增益 ≤1，额定点必须让增益小于 1 以留出调频裕量。取满载额定增益 $M_{nom} \approx 0.96$ （对应 $F=1.2$ ）：

$$n = \frac{V_s \cdot M_{nom}}{V_O} = \frac{200 \times 0.96}{48} = 4.0$$

取 **$n = 4$**（原边 : 副边 = 4 : 1）。

校验最低/最高输入时的增益：

$$M_{max} = \frac{nV_O}{V_{s,min}} = \frac{4 \times 48}{195} \approx 0.985,\qquad M_{min} = \frac{nV_O}{V_{s,max}} = \frac{4 \times 48}{205} \approx 0.937$$

两者均 < 1，SRC 降压型约束满足。由 $M = 1/\sqrt{1+Q^2(F-1/F)^2}$ （ $Q=0.8$ ）反推频率范围： $F = 1.12 \sim 1.26$ ，即 $f_s = 112 \sim 126$kHz，**窄调频**，控制实现简单。

> **励磁电感约束**：SRC 中 $L_m$ 必须远大于 $L_r$ 以使其不参与谐振（理想为无穷大），工程上取 $L_m \geq 10\,L_r$ 。 $L_r = 11.5\mu\text{H}$ → $L_m \geq 115\mu\text{H}$ 。磁芯选用高频低损耗铁氧体（如 PC95），副边 48V/68A 大电流需利兹线或铜排。

### 6.4 谐振电感 $L_r$ 与谐振电容 $C_r$

> **功率流位置**：半桥桥臂之后、变压器之前——谐振腔是 SRC 的**唯一储能网络**。

**第一步：求 $R_{ac}$ 与 $Z_0$**

$$R_{load} = \frac{V_O}{I_O} = \frac{48}{68.75} \approx 0.698\,\Omega$$

$$R_{ac} = \frac{8n^2}{\pi^2}R_{load} = \frac{8 \times 16}{\pi^2} \times 0.698 \approx 9.05\,\Omega$$

由额定点 $F=1.2$ 、 $M=0.96$ 反解 $Q$ ：

$$Q = \frac{\sqrt{1/M^2 - 1}}{F - 1/F} = \frac{\sqrt{(1/0.96)^2 - 1}}{1.2 - 0.833} = \frac{0.292}{0.367} \approx 0.80$$

$$Z_0 = Q \cdot R_{ac} = 0.80 \times 9.05 \approx 7.2\,\Omega$$

**第二步：由 $f_r$ 、 $Z_0$ 定 $L_r$ 、 $C_r$**

$$\omega_r = 2\pi f_r = 6.28 \times 10^5\ \text{rad/s}$$

$$L_r = \frac{Z_0}{\omega_r} = \frac{7.2}{6.28\times10^5} \approx 11.5\ \mu\text{H}$$

$$C_r = \frac{1}{\omega_r Z_0} = \frac{1}{6.28\times10^5 \times 7.2} \approx 221\ \text{nF} \to 220\ \text{nF}$$

**谐振电流**（满载额定点）：

$$I_{Lr,rms} = \frac{V_{s,\text{fund}}}{\sqrt{R_{ac}^2 + \left[Z_0(F-1/F)\right]^2}} = \frac{0.9\times200}{\sqrt{9.05^2 + (7.2\times0.367)^2}} \approx 19\ \text{A}$$

$$I_{Lr,pk} = \sqrt{2}\,I_{Lr,rms} \approx 27\ \text{A}$$

**谐振电容电压应力**： $v_{Cr}$ 以零为中心对称摆动（串联谐振电容隔直，无直流偏置），峰值电压

$$V_{Cr,pk} = \frac{I_{Lr,pk}}{\omega_s C_r} = \frac{27}{2\pi\times1.2\times10^5 \times 220\times10^{-9}} \approx 163\ \text{V}$$

取 ≥ 2 倍裕量 → 选 **400V 聚丙烯薄膜电容**（低 ESR、低损耗、高 $dv/dt$ 能力，优于 X7R 陶瓷）。

| 元件 | 值 | 说明 |
|------|-----|------|
| $L_r$ | 11.5µH | 铁氧体磁芯，饱和电流 ≥ 1.5×27A ≈ 40A，多股绞合线 |
| $C_r$ | 220nF/400V | 聚丙烯薄膜，低 ESR |

### 6.5 分压电容 $C_1$ 、 $C_2$

> **功率流位置**：与 MOS 管共同构成半桥桥臂——单路 $V_{in}$ 母线由此实现中点，是半桥**特有**的选型项。

分压电容必须远大于谐振电容，使其在 $f_r$ 处阻抗可忽略、不参与谐振：

$$C_1 = C_2 \geq 100\,C_r = 100 \times 220\text{nF} = 22\ \mu\text{F}$$

每个分压电容在其对应半周期流过谐振电流，RMS 电流：

$$I_{C1,rms} = I_{C2,rms} = \frac{I_{Lr,rms}}{\sqrt{2}} = \frac{19}{\sqrt{2}} \approx 13.5\ \text{A}$$

> 谐振电流 ~13.5A RMS 是分压电容的**选型瓶颈**——必须用薄膜电容（低 ESR、高纹波电流），普通电解电容无法承受。各并联一只 **470kΩ/1W** 均压电阻，强制静态均压。

### 6.6 功率 MOS 管（ $Q_1$ 、 $Q_2$ ）

> **功率流位置**：输入分压网络之后、谐振腔之前——半桥逆变桥臂。

#### 电压应力

每只管关断时承受整个母线电压（另一管导通时， $V_{SW}$ 拉到对侧）：

$$V_{DS,max} = V_{in,max} = 410\ \text{V}$$

计入 1.3 倍裕量（考虑尖峰）：

$$V_{DSS,rated} \geq 1.3 \times 410 \approx 533\ \text{V} \quad\Rightarrow\quad \text{选 650V 等级}$$

#### 电流应力

每只管导通半周期，谐振电流全周期 RMS 为 19A：

$$I_{DS,rms} = \frac{I_{Lr,rms}}{\sqrt{2}} = \frac{19}{\sqrt{2}} \approx 13.5\ \text{A},\qquad I_{DS,pk} = 27\ \text{A}$$

#### ZVS 死区校验（核心约束）

感性区 $F=1.2$ 时阻抗角 $\theta = \arctan\dfrac{Z_0(F-1/F)}{R_{ac}} = \arctan\dfrac{2.64}{9.05} \approx 16^\circ$ ，关断时刻电流：

$$i_{Lr}(t_{off}) = I_{Lr,pk}\cdot\sin\theta = 27 \times 0.28 \approx 7.6\ \text{A}$$

$$t_{dead} \geq \frac{2(C_{oss}+C_w)V_s}{i_{Lr}(t_{off})}$$

其中 $C_w$ 为变压器绕组分布电容。取 $C_{oss}(er)\approx150\text{pF}$ （SiC）、 $C_w\approx500\text{pF}$ ：

$$t_{dead} \geq \frac{2\times650\times10^{-12}\times200}{7.6} \approx 34\ \text{ns}$$

考虑离散性取 **$t_{dead} = 150\sim200$ns**（过长会加重体二极管导通损耗）。

#### 选型汇总

| 参数 | 计算值 | 选型要求 |
|------|--------|----------|
| $V_{DSS}$ | 410V（理论）| ≥ **650V** |
| $I_D$ （连续）| ~13.5A RMS | ≥ 25A @ 高温 |
| $I_{D,pulse}$ | 27A | ≥ 80A |
| $C_{oss}$ | — | 尽量小（利于 ZVS）|
| $R_{DS(on)}$ | — | 40~60mΩ（SiC 典型，导通损耗 ~8W）|

**推荐**：**650V SiC MOSFET**（如 Wolfspeed C3M0045065 / C3M0060065 系列， $R_{DS(on)}=45\sim60\text{m}\Omega$ ），或 650V GaN。SiC 的低 $C_{oss}$ 、无反向恢复体二极管（相对 Si）对 ZVS 和死区设计有利。

### 6.7 副边整流（全桥整流 / 同步整流）

> **功率流位置**：变压器副边之后、输出电容之前——全桥整流。

副边峰值电流为原边谐振电流的 $n$ 倍：

$$I_{sec,pk} = n\,I_{Lr,pk} = 4 \times 27 = 108\ \text{A},\qquad I_{sec,rms} = 4 \times 19 \approx 76\ \text{A}$$

全桥整流中每只器件导通半周期：

$$I_{D,avg} = \frac{I_O}{2} = 34.4\ \text{A},\qquad I_{D,rms} = \frac{I_{sec,rms}}{\sqrt{2}} \approx 54\ \text{A}$$

反向电压为输出电压 $V_O$ ：

$$V_{RRM} \geq 1.5\,V_O = 72\ \text{V} \quad\Rightarrow\quad \text{选 80V/100V 等级}$$

> **▎为什么 48V/68A 必须用同步整流（SR）而非二极管？**
>
> 若用肖特基二极管（ $V_F\approx0.5\text{V}$ ），整流导通损耗 $P = I_O V_F = 68.75\times0.5 \approx 34\text{W}$ ，占总功率 1%，且发热集中。改用低 $R_{DS(on)}$ 的 SR MOSFET：
>
> $$P_{SR} = I_{D,rms}^2 R_{DS(on)} = 54^2 \times 0.002 \approx 5.8\ \text{W/管}$$
>
> 损耗降为二极管的 1/3 以下。48V/3.3kW 低压大电流场景，同步整流是标准方案。

**推荐**：80V/100V 低 $R_{DS(on)}$ MOSFET（ $R_{DS(on)}\leq2\text{m}\Omega$ ，如 IRFH7440 / BSC007N04 等），4 只管构成全桥 SR，配 SR 驱动控制器。

### 6.8 输出滤波电容 $C_F$

> **功率流位置**：整流之后、负载之前——功率流最后一环。

输出电流为全波整流正弦，电容纹波电流（RMS）：

$$I_{C,rms} \approx 0.48\,I_O = 0.48 \times 68.75 \approx 33\ \text{A}$$

ESR 约束（纹波 $\Delta V_O \leq 1\%\cdot V_O = 0.48\text{V}$ ，峰值电流 108A）：

$$R_{ESR} \leq \frac{\Delta V_O}{I_{sec,pk}} = \frac{0.48}{108} \approx 4.4\ \text{m}\Omega$$

> 对谐振变换器，输出电容的**ESR 与纹波电流是瓶颈，电容量反而是次要的**（纹波频率为 $2f_s$ ，高频下 ESR 主导纹波）。

**方案**：**6 × 220µF/63V 低 ESR 聚合物电容**并联（并联 ESR ≈ 2mΩ）+ **4 × 10µF/100V MLCC** 高频分流。

## 七、拓扑对比

### 7.1 SRC vs LLC

| 维度 | 半桥 SRC | 半桥 LLC |
|------|:---:|:---:|
| 谐振元件 | $L_r$ + $C_r$ （一个谐振频率）| $L_r$ + $C_r$ + $L_m$ （两个谐振频率）|
| 励磁电感 | 不参与谐振，仅激磁 | 参与谐振，参与能量交换 |
| 增益范围 | ≤ 1（降压型）| 可升可降（宽增益）|
| 调频范围 | 窄（ $F=1.1\sim1.3$ ）| 宽（利用双谐振点）|
| 控制复杂度 | 简单 | 较高 |
| 适用场景 | 定频/窄调频、电压相对固定 | 宽输入/宽输出、电池全电压段充电 |

### 7.2 SRC vs 半桥隔离 Buck

| 维度 | 半桥 SRC | 半桥隔离 Buck |
|------|:---:|:---:|
| 储能/滤波 | 谐振腔（ $L_r$ 、 $C_r$ ）| 输出 LC 滤波 |
| 调节变量 | 频率 | 占空比 |
| 软开关 | ZVS（感性区）| 硬开关为主 |
| 输出电流波形 | 正弦 | 脉动方波（大纹波）|
| 输出电容 | 小（高频正弦纹波）| 大（LC 滤波需求）|
| 增益 | ≤1，窄调频 | $V_O = nDV_{in}/2$ ，宽占空比 |

## 八、快速小结

| 项目 | 结论 |
|------|------|
| 拓扑名称 | 半桥串联谐振变换器（Half-bridge SRC）|
| 电路本质 | 半桥逆变 + 串联谐振腔（ $L_r$ 、 $C_r$ ）+ 变压器隔离 + 全桥整流 + 电容滤波 |
| 家族归属 | **谐振型**（变频调压，增益 ≤ 1 降压型）|
| 核心公式 | $V_O = \dfrac{V_s}{n}\cdot\dfrac{1}{\sqrt{1+Q^2(F-1/F)^2}}$ |
| 推荐工作区 | 感性区 $F > 1$ （ZVS 开通），避开容性区与谐振点 |
| ZVS 核心约束 | $\lvert i_{Lr}(t_{off}) \rvert \geq \dfrac{2C_{oss}V_s}{t_{dead}}$ |
| 轻载短板 | ZVS 易丢失 → 变频/burst 控制维持谐振电流 |
| 设计案例 | 400V→48V / 3.3kW， $n=4$ ， $f_r=100\text{kHz}$ ， $f_s=120\text{kHz}$ （ $F=1.2$ ）|
| 谐振元件 | $L_r=11.5\mu\text{H}$ ， $C_r=220\text{nF}/400\text{V}$ |
| 开关管 | 650V SiC MOSFET（ $C_{oss}$ 小、利于 ZVS）|
| 副边整流 | 同步整流（48V/68A，二极管损耗不可接受）|
| 头号工程挑战 | 轻载 ZVS 丢失 + 谐振电容/分压电容纹波电流 |
| 最佳场景 | 车载充电机前端、服务器电源等定频/窄调频中功率隔离 DC/DC |
