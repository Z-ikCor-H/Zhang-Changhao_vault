# 推挽隔离 Boost 变换器（Push-Pull Isolated Boost Converter）

> 本笔记遵循 [00-统一规范](00-统一规范.md)。原理图（`拓扑图/Push-pull isolated boost converter.png`）为最高依据。
>
> **⚠️ 本笔记为完全重写版。** 原版把本拓扑当作"电压馈电推挽 + 加了个电感"来分析（两管交替导通、 $D<0.5$ 、推导出 $V=\frac{nV_g}{1-D}$ ），这是**根本性错误**。本拓扑属于**电流馈电型**，其升压发生在**两管重叠导通**期间， $D>0.5$ ，正确传输比为 $V_o=\dfrac{nV_g}{2(1-D)}$ 。详见 §四、§六 的推导与 §二十一 的勘误说明。

---

## 一、拓扑概述

### 1.1 拓扑名称与归类

**推挽隔离型 Boost 变换器**，属于**电流馈电型推挽**（Current-Fed Push-Pull, CFPP）。

| 归类维度 | 结论 |
|---|---|
| 家族 | **Boost 家族**（储能电感在输入侧、变压器之前） |
| 馈电方式 | **电流馈电**——变压器原边由电感"电流源"驱动（对比推挽 Buck 的电压馈电） |
| 励磁方式 | 双向励磁，但**不是**靠对称自动复位（见 §八） |
| 控制变量 | 占空比 $D$ （**两管各自**的导通占空比， $D>0.5$ ） |
| 开关管数量 | 2 |
| 整流结构 | 副边中心抽头**全波整流** |

> **一句话区分两个"推挽"**：
> - **推挽 Buck（电压馈电）**： $V_g$ **直接**接中心抽头，电感在**副边** → 两管**交替**导通， $d<0.5$ ， $V_o=2ndV_g$
> - **推挽 Boost（电流馈电）**： $V_g$ 经**电感**接中心抽头，电感在**原边** → 两管**重叠**导通， $D>0.5$ ， $V_o=\frac{nV_g}{2(1-D)}$
>
> 两者的**变压器结构相同**（中心抽头原边 + 全波整流副边），但**工作机理、模态、公式完全不同**。这是本文件夹里最容易被混淆的一对拓扑。

### 1.2 原理图解读

<img src="拓扑图/Push-pull%20isolated%20boost%20converter.png" width="650">

按原理图逐点确认连接关系：

| 位置 | 连接 |
|---|---|
| 输入源 | $V_g$ |
| **储能电感 $L$** | 串联在 $V_g$ 正端与变压器**原边中心抽头**之间（**这是 Boost 家族的标志**） |
| 原边绕组 | **带中心抽头的双半绕组**；上端接 $Q_1$ 漏极，下端接 $Q_2$ 漏极 |
| $Q_1$ / $Q_2$ | N 沟道 MOSFET，源极均接 $V_g$ 负端（**共地**） |
| 副边绕组 | **带中心抽头的双半绕组**；中心抽头接输出回线 |
| $D_1$ / $D_2$ | 全波整流： $D_1$ 阳极接副边上端、 $D_2$ 阳极接副边下端；两管阴极并接输出正端 |
| 输出滤波 | **只有 $C$ ，没有输出电感** ← Boost 家族的标志（能量经二极管直接给电容/负载） |

> **三个必须看清的点**
> 1. **电感在原边、在变压器之前**——所以它是"Boost + 隔离"，不是"隔离 + Buck"；
> 2. **输出侧没有滤波电感**——输出电流是脉冲式的，全部由 $C$ 平滑；
> 3. **两个开关管都把半绕组外端接地**——因此**两管同时导通时原边被完全短路**，这正是 Boost 充电状态的来源。

### 1.3 宏观工作机理

> ⚠️ **核心认知（原版错误的根源）**：
> **Boost 的"充电"必须让电感两端出现正电压。电感一端接 $V_g$ ，所以另一端（中心抽头）必须被拉到地电位——这要求两个半绕组的外端都被接地，即两管同时导通。**
> **任何一只管子单独导通时，电感电流必须经变压器流到副边（否则电流无路可走），此时中心抽头被输出电压顶高，电感处于"放电"状态。**

| 环节 | 功能 |
|---|---|
| ① Boost 储能电感 $L$ | 串联在 $V_g$ 与中心抽头之间；开关周期内储能/释能，提供升压 |
| ② 推挽开关（ $Q_1$ 、 $Q_2$ ） | **重叠导通**：重叠期原边短路（充电）；单管期电流经变压器流到副边（放电+传输） |
| ③ 高频变压器（中心抽头原边 $1:n$ ） | 电压变换 + 电气隔离；双向励磁 |
| ④ 全波整流（ $D_1$ 、 $D_2$ ） | 双极性 → 单向脉动，每半周仅一只二极管导通 |
| ⑤ 输出电容 $C$ | 平滑脉冲电流，支撑 $V_o$ |

**控制逻辑**： $Q_1$ 、 $Q_2$ 各以占空比 $D$ 导通，且 **$D>0.5$ 使两者存在重叠**。重叠越长（ $D$ 越大）→ 电感充电越久 → **升压比越高**。

$$V_o=\frac{nV_g}{2(1-D)}\qquad(D>0.5)$$

> **与全桥 Boost 的控制方向一致**：两者都是"重叠越长、升压越高"。不同的是全桥 Boost 用"$D$ 越小重叠越长"（因为它的 $D$ 定义为传输占空比），而推挽 Boost 用"$D$ 越大重叠越长"。**符号定义不同，物理方向相同。**

### 1.4 优点

1. **开关管少**——仅 2 管 + 2 路共地驱动，比全桥 Boost 省一半管子与驱动
2. **双重升压**——电感 Boost 因子 $\times$ 变压器匝比，总升压比大
3. **输入电流连续**——储能电感串联在输入端，**输入电流纹波小**（这是相对推挽 Buck 的显著优势）
4. **磁芯双向励磁**——磁芯利用率高
5. **两管共地**——驱动无需隔离，比全桥/半桥的高边管简单
6. **重叠导通保证电感电流始终有低阻通路**——无"断流"问题

### 1.5 缺点

1. **开关管电压应力由输出决定**——$V_{DS}=2V_o/n$ ；升压比越高、应力越大（这就是 Boost 的固有代价）
2. **变压器需中心抽头原边**——绕制复杂、漏感大、两半绕组必须严格对称；相比全桥 Boost 的简单原边是明显劣势
3. **副边二极管耐压高**——$2V_o$ （中心抽头全波整流的固有代价，**与全桥 Boost 相同**，原版"更低"的说法有误）
4. **换流时漏感尖峰严重**——电感是电流源，换流瞬间漏感电流被迫改变路径，关断管节点电压上冲，**必须加箝位/吸收**（见 §十四）
5. **占空比范围受限**——$D$ 必须同时满足 $>0.5$ （要重叠）与 $<1$ （要留裕量），且匝比受约束 $n<V_o/V_{g,max}$ （见 §六 约束）
6. **原边电流大**——升压拓扑输入电流 = $P_o/(\eta V_g)$ ，低压输入时电流很大 → 导通损耗显著

### 1.6 适用场景

> **结论写法**：不写"推挽 Boost 最好"，而写"**在什么条件下更合适**"。

| 场景 | 是否合适 | 原因 |
|---|:---:|---|
| 低压蓄电池升压（12/24/48V → 高压母线） | ✅ **最合适** | 低压输入 → 输入电流大 → 用最少的管子承担； $2V_o/n$ 应力可控 |
| 中小功率光伏隔离升压 | ✅ | 输入电流连续、结构简单 |
| 大功率（>1kW）升压 | ❌ **不推荐** | 输入电流全部流过 2 只管子 → 导通损耗随功率平方增长；改用全桥 Boost（电流分散到 4 管，应力减半） |
| 高压输入（>200V） | ❌ | 输入电流虽小，但 $2V_o/n$ 仍高且无必要；用全桥 Boost |
| 降压场景 | ❌ | 本拓扑只能升压；降压用推挽 Buck |

### 2.2 ★ 占空比定义（本拓扑关键）

| 符号 | 定义 | 范围 | 说明 |
|---|---|---|---|
| $D$ | **单管导通占空比** $=t_{on,Q}/T_s$ | $\mathbf{0.5<D<1}$ | $Q_1$ 、 $Q_2$ **各自**的导通时间占比 |
| $D_{boost}$ | **Boost 充电占空比** $=2D-1$ | $0<D_{boost}<1$ | 两管**重叠**（同时导通）的时间占比 |
| $1-D$ | 单管独立导通时间占比 | $0<1-D<0.5$ | 每个半周一段，一周期共 $2(1-D)T_s$ |

$$\boxed{D_{boost}=2D-1}$$

> **时间分配**（一周期）：
> - 两管**重叠**： $(2D-1)T_s=D_{boost}T_s$ ← **电感充电**
> - 仅 $Q_1$ 导通： $(1-D)T_s$ ← **电感放电、能量传向副边**
> - 仅 $Q_2$ 导通： $(1-D)T_s$ ← **电感放电、能量传向副边**
>
> 校验： $(2D-1)+2(1-D)=1$ ✓

> **⚠️ 不存在"两管全关"的稳态模态。** 正常情况下两管至少有一只导通，电感电流始终有低阻抗通路。只有为防止**直通**才插入极短的死区，那不是功率传输模态。

### 2.3 匝比定义

$$n=\frac{N_s}{N_{p,half}}$$

- $N_{p,half}$ ＝**半个原边绕组**匝数（中心抽头分两半，两半相同）
- $N_s$ ＝**半个副边绕组**匝数

> 原理图标注 "1 : n"，即半原边 : 半副边 $=1:n$ 。**全篇 $n$ 按此定义。**

## 三、电路结构完整拆解

### 3.1 输入侧

| 元件 | 功能 | 关键说明 |
|---|---|---|
| $V_g$ | 直流输入 | — |
| **$L$** | **Boost 储能电感** | 串联在 $V_g^+$ 与中心抽头之间；**它的电流就是输入电流** |
| $Q_1$ | 上管 | 导通时把**上半绕组外端**接地 |
| $Q_2$ | 下管 | 导通时把**下半绕组外端**接地 |
| 原边绕组 | 中心抽头双半绕组 | 两半**串联**、匝数相同、**绕向相反**（使两管激励的磁通方向相反） |

**同名端意图**：原理图中原边两个半绕组的打点端位于**外侧两端**；副边打点端同样位于**外侧两端**。

- $Q_1$ 导通（单管期）：电流自中心抽头**流入**上半绕组、从上端流出 → 副边**上端为正** → $D_1$ 导通
- $Q_2$ 导通（单管期）：极性反转 → 副边**下端为正** → $D_2$ 导通

> **为什么两半绕组反向绕制？** 两管单独导通时，电流都从中心抽头流入，要让磁通方向相反，必须反向绕制（打点端分居外侧）。若同向绕制，两个半周的磁通会同向叠加 → 磁芯单向饱和。

### 3.2 为什么"两管同时导通"能充电——从电感方程直接看

Boost 的本质是**给电感施加正向电压使其储能**。电感的两个端子：

- 一端： $V_g$ 正端（固定）
- 另一端：**变压器中心抽头**（电压记作 $v_{CT}$ ）

$$v_L=V_g-v_{CT}$$

**要让 $v_L>0$ （充电），必须 $v_{CT}<V_g$ ；要让充电最快（ $v_L=V_g$ ），必须 $v_{CT}=0$ 。**

而中心抽头的电位由两个半绕组的外端决定（对称结构下 $v_{CT}=\frac{v_A+v_B}{2}$ ）：

| 状态 | $v_A$ | $v_B$ | $v_{CT}$ | $v_L$ | 结论 |
|---|---|---|---|---|---|
| **两管全通** | 0（ $Q_1$ 接地） | 0（ $Q_2$ 接地） | **0** | $V_g$ | ★ **满压充电** |
| 仅 $Q_1$ 通 | 0 | $2V_o/n$ （被副边顶高） | $V_o/n$ | $V_g-\frac{V_o}{n}<0$ | 放电 + 传能 |
| 仅 $Q_2$ 通 | $2V_o/n$ | 0 | $V_o/n$ | $V_g-\frac{V_o}{n}<0$ | 放电 + 传能 |

> **这张表就是本拓扑的全部秘密。** 注意"仅单管导通"时中心抽头**向上**被顶到 $V_o/n$ （不是向下）——因为电感是电流源，它强制把中心抽头推到能让电流流进变压器的电位。

**为什么中心抽头是"中点电位"？** 原边是**连续绕制**的中心抽头绕组（ $A$—$CT$—$B$ ），沿绕线方向有 $v_A-v_{CT}=v_{CT}-v_B$ ，故

$$\boxed{v_{CT}=\frac{v_A+v_B}{2}}$$

这个关系贯穿全文，是推导 $2V_o/n$ 应力的关键。

### 3.3 副边

| 元件 | 功能 | 关键说明 |
|---|---|---|
| $D_1$ | 整流二极管（ $Q_1$ 单管期） | 导通期间向 $C$ 与负载输送能量 |
| $D_2$ | 整流二极管（ $Q_2$ 单管期） | 与 $D_1$ 交替导通 |
| $C$ | 输出滤波电容 | **唯一的输出储能元件**；重叠期单独向负载供电 |
| $R_o$ | 负载 | |

**重叠期（两管全通）的副边**： $v_{CT}=0$ → 两个半绕组电压均为 0 → 副边无感应电压 → **$D_1$ 、 $D_2$ 均截止** → 负载完全由 $C$ 供电。

> **这与推挽 Buck 完全相反**：推挽 Buck 的死区是"副边两管同时导通"，推挽 Boost 的重叠区是"副边两管同时截止"。**记忆方法**：Buck 型死区靠副边续流；Boost 型充电靠副边断开。

## 四、一个完整开关周期的工作过程

**总览**：CCM 下一个周期分 **3 个稳态模态**（重叠 / 仅 $Q_1$ / 重叠 / 仅 $Q_2$ ，共 4 段但只有 3 种状态）

| 阶段 | 时段 | 时长 | 主开关 | 副边 | 电感 |
|---|---|---|---|---|---|
| **模态 1** | $[t_0,t_1]$ | $(2D-1)T_s$ | $Q_1$+$Q_2$ **全通** | $D_1$ 、 $D_2$ 全截止 | **充电**（ $v_L=V_g$ ） |
| **模态 2** | $[t_1,t_2]$ | $(1-D)T_s$ | **仅 $Q_1$** | $D_1$ 导通 | 放电（ $v_L=V_g-\frac{V_o}{n}$ ） |
| **模态 3** | $[t_2,t_3]$ | $(2D-1)T_s$ | $Q_1$+$Q_2$ **全通** | 全截止 | **充电**（ $v_L=V_g$ ） |
| **模态 4** | $[t_3,t_4]$ | $(1-D)T_s$ | **仅 $Q_2$** | $D_2$ 导通 | 放电（ $v_L=V_g-\frac{V_o}{n}$ ） |

> 模态 3 ≡ 模态 1，模态 4 ≡ 模态 2（极性反转）。下面展开模态 1、2。

---

### 4.1 模态 1：两管全通（Boost 充电）——$[t_0,t_1]$ ，时长 $(2D-1)T_s$

#### （1）状态表

| 元件 | 状态 |
|---|---|
| $Q_1$ | **ON** |
| $Q_2$ | **ON** |
| $D_1$ 、 $D_2$ | **全 OFF** |
| 变压器 | **不工作**（净安匝为零，磁通不变） |
| $L$ （Boost 电感） | **储能**（电流线性上升） |
| $C$ | **放电**（单独向负载供电） |

#### （2）原边：电压与电流

两管同时导通 → 两个半绕组的外端都被接地：

$$v_A=v_B=0\quad\Rightarrow\quad v_{CT}=\frac{v_A+v_B}{2}=0$$

$$\boxed{v_L=V_g-v_{CT}=V_g>0}$$

**电流路径**（Anode→Cathode 规范）：

$$V_g(+) \to L \to \text{中心抽头} \to \begin{cases}\text{上半绕组}\to Q_1\to V_g(-)\\\\\text{下半绕组}\to Q_2\to V_g(-)\end{cases}$$

- 电感电流 $i_L$ 自中心抽头**平均分成两路**，各流过一半
- **两个半绕组的安匝相互抵消**（电流都从中心抽头流入，绕向相反 → MMF 一正一负）

$$\text{净MMF}=N_{p,half}\cdot\frac{i_L}{2}-N_{p,half}\cdot\frac{i_L}{2}=0$$

→ **磁通不变化** → 副边无感应电压 → $D_1$ 、 $D_2$ 截止 ✓

#### （3）为什么副边不出力（三重论证）

| 论证 | 说明 |
|---|---|
| **安匝抵消** | 两半绕组电流相等反向，净 MMF = 0，磁芯不励磁 |
| **电压角度** | 所有绕组（含副边）电压均为 0，无电压驱动副边电流 |
| **能量角度** | 此时原边被短路，能量以磁场形式存在 $L$ 中，未向副边传递 |

> **这正是 Boost 的"开关导通期"**：能量存在电感里，输出靠电容撑着。与普通 Boost 唯一的不同是——这里的"开关"由**两个 MOSFET 并联**构成（分别短路一个半绕组）。

#### （4）电压与电流

| 量 | 值/趋势 | 说明 |
|---|---|---|
| $v_L$ | $+V_g$ | 电感满压充电 |
| $v_{CT}$ | $0$ | 中心抽头被拉到地 |
| $v_A=v_B$ | $0$ | 两管都通 |
| $V_{DS}(Q_1)=V_{DS}(Q_2)$ | $\approx0$ | 导通 |
| $v_s$ （副边） | $0$ | 无感应电压 |
| $i_L$ | 线性上升 | $\dfrac{di_L}{dt}=\dfrac{V_g}{L}$ |
| $i_{Q1}=i_{Q2}$ | $i_L/2$ ，上升 | 各分一半 |
| $i_{D1}=i_{D2}$ | $0$ | 截止 |
| $i_C$ | $=-\,I_o$ | 电容放电，向负载供电 |

---

### 4.2 模态 2：仅 $Q_1$ 导通（放电 + 传能）——$[t_1,t_2]$ ，时长 $(1-D)T_s$

#### （1）状态表

| 元件 | 状态 |
|---|---|
| $Q_1$ | **ON** |
| $Q_2$ | **OFF** |
| $D_1$ | **ON** |
| $D_2$ | **OFF** |
| 变压器 | **正向励磁**（磁通增大） |
| $L$ | **释能**（电流线性下降） |
| $C$ | **充电**（同时向负载供电） |

#### （2）原边：中心抽头为什么被顶到 $V_o/n$

$Q_1$ 导通把节点 $A$ 拉到地； $Q_2$ 关断，节点 $B$ **悬空**。电感电流 $i_L$ 不能中断，必须继续流动 → 它只能从中心抽头流入**上半绕组**、经 $Q_1$ 回到地。

上半绕组有电流流过 → 按变压器原理，**副边上半绕组被驱动** → 副边电压达到 $V_o$ ， $D_1$ 导通 → 输出被接上。

**由副边反推原边电压**：

$$\text{副边上半绕组}=V_o\;\Rightarrow\;\text{原边上半绕组}=v_{CT}-v_A=\frac{V_o}{n}$$

$$\boxed{v_{CT}=\frac{V_o}{n}}\qquad(\text{因 }v_A=0)$$

**再求节点 $B$ （关断管漏极）电压**，用中点关系 $v_{CT}=\frac{v_A+v_B}{2}$ ：

$$v_B=2v_{CT}-v_A=2\cdot\frac{V_o}{n}-0=\boxed{\frac{2V_o}{n}}$$

> **★ 这是本拓扑开关管电压应力的来源**：关断管的漏极被顶到 $\frac{2V_o}{n}$ ，是中心抽头电位（ $\frac{V_o}{n}$ ）的两倍。
>
> **物理直觉**：中心抽头原边相当于一个 **2:1 自耦变压器**——一半绕组被驱动时，另一半绕组"骑"在它上面，把电压叠加起来。这与推挽 Buck 关断管承受 $2V_g$ 是**同一个机制**，只是激励源不同（Buck 型看输入，Boost 型看输出）。

**电感电压**：

$$v_L=V_g-v_{CT}=V_g-\frac{V_o}{n}<0\qquad(\text{升压 ⇒ }\frac{V_o}{n}>V_g)$$

**电流路径**：

$$V_g(+)\to L\to\text{中心抽头}\to\text{上半绕组}\to Q_1(\text{漏}\to\text{源})\to V_g(-)$$
$$\text{副边：上半绕组}\to D_1(\text{Anode}\to\text{Cathode})\to C\parallel R_o\to\text{中心抽头}$$

#### （3）副边： $D_1$ 为什么导通、 $D_2$ 为什么截止

- 原边打点端（上端）电位**低**于中心抽头 → 副边打点端（上端）电位**高**于副边中心抽头
- 副边中心抽头接输出回线（0V）→ 副边上端电位 $=+V_o$
- $D_1$ ：**阳极**接副边上端（ $+V_o$ ），**阴极**接输出正端 → 正偏 → **导通**
- $D_2$ ：**阳极**接副边下端（ $-V_o$ ），**阴极**接输出正端（ $+V_o$ ）→ 反偏 → **截止**
- $D_2$ 承受反向电压：

$$\boxed{V_{RR}(D_2)=2V_o}$$

> **注意**：这是中心抽头全波整流的固有代价——**不导通的那只二极管承受 2 倍输出电压**。全桥整流可以把每只二极管的耐压降到 $V_o$ ，但要多两只管子且压降翻倍。**推挽 Boost 与全桥 Boost 都用中心抽头整流，两者二极管耐压相同（都是 $2V_o$ ）**。

#### （4）电压与电流

| 量 | 值/趋势 | 说明 |
|---|---|---|
| $v_L$ | $V_g-\frac{V_o}{n}$ （负） | 电感释能 |
| $v_{CT}$ | $+\frac{V_o}{n}$ | 被副边顶高 |
| $v_B$ | $\frac{2V_o}{n}$ | ★ 关断管应力 |
| $v_A$ | $0$ | 导通管接地 |
| $V_{DS}(Q_2)$ | $\frac{2V_o}{n}$ | 关断管承受 |
| $v_s$ | $V_o$ | 副边输出电压 |
| $i_L$ | 线性下降 | $\dfrac{di_L}{dt}=\dfrac{V_g-V_o/n}{L}<0$ |
| $i_{Q1}$ | $=i_L$ | 全部电感电流 |
| $i_{Q2}$ | $0$ | 关断 |
| $i_{D1}$ | $=i_L/n$ | 反射到副边 |
| $i_{D2}$ | $0$ | 截止 |

---

### 4.3 模态 3 / 模态 4

与模态 1 / 模态 2 **完全对称、极性反转**：

- 模态 3 ≡ 模态 1：两管全通， $v_{CT}=0$ ， $v_L=V_g$ ，副边全截止
- 模态 4：仅 $Q_2$ 导通 → $v_B=0$ 、 $v_A=\frac{2V_o}{n}$ 、 $v_{CT}=\frac{V_o}{n}$ 、 $v_L=V_g-\frac{V_o}{n}$ ；副边**下端为正** → $D_2$ 导通、 $D_1$ 截止（此时 $D_1$ 承受 $2V_o$ ）

> **全波整流的作用**：把"副边极性反转"变成"输出极性不变"，所以 $v_s$ 在每个单管期都是 $+V_o$ 。

### 5.2 波形要点解读

| 观察 | 物理原因 |
|---|---|
| $v_{CT}$ 为 **单极性**（ $0$ 或 $+\frac{V_o}{n}$ ），**不是**双极性 | 电感是电流源，只能把中心抽头**向上**顶（电流必须流进变压器）。这与推挽 Buck 的 $v_T=\pm V_g$ （双极性）形成鲜明对比 |
| $V_{DS}$ 在单管期为 $\frac{2V_o}{n}$ | 自耦变压器效应：中心抽头电位 $\frac{V_o}{n}$ × 2 |
| 输出侧纹波频率为 $2f_s$ | 两个单管期各送一次能量 |
| $i_C$ 在重叠期为 $-I_o$ （纯放电） | Boost 家族特征：开关"导通"期输出全靠电容 |

> **波形对比记忆法**：
> - 推挽 **Buck**： $v_T=\pm V_g$ （双极性），死区副边两管**同时导通**
> - 推挽 **Boost**： $v_{CT}=0/+V_o/n$ （单极性），重叠区副边两管**同时截止**

## 六、稳态电压传输关系

### 6.1 物理意义

Boost 电感 $L$ 是储能元件。稳态下它每周期吸收的伏秒积必须等于放出的伏秒积。

### 6.2 电路状态（一周期）

| 时段 | 时长 | $v_L$ | 电感状态 |
|---|---|---|---|
| 模态 1 + 模态 3（重叠，充电） | $(2D-1)T_s$ | $+V_g$ | 储能 |
| 模态 2 + 模态 4（单管，放电） | $2(1-D)T_s$ | $V_g-\frac{V_o}{n}$ | 释能 |

### 6.3 推导

$$\underbrace{V_g\cdot(2D-1)T_s}_{\text{充电伏秒}}+\underbrace{\left(V_g-\frac{V_o}{n}\right)\cdot2(1-D)T_s}_{\text{放电伏秒}}=0$$

展开：

$$V_g(2D-1)+2V_g(1-D)-\frac{2(1-D)V_o}{n}=0$$

$$V_g\big[(2D-1)+2(1-D)\big]=\frac{2(1-D)V_o}{n}$$

$$V_g\cdot\underbrace{[2D-1+2-2D]}_{=1}=\frac{2(1-D)V_o}{n}$$

$$\boxed{V_o=\frac{n\,V_g}{2(1-D)}}\qquad\Longleftrightarrow\qquad\boxed{\frac{V_o}{V_g}=\frac{n}{2(1-D)}}$$

### 6.4 用"标准 Boost"形式重写（最简洁的记忆方式）

引入 $D_{boost}=2D-1$ （重叠占空比），则 $2(1-D)=1-D_{boost}$ ，于是：

$$\boxed{V_o=\frac{n\,V_g}{1-D_{boost}}}\qquad\text{或}\qquad\boxed{V_o/n=\frac{V_g}{1-D_{boost}}}$$

> **极简理解**：**这就是一个标准 Boost 变换器**，其
> - 开关导通占空比 $=D_{boost}=2D-1$ （重叠期）
> - 输出电压 $=V_o/n$ （副边折射到原边）
>
> 因此 $V_o/n=V_g/(1-D_{boost})$ ，即 $V_o=\dfrac{nV_g}{1-D_{boost}}$ ✓

### 6.5 变量定义与适用条件

| 符号 | 含义 | 范围 |
|---|---|---|
| $V_g$ | 输入直流电压 | — |
| $n$ | 匝比 $N_s/N_{p,half}$ | — |
| $D$ | 单管占空比 | $0.5<D<1$ |
| $D_{boost}$ | $=2D-1$ | $0<D_{boost}<1$ |
| $V_o$ | 输出电压 | $\ge nV_g$ （升压） |

**适用条件**：CCM · 理想器件 · 忽略漏感 · 稳态 · 小纹波近似。

### 6.6 两个由推导直接得到的设计约束

**约束 ①： $D$ 必须 > 0.5（否则无重叠、无升压）**

$$D>0.5\;\Longleftrightarrow\;D_{boost}>0$$

若 $D\le0.5$ ，两管不再重叠，本拓扑退化为推挽 Buck（输出将被直接钳到 $nV_g$ 以下），**失去升压能力**。

**约束 ②：匝比受限于 $n<V_o/V_{g,max}$**

要保证在**最高输入电压**时仍有重叠（ $D>0.5$ ）：

$$D_{min}=\frac{1}{2}\left(1+\frac{nV_{g,max}}{V_o}\right)>0.5\quad\Longleftrightarrow\quad\boxed{n<\frac{V_o}{V_{g,max}}}$$

> **这条约束非常关键，且容易被忽略**：升压比要求（ $n$ 大）与重叠要求（ $n$ 小）是**互相矛盾**的。 $n$ 取大了，最高输入时就没有重叠了。
>
> 工程上建议留裕量 $D_{min}\ge0.55$ ，即
> $$n\le\frac{0.9\,V_o}{V_{g,max}}$$

**设计流程小结**：先按约束 ② 定 $n$ 的上限 → 再按最低输入、最大占空比反解 $D_{max}$ → 校验 $D_{max}<1$ 且留裕量。

### 6.7 与全桥 Boost 的对照

| 对比 | 全桥 Boost | 推挽 Boost |
|---|---|---|
| 开关管数量 | 4 | **2** |
| $V_o$ 公式 | $V_o=\dfrac{nV_g}{2D}$ （ $D$ = 传输占空比， $D<0.5$ ）| $V_o=\dfrac{nV_g}{2(1-D)}$ （ $D$ = 单管占空比， $D>0.5$ ）|
| 升压方向 | $D\downarrow\Rightarrow V_o\uparrow$ | $D\uparrow\Rightarrow V_o\uparrow$ |
| 重叠（Boost 充电）占比 | $2(0.5-D)$ | $2D-1$ |
| **开关管电压应力** | $\dfrac{V_o}{n}$ | $\boxed{\dfrac{2V_o}{n}}$ （**2 倍**）|
| 副边二极管电压应力 | $2V_o$ | $2V_o$ （**相同**）|
| 变压器原边 | 简单绕组 | **中心抽头**（更复杂）|
| 最大升压比 | 理论 ∞（ $D\to0$ ）| 理论 ∞（ $D\to1$ ）|

> **核心结论**：推挽 Boost 用"**省 2 只管子**"换来了"**开关管电压应力翻倍 + 中心抽头变压器**"。副边二极管应力**没有优势**（原版笔记声称"推挽 Boost 二极管仅 133V，远低于全桥的 800V"是**错误**的——两者都用中心抽头整流，都承受 $2V_o$ ）。

## 七、稳态电流关系

### 7.1 基本关系（由功率守恒直接得到）

Boost 电感串联在输入端，其平均电流 **就是输入电流**：

$$\boxed{I_L=I_{in}=\frac{P_o}{\eta\,V_g}}$$

由 $V_o=\frac{nV_g}{2(1-D)}$ 可消去 $V_g$ ，得到用输出量表达的等效形式：

$$\boxed{I_L=\frac{n\,I_o}{2(1-D)}=\frac{n\,I_o}{1-D_{boost}}}$$

**输出电流与副边电流的关系**：副边只在两个单管期（合计 $2(1-D)T_s$ ）向输出送电，此时副边电流 $=i_L/n$ ：

$$I_o=2(1-D)\cdot\frac{I_L}{n}\qquad\Longleftrightarrow\qquad I_L=\frac{nI_o}{2(1-D)}\quad✓\ \text{与上式一致}$$

### 7.2 开关管电流

**平均值**——两个管子**分担**输入电流（重叠期各一半，单管期独担全流）：

$$I_{Q,avg}=\frac{1}{T_s}\left[\underbrace{\frac{i_L}{2}\cdot(2D-1)T_s}_{\text{重叠期各半}}+\underbrace{i_L\cdot(1-D)T_s}_{\text{单管期独担}}\right]=I_L\left[D-0.5+1-D\right]$$

$$\boxed{I_{Q,avg}=\frac{I_L}{2}}$$

> **校验**：总输入电流 $=2I_{Q,avg}=I_L$ ✓（两只管子各承担一半的输入电流——**这正是推挽 Boost 相对全桥 Boost 的电流劣势：全部输入电流都要经过这 2 只管子**）

**有效值**：

$$I_{Q,rms}^2=\frac{1}{T_s}\left[\left(\frac{i_L}{2}\right)^2(2D-1)T_s+i_L^2(1-D)T_s\right]=i_L^2\left[\frac{2D-1}{4}+1-D\right]$$

$$\boxed{I_{Q,rms}=I_L\sqrt{0.75-0.5D}}$$

> **注意**： $I_{Q,rms}$ 与 $I_L$ 的比值随 $D$ 变化——$D$ 越小（重叠越短），单管期越长，RMS 越大。因此**校核 RMS 应取 $D_{min}$**；但 $I_L$ 本身在 $V_{g,min}$ 时最大。**必须对两个工况都算，取大者。**

**峰值**：

$$i_{Q,pk}=i_{L,pk}=I_L+\frac{\Delta i_L}{2}$$

### 7.3 副边二极管电流

每只二极管在**自己的单管期**导通（ $(1-D)T_s$ ），电流 $=i_L/n$ ：

$$I_{D,avg}=(1-D)\cdot\frac{I_L}{n}=\frac{I_o}{2}$$

$$I_{D,rms}^2=2(1-D)\left(\frac{I_L}{n}\right)^2\quad\Rightarrow\quad\boxed{I_{D,rms}=\frac{I_o}{\sqrt{2(1-D)}}=\frac{I_o}{\sqrt{1-D_{boost}}}}$$

$$i_{D,pk}=\frac{i_{L,pk}}{n}$$

> **校验**： $2\times I_{D,avg}=I_o$ ✓（两只二极管平均各送一半的负载电流）

### 7.4 电容电流

**输出电容**（唯一的输出平滑元件，负担比 Boost 家族以外都重）：

- 重叠期：电容放电 $-I_o$ ，时长 $(2D-1)T_s$
- 单管期：电容充电 $i_L/n-I_o$ ，时长 $2(1-D)T_s$

$$I_{C,rms}=\sqrt{\frac{1}{T_s}\left[I_o^2(2D-1)T_s+\left(\frac{i_L}{n}-I_o\right)^2\cdot2(1-D)T_s\right]}\;\approx\;I_o\sqrt{\frac{2D-1}{2(1-D)}}=I_o\sqrt{\frac{D_{boost}}{1-D_{boost}}}$$

（推导中用了 $\frac{i_L}{n}\gg I_o$ 的近似；精确式请代入实际纹波）

**输入电容**：Boost 电感已平滑输入电流， $C_{in}$ **只需吸收电感纹波**（高频去耦）：

$$I_{C_{in},rms}\approx\frac{\Delta i_L}{2\sqrt3}$$

> **这是本拓扑的隐藏优点**：输入端因为串了电感，输入电流**连续**，输入电容的 RMS 压力远小于推挽 Buck（后者要承受脉冲电流）。

## 八、磁芯复位原理

### 8.1 为什么本拓扑的"复位"与推挽 Buck 不同

推挽 Buck 靠"正负半周伏秒积天然相等"实现自然复位（激励是**电压源** $\pm V_g$ ，对称性由电路结构保证）。

推挽 Boost 的激励是**电流源**（电感），中心抽头电压是**单极性**的 $0/+\frac{V_o}{n}$ ，不存在"正负对称"这回事。它的磁通平衡靠的是：

| 时段 | 绕组电压 | 伏秒积 |
|---|---|---|
| 模态 1、3（重叠） | 所有绕组 $0$V | $0$ |
| 模态 2（仅 $Q_1$ ） | 上半绕组 $+\frac{V_o}{n}$ ，持续 $(1-D)T_s$ | $+\frac{V_o}{n}(1-D)T_s$ |
| 模态 4（仅 $Q_2$ ） | 下半绕组 $+\frac{V_o}{n}$ （**反向**），持续 $(1-D)T_s$ | $-\frac{V_o}{n}(1-D)T_s$ |

$$\text{一周期净伏秒}=\frac{V_o}{n}(1-D)T_s-\frac{V_o}{n}(1-D)T_s=0\quad✓$$

> **关键**：两个单管期的**绕组电压方向相反**（因为电流分别流过绕向相反的两半绕组），所以伏秒积自动抵消 —— **前提是两段的时间严格相等（都为 $(1-D)T_s$ ）**。

### 8.2 一旦不对称会怎样

若 $Q_1$ 的单管期比 $Q_2$ 的长（驱动不对称、 $R_{DS(on)}$ 不一致等）：

$$\Delta\Phi_{net}=\frac{V_o}{n}\left[(1-D_1)-(1-D_2)\right]T_s\neq0$$

磁通逐周期累积 → 单向饱和 → 该侧半绕组励磁电感骤降 → 电流尖峰 → 管子烧毁。

**但本拓扑有一个推挽 Buck 没有的缓冲**：由于原边由**电流源**驱动，磁通偏移会使两个单管期的**中心抽头电压自动不等**（饱和侧电压降低），从而**部分自平衡**。加上励磁电感通常设计得较小（推挽 Boost 允许电感有气隙），偏磁容限比推挽 Buck 大。

> **结论**：推挽 Boost 的偏磁风险**低于**推挽 Buck，但**不能忽视**——仍应使用电流模式控制并保持两路驱动对称。

### 8.3 与推挽 Buck 的复位机制对照

| | 推挽 Buck（电压馈电） | 推挽 Boost（电流馈电） |
|---|---|---|
| 激励类型 | 电压源 $\pm V_g$ | 电流源（电感） |
| 中心抽头电压 | 双极性 $\pm V_g$ | 单极性 $0/+\frac{V_o}{n}$ |
| 复位机制 | 正负半周电压天然对称 | 两单管期绕组电压反向、时间相等 |
| 偏磁后果 | 严重（无缓冲） | 较严重（有一定自平衡） |
| 偏磁容限 | 低 | 中（励磁电感可设计得较小） |

## 九、器件电压应力

### 9.1 理论最大应力（理想器件、忽略漏感）

| 器件 | 应力 | 表达式 | 本案例（ $V_o=400\text{V}$ ， $n=6$ ） |
|---|---|---|---|
| $Q_1$ / $Q_2$ | $V_{DS}$ | $\boxed{\dfrac{2V_o}{n}}$ | **133V** |
| $D_1$ / $D_2$ | $V_{RR}$ | $\boxed{2V_o}$ | **800V** |
| 原边绕组 | 绕组间电压 | $\dfrac{2V_o}{n}$ （两半绕组之间） | 133V |

**$V_{DS}=\frac{2V_o}{n}$ 的推导**见 §四 模态 2（自耦变压器效应）。等价形式：

$$\frac{2V_o}{n}=\frac{V_g}{1-D}\quad(\text{用 }V_o=\tfrac{nV_g}{2(1-D)}\text{ 代入})$$

> **与"标准 Boost"的对照**：普通 Boost 的开关管承受 $V_o=\frac{V_g}{1-D}$ 。这里承受 $\frac{2V_o}{n}$——**若用 $D_{boost}$ 表示，则 $\frac{2V_o}{n}=\frac{2V_g}{1-D_{boost}}$ ，是普通 Boost（同 $D_{boost}$ ）的 2 倍**。这就是中心抽头自耦结构的代价。

### 9.2 寄生参数附加应力（本拓扑最需要注意的地方）

| 来源 | 附加量级 | 机理 |
|---|---|---|
| **换流漏感尖峰** | **可达理论值的 30%~100%** ★ | 见下方详述 |
| PCB 走线电感 | 数 V~十几 V | 高 di/dt 回路 |
| 二极管反向恢复 | 加剧尖峰 | $Q_{rr}$ 注入原边 |
| 振铃 | 叠加阻尼振荡 | $L_k$ 与 $C_{oss}$ 、结电容 |

> **★ 为什么本拓扑的换流尖峰特别严重**
>
> 原边被**电感（电流源）**驱动。在"两管全通 → 单管导通"的换流瞬间，关断的那只管子所连半绕组的电流（ $i_L/2$ ）**必须转移到另一半绕组**去。这个电流转移受**漏感**限制，不能瞬时完成，于是：
> 1. 关断管所在节点（ $A$ 或 $B$ ）电压**上冲**，直到漏感能量被 $C_{oss}$/吸收电路耗散；
> 2. 上冲幅度可以显著超过 $\frac{2V_o}{n}$ ；
> 3. 与推挽 Buck 不同，这里**没有二极管箝位通路**，能量无处回馈。
>
> **标准对策**：① 变压器工艺优先（三明治绕法、铜箔、双线并绕）从源头压低 $L_k$ ；② 加 **RCD 或 LCD 吸收**；③ 采用**有源箝位**（可回收漏感能量并实现 ZVS，是电流馈电拓扑的主流方案）；④ 选更高的 $V_{DS}$ 额定（最贵但最快）。

### 9.3 安全裕量与额定值

$$V_{DS,rated}\ge\underbrace{\frac{2V_o}{n}}_{\text{理论}}\times\underbrace{1.5\sim2.0}_{\text{电流馈电尖峰较大}}$$

本案例： $133\text{V}\times1.5=200\text{V}$ → 选 **250V** 等级（为尖峰留足余量）。

> **⚠️ 强制要求**：本拓扑的尖峰对布局与变压器工艺极敏感，**必须以示波器实测 $V_{DS}$ 波形为准**，且峰值不超过额定的 80%。

## 十、器件电流应力

### 10.1 理论电流（本案例， $n=6$ ， $I_o=2.5\text{A}$ ， $V_{g,min}=36\text{V}$ ， $D_{max}=0.73$ ， $\eta=0.93$ ）

| 器件 | 平均值 | 有效值 | 峰值 |
|---|---|---|---|
| $Q_1$/$Q_2$ | $\dfrac{I_L}{2}=14.9\text{A}$ | $I_L\sqrt{0.75-0.5D}=18.6\text{A}$ | $i_{L,pk}=33.7\text{A}$ |
| $D_1$/$D_2$ | $\dfrac{I_o}{2}=1.25\text{A}$ | $\dfrac{I_o}{\sqrt{2(1-D)}}=3.4\text{A}$ | $\dfrac{i_{L,pk}}{n}=5.6\text{A}$ |
| Boost 电感 $L$ | $I_L=29.9\text{A}$ | $\approx30\text{A}$ | 33.7A |
| 输出电容 $C$ | 0 | $I_o\sqrt{\dfrac{D_{boost}}{1-D_{boost}}}=2.3\text{A}$ | — |
| 输入电容 $C_{in}$ | 0 | $\dfrac{\Delta i_L}{2\sqrt3}=2.2\text{A}$ | — |

> **注意 $I_{Q,avg}=I_L/2$**：这是把 $2D-1$ 与 $1-D$ 两段加权后得到的漂亮结果——**两只管子平分输入电流**。也正因如此，**全部输入电流都要流过这 2 只管子**，这是推挽 Boost 在大功率下的根本瓶颈。

### 10.2 器件损耗

**MOSFET**

$$P_{Q,cond}=2\times I_{Q,rms}^2R_{DS(on)}(T_j)$$
$$P_{Q,sw}\approx2\times\frac{1}{2}V_{DS}i_{L,pk}(t_r+t_f)f_s$$
$$P_{Q,drive}=2\,Q_gV_{gs}f_s$$

> 本案例 $I_{Q,rms}=18.6\text{A}$ 很大，因此 **$R_{DS(on)}$ 是效率的主导因素**（见 §十五）。 $R_{DS(on)}$ 随结温上升，估算乘 **1.5**。

**二极管**

$$P_D=2\left(V_F\cdot I_{D,avg}+\tfrac{1}{2}V_{RR}Q_{rr}f_s\right)$$

> $V_{RR}=800\text{V}$ 很高，**$Q_{rr}$ 项不可忽略** → 应选 **SiC 肖特基**（ $Q_{rr}\approx0$ ）或超快恢复。
> 本拓扑输出电流小（2.5A），二极管损耗绝对值不大，**损耗压力主要在开关管一侧**。

## 十一、高频变压器设计

### 11.1 匝比 $n$ （★ 受 §6.6 约束限制）

$$n=\frac{V_o}{V_{g,min}}\cdot2(1-D_{max})\quad\text{且必须满足}\quad n<\frac{V_o}{V_{g,max}}$$

**设计步骤**：

1. 由约束 ② 定上限： $n<\dfrac{V_o}{V_{g,max}}=\dfrac{400}{60}=6.67$ ，留裕量取 $n\le0.9\times6.67=6.0$
2. 取 $n=6$
3. 反算 $D_{max}$ （最低输入、要达标）：
   $$D_{max}=1-\frac{nV_{g,min}}{2V_o}=1-\frac{6\times36}{800}=1-0.27=0.73$$
4. 校验 $D_{min}$ （最高输入、要有重叠）：
   $$D_{min}=1-\frac{nV_{g,max}}{2V_o}=1-\frac{6\times60}{800}=1-0.45=0.55>0.5\quad✓$$
5. 校验裕量： $D_{max}=0.73$ （<1，留 0.27 余量 ✓）； $D_{min}=0.55$ （>0.5，重叠占比 $2D_{min}-1=0.10$ ✓ 但仅 10%，偏紧）

> **本案例的 $n$ 已经在约束边界上**——这是 400V 输出、60V 最高输入、 $n$ 必须 <6.67 的直接后果。若输入范围更宽，需要重新权衡（或改用全桥 Boost）。

**匝数取整**： $n=6$ → 若 $N_{p,half}=4$ ，则 $N_s=24$ ；若 $N_{p,half}=5$ ，则 $N_s=30$ 。**取整后必须反算校验 $D_{max}$ 、 $D_{min}$ 与 $V_o$ 。**

### 11.2 磁芯选择

| 因素 | 本案例取向 |
|---|---|
| 工作频率 | 50kHz → 铁氧体 **PC40/PC44/PC95** |
| 传输功率 | 1kW → EE55 / PQ4040 量级（ $A_e\approx350\sim400\text{mm}^2$ ） |
| 磁通摆幅 | 双向励磁但**单极性占空**， $\Delta B$ 可取得较大（0.4~0.5T），需按铁损校核 |
| 温升 | 目标 <40K，绕组损耗是重点（原边电流大、匝数少） |

### 11.3 原边匝数与磁通摆幅

磁通只在**单管期**变化（重叠期所有绕组 0V，磁通冻结）：

$$\Delta B=\frac{1}{N_{p,half}A_e}\int_{\text{单管期}}v\,dt=\frac{(V_o/n)\cdot(1-D)T_s}{N_{p,half}A_e}$$

反解：

$$\boxed{N_{p,half}\ge\frac{(V_o/n)\,(1-D)T_s}{\Delta B_{allow}\,A_e}}$$

> **★ 取哪个工况？** 分子 $(V_o/n)(1-D)$ 在 **$D_{min}$**（最高输入）时最大——**这与推挽 Buck 相反**！推挽 Buck 的伏秒积 $V_gd$ 与输入无关；推挽 Boost 的伏秒积随 $D$ 变化，最恶劣在 $D_{min}$ 。**这是本拓扑最容易算错的地方。**

本案例： $(V_o/n)(1-D_{min})T_s=66.67\times0.45\times20\mu s=600\text{V}\cdot\mu s$

取 EE55（ $A_e=350\text{mm}^2$ ）、 $\Delta B=0.43\text{T}$ （双向励磁， $B_{pk}=0.215\text{T}$ ）：

$$N_{p,half}\ge\frac{600\times10^{-6}}{0.43\times350\times10^{-6}}=3.99\quad\Rightarrow\quad N_{p,half}=4\text{匝}$$

$$N_s=nN_{p,half}=6\times4=24\text{匝}$$

### 11.4 磁芯饱和与气隙

- **建议留小气隙**：本拓扑的励磁电感 $L_m$ 与 Boost 电感 $L$ 是**两个独立**的储能元件。 $L_m$ 大 → 励磁电流小、损耗小；但偏磁容限低。
- 工程折中： $L_m$ 使励磁电流峰值 ≈ 反射电流的 10~20%；必要时开小气隙换偏磁容限。

### 11.5 励磁电感与励磁电流

$$\boxed{L_m=\frac{\mu_0\mu_eN_{p,half}^2A_e}{l_e}},\qquad i_{m,pk}=\frac{(V_o/n)(1-D)T_s}{L_m}$$

### 11.6 绕组线径

| 绕组 | RMS 电流 | 电流密度 | 所需截面积 |
|---|---|---|---|
| 半原边 ×2 | 18.6A | 4A/mm² | 4.7mm² ← **主铜损来源** |
| 半副边 ×2 | 3.4A | 4A/mm² | 0.85mm² |

**集肤深度**（50kHz、铜、100°C）： $\delta\approx0.30\text{mm}$ → 单根线径 $<0.6\text{mm}$ ，或直接用铜箔。

> **原边必须用铜箔或多股并联**：4 匝 × 4.7mm² = 17.7mm² 的窗口需求。

### 11.7 漏感控制（本拓扑的**首要工艺目标**）

| 措施 | 说明 |
|---|---|
| **三明治绕法**（副边夹在两半原边之间） | 最有效 |
| 两半原边**双线并绕**后串接 | 保证对称 + 降低漏感 |
| 副边用细线多股（24 匝） | 24 匝细线可分层夹绕 |
| 减小绝缘厚度 | 直接降低漏感 |

> **目标**： $L_k\le1\%\cdot L_m$ 。本拓扑对漏感比对推挽 Buck 更敏感——因为它是**电流馈电**，漏感直接决定换流尖峰。

## 十二、输出电容设计（本拓扑无输出电感）

> **注意**：Boost 家族**没有输出滤波电感**，输出电流是**脉冲式**的，全部由 $C$ 平滑。因此输出电容的负担比 Buck 家族重得多，选型逻辑也完全不同。

### 12.1 容值（由放电时间决定）

输出电容在**重叠期**单独向负载供电，时长 $(2D-1)T_s=D_{boost}T_s$ ：

$$\Delta V_C=\frac{I_o\cdot D_{boost}T_s}{C}\quad\Rightarrow\quad\boxed{C\ge\frac{I_o\,(2D-1)\,T_s}{\Delta V_C}=\frac{I_o\,D_{boost}}{f_s\,\Delta V_C}}$$

> **取哪个 $D$ ？** $D_{boost}=2D-1$ 在 **$D_{max}$ （最低输入）** 时最大 → 放电时间最长 → 纹波最大。**用 $D_{max}$ 。**

本案例（ $\Delta V_C\le1\%\times400\text{V}=4\text{V}$ ， $D_{boost,max}=0.46$ ）：

$$C\ge\frac{2.5\times0.46\times20\times10^{-6}}{4}=5.8\mu F\quad\Rightarrow\quad\text{取 }47\mu F/450V$$

### 12.2 ESR

$$\Delta V_{ESR}=i_{C,pk}\cdot ESR\approx\frac{i_{L,pk}}{n}\cdot ESR$$

本案例： $5.6\text{A}\times ESR\le2\text{V}\Rightarrow ESR\le360\text{m}\Omega$ （**极易满足**）。

> **与 Buck 家族的关键区别**：Buck 型（低压大电流输出）的 ESR 是瓶颈；**Boost 型（高压小电流输出）的容值项才是瓶颈**，ESR 反而宽松。

### 12.3 其他校核

- **纹波电流**： $I_{C,rms}\approx I_o\sqrt{\frac{D_{boost}}{1-D_{boost}}}=2.3\text{A}$ → 选额定 ≥4A
- **耐压**： $\ge1.5\times V_o=600\text{V}$ → 选 **450V 不够，应选 500V 或 600V**（ $V_o=400\text{V}$ 时 450V 仅 1.125 倍裕量，偏紧）
- **寿命/温升**：高压电解电容的 ESR 与纹波电流额定随温度下降，需按实际工况降额

### 12.4 输入电容

Boost 电感已平滑输入电流 → $C_{in}$ **只做高频去耦**：

$$C_{in}\ge\frac{\Delta i_L}{8f_s\Delta V_{g}}\qquad(\text{另加 1µF MLCC 旁路})$$

本案例（ $\Delta i_L=7.5\text{A}$ ， $\Delta V_g\le0.5\text{V}$ ）： $C_{in}\ge\frac{7.5}{8\times5\times10^4\times0.5}=37.5\mu F$ → 取 47µF/100V + MLCC。

> **本拓扑的隐藏优点**：与推挽 Buck 相比，这里输入电流连续， $C_{in}$ 的 RMS 压力小得多。**代价转移到了输出电容。**

## 十三、关键工程问题

### 13.1 ★ 换流尖峰——本拓扑的头号工程难点

**机理**：见 §9.2 的详述。核心是"**电流源 + 漏感**"：关断半个绕组的电流必须转移到另一半绕组，漏感阻止瞬时转移，多余能量只能靠 $C_{oss}$/吸收电路消耗。

**对策（按优先级）**

| 措施 | 效果 | 代价 |
|---|---|---|
| 1. **变压器工艺**（三明治、双线并绕、铜箔） | 从源头降低 $L_k$ | 工艺复杂度 |
| 2. **有源箝位**（Active Clamp） | 漏感能量回收 + ZVS | 多加 1 管 + 1 电容 + 驱动 |
| 3. **RCD 吸收** | 简单有效 | 耗能型、降效率 |
| 4. **提高 $V_{DS}$ 额定** | 最快 | 贵、 $R_{DS(on)}$ 高 |

> **行业实践**：电流馈电拓扑（推挽 Boost、全桥 Boost）几乎都配**有源箝位**，因为漏感能量在此类拓扑中占比较大且无处可去。

### 13.2 偏磁

见 §八。要点：
- 本拓扑有**部分自平衡**能力（电流馈电 + 磁通偏移会自动改变中心抽头电压），风险低于推挽 Buck
- 仍必须：**电流模式控制** + 两路驱动严格对称 + 变压器两半绕组严格对称

### 13.3 直通（直通风险）

若**两管同时导通**——**这不是故障，而是本拓扑的正常工作状态！**（重叠充电期）

> **⚠️ 概念澄清**：半桥/全桥的"同桥臂直通"是**故障**（会短路输入母线）；而推挽 Boost 的"两管同时导通"是**正常工作**——因为两个半绕组的外端同时接地并不会短路输入源（输入源经电感隔离），它只会把原边短路，从而给电感充电。
>
> **但死区仍然需要**：在"仅 $Q_1$ → 两管全通"的过渡中，若换流时序不当，仍可能引起异常。实际驱动应保证**先开通后关断**（与全桥 Boost 的重叠换流一致）。

### 13.4 PCB 布局

| 要求 | 原因 |
|---|---|
| Boost 电感紧靠变压器中心抽头 | 缩短高 di/dt 回路 |
| $C_{in}$ 紧贴电感输入端 | 高频去耦 |
| 两管驱动走线**等长等阻** | 保证 $D_1=D_2$ （防偏磁的第一道防线） |
| 中心抽头到两管的走线**完全对称** | 两半绕组回路寄生参数一致 |
| 输出二极管回路面积最小 | 降低 EMI 与振铃 |
| 变压器下方禁止走线 | 避免噪声耦合 |

### 13.5 热设计

- **原边电流大**（本案例 30A）→ 管子导通损耗与变压器铜损是主要热源
- 两管**共地** → 可共用散热器
- 变压器为双向励磁，铁损按等效频率估算

### 13.6 EMI

| 噪声源 | 应对 |
|---|---|
| 换流尖峰（最严重） | 有源箝位 / RC 吸收 / 优化变压器 |
| 高 di/dt：原边回路 | 缩面积、加高频旁路 |
| 输出二极管反向恢复 | SiC 或超快恢复 |
| 共模噪声（变压器寄生电容） | 静电屏蔽层、Y 电容 |

## 十四、损耗与效率估算

### 14.1 损耗构成与估算（本案例）

| 损耗项 | 公式 | 估算值 |
|---|---|---|
| $Q$ 导通 | $2I_{Q,rms}^2R_{DS(on)}\times1.5$ | $2\times18.6^2\times0.025\times1.5=26.0\text{W}$ ★ |
| $Q$ 开关 | $2\times\tfrac12V_{DS}i_{L,pk}(t_r+t_f)f_s$ | $2\times0.5\times200\times33.7\times60n\times5\times10^4=20.2\text{W}$ ★ |
| $Q$ 驱动 | $2Q_gV_{gs}f_s$ | ≈0.5W |
| 整流二极管 | $2V_FI_{D,avg}$ （SiC $V_F\approx1.5\text{V}$ ） | $2\times1.5\times1.25=3.8\text{W}$ |
| 铜损 | $I_{P,rms}^2R_P+I_{S,rms}^2R_S$ | ≈10W |
| 磁芯损耗 | Steinmetz | ≈6W |
| 吸收/箝位损耗 | 漏感能量 | ≈4W |
| 其他（控制、ESR） | — | ≈2W |
| **合计** | | **≈72W** |
| **效率** | $\eta=\dfrac{P_o}{P_o+P_{loss}}$ | **93.3%** |

> **注**： $R_{DS(on)}$ 的取值对结果影响极大——本估算取 250V MOS 的 25mΩ（@100°C，已含温度系数）。若选到 15mΩ 的器件，导通损耗可降至 15.6W，效率提升约 1 个百分点。

### 14.2 效率瓶颈分析（本拓扑的本质弱点）

| 损耗项 | 占比 | 是否可优化 |
|---|---|---|
| **开关管导通** | 36% | 选更低 $R_{DS(on)}$ （受耐压与成本限制）★ **本质瓶颈** |
| **开关管开关** | 28% | 有源箝位实现软开关（可大幅降低） |
| 铜损 | 14% | 增大线径、优化窗口 |
| 磁芯 | 8% | 低损材质 |
| 箝位 | 6% | 有源箝位回收 |
| 二极管 | 5% | 已用 SiC |

> **本质结论**：推挽 Boost 的效率瓶颈是"**全部输入电流流过 2 只管子 + 高电压应力**"。在 1kW 量级， $\sim93\%$ 已接近该拓扑的实际上限；**功率再大必须换全桥 Boost**（电流分散到 4 管、应力减半）。

## 十五、完整设计实例

> **⚠️ 以下为教学设计案例，所有数值仅用于演示计算过程，不代表任何实际工程参数。器件型号仅为案例，参数以最新 Datasheet 为准。**

### 案例 D：低压蓄电池 → 高压直流母线

**为什么选这个场景**：48V 电池组 → 400V 直流母线是储能/光伏/车载升压的典型需求；用同一案例与全桥 Boost 对照，可直接看出两者差异。

#### 15.1 设计指标

| 参数 | 符号 | 值 |
|---|---|---|
| 输入电压 | $V_g$ | 48V（范围 **36~60V**） |
| 输出电压 | $V_o$ | 400V |
| 输出功率 | $P_o$ | 1kW（ $I_o=2.5\text{A}$ ） |
| 开关频率 | $f_s$ | 50kHz |
| 效率目标 | $\eta$ | ≥93% |
| **最大单管占空比** | $D_{max}$ | 待定（**$D>0.5$**） |
| 电压纹波 | $\Delta V_o$ | ≤1%（4V） |

#### 15.2 匝比与占空比

**① 由约束定 $n$ 上限**：

$$n<\frac{V_o}{V_{g,max}}=\frac{400}{60}=6.67\quad\Rightarrow\quad n\le0.9\times6.67\approx6.0$$

**② 取 $n=6$**

**③ 反算占空比范围**：

$$D_{max}=1-\frac{nV_{g,min}}{2V_o}=1-\frac{6\times36}{800}=0.73\qquad(V_{g}=36\text{V})$$
$$D_{min}=1-\frac{nV_{g,max}}{2V_o}=1-\frac{6\times60}{800}=0.55\qquad(V_{g}=60\text{V})$$

校验： $D_{min}=0.55>0.5$ ✓（重叠占比 0.10）； $D_{max}=0.73<1$ ✓

#### 15.3 Boost 储能电感

**电流**： $I_L=\dfrac{P_o}{\eta V_{g,min}}=\dfrac{1000}{0.93\times36}=29.9\text{A}$

**纹波**：取 $\Delta i_L=25\%I_L=7.5\text{A}$

**感量**（充电期 $v_L=V_g$ ，时长 $(2D-1)T_s$ ；取 $D_{max}$ 使充电期最长、纹波最大）：

$$L=\frac{V_{g,min}\cdot(2D_{max}-1)\cdot T_s}{\Delta i_L}=\frac{36\times0.46\times20\times10^{-6}}{7.5}=44.2\mu H\quad\Rightarrow\quad\text{取 }47\mu H$$

**磁芯**： $I_{pk}=33.7\text{A}$ ， $E=\tfrac12LI_{pk}^2=26.7\text{mJ}$ → 铁硅铝（Sendust）大电流型，或铁粉芯，双磁芯叠用以容纳 $I^2L$ 。

#### 15.4 变压器

**匝数**： $(V_o/n)(1-D_{min})T_s=66.67\times0.45\times20\mu s=600\text{V}\cdot\mu s$

取 EE55（ $A_e=350\text{mm}^2$ ）、 $\Delta B=0.43\text{T}$ ：

$$N_{p,half}=\frac{600\times10^{-6}}{0.43\times350\times10^{-6}}=3.99\to\boxed{N_{p,half}=4\text{匝}},\qquad N_s=6\times4=\boxed{24\text{匝}}$$

**校验实际 $n$**： $24/4=6$ ✓ 无需重算。

**结构**：原边双线并绕 4+4 匝（中心抽头），副边 24+24 匝分两层夹绕（三明治），副边中心抽头引出。

#### 15.5 各器件应力与选型（四级递进）

**MOSFET $Q_1$/$Q_2$**

| 步骤 | 内容 |
|---|---|
| ① 理论应力 | $V_{DS}=\dfrac{2V_o}{n}=\dfrac{800}{6}=133\text{V}$ ； $I_{Q,rms}=18.6\text{A}$ ； $i_{Q,pk}=33.7\text{A}$ ； $I_{Q,avg}=14.9\text{A}$ |
| ② 寄生附加 | 电流馈电换流尖峰（估 $0.5\times133\approx67\text{V}$ ）→ 峰值 $\approx200\text{V}$ |
| ③ 安全裕量 | ×1.5 → $V_{DSS}\ge300\text{V}$ ；取 **250~300V** 等级 |
| ④ 额定参数 | $V_{DSS}\ge250\text{V}$ ， $I_D\ge60\text{A}@T_c=100°C$ ， $R_{DS(on)}\le25\text{m}\Omega$ ， $Q_g\le100\text{nC}$ ，**低 $C_{oss}$** |
| ⑤ 案例型号 | 250V N 沟道 MOS（低 $Q_g$ 快开关型），**参数以最新 Datasheet 为准** |

**整流二极管 $D_1$/$D_2$**

| 步骤 | 内容 |
|---|---|
| ① 理论应力 | $V_{RR}=2V_o=800\text{V}$ ； $I_{D,avg}=1.25\text{A}$ ； $I_{D,rms}=3.4\text{A}$ ； $i_{D,pk}=5.6\text{A}$ |
| ② 寄生附加 | 漏感振铃 → 峰值 $\approx1.3\times800=1040\text{V}$ |
| ③ 安全裕量 | ×1.3 → $\ge1350\text{V}$ ；取 **1200V SiC**（ $V_{RRM}$ 1200V，且 $Q_{rr}\approx0$ ） |
| ④ 额定参数 | $V_{RRM}\ge1200\text{V}$ ， $I_F\ge5\text{A}@T_c=100°C$ ，**SiC 肖特基**（零反向恢复，应对 50kHz+高压） |
| ⑤ 案例型号 | 1200V/5A SiC 肖特基，**参数以最新 Datasheet 为准** |

> **对照全桥 Boost 的同场景**：二极管应力完全相同（都是 $2V_o=800\text{V}$ ）——**推挽 Boost 在副边没有任何优势**。

**Boost 电感 $L$**

要求： $47\mu H$ / $I_{sat}\ge40\text{A}$ / $I_{rms}\ge30\text{A}$ / 直流偏置下感量跌落 ≤30%。

**输出电容 $C$**

要求： $C\ge10\mu F$ 、 $ESR\le360\text{m}\Omega$ 、纹波电流 ≥4A、**耐压 ≥600V**（ $V_o=400\text{V}$ ，450V 裕量不足）。

**输入电容 $C_{in}$**

要求： $C\ge47\mu F$ 、耐压 ≥100V、RMS ≥3A。方案：47µF/100V 电解 + 1µF MLCC。

## 十七、优缺点与适用场景

### 17.1 优点

1. **2 管实现隔离升压**——比全桥 Boost 省 2 管 + 2 路驱动
2. **两管共地**——驱动电路简单，无需隔离
3. **输入电流连续**——电感串联在输入端，输入纹波小
4. **双重升压**——Boost 因子 × 匝比
5. **磁芯双向励磁**——利用率高
6. **重叠导通保证电感电流始终有通路**——无断流问题

### 17.2 缺点

1. **开关管电压应力翻倍**——$2V_o/n$ ，是全桥 Boost 的 2 倍
2. **全部输入电流经过 2 只管子**——大功率时导通损耗随功率平方增长
3. **副边二极管耐压高**——$2V_o$ （与全桥 Boost 相同，**无优势**）
4. **换流尖峰严重**——电流馈电 + 漏感，**必须加箝位**
5. **中心抽头变压器**——比全桥 Boost 的简单原边复杂
6. **匝比受约束** $n<V_o/V_{g,max}$——限制了升压比与输入范围的组合

### 17.3 适用场景结论

> **在"低压输入（<100V）+ 中小功率（200W~1kW）+ 成本敏感、可接受效率 ~93%"的条件下，推挽 Boost 更合适**——它用 2 只管子完成隔离升压，胜在简单与便宜。
>
> **一旦功率超过 1kW，或需要最高效率，就必须换全桥 Boost**——因为推挽 Boost 的两个根本瓶颈（应力翻倍、电流集中）随功率恶化。

## 十九、公式速查

### 19.1 占空比与传输比

| 参数 | 公式 | 备注 |
|---|---|---|
| Boost 充电占空比 | $D_{boost}=2D-1$ | **重叠**时间占比 |
| 电压传输比 | $V_o=\dfrac{nV_g}{2(1-D)}=\dfrac{nV_g}{1-D_{boost}}$ | CCM |
| 单管占空比范围 | $0.5<D<1$ | 必须有重叠 |
| 匝比约束 | $n<\dfrac{V_o}{V_{g,max}}$ | ★ 防最高输入时失去重叠 |
| 由 $V_g,V_o$ 反解 | $D=1-\dfrac{nV_g}{2V_o}$ | |

### 19.2 电压应力

| 器件 | 公式 | 对照 |
|---|---|---|
| MOSFET | $V_{DS}=\dfrac{2V_o}{n}=\dfrac{V_g}{1-D}$ （+ 换流尖峰） | 全桥为 $\frac{V_o}{n}$ |
| 整流二极管 | $V_{RR}=2V_o$ | 全桥**相同** |
| 关断管漏极（单管期） | $\dfrac{2V_o}{n}$ | 自耦变压器效应 |
| 中心抽头（单管期） | $\dfrac{V_o}{n}$ | 被副边顶高 |

### 19.3 电流应力

| 器件 | 平均值 | 有效值 | 峰值 |
|---|---|---|---|
| Boost 电感 | $I_L=\dfrac{P_o}{\eta V_g}=\dfrac{nI_o}{2(1-D)}$ | $\approx I_L$ | $I_L+\tfrac{\Delta i_L}{2}$ |
| MOSFET | $\dfrac{I_L}{2}$ | $I_L\sqrt{0.75-0.5D}$ | $i_{L,pk}$ |
| 整流二极管 | $\dfrac{I_o}{2}$ | $\dfrac{I_o}{\sqrt{2(1-D)}}$ | $\dfrac{i_{L,pk}}{n}$ |
| 输出电容 | 0 | $I_o\sqrt{\dfrac{2D-1}{2(1-D)}}$ | $\dfrac{i_{L,pk}}{n}-I_o$ |
| 输入电容 | 0 | $\dfrac{\Delta i_L}{2\sqrt3}$ | — |

### 19.4 磁元件与电容

| 参数 | 公式 |
|---|---|
| Boost 电感 | $L=\dfrac{V_{g,min}(2D_{max}-1)T_s}{\Delta i_L}$ |
| 原边匝数 | $N_{p,half}\ge\dfrac{(V_o/n)(1-D_{min})T_s}{\Delta B A_e}$ ← **取 $D_{min}$** |
| 副边匝数 | $N_s=nN_{p,half}$ |
| 励磁电流峰值 | $i_{m,pk}=\dfrac{(V_o/n)(1-D)T_s}{L_m}$ |
| **输出电容** | $C\ge\dfrac{I_o(2D_{max}-1)T_s}{\Delta V_C}=\dfrac{I_oD_{boost,max}}{f_s\Delta V_C}$ |
| 输入电容 | $C_{in}\ge\dfrac{\Delta i_L}{8f_s\Delta V_g}$ |

## 二十、学习总结

### 20.1 一句话记住这个拓扑

> **推挽 Boost = 把推挽 Buck 的"输入电压源"换成"输入电流源（电感）"，于是"两管交替"变成"两管重叠"，升压比随重叠时间增长。**

### 20.2 五个必须刻在脑子里的数

| 数 | 值 | 来源 |
|---|---|---|
| 单管占空比 | $D>0.5$ | 必须有重叠才能充电 |
| Boost 充电占空比 | $D_{boost}=2D-1$ | 重叠时间占比 |
| 电压传输比 | $\dfrac{nV_g}{2(1-D)}=\dfrac{nV_g}{1-D_{boost}}$ | 伏秒平衡 |
| **开关管电压应力** | $\mathbf{\dfrac{2V_o}{n}}$ | 中心抽头自耦效应 |
| 副边二极管应力 | $2V_o$ | 中心抽头全波整流 |

### 20.3 三个"为什么"

**Q1：为什么升压发生在"两管同时导通"时，而不是单管导通时？**
A：Boost 的本质是给电感施加**正向电压**。电感一端是 $V_g$ ，另一端是中心抽头。要让 $v_L=V_g$ （满压充电），中心抽头必须是 0V——而只有**两个半绕组的外端都被接地**（两管全通），中心抽头才会是 0V。任何单管导通时，电感电流必须流进变压器（否则无路可走），而变压器会把中心抽头**向上顶到 $V_o/n$**，电感反而在放电。

**Q2：为什么开关管要承受 $\frac{2V_o}{n}$ ，而全桥 Boost 只有 $\frac{V_o}{n}$ ？**
A：中心抽头原边本质上是一个 **2:1 自耦变压器**。单管导通时，被驱动的半绕组电压是 $\frac{V_o}{n}$ ，另一半绕组"骑"在它上面，把电位再抬高 $\frac{V_o}{n}$ ，所以关断管的漏极电位是 $\frac{2V_o}{n}$ 。全桥 Boost 的原边是简单绕组，没有这个自耦叠加效应。

**Q3：为什么匝比不能取大？**
A：因为"升压比要大（ $n$ 大）"与"最高输入时仍要有重叠（ $n$ 小）"互相矛盾。 $D_{min}=1-\frac{nV_{g,max}}{2V_o}>0.5$ 推出 $n<\frac{V_o}{V_{g,max}}$ 。**输入范围越宽，可用的 $n$ 越小，升压能力越受限**——这是推挽 Boost 最不直观的一条设计约束。

## 二十一、勘误说明（相对原版笔记）

> 本节记录重写前版本中的错误，供对照学习。**这些是最容易在"推挽"这一族拓扑上犯的错。**

| # | 原版说法 | 正确结论 | 性质 |
|---|---|---|---|
| 1 | "两管**交替**导通，单管占空比 $D<0.5$" | 两管**重叠**导通， $D>0.5$ （重叠 $(2D-1)T_s$ 为充电期） | **根本错误**——把电流馈电拓扑当成电压馈电分析 |
| 2 | $V=\dfrac{nV_g}{1-D}$ | $V_o=\dfrac{nV_g}{2(1-D)}=\dfrac{nV_g}{1-D_{boost}}$ | 公式错误（差了 2 倍，且 $D$ 的定义相反） |
| 3 | "模态 1： $Q_1$ 导通 → $v_L=V_g$ （电感储能）**且**能量同时传向副边" | 自相矛盾。 $Q_1$ 单管导通时 $v_L=V_g-\frac{V_o}{n}<0$ （放电）**并**传能；充电只发生在两管全通时 | **逻辑矛盾**——"充电"与"传能"不可能同时发生 |
| 4 | "过渡模态：两管同时关断，电感电流通过体二极管找回路" | **不存在这个稳态模态**。正常工作时至少一只管子导通，电感电流始终有低阻通路（这正是重叠控制的目的） | 编造了不存在的模态 |
| 5 | "开关管电压应力 $2V_g$" | $V_{DS}=\dfrac{2V_o}{n}=\dfrac{V_g}{1-D}$ （由**输出**决定，不是 $2V_g$ ） | 概念混用——套用了电压馈电推挽的结论 |
| 6 | "推挽 Boost 的二极管仅承受 $\frac{2V}{n}=133\text{V}$ ，远低于全桥 Boost 的 800V" | 两者都是中心抽头全波整流，**二极管都承受 $2V_o=800\text{V}$** | 错误结论——虚构了一个不存在的优势 |
| 7 | "模态 2： $Q_2$ 导通 → $v_T=V_{ct}$ （与模态 1 同向）" | 两个单管期的绕组电压**方向相反**（电流流过绕向相反的两半绕组），这正是磁通能平衡的原因 | 忽略了两半绕组反向绕制 |
| 8 | 未提及匝比约束 | $n<V_o/V_{g,max}$——最重要的隐藏设计约束 | 缺失关键约束 |

> **根因分析**：原版是照搬"推挽 Buck"的模态框架来写"推挽 Boost"的。两者**变压器结构相同、但馈电方式相反**，属于不同拓扑族。**教训：判断推挽拓扑时，第一件事是看"电感在输入侧还是输出侧"——它决定了 $D$ 是小于 0.5 还是大于 0.5。**
