# 全桥隔离 Boost 变换器（Full-Bridge Transformer-Isolated Boost Converter）

> 本笔记遵循 [00-统一规范](00-统一规范.md)。原理图（`拓扑图/Full-bridge transformer-isolated boost converter.png`）为最高依据。

---

## 一、拓扑概述

### 1.1 拓扑名称与归类

**全桥隔离型 Boost 变换器**，属于**电流馈电型全桥**（Current-Fed Full Bridge, CFFB）。

| 归类维度 | 结论 |
|---|---|
| 家族 | **Boost 家族**（储能电感在输入侧、变压器之前） |
| 馈电方式 | **电流馈电**——变压器由电感"电流源"驱动 |
| 励磁方式 | 双向励磁 |
| 控制变量 | 占空比 $D$ （**功率传输占空比**， $D<0.5$ ） |
| 开关管数量 | 4 |
| 整流结构 | 副边中心抽头**全波整流** |

### 1.2 原理图解读

![](拓扑图/Full-bridge%20transformer-isolated%20boost%20converter.png)

| 位置 | 连接 |
|---|---|
| 输入源 | $V_g$ |
| **储能电感 $L$** | 串联在 $V_g$ 正端与桥臂**上母线**（ $Q_1$/$Q_3$ 漏极）之间 |
| 左桥臂 | $Q_1$ （上）+ $Q_2$ （下） |
| 右桥臂 | $Q_3$ （上）+ $Q_4$ （下） |
| 原边绕组 | **简单绕组**，跨接在左桥臂中点与右桥臂中点之间 |
| 副边绕组 | 中心抽头双半绕组；中心抽头接输出回线 |
| $D_1$ / $D_2$ | 全波整流，两管阴极并接输出正端 |
| 输出滤波 | **只有 $C$ ，没有输出电感** ← Boost 家族标志 |

> **三个必须看清的点**
> 1. **电感在输入侧、桥臂之前**——Boost 家族的标志；
> 2. **上母线（ $Q_1$/$Q_3$ 漏极）由电感供电**，不是直接接 $V_g$——因此上母线电压是可变的，这是它能升压的根本；
> 3. **两桥臂的上下管都是"互补 + 移相"驱动**，不是简单对角驱动——这点与全桥 Buck 不同，务必区分。

### 1.3 宏观工作机理

> ⚠️ **核心认知**：
> **Boost 的"充电"必须让电感两端出现正电压。上母线由电感供电，要让 $v_L=V_g$ ，上母线必须被拉到 0V——这要求每个桥臂的上下管同时导通（把上下母线短路）——也就是"四管全通"。**

| 环节 | 功能 |
|---|---|
| ① Boost 储能电感 $L$ | 储能/释能，提供第一重升压 |
| ② 全桥（ $Q_1\sim Q_4$ ） | **重叠导通**：全通期上母线短路（充电）；对角期电感电流经变压器送副边（放电+传输） |
| ③ 高频变压器（简单原边 $1:n$ ） | 第二重升压 + 电气隔离 |
| ④ 全波整流（ $D_1$ 、 $D_2$ ） | 双极性 → 单向脉动 |
| ⑤ 输出电容 $C$ | 平滑脉冲电流，支撑 $V_o$ |

**控制逻辑**：**两桥臂的上下管互补（各 50% 占空），但左右两桥臂之间存在相位差**。每个半周期内：

- **对角期**（ $DT_s$ ）：一组对角线导通 → 电感电流经变压器送副边（**功率传输**）
- **全通期**（ $\Delta T_s$ ）：四管全通 → 上母线被短路 → 电感充电（**Boost 储能**）

$$D+\Delta=0.5\qquad\Longrightarrow\qquad\text{一周期两个对角期} + \text{两个全通期}$$

> **$D$ 越小 → 全通期 $\Delta$ 越长 → 充电越久 → 升压比越高**（这是 Boost 家族的普遍规律）

### 1.4 优点

1. **开关管电压应力最低（升压拓扑中）**——$V_{DS}=\dfrac{V_o}{n}$ ，是推挽 Boost（ $\frac{2V_o}{n}$ ）的**一半**
2. **电流应力分散到 4 管**——每管只承担部分输入电流，大功率时优势显著
3. **漏感能量有回馈通路**——换流时经体二极管回馈，尖峰小
4. **换流过程天然接近 ZVS**——电流源驱动 + $C_{oss}$ 充放电，可实现软开关
5. **原边是简单绕组**——绕制简单、漏感小、无两半绕组对称性问题
6. **输入电流连续**——电感串联在输入端
7. **功率扩展性最好**——1kW~10kW+ 升压场合的首选

### 1.5 缺点

1. **开关管最多（4 管 + 4 路驱动）**——其中 2 路高边需隔离驱动，成本最高
2. **驱动时序最复杂**——互补 + 移相 + 死区 + 重叠，逻辑复杂
3. **副边二极管耐压高**——$2V_o$ （与推挽 Boost 相同，**无优势**）
4. **匝比受限**——$n<V_o/V_{g,max}$ （与推挽 Boost 相同的约束）
5. **偏磁风险**——电流馈电，磁通平衡依赖时序对称
6. **必须加箝位/吸收**——虽比推挽轻，但换流仍需处理

### 1.6 适用场景

| 场景 | 是否合适 | 原因 |
|---|:---:|---|
| **大功率升压（>1kW）** | ✅ **最佳** | 电流分散到 4 管、应力减半、效率最高 |
| 储能变流器（PCS）、电池储能 | ✅ | 大功率双向应用 |
| 光伏组串/集中式逆变器前级 | ✅ | 低压直流 → 高压母线 |
| 电动汽车充电/放电 | ✅ | 大功率、高效率 |
| 中小功率升压（200W~1kW） | △ 过设计 | 推挽 Boost 更经济 |
| 降压场景 | ❌ | 本拓扑只能升压 |

## 二、统一符号定义

### 2.1 通用符号

| 符号 | 含义 | 本笔记取值示例 |
|---|---|---|
| $V_g$ | 输入直流电压 | 48V（范围 36~60V） |
| $V_o$ | 输出电压 | 400V |
| $I_o$ | 输出电流 | 2.5A |
| $P_o$ | 输出功率 | 1kW |
| $f_s$ | 开关频率 | 50kHz |
| $T_s$ | 开关周期 | 20µs |
| $\eta$ | 效率 | 0.93 |

### 2.2 ★ 占空比定义（本拓扑关键）

| 符号 | 定义 | 范围 | 说明 |
|---|---|---|---|
| $D$ | **功率传输占空比**（对角期 / $T_s$ ） | $\mathbf{0<D<0.5}$ | **不是单管占空比**！ |
| $\Delta$ | **全通期占空比**（Boost 充电） | $\Delta=0.5-D$ | 两管臂重叠的时间占比 |
| — | 单管占空比 | $=0.5$ （互补驱动） | 每管导通半周期 |

$$\boxed{D+\Delta=0.5}$$

> **与全桥 Buck 的定义完全不同**：
> - 全桥 **Buck**： $D_{eff}=2d$ （对角期总占比）， $D_{eff}$ 越大输出越高
> - 全桥 **Boost**： $D$ = 对角期占比，**$D$ 越小输出越高**（Boost 规律）
>
> **横向比较时务必注意这个定义差异。**

### 2.3 匝比定义

$$n=\frac{N_s}{N_p}\qquad(N_p\text{＝整个原边匝数，非中心抽头})$$

### 2.4 分析假设

CCM · 理想器件 · 忽略漏感 · 稳态 · 小纹波近似 · 理想变压器。

## 三、电路结构完整拆解

### 3.1 输入侧

| 元件 | 功能 | 关键说明 |
|---|---|---|
| $V_g$ | 直流输入 | 经电感后给桥臂上母线供电 |
| **$L$** | **Boost 储能电感** | 串联在 $V_g^+$ 与上母线之间；**它的电流就是输入电流** |
| $Q_1$ 、 $Q_2$ | 左桥臂（上、下） | **互补驱动**，中点接原边一端 |
| $Q_3$ 、 $Q_4$ | 右桥臂（上、下） | **互补驱动**，与左桥臂**相位差 ΔT** |
| 原边绕组 | 简单绕组 | 跨接在左右桥臂中点之间 |

**为什么"上母线不是 $V_g$"**：上母线由电感供电。当某桥臂上下管同时导通时，该桥臂把上母线短路到地 → 上母线 $=0$ 。因此**上母线电压是可变的**（ $0$ 或 $\frac{V_o}{n}$ ），这正是升压的机制。

### 3.2 副边

| 元件 | 功能 |
|---|---|
| $D_1$ 、 $D_2$ | 全波整流，交替导通 |
| $C$ | **唯一的输出储能元件** |
| $R_o$ | 负载 |

**全通期**： $v_T=0$ → 副边无电压 → **$D_1$ 、 $D_2$ 均截止** → 负载由 $C$ 供电。

## 四、一个完整开关周期的工作过程

**驱动时序**（关键！）

```
Q1:  ████████████████                        ████████████████
     |←    T/2    →|                          |←    T/2    →|
Q3:        ████████████████                        ████████████
Q2:                      ████████████████
Q4:                            ████████████████

     |← DTs →|← ΔTs →|← DTs →|← ΔTs →|
      模态2     模态3    模态4     模态1
     (Q1+Q4)   (全通)  (Q2+Q3)   (全通)
     能量传输   Boost充电 能量传输  Boost充电
```

**总览**（一个周期 4 段，2 种状态）

| 阶段 | 时长 | 开关状态 | 变压器 | 电感 |
|---|---|---|---|---|
| **能量传输**（对角期） | $DT_s$ | 一组对角线导通 | 有电压、传能 | **放电**（ $v_L=V_g-\frac{V_o}{n}$ ） |
| **Boost 充电**（全通期） | $\Delta T_s=(0.5-D)T_s$ | **四管全通** | 短路、无电压 | **充电**（ $v_L=V_g$ ） |

---

### 4.1 模态 1：四管全通（Boost 充电）——时长 $(0.5-D)T_s$

#### （1）状态表

| 元件 | 状态 |
|---|---|
| $Q_1\sim Q_4$ | **全部 ON** |
| $D_1$ 、 $D_2$ | **全 OFF** |
| 变压器 | **不工作**（ $v_T=0$ ，磁通不变） |
| $L_m$ | 保持（两端 0V） |
| $L$ | **储能**（电流上升） |
| $C$ | **放电**（单独向负载供电） |

#### （2）原边：上母线为什么被短路

四管全通 → 每个桥臂的上下管同时导通 → **每个桥臂都把上母线直接短路到地**：

$$v_{top}=0\quad\Rightarrow\quad\boxed{v_L=V_g-v_{top}=V_g>0}$$

**电流路径**：

$$V_g(+)\to L\to\text{上母线}\to\begin{cases}Q_1\to\text{左中点}\to Q_2\to\text{地}\\\\Q_3\to\text{右中点}\to Q_4\to\text{地}\end{cases}\to V_g(-)$$

- 上母线被两条腿同时短路 → **电感电流平均分到两条腿**，各 $i_L/2$
- 两桥臂中点电位相同（ $v_{ML}=v_{MR}$ ）→ **原边电压为零** → 磁通不变 → 副边无电压 ✓

> **注意**：这里的"四管全通"**不是故障**！与全桥 Buck 的"同桥臂直通"完全不同——本拓扑中它是**正常的工作状态**。原因：电流由**电感**提供（不是直接由 $V_g$ 硬接），短路的是**桥臂上母线**而不是输入源，电感限流决定了电流大小。

#### （3）电压与电流

| 量 | 值/趋势 |
|---|---|
| $v_L$ | $+V_g$ |
| $v_{top}$ （上母线） | $0$ |
| $v_T$ （原边） | $0$ |
| $V_{DS}(Q_1\sim Q_4)$ | $\approx0$ （全导通） |
| $i_L$ | 线性上升， $di_L/dt=V_g/L$ |
| 各管电流 | $i_L/2$ （每条腿分担一半） |
| $i_{D1}=i_{D2}$ | $0$ |
| $i_C$ | $=-I_o$ （电容放电） |

---

### 4.2 模态 2： $Q_1$+$Q_4$ 导通（正半周能量传输）——时长 $DT_s$

#### （1）状态表

| 元件 | 状态 |
|---|---|
| $Q_1$ 、 $Q_4$ | **ON**（对角线） |
| $Q_2$ 、 $Q_3$ | OFF |
| $D_1$ | **ON** |
| $D_2$ | OFF |
| 变压器 | **正向励磁** |
| $L$ | **释能**（电流下降） |
| $C$ | **充电** |

#### （2）原边：上母线电压被副边钳定

$Q_1$ 导通把左中点拉到上母线； $Q_4$ 导通把右中点拉到地。原边两端电压 = 上母线电压：

$$v_T=v_{top}$$

而副边 $D_1$ 导通、把副边接到 $V_o$ → 由变压器反推：

$$v_T=\frac{V_o}{n}\quad\Longrightarrow\quad v_{top}=\frac{V_o}{n}$$

$$\boxed{v_L=V_g-\frac{V_o}{n}<0}\qquad(\text{升压 ⇒ }V_o/n>V_g)$$

**电流路径**：

$$V_g\to L\to Q_1(\text{漏}\to\text{源})\to\text{原边绕组}\to Q_4(\text{漏}\to\text{源})\to V_g(-)$$
$$\text{副边：上端}\to D_1(\text{Anode}\to\text{Cathode})\to C\parallel R_o\to\text{中心抽头}$$

#### （3）开关管电压应力

关断管 $Q_2$ （左桥臂下管）的漏极 = 左中点 = 上母线 $=\frac{V_o}{n}$ ；源极接地：

$$\boxed{V_{DS}=\frac{V_o}{n}}$$

> **★ 这是全桥 Boost 相对推挽 Boost 的最大优势**：推挽 Boost 的关断管承受 $\frac{2V_o}{n}$ （中心抽头自耦叠加），全桥 Boost 只承受 $\frac{V_o}{n}$——**一半**。

#### （4）副边： $D_1$ 导通、 $D_2$ 截止

- 副边上端为 $+V_o$ ，下端为 $-V_o$ （相对中心抽头）
- $D_1$ ：**阳极** $+V_o$ ，**阴极** $+V_o$ （输出）→ 正偏导通
- $D_2$ ：**阳极** $-V_o$ ，**阴极** $+V_o$ → 反偏截止

$$\boxed{V_{RR}(D_2)=2V_o}$$

#### （5）电流与电压

| 量 | 值/趋势 |
|---|---|
| $v_L$ | $V_g-\frac{V_o}{n}$ （负） |
| $v_{top}$ | $\frac{V_o}{n}$ |
| $i_L$ | 线性下降 |
| $i_{Q1}=i_{Q4}$ | $=i_L$ （全部电流） |
| $i_{D1}$ | $=i_L/n$ |
| $v_s$ | $V_o$ |

---

### 4.3 模态 3 / 模态 4

- 模态 3 ≡ 模态 1（四管全通，充电）
- 模态 4 ≡ 模态 2 的极性反转（ $Q_2$+$Q_3$ 导通， $D_2$ 导通， $D_1$ 承受 $2V_o$ ）

**换流过程**（从对角期到全通期）：以"$Q_1$+$Q_4$ → 四管全通"为例——**先开通 $Q_2$ 、 $Q_3$**（此时 $Q_1$ 、 $Q_4$ 仍导通 → 四管全通），**再关断 $Q_1$ 、 $Q_4$**。由于电感电流是电流源，这个换流由电感电流驱动 $C_{oss}$ 充放电，**天然接近 ZVS，无断流、无尖峰**。

## 六、稳态电压传输关系

### 6.1 电路状态

| 时段 | 时长 | $v_L$ |
|---|---|---|
| 对角期（能量传输） | $2\times DT_s$ | $V_g-\frac{V_o}{n}$ |
| 全通期（Boost 充电） | $2\times(0.5-D)T_s$ | $+V_g$ |

### 6.2 推导

$$\underbrace{\left(V_g-\frac{V_o}{n}\right)\cdot2DT_s}_{\text{放电}}+\underbrace{V_g\cdot2(0.5-D)T_s}_{\text{充电}}=0$$

展开：

$$2V_gD-\frac{2DV_o}{n}+V_g(1-2D)=0$$

$$V_g(2D+1-2D)=\frac{2DV_o}{n}$$

$$V_g=\frac{2D\,V_o}{n}$$

$$\boxed{V_o=\frac{n\,V_g}{2D}}\qquad\Longleftrightarrow\qquad\boxed{\frac{V_o}{V_g}=\frac{n}{2D}}\qquad(D<0.5)$$

### 6.3 用"标准 Boost"形式重写

把对角期视为"开关关断"，全通期视为"开关导通"，则 Boost 开关占空比 $=2\Delta=1-2D$ ：

$$\frac{V_o/n}{V_g}=\frac{1}{1-(1-2D)}=\frac{1}{2D}\quad✓$$

> **极简理解**：**这就是一个标准 Boost**——开关导通占空比 $=1-2D$ ，输出电压 $=V_o/n$ （副边折射到原边）。

### 6.4 变量定义与适用条件

| 符号 | 含义 | 范围 |
|---|---|---|
| $D$ | 功率传输（对角）占空比 | $0<D<0.5$ |
| $\Delta$ | 全通占空比 $=0.5-D$ | $0<\Delta<0.5$ |
| $V_o$ | 输出电压 | $\ge nV_g$ （升压） |

**适用条件**：CCM · 理想器件 · 忽略漏感 · 稳态 · 小纹波近似。

### 6.5 设计约束： $n<\dfrac{V_o}{V_{g,max}}$

要保证最高输入时仍有全通期（ $\Delta>0$ ，即 $D<0.5$ ）：

$$D_{max}=\frac{nV_{g,max}}{2V_o}<0.5\quad\Longleftrightarrow\quad\boxed{n<\frac{V_o}{V_{g,max}}}$$

> **★ 这条约束与推挽 Boost 完全相同**——这是**所有电流馈电隔离升压拓扑的共同约束**。原因相同：升压能力（要求 $n$ 大）与"必须保留重叠/全通期"（要求 $n$ 小）互相矛盾。

### 6.6 与推挽 Boost 的公式对照

| 对比 | 全桥 Boost | 推挽 Boost |
|---|---|---|
| $V_o$ 公式 | $\dfrac{nV_g}{2D}$ | $\dfrac{nV_g}{2(1-D)}$ |
| $D$ 含义 | 功率传输占空比（ $D<0.5$ ） | 单管占空比（ $D>0.5$ ） |
| 充电占空比 | $1-2D$ | $2D-1$ |
| **开关管电压应力** | $\boxed{\dfrac{V_o}{n}}$ ★ | $\dfrac{2V_o}{n}$ |
| 副边二极管应力 | $2V_o$ | $2V_o$ |
| 变压器原边 | **简单绕组** ★ | 中心抽头 |
| 匝比约束 | $n<\dfrac{V_o}{V_{g,max}}$ | $n<\dfrac{V_o}{V_{g,max}}$ |

## 七、稳态电流关系

### 7.1 基本关系

$$\boxed{I_L=I_{in}=\frac{P_o}{\eta V_g}=\frac{nI_o}{2D}}$$

**校验**：副边只在两个对角期（合计 $2DT_s$ ）送电，副边电流 $=i_L/n$ ：

$$I_o=2D\cdot\frac{I_L}{n}\quad\Longleftrightarrow\quad I_L=\frac{nI_o}{2D}\quad✓$$

### 7.2 开关管电流（★ 与全桥 Buck 不同，务必区分）

**每管的导通时间 = $T_s/2$**（互补驱动），但**导通期间的电流不同**：

- **对角期**（ $DT_s$ ）：该管属对角线 → 流过**全部** $i_L$
- **全通期**（ $\Delta T_s=(0.5-D)T_s$ ）：该管所在腿分担一半 → 流过 $i_L/2$

$$I_{Q,avg}=\frac{1}{T_s}\left[i_L\cdot DT_s+\frac{i_L}{2}\cdot(0.5-D)T_s\right]=i_L\left[D+\frac{0.5-D}{2}\right]$$

$$\boxed{I_{Q,avg}=I_L\cdot\frac{0.5+D}{2}}$$

$$I_{Q,rms}^2=i_L^2\left[D+\frac{(0.5-D)}{4}\right]=i_L^2\left[\frac{0.5-D+4D}{4}\right]=i_L^2\cdot\frac{0.5+3D}{4}$$

$$\boxed{I_{Q,rms}=I_L\sqrt{\frac{0.5+3D}{4}}=I_L\sqrt{0.125+0.75D}}$$

> **★ 易错点**：本拓扑的开关管电流公式与全桥 **Buck** 完全不同。全桥 Buck 的每管只导通 $dT_s$ ；全桥 Boost 的每管导通 $T_s/2$ （半周期）。**切勿套用 Buck 的公式。**

**峰值**：

$$i_{Q,pk}=i_{L,pk}=I_L+\frac{\Delta i_L}{2}$$

### 7.3 副边二极管电流

每只二极管在**自己的对角期**导通（ $DT_s$ ），电流 $=i_L/n$ ：

$$I_{D,avg}=D\cdot\frac{I_L}{n}=\frac{I_o}{2}$$

$$I_{D,rms}^2=2D\left(\frac{I_L}{n}\right)^2\quad\Rightarrow\quad\boxed{I_{D,rms}=\frac{I_o}{2\sqrt{D}}}$$

$$i_{D,pk}=\frac{i_{L,pk}}{n}$$

> **校验**： $2I_{D,avg}=I_o$ ✓

### 7.4 电容电流

**输出电容**（全通期单独供电，时长 $(1-2D)T_s$ ）：

$$I_{C,rms}\approx I_o\sqrt{\frac{1-2D}{2D}}$$

**输入电容**：电感已平滑输入电流， $C_{in}$ 只做高频去耦：

$$I_{C_{in},rms}\approx\frac{\Delta i_L}{2\sqrt3}$$

> **本拓扑的隐藏优势**：输入电流连续 → $C_{in}$ 压力小；与推挽 Boost 相同。

## 八、磁芯复位原理

### 8.1 磁通平衡机制

| 时段 | 原边电压 | 伏秒积 |
|---|---|---|
| 对角期 A（ $DT_s$ ） | $+\frac{V_o}{n}$ | $+\frac{V_o}{n}DT_s$ |
| 全通期（ $\Delta T_s$ ） | $0$ | $0$ |
| 对角期 B（ $DT_s$ ） | $-\frac{V_o}{n}$ | $-\frac{V_o}{n}DT_s$ |
| 全通期（ $\Delta T_s$ ） | $0$ | $0$ |

$$\text{一周期净伏秒}=\frac{V_o}{n}DT_s-\frac{V_o}{n}DT_s=0\quad✓$$

> **关键**：两个对角期的**幅值相同、时间相同**（都为 $DT_s$ ），所以伏秒积自动抵消 → 磁通对称摆动 → 自动复位。

### 8.2 偏磁风险与对策

| 原因 | 机理 |
|---|---|
| 两桥臂相位差不对称 | 正负对角期时长不等 |
| $R_{DS(on)}$ 不一致 | 加在绕组上的电压不等 |
| 死区/换流不对称 | 换流过程不完全对称 |

**后果**：磁通累积 → 饱和 → 电流尖峰 → 管子损坏。

**对策**：

1. **电流模式控制**（逐周期平衡）
2. **原边串隔直电容** $C_b$ （大功率常用）
3. **桥臂波形对称性设计**（驱动等长等阻、环路对称）

> **与全桥 Buck 相同的需求**：全桥 Boost 也**没有天然隔直机制**，必须主动解决偏磁。

## 九、器件电压应力

### 9.1 理论最大应力

| 器件 | 应力 | 表达式 | 本案例（ $V_o=400\text{V}$ ， $n=5$ ） |
|---|---|---|---|
| $Q_1\sim Q_4$ | $V_{DS}$ | $\boxed{\dfrac{V_o}{n}=\dfrac{V_g}{2D}}$ | **80V** |
| $D_1$ / $D_2$ | $V_{RR}$ | $\boxed{2V_o}$ | **800V** |
| 原边绕组 | 绕组电压 | $\dfrac{V_o}{n}$ | 80V |

**等价形式**： $\dfrac{V_o}{n}=\dfrac{V_g}{2D}$ 。注意 $D<0.5$ ，故 $\frac{V_g}{2D}>V_g$——**升压拓扑的开关管必然承受高于输入的电压** ✓

> **与推挽 Boost 对比**：推挽 Boost 的应力是 $\frac{2V_o}{n}$ ，全桥 Boost 是 $\frac{V_o}{n}$——**正好一半**。这就是全桥多出的 2 只管子换来的东西。

### 9.2 寄生参数附加应力

| 来源 | 附加量级 | 机理 |
|---|---|---|
| 换流振铃 | **较小** ★ | 电流源驱动 + $C_{oss}$ ，换流天然接近 ZVS，且漏感能量经体二极管回馈 |
| PCB 走线电感 | 数 V | 高 di/dt 回路 |
| 二极管反向恢复 | 加剧振铃 | $Q_{rr}$ 注入原边 |

> **本拓扑的换流质量优于推挽 Boost**：因为四个管子构成两条独立通路，换流时总有低阻沟道路径（"先开通后关断"），电感电流不断流。

### 9.3 安全裕量与额定值

$$V_{DS,rated}\ge\frac{V_o}{n}\times1.5\sim2.0$$

本案例： $80\times1.5=120\text{V}$ → 选 **150V** 等级（留足换流尖峰裕量）。

## 十、器件电流应力

### 10.1 理论电流（本案例， $n=5$ ， $I_o=2.5\text{A}$ ， $V_{g,min}=36\text{V}$ ， $D_{min}=0.225$ ）

> 注意： $D$ 在**最低输入**时最小（升压需求最大）→ $I_L$ 最大、 $(0.5+3D)/4$ 最小 → **需对两个工况都算**。

$I_L=\dfrac{P_o}{\eta V_{g,min}}=\dfrac{1000}{0.93\times36}=29.9\text{A}$

| 器件 | 平均值 | 有效值 | 峰值 |
|---|---|---|---|
| $Q_1\sim Q_4$ （每只） | $I_L\frac{0.5+D}{2}=11.6\text{A}$ | $I_L\sqrt{0.125+0.75D}=17.2\text{A}$ | $i_{L,pk}=33.7\text{A}$ |
| $D_1$/$D_2$ | $\dfrac{I_o}{2}=1.25\text{A}$ | $\dfrac{I_o}{2\sqrt{D}}=2.63\text{A}$ | $\dfrac{i_{L,pk}}{n}=6.7\text{A}$ |
| Boost 电感 $L$ | 29.9A | $\approx30\text{A}$ | 33.7A |
| 输出电容 $C$ | 0 | $I_o\sqrt{\dfrac{1-2D}{2D}}=3.9\text{A}$ | — |
| 输入电容 $C_{in}$ | 0 | $\dfrac{\Delta i_L}{2\sqrt3}=2.2\text{A}$ | — |

> **与推挽 Boost 的电流对比**（同案例）：

| | 全桥 Boost | 推挽 Boost |
|---|---|---|
| 开关管数量 | 4 | 2 |
| 每管 RMS | 17.2A | 18.6A |
| **管子总 RMS 平方和** | $4\times17.2^2=1183$ | $2\times18.6^2=692$ |

> 单看"每管 RMS"，两者接近；但**导通损耗是 4 管 vs 2 管**——全桥每管的 $R_{DS(on)}$ 可以更宽裕（选更便宜的管子），且**电流分散使热分布更好**。真正的差距在**电压应力**（80V vs 133V）与**软开关能力**。

### 10.2 器件损耗

$$P_{Q,cond}=4I_{Q,rms}^2R_{DS(on)}(T_j)$$
$$P_{Q,sw}\approx 4\times\frac{1}{2}V_{DS}i_{L,pk}(t_r+t_f)f_s\quad(\text{实际因接近 ZVS 而显著更低})$$
$$P_{Q,drive}=4Q_gV_{gs}f_s$$

**二极管**：

$$P_D=2\left(V_FI_{D,avg}+\tfrac12V_{RR}Q_{rr}f_s\right)$$

> $V_{RR}=800\text{V}$ → **必须 SiC 肖特基**（零反向恢复）。

## 十一、高频变压器设计

### 11.1 匝数比 $n$

**双重约束**：

$$n=\frac{2D_{max}V_o}{V_{g,min}}\quad\text{且}\quad n<\frac{V_o}{V_{g,max}}$$

**设计步骤**：

1. 由约束定上限： $n<\dfrac{V_o}{V_{g,max}}=\dfrac{400}{60}=6.67$
2. 取 **$n=5$**（留裕量，使 $\Delta_{min}$ 不至于过小）
3. 反算 $D$ 范围：
   $$D_{min}=\frac{nV_{g,min}}{2V_o}=\frac{5\times36}{800}=0.225\quad(\text{最低输入，升压最大})$$
   $$D_{max}=\frac{nV_{g,max}}{2V_o}=\frac{5\times60}{800}=0.375\quad(\text{最高输入})$$
4. 校验全通期： $\Delta\in[0.125,0.275]$ ✓ 都 >0

> **为什么取 $n=5$ 而不是 6**： $n=6$ 时 $D_{max}=0.45$ ，全通期仅剩 $\Delta=0.05$ ，裕量太薄。**$n$ 越大 → $V_{DS}$ 越低（好），但全通期越薄（坏）**——这是本拓扑的核心折中。

**匝数取整**： $n=5$ → $N_p=4$ 、 $N_s=20$ 。

### 11.2 磁芯与匝数

磁通只在**对角期**变化（全通期所有绕组 0V，磁通冻结）：

$$\Delta B=\frac{(V_o/n)\cdot D\cdot T_s}{N_pA_e}\quad\Rightarrow\quad\boxed{N_p\ge\frac{(V_o/n)\,D_{max}\,T_s}{\Delta BA_e}}$$

> **取 $D_{max}$ （最高输入）**——因为 $(V_o/n)\cdot D=\dfrac{V_g}{2}$ ，故伏秒积随 $V_g$ 增大；最高输入时最大。

本案例： $\dfrac{V_g}{2}T_s=\dfrac{60}{2}\times20\mu s=600\text{V}\cdot\mu s$

取 EE55（ $A_e=350\text{mm}^2$ ）、 $\Delta B=0.43\text{T}$ ：

$$N_p\ge\frac{600\times10^{-6}}{0.43\times350\times10^{-6}}=3.99\to\boxed{N_p=4\text{匝}},\qquad N_s=nN_p=\boxed{20\text{匝}}$$

### 11.3 励磁电感与绕组

$$i_{m,pk}=\frac{(V_o/n)\cdot D\cdot T_s}{L_m}$$

- 励磁电流峰值控制在反射负载电流的 10~20%
- **原边 RMS 电流大**（本案例单管 17.2A，但绕组电流是两腿之和）→ 原边用铜箔或多股并联
- 副边 20 匝、RMS 2.63A → 常规多股线即可
- **不需要气隙**（传能型变压器），但建议留极小气隙换偏磁容限

## 十二、Boost储能电感设计

> **Boost 家族没有"输出滤波电感"**——它的储能元件在**输入侧的 Boost 电感 $L$**。本节专门讨论 $L$ 的设计；输出侧只有电容（见下一节）。

### 12.1 电感量

**物理意义**： $L$ 决定输入电流纹波。电感只在**全通期**（ $v_L=V_g$ ，时长 $(1-2D)T_s$ ）充电。

$$\Delta i_L=\frac{V_g\,(1-2D)\,T_s}{L}$$

反解：

$$\boxed{L=\frac{V_{g,min}\,(1-2D_{min})\,T_s}{\Delta i_L}}$$

> **★ 取 $D_{min}$ （最低输入）**——$D$ 越小、全通期越长、纹波越大。这与 Buck 家族"取 $D_{min}$"的形式相同，但注意判据来自**全通期最长的工况**。

**设计取值**： $\Delta i_L=k\,I_L$ ， $k=20\%\sim40\%$ （工程经验范围）。

### 12.2 电流与磁芯

| 参数 | 公式 | 本案例 |
|---|---|---|
| 平均电流 | $I_L=\dfrac{P_o}{\eta V_g}$ | 29.9A（@36V） |
| 峰值电流 | $I_L+\dfrac{\Delta i_L}{2}$ | 33.7A |
| 有效值 | $\approx I_L$ | ≈30A |
| 储能 | $\tfrac12 L I_{pk}^2$ | 26.7mJ |

**磁芯选型要点**：

| 因素 | 说明 |
|---|---|
| 材质 | 低压大电流 → 优选**铁硅铝（Sendust）**或铁粉芯（软饱和特性好，故障时电感缓降而非骤降） |
| 尺寸依据 | 按**储能 $\tfrac12LI_{pk}^2$** 与 $I^2L$ 选择（不是按感量单一指标） |
| 饱和校验 | 额定直流偏置下感量跌落 ≤30% |
| 气隙 | 铁粉芯/铁硅铝为分布式气隙；若用铁氧体则必须开气隙（储能元件） |
| 绕组 | 大电流 → 铜箔或多股并联；集肤深度按 $f_s$ 校核 |

> **为什么 Boost 电感必须能"存住"全部输入功率的能量？** 与 Buck-Boost/反激同源——电感在每个周期的全通期储存能量、在对角期释放。因此 $L$ 的**储能密度**是选型核心，这也是它比 Buck 家族的输出电感体积大的原因。

### 12.3 CCM / DCM 边界

$$L>L_{crit}=\frac{V_g\,(1-2D)\,T_s}{2\,I_{L,min}}\cdot\frac{V_g}{V_o/n-V_g}\quad\text{（精确式需按能量平衡推导）}$$

> **工程简化判据**：只要**满载最低输入时 $I_{L,min}>0$**，即认为工作在 CCM。DCM 会让增益公式与电流应力全部改变，**升压拓扑通常强制设计在 CCM**（DCM 下开关管电流尖峰极大）。

## 十三、输出电容设计（无输出电感）

### 13.1 容值

电容在**全通期**单独供电，时长 $(1-2D)T_s$ ：

$$\boxed{C\ge\frac{I_o\,(1-2D_{min})T_s}{\Delta V_C}}$$

> **取 $D_{min}$**——全通期最长、放电最久、纹波最大。

本案例（ $\Delta V_C\le4\text{V}$ ， $D_{min}=0.225$ ）：

$$C\ge\frac{2.5\times(1-0.45)\times20\times10^{-6}}{4}=6.9\mu F\quad\Rightarrow\quad\text{取 }47\mu F/\mathbf{600V}$$

### 13.2 ESR 与电流

$$\Delta V_{ESR}\approx\frac{i_{L,pk}}{n}\cdot ESR=6.7\text{A}\times ESR\le2\text{V}\Rightarrow ESR\le300\text{m}\Omega\quad(\text{极易满足})$$

$$I_{C,rms}=3.9\text{A}\quad\Rightarrow\quad\text{纹波电流额定}\ge6\text{A}$$

> **与 Buck 家族相反的规律**：高压小电流输出 → **容值项是瓶颈，ESR 宽松**。

### 13.3 输入电容

$$C_{in}\ge\frac{\Delta i_L}{8f_s\Delta V_g}$$

本案例（ $\Delta i_L=7.5\text{A}$ ， $\Delta V_g\le0.5\text{V}$ ）： $C_{in}\ge37.5\mu F$ → 47µF/100V + MLCC。

## 十四、关键工程问题

### 13.1 四管全通——是正常状态，不是故障

**必须彻底理解这一点**（否则会误判）。

| | 全桥 **Buck** | 全桥 **Boost** |
|---|---|---|
| 同桥臂同时导通 | **故障**（短路 $V_g$ ） | **正常工作状态** |
| 原因 | 桥臂直接跨接在 $V_g$ 上 | 桥臂跨接在**电感输出**上，电感限流 |

> **但死区仍然需要**：在"对角期 → 全通期"的换流中必须**先开通后关断**（保证电流不断流）；而在任何**不该全通**的时刻（例如故障保护、启动），仍需避免意外全通。

### 13.2 换流与软开关

- **换流机理**：电流源驱动 + $C_{oss}$ 充放电 → 天然接近 **ZVS**
- **顺序要求**：**先开通后关断**（与全桥 Boost 的重叠换流一致），确保电感电流始终有低阻沟道路径
- **漏感能量**：经体二极管回馈 → 尖峰远小于推挽

### 13.3 偏磁

见 §八。对策：电流模式控制 / 隔直电容 / 桥臂对称设计。

### 13.4 启动冲击

**电流馈电拓扑的共同问题**：启动瞬间输出电容未充电， $V_o=0$ → 变压器副边短路 → 电感电流迅速上升到极大值。

**对策**：
1. 启动时先给输出电容**预充电**（或分级启动）
2. **软启动**（占空比缓慢建立）
3. 电感饱和电流留足裕量
4. 逐周期限流保护

### 13.5 PCB 布局

| 要求 | 原因 |
|---|---|
| 两条桥臂的**环路对称且最小** | 保证正负对角期寄生参数一致（防偏磁） |
| 四管驱动走线**等长等阻** | 保证互补 + 移相时序精确 |
| 电感紧靠上母线 | 缩短高 di/dt 回路 |
| 高边驱动用隔离驱动/自举 | 高边管源极浮动 |
| 变压器下方禁止走线 | 避免噪声耦合 |

### 13.6 EMI

主要噪声源：桥臂中点高 dv/dt、原边高 di/dt 回路、输出二极管反向恢复。对策与全桥 Buck 相同。

| 磁芯损耗 | Steinmetz | ≈6W |
| 其他（控制、ESR、吸收） | — | ≈2W |
| **合计** | | **≈40W（含 ZVS）** |
| **效率** | | **≈96.2%** |

### 14.2 效率优化优先级

1. **开关损耗**（最大项）→ 优化换流时序、实现完整 ZVS
2. **导通损耗** → 降低 $R_{DS(on)}$
3. **铜损** → 原边铜箔/多股、优化窗口
4. **磁芯损耗** → 低损材质

## 十八、优缺点与适用场景

### 17.1 优点

1. **开关管电压应力最低**（ $\frac{V_o}{n}$ ，是推挽 Boost 的一半）
2. **电流分散到 4 管**——每管的 $R_{DS(on)}$ 要求宽松、热分布好
3. **换流接近 ZVS**——电流源驱动 + $C_{oss}$ ，开关损耗低
4. **漏感能量有回馈通路**——尖峰小
5. **原边简单绕组**——绕制简单、漏感小
6. **输入电流连续**
7. **功率扩展性最好**——1kW~10kW+ 升压首选

### 17.2 缺点

1. **4 管 + 4 驱动**——成本与复杂度最高
2. **驱动时序最复杂**（互补 + 移相 + 全通窗口）
3. **副边二极管耐压高**（ $2V_o$ ，与推挽 Boost 相同）
4. **匝比受限**（ $n<V_o/V_{g,max}$ ）
5. **启动冲击严重**（电流馈电通病）
6. **必须解决偏磁**

### 17.3 适用场景结论

> **在"大功率（>1kW）隔离升压 + 高效率要求"的条件下，全桥 Boost 更合适**——它用 4 只管子换来最低的电压应力、最低的开关损耗（ZVS）与最好的电流分布。
>
> **在 200W~1kW 的中小功率升压场合，推挽 Boost 的"2 管搞定"往往更划算**——除非效率要求 >94%，那就必须上全桥。

## 二十、公式速查

### 19.1 占空比与传输比

| 参数 | 公式 |
|---|---|
| 全通占空比 | $\Delta=0.5-D$ |
| 电压传输比 | $V_o=\dfrac{nV_g}{2D}$ ， $D<0.5$ |
| 匝比约束 | $n<\dfrac{V_o}{V_{g,max}}$ ★ |
| 由 $V_g,V_o$ 反解 | $D=\dfrac{nV_g}{2V_o}$ |

### 19.2 电压应力

| 器件 | 公式 |
|---|---|
| MOSFET | $V_{DS}=\dfrac{V_o}{n}=\dfrac{V_g}{2D}$ |
| 整流二极管 | $V_{RR}=2V_o$ |

### 19.3 电流应力

| 器件 | 平均值 | 有效值 | 峰值 |
|---|---|---|---|
| Boost 电感 | $I_L=\dfrac{P_o}{\eta V_g}=\dfrac{nI_o}{2D}$ | $\approx I_L$ | $I_L+\tfrac{\Delta i_L}{2}$ |
| MOSFET（每只） | $I_L\dfrac{0.5+D}{2}$ | $I_L\sqrt{0.125+0.75D}$ | $i_{L,pk}$ |
| 整流二极管 | $\dfrac{I_o}{2}$ | $\dfrac{I_o}{2\sqrt{D}}$ | $\dfrac{i_{L,pk}}{n}$ |
| 输出电容 | 0 | $I_o\sqrt{\dfrac{1-2D}{2D}}$ | $\dfrac{i_{L,pk}}{n}-I_o$ |
| 输入电容 | 0 | $\dfrac{\Delta i_L}{2\sqrt3}$ | — |

### 19.4 磁元件与电容

| 参数 | 公式 |
|---|---|
| Boost 电感 | $L=\dfrac{V_{g,min}(1-2D_{min})T_s}{\Delta i_L}$ |
| 原边匝数 | $N_p\ge\dfrac{(V_o/n)D_{max}T_s}{\Delta BA_e}$ ← **取 $D_{max}$** |
| 副边匝数 | $N_s=nN_p$ |
| 励磁电流峰值 | $i_{m,pk}=\dfrac{(V_o/n)DT_s}{L_m}$ |
| **输出电容** | $C\ge\dfrac{I_o(1-2D_{min})T_s}{\Delta V_C}$ |
| 输入电容 | $C_{in}\ge\dfrac{\Delta i_L}{8f_s\Delta V_g}$ |

## 二十一、学习总结

### 20.1 一句话记住这个拓扑

> **全桥 Boost = 在电流馈电全桥的输入侧串一个 Boost 电感。四管全通时上母线被短路 → 电感充电；对角导通时电感电流经变压器送副边 → 输出。**
> 收益：开关管应力只有 $\frac{V_o}{n}$ 、可 ZVS、电流分散。
> 代价：4 管 4 驱动、启动冲击、偏磁。

### 20.2 五个必须刻在脑子里的数

| 数 | 值 | 来源 |
|---|---|---|
| 传输占空比 | $D<0.5$ | 必须保留全通期 |
| 全通占空比 | $\Delta=0.5-D$ | Boost 充电时间 |
| 电压传输比 | $\dfrac{nV_g}{2D}$ | 伏秒平衡 |
| **开关管电压应力** | $\mathbf{\dfrac{V_o}{n}}$ ★ | 桥臂直接跨接，无自耦叠加 |
| 副边二极管应力 | $2V_o$ | 中心抽头全波整流 |

### 20.3 三个"为什么"

**Q1：为什么"四管全通"在全桥 Boost 里是正常状态，而在全桥 Buck 里是故障？**
A：因为**桥臂跨接的对象不同**。全桥 Buck 的桥臂直接跨在 $V_g$ 母线上，同桥臂导通就是直接短路输入源 → 故障。全桥 Boost 的桥臂跨在**电感之后的上母线**上，同桥臂导通只是把上母线短路，而电流由**电感**限流——这恰恰是 Boost 想要的充电状态。

**Q2：为什么全桥 Boost 的开关管应力只有推挽 Boost 的一半？**
A：因为**变压器原边的结构不同**。全桥 Boost 的原边是**简单绕组**，跨在两个桥臂中点之间，每只管子直接跨接在"母线—中点"之间，关断时承受的就是上母线电压 $\frac{V_o}{n}$ 。推挽 Boost 的原边是**中心抽头绕组**，相当于一个 2:1 自耦变压器，关断管承受"中心抽头电压 + 另一半绕组感应电压" $=\frac{2V_o}{n}$ 。

**Q3：为什么匝比不能取大（虽然 $n$ 越大 $V_{DS}$ 越低）？**
A：因为 $D=\frac{nV_g}{2V_o}$ ， $n$ 越大则 $D$ 越大，而 Boost 要求 $D<0.5$ （必须保留全通期）。极限时 $n<\frac{V_o}{V_{g,max}}$ 。**输入范围越宽，可用的 $n$ 越小**——这与推挽 Boost 的约束完全一致，是所有电流馈电隔离升压拓扑的共同特征。

### 20.4 学完之后你应该能

- [ ] 看到"电感 + 全桥 + 简单原边变压器"立刻判断这是电流馈电全桥 Boost， $D<0.5$
- [ ] 画出 4 段时序图与 2 种状态的电流路径
- [ ] 独立完成伏秒平衡推导 $V_o=\frac{nV_g}{2D}$
- [ ] 说清"四管全通 = 正常充电状态"的道理
- [ ] 用 $I_L\sqrt{0.125+0.75D}$ （而非全桥 Buck 的公式）算管子 RMS
- [ ] 记得校验 $n<V_o/V_{g,max}$
- [ ] 从效率数据说明"为什么大功率升压要用全桥"
