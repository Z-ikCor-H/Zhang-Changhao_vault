# 全桥隔离型 Boost 变换器——拓扑、模态与选型分析

---

## 一、拓扑概述

### 1.1 拓扑名称

**全桥隔离型 Boost 变换器**（Full-Bridge Isolated Boost Converter），亦称 **电流馈电型全桥变换器**（Current-Fed Full-Bridge Converter）。

### 1.2 电路结构与宏观工作机理

| 环节 | 功能 |
|------|------|
| ① Boost 储能电感 $L$ | 串联在 $V_g$ 与全桥之间，开关周期内储能/释能，是升压的核心 |
| ② 全桥逆变（$Q_1$~$Q_4$）| 对角管交替导通，将电感电流切换为流过变压器原边的双极性交流 |
| ③ 高频变压器（1:n）| 电压变换 + 电气隔离；双极性对称励磁，磁芯自动复位 |
| ④ 全波整流（$D_1$、$D_2$）| 将双极性方波整流为单向脉动直流，每半周仅一个二极管导通 |
| ⑤ 输出电容 $C$ | 滤除高频分量 + 支撑输出电压（Boost 不需要输出电感）|

**控制逻辑**：采用**重叠导通**策略——对角管交替导通（$Q_1+Q_4$ ↔ $Q_2+Q_3$），每次换向前短暂**四管全通**（overlap），让 Boost 电感通过 MOS 管沟道（而非体二极管）续流充电。通过调节占空比 $D$ 控制升压比——**$D$ 越小，升压比越高**（反比关系，后详）。

### 1.3 优点

1. **天然升压**——输入电流连续、输出可实现高于输入的任意电压，适合电池/燃料电池→高压直流母线
2. **变压器匝比分担升压压力**——极端升压比不用全压在 Boost 电感上，$n$ 承担一部分
3. **开关管电压应力低**——MOS 管关断时承受的是反射输出电压 $V_O/n$，而非满 $V_O$；合理设计 $n$ 可将应力控制在低压等级
4. **输入电流纹波小**——Boost 电感在输入侧，天然平滑输入电流，EMI 友好
5. **磁芯双向利用**——双极性对称励磁，磁芯利用率高，自动复位

### 1.4 缺点

1. **启动冲击**——上电时输出电容电压为零，Boost 电感无反向电压箝位，需软启动或预充电
2. **换流控制要求高**——必须在换向前短暂四管全通（重叠导通），若重叠时间不足或过长均会导致效率下降或直通风险
3. **控制复杂度**——占空比与输出电压关系为反比（$V_O \propto 1/D$），不同于 Buck 型的正比关系
4. **轻载/空载失控**——Boost 拓扑在极轻载下输出电压会飙升，需 Burst Mode 或假负载
5. **变压器漏感影响大**——漏感在换流时与 Boost 电感相互作用，产生额外电压应力

### 1.5 适用场景

| 场景                 | 是否适合 | 原因                  |
| ------------------ | :--: | ------------------- |
| 燃料电池/光伏 → 高压直流母线   | ✅ 最佳 | 低压大电流输入 + 高压输出，升压比大 |
| 储能电池 → 逆变器 DC-Link |  ✅   | 48V→380V 典型场景       |
| 电动汽车车载充电机前级        |  ✅   | 宽输入范围 + 隔离 + 升压     |
| 低压→低压              |  △   | 非隔离 Boost 更简单       |

## 二、高频开关周期模态分析

采用**重叠导通控制**——对角管交替导通，换向前短暂四管全通，确保电感电流始终有低阻抗路径。一个完整开关周期 $T_s$ 分为 4 个阶段。

**时序定义**（参考下图）：

```
Q1, Q4:  ████████████▌                  ████████████▌
Q2, Q3:           ▄▄▄▄▄▄▄▄▌████████████▌▄▄▄▄▄▄▄▄
                  ↑                    ↑
              重叠(全通)            重叠(全通)
              ← ΔTs →              ← ΔTs →
         |← DTs →|← ΔTs →|← DTs →|← ΔTs →|
         模态2           模态3    模态4    模态1
       (Q1+Q4+D1)      (全通)  (Q2+Q3+D2) (全通)
```

- 每组对角管导通时间 = $DT_s$（能量传输阶段）
- 每次重叠时间 = $\Delta T_s$（Boost 充电阶段）
- 约束：$2D + 2\Delta = 1$，即 $D + \Delta = 0.5$，$D < 0.5$
- **$D$ 越小 → $\Delta$ 越大 → 充电时间越长 → 升压比越高**

> **注意**：这里的 $D$ 是每组对角管的导通占空比（$t_{on}/T_s$），与 Buck 型全桥的有效占空比 $D_{eff}=2t_{on}/T_s$ 含义不同。

---

### 2.1 模态 1：四管全通（Boost 充电）——$[t_0, t_1]$

**(1) 开关管状态**
- $Q_1$、$Q_2$、$Q_3$、$Q_4$ **全部导通**（重叠阶段）

**(2) 变压器原边**
- 四个 MOS 管沟道将全桥的两个桥臂中点均短路到地（或均拉到 $V_{top}$——取决于具体导通路径），等效于变压器原边两端被全桥短路
- $v_T = 0$（原边两端无电位差）

> **电流路径**：$V_g(+) \to L \to$（$Q_1$ // $Q_3$ 分流）→ 地 $\to V_g(-)$。电感电流经 MOS 管沟道直接回流，**不经过变压器原边**。
>
> 另一视角：电感电流从 $V_{top}$ 分两路——一路经 $Q_1 \to Q_2$ 体二极管到地，一路经 $Q_3 \to Q_4$ 体二极管到地。等效为变压器原边被低阻抗短路。

- $L_M$ 两端电压 = 0 → $i_M$ **保持不变**
- 磁通 $\phi$ **不变**

**(3) 副边二极管**
- $v_T = 0$，副边无感应电压
- $D_1$、$D_2$ 均 **截止**（$V_O > 0$）
- 输出电容 $C$ 单独向负载供能

**(4) 电流变化**

| 电流 | 趋势 | 说明 |
|------|------|------|
| $i$（电感电流）| **线性上升** | $\frac{di}{dt} = \frac{V_g}{L} > 0$，**Boost 电感储能** |
| $i_M$ | 不变 | $v_T = 0$，励磁电流无变化 |
| $i_{D1}$、$i_{D2}$ | $0$ | 均截止 |
| $i_O$（输出）| 电容放电 | 输出电容向负载供能 |

**(5) 电压**
- $v_T = 0$
- $v_S = 0$
- $v_L = V_g > 0$（**电感充电**，$i$ 上升）
- $V_O$ 由输出电容维持

---

### 2.2 模态 2：$Q_1+Q_4$ 导通 + $D_1$ 导通（正半周能量传输）——$[t_1, t_2]$

**(1) 开关管状态**
- $Q_1$、$Q_4$ **导通**（对角管），$Q_2$、$Q_3$ **关断**

**(2) 变压器原边**
- $Q_1$ 将左桥臂中点拉到 $V_{top}$，$Q_4$ 将右桥臂中点拉到地
- $v_T = V_{top} = V_O/n$（副边反射输出电压箝位）

> **电流路径**：$V_g(+) \to L \to Q_1$（漏→源）$\to$ 变压器原边（上→下）$\to Q_4$（漏→源）$\to V_g(-)$。**电感电流流经变压器原边，能量耦合到副边输出。**

- $L_M$ **正向励磁**：$\frac{di_M}{dt} = \frac{V_O/n}{L_M}$，$i_M$ 正向线性增大
- 磁通 $\phi$ **正向增大**

**(3) 副边二极管**
- 原边上端打点端为正 → 副边上绕组打点端（上端）为正
- $D_1$：阳极接打点端（正电位）→ **导通**
- $D_2$：阳极接非打点端（负电位）→ **截止**，反向电压 ≈ $2V_O$

**(4) 电流变化**

| 电流 | 趋势 | 说明 |
|------|------|------|
| $i$（电感电流）| **线性下降** | $\frac{di}{dt} = \frac{V_g - V_O/n}{L} < 0$（$V_O/n > V_g$）|
| $i_M$ | 正向线性增大 | 励磁 |
| $i_{D1}$ | 跟随 $i$ | $i_{D1} = n \cdot i$ |
| $i_{D2}$ | $0$ | 截止 |

**(5) 电压**
- $v_T = +V_O/n$
- $v_S = V_O$（上正下负）
- $v_L = V_g - V_O/n < 0$（**电感释能**，向负载传输）
- $V_O \approx$ 恒定

---

### 2.3 模态 3：四管全通（Boost 充电）——$[t_2, t_3]$

与模态 1 完全相同。四管全通 → $v_T = 0$ → $v_L = V_g$ → 电感储能，$i$ 上升。$D_1$、$D_2$ 均截止，输出电容单独供能。

> **换流过程**：从模态 2 的 $Q_1+Q_4$ 导通过渡到模态 4 的 $Q_2+Q_3$ 导通。先开通 $Q_2$、$Q_3$（此时 $Q_1$、$Q_4$ 仍导通 → 四管全通），再关断 $Q_1$、$Q_4$。电感电流始终有低阻抗 MOS 沟道路径，**无断流、无漏感尖峰**。

---

### 2.4 模态 4：$Q_2+Q_3$ 导通 + $D_2$ 导通（负半周能量传输）——$[t_3, t_4]$

与模态 2 对称，变压器原边电压极性反转。

**(1) 开关管状态**
- $Q_2$、$Q_3$ **导通**，$Q_1$、$Q_4$ **关断**

**(2) 变压器原边**
- $Q_3$ 将右桥臂中点拉到 $V_{top}$，$Q_2$ 将左桥臂中点拉到地
- $v_T = -V_{top} = -V_O/n$（原边上端 −，下端 +）

> **电流路径**：$V_g(+) \to L \to Q_3$（漏→源）$\to$ 变压器原边（下→上）$\to Q_2$（漏→源）$\to V_g(-)$。电流反向流过原边，磁通反向复位。

- $L_M$ **反向励磁**：$\frac{di_M}{dt} = -\frac{V_O/n}{L_M}$，$i_M$ 负向线性增大
- 磁通 $\phi$ **反向增大**（双极性对称，自动复位）

**(3) 副边二极管**
- $D_2$ **导通**（下绕组底端为正），$D_1$ **截止**

**(4) 电流变化**——同模态 2，$i$ 线性下降，能量传输到负载。

**(5) 电压**
- $v_T = -V_O/n$
- $v_S = V_O$（全波整流，输出极性不变）
- $v_L = V_g - V_O/n < 0$

---

### 2.5 关键波形汇总（一个周期）

```
         模态1     模态2     模态3     模态4
        四管全通  Q1+Q4+D1  四管全通  Q2+Q3+D2
          ΔTs       DTs       ΔTs       DTs
         充电      传能      充电      传能
vT:       0      +Vo/n       0      -Vo/n
vS:       0        Vo        0        Vo
vL:      +Vg    Vg-Vo/n    +Vg     Vg-Vo/n
 i:      上升      下降      上升      下降
 iM:     持平      正增      持平      负增
```

**重叠导通 vs 死区续流（为什么工程上选重叠导通）**：

| 维度 | 死区续流（体二极管）| **重叠导通（MOS 沟道）** |
|------|:---:|:---:|
| 电感充电路径 | 体二极管（$V_F \approx 0.7\sim1.5\text{V}$）| MOS 沟道（$R_{DS(on)} \times I$）|
| 导通损耗 | 高（$P = V_F \cdot I$）| **低**（$P = I^2 R_{DS(on)}$）|
| 漏感尖峰 | **有**（换流时断流 → $L_{lk}\cdot di/dt$）| **无**（电流路径连续）|
| 是否需要钳位电路 | 需要 RCD/有源钳位 | **不需要** |
| EMI | 差 | **好** |
| 控制复杂度 | 简单（固定死区）| 略高（动态重叠时间）|

### 2.6 磁通双向平衡原理

- 模态 2：磁通正向增长 $\Delta\Phi_2 \propto (V_O/n) \cdot DT_s$
- 模态 4：磁通反向增长 $\Delta\Phi_4 \propto (V_O/n) \cdot DT_s$（大小相等、方向相反）
- 模态 1/3（全通）：$v_T = 0$，磁通不变
- 一个完整周期净磁通变化为零 → 磁芯在 I/III 象限对称工作
- **对称性由 $v_T = \pm V_O/n$ 自动保证**，不依赖占空比对称

## 三、输入-输出电压关系推导

**方法**：电感 $L$ 伏秒平衡（一个完整开关周期内）。

模态 2 或 4（对角导通，合计 $2DT_s$）：$v_L = V_g - \dfrac{V_O}{n}$

模态 1 或 3（四管全通重叠，合计 $(1-2D)T_s$）：$v_L = V_g$

$$(V_g - \frac{V_O}{n}) \cdot 2DT_s + V_g \cdot (1-2D)T_s = 0$$

$$2D V_g - 2D \frac{V_O}{n} + V_g - 2D V_g = 0$$

$$V_g = 2D \frac{V_O}{n}$$

$$\boxed{V_O = \frac{n V_g}{2D}}$$

| 符号 | 含义 | 范围 |
|------|------|------|
| $V_g$ | 直流输入电压 | — |
| $n$ | 变压器匝比（副边/原边），$n > 1$ 实现升压 | — |
| $D$ | 对角管导通占空比（$t_{on}/T_s$）| $0 < D < 0.5$ |
| $1-2D$ | 四管全通总占空比（Boost 充电）| $0 < 1-2D < 1$ |
| $V_O$ | 输出电压 | $V_O \geq nV_g$（升压）|

### 升压的两层来源

$$V_O = \underbrace{n}_{\text{变压器升压}} \cdot \underbrace{\frac{1}{2D}}_{\text{Boost 升压}} \cdot V_g$$

- **第一层（变压器匝比 $n$）**：若 $n=3$，则 $V_O$ 至少是 $V_g$ 的 3 倍
- **第二层（Boost 因子 $1/(2D)$）**：$D < 0.5$ → $1/(2D) > 1$。$D=0.3$ 时因子 = 1.67，$D=0.2$ 时因子 = 2.5
- 两层合起来：$n=3$、$D=0.3$ → $V_O = 3 \times 1.67 \times V_g = 5V_g$

### 与 Buck 型全桥的关键对比

| 对比 | Buck 型全桥 | Boost 型全桥 |
|------|:---:|:---:|
| $V_O$ 公式 | $V_O = n D_{eff} V_{in}$ | $V_O = \dfrac{n V_g}{2D}$ |
| $V_O$ 与 $D$ 关系 | **正比**（$D \uparrow \Rightarrow V_O \uparrow$）| **反比**（$D \uparrow \Rightarrow V_O \downarrow$）|
| $D$ 范围 | $0 < D_{eff} < 1$ | $0 < D < 0.5$ |
| $V_O$ 范围 | $0 \sim nV_{in}$ | $nV_g \sim \infty$（理论）|
| 控制逻辑 | 增大 $D$ → 升压 | **减小 $D$ → 升压** |

> **控制直觉差异**：Buck 型全桥想升压就加大 $D$；Boost 型全桥想升压反而要**减小 $D$**（让重叠全通时间更长 = Boost 充电时间更长）。这是两者最反直觉的区别。

## 四、专题深入：Boost 型全桥的关键问题

### 4.1 "升压"的两层来源详解

非隔离 Boost 的 $V_O = V_g/(1-D_{boost})$，升压全靠占空比。全桥隔离 Boost 把升压任务拆成两块：

$$V_O = n \cdot \frac{1}{2D} \cdot V_g$$

| 设计策略 | 匝比 $n$ | Boost 因子 $1/(2D)$ | MOS 管电压应力 |
|----------|:------:|:------:|:------:|
| 变压器多承担 | 大（如 $n=6$）| 小（$D$ 接近 0.5）| $V_O/n$ 小 → MOS 应力低 |
| Boost 电感多承担 | 小（如 $n=2$）| 大（$D$ 远小于 0.5）| $V_O/n$ 大 → MOS 应力高 |

**工程设计折中**：$n$ 不是越大越好——$n$ 大意味着副边匝数多 → 变压器体积大、漏感大、二极管电压应力高。通常让 $n$ 承担 60%~70% 的升压比，剩下的由 Boost 因子补齐。

### 4.2 为什么必须用重叠导通（而非死区续流）

曾经有一种思路是用"死区"（四管全关、体二极管续流）来做 Boost 充电阶段。这种方案虽然在教科书理想分析中成立，但工程上几乎不可行：

**死区续流的致命问题——漏感尖峰**：

- 从对角导通切换到全关时，电感电流被迫从 MOS 沟道切换到体二极管路径
- 变压器漏感 $L_{lk}$ 阻碍电流路径切换 → 储存在漏感中的能量 $\frac{1}{2}L_{lk}I^2$ 无处释放
- 在 MOS 管漏源两端产生高压尖峰，幅度可达 $V_O/n$ 的 2~3 倍
- 需要额外的 RCD 吸收电路或有源钳位来抑制，增加成本 + 损耗

**重叠导通如何解决**：

```
死区方案：Q1+Q4 ON → [全关,体二极管续流] → Q2+Q3 ON
          ↑ 电流断流 → 漏感尖峰！

重叠方案：Q1+Q4 ON → [Q2+Q3也开通→四管全通] → Q1+Q4关断 → Q2+Q3 ON  
          ↑ 电流路径始终连续（MOS沟道），无断流！
```

| 对比 | 死区续流 | 重叠导通 |
|------|:---:|:---:|
| 电感充电路径 | 体二极管（$V_F \approx 0.7\sim1.5\text{V}$）| MOS 沟道（$I^2 R_{DS(on)}$）|
| 漏感尖峰 | **有**（换流断流）| **无**（电流连续）|
| 额外钳位电路 | 需要 | **不需要** |
| 导通损耗 | 高 | 低 |
| 控制 | 简单固定死区 | 需动态调整重叠时间 |

**结论**：重叠导通是电流馈电型全桥的**标准工程方案**——用短暂的四管全通换取无尖峰、低损耗的可靠换流。这也是为什么实际产品中看不到"死区续流"型 Boost 全桥的原因。

### 4.3 偏磁分析

与 Buck 型全桥类似，Boost 型全桥的变压器也是双极性对称励磁。但由于 $v_T = \pm V_O/n$ 直接由输出电压反射箝位（而非由输入电压决定），正负半周的伏秒积天然对称——**只要 $V_O$ 稳定，偏磁风险低于推挽**。

潜在偏磁来源：$Q_1$+$Q_4$ 和 $Q_2$+$Q_3$ 的导通压降不对称 → $v_T$ 正负半周幅值略有差异。抑制方案同 Buck 型全桥：串联隔直电容或电流模式控制。

### 4.4 启动问题

上电瞬间 $V_O = 0$，$v_T = V_O/n = 0$ → 电感两端始终 $v_L = V_g$ → 电感电流持续上升无限制。

**必须的启动措施**：
- **软启动**：DSP/MCU 从极小 $D$（≈0.05）逐渐增大，让 $V_O$ 缓慢建立
- **预充电**：通过辅助电路先给输出电容充电到 $nV_g$ 以上
- **打嗝模式**：检测到过流后关闭驱动，间歇重试

### 4.5 同侧桥臂直通——与"有意重叠"的区别

需要严格区分两个概念：

| | **重叠导通（Overlap）** | **同侧直通（Shoot-Through）** |
|------|:---:|:---:|
| 谁导通 | 四个管子**全部**导通 | 同侧上下管（$Q_1$+$Q_2$ 或 $Q_3$+$Q_4$）导通 |
| 电流路径 | 电感电流经全桥分流到地，路径受控 | $V_g$ 通过两管直接短路到地，**无电感限流** |
| 后果 | 正常的 Boost 充电阶段 | **灾难性**——$di/dt = V_g/L_{stray}$，纳秒级过流 |
| 是否允许 | ✅ 有意为之，时序精确控制 | ❌ 必须杜绝 |

> **注意**：重叠导通中四个管子全通，包含"左桥臂上下管同时导通"——但这与意外直通有本质区别。重叠导通时电流受 Boost 电感 $L$ 限制（$di/dt = V_g/L$），且持续时间 $\Delta T_s$ 极短（通常 < 1µs）；而意外直通时没有电感限流，$di/dt$ 仅受寄生电感限制（纳秒级炸管）。

**规避同侧直通的方案**：
- 硬件死区插入（驱动芯片 Adaptive Deadtime），确保同侧上下管不会因传播延迟差异而同时导通
- MCU/DSP 互补 PWM 模块自动管理
- **注意**：死区只针对**同侧桥臂**，四管全通（交叉桥臂）是通过提前开通实现的，不依赖死区
- 过流保护（逐周期 Cycle-by-Cycle）作为最后防线

## 五、元件选型依据与计算

> **▎为什么选这个场景？**
>
> 以下选用 **储能电池→逆变器直流母线** 作为设计场景，这是全桥隔离 Boost 最典型的落地应用：
>
> - **48V 输入**是锂电池组/燃料电池堆的常见电压等级，范围 36~60V；
> - **200V 输出**是单相逆变器的典型 DC-Link 电压（220V AC 整流后约 310V，此例取中间母线）；
> - **1kW** 是家用储能/小型光伏系统的典型功率；
> - 总升压比 $200/36 \approx 5.6\times$（最恶劣），单靠非隔离 Boost 需要 $D \approx 0.82$，效率极差——隔离 Boost 用匝比分担后 $D$ 仅 0.27~0.45，从容得多；
> - **全桥结构**在 1kW 级别提供了最佳的开关管电压应力（仅 ~67V）和变压器利用率。
>
> 所有公式保留符号形式，可直接代入其他设计指标复用。

### 5.1 设计指标

| 参数 | 符号 | 示例值 |
|------|------|--------|
| 输入电压 | $V_g$ | 48V（范围 36~60V）|
| 输出电压 | $V_O$ | 200V |
| 额定输出功率 | $P_O$ | 1kW |
| 开关频率 | $f_s$ | 50kHz |
| 最大占空比 | $D_{max}$ | 0.45 |
| 效率目标 | $\eta$ | ≥ 93% |

### 5.2 公式速查卡

| 元件 | 核心公式 | 关键决定因素 |
|------|----------|-------------|
| Boost 电感 | $L = \dfrac{V_{g,max} \cdot (1-2D_{min})}{2 f_s \cdot \Delta i_L}$ | 最大重叠时长（$D_{min}$ 工况，重叠最长）|
| MOS 管 | $V_{DSS} \geq 1.5 \cdot V_O/n$ | **反射输出电压决定，而非 $V_O$** |
| 变压器匝比 | $n = \dfrac{2D_{max} \cdot V_O}{V_{g,max}}$ | 最高输入 + 最大占空比 |
| 整流二极管 | $V_{RRM} \geq 2 \cdot V_O \times 1.5$ | **承受 $2V_O$**（全波中心抽头结构）|
| 输出电容 | $C \geq \dfrac{I_O \cdot (1-2D_{min})}{2 f_s \cdot \Delta V_O}$ | 重叠期间单独供电的电荷量 |

---

### 5.3 变压器匝比 $n$

> **功率流位置**：全桥逆变之后，整流之前——电压变换 + 隔离的核心。

设计逻辑：在最高输入电压（最不需要升压的工况）下，$D$ 取最大值 → 确定匝比 $n$。

$$V_O = \frac{n V_{g,max}}{2D_{max}} \quad\Rightarrow\quad n = \frac{2D_{max} \cdot V_O}{V_{g,max}} = \frac{2 \times 0.45 \times 200}{60} = 3.0$$

取 **$n = 3$**（原边 : 副边 = 1 : 3）。

校验最低输入时的占空比：

$$D_{min} = \frac{n V_{g,min}}{2V_O} = \frac{3 \times 36}{2 \times 200} = 0.27$$

$D$ 范围 0.27~0.45，在 (0, 0.5) 内且不接近边界，合理。

> **对比 Buck 型全桥**（同是 48V→200V 场景）：Buck 型 $n = V_O/(D_{max}V_{in,min}) = 200/(0.8\times36) \approx 7$，匝比是 Boost 型的 2.3 倍。Boost 型靠 $1/(2D)$ 因子分担了升压比，匝比需求更低。

---

### 5.4 Boost 储能电感 $L$

> **功率流位置**：输入源之后、全桥之前——**这是与 Buck 型全桥最本质的结构差异**。

#### 电感量计算

CCM 模式下，设定电流纹波率 $\Delta i_L \leq 25\% \cdot I_{L,avg}$：

$$I_{L,avg} = \frac{P_O}{\eta \cdot V_{g,min}} = \frac{1000}{0.93 \times 36} \approx 29.9\text{A}$$

$$\Delta i_L = 0.25 \times 29.9 \approx 7.5\text{A}$$

在全通重叠（模态 1/3）期间，$v_L = V_g$，电感充电。**最恶劣工况为 $D_{min}$**（对角导通时间最短，重叠时间最长）：

重叠总时长 $= (1-2D_{min})T_s$，单次重叠时长 $= (1-2D_{min})T_s/2$：

$$L = \frac{V_{g,max} \cdot (1-2D_{min}) \cdot T_s / 2}{\Delta i_L} = \frac{V_{g,max} \cdot (1-2D_{min})}{2 f_s \cdot \Delta i_L}$$

代入：$V_{g,max} = 60\text{V}$，$D_{min} = 0.27$，$f_s = 50\text{kHz}$，$\Delta i_L = 7.5\text{A}$

$$L = \frac{60 \times (1 - 0.54)}{2 \times 5\times10^4 \times 7.5} = \frac{60 \times 0.46}{7.5 \times 10^5} \approx 36.8\mu\text{H}$$

取标称值 **$L = 40\mu\text{H}$**。

#### 磁芯与绕组

| 参数 | 值 |
|------|-----|
| 电感量 | $40\mu\text{H}$ |
| 平均电流 | $I_{L,avg} = 29.9\text{A}$ |
| 峰值电流 | $I_{L,pk} = I_{L,avg} + \Delta i_L/2 \approx 33.7\text{A}$ |
| 推荐磁芯 | 铁硅铝（Sendust），如 2×KS157-060A 叠用 |
| 储能校验 | $E = \frac{1}{2}LI_{pk}^2 = \frac{1}{2} \times 4\times10^{-5} \times 33.7^2 \approx 22.7\text{mJ}$ |

> 储能 22.7mJ 远大于 Buck 型全桥的输出电感（~5mJ）——Boost 电感的储能负担更重。

---

### 5.5 功率 MOS 管（$Q_1 \sim Q_4$）

> **功率流位置**：Boost 电感之后，变压器原边——全桥逆变桥臂。

#### 电压应力

每个 MOS 管关断时承受 $V_{top}$（全桥上端电压）。在全通重叠期间 $V_{top} \approx 0$（桥臂短路到地），在对角导通期间 $V_{top} = V_O/n$：

$$V_{DS,max} = V_O / n = 200 / 3 \approx 66.7\text{V}$$

计入 **1.5 倍安全裕量**（考虑漏感尖峰）：

$$V_{DSS,rated} \geq 1.5 \times 66.7 \approx 100\text{V} \quad\Rightarrow\quad \text{选 150V 等级}$$

> **对比 Buck 型全桥**（同是 48V 输入）：Buck 型 MOS 管耐压 = $V_{in,max} = 60\text{V}$。Boost 型的 MOS 管耐压由**反射输出电压**决定（67V），略高于 Buck 型但仍属低压等级——这就是全桥结构的优势。

#### 电流应力

电感平均电流即为流入全桥的电流。每只 MOS 管在对角导通期间（$DT_s$）流过全部电感电流：

$$I_{DS,rms} = I_{L,avg} \cdot \sqrt{D_{max}} = 29.9 \times \sqrt{0.45} \approx 20.1\text{A}$$

峰值电流（含纹波）：

$$I_{DS,peak} = I_{L,pk} \approx 33.7\text{A}$$

#### 选型汇总

| 参数 | 计算值 | 选型要求 |
|------|--------|----------|
| $V_{DSS}$ | 66.7V（理论）| ≥ 150V（漏感尖峰裕量）|
| $I_D$（连续）| ~20A RMS | ≥ 50A @ $T_c=100^\circ\text{C}$ |
| $I_{D,pulse}$ | ~34A | ≥ 100A |
| $R_{DS(on)}$ | — | ≤ 5mΩ（控制导通损耗）|
| $Q_g$ | — | ≤ 50nC（50kHz 下驱动损耗可接受）|

**推荐**：Infineon **IRFP4368**（$V_{DSS}=150\text{V}$，$R_{DS(on)}=1.85\text{m}\Omega$，$I_D=93\text{A}$）或同等级器件。

---

### 5.6 副边整流二极管（$D_1$、$D_2$）

> **功率流位置**：变压器副边之后，输出电容之前——全波整流。

#### 电压应力

全波整流中心抽头结构，二极管承受反向电压：

$$V_{RRM} \geq 2 \cdot n \cdot V_{top,max} = 2 \cdot n \cdot (V_O/n) = 2V_O = 400\text{V}$$

计入 **1.5 倍安全裕量**（考虑漏感振荡）：

$$V_{RRM,rated} \geq 600\text{V}$$

#### 电流应力

输出电流：$I_O = P_O / V_O = 1000 / 200 = 5\text{A}$

每只二极管仅在半个周期导通（对应对角管导通期间）：

$$I_{D,avg} = I_O \cdot D_{max} = 5 \times 0.45 \approx 2.25\text{A}$$

峰值电流（副边反射）：

$$I_{D,peak} = n \cdot I_{L,pk} = 3 \times 33.7 \approx 101\text{A}$$

> 峰值电流很大（100A+）但持续时间极短（$DT_s \approx 9\mu\text{s}$），选型时关注 $I_{FSM}$（浪涌电流）而非 $I_{F,avg}$。

#### 选型汇总

| 参数 | 计算值 | 选型要求 |
|------|--------|----------|
| $V_{RRM}$ | 400V（理论）| ≥ **600V** |
| $I_{F,avg}$ | ~2.3A | ≥ 5A |
| $I_{FSM}$ | — | ≥ 150A（高浪涌）|
| $t_{rr}$ | — | **零反向恢复优先**（SiC，高压高频）|

**推荐类型**：**SiC 肖特基二极管**（600V/650V 等级，零 $t_{rr}$，$V_F$ 低）。如 CREE/Wolfspeed **C3D06065A**（650V/6A）或同等器件。

> $V_O=200\text{V}$ 时二极管承受 $2V_O=400\text{V}$，选 600V 等级。这是 Boost 型全桥的一个重要特征——**副边二极管电压应力 = $2V_O$**，比 Buck 型全桥（$2nV_{in}$）高得多。高压输出场景下，SiC 二极管几乎是必选。

---

### 5.7 输出滤波电容 $C$

> **功率流位置**：整流之后，负载之前——Boost 型全桥**没有输出电感**，电容直接面对整流脉冲。

#### 电容量计算

全通重叠期间（电感不向输出传输能量），输出电容单独向负载供电。单次重叠时长 $= (1-2D)T_s/2$，最恶劣为 $D=D_{min}$：

$$C_{min} = \frac{I_O \cdot (1-2D_{min}) \cdot T_s / 2}{\Delta V_O}$$

输出电压纹波 $\Delta V_O \leq 1\% \cdot V_O = 2\text{V}$：

$$C_{min} = \frac{5 \times (1 - 0.54) / (2 \times 5\times10^4)}{2} = \frac{5 \times 0.46 / 10^5}{2} \approx 11.5\mu\text{F}$$

#### ESR 约束

ESR 引起的纹波远大于容性纹波（Boost 输出电容直接承受脉冲充电电流）：

$$R_{ESR} \leq \frac{\Delta V_O}{I_{D,peak}} = \frac{2}{101} \approx 20\text{m}\Omega$$

计入降额和频率特性，取 **ESR ≤ 10mΩ**。

#### 方案

| 方案 | 配置 | ESR |
|------|------|-----|
| 电解并联 | 3 × 100µF/250V 高频低阻型 | ~30mΩ |
| 混合 | 2 × 100µF/250V 电解 + 1 × 4.7µF/400V 薄膜 | < 15mΩ |

> 高压输出电容（250V+）的 ESR 天然比低压电容高，这是 Boost 型全桥的痛点之一。取 3 倍计算裕量：**$C \geq 47\mu\text{F}/250\text{V}$ × 3 并联**。

---

### 5.8 输入滤波电容 $C_{in}$

> **功率流位置**：输入源两端，平滑 Boost 电感汲取的脉动电流。

Boost 电感本身提供了一定的输入电流平滑。输入电容主要滤除高频开关纹波：

$$C_{in} \geq \frac{\Delta i_L}{8 f_s \cdot \Delta V_{in}} = \frac{7.5}{8 \times 5\times10^4 \times 0.5} \approx 37.5\mu\text{F}$$

输入电压纹波 ≤ 1%·$V_g$ = 0.5V。方案：**3 × 47µF/100V 电解并联** + 1 × 1µF MLCC（高频去耦）。

---

| 位置 | 元件 | 关键参数 | 推荐规格 | 数量 |
|------|------|----------|----------|------|
| 输入 | Boost 电感 $L$ | 40µH / 34A 饱和 | 2×KS157-060A 铁硅铝 | 1 |
| 输入 | 电容 $C_{in}$ | ≥38µF / 100V | 3×47µF 电解 + 1µF MLCC | 4 |

## 六、拓扑对比

### 6.1 Boost 型全桥 vs Buck 型全桥

| 维度 | Buck 型全桥 | Boost 型全桥 |
|------|:---:|:---:|
| 电感位置 | 副边输出侧 | **原边输入侧** |
| 电压关系 | $V_O = nDV_{in}$（降压）| $V_O = nV_g/(2D)$（升压）|
| MOS 管电压应力 | $V_{in}$ | $V_O/n$ |
| 二极管电压应力 | $2nV_{in}$ | $2V_O$ |
| 输出滤波 | LC | **仅 C** |
| 输入电流 | 脉动（需输入电容）| **连续**（Boost 电感平滑）|
| 启动 | 正常（输出从 0 开始）| **需软启动**（否则电感电流失控）|
| 适合方向 | 降压 | **升压** |

### 6.2 Boost 型全桥 vs 非隔离 Boost

| 维度 | 非隔离 Boost | Boost 型全桥 |
|------|:---:|:---:|
| $V_O$ 公式 | $V_O = V_g/(1-D)$ | $V_O = nV_g/(2D)$ |
| 高升压比实现 | 靠极端 $D$（如 48→400V 需 $D=0.88$）| 匝比分担，$D$ 从容 |
| 隔离 | 无 | **有**（安全、可级联）|
| 开关管电压应力 | $V_O$（高压）| $V_O/n$（**低压**）|
| 开关管数量 | 1 | 4 |
| 适合场景 | 低压→低压（如 12→24V）| 低压→高压（如 48→400V）|

### 6.3 五类隔离拓扑的升压/降压适配总结

| 拓扑 | 电压传输比 | 升降压 | $V_O$ vs $D$ | 典型场景 |
|------|----------|:---:|:---:|------|
| **Boost 型全桥** | $V_O = \dfrac{nV_g}{2D}$ | ⬆ 升压 | 反比 | 电池→直流母线 |
| Buck 型全桥 | $V_O = nDV_{in}$ | ⬇ 降压 | 正比 | 通信电源 |
| 推挽（Buck 型）| $V = 2nDV_g$ | ⬇ 降压 | 正比 | 低压大电流 DC-DC |
| 半桥（Buck 型）| $V_O = \dfrac{nDV_{in}}{2}$ | ⬇ 降压 | 正比 | 中压中功率 |
| 反激 | $V_O = nV_g \cdot \dfrac{D}{1-D}$ | ⬆⬇ 均可 | 正比 | 小功率多路输出 |

## 七、快速小结

| 项目 | 结论 |
|------|------|
| 拓扑名称 | 全桥隔离型 Boost 变换器（电流馈电型全桥） |
| 电路本质 | Boost 电感 + 全桥逆变 + 变压器隔离 + 全波整流 + C 滤波 |
| 家族归属 | **Boost 家族**（电感在桥前，升压型）|
| 模态数 | 4 个/周期（2 四管全通重叠 + 2 对角导通）|
| 核心公式 | $V_O = \dfrac{nV_g}{2D}$（**反比关系**：$D \downarrow \Rightarrow V_O \uparrow$）|
| 升压来源 | **两层**：变压器匝比 $n$ + Boost 因子 $1/(2D)$ |
| 重叠/全通角色 | **Boost 充电阶段**（$v_L = V_g$，电感储能）— 与 Buck 型相反 |
| MOS 管电压应力 | $V_O/n \approx 67\text{V}$（反射输出电压，低压等级）|
| 二极管电压应力 | $2V_O = 400\text{V}$（**需要 SiC**）|
| 变压器匝比 | $n = 3$（1:3 升压）|
| Boost 电感 | $40\mu\text{H}$ / 34A 铁硅铝 |
| 输出电容 | ≥47µF / 250V 低 ESR |
| 头号工程挑战 | **启动冲击**（需软启动） + **重叠时间动态调节**|
| 最佳场景 | 低压大电流输入 → 高压输出（电池/燃料电池 → 逆变器直流母线）|
