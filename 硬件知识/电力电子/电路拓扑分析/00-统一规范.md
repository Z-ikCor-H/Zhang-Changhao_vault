## 一、符号约定表（全文强制统一）

### 1.1 通用电气量

| 符号 | 含义 | 单位 | 备注 |
|---|---|---|---|
| $V_g$ | 输入直流电压 | V | 原边侧电源；**不使用 $V_{in}$**（全库统一为 $V_g$ ） |
| $V_{g,\min}$ / $V_{g,\max}$ | 输入电压范围 | V | 设计取值 |
| $V_o$ | 输出电压 | V | **不使用 $V$ 、 $V_O$** |
| $I_o$ | 输出（负载）电流 | A | |
| $P_o$ | 输出功率 | W | |
| $R_o$ / $R_{load}$ | 负载电阻 | Ω | 统一用 $R_o$ |
| $f_s$ | 开关频率 | Hz | |
| $T_s$ | 开关周期， $T_s=1/f_s$ | s | |
| $D$ | 占空比 | — | **定义见 §二**，各拓扑必须显式声明 |
| $D_{eff}$ | 有效占空比 | — | 桥式/推挽类专用，见 §二 |
| $d$ | 单管占空比 | — | 仅推挽/桥式定义有效占空比时使用 |
| $\eta$ | 效率 | — | 理想分析取 1，设计时取目标值 |

### 1.2 变压器与磁性元件

| 符号 | 含义 | 备注 |
|---|---|---|
| $N_p$ / $N_s$ | 原边 / 副边**总**匝数 | 中心抽头结构：半绕组记为 $N_{p}/2$ |
| $n$ | **匝比 $n = N_s / N_p$ （副边/原边）** | ★ 全库统一，禁止反向 |
| $L_m$ | 励磁（磁化）电感 | **不使用 $L_M$** |
| $L_k$ | 漏感 | 折算到原边 |
| $L$ | 输出滤波电感 / Boost 储能电感 | 按拓扑语境，需在符号表中注明 |
| $C$ | 输出滤波电容 | 桥式/正激 |
| $C_{in}$ | 输入滤波电容 | 含母线电容 $C_{bulk}$ |
| $C_{oss}$ | MOSFET 输出电容 | 非理想分析用 |
| $A_e$ | 磁芯有效截面积 | mm² |
| $\Delta B$ | 磁通密度摆幅（峰峰） | T |
| $B_{sat}$ / $B_r$ | 饱和磁密 / 剩磁 | T |

> **中心抽头拓扑的 $n$ 定义（重点）**：推挽、全波整流结构中， $n$ 一律定义为
> $$n=\frac{N_s/2\ \text{或}\ N_s}{N_p/2\ \text{或}\ N_p}$$
> ——**以"单个半绕组对单个半绕组"为口径**。笔记中必须写清是哪两个绕组之比，例如：
> "本笔记 $n=N_s/N_{p}$ ，其中 $N_p$ 指**半个原边绕组**的匝数"。

### 1.3 谐振变换器专用

| 符号 | 含义 |
|---|---|
| $L_r$ / $C_r$ | 谐振电感 / 谐振电容 |
| $f_r$ | 谐振频率， $f_r=1/(2\pi\sqrt{L_rC_r})$ |
| $F$ | 归一化频率， $F=f_s/f_r$ |
| $Z_0$ | 特征阻抗， $Z_0=\sqrt{L_r/C_r}$ |
| $Q$ | 品质因数， $Q=Z_0/R_{ac}$ |
| $R_{ac}$ | 折算到原边的等效交流负载 |
| $M$ | 归一化电压增益（FHA） |

## 二、占空比定义（各拓扑必须显式声明）

不同拓扑族的占空比定义**不同且不可强行统一**，每篇笔记开头必须原样声明：

| 拓扑族 | 符号 | 定义 | 取值范围 |
|---|---|---|---|
| 正激（单管/双管） | $D$ | 主管导通时间 / $T_s$ | $0<D<D_{max}$ （双管正激 $D_{max}=0.5$ ） |
| 推挽 Buck（电压馈电） | $d$ | **单管**导通时间 / $T_s$ | $0<d<0.5$ |
| 推挽 Buck | $D_{eff}$ | $2d$ （每周期两个功率脉冲） | $0<D_{eff}<1$ |
| 推挽 Boost（电流馈电） | $D$ | **单管**导通时间 / $T_s$ | $0.5<D<1$ （**必须重叠导通**） |
| 半桥 / 全桥 Buck | $d$ | 单管导通时间 / $T_s$ | $0<d<0.5$ |
| 半桥 / 全桥 Buck | $D_{eff}$ | $2d$ （有效占空比） | $0<D_{eff}<1$ |
| 全桥 Boost（电流馈电） | $D$ | "功率传输"占空比 | $0<D<0.5$ |
| 半桥 SRC / LLC | — | **无占空比**，控制量为频率 | 固定 50% 或变频 |

> **写作要求**：凡是公式中出现 $D$ ，必须在**同一行或紧邻位置**注明"（本拓扑 $D$ 为……）"，禁止只写符号。

### 3.1 每个模态必须包含的"状态表"

| 元件 | 状态 |
|---|---|
| $Q_1$ / $Q_2$ … | ON / OFF |
| $D_1$ / $D_2$ … | ON / OFF |
| 变压器 | 正向励磁 / 反向励磁 / 复位 / 不工作 |
| $L$ （或 $L_m$ ） | 储能 / 释能 / 续流 |
| $C$ | 充电 / 放电 / 保持 |

并逐条解释：电流从哪流到哪、各节点电位、器件两端电压极性、谁承担电压、能量从哪到哪、电感电流升还是降、磁通增还是减。**必须先说"为什么"，再说"是什么"。**

### 3.2 二极管方向表述

统一使用 **Anode（阳极）→ Cathode（阴极）** 描述正向电流方向。
**禁止**使用"二极管箭头方向"这类含混表述。

### 3.3 同步开关 vs 同步整流

- 两个主管同时通断 → 写"**同相驱动**"或"**同时导通/同时关断**"
- 副边 MOS 替代整流二极管 → 写"**同步整流（SR）**"
- **严禁混用**

## 四、公式推导规范

每个关键公式必须按 **物理意义 → 电路状态 → 推导 → 公式 → 工程意义** 五步展开。

推导必须完整可跟算：写出模态 1 的电感电压 → 写出模态 2 的电感电压 → 伏秒平衡 → 展开 → 结论。

每个公式必须标注**适用条件**（勾选适用的）：

- [ ] CCM / [ ] DCM / [ ] BCM
- [ ] 理想器件 / [ ] 含器件压降
- [ ] 忽略漏感 / [ ] 含漏感
- [ ] 稳态 / [ ] 动态
- [ ] 小纹波近似
- [ ] 理想变压器（ $L_m\to\infty$ ）

## 五、器件选型规范

采用四级递进，**禁止从输入电压直接跳到型号**：

```
理论最大应力 → 寄生附加应力（漏感尖峰/反向恢复/振铃） → 安全裕量 → 器件额定参数 → 案例型号
```

- **MOSFET** 至少分析： $V_{DS}$ 、 $I_{D,avg}$ 、 $I_{D,rms}$ 、 $I_{D,peak}$ 、 $R_{DS(on)}$ 、 $Q_g$ 、 $C_{oss}$ 、开关损耗、导通损耗、热设计
- **二极管** 至少分析： $V_{RRM}$ 、 $I_{F,avg}$ 、 $I_{F,peak}$ 、 $I_{F,rms}$ 、 $t_{rr}$ 、 $Q_{rr}$ 、 $V_F$ 、反向恢复损耗

> **器件型号只能作为案例**，且必须注明"参数以最新 Datasheet 为准"。

## 八、质量红线

1. **不得为了套模板而混淆拓扑工作原理**——电压馈电与电流馈电推挽是两种不同拓扑，模态与公式完全不同。
2. **不得编造不存在的工作模态**——没有的状态不要写。
3. **不得编造器件参数**——案例型号必须真实存在或标注为"示例"。
4. **所有数值必须重新验算**，并保留中间步骤。
5. **优先级**：原理论文/教材 > 原理图 > 本规范 > 既有笔记文字描述。

### 9.1 六拓扑核心公式一览（速查）

| 拓扑 | 传输比 | 开关管电压应力 | 副边二极管应力 | 控制量 |
|---|---|---|---|---|
| 推挽 Buck | $V_o=2ndV_g$ | $2V_g$ | $V_o+nV_{g,\max}$ | $d<0.5$ |
| 推挽 Boost | $V_o=\dfrac{nV_g}{2(1-D)}$ | $\dfrac{2V_o}{n}$ | $2V_o$ | $D>0.5$ |
| 半桥 Buck | $V_o=ndV_g$ | $V_g$ | $V_o+\dfrac{nV_{g,\max}}{2}$ | $D_{eff}=2d$ |
| 全桥 Buck | $V_o=2ndV_g$ | $V_g$ | $V_o+nV_{g,\max}$ | $D_{eff}=2d$ |
| 全桥 Boost | $V_o=\dfrac{nV_g}{2D}$ | $\dfrac{V_o}{n}$ | $2V_o$ | $D<0.5$ |
| 半桥 SRC | $V_o=nV_sM(F,Q)$ | $V_{bus}$ | $V_o$ | **频率 $F$** |
| 双管正激 | $V_o=nDV_g$ | $V_g$ | $nV_g$ | $D\le0.5$ |

> **共用的两条约束**（所有电流馈电隔离升压拓扑）： $n<\dfrac{V_o}{V_{g,max}}$ 。
