# 全桥隔离 Buck 变换器（Full-Bridge Isolated Buck Converter）

> 原理图（`拓扑图/Full-bridge transformer-isolated buck converter.png`）为最高依据。

---

## 一、拓扑概述

### 1.1 拓扑名称与归类

**全桥隔离型 Buck 变换器**，属于隔离型 Buck 家族。

| 归类维度 | 结论 |
|---|---|
| 家族 | **Buck 家族**（隔离衍生）——输出侧有滤波电感，本质是隔离 Buck |
| 励磁方式 | **双向励磁**（I/III 象限），磁芯自动复位 |
| 控制变量 | 占空比（**有效占空比** $D_{eff}$ ） |
| 开关管数量 | 4 |
| 整流结构 | 副边中心抽头**全波整流** |

### 1.2 原理图解读

![](拓扑图/Full-bridge%20transformer-isolated%20buck%20converter.png)

按原理图逐点确认连接关系：

| 位置 | 连接 |
|---|---|
| 输入源 | $V_g$ |
| 左桥臂 | $Q_1$ （上管）+ $D_1$ （其体二极管）； $Q_2$ （下管）+ $D_2$ |
| 右桥臂 | $Q_3$ （上管）+ $D_3$ ； $Q_4$ （下管）+ $D_4$ |
| 原边绕组 | **简单绕组**（非中心抽头），接在**左桥臂中点与右桥臂中点**之间 |
| 副边绕组 | **带中心抽头**的双半绕组；中心抽头接输出回线 |
| $D_5$ / $D_6$ | 全波整流： $D_5$ 阳极接副边上端、 $D_6$ 阳极接副边下端；两管阴极并接输出正端 |
| 输出滤波 | $L$ 串联、 $C$ 并联 |

> **三个必须看清的点**
> 1. **原边是简单绕组**（不像推挽需要中心抽头）——绕制简单、漏感小、无两半绕组对称性问题；
> 2. **四个管子构成两个桥臂**，变压器跨接在两桥臂中点之间——因此**每管只承受 $V_g$**（不是推挽的 $2V_g$ ）；
> 3. **对角线成对工作**： $Q_1+Q_4$ 一组、 $Q_2+Q_3$ 一组，交替导通。 $D_1\sim D_4$ 是四个管子的**体二极管**，不是独立器件，但在死区换流时起关键作用。

### 1.3 宏观工作机理

| 环节 | 功能 |
|---|---|
| ① 全桥斩波（ $Q_1\sim Q_4$ ） | 对角线成对导通，把直流 $V_g$ 斩波为**双极性方波** $\pm V_g$ 加在原边 |
| ② 高频变压器（简单原边 $1:n$ ） | 电压变换 + 电气隔离；双向对称励磁，自动复位 |
| ③ 全波整流（ $D_5$ 、 $D_6$ ） | 双极性方波 → 单向脉动直流 |
| ④ LC 滤波（ $L$ 、 $C$ ） | 滤除高频分量，输出平滑直流 $V_o$ |

**控制逻辑**： $Q_1$ 、 $Q_4$ **同相驱动**（同时导通/同时关断）； $Q_2$ 、 $Q_3$ 也**同相驱动**，与前者互补（各 50% 相位差）。同组对角线开通时留**死区**防直通。

> **术语提醒**： $Q_1$ 与 $Q_4$ 是"**同相驱动**"（同时导通/同时关断），**不要**写成"同步整流"——同步整流特指用 MOS 管替代副边整流二极管。

> **本质认知**：把"$Q_1\sim Q_4$ + 变压器 + $D_5$ 、 $D_6$"整体看成一个受 $D_{eff}$ 控制的**理想直流变压器**（增益 $nD_{eff}$ ），后面就是 Buck 的 LC 与负载。**因此 Buck 的全部结论都可平移。**

### 1.4 优点

1. **开关管电压应力最低**——$V_{DS}=V_g$ （推挽为 $2V_g$ ，半桥虽同为 $V_g$ 但原边只吃到 $V_g/2$ ）
2. **原边电压幅值最大**——$v_T=\pm V_g$ （半桥仅 $\pm V_g/2$ ），同功率下原边电流最小 → 导通损耗最小
3. **变压器原边结构简单**——无中心抽头 → 绕制简单、漏感小、无对称性要求
4. **漏感能量有回馈通路**——死区期间漏感电流经体二极管回馈 $V_g$ ，**自带箝位**，尖峰远小于推挽
5. **磁芯双向励磁**——利用率高，自动复位
6. **软开关潜力**——配合移相控制可实现 ZVS，是大功率高效电源的首选
7. **功率扩展性最好**——可做到 10kW 以上

### 1.5 缺点

1. **开关管数量最多**——4 管 + 4 路驱动，其中 2 路高边驱动必须隔离（变压器驱动或隔离驱动芯片）
2. **驱动时序最复杂**——4 管的死区、相位、直通保护都要处理
3. **存在偏磁风险**——虽为双向励磁，但正负半周伏秒积不等仍会偏磁（需隔直电容或电流模式控制）
4. **成本最高**——器件与驱动成本约为半桥的 2 倍
5. **PCB 布局要求最高**——4 管 + 2 桥臂，环路面积与对称性要求严格

### 1.6 适用场景

> **结论写法**：不写"全桥最好"，而写"**在什么条件下更合适**"。

| 场景 | 是否合适 | 原因 |
|---|:---:|---|
| 高压输入 + 大功率（500W~10kW+） | ✅ **最佳** | 应力低（ $V_g$ ）、电流小、可 ZVS |
| 通信电源、服务器电源 | ✅ | 高效率 + 高功率密度 |
| 电动汽车车载充电机（OBC）、充电桩 | ✅ | 大功率 + 高效率 |
| 工业电源、电焊机、感应加热 | ✅ | 大功率场合的首选 |
| 中压 + 中功率（100~500W） | △ 过设计 | 半桥更经济（省 2 管 + 2 驱动） |
| 低压 + 中功率 | ❌ | 推挽更合适（2 管即可，磁芯最省） |
| 小功率（<100W） | ❌ | 反激/正激更简单便宜 |

**选择逻辑**

```
输入电压 > 100V ?
├── 是 → 功率 > 500W ? → 全桥（应力低、可 ZVS）
│        功率 100~500W → 半桥（省 2 管 + 2 驱动）
└── 否 → 功率 > 500W ? → 全桥（电流分散到 4 管）
         功率 100~500W → 推挽（磁芯最省）
         功率 < 100W   → 反激 / 正激
```

## 二、统一符号定义

### 2.1 通用符号

| 符号 | 含义 | 本笔记取值示例 |
|---|---|---|
| $V_g$ | 输入直流电压 | 48V（范围 36~60V） |
| $V_o$ | 输出电压 | 12V |
| $I_o$ | 输出电流 | 41.7A |
| $P_o$ | 输出功率 | 500W |
| $f_s$ | 开关频率 | 100kHz |
| $T_s$ | 开关周期 | 10µs |
| $\eta$ | 效率 | 0.92 |

### 2.2 ★ 占空比定义

| 符号 | 定义 | 范围 | 说明 |
|---|---|---|---|
| $d$ | **单管占空比** $=t_{on}/T_s$ | $0<d<0.5$ | 单只管子在一个周期内的导通时间占比 |
| $D_{eff}$ | **有效占空比** $=2d$ | $0<D_{eff}<1$ | 对角线在一个周期内的合计导通占比 |

$$\boxed{D_{eff}=2d}$$

> **时间分配**：半周期 $T_s/2$ 内，对角线导通 $dT_s$ 、死区 $(0.5-d)T_s$ ；一周期共两段。
>
> **死区**： $t_d=(0.5-d)T_s=(1-D_{eff})T_s/2$ ，每半周一个，一周期共两个。

### 2.3 匝比定义

$$n=\frac{N_s}{N_p}$$

- $N_p$ ＝原边（**简单绕组**，非中心抽头）匝数
- $N_s$ ＝**半个副边绕组**匝数

> 原理图标注 "1 : n"。**全篇 $n$ 按此定义。**
> **注意**：本拓扑 $n$ 的定义与推挽不同——推挽是"半原边对半副边"，这里是"整个原边对半个副边"。横向比较时必须注意口径。

### 2.4 磁元件与假设

| 符号 | 含义 |
|---|---|
| $L_m$ | 原边励磁电感 |
| $L_k$ | 漏感 |
| $L$ | 输出滤波电感 |
| $C$ | 输出滤波电容 |

**分析假设**：CCM · 理想器件 · 忽略漏感 · 稳态 · 小纹波近似 · 理想变压器。

## 三、电路结构完整拆解

### 3.1 输入侧

| 元件 | 功能 | 关键说明 |
|---|---|---|
| $V_g$ | 直流输入 | 跨接在上下两条母线之间 |
| $Q_1$ 、 $Q_2$ | **左桥臂**（上管、下管） | 中点接变压器原边一端 |
| $Q_3$ 、 $Q_4$ | **右桥臂**（上管、下管） | 中点接变压器原边另一端 |
| $D_1\sim D_4$ | 四个管子的**体二极管** | 死区换流时提供续流与能量回馈通路 |
| 原边绕组 | **简单绕组** | 无中心抽头 |

**同名端与极性**： $Q_1$+$Q_4$ 导通时，左桥臂中点被拉到 $V_g$ 、右桥臂中点被拉到 $0$ → $v_T=+V_g$ ； $Q_2$+$Q_3$ 导通时极性反转 → $v_T=-V_g$ 。

### 3.2 副边

| 元件 | 功能 | 关键说明 |
|---|---|---|
| $D_5$ | 整流二极管（正半周） | 与 $D_6$ 交替导通 |
| $D_6$ | 整流二极管（负半周） | |
| $L$ | 输出滤波电感 | 真正的储能元件 |
| $C$ | 输出滤波电容 | |
| $R_o$ | 负载 | |

**死区期间**： $D_5$ 、 $D_6$ **同时导通**续流（各分一半），副边被短路 → $v_s=0$ → $v_L=-V_o$ 。

## 四、一个完整开关周期的工作过程

**总览**：CCM 下一个周期分 **4 个阶段**

| 阶段 | 时段 | 时长 | 开关状态 | 副边 |
|---|---|---|---|---|
| 模态 1 | $[t_0,t_1]$ | $dT_s$ | $Q_1$+$Q_4$ **同相导通** | $D_5$ 导通 |
| 模态 2 | $[t_1,t_2]$ | $(0.5-d)T_s$ | **全部关断**（死区） | $D_5$ 、 $D_6$ 同时导通（续流） |
| 模态 3 | $[t_2,t_3]$ | $dT_s$ | $Q_2$+$Q_3$ **同相导通** | $D_6$ 导通 |
| 模态 4 | $[t_3,t_4]$ | $(0.5-d)T_s$ | **全部关断**（死区） | $D_5$ 、 $D_6$ 同时导通（续流） |

---

### 4.1 模态 1： $Q_1$+$Q_4$ 同相导通（正半周功率传输）——$[t_0,t_1]$

#### （1）状态表

| 元件 | 状态 |
|---|---|
| $Q_1$ / $Q_4$ | **ON**（同相驱动） |
| $Q_2$ / $Q_3$ | OFF |
| $D_5$ | **ON** |
| $D_6$ | OFF |
| 变压器 | **正向励磁**（磁通增大） |
| $L_m$ | 储能（励磁电流上升） |
| $L$ （输出电感） | **储能**（电流上升） |
| $C$ | 充电（同时向负载放电） |

#### （2）原边：电压与电流路径

$Q_1$ 把左桥臂中点拉到 $V_g$ ， $Q_4$ 把右桥臂中点拉到 $0$ ：

$$\boxed{v_T=+V_g}$$

**电流路径**：

$$V_g(+)\to Q_1(\text{漏}\to\text{源})\to\text{原边绕组}\to Q_4(\text{漏}\to\text{源})\to V_g(-)$$

- 励磁电流 $i_m$ 线性上升： $\dfrac{di_m}{dt}=\dfrac{V_g}{L_m}$
- 原边总电流 = 负载反射电流 + 励磁电流： $i_p=n\,i_L+i_m$

> **为什么管子只承受 $V_g$ ？** 见模态 2 的分析。要点：每只管子**直接跨接在母线与桥臂中点之间**，关断时承受的正是母线电压 $V_g$ （不像推挽那样有自耦叠加）。

#### （3）副边： $D_5$ 导通、 $D_6$ 截止

- 原边上端（打点端）为正 → 副边上端（打点端）为正
- $D_5$ ：**阳极**接副边上端（ $+nV_g$ ），**阴极**接输出正端 → 正偏 → **导通**
- $D_6$ ：**阳极**接副边下端（ $-nV_g$ ），**阴极**接输出正端 → 反偏 → **截止**
- $D_6$ 承受反向电压：

$$V_{RR}(D_6)=V_o+nV_g$$

> **注意**：这是中心抽头全波整流的固有代价。严格式是 $V_o+nV_g$ ；工程保守值常直接写 $2nV_g$ 。因为 $V_o=nD_{eff}V_g<nV_g$ ，所以 $2nV_g$ 是保守值。

#### （4）电流与电压

| 量 | 趋势 | 表达式 |
|---|---|---|
| $i_{Q1}=i_{Q4}$ | 线性上升 | $=n\,i_L+i_m$ |
| $i_m$ | 线性上升 | $V_g/L_m$ |
| $i_{D5}$ | 线性上升 | $=i_L$ |
| $i_{D6}$ | $0$ | 截止 |
| $i_L$ | 线性上升 | $\dfrac{di_L}{dt}=\dfrac{nV_g-V_o}{L}>0$ |
| $v_T$ | $+V_g$ | — |
| $v_s$ | $nV_g$ | 上正下负 |
| $v_L$ | $nV_g-V_o$ | $>0$ |

---

### 4.2 模态 2：死区（全部关断）——$[t_1,t_2]$

#### （1）状态表

| 元件 | 状态 |
|---|---|
| $Q_1\sim Q_4$ | **全 OFF** |
| $D_5$ 、 $D_6$ | **同时 ON**（续流） |
| 体二极管 $D_1\sim D_4$ | 换流瞬间参与（见下） |
| 变压器 | 原边**零压**，磁通不变 |
| $L_m$ | 保持（两端≈0V） |
| $L$ | **释能**（电流下降） |
| $C$ | 放电（向负载供电） |

#### （2）副边：为什么两只二极管同时导通

1. **$i_L$ 不能突变**——原边已全部关断，但 $i_L$ 必须继续流
2. **续流回路强迫 $D_5$ 、 $D_6$ 同时导通**：
   $$L\to\text{负载}\to\text{输出回线}\to\text{副边中心抽头}\to\begin{cases}\text{上半绕组}\to D_5\\\\\text{下半绕组}\to D_6\end{cases}\to\text{汇合}\to L$$
   两管**平分**： $i_{D5}\approx i_{D6}\approx i_L/2$
3. **副边被短路 → $v_s=0$**
4. **KVL**： $v_L=v_s-V_o=-V_o$

> **这就是 Buck 的续流阶段**，机理与 Buck 变换器完全相同。

#### （3）原边：换流与**漏感能量回馈**（全桥的关键优势）

$Q_1$ 、 $Q_4$ 关断瞬间，原边电流 $i_p$ 失去沟道通路。它的去向分两段：

**① 换流瞬间（ns 级）**： $i_p$ 给 $Q_1$/$Q_4$ 的 $C_{oss}$ 充电、给 $Q_2$/$Q_3$ 的 $C_{oss}$ 放电；同时副边完成 $D_6$ 的正偏换流。

**② 稳定死区**：副边两管同时导通把副边**短路**，该短路经变压器折射到原边 → **原边电压被钳位到 $\approx0$**：

$$v_T\approx0\;\Rightarrow\;v_{L_m}\approx0\;\Rightarrow\;i_m\approx\text{const}$$

**③ 漏感能量的去向**：原边漏感 $L_k$ 中的电流在原边电压反向时，会通过**体二极管 $D_2$ 、 $D_3$** 把能量回灌到 $V_g$ ：

$$L_k\to\text{原边绕组}\to D_2\text{（或 }D_3\text{）}\to V_g\to\cdots$$

> **★ 这是全桥相对推挽的重大优势**：漏感能量**有天然的回馈通路（体二极管）**，不需要额外加 RCD 吸收。推挽拓扑没有这个通路，因此尖峰高得多。

> **⚠️ 严谨表述**：不要简单写成"励磁电流通过 $Q_2$ 体二极管续流"。当 $v_T=0$ 时原边两端等电位，体二极管**不具备持续的导通条件**。准确说法是：**副边续流短路折射到原边，把原边电压钳到零，励磁电流因 $L_m$ 两端零压而保持不变；漏感电流则通过 $C_{oss}$ 与体二极管完成衰减振荡，能量大部分回馈 $V_g$ 、小部分以损耗散掉。**

#### （4）电压与电流

| 量 | 趋势 |
|---|---|
| $i_L$ | 线性下降， $di_L/dt=-V_o/L$ |
| $i_{D5}$ 、 $i_{D6}$ | 各 $\approx i_L/2$ ，下降 |
| $i_m$ | 近似不变 |
| $v_T$ 、 $v_s$ | $\approx0$ |
| $v_L$ | $-V_o$ |
| $V_{DS}(Q_1\sim Q_4)$ | 关断瞬间由 $C_{oss}$ 决定，稳态对称时 $\approx V_g/2$ （两管分压）——**但选型必须按最恶劣的 $V_g$** |

---

### 4.3 模态 3 / 模态 4

与模态 1 / 模态 2 **完全对称、极性反转**：

- 模态 3： $Q_2$+$Q_3$ 导通 → $v_T=-V_g$ ；副边**下端为正** → $D_6$ 导通、 $D_5$ 截止（ $D_5$ 承受 $V_o+nV_g$ ）； $v_s$ 经全波整流后**仍为上正下负**， $v_L=nV_g-V_o>0$ 。
- 模态 4：死区，同模态 2。

## 五、关键波形

### 5.1 一个周期的波形（理想、CCM）

```
          模态1        模态2        模态3        模态4
        Q1+Q4导通     死区        Q2+Q3导通     死区
        ←  dTs  →   ←(0.5-d)Ts→  ←  dTs  →   ←(0.5-d)Ts→

v_g(Q1,Q4) ┌──────┐              ┌──────┐
           ┘      └──────────────┘      └──────────
v_g(Q2,Q3)        ┌──────┐              ┌──────┐
           ───────┘      └──────────────┘      └────

 v_T      +Vg  │   0    │   -Vg   │   0
        ───────┼────────┼─────────┼────────

 v_s      nVg  │   0    │   nVg   │   0     ← 整流后极性不变
        ───────┼────────┼─────────┼────────

 v_L     nVg-Vo│  -Vo   │ nVg-Vo  │  -Vo
        ───────┼────────┼─────────┼────────

 i_L (输出) 上升 │  下降   │  上升   │  下降   ← 纹波频率 = 2fs
        ───────┼────────┼─────────┼────────

 i_m      正增  │  持平   │  负增   │  持平
        ───────┼────────┼─────────┼────────

 V_DS(Q1)   0   │ ≈Vg/2  │  Vg     │ ≈Vg/2    ← 关断瞬间有漏感振铃
        ───────┼────────┼─────────┼────────

 i_D5      i_L  │ i_L/2  │   0     │ i_L/2
 i_D6       0   │ i_L/2  │  i_L    │ i_L/2
```

### 5.2 波形要点解读

| 观察 | 物理原因 |
|---|---|
| $v_T=\pm V_g$ （双极性、满幅） | 桥臂中点被母线直接驱动——幅值最大，同功率下电流最小 |
| $i_L$ 纹波频率 $=2f_s$ | 每周期两个能量脉冲 → 滤波压力小 |
| 死区时 $V_{DS}\approx V_g/2$ （对称时） | 原边悬空，两管 $C_{oss}$ 分压；但**选型按 $V_g$** |
| 关断瞬间 $V_{DS}$ 有振铃但幅度小 | 漏感能量经体二极管回馈 $V_g$ （**自箝位**）★ 全桥的关键优势 |

> **与推挽的波形对比**：形状完全相同，幅值也相同（都是 $\pm V_g$ ）；差别在于**尖峰高度**——全桥因漏感能量可回馈而振铃小，推挽则尖峰严重。

## 六、稳态电压传输关系

### 6.1 物理意义

输出电感 $L$ 是真正的储能元件，稳态下伏秒平衡。

### 6.2 电路状态（半周期即可）

以模态 1 + 模态 2 为半周期 $T_s/2$ ：

| 时段 | 时长 | $v_L$ |
|---|---|---|
| 导通（ $D_5$ 导通） | $d\,T_s$ | $nV_g-V_o$ |
| 自由续流（ $D_5$ 、 $D_6$ 同时导通） | $(0.5-d)T_s$ | $-V_o$ |

### 6.3 推导

$$\underbrace{(nV_g-V_o)\cdot dT_s}_{\text{储能}}+\underbrace{(-V_o)\cdot(0.5-d)T_s}_{\text{释能}}=0$$

展开：

$$nV_g\,dT_s-V_o\,dT_s-0.5V_oT_s+dV_oT_s=0$$

$$nV_g\,d=0.5V_o$$

$$\boxed{V_o=2n\,d\,V_g}\qquad\Longleftrightarrow\qquad\boxed{\frac{V_o}{V_g}=2n\,d=n\,D_{eff}}$$

### 6.4 变量定义与适用条件

| 符号 | 含义 | 范围 |
|---|---|---|
| $V_g$ | 输入直流电压 | — |
| $n$ | 匝比 $N_s/N_p$ | — |
| $d$ | 单管占空比 | $0<d<0.5$ |
| $D_{eff}$ | 有效占空比 $=2d$ | $0<D_{eff}<1$ |
| $V_o$ | 输出电压 | — |

**适用条件**：CCM · 理想器件 · 忽略漏感 · 稳态 · 小纹波近似。

### 6.5 三个层次的理解

**① 为什么是 $2n$**：每周期两个能量脉冲 → 等效占空比翻倍。

**② 与推挽的数学等价**： $V_o=nD_{eff}V_g$ —— **推挽与全桥传输比完全相同**。区别在于：

| | 推挽 | 全桥 |
|---|---|---|
| 开关管数 | 2 | 4 |
| 原边激励 | $\pm V_g$ | $\pm V_g$ |
| **开关管应力** | $2V_g$ | $V_g$ |
| 变压器原边 | 中心抽头 | 简单 |

> **核心 trade-off**：推挽用"2 管 + $2V_g$ 应力"换取"4 管 + $V_g$ 应力"的等价传输能力。**选管子还是选应力，就是这对拓扑的全部选择。**

**③ 对设计的含义**： $D_{eff}$ 上限 < 1（因死区），故 $V_o<nV_g$ 。设计时保证在**最低输入 + 最大占空比**下达到目标输出。

## 七、稳态电流关系

### 7.1 输出侧（与 Buck 完全相同）

| 量 | 表达式 |
|---|---|
| $I_L$ | $=I_o$ |
| $\Delta i_L$ | $\dfrac{V_o(1-D_{eff})T_s}{2L}$ （峰峰，见 §十二） |
| $i_{L,pk}$ | $I_o+\dfrac{\Delta i_L}{2}$ |
| $I_{L,rms}$ | $\sqrt{I_o^2+\dfrac{\Delta i_L^2}{12}}\approx I_o$ |

### 7.2 原边侧

**反射负载电流**（折算到原边）：

$$i_{p,\text{load}}=n\,i_L\approx nI_o$$

**效率修正后的导通期原边电流**（一阶修正）：

$$i_{p,on}\approx\frac{nI_o}{\eta}$$

**每管电流**（每管在自己所属对角线的导通期 $dT_s$ 内流过全部原边电流）：

| 量 | 推导 | 结果 |
|---|---|---|
| 平均值 | 导通期 $i_{p,on}$ ，占比 $d$ | $I_{Q,avg}=\dfrac{nI_o}{\eta}\cdot d$ |
| 有效值 | $i_{p,on}\sqrt{d}$ | $\boxed{I_{Q,rms}=\dfrac{nI_o}{\eta}\sqrt{d}=\dfrac{nI_o}{\eta}\sqrt{\dfrac{D_{eff}}{2}}}$ |
| 峰值 | 见下 | $n\left(I_o+\tfrac{\Delta i_L}{2}\right)+i_{m,pk}$ |

> **★ 易错点**：每只管子在一个周期内只导通 $dT_s=D_{eff}T_s/2$ ，**不是 $T_s/2$**。因此
> $$I_{Q,rms}=i_{p,on}\sqrt{d}\propto\sqrt{D_{eff}/2}$$
> 若误用 $\sqrt{D_{eff}/4}$ ，会把管子电流低估 $\sqrt2$ 倍。

**功率守恒校验**：

$$P_{in}=V_g\cdot I_{in}=V_g\cdot i_{p,on}\cdot D_{eff}=V_g\cdot\frac{nI_o}{\eta}\cdot D_{eff}=\frac{V_oI_o}{\eta}\quad✓$$

### 7.3 副边二极管电流

每只二极管在**自己的半周**导通（承担全部 $i_L$ ，时长 $dT_s$ ），在两个死区中各承担 $i_L/2$ ：

$$I_{D,avg}=\frac{1}{T_s}\left[\underbrace{i_L\cdot dT_s}_{\text{导通期}}+\underbrace{\frac{i_L}{2}\cdot 2(0.5-d)T_s}_{\text{两个死区}}\right]=\frac{I_o}{2}$$

> 推导： $I_o\cdot\left[d+(0.5-d)\right]=I_o\cdot0.5$ （用了 $i_L\approx I_o$ ）

$$\boxed{I_{D,avg}=\frac{I_o}{2}}$$

$$I_{D,rms}^2\approx I_o^2\left[d+\frac{1-2d}{4}\right]=I_o^2\left[\frac{D_{eff}}{2}+\frac{1-D_{eff}}{4}\right]=I_o^2\cdot\frac{1+D_{eff}}{4}$$

$$\boxed{I_{D,rms}=I_o\sqrt{\frac{1+D_{eff}}{4}}}$$

$$i_{D,pk}=I_o+\frac{\Delta i_L}{2}$$

> **校验**： $2\times I_{D,avg}=I_o$ ✓

### 7.4 电容电流

**输出电容**：与 Buck 相同

$$I_{C,rms}\approx\frac{\Delta i_L}{2\sqrt3}$$

**输入电容**：全桥的输入电流是**脉冲式**的（只在导通期取电），需要 $C_{in}$ 就近提供脉冲电流：

$$I_{in,rms}=i_{p,on}\sqrt{D_{eff}},\qquad I_{in,avg}=i_{p,on}D_{eff}$$

$$I_{C_{in},rms}=\sqrt{I_{in,rms}^2-I_{in,avg}^2}=i_{p,on}\sqrt{D_{eff}(1-D_{eff})}$$

## 八、磁芯复位原理

### 8.1 为什么全桥能自动复位

双向励磁： $Q_1Q_4$ 导通时 $v_T=+V_g$ ， $Q_2Q_3$ 导通时 $v_T=-V_g$ ，**幅值相同、时间相同** → 一周期净伏秒积为零 → 磁通对称摆动 → 自动复位。

| 时段 | $v_T$ | 伏秒积 |
|---|---|---|
| 模态 1（ $dT_s$ ） | $+V_g$ | $+V_g\,dT_s$ |
| 模态 3（ $dT_s$ ） | $-V_g$ | $-V_g\,dT_s$ |
| 模态 2、4（死区） | $\approx0$ | $0$ |

$$\text{净伏秒}=V_g\,dT_s-V_g\,dT_s=0\quad✓$$

### 8.2 全桥的偏磁风险与隔直电容

虽然结构对称，但**正负半周伏秒积不等**的情况仍会发生：

| 原因 | 机理 |
|---|---|
| 驱动不对称 | 两个对角线的导通时间不等 |
| $R_{DS(on)}$ 不一致 | 实际加在绕组上的电压不等 |
| 体二极管/死区差异 | 换流过程不完全对称 |
| **磁芯 $B_r$ 不对称** | 材料固有的剩磁偏移 |

**后果**：磁通逐周期累积 → 单向饱和 → 管子烧毁。

**解决**：在原边串联**隔直电容** $C_b$ ，阻断直流偏磁：

$$C_b\ge\frac{I_{p,rms}\cdot D_{eff}T_s}{\Delta V_{C_b}}\quad(\Delta V_{C_b}\text{ 取 }5\%\sim10\%\cdot V_g)$$

> **与半桥的对比**：**半桥靠分压电容天然隔直，无需额外器件**；**全桥必须额外串隔直电容**（或用电流模式控制）。这是全桥相对半桥的一个隐性成本。

### 8.3 与推挽的对比

| | 推挽 | 全桥 |
|---|---|---|
| 复位机制 | 中心抽头对称励磁 | 桥臂对称励磁 |
| 偏磁风险 | **高**（无隔直机制） | 中（可串隔直电容） |
| 隔直手段 | 无天然手段 | 串隔直电容 / 电流模式 |

## 九、器件电压应力

### 9.1 理论最大应力（理想器件、忽略漏感）

| 器件 | 应力 | 表达式 | 本案例（ $V_{g,max}=60\text{V}$ ） |
|---|---|---|---|
| $Q_1\sim Q_4$ | $V_{DS}$ | $\boxed{V_{g,max}}$ | **60V** |
| $D_5$ / $D_6$ | $V_{RR}$ | $\boxed{V_o+nV_{g,max}}$ （保守 $2nV_{g,max}$ ） | $12+30=42\text{V}$ （保守 60V） |
| 隔直电容 | $V_{C_b}$ | $\Delta V_{C_b}$ （小） | 数 V |

**为什么管子只承受 $V_g$**：每只管子**直接跨接在母线与桥臂中点之间**（上管的漏极接 $V_g^+$ 、源极接中点；下管的漏极接中点、源极接 $V_g^-$ ）。关断时桥臂中点被另一只管子拉到对侧母线，因此关断管承受的正是 $V_g$ 。**没有任何自耦叠加。**

> **对比推挽的 $2V_g$**：推挽管不是桥臂结构，而是各自把半绕组外端接地，中心抽头被电源钳位、另一半绕组感应叠加 → $2V_g$ 。**这就是全桥用 4 管换来的最大收益。**

### 9.2 寄生参数附加应力

| 来源 | 附加量级 | 机理 |
|---|---|---|
| 漏感振铃 | **较小**（自带箝位）★ | 漏感能量经体二极管回馈 $V_g$ ，被箝在 $V_g$ 附近 |
| PCB 走线电感 | 数 V | 高 di/dt 回路 |
| 二极管反向恢复 | 加剧振铃 | $Q_{rr}$ 注入原边 |
| 死区分压 | $V_g/2$ （对称时） | 原边悬空，两管 $C_{oss}$ 分压 |

> **★ 全桥的核心优势之一**：漏感能量有**体二极管回馈通路**，尖峰远小于推挽（推挽无此通路，尖峰可达理论值的 30~100%）。因此全桥通常**不需要 RCD 吸收**。

### 9.3 安全裕量与额定值

$$V_{DS,rated}\ge V_{g,max}\times1.5$$

本案例： $60\times1.5=90\text{V}$ → 选 **100V** 等级。

> **⚠️ 强制要求**：最终必须以**示波器实测 $V_{DS}$ 波形**确认尖峰 <额定的 80%。

## 十、器件电流应力

### 10.1 理论电流（本案例， $n=0.5$ ， $I_o=41.7\text{A}$ ， $D_{eff,max}=0.667$ ， $\eta=0.92$ ）

$i_{p,on}=\dfrac{nI_o}{\eta}=\dfrac{0.5\times41.7}{0.92}=22.7\text{A}$

| 器件 | 平均值 | 有效值 | 峰值 |
|---|---|---|---|
| $Q_1\sim Q_4$ （每只） | $i_{p,on}\cdot d=22.7\times0.333=7.6\text{A}$ | $22.7\sqrt{0.333}=13.1\text{A}$ | $\approx n\!\left(I_o+\tfrac{\Delta i_L}{2}\right)+i_{m,pk}\approx26\text{A}$ |
| $D_5$/$D_6$ | $\dfrac{I_o}{2}=20.9\text{A}$ | $I_o\sqrt{\dfrac{1+D_{eff}}{4}}=41.7\times0.645=26.9\text{A}$ | $I_o+\tfrac{\Delta i_L}{2}=46.2\text{A}$ |
| 输出电感 $L$ | $I_o=41.7\text{A}$ | $\approx41.7\text{A}$ | 46.2A |
| 输出电容 $C$ | 0 | $\dfrac{\Delta i_L}{2\sqrt3}=2.6\text{A}$ | — |
| 输入电容 $C_{in}$ | 0 | $i_{p,on}\sqrt{D_{eff}(1-D_{eff})}=22.7\times0.471=10.7\text{A}$ | — |

> **注意输入电容的 RMS**：全桥输入电流是脉冲式的， $C_{in}$ 的压力不小（10.7A），需多只并联。这是全桥相对推挽 Boost 这类"输入电流连续"拓扑的劣势。

### 10.2 器件损耗

**MOSFET**

$$P_{Q,cond}=4\times I_{Q,rms}^2R_{DS(on)}(T_j)=2\,i_{p,on}^2R_{DS(on)}D_{eff}$$

> **简洁形式推导**：导通期间两个管子串联流过 $i_{p,on}$ ，损失 $2i_{p,on}^2R$ ；占空比 $D_{eff}/2$ 每对角线，两对角线合计 $D_{eff}$ 。故总导通损失 $=2i_{p,on}^2RD_{eff}$ 。

$$P_{Q,sw}=4\times\frac{1}{2}V_{DS}i_{p,on}(t_r+t_f)f_s\quad(\text{每管每周期一次硬开关})$$

$$P_{Q,drive}=4\,Q_gV_{gs}f_s$$

**二极管**

$$P_D=2\left(V_F\cdot I_{D,avg}+\tfrac{1}{2}V_{RR}Q_{rr}f_s\right)$$

> 低压大电流输出（12V/41.7A）→ **强烈建议同步整流**： $P_{SR}=2I_{D,rms}^2R_{DS(on),SR}$ ，可将整流损耗降低 3~5 倍。

**隔直电容**： $P_{C_b}=I_{p,rms}^2\cdot ESR_{C_b}$

## 十一、高频变压器设计

### 11.1 匝数比 $n$

$$n=\frac{V_o}{D_{eff,max}\cdot V_{g,min}}$$

本案例： $n=\dfrac{12}{0.667\times36}=0.5$ 。

**校验最小占空比**：

$$D_{eff,min}=\frac{V_o}{nV_{g,max}}=\frac{12}{0.5\times60}=0.4$$

$D_{eff}$ 范围 $0.4\sim0.667$ ✓（远离 0 与 1，控制分辨率与死区裕量都充足）

**匝数取整**： $n=N_s/N_p=0.5$ → 取 $N_p=8$ 、 $N_s=4$ 。

### 11.2 磁芯选择

| 因素 | 本案例取向 |
|---|---|
| 工作频率 | 100kHz → 铁氧体 PC44/PC95 |
| 传输功率 | 500W → EE42 / PQ3230（ $A_e\approx180\sim230\text{mm}^2$ ） |
| 磁通摆幅 | 双向励磁， $\Delta B=0.2\sim0.3\text{T}$ |
| 温升 | <40K（副边大电流是铜损重点） |

### 11.3 原边匝数

$$\Delta B=\frac{V_g\,d\,T_s}{N_pA_e}\quad\Rightarrow\quad\boxed{N_p\ge\frac{V_{g,max}\,d_{min}\,T_s}{\Delta B_{allow}A_e}}$$

> **注意**：全桥与推挽 Buck 一样， $V_g\cdot d=\dfrac{V_o}{2n}=$ **常数**，所以磁通摆幅与输入电压无关 ✓（这与推挽 Boost 不同——后者要取 $D_{min}$ 的工况）。

本案例： $V_gd=\dfrac{V_o}{2n}=\dfrac{12}{1}=12\text{V}$ ， $\times T_s=120\text{V}\cdot\mu s$

取 $A_e=200\text{mm}^2$ 、 $\Delta B=0.15\text{T}$ ：

$$N_p\ge\frac{120\times10^{-6}}{0.15\times200\times10^{-6}}=4\quad\Rightarrow\quad N_p=8\text{匝（取整兼顾 n=0.5）}$$

$$N_s=nN_p=0.5\times8=4\text{匝}$$

### 11.4 磁芯饱和与气隙

- **不需要气隙**——全桥是"传能型"变压器（原副边同时有电流），励磁电流小
- 但建议留极小气隙或选高 $B_{sat}$ 材质，增大偏磁容限

### 11.5 励磁电感与励磁电流

$$i_{m,pk}=\frac{V_g\,d\,T_s}{L_m}=\frac{120\text{V}\cdot\mu s}{L_m}$$

> 设计要求： $i_{m,pk}$ 控制在反射负载电流的 5~15%。本案例反射电流 $ni_{p,on}$... 即 $nI_o=20.9\text{A}$ → $i_{m,pk}\approx1\sim3\text{A}$ → $L_m\approx40\sim120\mu H$ 。

### 11.6 绕组线径

| 绕组 | RMS 电流 | 电流密度 | 所需截面积 |
|---|---|---|---|
| 原边 | $\approx13\times\sqrt2=18.5\text{A}$ （两管串联，绕组电流等于单管电流） | 4A/mm² | 4.6mm² |
| 副边 ×2 | 26.9A | 4A/mm² | 6.7mm² ← **副边是铜损重点** |

**集肤深度**（100kHz、铜、100°C）： $\delta\approx0.21\text{mm}$ → 单根线径 $<0.4\text{mm}$ 。

> **副边建议用铜箔**：6.7mm² 的大电流 + 集肤效应 → 铜箔是最优解。

### 11.7 漏感控制

原边是简单绕组，漏感天然比推挽小。措施：三明治绕法、减小绝缘厚度、副边铜箔。

> 全桥对漏感的宽容度高于推挽（因为有体二极管回馈通路），但仍应控制在 $L_k\le1\%\cdot L_m$ 。

## 十二、输出滤波电感设计

### 12.1 电感量

纹波频率 $2f_s$ 。在半周期 $T_s/2$ 内：导通 $dT_s$ ，续流 $(0.5-d)T_s$ 。

$$\Delta i_L=\frac{V_o\,(0.5-d_{min})\,T_s}{L}=\frac{V_o\,(1-D_{eff,min})\,T_s}{2L}$$

> 两个形式等价： $(1-D_{eff})T_s/2=2(0.5-d)T_s/2=(0.5-d)T_s$ ✓

反解：

$$\boxed{L=\frac{V_o\,(0.5-d_{min})\,T_s}{\Delta i_L}=\frac{V_o\,(1-D_{eff,min})}{2f_s\,\Delta i_L}}$$

> **取 $D_{eff,min}$ （最高输入）**——续流时间最长、纹波最大。

本案例： $\Delta i_L=0.2I_o=8.3\text{A}$ ， $D_{eff,min}=0.4$ ：

$$L=\frac{12\times(1-0.4)}{2\times10^5\times8.3}=4.3\mu H\quad\Rightarrow\quad\text{取 }4.7\mu H$$

### 12.2 电流与磁芯

| 参数 | 值 |
|---|---|
| 平均电流 | 41.7A |
| 峰值电流 | 46.2A |
| RMS 电流 | ≈41.7A |
| 储能 | $\tfrac12LI_{pk}^2=5.0\text{mJ}$ |

**磁芯**：低压大电流 → 铁硅铝（Sendust）或铁粉芯，大电流型号，可能需要双芯叠用。

## 十三、电容设计

### 13.1 输出电容

$$\Delta V_o\approx\underbrace{\frac{\Delta i_L}{16f_sC}}_{\text{容值项}}+\underbrace{\Delta i_L\cdot ESR}_{\text{ESR 项}}$$

$$C\ge\frac{\Delta i_L}{16f_s\Delta V_C}$$

本案例（ $\Delta V_o\le1\%\times12\text{V}=120\text{mV}$ ， $\Delta i_L=8.3\text{A}$ ）：

- ESR 分配一半预算： $ESR\le60\text{mV}/8.3\text{A}=7.2\text{m}\Omega$
- 容值： $C\ge\dfrac{8.3}{16\times10^5\times0.06}=8.6\mu F$

**方案**：3×100µF/25V 低阻电解 + 2×10µF MLCC（并联后 ESR <7mΩ）。

> 低压大电流输出 → **ESR 是瓶颈**。用固态电容或 MLCC 并联是常规做法。

### 13.2 输入电容

全桥输入电流为**脉冲式**（仅导通期取电）：

$$C_{in}\ge\frac{i_{p,on}\cdot d\,T_s}{\Delta V_g}=\frac{I_{in,avg}\,D_{eff}T_s/2}{\Delta V_g}$$

本案例（ $\Delta V_g\le5\%\times48\text{V}=2.4\text{V}$ ）：

$$C_{in}\ge\frac{15.1\times0.667\times10^{-5}/2}{2.4}\approx21\mu F$$

**RMS 电流是瓶颈**（10.7A）：需多只并联。
**方案**：4×47µF/100V 高频低阻电解 + 1µF MLCC。

> **布局要求**： $C_{in}$ 必须紧贴两个桥臂的上管漏极与下管源极，最小化脉冲电流回路面积。

## 十四、关键工程问题

### 14.1 偏磁与隔直电容

见 §八。**全桥必须主动解决偏磁**——半桥有分压电容天然隔直，全桥没有。

两种方案：

| 方案 | 优点 | 代价 |
|---|---|---|
| **原边串隔直电容** $C_b$ | 直接阻断直流，可靠 | 增加器件与损耗； $C_b$ 需承受原边交流电流 |
| **峰值电流模式控制** | 无需额外器件，逐周期平衡 | 控制环路复杂、需斜坡补偿 |

> 工程实践：中小功率用电流模式控制；大功率常用隔直电容（或两者兼用）。

### 14.2 死区与直通

**直通（shoot-through）**：同一桥臂的上下管同时导通 → **直接短路 $V_g$** → 电流极大 → 管子瞬间损坏。这是全桥最危险的故障模式。

**必须设置死区**：换向时先关断、后开通，死区时间需覆盖管子的关断时间（含温度与器件分散性），典型 $100\sim300\text{ns}$ （视器件与驱动而定）。

> **死区过大的代价**：死区期间副边续流、不传输能量 → $D_{eff}$ 被压缩 → 同样输出需要更大的 $d$ ；且死区会引起输出电压跌落（占空比丢失效应）。

### 14.3 漏感与振铃（全桥的优势所在）

- 漏感能量在死区经**体二极管回馈 $V_g$** → 自带箝位
- 因此全桥**通常不需要 RCD 吸收**
- 但副边的**二极管反向恢复**仍会引起振铃，需用超快恢复/SiC 或加 RC 吸收

### 14.4 PCB 布局

| 要求 | 原因 |
|---|---|
| 两个桥臂的**环路面积对称且最小** | 保证正负半周寄生参数一致（防偏磁） |
| 四个管子的驱动走线**等长等阻** | 保证同相驱动严格同步 |
| $C_{in}$ 紧贴桥臂 | 最小化脉冲电流回路 |
| 高边驱动用隔离驱动或自举 | 高边管的源极是浮动的桥臂中点 |
| 变压器下方禁止走线 | 避免噪声耦合 |
| 死区时间必须实测确认 | 防直通 |

### 14.5 热设计

- 4 只管子 → 发热分散；但**高边管源极浮动**，散热器需**隔离**（或用独立散热片）
- 副边大电流（41.7A）→ 副边铜损与整流器件是主要热源
- 变压器双向励磁，铁损按等效频率估算

### 14.6 EMI

| 噪声源 | 应对 |
|---|---|
| 桥臂中点的高 dv/dt | 适当增大栅极电阻、必要时加 RC 吸收 |
| 原边高 di/dt 回路 | 缩面积、加高频旁路 |
| 副边整流振铃 | 超快恢复/SiC、RC 吸收 |
| 共模噪声 | 变压器静电屏蔽、Y 电容 |

## 十五、损耗与效率估算

### 15.1 损耗构成与估算（本案例）

| 损耗项 | 公式 | 估算 |
|---|---|---|
| $Q$ 导通 | $2i_{p,on}^2R_{DS(on)}\times1.5\times D_{eff}$ | $2\times22.7^2\times0.010\times1.5\times0.667=10.3\text{W}$ |
| $Q$ 开关 | $4\times\tfrac12V_{DS}i_{p,on}(t_r+t_f)f_s$ | $4\times0.5\times60\times22.7\times30n\times10^5=8.2\text{W}$ |
| $Q$ 驱动 | $4Q_gV_{gs}f_s$ | ≈0.6W |
| 整流**二极管** | $2V_FI_{D,avg}$ | $2\times0.5\times20.9=20.9\text{W}$ |
| 整流**同步整流** | $2I_{D,rms}^2R_{DS(on),SR}$ | $2\times26.9^2\times0.005=7.2\text{W}$ ★ |
| 铜损 | $I_P^2R_P+I_S^2R_S$ | ≈8W |
| 磁芯损耗 | Steinmetz | ≈4W |
| 其他（控制、ESR、隔直电容） | — | ≈2W |
| **合计** | | **≈54W（二极管）/ 40W（SR）** |
| **效率** | | **90.2% / 92.6%** |

> **结论**：500W 全桥，用二极管整流约 90%，用**同步整流可到 92.6%**——低压大电流输出必须上 SR。

### 15.2 效率优化优先级

1. **副边整流**（占比最大）→ **同步整流**
2. **开关管导通损耗** → 降低 $R_{DS(on)}$
3. **开关损耗** → 移相控制实现 ZVS（大功率首选）
4. **铜损** → 副边铜箔、优化窗口

## 十八、优缺点与适用场景

### 18.1 优点

1. **开关管电压应力最低**（ $V_g$ ）——同功率下电流最小、导通损耗最低
2. **原边电压幅值最大**（ $\pm V_g$ ）——变压器利用率最高
3. **原边结构简单**——无中心抽头，绕制简单、漏感小
4. **漏感能量自带回馈通路**——不需要额外的 RCD 吸收
5. **磁芯双向励磁**——利用率高、自动复位
6. **可扩展性最好**——可做到 10kW 以上；移相控制可实现 ZVS

### 18.2 缺点

1. **开关管最多（4 管 + 4 路驱动）**——成本与复杂度最高
2. **必须解决偏磁**——需隔直电容或电流模式控制（半桥不需要）
3. **直通风险**——同桥臂直通是最危险的故障，死区必须严格
4. **高边驱动需隔离**——增加驱动成本
5. **PCB 布局要求最高**

### 18.3 适用场景结论

> **在"高压输入（>100V）或大功率（>500W）"的条件下，全桥更合适**——它用 4 只管子换来了最低的电压应力与电流应力，并天然具备漏感能量回馈与软开关潜力。
>
> **反之，在 100~500W 的中功率场合，全桥多出的 2 管 + 2 路隔离驱动往往不划算**——此时半桥（应力相同、省 2 管）更经济。

## 二十、公式速查

### 20.1 电压传输与占空比

| 参数 | 公式 |
|---|---|
| 电压传输比 | $V_o=2ndV_g=nD_{eff}V_g$ |
| 有效占空比 | $D_{eff}=2d$ |
| 匝比 | $n=\dfrac{V_o}{D_{eff,max}V_{g,min}}$ |
| 占空比反解 | $D_{eff}=\dfrac{V_o}{nV_g}$ ， $d=\dfrac{V_o}{2nV_g}$ |

### 20.2 电压应力

| 器件 | 公式 |
|---|---|
| MOSFET | $V_{DS}=V_{g,max}$ （+漏感振铃，但全桥自带箝位） |
| 整流二极管 | $V_{RR}=V_o+nV_{g,max}$ （保守 $2nV_{g,max}$ ） |

### 20.3 电流应力

| 器件 | 平均值 | 有效值 | 峰值 |
|---|---|---|---|
| MOSFET（每只） | $\dfrac{nI_o}{\eta}d$ | $\dfrac{nI_o}{\eta}\sqrt{d}=\dfrac{nI_o}{\eta}\sqrt{\dfrac{D_{eff}}{2}}$ | $n\!\left(I_o+\tfrac{\Delta i_L}{2}\right)+i_{m,pk}$ |
| 整流二极管（每只） | $\dfrac{I_o}{2}$ | $I_o\sqrt{\dfrac{1+D_{eff}}{4}}$ | $I_o+\tfrac{\Delta i_L}{2}$ |
| 输出电感 | $I_o$ | $\sqrt{I_o^2+\tfrac{\Delta i_L^2}{12}}$ | $I_o+\tfrac{\Delta i_L}{2}$ |
| 输入电容 | 0 | $\dfrac{nI_o}{\eta}\sqrt{D_{eff}(1-D_{eff})}$ | — |

### 20.4 磁元件与电容

| 参数 | 公式 |
|---|---|
| 输出电感 | $L=\dfrac{V_o(1-D_{eff,min})}{2f_s\Delta i_L}$ |
| 电感纹波 | $\Delta i_L=\dfrac{V_o(1-D_{eff})T_s}{2L}$ |
| 原边匝数 | $N_p\ge\dfrac{V_gd\,T_s}{\Delta BA_e}$ ，其中 $V_gd=\dfrac{V_o}{2n}$ ＝常数 |
| 副边匝数 | $N_s=nN_p$ |
| 励磁电流峰值 | $i_{m,pk}=\dfrac{V_gd\,T_s}{L_m}$ |
| 输出电容 | $C\ge\dfrac{\Delta i_L}{16f_s\Delta V_C}$ |
| 隔直电容 | $C_b\ge\dfrac{I_{p,rms}D_{eff}}{2f_s\Delta V_{C_b}}$ |

## 二十一、学习总结

### 21.1 一句话记住这个拓扑

> **全桥 = 用 4 只管子搭成两个桥臂，把变压器原边直接跨接在两桥臂中点之间。**
> 收益：管子只承受 $V_g$ 、原边吃满 $V_g$ 、漏感能量可回馈。
> 代价：4 管 4 驱动、直通风险、需解决偏磁。

### 21.2 五个必须刻在脑子里的数

| 数 | 值 | 来源 |
|---|---|---|
| 原边激励幅值 | $\pm V_g$ | 桥臂中点直接由母线驱动 |
| **开关管电压应力** | $\mathbf{V_g}$ | 管子直接跨接在母线与中点之间 |
| 电压传输比 | $2nd=nD_{eff}$ | 每周期两个脉冲 |
| 输出纹波频率 | $2f_s$ | 全波整流 |
| 单管占空比 | $d<0.5$ | 防同桥臂直通 |

### 21.3 三个"为什么"

**Q1：为什么全桥的管子只承受 $V_g$ ，而推挽要承受 $2V_g$ ？**
A：因为**连接方式不同**。全桥的每只管子直接跨接在"母线—桥臂中点"之间，关断时中点被另一只管拉到对侧母线，所以管子承受的就是母线电压 $V_g$ 。推挽的管子是"半绕组外端→地"，关断时其漏极电位 = 中心抽头电位（ $V_g$ ）+ 另一半绕组的感应电压（ $V_g$ ）——两个 $V_g$ **叠加**成 $2V_g$ 。

**Q2：为什么全桥不需要 RCD 吸收，而推挽需要？**
A：因为**漏感能量的去向不同**。全桥在死区时原边电压反向，漏感电流可以经**体二极管**回灌到 $V_g$——有一条现成的、无损的能量回收通路，所以漏感只会引起小幅振铃。推挽没有这样的通路（它的漏感电流无处可去），能量只能靠 $C_{oss}$ 吸收并以热耗散，因此尖峰高得多。

**Q3：为什么全桥反而需要额外的隔直电容，而半桥不需要？**
A：半桥的两个分压电容**串联在变压器回路中**，天然阻断直流分量，所以中点自动平衡、无偏磁。全桥与变压器之间**没有隔直元件**，一旦正负半周伏秒积不等，磁通就会累积——所以必须外串隔直电容（或用电流模式控制逐周期平衡）。

### 21.4 学完之后你应该能

- [ ] 看到 4 管 + 简单原边变压器，立刻说出"对角线同相驱动、 $V_{DS}=V_g$"
- [ ] 画出 4 个模态的电流路径与状态表
- [ ] 独立完成伏秒平衡推导 $V_o=2ndV_g$
- [ ] 说清漏感能量经体二极管回馈的机理
- [ ] 用 $\sqrt{D_{eff}/2}$ （而非 $\sqrt{D_{eff}/4}$ ）正确计算管子的 RMS 电流
- [ ] 解释为什么全桥需要隔直电容而半桥不需要
- [ ] 判断什么场合该用全桥、什么场合用半桥更经济
