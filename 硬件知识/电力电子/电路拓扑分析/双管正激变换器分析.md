## 一、拓扑概述

### 1.1 拓扑名称与归类

**双管正激变换器**（Two-Transistor Forward Converter，2TFC），亦称双开关正激。

| 归类维度 | 结论 |
|---|---|
| 家族 | **Buck 家族**（隔离衍生）——输出侧有滤波电感，本质是隔离 Buck |
| 励磁方式 | **单向励磁**（仅第一象限），需**强制复位** |
| 控制变量 | 占空比 $D$ （ $0<D\le0.5$ ） |
| 开关管数量 | 2（**同相驱动**，同时导通/同时关断） |
| 复位方式 | $D_1$ 、 $D_2$ 箝位复位，**能量回馈输入** |
| 整流结构 | 副边单端整流 + 续流（ $D_3$ 、 $D_4$ ） |

**功率链路**：斩波（ $Q_1$ 、 $Q_2$ ）+ 高频变压器隔离变压（ $1:n$ ）+ 单端整流（ $D_3$ 、 $D_4$ ）+ LC 低通滤波。

> **本质认知**：双管正激 = **Buck 的隔离化**。Buck 中"开关管 + 续流二极管"这个斩波单元被整体替换成"$Q_1$+$Q_2$+变压器+$D_3$+$D_4$"；输出 LC 与负载部分与 Buck 一字不差。因此它的**小信号模型、补偿器设计、纹波计算全部可以照搬 Buck**，唯一多出的硬约束是变压器复位带来的 $D_{max}=0.5$ （见 §八）。

### 1.2 宏观工作机理

| 环节 | 器件 | 功能 |
|---|---|---|
| ① 斩波 | $Q_1$ 、 $Q_2$ | 同一路 PWM 驱动，**同时导通/同时关断**，把直流 $V_g$ 斩成单极性方波加到原边 |
| ② 原边箝位复位 | $D_1$ 、 $D_2$ | 关断期把原边箝到 $-V_g$ ，强制磁芯复位，并把励磁与漏感能量**回馈输入端** |
| ③ 高频变压器 | $1:n$ | 电压变换 + 电气隔离；**单端正激**（只从副边送出能量，自身不储能） |
| ④ 整流 + 续流 | $D_3$ 、 $D_4$ | $D_3$ 导通期整流给负载； $D_4$ 关断期给电感续流 |
| ⑤ LC 滤波 | $L$ 、 $C$ | 与 Buck 完全相同 |

**控制逻辑**： $Q_1$ 、 $Q_2$ 完全同步（ $t_{on}=DT_s$ ），调节 $D$ 控制输出：

$$\boxed{V_o=nDV_g}$$

### 1.3 优点

1. **开关管电压应力最低**——每管只承受 $V_g$ （不是单管正激的 $2V_g$ ，也不是反激的 $V_g+U_{or}$ ）。**$V_g$ 越高这一优势越关键**，故双管正激是高压母线（如 380V）中功率场合的经典选择。
2. **漏感能量可回馈**——复位期原边被 $D_1$ 、 $D_2$ 箝到 $-V_g$ ，漏感电流被直接倒灌回输入源，**不需要 RCD 吸收电路**。这是相对单管正激效率优势的主要来源。
3. **无 RCD 损耗、无复位绕组**——省掉复位绕组与吸收网络，磁元件与 BOM 都更简单。
4. **磁芯自动复位，无偏磁累积机制**——只要 $D<0.5$ 且复位时间足够，励磁电流自然降到零，磁通停在复位点不再变化（见 §八）。
5. **无桥臂直通风险**——两管**串联在原边两端**（把变压器夹在中间），即便驱动出错同时导通，电流也被变压器与负载限制，**不会直接短路 $V_g$**。这是相对半桥/全桥的可靠性优势。
6. **管子耐压低 → 可选低 $R_{DS(on)}$ 、低 $Q_g$ 器件**，同功率下导通与驱动损耗都优于高耐压方案。

### 1.4 缺点

1. **开关管数量翻倍**——2 只 MOS + 2 路驱动，成本与布板面积上升。
2. **$Q_1$ 是浮地高边，驱动复杂** ★——$Q_1$ 的源极是节点 A（电位在 $0\sim V_g$ 之间跳变），**必须用隔离驱动（数字隔离器+隔离电源）、栅极驱动变压器或自举驱动**；且两管必须严格同步（见 §14.3）。
3. **原边电流由两管共同承担**——虽然每管只承受 $V_g$ ，但两管都流过**全部**原边电流，导通损耗是两只之和 $2I_{p,rms}^2R_{DS(on)}$ 。
4. **$D_{max}=0.5$ 硬约束**——匝比 $n$ 被迫取较大值（ $n\ge2V_o/V_{g,min}$ 量级），原边电流大、副边二极管电压应力高。
5. **磁芯利用率低**——单端工作，磁通只在第一象限 $B_r\to B_r+\Delta B$ 变化，**同功率下磁芯体积约为双端拓扑（全桥/推挽）的 2 倍**。
6. **PCB 与 EMI 要求高**——开关节点 $\mathrm{d}v/\mathrm{d}t$ 、原边回路 $\mathrm{d}i/\mathrm{d}t$ 都很大，换流回路面积必须压到最小。
7. **副边二极管损耗占比高**——低压大电流输出时， $D_3$ 、 $D_4$ 损耗常是第一大项（见 §十五）。

### 1.5 适用场景

| 场景 | 是否适合 | 原因 |
|---|:--:|---|
| 高输入电压（≥300V）+ 中功率（300W~1kW） | ✅ **最佳** | 管子只需 $V_g$ 耐压，漏感能量回馈，性价比高于单管正激 |
| 通信／工业电源（48V~400V 母线） | ✅ | 无需复位绕组与 RCD，成本与可靠性都好 |
| 高压输入 + 可靠性优先 | ✅ | 无耗散型吸收电路、无桥臂直通、无偏磁失控风险 |
| 低压输入（<24V） | △ | 管子耐压低本来就不贵，双管的驱动复杂度不划算 |
| 需要 $D>0.5$ 的宽输入范围 | ❌ | 本拓扑做不到 → 改用**有源钳位正激（ACF）** |
| 小功率（<100W） | △ | 比单管正激多一只管 + 一路隔离驱动，成本不占优 |

**选择逻辑**

```
输入电压 > 200V ?
├── 是 → 功率 > 1kW ? → 全桥（可 ZVS，电流分散）
│        功率 300W~1kW → 双管正激 ★（应力低 + 能量回馈 + 无直通）
│        功率 < 300W  → 单管正激（省一管一驱动）
└── 否 → 功率 > 500W ? → 半桥 / 全桥
         功率 100~500W → 推挽（低压下磁芯最省）
         功率 < 100W   → 反激 / 单管正激
```

### 2.1 通用符号

| 符号 | 含义 | 本笔记取值示例 |
|---|---|---|
| $V_g$ | 输入直流电压 | 48V（范围 36~60V） |
| $V_o$ | 输出电压 | 12V |
| $I_o$ | 输出电流 | 10A |
| $P_o$ | 输出功率 | 120W |
| $f_s$ | 开关频率 | 100kHz |
| $T_s$ | 开关周期 | 10µs |
| $\eta$ | 效率 | 0.92 |
| $R_o$ | 负载电阻 $=V_o/I_o$ | 1.2Ω |

### 2.2 ★ 占空比定义

| 符号 | 定义 | 范围 | 说明 |
|---|---|---|---|
| $D$ | **主管导通占空比** $=t_{on}/T_s$ | $\mathbf{0<D\le0.5}$ | 本拓扑**硬上限 0.5**（见 §八） |

> **本拓扑只有一个占空比**（两管同相驱动，不存在单管/有效占空比之分），这与推挽、桥式的 $d$/$D_{eff}$ 体系不同。

**三个时间段的划分**：

| 时段 | 时长 | 原边 |
|---|---|---|
| 导通期 | $DT_s$ | $v_p=+V_g$ |
| **复位期** | $t_{reset}=DT_s$ | $v_p=-V_g$ （ $D_1$/$D_2$ 导通） |
| **空闲期** | $(1-2D)T_s$ | 原边悬空， $v_p\approx0$ |

> 注意：复位期与空闲期**都属于"开关管关断"**，但内部机理完全不同——只有复位期有原边电流与能量回馈。**计算副边与纹波时可合并，计算磁芯复位/$V_{DS}$/二极管损耗时必须分开**。

### 2.3 匝比定义

$$n=\frac{N_s}{N_p}\qquad(\text{原理图 } N_p:N_s=1:n)$$

### 2.4 磁元件符号

| 符号 | 含义 |
|---|---|
| $L_m$ | 原边励磁电感 |
| $L_k$ | 原边漏感 |
| $L$ | 输出滤波电感 |
| $C$ | 输出滤波电容 |
| $C_{in}$ | 输入滤波电容 |
| $A_e$ | 磁芯有效截面积 |
| $\Delta B$ | 磁通密度摆幅 |

### 2.5 节点定义（后文沿用）

- **节点 A**：原边同名端（ $Q_1$ 源极）；副边同名端与之同相
- **节点 B**：原边非同名端（ $Q_2$ 漏极）
- $v_p=v_A-v_B$ ， $v_s=nv_p$
- $v_L$ ：输出电感两端电压（左端对输出回线）
- 输出回线（副边下端、 $D_4$ 阳极、 $C$ 负极、 $R_o$ 下端）定义为副边参考地

## 三、电路结构完整拆解

![](拓扑图/Two-transistor%20Forward%20Converter.png)

### 3.1 读图要点：别被画法骗了

$D_1$ 、 $D_2$ 在图上竖向叠画在同一列，很容易被误读成"跨接在 $V_g$ 上串联的两只二极管"。**实际接法是交叉配合**：

| 节点 | 图上位置 | 连接的实际器件 |
|---|---|---|
| 顶部母线 | 上横线 | $V_g$ 正端、 $Q_1$ 漏极、 $D_1$ **阴极** |
| **节点 A**（原边同名端） | 原边上端（打点处） | $Q_1$ **源极**、原边绕组打点端、 $D_2$ **阴极** |
| **节点 B**（原边非同名端） | 原边下端 | $Q_2$ **漏极**、原边绕组非打点端、 $D_1$ **阳极** |
| 底部母线 | 下横线 | $V_g$ 负端、 $Q_2$ **源极**、 $D_2$ **阳极** |

**图上的"跨线半圆"（hop）**： $D_2$ 的阴极引线向上走，在原边下端那条横线上画了一个不连通的半圆跳线，然后继续上行接节点 A。这表示 **$D_2$ 阴极与节点 B 之间不连通**——$D_1$ 阳极只接节点 B， $D_2$ 阴极只接节点 A。

> **▎读图要点： $D_1$ 、 $D_2$ 是交叉接法，不是串联**
>
> 由此得到两只复位二极管的真实接法：
> - $D_1$ ：**阳极**接节点 B（ $Q_2$ 侧），**阴极**接 $V_g^+$
> - $D_2$ ：**阳极**接 $V_g^-$ ，**阴极**接节点 A（ $Q_1$ 侧）
>
> 这不是画错，而是复位的物理必然：关断后励磁电流方向不能突变，只能从节点 B 经 $D_1$ 灌回 $V_g^+$ ，再从 $V_g^-$ 经 $D_2$ 补入节点 A（推导见 §4.2）。**若两只管子真的串联在 $V_g^+$ 与 $V_g^-$ 之间，二者永远反向截止，变压器得不到复位通路，电路根本无法工作。**

### 3.2 逐点连接清单

1. $Q_1$ 、 $Q_2$ 均为 **N 沟道 MOSFET**；
2. $Q_1$ 漏极接 $V_g^+$ ，**源极接节点 A**（浮地高边）；
3. $Q_2$ 漏极接节点 B，**源极接 $V_g^-$**（低边）；
4. $D_1$ 阳极接节点 B，阴极接 $V_g^+$ ；
5. $D_2$ 阳极接 $V_g^-$ ，阴极接节点 A；
6. 原边打点端在**上**（节点 A 侧），副边打点端也在**上**；
7. 变压器变比标注 $1:n$ ，与 $n=N_s/N_p$ 一致；
8. 副边： $D_3$ 为整流管（阳极接副边同名端，阴极接 $L$ ）； $D_4$ 为续流管（阴极接 $D_3$ 阴极与 $L$ 之间的节点，阳极接输出回线）； $L$ 、 $C$ 、 $R_o$ 依次为滤波电感、滤波电容、负载。

### 3.3 输入侧：斩波与复位网络

- $Q_1$ 、 $Q_2$ 由**同一个 PWM 逻辑**驱动，正常工作时**同相驱动**（同时导通、同时关断）；
- **导通期**： $Q_1$ 把节点 A 拉到 $V_g^+$ ， $Q_2$ 把节点 B 拉到 $V_g^-$ ，原边获得 $+V_g$ ；
- **关断期**： $D_1$ 、 $D_2$ 同时导通，把原边箝到 $-V_g$ ，构成**磁芯复位回路**；
- **同名端与极性**：原边打点端在上（节点 A），导通期电流由节点 A 流入绕组（ $A\to B$ ），故打点端为正；副边打点端也在上，故副边电压在导通期为上正下负， $D_3$ 正向导通。

> **▎为什么 $Q_2$ 在下面，而不是"两只管子都挂在高边"？**
>
> $Q_1$ 在 $V_g^+$ 侧、 $Q_2$ 在 $V_g^-$ 侧，两只管子**把变压器原边夹在中间**。这样带来三个好处：
> ① 关断时原边两端可分别被 $D_1$ 、 $D_2$ 拉到 $V_g^+$ 与 $V_g^-$ ，复位电压恰好是 $-V_g$ ；
> ② 每只管子的 $V_{DS}$ 都只有 $V_g$ ；
> ③ 两管同时导通时**不会把 $V_g$ 短路**（变压器绕组在中间挡着）。

### 3.4 副边：整流、续流与滤波

- $D_3$ ：**整流二极管**，导通期把副边能量送到负载， $I_{D3,avg}=DI_o$
- $D_4$ ：**续流二极管**，关断期维持电感电流连续， $I_{D4,avg}=(1-D)I_o$
- $L$ 、 $C$ ：与 Buck 相同的 LC 低通滤波
- $R_o$ ：负载

**副边只有两种状态**：要么 $D_3$ 导通（副边供能），要么 $D_4$ 导通（电感续流）。**原边的"复位期"与"空闲期"在副边看起来是同一种状态**——这正是 §六 伏秒平衡成立的前提。

## 四、一个完整开关周期的工作过程

**总览**：一个周期分 **3 个阶段**

| 阶段 | 时段 | 时长 | $Q_1$/$Q_2$ | $D_1$/$D_2$ | $D_3$/$D_4$ | $v_p$ |
|---|---|---|---|---|---|---|
| **阶段 1** 导通 | $[t_0,t_1]$ | $DT_s$ | **同相导通** | 截止 | $D_3$ 通／ $D_4$ 止 | $+V_g$ |
| **阶段 2** 复位 | $[t_1,t_2]$ | $DT_s$ | 同相关断 | **同时导通** | $D_3$ 止／ $D_4$ 通 | $-V_g$ |
| **阶段 3** 空闲 | $[t_2,t_3]$ | $(1-2D)T_s$ | 同相关断 | 截止 | $D_3$ 止／ $D_4$ 通 | $\approx0$ |

---

### 4.1 阶段 1： $Q_1$ 、 $Q_2$ 同时导通——$[t_0,t_1]$ ，时长 $DT_s$

#### （1）状态表

| 元件 | 状态 |
|---|---|
| $Q_1$ / $Q_2$ | **ON**（同相驱动） |
| $D_1$ / $D_2$ | OFF（反偏） |
| $D_3$ | **ON**（整流） |
| $D_4$ | OFF（反偏） |
| 变压器 | **正向励磁**（磁通增大） |
| $L_m$ | 储能（励磁电流上升） |
| $L$ （输出电感） | **储能**（电流上升） |
| $C$ | 充电（同时向负载放电） |

#### （2）原边：电压与电流路径

$Q_1$ 把节点 A 拉到 $V_g^+$ ， $Q_2$ 把节点 B 拉到 $V_g^-$ ：

$$\boxed{v_p=+V_g}$$

**电流路径**（Anode→Cathode 规范）：

$$V_g^+\to Q_1(\text{漏}\to\text{源})\to\text{原边绕组}(A\to B)\to Q_2(\text{漏}\to\text{源})\to V_g^-$$

**原边电流构成**（物理意义：反射负载电流 + 励磁电流）：

$$i_p=i_{load,reflected}+i_m\approx n\,i_L+i_m$$

**励磁电流**（三角波上升）：

$$\frac{\mathrm{d}i_m}{\mathrm{d}t}=\frac{V_g}{L_m}>0\quad\Longrightarrow\quad i_{m,pk}=\frac{V_g\,DT_s}{L_m}$$

#### （3）副边： $D_3$ 导通、 $D_4$ 截止

- 原边打点端（节点 A）为正 → 副边打点端（上端）为正
- $D_3$ ：**阳极**接副边上端（ $+nV_g$ ），**阴极**接 $L$ → 正偏 → **导通**
- $D_4$ ：**阳极**接输出回线，**阴极**接节点 $L$ 左端 → 反偏 → **截止**（承受 $nV_g$ ）

#### （4）电压与电流

| 量 | 趋势 | 表达式 |
|---|---|---|
| $i_p$ | 线性上升 | $=n\,i_L+i_m$ |
| $i_{D3}$ | 线性上升 | $=i_L$ |
| $i_{D4}$ | $0$ | 截止 |
| $i_L$ | 线性上升 | $\dfrac{\mathrm{d}i_L}{\mathrm{d}t}=\dfrac{nV_g-V_o}{L}>0$ |
| $v_p$ | $+V_g$ | — |
| $v_s$ | $nV_g$ | 上正下负 |
| $v_L$ | $nV_g-V_o$ | $>0$ |
| $V_{DS}(Q_1)$ 、 $V_{DS}(Q_2)$ | $0$ | 导通 |

---

### 4.2 阶段 2： $Q_1$ 、 $Q_2$ 同时关断，变压器复位——$[t_1,t_2]$ ，时长 $t_{reset}=DT_s$

#### （1）状态表

| 元件 | 状态 |
|---|---|
| $Q_1$ / $Q_2$ | **全 OFF** |
| $D_1$ / $D_2$ | **同时 ON**（复位回路） |
| $D_3$ | OFF（反偏） |
| $D_4$ | **ON**（续流） |
| 变压器 | **反向励磁 → 复位**（磁通下降） |
| $L_m$ | 释能（励磁电流下降） |
| $L$ | **释能**（电流下降） |
| $C$ | 放电（向负载供电） |

#### （2）为什么 $D_1$ 、 $D_2$ 会同时导通

关断瞬间，原边电流 $i_p$ （含励磁电流 $i_m$ ）**不能突变**，它在绕组内仍沿 $A\to B$ 方向流动，于是必须在外电路找到续流回路：

1. $Q_2$ 已关断 → 节点 B 的电位被电流**顶到 $V_g^+$ 以上** → 使 $D_1$ （阳极在节点 B、阴极在 $V_g^+$ ）**正向导通**
2. 电流经 $V_g$ 源流回 $V_g^-$ → 节点 A 的电位被**压到 $V_g^-$ 以下** → 使 $D_2$ （阳极在 $V_g^-$ 、阴极在节点 A）**正向导通**

形成完整回路：

$$B\to D_1\to V_g^+\to\boxed{V_g}\to V_g^-\to D_2\to A\to\text{原边绕组}(A\to B)$$

> **$D_1$ 与 $D_2$ 必须成对导通，缺一不成回路。** 它们在回路中一只在电源"上方"、一只在电源"下方"，把励磁能量（以及漏感能量）**送回输入源**。

#### （3）原边电压与励磁电流

$$\boxed{v_p=-V_g}\qquad(v_A\approx V_g^-,\ v_B\approx V_g^+,\ \text{差值}-V_g)$$

$$\frac{\mathrm{d}i_m}{\mathrm{d}t}=-\frac{V_g}{L_m}<0$$

**斜率大小与导通期相同**（都是 $\pm V_g/L_m$ ），因此励磁电流从 $i_{m,pk}$ 降到零所需时间恰为：

$$\boxed{t_{reset}=\frac{i_{m,pk}}{V_g/L_m}=\frac{V_gDT_s/L_m}{V_g/L_m}=DT_s}$$

> **★ 复位时间恰好等于导通时间**——这是"复位电压幅值 = 输入电压幅值"的直接结果，也是 $D_{max}=0.5$ 的来源。

#### （4） $V_{DS}$ 应力：为什么不是 $2V_g$

单管正激的复位期，开关管要承受 $V_g+V_g=2V_g$ （输入电压 + 复位绕组/励磁电压叠加）。

双管正激中，**两只管子分别接在电源的两端**： $Q_1$ 的源极（节点 A）被 $D_2$ 箝到 $V_g^-$ ， $Q_2$ 的漏极（节点 B）被 $D_1$ 箝到 $V_g^+$ ，因此

$$\boxed{V_{DS}(Q_1)=V_g^+-v_A\approx V_g,\qquad V_{DS}(Q_2)=v_B-V_g^-\approx V_g}$$

**两只管子各承受 $V_g$ ，没有 $2V_g$ 问题**——复位电压被"分摊"到了电源两端。

#### （5）副边与输出电感

- 副边电压反向： $v_s=-nV_g$ ，副边同名端变负
- $D_3$ 反偏截止（承受 $nV_g$ ）， $D_4$ **正向导通续流**
- $v_L=-V_o<0$ ， $i_L$ 线性下降

#### （6）漏感能量的去向

漏感电流与原边电流同向，关断后同样被 $D_1$ 、 $D_2$ 箝位并**回馈输入**，所以**不需要 RCD 吸收**。

但漏感与 MOSFET 的 $C_{oss}$ 、二极管结电容在换流瞬间会形成高频振荡（ $L_k$-$C_{oss}$ 谐振），表现为 $V_{DS}$ 上的一小段振铃；由于 $D_1$/$D_2$ 的箝位作用，振铃幅度被限制在 $V_g$ 上下一个二极管压降之内，属于"**自箝位**"。

---

### 4.3 阶段 3：复位完成后的剩余关断时间——$[t_2,t_3]$ ，时长 $(1-2D)T_s$

- 当 $i_m$ 降到零后，**$D_1$ 、 $D_2$ 不再导通**——二者是二极管，不能通过反向电流，因此复位回路**自然断开**（不是靠控制信号关断的）
- 变压器**已完成复位**，原边两端事实上悬空，电压只由寄生电容分压决定（对称时 $v_A=v_B\approx V_g/2$ ，即 $v_p\approx0$ ）
- 副边**继续由 $D_4$ 与输出电感维持负载电流**， $v_L=-V_o$ ，与阶段 2 无缝衔接
- **阶段 2 与阶段 3 在副边波形上不可区分，但在原边完全不同**——阶段 2 有原边电流（ $D_1$/$D_2$ 导通、能量回馈），阶段 3 原边电流为零（无能量流动、无损耗）

#### $V_{DS}$ 应力

- **复位期**： $V_{DS}\approx V_g$ （工程上再叠加两个二极管压降与振铃）
- **空闲期**： $v_A=v_B\approx V_g/2$ → $V_{DS}(Q_1)=V_{DS}(Q_2)\approx V_g/2$

> **平均应力更低，但选型必须按最恶劣的 $V_g$**（复位期间的瞬时值），还要叠加漏感振铃与寄生电感引起的尖峰。

## 五、关键波形

### 5.1 一个周期的波形（理想、CCM）

```
              阶段1        阶段2        阶段3
             导通期       复位期       空闲期
             ←  DTs  →   ←  DTs  →   ← (1-2D)Ts →

 v_g(Q1,Q2)  ████████████
             ────────────┴───────────────────────

 v_p        +Vg │   -Vg    │    ≈0（悬空分压）
           ─────┼──────────┼──────────────────────

 i_m        上升 │   下降    │    0
           ─────┼──────────┼──────────────────────

 i_p        上升 │   下降    │    0
           ─────┼──────────┼──────────────────────

 V_DS(Q1)     0  │  ≈Vg(+振铃) │  ≈Vg/2
           ─────┼──────────┼──────────────────────
 V_DS(Q2)     0  │  ≈Vg(+振铃) │  ≈Vg/2
           ─────┼──────────┼──────────────────────

 v_s        nVg  │   -nVg    │   ≈0
           ─────┼──────────┼──────────────────────

 i_D3        i_L │     0     │    0
 i_D4         0  │    i_L    │   i_L      ← 副边只看两种状态

 v_L      nVg-Vo │   -Vo     │   -Vo
           ─────┼──────────┼──────────────────────

 i_L        上升 │   下降     │   下降     ← 与 Buck 完全相同
           ─────┼──────────┼──────────────────────

 i_D1,i_D2    0  │ i_m 的下降段 │   0      ← 复位电流很小
```

### 5.2 波形要点解读

| 观察 | 物理原因 |
|---|---|
| $v_p$ 只有 $+V_g$ / $-V_g$ / $0$ 三态 | 单极性激励 + 复位箝位 + 空闲悬空 |
| **副边 $v_s$ 只有两种有效状态** | 无论原边处于复位期还是空闲期，副边都是 $D_4$ 续流 —— **这就是"隔离 Buck"的直观体现** |
| $V_{DS}$ 在复位期为 $\approx V_g$ ，空闲期降到 $\approx V_g/2$ | 复位期两端被箝到 $V_g^\pm$ ；空闲期原边悬空、两管 $C_{oss}$ 分压 |
| $i_{D1}$ 、 $i_{D2}$ 很小 | 只承担励磁电流（ $\approx$ 反射负载电流的 5~15%）——**复位二极管可用小电流器件** |
| $i_L$ 纹波频率仍为 $f_s$ | 单端拓扑，每周期只有一个能量脉冲（对比推挽/桥式的 $2f_s$ ） |

## 六、稳态电压传输关系

### 6.1 物理意义

输出电感 $L$ 是真正的储能元件，稳态下它每周期吸收的伏秒积必须等于放出的伏秒积。

### 6.2 电路状态

**无论原边处于复位期还是空闲期，副边都是 $D_4$ 导通、 $v_L=-V_o$**，所以电感只有两种状态：

$$v_L=\begin{cases} nV_g-V_o, & 0<t<DT_s\ (D_3\ \text{导通，储能})\\\\ -V_o, & DT_s<t<T_s\ (D_4\ \text{续流，释能}) \end{cases}$$

### 6.3 推导

$$\underbrace{(nV_g-V_o)\cdot DT_s}_{\text{储能}}+\underbrace{(-V_o)\cdot(1-D)T_s}_{\text{释能}}=0$$

展开：

$$nV_gDT_s-V_oT_s=0$$

$$\boxed{V_o=nDV_g}\qquad\Longleftrightarrow\qquad\boxed{\frac{V_o}{V_g}=nD}$$

### 6.4 变量定义与适用条件

| 符号 | 含义 | 范围 |
|---|---|---|
| $V_g$ | 输入直流电压 | — |
| $n$ | 匝比 $N_s/N_p$ | — |
| $D$ | 占空比 | $0<D\le0.5$ |
| $V_o$ | 输出电压 | — |

**适用条件**：CCM · 理想器件 · 忽略漏感 · 稳态 · 小纹波近似。

### 6.5 三个层次的理解

**① 为什么是 $nD$ 而不是 $D$**：变压器把 $V_g$ 变成 $nV_g$ ，再由开关管"斩波"，输出就是 Buck 的 $D$ 乘以匝数比。**匝数比是"粗调"，占空比是"细调"。**

**② 为什么说它是隔离 Buck**：把"$Q_1$+$Q_2$+变压器+$D_3$+$D_4$"整体看成一个受 $D$ 控制的**理想直流变压器**（增益 $nD$ ），后面就是 Buck 的 LC 与负载。因此 **Buck 的所有结论（CCM/DCM 边界、纹波公式、小信号模型、环路补偿）都可以平移过来**。

**③ 与三桥式拓扑的对照**

| 拓扑 | 传输比 | 原边激励幅值 | $D$ 范围 | 每周期脉冲数 |
|---|---|---|---|---|
| **双管正激** | $V_o=nDV_g$ | $0/+V_g$ （**单极性**） | $\le0.5$ | **1** |
| 推挽 | $V_o=2ndV_g$ | $\pm V_g$ | $d<0.5$ | 2 |
| 全桥 | $V_o=2ndV_g$ | $\pm V_g$ | $d<0.5$ | 2 |
| 半桥 | $V_o=ndV_g$ | $\pm V_g/2$ | $d<0.5$ | 2 |

> **注意**：双管正激的传输比与半桥相同（都是 $ndV_g$ ），但**机理完全不同**——半桥靠"两个脉冲 × 半个母线电压"，双管正激靠"一个脉冲 × 整个母线电压 × 受限于 0.5 的占空比"。

### 6.6 匝数比与占空比的影响

| 参数变化 | 对 $V_o$ 的影响 | 连带影响 |
|---|---|---|
| $n$ 增大 | $V_o$ 线性上升 | 原边电流增大（ $i_p=ni_L$ ），副边二极管应力 $nV_g$ 增大 |
| $n$ 减小 | $V_o$ 线性下降 | 原边电流减小，但需要更大 $D$ ，受 $D_{max}$ 挤压 |
| $D$ 增大 | $V_o$ 线性上升 | 原边电流有效值上升、复位时间变长、 $D_4$ 导通时间变短 |
| $f_s$ 升高 | 与 $V_o$ 无关（CCM） | 磁芯与滤波器体积减小，开关损耗上升 |

## 七、稳态电流关系

### 7.1 副边（与 Buck 完全相同）

| 量 | 表达式 |
|---|---|
| $I_L$ | $=I_o$ |
| $\Delta I_L$ | $\dfrac{V_o(1-D)}{Lf_s}$ （峰峰，见 §十二） |
| $i_{L,pk}$ | $I_o+\dfrac{\Delta I_L}{2}$ |
| $I_{L,rms}$ | $\approx I_o$ （ $\Delta I_L\ll I_o$ 时） |

### 7.2 副边二极管

| 量 | $D_3$ （整流） | $D_4$ （续流） |
|---|---|---|
| 平均电流 | $I_{D3,avg}=DI_o$ | $I_{D4,avg}=(1-D)I_o$ |
| 有效值 | $I_{D3,rms}=I_o\sqrt{D}$ | $I_{D4,rms}=I_o\sqrt{1-D}$ |
| 峰值 | $i_{L,pk}$ | $i_{L,pk}$ |
| 反向电压 | $nV_{g,max}$ | $nV_{g,max}$ |

> **两条重要规律**：
> ① $I_{D3,avg}+I_{D4,avg}=I_o$ 恒成立；
> ② 因 $D<0.5$ ，**$D_4$ （续流管）的平均电流大于 $D_3$**——热设计要重点照顾 $D_4$ 。

### 7.3 原边

**导通期原边电流**（一阶效率修正后）：

$$i_{p,on}\approx\frac{nI_o}{\eta}$$

| 量 | 表达式 | 说明 |
|---|---|---|
| **每管有效值** | $\boxed{I_{Q,rms}=I_{p,rms}\approx\dfrac{nI_o}{\eta}\sqrt{D}}$ | 两管流过**同一**原边电流 |
| **每管平均值** | $I_{Q,avg}=i_{p,on}\cdot D$ | |
| **每管峰值** | $I_{Q,pk}=n\!\left(I_o+\dfrac{\Delta I_L}{2}\right)+i_{m,pk}$ | 出现在导通期末 |
| 励磁电流峰值 | $i_{m,pk}=\dfrac{V_gD\,T_s}{L_m}=\dfrac{(V_o/n)\,T_s}{L_m}$ | 见下方注释 |

> **★ 注意 $V_gD=V_o/n$ 是常数**：因为 $V_o=nDV_g$ ，所以 $V_gD=V_o/n$ 与输入电压无关。这意味着**励磁电流峰值、磁通摆幅 $\Delta B$ 在整个输入范围内恒定**——这是一个很好的设计性质（与 Buck-Boost/反激不同）。

**功率守恒校验**：

$$P_{in}=V_g\cdot I_{in}=V_g\cdot i_{p,on}\cdot D=V_g\cdot\frac{nI_o}{\eta}\cdot D=\frac{nDV_gI_o}{\eta}=\frac{V_oI_o}{\eta}\quad✓$$

### 7.4 复位二极管 $D_1$ 、 $D_2$

励磁电流在 $t_{reset}=DT_s$ 内从 $i_{m,pk}$ 线性降到零，一周期平均值：

$$\boxed{I_{D1,avg}=I_{D2,avg}=\frac12\,i_{m,pk}\cdot\frac{DT_s}{T_s}=\frac12\,i_{m,pk}\,D}$$

**峰值**： $i_{m,pk}$ 量级（换流瞬间还要叠加漏感电流冲击）。

> **复位二极管的电流极小**（本案例仅约 0.1A）——这是双管正激的一个设计便利，可用小电流器件。

### 7.5 电容电流

**输出电容**：

$$I_{C,rms}\approx\frac{\Delta I_L}{2\sqrt3}$$

**输入电容**（原边是脉冲电流，只在 $DT_s$ 内流动）：

$$I_{Cin,rms}=i_{p,on}\sqrt{D(1-D)}=I_{in}\sqrt{\frac{1-D}{D}}$$

> **推导**：输入电流是幅值 $i_{p,on}$ 、占空比 $D$ 的脉冲。 $I_{in,avg}=i_{p,on}D$ ， $I_{in,rms}=i_{p,on}\sqrt D$ ，故
> $$I_{Cin,rms}=\sqrt{I_{in,rms}^2-I_{in,avg}^2}=i_{p,on}\sqrt{D(1-D)}$$

## 八、磁芯复位原理

### 8.1 复位机制：为什么复位电压恰好是 $-V_g$

复位回路由 $D_1$ 、 $D_2$ 与原边绕组、 $V_g$ 源构成，把原边电压箝到 $-V_g$ （见 §4.2）。因此：

| 阶段 | $v_p$ | 时长 | 伏秒积 |
|---|---|---|---|
| 导通期 | $+V_g$ | $DT_s$ | $+V_gDT_s$ |
| 复位期 | $-V_g$ | $t_{reset}$ | $-V_g\,t_{reset}$ |

**复位完成的充要条件是伏秒积相消**：

$$V_gDT_s=V_g\,t_{reset}\quad\Longrightarrow\quad\boxed{t_{reset}=DT_s}$$

> **为什么可以这么简洁？** 因为**复位电压的幅值恰好等于输入电压的幅值**。励磁电流的上升斜率与下降斜率大小完全相等（都是 $V_g/L_m$ ），所以"升多久就降多久"。

### 8.2 最大占空比 $D_{max}=0.5$ 的严格推导

复位必须在下一个导通期到来之前结束：

$$t_{reset}=DT_s\le(1-D)T_s\quad\Longrightarrow\quad\boxed{D\le0.5,\quad D_{max}=0.5}$$

> **⚠️ 适用范围**： $D_{max}=0.5$ **不是所有正激变换器的普适结论**，它只适用于"复位电压被 $D_1$/$D_2$ 箝到 $-V_g$"的**经典双管正激**。
> - 单管正激若采用**复位绕组**，复位电压为 $(N_p/N_r)V_g$ ，取 $N_r<N_p$ 即可让复位更快， $D$ 可 >0.5
> - **有源钳位正激（ACF）** 用钳位电容复位， $D$ 同样可 >0.5

### 8.3 实际设计为什么要留复位裕量

理论上 $D$ 可取到 0.5，但工程上通常取 **$D_{max}=0.40\sim0.45$**：

1. **复位电流的"尾巴"**——漏感与寄生电容会让 $i_m$ 的过零时刻滞后于理想值
2. **参数漂移**——$f_s$ 容差、 $\Delta B$ 随温度变化、铁氧体 $B_{sat}$ 高温下降
3. **输入电压波动与瞬态**——输入跌落时环路会把 $D$ 顶到极限，若极限就在 0.5 附近，动态过程中容易越界
4. **避免"临界饱和"**——$D$ 恰好 0.5 时复位时间被榨干，任何扰动都可能让磁通偏高，长期运行温升叠加

### 8.4 如果超过 0.5 会怎样

**磁通逐周期累积**：设 $D>0.5$ ，每周期励磁电流上升 $V_gDT_s/L_m$ 、下降 $V_g(1-D)T_s/L_m$ ，而 $t_{off}=(1-D)T_s<DT_s$——**在 $i_m$ 降到零之前下一周期就开始了**，于是每周期净增：

$$\Delta i_{m,net}=\frac{V_g}{L_m}\left[DT_s-(1-D)T_s\right]=\frac{V_g}{L_m}(2D-1)T_s>0$$

对应磁通每周期净增：

$$\Delta\phi_{net}=\frac{V_g(2D-1)T_s}{N_p}$$

**后果链条**：

```
磁通起点逐周期抬高 → 工作点上移
→ 峰值磁密触及 B_sat → 磁芯饱和
→ 原边励磁电感崩塌（L_m→极小，只剩漏感）
→ 原边电流暴增（等效直通）
→ 开关管过流、D1/D2 过流、变压器高温 → 器件损坏
```

> **方向性要点**：这个"走磁"是**单方向累积**的（不是振荡），**不会自己稳定下来**。
>
> 反过来说：**只要设计上守住 $D<0.5$ 并留裕量，机制上就不会跑偏**——这正是双管正激**不需要偏磁检测与校正电路**的原因（对比推挽的偏磁高风险）。但一旦设计失误越过 0.5，**靠闭环也无法挽回**。

### 8.5 与三种复位机制的对照

| 复位机制 | $D$ 上限 | 是否需要额外器件 | 漏感能量 |
|---|---|---|---|
| **双管正激（ $D_1$/$D_2$ 箝位）** | **0.5** | 2 只小电流二极管 | **回馈输入** ★ |
| 单管正激（复位绕组） | $\dfrac{1}{1+N_p/N_r}$ （可 >0.5） | 复位绕组 + 1 只二极管 | 需 RCD 吸收 |
| 有源钳位正激（ACF） | 可 >0.5 | 1 管 + 1 电容 | 回馈（且可 ZVS）★ |

## 九、器件电压应力

### 9.1 理论最大应力

| 器件 | 应力 | 表达式 | 本案例（ $V_{g,max}=60\text{V}$ ， $n=0.75$ ） |
|---|---|---|---|
| $Q_1$ / $Q_2$ | $V_{DS}$ | $\boxed{V_{g,max}}$ | **60V** |
| $D_1$ / $D_2$ | $V_R$ | $\boxed{V_{g,max}}$ | **60V** |
| $D_3$ / $D_4$ | $V_R$ | $\boxed{nV_{g,max}=\dfrac{V_o}{D_{min}}}$ | **45V** |
| 输出电感/电容 | 电压 | $V_o$ | 12V |

> **$D_3$/$D_4$ 的应力恒大于 $2V_o$**：因为 $nV_{g,max}=V_o/D_{min}$ ，而 $D_{min}<0.5$ → $V_o/D_{min}>2V_o$ 。
> **这是 $D_{max}=0.5$ 约束的连带代价**——副边二极管被迫选高耐压器件。

### 9.2 寄生参数附加应力

| 来源 | 附加量级 | 机理 |
|---|---|---|
| **漏感振铃** | 较小 ★ | $L_k$ 与 $C_{oss}$ 、结电容谐振，但被 $D_1$/$D_2$ **自箝位**在 $V_g$ 附近 |
| PCB 寄生电感 | 数 V | 换流回路面积决定 |
| 二极管反向恢复 | 加剧振铃 | $D_3$/$D_4$ 的反向恢复电流经变压器反射到原边 |

> **★ 相对单管正激的重大优势**：单管正激的漏感能量只能靠 RCD 烧掉，尖峰可达 $2V_g$ 级以上；双管正激被箝在 $V_g$ 上下一个二极管压降内。

### 9.3 安全裕量与额定值

$$V_{DS,rated}>V_{g,max}+V_{spike}$$

本案例： $V_{g,max}=60\text{V}$ ，复位期叠加二极管压降与振铃后实测峰值约 $70\sim80\text{V}$ → 选 **100V** 档（峰值占额定 70%~80%，留 20%~30% 裕量）。

> **⚠️ 强制要求**： $V_{spike}$ 无法只靠公式确定，**只能通过示波器实测 $V_{DS}$ 波形**（探头短地弹簧、最小环路、满负载 + 最高输入电压 + 最恶劣工况）确认，再对漏感、吸收、布板做迭代。

## 十、器件电流应力

### 10.1 理论电流（本案例， $n=0.75$ ， $I_o=10\text{A}$ ， $D\in[0.267,0.444]$ ， $\eta=0.92$ ）

$i_{p,on}=\dfrac{nI_o}{\eta}=\dfrac{0.75\times10}{0.92}=8.15\text{A}$

| 器件 | 平均值 | 有效值 | 峰值 |
|---|---|---|---|
| $Q_1$/$Q_2$ （每只） | $i_{p,on}D=3.6\text{A}$ | $8.15\sqrt{0.444}=5.43\text{A}$ | $\approx8.9\text{A}$ |
| $D_1$/$D_2$ （每只） | $\tfrac12i_{m,pk}D=0.10\text{A}$ | — | ≈0.43A |
| $D_3$ （整流） | $DI_o=4.4\text{A}$ | $I_o\sqrt{D}=6.7\text{A}$ | $i_{L,pk}=11.3\text{A}$ |
| $D_4$ （续流） | $(1-D)I_o=5.6\text{A}$ | $I_o\sqrt{1-D}=7.5\text{A}$ | $i_{L,pk}=11.3\text{A}$ |
| 输出电感 $L$ | $I_o=10\text{A}$ | $\approx10\text{A}$ | 11.3A |
| 输出电容 $C$ | 0 | $\dfrac{\Delta I_L}{2\sqrt3}=0.77\text{A}$ | — |
| 输入电容 $C_{in}$ | 0 | $8.15\sqrt{0.444\times0.556}=4.1\text{A}$ | — |

> **★ 两管流过同一电流**： $Q_1$ 、 $Q_2$ **串联**在原边回路中，**每只都流过全部原边电流** → 总导通损耗是两管之和。
>
> 这与推挽（两管分流、各承担一半）形成鲜明对比——**双管正激用"2 只管子"并没换来"电流减半"**，换来的是**电压应力减半 + 漏感能量回馈**。

### 10.2 器件损耗

**MOSFET**

$$P_{Q,cond}=2\times I_{Q,rms}^2R_{DS(on)}(T_j)$$
$$P_{Q,sw}\approx2\times\frac12V_{DS}I_{Q,pk}(t_r+t_f)f_s$$
$$P_{Q,drive}=2Q_gV_{gs}f_s$$

> **双管正激不是软开关**：开通过程中 $C_{oss}$ 的能量被耗散、关断过程电压电流交叠，因此开关损耗与 $f_s$ 成正比。选频率时要在"磁芯/滤波体积"与"开关损耗"之间权衡。

**复位二极管**

$$P_{D1}=P_{D2}=V_F\cdot I_{D,avg}\quad(\text{极小，可忽略})$$

**副边二极管**

$$P_{D3}+P_{D4}=V_F\cdot I_o\quad(\text{与 }D\text{ 无关！})$$

> **★ 这是一个漂亮的性质**： $P_{D3}+P_{D4}=V_F(DI_o)+V_F(1-D)I_o=V_FI_o$——**副边二极管总损耗只取决于 $V_F$ 与 $I_o$ ，与占空比无关**。改变 $D$ 只是把损耗在 $D_3$ 与 $D_4$ 之间搬来搬去，**但 $D_4$ 始终更重**（因为 $D<0.5$ ），热设计要重点照顾它。

## 十一、高频变压器设计

### 11.1 匝数比

$$\boxed{n\ge\frac{V_o}{D_{max}\,V_{g,min}}}$$

**设计方法**：用**最低输入电压 + 最大占空比**定 $n$ （保证最恶劣工况还能顶出额定输出），再用**最高输入电压**反算 $D_{min}$ 做校核：

$$D_{min}=\frac{V_o}{nV_{g,max}}$$

要求 $D_{min}$ 不至于过小（一般 $\ge0.1\sim0.15$ ，否则控制范围过窄、二极管导通时间过短、CCM 难保证）。

本案例： $n\ge\dfrac{12}{0.45\times36}=0.74$ → 取 $n=0.75$ 。

校验： $D_{max}=12/(0.75\times36)=0.444$ ✓（≤0.45）； $D_{min}=12/(0.75\times60)=0.267$ ✓（≥0.15）

### 11.2 磁芯选择

**单端工作导致的利用率问题（关键）**：磁通只在第一象限变化，工作区间为

$$B_r\longrightarrow B_r+\Delta B$$

其中 $B_r$ 是复位点（ $H=0$ 时的剩余磁密）。因此限制条件是

$$\Delta B\le B_{sat}(T)-B_r-\text{裕量}$$

而双端拓扑（全桥/推挽）磁通在 $\pm B_{sat}$ 之间对称摆动，可用 $\Delta B\approx2B_{sat}$ 。

> **所以同功率下正激的磁芯体积约是全桥的 2 倍**——这是单端拓扑的固有代价。

**选型方法**：工程上常用**面积积法（AP 法）**估算后迭代；更实用的是**先按经验选型（EE/PQ 系列对应功率的常规型号），再用 $\Delta B$ 校核**。

本案例：选 PC40 材质 **EE33**， $A_e=119\text{mm}^2$ ， $A_w=133.6\text{mm}^2$ ， $A_P\approx1.59\text{cm}^4$ 。

### 11.3 原边匝数（★ 重要修正）

**物理意义**： $v_p=N_pA_e\dfrac{\mathrm{d}B}{\mathrm{d}t}$——在给定的 $\Delta B$ 与 $A_e$ 下，匝数决定"能承受多少伏秒"。

导通期 $v_p=V_g$ ，持续 $DT_s$ ：

$$\Delta B=\frac{V_g\,DT_s}{N_pA_e}=\frac{V_gD}{N_pf_sA_e}$$

反解：

$$\boxed{N_p\ge\frac{V_gD\,T_s}{\Delta B_{allow}A_e}=\frac{(V_o/n)\,T_s}{\Delta B_{allow}A_e}}$$

> **★★ 关键： $V_gD=V_o/n$ 是常数，与输入电压无关！**
>
> 因为 $V_o=nDV_g$ ，所以 $V_gD=V_o/n$ 在整个输入范围内恒定。**这意味着磁通摆幅 $\Delta B$ 与输入电压无关**——伏秒积最恶劣点就是 $V_o/n$ ，不需要按 $V_{g,max}D_{max}$ 计算。
>
> **⚠️ 常见错误**：若写成 $N_p\ge\dfrac{V_{g,max}D_{max}}{\Delta Bf_sA_e}$ ，会多算 $V_{g,max}D_{max}/(V_o/n)$ 倍。本案例中该比值为 $60\times0.45/16=1.69$——**磁芯被白白放大 1.7 倍**，浪费窗口面积与铜损。

本案例（ $\Delta B_{allow}=0.2\text{T}$ ， $V_o/n=16\text{V}$ ）：

$$N_p\ge\frac{16\times10\times10^{-6}}{0.2\times119\times10^{-6}}=\frac{160\times10^{-6}}{23.8\times10^{-6}}=6.72\to\boxed{N_p=8\ \text{匝}}$$

> 取 8 匝（而非 7 匝）是为了让副边匝数能配出整数倍的 $n=0.75$ 。

反算实际摆幅： $\Delta B=\dfrac{16\times10\times10^{-6}}{8\times119\times10^{-6}}=0.168\text{T}$ ✓（留有裕量）

> **设计校核链**： $\Delta B$ 超限 → 增大 $N_p$ （但窗口紧张、铜损上升）→ 或换更大 $A_e$ 的磁芯 → 或提高 $f_s$ 。

**$\Delta B$ 、 $B_{max}$ 与饱和的关系**：

- $B_{sat}$ ：材料饱和磁密，**随温度升高而下降**（PC40 从 25°C 的 0.51T 降到 100°C 的约 0.39T）
- $B_r$ ：剩余磁密， $H=0$ 时的磁密，铁氧体约 0.1T 量级
- **复位点在 $B_r$ 附近，峰值是 $B_r+\Delta B$**，所以真正可用的是 $\Delta B_{allow}=B_{sat}(T)-B_r-\text{裕量}$
- 裕量必须预留：磁芯批次差异、温度、瞬态过冲、 $D$ 的短时越界风险

### 11.4 副边匝数

$$\boxed{N_s=nN_p}$$

本案例： $0.75\times8=6$ 匝。

**必须重新校核**（匝数取整会改变实际 $n$ ）：

$$n_{real}=\frac{N_s}{N_p}=\frac{6}{8}=0.75\ ✓,\qquad D_{max}=\frac{V_o}{n_{real}V_{g,min}}=0.444\ ✓$$

> 若取整后 $D$ 超出上限，应微调 $N_p$ 或 $N_s$ ，或放宽 $\Delta B$ 后复核。

### 11.5 绕组线径与结构

**绕组电流**：

$$I_{p,rms}\approx\frac{nI_o}{\eta}\sqrt{D},\qquad I_{s,rms}\approx I_o\sqrt{D}$$

本案例： $I_{p,rms}\approx5.43\text{A}$ ， $I_{s,rms}\approx6.67\text{A}$ 。

**电流密度**：自然冷却 $J=3\sim4\text{A/mm}^2$ ，强制风冷 $J=4\sim6\text{A/mm}^2$ 。

$$S_{p,min}=\frac{I_{p,rms}}{J},\qquad S_{s,min}=\frac{I_{s,rms}}{J}$$

本案例（ $J=4$ ）： $S_p\approx1.36\text{mm}^2$ ， $S_s\approx1.67\text{mm}^2$ 。

**集肤深度**（铜，20°C）：

$$\delta\approx\frac{66}{\sqrt{f_s}}\ \text{mm}\ (f_s\text{ 单位 Hz})$$

本案例： $100\text{kHz}\Rightarrow\delta\approx0.21\text{mm}$ → 单根漆包线线径应 $\lesssim2\delta\approx0.42\text{mm}$ ，更粗时必须**多股并绕**或**用铜箔**。

**结构安排**：

1. **三明治绕法**（原边一半—副边—原边一半）可显著降低漏感与邻近效应损耗——这是**降低漏感尖峰最有效的设计手段**
2. 副边大电流用**铜箔**或**多股细线并绕**
3. 窗口填充系数一般取 $K_u\approx0.3\sim0.4$

**绝缘与安规**：原副边之间需满足爬电距离/电气间隙要求；必要时用三层绝缘线、加屏蔽层（降低共模 EMI）、骨架加档墙。

## 十二、输出滤波电感设计

### 12.1 电感量（★ 重要修正）

导通期 $v_L=nV_g-V_o$ ，持续 $DT_s$ ；续流期 $v_L=-V_o$ ，持续 $(1-D)T_s$ 。稳态下：

$$\Delta I_L=\frac{(nV_g-V_o)\cdot D}{Lf_s}$$

代入 $V_o=nDV_g$ 简化：

$$\boxed{\Delta I_L=\frac{V_o(1-D)}{Lf_s}}$$

**设计取值**（令 $\Delta I_L=kI_o$ ）：

$$\boxed{L=\frac{V_o(1-D)}{f_s\,\Delta I_L}=\frac{V_o(1-D)}{k\,I_of_s}}$$

> **★★ 取哪个工况？必须取 $D_{min}$ （最高输入）！**
>
> 因为 $\Delta I_L\propto(1-D)$——**$D$ 越小、续流时间越长、纹波越大**。所以最恶劣工况是**最高输入电压**（ $D_{min}$ ）。
>
> **⚠️ 常见错误**：若误按 $D_{max}$ 计算，电感会偏小，导致最高输入时纹波超标。本案例中 $\dfrac{1-D_{min}}{1-D_{max}}=\dfrac{0.733}{0.556}=1.32$——**电感偏小 32%，纹波超标 32%**。

本案例（ $k=30\%\to\Delta I_L=3\text{A}$ ， $D_{min}=0.267$ ）：

$$L=\frac{12\times(1-0.267)}{10^5\times3}=\frac{8.8}{3\times10^5}=29.3\mu H\to\boxed{L=33\mu H}$$

**校核**（取 33µH 后）：

| 工况 | $D$ | $\Delta I_L$ | 纹波率 |
|---|---|---|---|
| $V_{g,min}=36\text{V}$ | 0.444 | $\dfrac{12\times0.556}{33\mu\times10^5}=2.02\text{A}$ | 20% |
| $V_{g,max}=60\text{V}$ | 0.267 | $\dfrac{12\times0.733}{33\mu\times10^5}=2.67\text{A}$ | **27%** ✓ |

两种工况都在 30% 目标内 ✓

> **$k=20\%\sim40\%$ 的说明**：这是**工程经验范围，不是固定规则**。 $k$ 小（电感大）→ 纹波小、CCM 范围宽，但体积大、动态响应慢； $k$ 大（电感小）→ 体积小、响应快，但纹波与铜损上升、轻载易进 DCM。低压大电流输出常用较小的 $k$ 。

### 12.2 电流与磁芯

| 参数 | 公式 | 本案例 |
|---|---|---|
| 峰值电流 | $I_{L,pk}=I_o+\dfrac{\Delta I_L}{2}$ | 11.3A |
| RMS 电流 | $\approx I_o$ | ≈10A |
| 储能 | $\tfrac12LI_{pk}^2$ | 2.1mJ |

**CCM 临界条件**：

$$L_{crit}=\frac{V_o(1-D)}{2I_of_s}$$

本案例： $L_{crit}=\dfrac{12\times0.733}{2\times10\times10^5}=4.4\mu H$ （按 $D_{min}$ 算）→ 设计值 33µH 远大于它，CCM 可维持到约 1.3A（13% 负载）✓

**磁芯与饱和裕量**：滤波电感**必须开气隙**（储能、防饱和）。推荐**粉芯**（铁硅铝 Sendust／铁镍钼）或铁氧体 + 气隙。

- 饱和电流校验： $I_{sat}>I_{L,pk}\times(1.2\sim1.3)$
- 峰值磁密校验： $B_{pk}=\dfrac{LI_{L,pk}}{N_LA_e}\le B_{sat}$ （粉芯按软饱和曲线取值）
- 匝数： $N_L=\sqrt{L/A_L}$ （ $A_L$ 为磁芯电感系数）

> **⚠️ DCM 提醒**：轻载进入 DCM 后，传输关系不再是 $V_o=nDV_g$ （变为与负载有关的非线性关系），环路增益与动态特性都会变化。若要求全负载范围 CCM，需按最小负载电流校核 $L$ ；若允许 DCM，则要重新设计补偿器。

## 十三、电容设计

### 13.1 输出电容

**容值（充放电纹波）**：

$$\Delta V_C\approx\frac{\Delta I_L}{8f_sC}\quad\Longrightarrow\quad\boxed{C\ge\frac{\Delta I_L}{8f_s\Delta V_C}}$$

**ESR 纹波**：

$$\Delta V_{ESR}\approx\Delta I_L\cdot ESR$$

**总输出纹波**（两项算术相加，工程上偏保守）：

$$\boxed{\Delta V_o\approx\frac{\Delta I_L}{8f_sC}+\Delta I_L\cdot ESR}$$

本案例（ $\Delta V_o\le1\%\times12\text{V}=120\text{mV}$ ， $\Delta I_L=2.67\text{A}$ @$D_{min}$ ）：

- 全部由 ESR 承担时： $ESR\le120\text{mV}/2.67\text{A}\approx45\text{m}\Omega$
- 取 $ESR\le15\text{m}\Omega$ （分配 40mV 给 ESR），余下 80mV 给容值 → $C\ge\dfrac{2.67}{8\times10^5\times0.08}=42\mu F$
- 实际取 **2×220µF/25V 低 ESR 电解 + 2×10µF MLCC**，兼顾容值、ESR 与高频旁路

### 13.2 选型逻辑

| 考量 | 说明 |
|---|---|
| 耐压 | 额定 ≥ $1.5\times V_o$ （12V 输出常用 25V 档） |
| **RMS 纹波电流** | $\approx\Delta I_L/\sqrt{12}$ （本案例 ≈0.77A），必须小于电容额定额定值（含频率修正与温度降额）——**电解电容最容易踩的坑** |
| ESR | 决定纹波电压与自发热；多只并联可同时降低 ESR 与分流纹波电流 |
| ESL | 影响高频纹波与环路；MLCC 就近放置可抑制 |
| 温升与寿命 | 电解电容寿命按"每升 10°C 减半"估算，纹波电流自发热直接决定寿命 |
| 类型 | **电解**：容值大、成本低、ESR 与寿命受限；**固态/聚合物**：ESR 低、寿命长、成本高；**MLCC**：ESL 极低、高频好、容值受直流偏压影响大 |

### 13.3 输入电容

原边电流是**脉冲电流**（只在 $DT_s$ 内流动），输入电容必须提供其交流分量，抑制输入电压纹波与传导 EMI：

$$I_{Cin,rms}=I_{in}\sqrt{\frac{1-D}{D}}=i_{p,on}\sqrt{D(1-D)}$$

本案例： $I_{in}=\dfrac{120}{0.92\times36}=3.6\text{A}$ ， $D=0.444$ → $I_{Cin,rms}\approx4.1\text{A}$ 。

**容值**（限输入电压纹波）：

$$C_{in}\ge\frac{i_{p,on}\cdot D\,T_s}{\Delta V_g}$$

**选型**：多只低 ESR 电解/MLCC 并联（如 4×47µF/100V 高频低阻 + 2×1µF MLCC），并**就近紧贴 $Q_1$ 漏极与 $Q_2$ 源极**——这一点的布板意义甚至大于容值本身（见 §十四）。

## 十四、关键工程问题

### 14.1 漏感尖峰与"自箝位"特性

- 关断瞬间，漏感电流经 $D_1$/$D_2$ 灌入输入源，**能量回收**
- 但换流过程是**振铃过程**： $L_k$ 与 $C_{oss}$ 、二极管结电容形成高频谐振，在 $V_{DS}$ 上表现为尖峰 + 振铃
- 由于 $D_1$/$D_2$ 的箝位，尖峰上限被限制在 $V_g$ 之上一个二极管压降左右，**远优于单管正激的 $2V_g$ 级尖峰**
- 振铃频率与幅度取决于**换流回路寄生电感**与器件电容——这是布板与器件选择的战场

**降低尖峰的手段（按性价比排序）**：

1. **减小漏感**：变压器三明治绕法、增大耦合、缩短绕组间距离
2. **减小回路寄生电感**：原边换流回路面积最小化、多层板就近回流、电容紧贴开关管
3. **适度增大 $C_{oss}$**：降低振铃频率与峰值（代价：开关损耗上升）
4. **RC 缓冲**：万不得已时用于抑制副边振铃（原边通常不需要）
5. **降低 $\mathrm{d}i/\mathrm{d}t$**：增大栅极电阻（代价：开关损耗上升）

> **副边振铃**： $D_3$/$D_4$ 的反向恢复 + 副边漏感在副边节点上产生振铃，通过变压器反射到原边，是**共模 EMI 的主要来源**。对策：在 $D_3$/$D_4$ 两端加 RC 缓冲，或换用无反向恢复的肖特基/SiC/同步整流。

### 14.2 ★ 用同步整流时的最大陷阱

> **⚠️ 用 SR 时必须注意**
>
> 二极管是单向器件——$D_3$ 截止时副边绕组对原边"开路"，原边才能靠 $D_1$/$D_2$ 复位。
>
> 而 SR 用的 MOSFET **是双向导通**的：若续流 SR 在**复位期仍然导通**，它会把副边绕组短路 → 反射到原边把原边电压箝到 0 → **励磁电流无法下降 → 磁芯无法复位 → 逐周期偏磁 → 饱和**。
>
> **因此 SR 控制必须保证：原边复位期间关断续流 SR**（或只允许体二极管以单向方式工作）。**这是 SR 正激最容易翻车的地方。**

### 14.3 驱动设计

- $Q_2$ 源极接 $V_g^-$ ，**低边驱动**，最简单
- $Q_1$ 是**浮地高边**（参考节点 A，电位在 $0\sim V_g$ 间跳变），必须用以下之一：
  - **隔离驱动**（数字隔离器 + 隔离电源）——最可靠，推荐
  - **栅极驱动变压器**
  - **自举驱动**
- **⚠️ 自举方案的注意点**：自举二极管接 $V_g^+$ ，自举电容参考节点 A。节点 A 在**复位期** $\approx V_g^-$ （可充满至接近 $V_g$ ），但在**空闲期** $\approx V_g/2$ ，充电电压只剩一半。因此必须校核**复位期是否足够长**（ $t_{reset}=DT_s$ 足够给自举电容补电），否则栅极电压不足、 $R_{DS(on)}$ 上升甚至热失控。
- 两管必须**同相驱动**，驱动延迟差异尽可能小（尤其关断沿，避免一侧先断造成额外换流损耗）

### 14.4 PCB 布局

| 项目 | 要求 |
|---|---|
| 高 $\mathrm{d}i/\mathrm{d}t$ 回路①（斩波回路） | $V_g^+\to Q_1\to$ 原边 $\to Q_2\to V_g^-$ ：**面积最小**，用铜皮/多层平面就近回流 |
| 高 $\mathrm{d}i/\mathrm{d}t$ 回路②（复位回路） | $B\to D_1\to V_g^+\to C_{in}\to V_g^-\to D_2\to A$ ：同样紧凑， $D_1$/$D_2$ 紧靠开关管与输入电容 |
| 高 $\mathrm{d}v/\mathrm{d}t$ 节点 | 节点 A、节点 B、副边整流节点：铜面积尽量小（降低容性耦合），必要时加屏蔽或 RC |
| 输入电容位置 | 紧贴 $Q_1$ 漏极与 $Q_2$ 源极，先过电容再进开关管 |
| 栅极回路 | 驱动回路面积最小，开尔文源极接法，栅极电阻就近 |
| 电流采样 | 原边采样优于副边（电流小、地参考干净），采样回路不要串入换流回路 |
| 原副边隔离 | 满足安规爬电/电气间隙；变压器下方避免走线跨越隔离带；Y 电容位置与共模路径一起规划 |

### 14.5 EMI

| 来源 | 控制手段 |
|---|---|
| 原边换流振铃（差模） | 减小回路面积与漏感、RC 缓冲、优化栅极驱动速度 |
| 副边整流振铃（共模） | 无反向恢复二极管/SR、RC 缓冲、变压器屏蔽层、Y 电容 |
| 开关节点容性耦合 | 缩小高 $\mathrm{d}v/\mathrm{d}t$ 铜面积、加屏蔽 |
| 传导干扰 | 输入 EMI 滤波器（共模电感 + X/Y 电容），注意与输入电容的阻抗配合 |

| 器件 | 本案例损耗 | 备注 |

| $D_3$+$D_4$ | **≈5.0W** | **低压输出的第一大损耗项** |

## 十五、损耗与效率估算

### 15.1 损耗构成

$$P_{loss}=P_{Q,cond}+P_{Q,sw}+P_{Q,drv}+P_{D3}+P_{D4}+P_{D1}+P_{D2}+P_{Cu}+P_{core}+P_{other}$$

| 损耗项 | 公式 | 本案例 |
|---|---|---|
| $Q$ 导通 | $2I_{Q,rms}^2R_{DS(on)}\times1.5$ | $2\times5.43^2\times0.030\times1.5=2.7\text{W}$ |
| $Q$ 开关 | $2\times\tfrac12V_{DS}I_{Q,pk}(t_r+t_f)f_s$ | $2\times0.5\times80\times8.9\times60n\times10^5=4.3\text{W}$ |
| $Q$ 驱动 | $2Q_gV_{gs}f_s$ | ≈0.3W |
| 副边整流（肖特基 $V_F=0.5\text{V}$ ） | $V_FI_o$ | $0.5\times10=5.0\text{W}$ ★ |
| 副边整流（**同步整流**） | $I_{s,rms}^2\cdot2R_{DS(on),SR}$ | $6.67^2\times2\times0.005=0.45\text{W}$ |
| 变压器铜损 | $I_p^2R_p+I_s^2R_s$ | ≈2.2W |
| 电感铜损 | $I_o^2R_{DCR}$ | ≈1.0W |
| 磁芯铁损 | Steinmetz | ≈1.0W |
| 复位二极管 | $2V_FI_{D,avg}$ | ≈0.2W |
| 控制类 | — | ≈0.4W |
| **合计** | | **≈17.1W（二极管）/ 12.5W（SR）** |
| **效率** | $\eta=\dfrac{P_o}{P_o+P_{loss}}$ | **87.5% / 90.6%** |

> **★ 结论一眼看出**：
> - **副边整流是第一大损耗项**（5.0W，占 29%）——低压输出（12V 及以下）必须考虑**同步整流**，可把它从 5.0W 降到 0.45W，效率提升约 3 个百分点
> - **开关损耗是第二大项**（4.3W，占 25%）——双管正激不是软开关，且 $V_{DS}$ 较高（80V 峰值），这是硬开关拓扑的固有代价

### 15.2 效率优化优先级

1. **副边整流**（占比最大）→ **同步整流**（注意 §14.2 的复位陷阱）
2. **开关损耗** → 适当降低 $f_s$ 、选低 $Q_{gd}$/低 $C_{oss}$ 器件、优化驱动速度
3. **导通损耗** → 降低 $R_{DS(on)}$ （注意两管之和）
4. **铜损** → 三明治绕法、铜箔/多股、优化窗口
5. **磁芯损耗** → 低损材质（PC95 等）或适度降低 $\Delta B$

## 十六、完整设计实例

> **⚠️ 以下为教学设计案例，所有数值仅用于演示计算过程，不代表任何实际工程参数。器件型号仅为案例，参数以最新 Datasheet 为准。**

### 案例 C：48V 母线 → 12V/120W 隔离电源

> **场景说明**：本拓扑的**真正主场是高输入电压（300~400V 母线）**——那里"管子只承受 $V_g$"与"漏感能量回馈"两个优势最大化。
> 但为了与其余六篇笔记（同为 48V/36~60V 输入）**横向对照**，本案例仍采用低压输入。读者应自行体会：若把 $V_g$ 换成 375V， $n$ 、 $N_p$ 、 $N_s$ 、 $\Delta B$ 会如何变化，而"$V_{DS}=V_g$"这一优势会放大多少倍。

#### 16.1 设计指标

| 参数 | 符号 | 值 |
|---|---|---|
| 输入电压 | $V_g$ | 48V（范围 **36~60V**）※为便于与前六篇对照，此处仍用低压案例 |
| 输出电压 | $V_o$ | 12V |
| 输出功率 | $P_o$ | 120W（ $I_o=10\text{A}$ ， $R_o=1.2\Omega$ ） |
| 开关频率 | $f_s$ | 100kHz |
| 最大占空比 | $D_{max}$ | 0.45 |
| 效率目标 | $\eta$ | ≥90% |
| 输出纹波 | $\Delta V_o$ | ≤1%（120mV） |

#### 16.2 匝比与匝数

$$n\ge\frac{V_o}{D_{max}V_{g,min}}=\frac{12}{0.45\times36}=0.74\to\boxed{n=0.75}$$

**匝数**（ $\Delta B_{allow}=0.2\text{T}$ ，EE33 $A_e=119\text{mm}^2$ ）：

$$N_p\ge\frac{(V_o/n)T_s}{\Delta BA_e}=\frac{16\times10\mu s}{0.2\times119\text{mm}^2}=6.72\to\boxed{N_p=8\text{匝}},\quad N_s=6\text{匝}$$

**校验**： $n_{real}=6/8=0.75$ ✓； $\Delta B=16\times10\mu s/(8\times119\text{mm}^2)=0.168\text{T}$ ✓
**占空比**： $D_{max}=0.444$ （36V）✓， $D_{min}=0.267$ （60V）✓

#### 16.3 输出电感与电容

$$L=\frac{V_o(1-D_{min})}{f_s\,kI_o}=\frac{12\times0.733}{10^5\times3}=29.3\mu H\to\boxed{L=33\mu H}$$

校核： $\Delta I_L=2.67\text{A}$ （27%）@$D_{min}$ ✓、 $2.02\text{A}$ （20%）@$D_{max}$ ✓

要求： $I_{sat}\ge15\text{A}$ 、 $I_{rms}\ge10\text{A}$ 、直流偏置下感量跌落 ≤30%。铁硅铝磁芯。

**输出电容**： $C\ge42\mu F$ 、 $ESR\le15\text{m}\Omega$ 、纹波电流 ≥1.5A、耐压 ≥25V。
方案：2×220µF/25V 低 ESR 电解 + 2×10µF MLCC。

**输入电容**： $C\ge\dfrac{8.15\times0.444\times10\mu s}{\Delta V_g}$ ，取 4×47µF/100V 高频低阻 + 2×1µF MLCC（RMS 4.1A）。

## 十八、优缺点与适用场景

### 18.1 优点（逐条对应机理）

| 优势 | 机理 |
|---|---|
| ① MOSFET 耐压较低（ $\approx V_g$ ） | 复位期原边被箝到 $-V_g$ ，两管分处 $V_g^+$/$V_g^-$ 两端，各承担 $V_g$ |
| ② 漏感能量回馈输入 | $D_1$ 、 $D_2$ 构成双向箝位回路，漏感电流经 $V_g$ 源倒灌回输入端，**不需要 RCD** |
| ③ 磁芯自动复位 | 复位电压恒为 $-V_g$ ，无需复位绕组、无需复位控制 |
| ④ 不需要额外复位绕组 | 省一整套绕组与窗口面积，铜损更低、漏感更小 |
| ⑤ 无桥臂直通风险 | 两管串联、变压器夹中间，同时导通也不会短路 $V_g$ |
| ⑥ 适合中功率隔离电源 | 两管分摊热耗，无直通风险，可靠性高；**300W~1kW 是甜点区** |

### 18.2 缺点（逐条对应机理与应对）

| 缺点 | 机理与应对 |
|---|---|
| ① 管子数量增加 | 2 管 + 2 路驱动，成本与布板面积上升 |
| ② **$Q_1$ 浮地高边，驱动复杂** ★ | 需隔离驱动/自举；**自举时还要校核复位期是否够长** |
| ③ 两管共同承担原边电流 | 导通损耗为两只之和 $2I_{p,rms}^2R_{DS(on)}$ ，需选低 $R_{DS(on)}$ |
| ④ $D_{max}=0.5$ 硬约束 | 匝比 $n$ 被迫偏大 → 原边电流大、副边二极管应力 $>2V_o$ |
| ⑤ 磁芯利用率低 | 单端工作，磁芯体积约为双端拓扑的 2 倍 |
| ⑥ 副边二极管损耗占比高 | $V_FI_o$ 与 $D$ 无关；低压输出时是第一大损耗项 → 上 SR |
| ⑦ PCB 布局要求高 | 原边换流回路、复位回路、栅极回路面积必须最小化 |
| ⑧ 高 $\mathrm{d}i/\mathrm{d}t$ 、 $\mathrm{d}v/\mathrm{d}t$ → EMI | 换流点振铃是主要干扰源，需要缓冲与屏蔽 |

### 18.3 适用场景结论

> **在"高输入电压（>200V）+ 中功率（300W~1kW）"的条件下，双管正激更合适**——它用 2 只管子换来了最低的电压应力（ $V_g$ ）、**漏感能量回馈**（无需 RCD）、以及**无桥臂直通的可靠性**。
>
> **代价是**： $D\le0.5$ 限制了输入范围与匝比、磁芯利用率只有双端拓扑的一半、副边二极管应力 $>2V_o$ 。
>
> **如果要宽输入范围（需要 $D>0.5$ ）**，就必须改用**有源钳位正激（ACF）**——它同样能回馈漏感能量，还能实现 ZVS。

## 十九、与相近拓扑比较

### 19.1 双管正激 vs 单管正激

| 对比项 | 单管正激（复位绕组） | **双管正激** | 工程含义 |
|---|---|---|---|
| 开关数量 | 1 | 2 | 双管成本高、驱动多一路 |
| 复位方式 | 复位绕组 + 二极管，复位电压 $-(N_p/N_r)V_g$ | $D_1$ 、 $D_2$ 箝位，复位电压 $-V_g$ | 双管**不需要复位绕组** |
| MOSFET 耐压 | $V_g\left(1+\dfrac{N_p}{N_r}\right)$ ，常取 $2V_g$ 以上 | $\approx V_g$ | **双管可用更低耐压、更低 $R_{DS(on)}$ 的器件** |
| 最大占空比 | $D<\dfrac{1}{1+N_p/N_r}$ ，取 $N_r<N_p$ 可 >0.5 | $D\le0.5$ （**硬约束**） | 单管输入范围更宽，双管更"憋" |
| 漏感能量处理 | **需 RCD 吸收**，能量以热耗散 | 经 $D_1$ 、 $D_2$ **回馈输入** | **双管效率优势的主要来源** |
| 驱动复杂度 | 低边驱动，简单 | 一路低边 + 一路**浮地/隔离**驱动 | 单管更简单 |
| 器件成本 | 低（1 管）或中（含 RCD） | 中（2 管 + 2 驱动） | 小功率单管胜，中高功率双管胜 |
| EMI | 有 RCD 的耗散型尖峰，环路大 | 尖峰被箝位但换流更剧烈 | 双管需更严谨的布板 |
| 适用功率 | 几十瓦 ~ 300W | **300W ~ 1kW**（可更高） | 交叉区按成本与效率目标取舍 |
| 典型应用 | 小功率适配器、辅助电源 | 通信/工业电源、高压母线中功率隔离电源 | — |

> **工程取舍结论**：不存在"谁绝对更好"。
> - **输入电压高、功率中上、效率与可靠性优先** → 双管正激
> - **输入电压低、功率小、成本极致敏感** → 单管正激
> - **需要 $D>0.5$ 的宽输入范围** → 有源钳位正激（ACF）

### 19.2 正激 vs 反激：能量传递机制

**正激（含双管正激）——导通期直接传输**：

$$V_g\to\text{Transformer}\to\text{Rectifier}\to L\to\text{Load}$$

变压器是"透明的"——同时传输能量、完成隔离与变比；**输出电感 $L$ 是重要储能元件**，负责在关断期给负载续流。

**反激——导通期储能、关断期释放**：

$$V_g\to L_m\ (\text{储能为 }\tfrac12L_mi_{pk}^2)\quad\Rightarrow\quad\text{关断后经副边二极管释放}$$

副边电容承担了"续流储能"的角色，**输出端通常不需要滤波电感**。

> **一句话本质区别**：**正激的变压器主要承担隔离与电压变换；反激的变压器（磁化电感）承担主要储能功能**——反激变压器本质上是一个"耦合电感"。

| 对比项 | 正激（含双管正激） | 反激 |
|---|---|---|
| 能量传输时刻 | 开关导通期**直接**传递 | 开关关断期释放 |
| 变压器角色 | 隔离 + 变压（**不储能**） | 耦合电感（**主要储能**） |
| 输出滤波电感 | **必需**，是主要储能元件 | 通常不需要 |
| 磁芯利用 | 单端，利用率低（ $0\sim\Delta B$ ） | 单端，但磁芯带气隙储能 |
| 输出电流能力 | 强（可由电感平滑大电流） | 弱（纹波大、峰值电流高） |
| 功率范围 | 数十瓦 ~ 千瓦级 | 数瓦 ~ 100W 级 |
| 输出纹波 | 小（LC 二阶滤波） | 较大（靠电容吸收） |
| 变压器气隙 | 一般**不开**气隙（增大 $L_m$ ） | **必须开**气隙（防饱和、储能） |
| 典型应用 | 工业/通信/适配器中高功率 | 小功率充电器、辅助电源 |

### 19.3 与其他隔离 Buck 拓扑的横向比较

| 维度 | **双管正激** | 半桥 | 全桥 | 推挽 |
|---|---|---|---|---|

| 设计条件 | 更合适的拓扑 | 原因 |

## 二十一、学习总结

### 21.1 一句话记住这个拓扑

> **双管正激 = 两只管子把变压器原边「夹」在中间，同开同关。**
> 关断时 $D_1$ 、 $D_2$ 把原边箝到 $-V_g$ 完成复位并把漏感能量**送回电源**。
> 收益：管子只承受 $V_g$ 、不需要 RCD、无桥臂直通、无偏磁。
> 代价： $D\le0.5$ 、磁芯大、副边二极管应力 $>2V_o$ 、 $Q_1$ 浮地驱动。

### 21.2 五个必须刻在脑子里的数

| 数 | 值 | 来源 |
|---|---|---|
| 电压传输比 | $nD$ | 隔离 Buck |
| **最大占空比** | $\mathbf{0.5}$ | 复位电压幅值 = 输入电压幅值 → $t_{reset}=DT_s$ |
| **开关管电压应力** | $\mathbf{V_g}$ | 两管分处电源两端，复位电压被分摊 |
| 副边二极管应力 | $\dfrac{V_o}{D_{min}}>2V_o$ | $D<0.5$ 的连带代价 |
| **伏秒积 $V_gD$** | $\mathbf{=V_o/n}$ ，**常数** | 与输入电压无关 → 磁通摆幅恒定 |

### 21.3 三个"为什么"

**Q1：为什么 $D$ 不能超过 0.5？**
A：因为关断期励磁电流的下降斜率与导通期的上升斜率**大小相等**（复位电压幅值恰好等于输入电压幅值，都是 $V_g$ ），所以"升多久就得降多久"——$t_{reset}=DT_s$ 。而一个周期只有 $D T_s$ 的导通时间和 $(1-D)T_s$ 的关断时间，要容纳 $DT_s$ 的复位时间就得 $D\le0.5$ 。**若超过，励磁电流每周期净增，磁通单向累积直到饱和。**

**Q2：为什么两只管子只承受 $V_g$ ，而单管正激要承受 $2V_g$ ？**
A：因为**连接方式不同**。单管正激的管子在一侧，复位时绕组电压与输入电压**串联叠加**在管子上（ $V_g + V_g = 2V_g$ ）。双管正激的两只管子**分处电源的上下两端**，关断时节点 A 被 $D_2$ 箝到 $V_g^-$ 、节点 B 被 $D_1$ 箝到 $V_g^+$——**复位电压被"分摊"到了电源两端**，每只管子各自只承担 $V_g$ 。

**Q3：为什么 $Q_1$ 的驱动必须隔离（或用自举）？**
A：因为 $Q_1$ 的源极是**节点 A**，它的电位在 $0\sim V_g$ 之间跳变（导通期 $=V_g^+$ 、复位期 $=V_g^-$ 、空闲期 $\approx V_g/2$ ）——**不是地电位**。常规低边驱动无法直接驱动它，必须用隔离驱动（数字隔离器+隔离电源）或自举电路把驱动信号的参考点"抬"到节点 A。
> **自举的坑**：自举电容靠节点 A 电位低时充电。但节点 A 只在**复位期**和**空闲期**低位，而空闲期电位是 $V_g/2$ （不是 $V_g^-$ ）——**充电电压只剩一半**。因此必须校核复位期 $t_{reset}=DT_s$ 是否足够给自举电容补电。

### 21.4 学完之后你应该能

- [ ] 看到"两只管子把变压器夹中间 + 两只交叉接的二极管"立刻认出双管正激
- [ ] 画出三个阶段（导通/复位/空闲）的电流路径与状态表
- [ ] 独立完成伏秒平衡推导 $V_o=nDV_g$ 与复位推导 $D\le0.5$
- [ ] 说清"复位电压被分摊到电源两端"为什么使 $V_{DS}=V_g$
- [ ] 用 $V_gD=V_o/n$ （常数）正确计算原边匝数
- [ ] 用 $D_{min}$ 正确设计输出电感
