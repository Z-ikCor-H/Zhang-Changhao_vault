## 一、拓扑概述

### 1.1 拓扑名称与归类

**双管正激变换器**（Two-Transistor Forward Converter，2TFC），亦称**双开关正激变换器**。

它属于**隔离型 Buck 类 DC-DC 变换器**：功率链路 = 斩波（ $Q_1$ 、 $Q_2$ ）+ 高频变压器隔离变压（ $1:n$ ）+ 单端正激整流（ $D_3$ 、 $D_4$ ）+ LC 低通滤波。变压器的任务是**隔离与电压变换**（不是储能），输出电感才是储能元件——这两点决定了它和反激的本质区别（见 §八）。

### 1.2 原理图解读（以原理图为准）

阅读本图的关键是**别被画法骗了**。 $D_1$ 、 $D_2$ 在图上竖向叠画在同一列，很容易被误读成"跨接在 $V_g$ 上串联的两只二极管"。实际连接关系必须逐点核对：

| 节点 | 图上位置 | 连接的实际器件 |
| --- | --- | --- |
| 顶部母线 | 上横线 | $V_g$ 正端、 $Q_1$ 漏极、 $D_1$ **阴极** |
| 节点 A（原边同名端） | 原边上端（打点处） | $Q_1$ **源极**、原边绕组打点端、 $D_2$ **阴极** |
| 节点 B（原边非同名端） | 原边下端 | $Q_2$ **漏极**、原边绕组非打点端、 $D_1$ **阳极** |
| 底部母线 | 下横线 | $V_g$ 负端、 $Q_2$ **源极**、 $D_2$ **阳极** |

**图上的"跨线半圆"（hop）**： $D_2$ 的阴极引线向上走，在原边下端那条横线上画了一个不连通的半圆跳线，然后继续上行接节点 A。这表示 **$D_2$ 阴极与节点 B 之间不连通**——$D_1$ 阳极只接节点 B， $D_2$ 阴极只接节点 A。

**四只器件的连接清单（原文核实结论）**：

1. $Q_1$ 、 $Q_2$ 均为 **N 沟道 MOSFET**，符号中体二极管箭头自源极指向沟道（源极朝向 $V_g^+$ 侧的那只管为 $Q_1$ ）；
2. $Q_1$ 漏极接 $V_g^+$ ，源极接原边同名端（节点 A）；
3. $Q_2$ 漏极接原边非同名端（节点 B），源极接 $V_g^-$ ；
4. $D_1$ 阳极接节点 B，**阴极接 $V_g^+$**；
5. $D_2$ **阳极接 $V_g^-$**，阴极接节点 A；
6. 原边打点端在**上**（ $Q_1$ 侧），副边打点端也在**上**，两只 MOSFET 上管为 $Q_1$ 、下管为 $Q_2$ ；
7. 变压器变比标注为 $1:n$ ，即原边 1 匝对应副边 $n$ 匝，与 $n=N_s/N_p$ 一致；
8. 副边 $D_3$ 为整流管（阳极接副边同名端，阴极接 $L$ ）； $D_4$ 为续流管（阴极接 $D_3$ 阴极与 $L$ 之间的节点，阳极接输出回线）； $L$ 、 $C$ 、 $R$ 依次为滤波电感、滤波电容、负载。

> **▎文字描述与原理图的核对结论**
>
> 逐项核对后，任务书中的文字描述（ $Q_1$/$Q_2$ 同为 N 沟道、同开同关、 $D_1$/$D_2$ 构成复位通道、 $D_3$ 整流、 $D_4$ 续流、原边导通电压 $+V_g$ 、复位电压 $-V_g$ 、 $D_{max}=0.5$ ）**与原理图完全一致，未发现实质性冲突**，因此本笔记不改动任何拓扑连接。
>
> 但有两处**极易误读**，必须点明，否则后续所有推导都会崩：
>
> - **误读一**：以为 $D_1$ 、 $D_2$ 串联在 $V_g^+$ 与 $V_g^-$ 之间。若真是那样，两只管永远反向截止，变压器根本得不到复位通路。图上的跨线半圆已经否定了这种读法。
> - **误读二**：以为"每只二极管贴着自己那一侧的开关管"（ $D_1$ 贴 $Q_1$ 、 $D_2$ 贴 $Q_2$ ）。实际是**交叉配合**： $D_1$ 接在 $Q_2$ 侧的节点 B 与 $V_g^+$ 之间， $D_2$ 接在 $Q_1$ 侧的节点 A 与 $V_g^-$ 之间。这不是画错，而是复位的物理必然——励磁电流方向不能突变，只能从节点 B 经 $D_1$ 灌回 $V_g^+$ 、再从 $V_g^-$ 经 $D_2$ 补入节点 A（推导见 §三 阶段 2）。

### 1.3 宏观工作机理

| 环节 | 器件 | 功能 |
| --- | --- | --- |
| ① 斩波 | $Q_1$ 、 $Q_2$ | 同一路 PWM 驱动，同时导通／同时关断，把直流 $V_g$ 斩成单极性高频方波加到原边 |
| ② 原边箝位复位 | $D_1$ 、 $D_2$ | 关断期把原边电压箝到 $-V_g$ ，强制磁芯复位，并把励磁与漏感能量回馈输入端 |
| ③ 高频变压器 | $1:n$ | 电压变换 + 电气隔离；**单端正激**工作（只从副边送出能量，自身不储能） |
| ④ 整流 + 续流 | $D_3$ 、 $D_4$ | $D_3$ 在导通期把副边电压整流给负载； $D_4$ 在关断期给电感续流 |
| ⑤ LC 滤波 | $L$ 、 $C$ | 与 Buck 完全相同，滤出平滑直流 $V_o$ |

**控制逻辑**： $Q_1$ 、 $Q_2$ 完全同步（ $t_{on}=DT_s$ ），通过调节 $D$ 控制输出：

$$V_o = nDV_g$$

> **本质认知**：双管正激 = **Buck 变换器的隔离化**。Buck 中"开关管 + 续流二极管"这个斩波单元，被整体替换成"$Q_1$ + $Q_2$ + 变压器 + $D_3$ + $D_4$"；输出 LC 与负载部分与 Buck 一字不差。因此它的**小信号模型、补偿器设计、纹波计算全部可以照搬 Buck**，唯一多出来的约束是变压器复位带来的 $D_{max}\approx 0.5$ （见 §五）。

### 1.4 优点

1. **开关管电压应力低**——理想工况下每只管子只承受 $V_g$ （不是单管正激的 $2V_g$ 、也不是反激的 $V_g+V_{or}$ ）。 $V_g$ 越高，这一优势越关键，所以双管正激是高输入电压（如 380 V 母线）中功率场合的经典选择。
2. **漏感能量可回馈**——复位期原边被 $D_1$ 、 $D_2$ 箝到 $-V_g$ ，漏感电流被直接"倒灌"回输入源，**不需要 RCD 吸收电路**。单管正激必须用 RCD 把漏感能量烧掉，这是双管正激效率优势的主要来源。
3. **无 RCD 损耗、无复位绕组**——省掉复位绕组、省掉吸收网络，磁性器件和 BOM 都更简单。
4. **磁芯自动复位，无偏磁累积机制**（只要 $D<0.5$ 且复位时间足够）——励磁电流自然降到零， $D_1$ 、 $D_2$ 随之截止，磁通停在复位点不再变化。
5. **两管串联在原边两端，没有半桥／全桥那样的桥臂直通风险**——即便驱动出错同时导通，电流也被变压器与负载限制，不是直接短路 $V_g$ 。
6. **管电压应力低 = 可选低 $R_{DS(on)}$ 、低 $Q_g$ 的器件**，同功率下导通损耗与驱动损耗都优于高耐压方案。

### 1.5 缺点

1. **开关管数量翻倍**——两只 MOS 管 + 两路驱动（其中 $Q_1$ 是浮地高边驱动）。
2. **驱动更复杂**——$Q_1$ 的参考点是节点 A（电位在 $0\sim V_g$ 之间跳），必须用隔离驱动或自举驱动；两只管子还必须严格同步。
3. **原边电流由两管共同承担**——虽然每管只承受 $V_g$ ，但两管都流过全部原边电流，**导通损耗是两只管之和**（ $2I_{rms}^2R_{DS(on)}$ ）。
4. **最大占空比受限 $D<0.5$**——变压比 $n$ 被迫取较大值（ $n\geq 2V_o/V_{g,min}$ 量级），原边电流大、副边二极管电压应力高。
5. **磁芯利用率低**——单端工作，磁通只在第一象限 $B_r \to B_r+\Delta B$ 变化，同功率下磁芯体积约为双端拓扑（全桥／推挽）的 2 倍。
6. **PCB 与 EMI 要求高**——开关节点的 $\mathrm{d}v/\mathrm{d}t$ 、原边回路的 $\mathrm{d}i/\mathrm{d}t$ 都很大，换流回路面积必须压到最小。
7. **次级二极管损耗占比高**——$D_3$ 、 $D_4$ 各承担一段输出电流，低压大电流输出时二极管损耗显著（例：12 V 输出、 $D\approx0.33$ 时， $D_4$ 平均电流是 $D_3$ 的两倍）。

### 1.6 适用场景

| 场景 | 是否适合 | 原因 |
| --- | :--: | --- |
| 高输入电压（≥300 V）+ 中功率（300 W~1 kW） | ✅ 最佳 | 管子只需 $V_g$ 耐压，漏感能量回馈，性价比高于单管正激 |
| 通信／工业电源（48 V~400 V 母线） | ✅ | 无需复位绕组与 RCD，成本与可靠性都好 |
| 高压输入的可靠性优先场合 | ✅ | 无吸收电路的耗散元件，无偏磁失控风险（ $D$ 受限于硬件机制） |
| 低压输入（<24 V） | △ | 管子耐压低本来就不贵，双管的驱动复杂度不划算，可考虑推挽／有源钳位正激 |
| 需要 $D>0.5$ 拓宽输入范围 | ❌ | 本拓扑做不到，改用**有源钳位正激**（ACF， $D$ 可 >0.5）或双管正激 + 复位绕组变比 |
| 小功率（<100 W） | △ | 与单管正激相比多一只管 + 一路隔离驱动，成本不占优 |

## 二、统一符号定义

全文统一采用以下符号，不再重复定义：

| 符号 | 含义 | 符号 | 含义 |
| --- | --- | --- | --- |
| $V_g$ | 输入电压（ $V_{g,min}$ ／ $V_{g,max}$ 为范围两端） | $L_m$ | 原边励磁电感 |
| $V_o$ | 输出电压 | $L_k$ | 原边漏感 |
| $I_o$ | 输出电流 | $L$ | 输出滤波电感 |
| $P_o$ | 输出功率 | $C$ | 输出滤波电容 |
| $f_s$ | 开关频率 | $R$ | 负载 |
| $T_s=1/f_s$ | 开关周期 | $i_m$ | 励磁电流 |
| $D=t_{on}/T_s$ | 占空比 | $i_L$ | 输出电感电流 |
| $N_p$ ／ $N_s$ | 原边／副边匝数 | $v_p$ | 原边绕组电压（同名端为正） |
| $n=N_s/N_p$ | 变压器匝数比（原理图 $N_p:N_s=1:n$ ） | $v_s$ | 副边绕组电压 |

**节点定义**（后文全部沿用）：

- 节点 A：原边同名端（ $Q_1$ 源极、副边同名端与之同相）；
- 节点 B：原边非同名端（ $Q_2$ 漏极）；
- $v_p=v_A-v_B$ ， $v_s=nv_p$ ；
- $v_L$ ：输出电感两端电压（电感左端对输出回线）；
- 输出回线（副边下端、 $D_4$ 阳极、 $C$ 负极、 $R$ 下端）定义为副边参考地。

> **符号提醒**： $n$ 在全文中只表示匝数比 $N_s/N_p$ ，不表示任何其他量； $D$ 只表示占空比，不代表二极管。

## 三、电路结构完整拆解

### 3.1 输入侧：斩波与复位网络

- $Q_1$ 、 $Q_2$ 为 N 沟道 MOSFET，由**同一个 PWM 逻辑**驱动，正常工作时**同时导通、同时关断**；
- 导通期： $Q_1$ 把节点 A 拉到 $V_g^+$ ， $Q_2$ 把节点 B 拉到 $V_g^-$ ，原边获得 $+V_g$ ；
- 关断期： $D_1$ 、 $D_2$ 同时导通，把原边箝到 $-V_g$ ，构成**磁芯复位回路**；
- **同名端与极性**：原边打点端在上（节点 A），导通期电流由节点 A 流入绕组（ $A\to B$ ），故打点端为正。副边打点端也在上，故副边电压在导通期为上正下负， $D_3$ 正向导通。

> **▎为什么 $Q_2$ 在下面而不是"两只管子都挂在高边"？**
>
> $Q_1$ 在 $V_g^+$ 侧、 $Q_2$ 在 $V_g^-$ 侧，两只管子**把变压器原边夹在中间**。这样：① 关断时原边两端可以分别被 $D_1$ 、 $D_2$ 拉到 $V_g^+$ 与 $V_g^-$ ，复位电压恰好是 $-V_g$ ；② 每只管子的 $V_{DS}$ 都只有 $V_g$ ；③ 两管同时导通时不会把 $V_g$ 短路（变压器绕组在中间挡着）。

### 3.2 副边：整流、续流与滤波

- $D_3$ ：**整流二极管**，负责导通期把副边能量送到负载，平均电流 $I_{D3,avg}=DI_o$ ；
- $D_4$ ：**续流二极管**，负责关断期维持电感电流连续，平均电流 $I_{D4,avg}=(1-D)I_o$ ；
- $L$ 、 $C$ ：与 Buck 相同的 LC 低通滤波；
- $R$ ：负载，输出电压 $V_o$ 。

**注意副边只有两种状态**：要么 $D_3$ 导通（副边向电感与负载供能），要么 $D_4$ 导通（电感续流）。**原边的"复位期"与"空闲期"在副边看起来是同一种状态**——这正是为什么输出电感看到的仍然是标准 Buck 的两电平波形（这一点是 §四伏秒平衡成立的前提）。

## 四、一个完整开关周期的工作过程

一个周期分为**三个阶段**：导通期、复位期（励磁电流非零）、空闲期（复位已完成）。第二阶段与第三阶段都属于"开关管关断"，但内部机理完全不同，不能混为一谈。

### 4.1 阶段 1： $Q_1$ 、 $Q_2$ 同时导通——$[t_0,t_1]$ ，时长 $DT_s$

**(1) 原边电压**

$$v_p = V_g \qquad (v_A=V_g^+,\ v_B=V_g^-)$$

**(2) 磁通变化**：由 $v_p=N_pA_e\dfrac{\mathrm{d}B}{\mathrm{d}t}$ 得磁通**线性上升**：

$$\frac{\mathrm{d}B}{\mathrm{d}t}=\frac{V_g}{N_pA_e}>0$$

**(3) 励磁电流变化**：原边等效为励磁电感 $L_m$ 被 $V_g$ 充电

$$\frac{\mathrm{d}i_m}{\mathrm{d}t}=\frac{V_g}{L_m}>0 \quad\Longrightarrow\quad i_{m,pk}=\frac{V_g\cdot DT_s}{L_m}$$

**(4) 副边感应电压**： $v_s=nv_p=nV_g$ ，**上正下负**（与同名端一致）。

**(5) 二极管状态**： $D_3$ 正向导通（阳极接副边同名端， $nV_g$ 正偏）； $D_4$ 反向截止。

**(6) 输出电感电压**：

$$v_L = nV_g - V_o > 0$$

**(7) 输出电感电流变化**：

$$\frac{\mathrm{d}i_L}{\mathrm{d}t}=\frac{nV_g-V_o}{L}>0$$

**(8) 输入能量传递路径**

$$V_g^+ \rightarrow Q_1 \rightarrow \text{原边绕组}(A\to B) \rightarrow Q_2 \rightarrow V_g^-$$

原边电流是"负载反射电流 + 励磁电流"的叠加：

$$i_p = i_{load,reflected} + i_m \approx n\,i_L + i_m$$

**(9) 副边与负载能量路径**

$$T_s(\text{副边同名端}) \rightarrow D_3 \rightarrow L \rightarrow (\text{负载 } R \parallel \text{电容 } C) \rightarrow \text{输出回线} \rightarrow T_s(\text{下端})$$

> **工程意义**：导通期原边与副边**同时**传递能量——变压器只是"透视"过去，能量不靠励磁电感储存。这与反激完全不同（反激导通期副边不导通，能量存在 $L_m$ 里）。

### 4.2 阶段 2： $Q_1$ 、 $Q_2$ 同时关断，变压器复位——$[t_1,t_2]$ ，时长 $t_{reset}=DT_s$

**(1) 为什么 $D_1$ 、 $D_2$ 会同时导通？**

关断瞬间，原边电流 $i_p$ （含励磁电流 $i_m$ ）**不能突变**：它在绕组内仍沿 $A\to B$ 方向流动，于是必须在外电路找到续流回路。此时 $Q_2$ 已关断，节点 B 的电位被电流"顶"到 $V_g^+$ 以上，使 $D_1$ （阳极在节点 B、阴极在 $V_g^+$ ）**正向导通**；电流经 $V_g$ 源流回 $V_g^-$ ，使节点 A 的电位被"压"到 $V_g^-$ 以下，使 $D_2$ （阳极在 $V_g^-$ 、阴极在节点 A）**正向导通**。于是形成完整回路：

$$B \rightarrow D_1 \rightarrow V_g^+ \rightarrow \boxed{V_g} \rightarrow V_g^- \rightarrow D_2 \rightarrow A \rightarrow \text{原边绕组}(A\to B)$$

也就是说：**$D_1$ 与 $D_2$ 必须成对导通**，缺一不成回路。它们在回路中一只在电源"上方"、一只在电源"下方"，把励磁能量（以及漏感能量）**送回输入源**。

**(2) 变压器原边电压**

$$v_p=-V_g \qquad (v_A\approx V_g^-,\ v_B\approx V_g^+,\ \text{差值 } v_p=-V_g)$$

**(3) 励磁电流下降**

$$\frac{\mathrm{d}i_m}{\mathrm{d}t}=-\frac{V_g}{L_m}<0$$

斜率大小与导通期相同（ $\pm V_g/L_m$ ），因此励磁电流从 $i_{m,pk}$ 降到零所需时间恰为

$$t_{reset}=\frac{i_{m,pk}}{V_g/L_m}=\frac{V_gDT_s/L_m}{V_g/L_m}=DT_s$$

**(4) 磁通下降**： $v_p$ 反向，磁通线性下降，斜率与上升期对称。

**(5) 磁芯复位**：当 $i_m$ 回到零，磁通回到本周期起点（ $H=0$ 处，即材料的剩余磁密 $B_r$ 附近），磁芯**完全复位**——下个周期从同一点重新开始，不存在逐周期累积。

**(6) 磁化能量回馈输入端**：励磁能量 $W_m=\frac12 L_m i_{m,pk}^2$ 经 $D_1$ 、 $D_2$ 全部回灌 $V_g$ ，**以热的形式损失的部分极少**（只有二极管正向压降的损耗）。这也是双管正激比单管正激效率高的核心原因。

**(7) 漏感能量如何处理**：漏感电流与原边电流同向，关断后同样被 $D_1$ 、 $D_2$ 箝位并回馈输入，所以**不需要 RCD 吸收**。但漏感与 MOSFET 的 $C_{oss}$ 、二极管结电容在换流瞬间会形成高频振荡（ $L_k$-$C_{oss}$ 谐振），表现为管子 $V_{DS}$ 上的一小段振铃；由于 $D_1$/$D_2$ 的箝位作用，振铃幅度被限制在 $V_g$ 上下一个二极管压降之内，属于"自箝位"。

**(8) 为什么 MOSFET 不会承受约 $2V_g$ 的理想关断电压？**

单管正激里，原边续流回路把储能释放后，复位期间开关管要承受 $V_g+V_g=2V_g$ （输入电压 + 复位绕组/励磁电压叠加）。双管正激中，**两只管子分别接在电源的两端**： $Q_1$ 的源极（节点 A）被 $D_2$ 箝到 $V_g^-$ ， $Q_2$ 的漏极（节点 B）被 $D_1$ 箝到 $V_g^+$ ，因此

$$V_{DS}(Q_1)=V_g^+-v_A\approx V_g,\qquad V_{DS}(Q_2)=v_B-V_g^-\approx V_g$$

两只管子各承受 $V_g$ ，**没有 $2V_g$ 的问题**——复位电压被"分摊"到了电源两端。

**(9) $Q_1$ 、 $Q_2$ 的 $V_{DS}$ 应力**：复位期 $V_{DS}\approx V_g$ （工程上再叠加两个二极管压降与振铃）；空闲期由于原边两端悬空，电压由两管的 $C_{oss}$ 与二极管结电容分压，理想对称时

$$V_{DS}(Q_1)=V_{DS}(Q_2)\approx \frac{V_g}{2}$$

即**平均应力更低，但选型必须按最恶劣的 $V_g$**（复位期间的瞬时值）。实际选型还要叠加漏感振铃与寄生电感引起的尖峰，见 §十。

**(10) 副边 $D_3$ 、 $D_4$ 状态**：副边电压反向， $v_s=-nV_g$ ，副边同名端变为负。 $D_3$ 反偏截止（承受反向电压 $\approx nV_g$ ）， $D_4$ 正向导通续流。

**(11) 输出电感续流**： $v_L=-V_o<0$ ， $i_L$ 线性下降：

$$\frac{\mathrm{d}i_L}{\mathrm{d}t}=-\frac{V_o}{L}<0$$

### 4.3 阶段 3：复位完成后的剩余关断时间——$[t_2,t_3]$ ，时长 $(1-2D)T_s$

- 当 $i_m$ 降到零后，**$D_1$ 、 $D_2$ 不再导通**：二者是二极管，不能通过反向电流，因此复位回路自然断开（不是靠控制信号关断的）；
- 变压器**已完成复位**，原边两端事实上悬空，电压只由寄生电容分压决定（对称时 $v_A=v_B\approx V_g/2$ ，即 $v_p\approx 0$ ）；
- 副边**继续由 $D_4$ 与输出电感维持负载电流**， $v_L=-V_o$ ，与阶段 2 无缝衔接；
- 因此：**阶段 2 与阶段 3 在副边波形上不可区分，但在原边完全不同**——阶段 2 有原边电流（ $D_1$/$D_2$ 导通、能量回馈），阶段 3 原边电流为零（无能量流动、无损耗）。

> **简化与严谨的取舍**：工程上常把阶段 2 + 阶段 3 统称"关断阶段（ $t_{off}$ ）"，这样对副边与输出纹波计算完全够用；但只要涉及**磁芯复位、 $V_{DS}$ 应力、二极管损耗**，就必须区分这两个子状态。本笔记一律区分。

### 4.4 一个周期的关键波形汇总

| 时段 | $[t_0,t_1]$ 导通 | $[t_1,t_2]$ 复位 | $[t_2,t_3]$ 空闲 |
| --- | --- | --- | --- |
| $Q_1$ 、 $Q_2$ | 导通 | 关断 | 关断 |
| $v_p$ | $+V_g$ | $-V_g$ | $\approx 0$ （悬空分压） |
| $i_m$ | $0\to i_{m,pk}$ 上升 | $i_{m,pk}\to 0$ 下降 | $0$ |
| 磁通 $\phi$ | 上升 | 下降（复位） | 不变 |
| $D_1$ 、 $D_2$ | 截止 | **导通**（能量回馈） | 截止 |
| $v_s$ | $+nV_g$ （ $D_3$ 导通） | $-nV_g$ （ $D_3$ 截止、绕组开路） | $\approx 0$ （原边悬空分压） |
| $D_3$ ／ $D_4$ | 导通／截止 | 截止／导通 | 截止／导通 |
| $v_L$ | $nV_g-V_o$ | $-V_o$ | $-V_o$ |
| $i_L$ | 上升 | 下降 | 下降 |
| $V_{DS}(Q_1,Q_2)$ | $0$ | $\approx V_g$ | $\approx V_g/2$ |

## 五、稳态电压传输关系

### 5.1 从输出电感伏秒平衡推导

**物理意义**：输出电感 $L$ 是真正的储能元件，稳态下它每个周期吸收的伏秒积必须等于放出的伏秒积，否则电流会单向漂移。

**电路状态**：无论原边处于复位期还是空闲期，副边都是 $D_4$ 导通、 $v_L=-V_o$ ，所以电感只有两种状态：

$$v_L=\begin{cases} nV_g-V_o, & 0<t<DT_s \quad (D_3\ \text{导通，电感储能})\\\\ -V_o, & DT_s<t<T_s \quad (D_4\ \text{续流，电感释能}) \end{cases}$$

**推导**：稳态下一个开关周期内电感电压平均值为零：

$$(nV_g-V_o)\cdot DT_s + (-V_o)\cdot(1-D)T_s = 0$$

展开：

$$nV_gDT_s - V_oT_s = 0$$

**公式**：

$$\boxed{V_o=nDV_g}\qquad\Longleftrightarrow\qquad \boxed{\frac{V_o}{V_g}=nD}$$

**工程意义**：

1. **为什么是 $nD$ 而不是 $D$**：变压器把 $V_g$ 变成 $nV_g$ ，再由开关管"斩波"，输出就是 Buck 的 $D$ 乘以匝数比。变压器匝数比是"粗调"，占空比 $D$ 是"细调"。
2. **为什么说它是隔离 Buck**：把"$Q_1$+$Q_2$+变压器+$D_3$+$D_4$"整体看成一个受 $D$ 控制的**理想直流变压器**（增益 $nD$ ），后面就是 Buck 的 LC 与负载。因此 Buck 的所有结论（CCM/DCM 边界、纹波公式、小信号模型、环路补偿）都可以平移过来。
3. **对控制的意义**： $D$ 与 $V_o$ 是线性关系，增益为 $nV_g$ ；输入电压变化时用 $D$ 反向补偿，闭环即可稳压。

### 5.2 匝数比与占空比的影响

| 参数变化 | 对 $V_o$ 的影响 | 对设计的连带影响 |
| --- | --- | --- |
| $n$ 增大（副边匝数多） | $V_o$ 线性上升 | 原边电流增大（ $i_p=ni_L$ ）， $D_3$/$D_4$ 电压应力 $nV_g$ 增大 |
| $n$ 减小 | $V_o$ 线性下降 | 原边电流减小，但为保证 $V_{o}$ 需要更大 $D$ ，受 $D_{max}$ 挤压 |
| $D$ 增大 | $V_o$ 线性上升 | 原边电流有效值上升、复位时间 $DT_s$ 变长、 $D_4$ 导通时间变短 |
| $f_s$ 升高 | 与 $V_o$ 无关（CCM） | 磁芯与滤波器体积减小，开关损耗上升 |

> **设计要点**： $n$ 的选取是"用最小输入电压能否顶出额定输出"决定的（见 §十三 13.1），一旦 $n$ 确定，额定输入下的 $D$ 就定了，输出调节全靠 $D$ 。

## 六、最大占空比为什么不能超过 50%

### 6.1 从变压器伏秒平衡严格推导

**物理意义**：变压器的励磁电流必须每周期回到零，否则磁通会逐周期累积。而励磁电流的斜率是 $\pm V_g/L_m$ ，**正负斜率大小完全相等**（这是本拓扑的关键：复位电压恰好等于输入电压），因此

**推导**：

- 导通期： $v_p=+V_g$ ，时长 $DT_s$ ，伏秒积 $ +V_g\cdot DT_s$ ；
- 复位期： $v_p=-V_g$ ，时长 $t_{reset}$ ，伏秒积 $-V_g\cdot t_{reset}$ ；
- 复位完成要求伏秒积相消：

$$V_g\cdot DT_s = V_g\cdot t_{reset} \quad\Longrightarrow\quad t_{reset}=DT_s$$

而复位必须在下一个导通期到来之前结束，即

$$t_{reset}=DT_s \leq (1-D)T_s$$

**公式**：

$$\boxed{D\leq 0.5}\qquad\text{即}\qquad \boxed{D_{max}=0.5}$$

**工程意义**：这是**本图示经典双管正激（1:1 复位电压）的理论上限**。

> **限定语（重要）**： $D_{max}=0.5$ **不是所有正激变换器的普适结论**。单管正激若采用复位绕组，复位电压为 $(N_p/N_r)V_g$ ，取 $N_r<N_p$ 即可让复位更快， $D$ 可 >0.5；有源钳位正激（ACF）用钳位电容复位， $D$ 也可 >0.5。**本结论只适用于"复位电压由 $D_1$/$D_2$ 箝到 $-V_g$"的经典双管正激。**

### 6.2 实际设计为什么必须留复位裕量

理论上 $D$ 可以取到 0.5，但工程上通常取 $D_{max}=0.40\sim0.45$ ：

1. **复位电流的"尾巴"**——漏感与寄生电容会让 $i_m$ 的过零时刻滞后于理想值，复位实际需要比 $DT_s$ 稍长的时间；
2. **参数漂移**——$f_s$ 容差、磁芯 $\Delta B$ 随温度变化、 $L_m$ 随温度下降（铁氧体的 $B_{sat}$ 在高温下也会下降）；
3. **输入电压的波动与瞬态**——输入跌落时环路会把 $D$ 顶到极限，若极限就在 0.5 附近，容易在动态过程中越界；
4. **避免"临界饱和"**——$D$ 恰好 0.5 时复位时间被榨干，任何一点额外损耗或扰动都可能让磁通偏高，长期运行会温升叠加。

### 6.3 如果超过 0.5 会发生什么

**磁通逐周期累积过程**：

设 $D>0.5$ 。每周期励磁电流上升 $V_gDT_s/L_m$ 、下降 $V_g(1-D)T_s/L_m$ （下降时间只有 $t_{off}=(1-D)T_s<(D)T_s$ ，**在 $i_m$ 降到零之前下一周期就开始了**），于是每周期净增加

$$\Delta i_{m,net}=\frac{V_g}{L_m}\left[DT_s-(1-D)T_s\right]=\frac{V_g}{L_m}(2D-1)T_s>0$$

对应磁通每周期净增：

$$\Delta \phi_{net}=\frac{V_g(2D-1)T_s}{N_p}$$

**后果链条**：磁通起点逐周期抬高 → 工作点上移 → 当峰值磁密触及 $B_{sat}$ 时，磁芯饱和 → 原边励磁电感崩塌（ $L_m\to$ 极小，只剩漏感）→ 原边电流暴增（等效直通）→ 开关管过流、 $D_1$/$D_2$ 过流、变压器高温 → 器件损坏。

> **注意方向性**：这个"走磁"是**单方向累积**的（不是振荡），所以它不会自己稳定下来。这也是为什么双管正激**不需要偏磁检测与校正电路**——只要设计上守住 $D<0.5$ 并留裕量，机制上就不会跑偏；反过来说，一旦设计失误越过 0.5，靠闭环也无法挽回。

## 七、双管正激的核心优势与代价

### 7.1 工程优势逐条分析

| 优势 | 机理 |
| --- | --- |
| ① MOSFET 耐压较低（ $\approx V_g$ ） | 复位期原边被箝到 $-V_g$ ，两只管子分处 $V_g^+$ ／ $V_g^-$ 两端，各自只承担 $V_g$ |
| ② 漏感能量回馈输入 | $D_1$ 、 $D_2$ 构成双向箝位回路，漏感电流经 $V_g$ 源倒灌回输入端，不需要 RCD |
| ③ 磁芯自动复位 | 复位电压恒为 $-V_g$ ，无需复位绕组、无需复位控制 |
| ④ 不需要额外复位绕组 | 省一整套绕组与窗口面积，铜损更低，漏感更小 |
| ⑤ 适合较高输入电压 | 管子耐压只有 $V_g$ ， $300\sim 400$ V 母线可用 500 V／600 V 器件，导通电阻与成本都友好 |
| ⑥ 适合中功率／较高功率隔离电源 | 两只管子分摊热耗，无直通风险，可靠性高；300 W~1 kW 是甜点区 |

### 7.2 代价与设计代价

| 缺点 | 机理与应对 |
| --- | --- |
| ① 管子数量增加 | 2 管 + 2 路驱动，成本与布板面积上升 |
| ② 驱动电路复杂 | $Q_1$ 浮地，需隔离驱动／自举；两管必须严格同步（见 §十六） |
| ③ 两管共同承担原边电流 | 导通损耗为两只之和 $2I_{p,rms}^2R_{DS(on)}$ ，选低 $R_{DS(on)}$ 器件 |
| ④ $D_{max}\approx0.5$ | 匝比 $n$ 被迫偏大 → 原边电流大、副边二极管应力高；需要更宽的输入范围时要换拓扑 |
| ⑤ PCB 布局要求高 | 原边换流回路、复位回路、栅极回路面积必须最小化 |
| ⑥ 高 $\mathrm{d}i/\mathrm{d}t$ 、 $\mathrm{d}v/\mathrm{d}t$ → EMI | 换流点振铃是主要干扰源，需要缓冲与屏蔽 |
| ⑦ 漏感／寄生参数引起电压尖峰 | 虽然被箝位在 $V_g$ 附近，但换流回路寄生电感仍会造成局部尖峰与振铃 |

## 八、双管正激 vs 单管正激

| 对比项 | 单管正激（复位绕组） | 双管正激（本拓扑） | 工程含义 |
| --- | --- | --- | --- |
| 开关数量 | 1 | 2 | 双管成本高、驱动多一路 |
| 复位方式 | 复位绕组 + 二极管，复位电压 $-(N_p/N_r)V_g$ | $D_1$ 、 $D_2$ 箝位，复位电压 $-V_g$ | 双管不需要复位绕组 |
| MOSFET 耐压 | $V_g\left(1+\dfrac{N_p}{N_r}\right)$ ，常取 $2V_g$ 以上 | $\approx V_g$ | **双管可用更低耐压、更低 $R_{DS(on)}$ 的器件** |
| 最大占空比 | $D<\dfrac{1}{1+N_p/N_r}$ ，取 $N_r<N_p$ 可 >0.5 | $D\leq0.5$ （硬约束） | 单管输入范围更宽，双管更"憋" |
| 漏感能量处理 | 需 RCD 吸收，能量以热耗散 | 经 $D_1$ 、 $D_2$ 回馈输入 | **双管效率优势的主要来源** |
| 驱动复杂度 | 低边驱动，简单 | 一路低边 + 一路浮地／隔离驱动 | 单管更简单 |
| 器件成本 | 低（1 管 + 无吸收）或中（含 RCD） | 中（2 管 + 2 驱动） | 小功率单管胜，中高功率双管胜 |
| EMI | 有 RCD 的耗散型尖峰，环路大 | 尖峰被箝位但换流更剧烈 | 双管需更严谨的布板 |
| 适用功率 | 几十瓦 ~ 300 W | 300 W ~ 1 kW（可更高） | 交叉区按成本与效率目标取舍 |
| 典型应用 | 小功率适配器、辅助电源 | 通信／工业电源、高压母线中功率隔离电源 | — |

> **工程取舍结论**：不存在"谁绝对更好"。**输入电压高、功率中上、效率与可靠性优先** → 双管正激；**输入电压低、功率小、成本极致敏感** → 单管正激；**需要 $D>0.5$ 的宽输入范围** → 有源钳位正激。

## 九、正激 vs 反激：能量传递机制

### 9.1 正激：导通期直接传输

**能量传递机制**：开关导通时，能量**直接**通过变压器耦合到副边，经整流后送入 LC 与负载：

$$V_g \rightarrow \text{Transformer} \rightarrow \text{Rectifier} \rightarrow L \rightarrow \text{Load}$$

变压器是"透明的"——它同时传输能量、完成隔离与变比；**输出电感 $L$ 是重要储能元件**，负责在关断期给负载续流。

**输出能力**： $V_o=nDV_g$ ，只与变比和占空比有关，与负载电流无关（CCM 下），因此正激的变压器**不做储能**，磁芯只需承受励磁的微小 $\Delta B$ （反而可以做得较小）。

### 9.2 反激：导通期储能、关断期释放

**能量传递机制**：开关导通时副边二极管反偏，能量全部储存在**磁化电感**中：

$$V_g \rightarrow L_m \ (\text{储能为 } \tfrac12 L_m i_{pk}^2)$$

开关关断后， $L_m$ 电流被迫转移到副边，能量才经二极管释放给负载与电容。副边电容承担了"续流储能"的角色，**输出端通常不需要滤波电感**。

> **一句话本质区别**：正激的变压器主要承担**隔离与电压变换**；反激的变压器（磁化电感）承担**主要储能功能**——反激变压器本质上是一个"耦合电感"。

### 9.3 对比表

| 对比项 | 正激（含双管正激） | 反激 |
| --- | --- | --- |
| 能量传输时刻 | 开关导通期直接传递 | 开关关断期释放 |
| 变压器角色 | 隔离 + 变压（不储能） | 耦合电感（主要储能） |
| 输出滤波电感 | 必需，是主要储能元件 | 通常不需要 |
| 磁芯利用 | 单端，利用率低（0~$\Delta B$ ） | 单端，但磁芯带气隙储能 |
| 输出电流能力 | 强（可由电感平滑大电流） | 弱（纹波大、峰值电流高） |
| 功率范围 | 数十瓦 ~ 千瓦级（双管可更高） | 数瓦 ~ 100 W 级 |
| 输出纹波 | 小（LC 二阶滤波） | 较大（需靠电容吸收） |
| 变压器气隙 | 一般不开气隙（增大 $L_m$ ） | 必须开气隙（防饱和、储能） |
| 典型应用 | 工业／通信／适配器中高功率 | 小功率充电器、辅助电源 |

## 十一、MOSFET $Q_1$ 、 $Q_2$ 选型

### 11.1 耐压

**理想情况**：

$$V_{DS,max}\approx V_{g,max}$$

（复位期两管各承受 $V_g$ ；空闲期若寄生电容对称，各管只承受 $V_g/2$ 。）

**实际必须考虑**：

- **漏感尖峰**——关断瞬间 $L_k$ 与 $C_{oss}$ 的换流振铃；
- **PCB 寄生电感**——换流回路面积决定的 $L_{loop}\cdot \mathrm{d}i/\mathrm{d}t$ ；
- **MOSFET 寄生参数**——$C_{oss}$ 与封装内引线电感；
- **二极管反向恢复**——$D_1$/$D_2$ （以及副边 $D_3$/$D_4$ ）的反向恢复电流注入换流回路；
- **开关振铃**——上述因素在开关沿附近的高频振铃，示波器上表现为 $V_{DS}$ 上的尖峰。

**工程设计关系**：

$$V_{DS,rated} > V_{g,max} + V_{spike}$$

**示例**： $V_{g,max}=60\text{ V}$ ，复位期叠加二极管压降与振铃后实测峰值约 $70\sim 80\text{ V}$ → 选 **100 V** 档（峰值只占额定的 70%~80%，留 20%~30% 裕量）。

> **必须实测**： $V_{spike}$ 无法只靠公式确定，只能通过**示波器实测 $V_{DS}$ 波形**（探头短地弹簧、最小环路、满负载 + 最高输入电压 + 最恶劣工况）来确认，再对漏感、吸收、布板做迭代。

### 11.2 电流

**原边电流构成**（物理意义：原边电流 = 负载反射电流 + 励磁电流）：

$$i_p = i_{load,reflected} + i_m$$

其中

$$i_{load,reflected}\approx n\,i_L,\qquad i_m\ \text{是三角波，峰值}\ i_{m,pk}=\frac{V_{g,max}D_{max}}{L_mf_s}$$

**峰值电流**（出现在导通期末、最高输入电压时）：

$$\boxed{I_{Q,pk}\approx n\left(I_o+\frac{\Delta I_L}{2}\right)+i_{m,pk}}$$

**有效值电流**（近似认为原边电流在 $DT_s$ 内近似为平顶，占空比为 $D$ ）：

$$\boxed{I_{Q,rms}\approx n\,I_o\sqrt{D}}$$

**示例**： $n=0.75$ ， $I_o=10\text{ A}$ ， $\Delta I_L=3\text{ A}$ （§十四）， $i_{m,pk}\approx0.43\text{ A}$ ：

$$I_{Q,pk}\approx 0.75\times(10+1.5)+0.43\approx \boxed{9.1\text{ A}}$$

$$I_{Q,rms}\approx 0.75\times10\times\sqrt{0.444}\approx \boxed{5.0\text{ A}}$$

**导通损耗**：

$$P_{cond}=I_{Q,rms}^2R_{DS(on)}$$

两只管子都流过全部原边电流，**总导通损耗为两管之和**：

$$P_{cond,total}=2\times5.0^2\times30\text{m}\Omega\approx \boxed{1.5\text{ W}}$$

**开关损耗的基本来源**：

$$P_{sw}\approx \frac12V_{DS}I_{Q,pk}(t_r+t_f)f_s$$

双管正激**不是软开关**，开通过程中 $C_{oss}$ 的能量被耗散、关断过程中电压电流交叠，因此开关损耗与 $f_s$ 成正比。选择开关频率时要在"磁芯／滤波体积"与"开关损耗"之间权衡。示例按 $t_r+t_f=60\text{ ns}$ 估算约 $0.8\text{ W}$ （单管），两管合计约 $1.6\text{ W}$ （量级估算）。

### 11.3 关键参数选型表

| 参数 | 取值／要求 | 原因 |
| --- | --- | --- |
| $V_{DSS}$ | $>V_{g,max}+V_{spike}$ ，示例取 100 V | 复位期应力 + 尖峰 |
| $R_{DS(on)}$ | 越小越好（导通损耗 ∝ 它），但注意 $Q_g$ 上升 | 2 只管子串联承担全部原边电流 |
| $Q_g$ 、 $C_{oss}$ | 适度小 | 驱动损耗与开关损耗；但 $C_{oss}$ 过小会让关断振铃频率更高 |
| 体二极管 $t_{rr}$ | 越小越好 | 死区／换流时应避免体二极管导通时间过长 |
| $V_{GS(th)}$ ／驱动电压 | 匹配驱动电路（常 10~12 V） | 充分饱和、降低 $R_{DS(on)}$ |
| 封装与热阻 | 优先低 $R_{th(j-c)}$ 、可贴散热器 | 2 只管子的热源 |

## 十二、 $D_1$ 、 $D_2$ 复位二极管

> **特别说明**： $D_1$ 、 $D_2$ **不是普通"整流二极管"**，而是变压器复位／箝位回路的重要组成部分。它们的性能直接决定复位质量、开关管 $V_{DS}$ 尖峰与 EMI。

**1. 工作原理**：关断期同时导通，与原边绕组、 $V_g$ 源构成回路

$$A\to\text{原边绕组}\to B\to D_1\to V_g^+\to V_g\to V_g^-\to D_2\to A$$

把原边电压箝在 $-V_g$ ，迫使励磁电流线性下降并回馈输入。

**2. 导通路径**：如上；两只管子缺一不可（ $D_1$ 提供"向上"通道， $D_2$ 提供"向下"通道）。

**3. 反向耐压**：导通期节点 B 被拉到 $V_g^-$ ， $D_1$ 承受反向电压 $V_g$ ；同理 $D_2$ 在导通期承受 $V_g$ 。故

$$V_{R,D1}=V_{R,D2}\approx V_{g,max}$$

**示例**： $V_{g,max}=60\text{ V}$ → 选 100 V 档（与 MOSFET 同档位，便于简化 BOM）。

**4. 正向平均电流**：励磁电流在 $t_{reset}=D T_s$ 内从 $i_{m,pk}$ 线性降到零，一周期平均值

$$\boxed{I_{D1,avg}=I_{D2,avg}=\frac12 i_{m,pk}\cdot \frac{D T_s}{T_s}=\frac12 i_{m,pk}D}$$

**示例**： $\frac12\times0.43\times0.444\approx \boxed{0.1\text{ A}}$ ——**很小**，因此复位二极管可以用小电流器件（这是双管正激的一大设计便利）。

**5. 峰值电流**： $I_{D,pk}=i_{m,pk}+$ （漏感电流在换流瞬间的贡献），示例约 $0.43\text{ A}$ 量级，但换流瞬间需能承受漏感电流的冲击。

**6. 反向恢复**： $i_m$ 过零时二极管电流自然降到零，**理论上属零电流关断（ZCS）**，反向恢复电流很小——这是优点。但 **$D_3$/$D_4$ 的反向恢复电流会通过变压器反射到原边**，叠加在换流回路上，产生 $V_{DS}$ 振铃（这一点常被忽略）。

**7. 高频损耗**：

$$P_{D1}=V_F\cdot I_{D1,avg}$$

**示例**： $1\text{ V}\times0.1\text{ A}=0.1\text{ W}$ ，可忽略。**这正是双管正激"漏感能量回馈而不是烧掉"的直观体现**：单管正激的 RCD 吸收上会消耗掉与漏感能量同量级甚至更多的功率。

**8. 选型建议**

| 场景 | 推荐器件 | 理由 |
| --- | --- | --- |
| 通用中低压（ $V_g\lesssim100\text{ V}$ ） | 超快恢复二极管（ $t_{rr}\le35\text{ ns}$ ） | 成本低，恢复特性够用 |
| 高频（ $\ge200\text{ kHz}$ ）／高 $V_g$ | 快恢复／碳化硅肖特基（SiC SBD） | 无反向恢复电流，显著降低换流振铃与 EMI |
| 追求 BOM 简化 | 与副边 $D_3$ ／ $D_4$ 同型号 | 便于统一采购 |

> **SiC 肖特基的取舍**：无反向恢复、几乎无开关损耗，代价是成本与正向压降略高。在复位电路中平均电流极小，主要收益不在"损耗"而在**降低换流振铃与 EMI**。

## 十三、 $D_3$ 、 $D_4$ 副边二极管

### 13.1 $D_3$ （整流二极管）

| 项目 | 表达式 | 示例（ $I_o=10\text{ A}$ ， $D=0.333$@48 V， $D_{max}=0.444$ ） |
| --- | --- | --- |
| 正向导通电流 | 导通期流过 $i_L$ | $0\sim11.5\text{ A}$ |
| 平均电流 | $I_{D3,avg}=DI_o$ | $3.3\text{ A}$ （ $D_{max}$ 时 $4.4\text{ A}$ ） |
| 峰值电流 | $I_{D3,pk}=I_o+\Delta I_L/2$ | $11.5\text{ A}$ |
| 反向耐压 | $V_{R,D3}\approx nV_{g,max}=V_o/D_{min}$ | $45\text{ V}$ |
| 反向恢复损耗 | $\approx \frac12 V_R I_{rr}t_{rr}f_s$ | 与 $D_4$ 的反向恢复共同构成副边主要开关损耗 |

### 13.2 $D_4$ （续流二极管）

| 项目 | 表达式 | 示例 |
| --- | --- | --- |
| 续流电流 | 关断期流过 $i_L$ | $0\sim11.5\text{ A}$ |
| 平均电流 | $I_{D4,avg}=(1-D)I_o$ | $6.7\text{ A}$ （ $D_{max}$ 时 $5.6\text{ A}$ ） |
| 峰值电流 | $I_{D4,pk}=I_o+\Delta I_L/2$ | $11.5\text{ A}$ |
| 反向耐压 | $V_{R,D4}\approx nV_{g,max}$ | $45\text{ V}$ |
| 高频反向恢复 | $t_{rr}$ 越小越好 | — |

> **重要提醒**： $I_{D3,avg}+I_{D4,avg}=I_o$ 恒成立。由于 $D<0.5$ ，**$D_4$ （续流管）的平均电流大于 $D_3$**，热设计要重点照顾 $D_4$ 。

### 13.3 理想条件下的电压应力关系与选型

$$V_{R,D3}=V_{R,D4}\approx nV_{g,max}=\frac{V_o}{D_{min}}$$

因为 $D_{min}<0.5$ ，所以副边二极管的电压应力**总是大于 $2V_o$**：

$$nV_{g,max}=\frac{V_o}{D_{min}}>2V_o$$

**示例**： $V_o=12\text{ V}$ ， $D_{min}=0.267$ （ $V_{g,max}=60\text{ V}$ ）→ 应力 $45\text{ V}$ ，考虑反向恢复振铃后选 **100 V** 档。

**器件选择逻辑**：

| 输出规格 | 推荐 | 理由 |
| --- | --- | --- |
| 低压大电流（≤24 V，大 $I_o$ ） | 肖特基（Schottky）或**同步整流（SR）** | 肖特基 $V_F$ 低、无反向恢复；SR 可把损耗再降一半以上 |
| 高压输出／高 $V_R$ | 超快恢复／SiC SBD | 反向恢复小， $V_R$ 高 |
| 效率优先 | 同步整流 MOSFET | 示例中 $D_3+D_4$ 损耗约 $5\text{ W}$ （占输出 4%），换 SR 可显著提升效率 |

**副边损耗估算（示例，肖特基 $V_F\approx0.5\text{ V}$ ）**：

$$P_{D3}=0.5\times3.3\approx1.7\text{ W}\qquad P_{D4}=0.5\times6.7\approx3.3\text{ W}$$

$$P_{D3}+P_{D4}\approx5.0\text{ W}\quad(\text{占 }P_o\text{ 的 }4\%\text{ 以上})$$

> **工程结论**：低压输出（12 V 及以下）的双管正激，副边整流损耗往往是**第一大损耗项**，是否上同步整流是效率分水岭。

> **⚠️ 用同步整流时必须注意的一点**
>
> 二极管是单向器件， $D_3$ 截止时副边绕组对原边"开路"，原边才能靠 $D_1$/$D_2$ 复位。而 SR 用的 MOSFET **是双向导通**的：若续流 SR 在**复位期间仍然导通**，它会把副边绕组短路，进而反射到原边把原边电压也箝到 0，励磁电流无法下降 → **磁芯无法复位 → 逐周期偏磁 → 饱和**。因此 SR 控制必须保证：**原边复位期间关断续流 SR**（或在复位期只允许体二极管以单向方式工作）。这是 SR 正激最容易翻车的地方。

## 十四、高频变压器设计

### 14.1 匝数比

由 $V_o=nDV_g$ 得

$$\boxed{n=\frac{V_o}{DV_g}}$$

**设计方法**：用**最低输入电压** + **最大占空比**下定 $n$ （保证最恶劣工况还能顶出额定输出）：

$$\boxed{n\geq \frac{V_o}{D_{max}V_{g,min}}}$$

再用**最高输入电压**反算最小占空比做校核，要求 $D_{min}$ 不至于过小（一般希望 $\ge$ 0.1~0.15，否则控制范围过窄、二极管导通时间过短、CCM 难保证）：

$$D_{min}=\frac{V_o}{nV_{g,max}}$$

**示例**： $n\geq \dfrac{12}{0.45\times36}=0.74$ → 取 $n=0.75$ （取整为 $N_p:N_s=4:3$ 的整数倍）。

校核： $V_{g,min}=36\text{ V}\Rightarrow D=12/(0.75\times36)=0.444$ ✅（≤0.45）； $V_{g,max}=60\text{ V}\Rightarrow D=0.267$ ✅（≥0.15）； $V_{g,nom}=48\text{ V}\Rightarrow D=0.333$ 。

### 14.2 磁芯选择

**依据**：工作频率、功率、允许最大磁密、有效截面积 $A_e$ 、材料（铁损／ $B_{sat}$ ）、铜损、温升。

**单端工作导致的利用率问题（关键）**：双管正激的磁通只在第一象限内变化，工作区间为

$$B_r \longrightarrow B_r+\Delta B$$

其中 $B_r$ 是复位点（ $H=0$ 时的剩余磁密）。因此限制条件是

$$\Delta B \leq B_{sat}(T)-B_r-\text{裕量}$$

而双端拓扑（全桥／推挽）磁通在 $\pm B_{sat}$ 之间对称摆动，可用 $\Delta B\approx 2B_{sat}$ 。**所以同功率下正激的磁芯体积约是全桥的 2 倍**，这是单端拓扑的固有代价。

**方法**：常用**面积积法**（AP 法）估算：

$$A_P=A_eA_w\geq \frac{P_o\,(1+\frac1\eta)}{K_uK_jB_{max}f_s}\times10^{4}\ \ (\text{经验式，系数随教材写法不同})$$

工程上更实用的做法是**先按经验选型（如 EE／PQ 系列对应功率的常规型号），再用 $\Delta B$ 校核并迭代**。

**示例**：选 PC40 材质 EE33 磁芯， $A_e=119\text{ mm}^2$ ， $A_w=133.6\text{ mm}^2$ ， $A_P\approx1.59\text{ cm}^4$ ； $100\text{ kHz}$ 下按 PC40 的 $P_v$-$f$-$B$ 损耗曲线核对（示例取 $\Delta B=0.2\text{ T}$ ，见下）。

### 14.3 原边匝数

**物理意义**： $v_p=N_pA_e\dfrac{\mathrm{d}B}{\mathrm{d}t}$——在给定的 $\Delta B$ 与 $A_e$ 下，匝数决定"能承受多少伏秒"。

**推导**：导通期 $v_p=V_g$ ，持续 $DT_s$ ，

$$\Delta B=\frac{V_g\cdot DT_s}{N_pA_e}=\frac{V_gD}{N_pf_sA_e}$$

反解匝数：

$$\boxed{N_p\geq \frac{V_{g,max}D_{max}}{\Delta B_{allow}f_sA_e}}$$

**$\Delta B$ 、 $B_{max}$ 与饱和的关系**：

- $B_{sat}$ ：材料饱和磁密，随温度升高而下降（PC40 从 25 ℃ 的 0.51 T 降到 100 ℃ 的约 0.39 T）；
- $B_r$ ：剩余磁密， $H=0$ 时的磁密，铁氧体约 0.1 T 量级；
- **复位点在 $B_r$ 附近，峰值是 $B_r+\Delta B$**，所以真正可用的是 $\Delta B_{allow}=B_{sat}(T)-B_r-\text{裕量}$ ；
- 裕量必须预留：磁芯批次差异、温度、瞬态过冲、以及 $D$ 的短时越界风险。

**示例**：取 $\Delta B_{allow}=0.2\text{ T}$ ：

$$N_p\geq\frac{60\times0.45}{0.2\times100\times10^3\times119\times10^{-6}}=\frac{27}{2.38}\approx11.3\ \Rightarrow\ \boxed{N_p=12}$$

反算实际磁密摆幅： $\Delta B=\dfrac{60\times0.45}{12\times100\times10^3\times119\times10^{-6}}\approx0.19\text{ T}$ ✅（留有裕量）。

> **设计校核链**： $\Delta B$ 超限 → 增大 $N_p$ （但窗口面积紧张、铜损上升）或换更大 $A_e$ 的磁芯或提高 $f_s$ 。

### 14.4 副边匝数

$$\boxed{N_s=nN_p}$$

**示例**： $n=0.75$ ， $N_p=12$ → $N_s=9$ 。

**必须重新校核输出电压**（因为匝数取整会改变实际 $n$ ）：

$$n_{real}=\frac{N_s}{N_p}=\frac{9}{12}=0.75,\qquad D_{max}=\frac{V_o}{n_{real}V_{g,min}}=0.444\ ✅$$

若取整后 $D$ 超出上限，应微调 $N_p$ 或 $N_s$ ，或放宽 $\Delta B$ 后复核。

### 14.5 绕组线径与结构

**依据**：绕组的 RMS 电流、允许电流密度 $J$ 、截面积、集肤效应、邻近效应、窗口面积。

**绕组电流**：

$$I_{p,rms}\approx nI_o\sqrt{D},\qquad I_{s,rms}\approx I_o\sqrt{D}$$

**示例**： $I_{p,rms}\approx5.0\text{ A}$ ， $I_{s,rms}\approx10\times\sqrt{0.444}\approx6.7\text{ A}$ 。

**电流密度**：自然冷却取 $J=3\sim4\text{ A/mm}^2$ ，强制风冷可取 $4\sim6\text{ A/mm}^2$ 。

$$S_{p,min}=\frac{I_{p,rms}}{J}\qquad S_{s,min}=\frac{I_{s,rms}}{J}$$

**示例**（ $J=4\text{ A/mm}^2$ ）： $S_p\approx1.25\text{ mm}^2$ ， $S_s\approx1.68\text{ mm}^2$ 。

**集肤深度**（铜，20 ℃）：

$$\delta\approx\frac{66}{\sqrt{f_s}}\text{ mm (}f_s\text{ 单位 Hz)}$$

**示例**： $100\text{ kHz}\Rightarrow\delta\approx0.21\text{ mm}$ → 单根漆包线线径应 $\lesssim 2\delta\approx0.42\text{ mm}$ ，更粗时必须**多股并绕**或**用铜箔**。

**邻近效应与结构安排**：

1. **交错绕制**（三明治绕法：原边一半—副边—原边一半）可显著降低漏感与邻近效应损耗，这是降低漏感尖峰最有效的**设计**手段；
2. 副边大电流用**铜箔**或**多股细线并绕**；
3. 窗口填充系数一般取 $K_u\approx0.3\sim0.4$ 。

**损耗与温升**：

$$P_{cu}=I_{p,rms}^2R_p+I_{s,rms}^2R_s,\qquad R=N\cdot\frac{\rho\,l_{mean}}{S_{\text{有效}}}\times F_R\ (\text{集肤修正系数})$$

$$P_{fe}=k f_s^{\alpha}B_{max}^{\beta}\cdot V_e\ (\text{Steinmetz 经验式})$$

温升一般控制 $\le40\text{ K}$ （按实际散热条件）。

**绝缘与安规**：原副边之间需满足爬电距离／电气间隙要求（依安规等级）；必要时用三层绝缘线、加屏蔽层（降低共模 EMI）、骨架加档墙。

## 十五、输出滤波电感 $L$

### 15.1 电感量设计（假设 CCM）

**物理意义**： $L$ 决定输出电流纹波； $L$ 越大纹波越小，但体积、成本和响应速度变差。

**推导**：导通期 $v_L=nV_g-V_o$ ，持续 $DT_s$ ，

$$\Delta I_L=\frac{(nV_g-V_o)D}{Lf_s}=\frac{V_oDT_s}{L}\cdot\frac{nV_g-V_o}{V_o}$$

代入 $V_o=nDV_g$ 简化：

$$\boxed{\Delta I_L=\frac{V_o(1-D)}{Lf_s}}$$

**设计取值**：令 $\Delta I_L=kI_o$ ，

$$\boxed{L=\frac{V_o(1-D)}{f_s\,\Delta I_L}=\frac{V_o(1-D)}{kI_of_s}}$$

**示例**：取 $k=30\%$ → $\Delta I_L=3\text{ A}$ ；按**最恶劣工况**（ $D$ 最大、需要最大 $L$ ）校核：

- $D=0.333$ （48 V）： $L=\dfrac{12\times0.667}{10^5\times3}=26.7\text{ µH}$
- $D=0.444$ （36 V）： $L=\dfrac{12\times0.556}{10^5\times3}=22.2\text{ µH}$

取 $\boxed{L=22\text{ µH}}$ （按最大 $D$ 工况），此时额定 $D$ 下 $\Delta I_L\approx3.6\text{ A}$ （ $36\%I_o$ ），仍在合理范围。

> **$k=20\%\sim40\%$ 的说明**：这是**工程经验范围，不是固定规则**。 $k$ 小（电感大）→ 纹波小、CCM 范围宽，但体积大、动态响应慢； $k$ 大（电感小）→ 体积小、响应快，但纹波与铜损上升、轻载易进 DCM。低压大电流输出常用较小的 $k$ 来压低纹波。

### 15.2 电流与磁芯

**峰值电流**：

$$I_{L,pk}=I_o+\frac{\Delta I_L}{2}$$

**示例**： $I_{L,pk}=10+1.8\approx11.8\text{ A}$ 。

**RMS 电流**（近似等于 $I_o$ ）：

$$I_{L,rms}\approx I_o=10\text{ A}$$

**CCM 临界条件**（进入 DCM 的负载电流）：

$$I_{o,crit}=\frac{\Delta I_L}{2}=\frac{V_o(1-D)}{2Lf_s}\quad\Longrightarrow\quad L_{crit}=\frac{V_o(1-D)}{2I_of_s}$$

**示例**： $L_{crit}=\dfrac{12\times0.444}{2\times10\times10^5}\approx2.7\text{ µH}$ → 设计值 22 µH 远大于它，CCM 可一直维持到约 $1.35\text{ A}$ （13% 负载）。

**磁芯与饱和裕量**：滤波电感**必须开气隙**（储能、防饱和）。推荐粉芯（铁硅铝 Sendust／铁镍钼）或铁氧体 + 气隙。

- 饱和电流校验： $I_{sat}>I_{L,pk}\times(1.2\sim1.3)$ ；
- 峰值磁密校验： $B_{pk}=\dfrac{L I_{L,pk}}{N_L A_e}\le B_{sat}$ （粉芯按软饱和曲线取值）；
- 匝数： $N_L=\sqrt{L/A_L}$ （ $A_L$ 为磁芯电感系数）。

**损耗**：

$$P_{cu}=I_{L,rms}^2R_{DCR},\qquad P_{fe}=\text{磁芯损耗（粉芯用厂家损耗曲线）}$$

**示例**： $R_{DCR}=10\text{ m}\Omega$ → $P_{cu}=10^2\times0.01=1.0\text{ W}$ 。

> **DCM 提醒**：轻载进入 DCM 后，传输关系不再是 $V_o=nDV_g$ （变为与负载有关的非线性关系），环路增益与动态特性都会变化。若要求全负载范围 CCM，需按最小负载电流校核 $L$ ；若允许 DCM，则要重新设计补偿器。

## 十六、输出电容 $C$ 与输入电容

### 16.1 输出电容充放电纹波

**物理意义**：电感的纹波电流全部由电容吸收，电容电压纹波由电荷变化产生。

$$\boxed{\Delta V_C\approx\frac{\Delta I_L}{8f_sC}}\qquad\Longrightarrow\qquad \boxed{C\geq\frac{\Delta I_L}{8f_s\Delta V_C}}$$

### 16.2 ESR 纹波

$$\Delta V_{ESR}\approx\Delta I_L\cdot ESR$$

**总输出纹波近似**（两项算术相加，工程上偏保守）：

$$\boxed{\Delta V_o\approx\frac{\Delta I_L}{8f_sC}+\Delta I_L\cdot ESR}$$

**示例**：要求 $\Delta V_o\le1\%\times12\text{ V}=120\text{ mV}$ ， $\Delta I_L=3.6\text{ A}$ ：

- 全部由 ESR 承担时： $ESR\le120\text{ mV}/3.6\text{ A}\approx33\text{ m}\Omega$ ；
- 取 $ESR\le15\text{ m}\Omega$ （分配 54 mV 给 ESR），余下 66 mV 给容值 → $C\geq\dfrac{3.6}{8\times10^5\times0.066}\approx68\text{ µF}$ ；
- 实际取 **2×220 µF 电解（低 ESR）+ 2×10 µF MLCC**，兼顾容值、ESR 与高频旁路。

### 16.3 选型逻辑

| 考量 | 说明 |
| --- | --- |
| 耐压 | 额定电压 ≥ $1.5\times V_o$ （电解常取 25 V 档用于 12 V 输出） |
| **RMS 纹波电流** | 电容纹波电流 $\approx\Delta I_L/\sqrt{12}$ （示例 $\approx1.0\text{ A}$ ），必须小于电容额定纹波电流（含频率修正与温度降额），这是电解电容最容易踩的坑 |
| ESR | 决定纹波电压与自发热，多只并联可同时降低 ESR 与分流纹波电流 |
| ESL | 影响高频纹波与环路，MLCC 就近放置可抑制 |
| 温升与寿命 | 电解电容寿命 $\propto$ $\dfrac{1}{2^{\Delta T/10}}$ ，纹波电流引起的自发热直接决定寿命 |
| 电容类型 | **电解**：容值大、成本低、ESR 与寿命受限；**固态／聚合物**：ESR 低、寿命长、成本高；**MLCC**：ESL 极低、高频特性好、容值受直流偏压影响大 |

### 16.4 输入电容

**物理意义**：原边电流是**脉冲电流**（只在 $DT_s$ 内流动），输入电容必须提供这个脉冲的交流分量，抑制输入电压纹波与传导 EMI。

$$I_{Cin,rms}\approx I_{in}\sqrt{\frac{1-D}{D}}\quad\text{或等价地}\quad I_{Cin,rms}\approx I_{p,pk}\sqrt{D(1-D)}$$

其中 $I_{in}\approx\dfrac{P_o}{\eta V_g}$ 。

**示例**： $V_{g,min}=36\text{ V}$ ， $\eta=0.92$ → $I_{in}\approx\dfrac{120}{0.92\times36}\approx3.6\text{ A}$ ， $D=0.444$ ：

$$I_{Cin,rms}\approx3.6\times\sqrt{\frac{0.556}{0.444}}\approx\boxed{4.0\text{ A}}$$

**选型**：多只低 ESR 电解／MLCC 并联（例如 4×47 µF／100 V 高频低阻 + 2×1 µF MLCC），并**就近紧贴 $Q_1$ 漏极与 $Q_2$ 源极**放置——这一点的布板意义甚至大于容值本身（见 §十七）。

## 十七、漏感、振铃、吸收与 PCB／EMI／热设计

### 17.1 漏感尖峰与"自箝位"特性

- 关断瞬间，漏感电流 $i_{p}$ 通过 $D_1$ ／ $D_2$ 灌入输入源，能量回收；
- 但换流过程是**振铃过程**： $L_k$ 与 $C_{oss}$ 、二极管结电容形成高频谐振，在 $V_{DS}$ 上表现为尖峰 + 振铃；
- 由于 $D_1$ ／ $D_2$ 的箝位，尖峰上限被限制在 $V_g$ 之上一个二极管压降左右，**远优于单管正激的 $2V_g$ 级尖峰**；
- 振铃频率与幅度取决于**换流回路寄生电感**与器件电容——这是布板与器件选择的战场。

**降低尖峰的手段（按性价比排序）**：

1. **减小漏感**：变压器交错绕制（三明治）、增大耦合、缩短绕组间距离；
2. **减小回路寄生电感**：原边换流回路面积最小化、多层板就近回流、电容紧贴开关管；
3. **适度增大 $C_{oss}$**：可降低振铃频率与峰值（代价：开关损耗上升）；
4. **RC／RCD 缓冲**：在万不得已时用于抑制副边振铃（对原边通常不需要）；
5. **降低 $\mathrm{d}i/\mathrm{d}t$**：增大栅极电阻（代价：开关损耗上升）。

> **副边振铃**： $D_3$/$D_4$ 的反向恢复 + 副边漏感会在副边节点上产生振铃，通过变压器反射到原边，是**共模 EMI 的主要来源**。常用的做法是在 $D_3$ ／ $D_4$ 两端加 RC 缓冲，或换用无反向恢复的肖特基／SiC／同步整流。

### 17.2 PCB 布局要点

| 项目 | 要求 |
| --- | --- |
| 高 $\mathrm{d}i/\mathrm{d}t$ 回路①（斩波回路） | $V_g^+ to Q_1 to$ 原边 $\to Q_2 \to V_g^-$ ：**面积最小**，用铜皮/多层平面就近回流 |
| 高 $\mathrm{d}i/\mathrm{d}t$ 回路②（复位回路） | $B\to D_1\to V_g^+\to C_{in}\to V_g^-\to D_2\to A$ ：同样要紧凑， $D_1$ ／ $D_2$ 紧靠开关管与输入电容 |
| 高 $\mathrm{d}v/\mathrm{d}t$ 节点 | 节点 A、节点 B、副边整流节点：铜面积尽量小（降低容性耦合），必要时加屏蔽或 RC |
| 输入电容位置 | 紧贴 $Q_1$ 漏极与 $Q_2$ 源极，先过电容再进开关管 |
| 栅极回路 | 驱动回路面积最小，开尔文源极接法，栅极电阻就近 |
| 电流采样 | 原边采样比副边更好（电流小、地参考干净），注意采样回路不要串入换流回路 |
| 原副边隔离 | 满足安规爬电／电气间隙；变压器下方避免走线跨越隔离带；Y 电容位置与共模路径一起规划 |

### 17.3 驱动与 EMI、热设计

**驱动**：

- $Q_2$ 源极接 $V_g^-$ ，**低边驱动**，最简单；
- $Q_1$ 是**浮地高边**（参考节点 A，电位在 $0\sim V_g$ 间跳变），必须用：**隔离驱动（数字隔离器 + 隔离电源）**、**栅极驱动变压器**，或**自举驱动**；
- ⚠️ 自举方案的注意点：自举二极管接 $V_g^+$ ，自举电容参考节点 A。节点 A 在复位期≈$V_g^-$ （可充满至接近 $V_g$ ），但在**空闲期≈$V_g/2$**，充电电压只剩一半。因此必须校核**复位期是否足够长**（ $t_{reset}=DT_s$ 足够给自举电容补电），否则栅极电压不足、 $R_{DS(on)}$ 上升甚至热失控；
- 两管必须**同步开关**，驱动延迟差异尽可能小（尤其关断沿，避免一侧先断造成额外换流损耗）。

**EMI 主要来源与控制**：

| 来源 | 控制手段 |
| --- | --- |
| 原边换流振铃（差模） | 减小回路面积与漏感、RC 缓冲、优化栅极驱动速度 |
| 副边整流振铃（共模） | 无反向恢复二极管／SR、RC 缓冲、变压器屏蔽层、Y 电容 |
| 开关节点容性耦合 | 缩小高 $\mathrm{d}v/\mathrm{d}t$ 铜面积、加屏蔽 |
| 传导干扰 | 输入 EMI 滤波器（共模电感 + X/Y 电容），注意与输入电容的阻抗配合 |

**热设计**：损耗清单与主要发热点

| 器件 | 示例损耗 | 备注 |
| --- | --- | --- |
| $Q_1$+$Q_2$ 导通 | ≈1.5 W | 两管各承担一半，需各自散热 |
| $Q_1$+$Q_2$ 开关 | ≈1.6 W | 随 $f_s$ 上升 |
| $D_3$+$D_4$ | ≈5.0 W | **低压输出的第一损耗项** |
| 输出电感 | ≈1.0 W（铜损）+ 铁损 | 大电流时显著 |
| $D_1$+$D_2$ | ≈0.2 W | 几乎可忽略 |
| 磁芯铁损 | 由 $\Delta B$ 、 $f_s$ 与材质决定 | 100 kHz、0.19 T 时需查损耗曲线 |

**总损耗示例约 10~12 W** → 效率约 91%~92%。散热要求：MOSFET 与副边二极管需贴散热器或大面积铜箔散热；变压器与电感注意温升 $\le40\text{ K}$ 。

| # | 检查项 | 判据 / 关注点 |
| --- | --- | --- |
| 1 | 输入电压范围 | $V_{g,min}$ ／ $V_{g,max}$ ／瞬态与掉电保持时间是否考虑 |

| 13 | $D_1$/$D_2$ 耐压 | $\approx V_{g,max}$ （含振铃裕量） |
| 14 | $D_1$/$D_2$ 电流 | 平均 $\approx\frac12 i_{m,pk}D$ ，峰值耐量 + 恢复特性 |

| 16 | $D_3$/$D_4$ 电流 | $DI_o$ 与 $(1-D)I_o$ ，注意 $D_4$ 更大 |
| 17 | 输出电感 | $L=V_o(1-D)/(f_s kI_o)$ ，按最大 $D$ 工况设计 |
| 18 | 电感峰值电流 | $I_o+\Delta I_L/2$ ，饱和电流留 1.2~1.3 倍 |

| 22 | 漏感尖峰 | 实测 $V_{DS}$ 峰值，确认降额 |
| 23 | 吸收电路 | 原边通常不需要；副边是否需要 RC 缓冲 |
| 24 | PCB 高 $\mathrm{d}i/\mathrm{d}t$ 回路 | 斩波回路 + 复位回路面积最小化 |
| 25 | PCB 高 $\mathrm{d}v/\mathrm{d}t$ 节点 | 铜面积小、隔离、屏蔽 |
| 26 | EMI | 传导／辐射预测试，Y 电容与屏蔽层设计 |
| 27 | 热设计 | 各器件温升、变压器／电感温升、寿命评估 |

## 十九、快速小结

| 项目 | 结论 |
| --- | --- |
| 拓扑名称 | 双管正激变换器（Two-Transistor Forward Converter） |
| 电路本质 | 隔离型 Buck：斩波 + 变压器 + 单端整流 + LC 滤波 |
| 开关逻辑 | $Q_1$ 、 $Q_2$ 同开同关，同一路 PWM |
| 复位方式 | $D_1$ 、 $D_2$ 把原边箝到 $-V_g$ ，磁化 + 漏感能量回馈输入 |
| 核心公式 | $V_o=nDV_g$ |
| 最大占空比 | $D_{max}=0.5$ （本拓扑理论极限），工程取值 0.40~0.45 |
| 开关管应力 | $V_{DS}\approx V_g$ （复位期）；空闲期约 $V_g/2$ |
| 副边二极管应力 | $V_R\approx nV_{g,max}=V_o/D_{min}>2V_o$ |
| 三个阶段 | 导通期 → 复位期（ $t_{reset}=DT_s$ ）→ 空闲期（ $(1-2D)T_s$ ） |
| 磁芯工作区间 | $B_r\to B_r+\Delta B$ （单端，利用率低，体积约为双端 2 倍） |
| 输入电容 RMS | $\approx I_{in}\sqrt{(1-D)/D}$ |
| 输出电感纹波 | $\Delta I_L=V_o(1-D)/(Lf_s)$ |
| 最大优势 | 管子耐压低 + 漏感能量回馈，无需 RCD 与复位绕组 |
| 最大代价 | 2 管 2 驱动、 $D\le0.5$ 、磁芯大、副边二极管损耗高 |
| 典型应用 | 300 W~1 kW 高压输入隔离电源；小功率请用单管正激 |
