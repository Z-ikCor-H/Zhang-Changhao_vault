# 半桥隔离 Buck 变换器（Half-Bridge Isolated Buck Converter）

> 原理图（`拓扑图/Half-bridge transformer-isolated buck converter.png`）为最高依据。

---

## 一、拓扑概述

### 1.1 拓扑名称与归类

**半桥隔离型 Buck 变换器**，亦称**半桥正激**。可视为全桥的"减半"版本。

| 归类维度 | 结论 |
|---|---|
| 家族 | **Buck 家族**（隔离衍生） |
| 励磁方式 | **双向励磁**（I/III 象限），磁芯自动复位 |
| 控制变量 | 占空比（**有效占空比** $D_{eff}$ ） |
| 开关管数量 | 2 |
| 整流结构 | 副边中心抽头**全波整流** |

### 1.2 原理图解读

![](拓扑图/Half-bridge%20transformer-isolated%20buck%20converter.png)

| 位置 | 连接 |
|---|---|
| 输入源 | $V_g$ |
| **开关腿**（左） | $Q_1$ （上）+ $D_1$ （其体二极管）； $Q_2$ （下）+ $D_2$ |
| **电容腿**（右） | $C_a$ （上）+ $C_b$ （下），**分压电容** |
| 原边绕组 | **简单绕组**，跨接在**开关腿中点与电容腿中点**之间 |
| 副边绕组 | 中心抽头双半绕组；中心抽头接输出回线 |
| $D_3$ / $D_4$ | 全波整流，两管阴极并接输出正端 |
| 输出滤波 | $L$ 串联 + $C$ 并联 |

> **三个必须看清的点**
> 1. 全桥的**右桥臂（ $Q_3$ 、 $Q_4$ ）被两个分压电容替换**——这是"半桥"名称的来源；
> 2. 原边**一端接开关腿中点、另一端接电容腿中点**——所以原边电压幅值是 $V_g/2$ （全桥是 $V_g$ ）；
> 3. $D_1$ 、 $D_2$ 是 $Q_1$ 、 $Q_2$ 的**体二极管**，不是独立器件，但在死区换流时起关键作用。

### 1.3 宏观工作机理

| 环节 | 功能 |
|---|---|
| ① 分压电容（ $C_a$ 、 $C_b$ ） | 把 $V_g$ 一分为二，中点提供 $V_g/2$ 直流电位，作为原边一端 |
| ② 半桥斩波（ $Q_1$ 、 $Q_2$ ） | $Q_1$ 导通 → 原边 $+V_g/2$ ； $Q_2$ 导通 → $-V_g/2$ ；双极性方波激励 |
| ③ 高频变压器（简单原边 $1:n$ ） | 电压变换 + 电气隔离；双向励磁，自动复位 |
| ④ 全波整流（ $D_3$ 、 $D_4$ ） | 双极性 → 单向脉动 |
| ⑤ LC 滤波 | 输出平滑直流 $V_o$ |

**控制逻辑**： $Q_1$ 、 $Q_2$ **互补驱动**（各 <50% 留死区），调节占空比控制输出。与全桥的本质区别：**原边电压恒为 $V_g/2$**。

### 1.4 中点为什么稳定在 $V_g/2$ （★ 半桥的核心机制）

**① 静态分压**： $C_a=C_b$ 串联跨接 $V_g$ ，中点对地 $=V_g/2$ 。

**② 动态自平衡（真正的保证）**：

| 模态 | 电容状态 |
|---|---|
| $Q_1$ 导通 | $C_a$ 放电、 $C_b$ 充电 → $V_{Ca}\downarrow$ 、 $V_{Cb}\uparrow$ |
| $Q_2$ 导通 | $C_b$ 放电、 $C_a$ 充电 → $V_{Cb}\downarrow$ 、 $V_{Ca}\uparrow$ |

一周期净充放电为零 → 中点稳定。

**③ 更关键的一点——天然隔直**：原边电流的**唯一通路必须经过 $C_a$ 或 $C_b$**，而电容**不能通过直流**。因此：

> **变压器原边不可能有直流电流分量 → 不可能有直流偏磁 → 磁通自动平衡。**

若中点偏离 $V_g/2$ ，则正负半周的伏秒积不等 → 产生直流励磁电流 → 该电流对两电容**差模充放电**，把中点拉回 $V_g/2$ 。**这是一个负反馈自平衡机制。**

> **★ 这是半桥最重要的优点**：**不需要隔直电容、不需要担心偏磁**——而全桥必须外串隔直电容，推挽完全没有这个机制。

### 1.5 优点

1. **开关管少**——仅 2 管 + 2 路驱动，成本约为全桥的 50%
2. **天然隔直、无偏磁风险** ★——分压电容串在原边回路中，这是半桥独有的机制
3. **开关管电压应力低**——$V_{DS}=V_g$ （与全桥相同，**不因省管而变差**）
4. **控制简单**——两管互补，无对角同步约束，死区逻辑容易实现
5. **中功率性价比最高**——100~500W 区间，全桥多出的 2 管 + 2 路隔离驱动是纯浪费

### 1.6 缺点

1. **原边电压减半**——$v_T=\pm V_g/2$ ；同功率、同 $V_g$ 下**原边电流是全桥的 2 倍**
2. **需要大容量分压电容** ★——$C_a$ 、 $C_b$ 流过**全部原边交流电流**，RMS 可达 20A 以上，需大量并联，占用 PCB 面积与成本
3. **导通损耗更高**——原边电流翻倍 → 每管导通损耗 ×4；总导通损耗约为全桥的 2 倍
4. **直通风险与全桥相同**——同桥臂上下管同时导通会**直接短路 $V_g$**（见 §14.3 澄清）
5. **高边驱动需隔离/自举**——$Q_1$ 源极浮动

### 1.7 适用场景

| 场景 | 是否合适 | 原因 |
|---|:---:|---|
| ATX 电脑电源（400V→12V/5V/3.3V） | ✅ **经典应用** | 功率适中（200~500W）、成本敏感、天然隔直 |
| 通信电源模块（48V→12V，200~500W） | ✅ | 半桥范围内比全桥省 2 管 + 2 驱动 |
| 工业辅助电源（100~300W） | ✅ | 可靠性高 + 自带隔直 |
| 大功率（>500W） | ❌ | 原边电流翻倍 → 导通损耗劣势放大 → 用全桥 |
| 超低成本小功率（<100W） | △ | 分压电容占面积，不如反激简单 |
| 低压输入（<100V）+ 中大功率 | ❌ | 推挽更优（同 2 管但磁芯最省、无分压电容） |

**选择逻辑**

```
输入电压 > 100V ?
├── 是 → 功率 > 500W ? → 全桥（原边电流小）
│        功率 100~500W → 半桥 ★（省 2 管 + 天然隔直）
└── 否 → 功率 > 500W ? → 全桥
         功率 100~500W → 推挽（无分压电容、磁芯最省）
```

## 三、电路结构完整拆解

### 3.1 输入侧

| 元件 | 功能 | 关键说明 |
|---|---|---|
| $V_g$ | 直流输入 | 跨接在上下母线 |
| $Q_1$ 、 $Q_2$ | 开关腿（上、下） | 中点接原边一端；**互补驱动** |
| $D_1$ 、 $D_2$ | $Q_1$ 、 $Q_2$ 的**体二极管** | 死区换流时提供续流与能量回馈 |
| $C_a$ 、 $C_b$ | 电容腿（上、下） | **分压 + 隔直**；流过全部原边交流电流 |
| 原边绕组 | 简单绕组 | 跨接在开关腿中点与电容腿中点之间 |

**关键认知**：原边电压 = (开关腿中点电位) − (电容腿中点电位) = (开关腿中点) − $V_g/2$ 。

- $Q_1$ 导通：开关腿中点 $=V_g$ → $v_T=+V_g/2$
- $Q_2$ 导通：开关腿中点 $=0$ → $v_T=-V_g/2$

### 3.2 副边

| 元件 | 功能 |
|---|---|
| $D_3$ 、 $D_4$ | 全波整流，交替导通 |
| $L$ | 输出滤波电感（真正的储能元件） |
| $C$ | 输出滤波电容 |

**死区期间**： $D_3$ 、 $D_4$ **同时导通**续流（各分一半）， $v_s=0$ ， $v_L=-V_o$ 。

## 四、一个完整开关周期的工作过程

| 阶段   | 时段          | 时长           | 开关       | 副边               |
| ---- | ----------- | ------------ | -------- | ---------------- |
| 模态 1 | $[t_0,t_1]$ | $dT_s$       | $Q_1$ 导通 | $D_3$ 导通         |
| 模态 2 | $[t_1,t_2]$ | $(0.5-d)T_s$ | 全关断（死区）  | $D_3$ 、 $D_4$ 同时导通 |
| 模态 3 | $[t_2,t_3]$ | $dT_s$       | $Q_2$ 导通 | $D_4$ 导通         |
| 模态 4 | $[t_3,t_4]$ | $(0.5-d)T_s$ | 全关断（死区）  | $D_3$ 、 $D_4$ 同时导通 |

---

### 4.1 模态 1： $Q_1$ 导通（正半周功率传输）——$[t_0,t_1]$

#### （1）状态表

| 元件 | 状态 |
|---|---|
| $Q_1$ | **ON** |
| $Q_2$ | OFF |
| $D_3$ | **ON** |
| $D_4$ | OFF |
| 变压器 | **正向励磁**（磁通增大） |
| $L_m$ | 储能（励磁电流上升） |
| $C_a$ | **放电**； $C_b$ **充电** |
| $L$ | **储能**（电流上升） |
| $C$ | 充电（同时向负载放电） |

#### （2）原边：电压与电流路径

$Q_1$ 导通 → 开关腿中点被拉到 $V_g$ ；电容腿中点固定 $V_g/2$ ：

$$\boxed{v_T=V_g-\frac{V_g}{2}=+\frac{V_g}{2}}$$

**电流路径**（Anode→Cathode 规范）：

$$V_g(+)\to Q_1(\text{漏}\to\text{源})\to\text{原边绕组}\to\text{电容腿中点}\to C_b\to V_g(-)$$

> **注意**：原边电流**必经 $C_b$ （或 $C_a$ ）**——这正是"天然隔直"的物理来源。回路的另一半是 $C_a$ 经 $V_g$ 源的充电。

- 励磁电流线性上升： $\dfrac{di_m}{dt}=\dfrac{V_g/2}{L_m}$
- 原边电流 = 负载反射电流 + 励磁电流： $i_p=n\,i_L+i_m$

#### （3）开关管电压应力

$Q_1$ 导通时， $Q_2$ 漏极（开关腿中点） $=V_g$ ，源极接地：

$$\boxed{V_{DS}(Q_2)=V_g}$$

> **半桥与全桥的应力相同**（都是 $V_g$ ）——**省了 2 只管子，但每只管子的耐压要求没有降低**。

#### （4）副边

- 原边打点端为正 → 副边打点端为正
- $D_3$ ：**阳极**接副边上端（ $+nV_g/2$ ），**阴极**接输出正端 → **导通**
- $D_4$ ：**阳极**接副边下端（ $-nV_g/2$ ），**阴极**接输出正端 → **截止**
- $D_4$ 承受反向电压：

$$V_{RR}(D_4)=V_o+\frac{nV_g}{2}$$

#### （5）电流与电压

| 量        | 趋势           | 表达式                                        |
| -------- | ------------ | ------------------------------------------ |
| $i_{Q1}$ | 线性上升         | $=n\,i_L+i_m$                              |
| $i_m$    | 线性上升         | $(V_g/2)/L_m$                              |
| $i_{D3}$ | 线性上升         | $=i_L$                                     |
| $i_L$    | 线性上升         | $\dfrac{di_L}{dt}=\dfrac{nV_g/2-V_o}{L}>0$ |
| $v_T$    | $+V_g/2$     | —                                          |
| $v_s$    | $nV_g/2$     | —                                          |
| $v_L$    | $nV_g/2-V_o$ | $>0$                                       |

---

### 4.2 模态 2：死区（全关断）——$[t_1,t_2]$

#### （1）状态表

| 元件               | 状态            |
| ---------------- | ------------- |
| $Q_1$ 、 $Q_2$      | **全 OFF**     |
| $D_3$ 、 $D_4$      | **同时 ON**（续流） |
| 体二极管 $D_1$/$D_2$ | 换流瞬间参与        |
| 变压器              | 原边**零压**，磁通不变 |
| $L$              | **释能**（电流下降）  |
| $C$              | 放电（向负载供电）     |

#### （2）副边：为什么两只二极管同时导通

与全桥/推挽完全相同： $i_L$ 必须连续 → 续流回路强迫 $D_3$ 、 $D_4$ 同时导通 → 副边被短路 → $v_s=0$ → $v_L=-V_o$ 。

#### （3）原边：换流过程（严谨版）

$Q_1$ 关断瞬间，原边电流 $i_p$ 失去沟道路径，分两段处理：

**① 换流瞬间（ns 级）**： $i_p$ 给 $Q_1$ 的 $C_{oss}$ 充电、给 $Q_2$ 的 $C_{oss}$ 放电；同时副边完成 $D_4$ 的正偏换流。

**② 稳定死区**：副边两管同时导通把副边**短路**，经变压器折射到原边 → **原边电压钳位到 $\approx0$**：

$$v_T\approx0\;\Rightarrow\;v_{L_m}\approx0\;\Rightarrow\;i_m\approx\text{const}$$

**③ 漏感能量**：通过 $C_{oss}$ 与**体二极管**完成衰减振荡，能量部分回馈 $V_g$ 、部分损耗散掉。

> **⚠️ 常见错误表述**：不要写"励磁电流通过 $Q_2$ 体二极管续流"。当 $v_T=0$ 时原边两端等电位，体二极管**不具备持续导通条件**。准确表述见上。

> **对输出电压分析**：只需记住 $v_T\approx0$ 、 $v_s=0$ 、 $v_L=-V_o$ 即可。

#### （4）电流与电压

| 量                 | 趋势                    |     |
| ----------------- | --------------------- | --- |
| $i_L$             | 线性下降， $di_L/dt=-V_o/L$ |     |
| $i_{D3}$ 、 $i_{D4}$ | 各 $\approx i_L/2$ ，下降  |     |
| $i_m$             | 近似不变                  |     |
| $v_T$ 、 $v_s$       | $\approx0$            |     |
| $v_L$             | $-V_o$                |     |

---

### 4.3 模态 3 / 模态 4

与模态 1 / 模态 2 完全对称、极性反转：

- 模态 3： $Q_2$ 导通 → 开关腿中点 $=0$ → $v_T=-V_g/2$ ； $C_b$ 放电、 $C_a$ 充电；副边**下端为正** → $D_4$ 导通、 $D_3$ 截止； $v_s$ 经全波整流仍为 $+nV_g/2$ ， $v_L=nV_g/2-V_o>0$ 。
- 模态 4：死区，同模态 2。

         Q1导通       死区        Q2导通       死区

v_g(Q1)  ┌──────┐              ┌──────┐

v_g(Q2)         ┌──────┐              ┌──────┐

## 六、稳态电压传输关系

### 6.1 电路状态（半周期）

| 时段 | 时长 | $v_L$ |
|---|---|---|
| 导通（ $D_3$ 导通） | $d\,T_s$ | $\dfrac{nV_g}{2}-V_o$ |
| 死区（自由续流） | $(0.5-d)T_s$ | $-V_o$ |

### 6.2 推导

$$\underbrace{\left(\frac{nV_g}{2}-V_o\right)\cdot dT_s}_{\text{储能}}+\underbrace{(-V_o)\cdot(0.5-d)T_s}_{\text{释能}}=0$$

展开：

$$\frac{nV_g}{2}dT_s-V_o\,dT_s-0.5V_oT_s+dV_oT_s=0$$

$$\frac{nV_g}{2}d=0.5V_o$$

$$\boxed{V_o=2n\,d\cdot\frac{V_g}{2}=n\,d\,V_g}\qquad\Longleftrightarrow\qquad\boxed{\frac{V_o}{V_g}=n\,D_{eff}}$$

### 6.3 变量定义与适用条件

| 符号 | 含义 | 范围 |
|---|---|---|
| $d$ | 单管占空比 | $0<d<0.5$ |
| $D_{eff}$ | 有效占空比 $=2d$ | $0<D_{eff}<1$ |

**适用条件**：CCM · 理想器件 · 忽略漏感 · 稳态 · 小纹波近似。

### 6.4 三个层次的理解

**① 为什么是 $nD_{eff}$ 而不是 $2nD_{eff}$**：虽然仍是每周期两个脉冲（ $D_{eff}=2d$ ），但每次脉冲的副边电压只有 $nV_g/2$ （全桥是 $nV_g$ ）。两个因子相乘：

$$V_o=\underbrace{\frac{nV_g}{2}}_{\text{每次脉冲幅值}}\times\underbrace{2d}_{D_{eff}}=n\,d\,V_g=n\,D_{eff}\cdot\frac{V_g}{2}\times2$$

**② 三拓扑传输比对照**

| 拓扑     | 传输比                                       | 原边幅值        | 管子数 |
| ------ | ----------------------------------------- | ----------- | --- |
| **半桥** | $V_o=nD_{eff}\dfrac{V_g}{2}\cdot2=n dV_g$ | $\pm V_g/2$ | 2   |
| 推挽     | $V_o=nD_{eff}V_g$                         | $\pm V_g$   | 2   |
| 全桥     | $V_o=nD_{eff}V_g$                         | $\pm V_g$   | 4   |

> **记忆法**：**半桥的 $V_o$ 只有推挽/全桥的一半**（同 $n$ 、同 $D_{eff}$ ）。要补回来，必须把 $n$ 或 $D_{eff}$ 加倍——这就是半桥"原边电流翻倍"的根源。

**③ 设计含义**： $D_{eff}$ 上限 <1（因死区），故 $V_o<nV_g/2$ 。设计时保证最低输入 + 最大占空比下达到目标输出。

## 七、稳态电流关系

### 7.1 输出侧（与 Buck 相同）

| 量 | 表达式 |
|---|---|
| $I_L$ | $=I_o$ |
| $\Delta i_L$ | $\dfrac{V_o(1-D_{eff})T_s}{2L}$ |
| $i_{L,pk}$ | $I_o+\dfrac{\Delta i_L}{2}$ |

### 7.2 原边侧（★ 注意"电流翻倍"）

**导通期原边电流**（效率修正后）：

$$i_{p,on}\approx\frac{nI_o}{\eta}$$

**每管电流**（每管导通 $dT_s=D_{eff}T_s/2$ ）：

| 量 | 推导 | 结果 |
|---|---|---|
| 平均值 | $i_{p,on}\cdot d$ | $I_{Q,avg}=\dfrac{nI_o}{\eta}d$ |
| 有效值 | $i_{p,on}\sqrt{d}$ | $\boxed{I_{Q,rms}=\dfrac{nI_o}{\eta}\sqrt{d}}$ |
| 峰值 | — | $n\!\left(I_o+\tfrac{\Delta i_L}{2}\right)+i_{m,pk}$ |

**功率守恒校验**：

$$P_{in}=V_g\cdot i_{p,on}\cdot D_{eff}=V_g\cdot\frac{nI_o}{\eta}\cdot D_{eff}=\frac{nD_{eff}V_gI_o}{\eta}=\frac{V_oI_o}{\eta}\quad✓$$

> **公式形式与全桥完全相同**（ $I_{Q,rms}=i_{p,on}\sqrt{d}$ ）。**但物理上的差别在 $n$**：
> 同 $V_g$ 、 $V_o$ 、 $P_o$ 下，半桥必须取 $n_{half}\approx2n_{full}$ （因为原边幅值减半），因此
> $$\frac{i_{p,half}}{i_{p,full}}=\frac{n_{half}I_o}{n_{full}I_o}\approx2$$
> **原边电流与每管电流都约为全桥的 2 倍 → 每管导通损耗约 4 倍。**

### 7.3 副边二极管电流

与全桥相同：

$$I_{D,avg}=\frac{I_o}{2},\qquad \boxed{I_{D,rms}=I_o\sqrt{\frac{1+D_{eff}}{4}}},\qquad i_{D,pk}=I_o+\frac{\Delta i_L}{2}$$

> **注意**：与全桥对比，副边的**电流**相同（负载侧不变），但**电压应力更低**（因为 $v_s=nV_g/2$ 只有全桥的一半）——见 §九。

### 7.4 分压电容电流（★ 半桥特有的选型瓶颈）

原边电流的**唯一通路必经 $C_a$ 或 $C_b$**，因此分压电容要承受**全部原边交流电流**：

$$I_{C_a,rms}=I_{C_b,rms}=I_{Q,rms}=i_{p,on}\sqrt{d}$$

> **★ 这是半桥的重大代价**：电容的 RMS 电流需求与开关管相同（本案例 24.8A），而单只电解电容的额定 RMS 电流只有 1~3A → **需要大量并联**，占用 PCB 面积与成本。
>
> **全桥没有这个负担**——这是"省 2 只 MOS 管"换来的隐性代价。

### 7.5 输出与输入电容

$$I_{C,rms}\approx\frac{\Delta i_L}{2\sqrt3}\quad(\text{输出}),\qquad I_{C_{in},rms}=i_{p,on}\sqrt{D_{eff}(1-D_{eff})}\quad(\text{输入})$$

## 八、磁芯复位原理

### 8.1 双向励磁自动复位

| 时段 | $v_T$ | 伏秒积 |
|---|---|---|
| 模态 1（ $dT_s$ ） | $+V_g/2$ | $+\frac{V_g}{2}dT_s$ |
| 模态 3（ $dT_s$ ） | $-V_g/2$ | $-\frac{V_g}{2}dT_s$ |
| 死区 | $\approx0$ | $0$ |

$$\text{净伏秒}=\frac{V_g}{2}dT_s-\frac{V_g}{2}dT_s=0\quad✓$$

### 8.2 ★ 天然隔直——半桥独有的优势

**机制**：原边电流通路**必经 $C_a$/$C_b$**，电容不能通直流 → 原边无直流分量 → **无直流偏磁**。

**自平衡过程**（负反馈）：

```
中点漂移（如 >Vg/2）
→ 正半周伏秒积 > 负半周
→ 产生直流励磁电流
→ 该电流对 Ca、Cb 差模充放电
→ 中点被拉回 Vg/2
```

> **★ 这是半桥相对全桥与推挽的最大优势**：
> - 全桥：**必须外串隔直电容**（或用电流模式控制）
> - 推挽：**完全没有隔直机制**，只能靠对称性，且无自平衡
> - 半桥：**分压电容天然隔直，自平衡**

### 8.3 与全桥/推挽的复位机制对照

| | 半桥 | 全桥 | 推挽 |
|---|---|---|---|
| 复位机制 | 双向励磁 + 电容隔直自平衡 | 双向励磁 | 双向励磁 |
| 隔直机制 | **分压电容天然隔直** ★ | 需外串隔直电容 | **无** |
| 偏磁风险 | **低** ★ | 中 | **高** |

## 九、器件电压应力

### 9.1 理论最大应力

| 器件 | 应力 | 表达式 | 本案例（ $V_{g,max}=60\text{V}$ ） |
|---|---|---|---|
| $Q_1$ / $Q_2$ | $V_{DS}$ | $\boxed{V_{g,max}}$ | **60V** |
| $D_3$ / $D_4$ | $V_{RR}$ | $\boxed{V_o+\dfrac{nV_{g,max}}{2}}$ （保守 $nV_{g,max}$ ） | $12+27=39\text{V}$ （保守 54V） |
| 分压电容 | $V_{Ca}=V_{Cb}$ | $\approx V_g/2$ | 24~30V |

> **两个对比要点**：
> - **MOSFET 应力与全桥相同**（都是 $V_g$ ）——**省管子不等于省耐压**
> - **二极管应力比全桥低一半**（ $v_s$ 减半）——这是半桥对副边的"意外好处"

### 9.2 寄生参数附加应力

| 来源 | 附加量级 |
|---|---|
| 漏感振铃 | 较小（体二极管回馈） |
| PCB 走线电感 | 数 V |
| 二极管反向恢复 | 加剧振铃 |

### 9.3 安全裕量与额定值

$$V_{DS,rated}\ge V_{g,max}\times1.5$$

本案例： $60\times1.5=90\text{V}$ → 选 **100V** 等级。

> 必须以**示波器实测 $V_{DS}$ 波形**确认尖峰 <额定的 80%。

## 十、器件电流应力

### 10.1 理论电流（本案例， $n=0.9$ ， $I_o=41.7\text{A}$ ， $D_{eff,max}=0.741$ ， $\eta=0.92$ ）

$i_{p,on}=\dfrac{nI_o}{\eta}=\dfrac{0.9\times41.7}{0.92}=40.8\text{A}$

| 器件 | 平均值 | 有效值 | 峰值 |
|---|---|---|---|
| $Q_1$/$Q_2$ | $i_{p,on}d=15.1\text{A}$ | $40.8\sqrt{0.370}=24.8\text{A}$ | $\approx n(I_o+\tfrac{\Delta i_L}{2})+i_{m,pk}\approx46\text{A}$ |
| $D_3$/$D_4$ | $\dfrac{I_o}{2}=20.9\text{A}$ | $I_o\sqrt{\dfrac{1+D_{eff}}{4}}=30.8\text{A}$ | $I_o+\tfrac{\Delta i_L}{2}=46.2\text{A}$ |
| **分压电容 $C_a$/$C_b$** | 0 | $\boxed{24.8\text{A}}$ ★ | — |
| 输出电感 $L$ | 41.7A | $\approx41.7\text{A}$ | 46.2A |
| 输出电容 $C$ | 0 | 2.6A | — |
| 输入电容 $C_{in}$ | 0 | $40.8\sqrt{0.741\times0.259}=17.9\text{A}$ | — |

> **★ 三个数字要记住**：
> - 开关管 RMS **24.8A**（全桥同案例为 13.1A —— **约 2 倍**）
> - 分压电容 RMS **24.8A**（全桥**没有**这个负担）
> - 输入电容 RMS **17.9A**（全桥为 10.7A）

### 10.2 器件损耗

**MOSFET**

$$P_{Q,cond}=2I_{Q,rms}^2R_{DS(on)}$$

与全桥的定量对比：

| | 全桥 Buck | 半桥 Buck |
|---|---|---|
| 每管 RMS | $i_p\sqrt{d}=13.1\text{A}$ | $2i_p\sqrt{d}=24.8\text{A}$ |
| 管数 | 4 | 2 |
| 总导通损耗（同 $R$ ） | $4\times13.1^2R=687R$ | $2\times24.8^2R=1230R$ |
| **比值** | 1 | **≈1.8 倍** |

> **结论**：半桥的**每管**导通损耗约 4 倍（ $I^2R$ ），但管子减半，故**总导通损耗约 1.8~2 倍**全桥。注意措辞，不要说"总损耗 4 倍"。

**分压电容损耗**（新增项）：

$$P_{Ca}+P_{Cb}=2\times I_{C,rms}^2\cdot ESR_C$$

> 本案例 24.8A 的 RMS 电流流过 ESR → **这是半桥的隐性损耗**，选低 ESR 电容至关重要。

## 十一、高频变压器设计

### 11.1 匝数比 $n$

$$n=\frac{2V_o}{D_{eff,max}\cdot V_{g,min}}$$

本案例： $n=\dfrac{2\times12}{0.741\times36}=0.9$

**校验最小占空比**：

$$D_{eff,min}=\frac{2V_o}{nV_{g,max}}=\frac{24}{0.9\times60}=0.444$$

$D_{eff}$ 范围 $0.444\sim0.741$ ， $d$ 范围 $0.222\sim0.370$ ✓

> **与全桥对比**：全桥 $n=0.5$ ，半桥 $n=0.9$ —— **半桥的 $n$ 约为全桥的 1.8 倍**，用于补偿"原边电压减半"。

**匝数取整**： $n=0.9$ → 取 $N_p=10$ 、 $N_s=9$ 。

### 11.2 磁芯与匝数

$$\Delta B=\frac{(V_g/2)\cdot d\cdot T_s}{N_pA_e}\quad\Rightarrow\quad\boxed{N_p\ge\frac{(V_{g,max}/2)\cdot d_{min}\cdot T_s}{\Delta BA_e}}$$

> **注意**：与全桥不同，半桥的伏秒积是 $\frac{V_g}{2}\cdot d=\frac{V_o}{2n}=$ **常数**（ $V_g$ 与 $d$ 的乘积不变）→ 磁通摆幅与输入电压无关 ✓

本案例： $\dfrac{V_o}{2n}=\dfrac{12}{1.8}=6.67\text{V}$ ， $\times T_s=66.7\text{V}\cdot\mu s$

取 $A_e=200\text{mm}^2$ 、 $\Delta B=0.1\text{T}$ ：

$$N_p\ge\frac{66.7\times10^{-6}}{0.1\times200\times10^{-6}}=3.3\to\boxed{N_p=10\text{匝（配 n=0.9）}},\qquad N_s=9\text{匝}$$

### 11.3 励磁电流

$$i_{m,pk}=\frac{(V_g/2)\cdot d\,T_s}{L_m}=\frac{66.7\text{V}\cdot\mu s}{L_m}$$

> **半桥的励磁电流是全桥的一半**（ $v_T$ 减半）——同 $L_m$ 下励磁损耗更小。

### 11.4 绕组线径

| 绕组 | RMS 电流 | 所需截面积（4A/mm²） |
|---|---|---|
| 原边 | **≈41A**（导通期电流 × √d... 实际 RMS ≈ 28A） | **7~10mm²** ★ 铜箔 |
| 副边 ×2 | 30.8A | 7.7mm² ← 铜箔 |

> **半桥的原边电流是最大痛点**：必须用厚铜箔或多股并联，窗口利用率是设计难点。

### 11.5 漏感控制

三明治绕法、铜箔、减小绝缘厚度。目标 $L_k\le1\%L_m$ 。

## 十二、输出滤波电感设计

$$L=\frac{V_o\,(0.5-d_{min})\,T_s}{\Delta i_L}=\frac{V_o\,(1-D_{eff,min})}{2f_s\,\Delta i_L}$$

本案例： $d_{min}=0.222$ ， $\Delta i_L=0.2I_o=8.3\text{A}$ ：

$$L=\frac{12\times(0.5-0.222)}{10^5\times8.3}=4.0\mu H\to\text{取 }4.7\mu H$$

要求： $I_{sat}\ge50\text{A}$ 、 $I_{rms}\ge42\text{A}$ 。磁芯与全桥相同（铁硅铝）。

## 十三、电容设计

### 13.1 输出电容

$$C\ge\frac{\Delta i_L}{16f_s\Delta V_C},\qquad ESR\le\frac{\Delta V_{ESR}}{\Delta i_L}$$

本案例： $C\ge8.6\mu F$ 、 $ESR\le7.2\text{m}\Omega$ → 3×100µF/25V 低阻电解 + 2×10µF MLCC。

### 13.2 ★ 分压电容 $C_a$ 、 $C_b$ （半桥特有的选型瓶颈）

**① 容值**（限制中点电压纹波）：

$$C_a=C_b\ge\frac{i_{p,on}\cdot d\,T_s}{\Delta V_{mid}}$$

本案例（ $\Delta V_{mid}\le5\%\times V_g/2=1.2\text{V}$ ， $d=0.370$ ）：

$$C_a=C_b\ge\frac{40.8\times0.370\times10\times10^{-6}}{1.2}=126\mu F$$

**② RMS 纹波电流（真正的瓶颈）**： $I_{C,rms}=24.8\text{A}$

| 方案 | 配置 | 总 RMS |
|---|---|---|
| 电解并联 | 12×100µF/100V 高频低阻 | ≈25A |
| 电解 + 薄膜 | 10×100µF 电解 + 2×10µF 薄膜 | ≈25A |

> **⚠️ 这是半桥最容易被低估的成本项**：24.8A 的 RMS 电流需要十几只电容并联，占用大量 PCB 面积与成本——**常常抵消掉"省 2 只 MOS 管"的收益**。
>
> **对策**：选低 ESR 的高频低阻电解或薄膜电容；必要时提高开关频率（减小 $dT_s$ ）以减小容值需求。

**③ 均压电阻**：在 $C_a$ 、 $C_b$ 上各并联一只 **47kΩ~100kΩ/1W** 电阻，强制静态均压，防止中点漂移（尤其在启动与空载时）。

**④ 耐压**： $\ge1.5\times V_g/2$ （本案例 $V_g/2\le30\text{V}$ → 选 50V 或 100V）。

### 13.3 输入电容

$$C_{in}\ge\frac{i_{p,on}\cdot d\,T_s}{\Delta V_g}$$

**RMS 电流 17.9A** 是瓶颈 → 需多只并联。方案：6×47µF/100V 高频低阻电解。

## 十四、关键工程问题

### 14.1 分压电容的容值不匹配与中点漂移

$C_a$ 、 $C_b$ 容值偏差 → 中点偏离 $V_g/2$ → 正负半周伏秒积不等。

> **但半桥有自平衡能力**（见 §1.4）：直流励磁电流会自动把中点拉回。因此容值偏差不是致命问题（如推挽那样），但会**增大直流励磁电流与损耗**。
>
> **对策**：选同一批次、容值接近的电容；加均压电阻；必要时用电流模式控制。

### 14.2 偏磁（低风险）

半桥的偏磁风险**远低于推挽**（有天然隔直 + 自平衡），但仍不应忽视：

- 驱动不对称、管子压降不一致 → 产生直流励磁电流 → 增加损耗（**注意：不会无限累积，因为电容会阻断直流**）
- 对策：驱动对称设计、均压电阻、电流模式控制

### 14.3 ★ 直通（同桥臂短路）——与全桥同等危险

**必须澄清一个常见误解**：

> **❌ 错误说法**："半桥同桥臂直通时电流被 $C_a$ （或 $C_b$ ）限制，不会立即短路 $V_g$ ，硬故障容错优于全桥。"
>
> **✅ 正确结论**： $C_a$ 、 $C_b$ 是**与开关腿并联的分压支路**，**不在主电流路径上**。 $Q_1$ 、 $Q_2$ 同时导通时，输入母线**经两只 MOSFET 直接短路**——与全桥完全相同，电流极大、管子瞬间损坏。

**必须设置死区**：换向时先关断、后开通，死区需覆盖关断时间（含温度与器件分散性），典型 **100~300ns**。

> **死区过大的代价**：死区期间副边续流、不传能 → $D_{eff}$ 被压缩；且死区会造成输出电压跌落（占空比丢失）。

### 14.4 漏感与振铃

漏感能量经体二极管回馈 $V_g$ （**自带箝位**）→ 尖峰小，**通常不需要 RCD 吸收**。

### 14.5 PCB 布局

| 要求 | 原因 |
|---|---|
| 两桥臂功率环路对称且最小 | 保证正负半周寄生参数一致 |
| 两管驱动走线等长等阻 | 保证互补驱动严格同步 |
| **分压电容紧贴开关腿** | 原边电流回路面积最小化（24.8A 的 RMS！） |
| 均压电阻就近布置 | 静态均压 |
| 高边驱动用隔离/自举 | $Q_1$ 源极浮动 |
| 变压器下方禁止走线 | 避免噪声耦合 |

### 14.6 热设计

- 2 管发热集中（vs 全桥的 4 管分散）→ **每管功耗约为全桥的 4 倍**，散热压力更大
- **高边管需隔离散热器**（源极浮动）
- 分压电容的 ESR 损耗也是热源

### 14.7 EMI

同全桥：桥臂中点高 dv/dt、原边高 di/dt 回路、副边整流振铃。

## 十五、损耗与效率估算

### 15.1 损耗构成（本案例）

| 损耗项 | 公式 | 估算 |
|---|---|---|
| $Q$ 导通 | $2I_{Q,rms}^2R_{DS(on)}\times1.5$ | $2\times24.8^2\times0.005\times1.5=9.2\text{W}$ |
| $Q$ 开关 | $2\times\tfrac12V_{DS}i_{p,on}(t_r+t_f)f_s$ | $2\times0.5\times60\times40.8\times30n\times10^5=7.3\text{W}$ |
| $Q$ 驱动 | $2Q_gV_{gs}f_s$ | ≈0.4W |
| **分压电容 ESR** | $2I_{C,rms}^2ESR_C$ | $2\times24.8^2\times0.005=6.2\text{W}$ ★ |
| 整流二极管 | $2V_FI_{D,avg}$ | $2\times0.5\times20.9=20.9\text{W}$ |
| 整流**同步整流** | $2I_{D,rms}^2R_{DS(on),SR}$ | $2\times30.8^2\times0.005=9.5\text{W}$ |
| 铜损 | $I_P^2R_P+I_S^2R_S$ | ≈10W（原边电流大） |
| 磁芯损耗 | Steinmetz | ≈4W |
| 其他 | — | ≈2W |
| **合计** | | **≈60W（二极管）/ 49W（SR）** |
| **效率** | | **≈89.3% / 91.1%** |

> **与全桥同案例对比**：

| | 全桥 Buck | 半桥 Buck |
|---|---|---|
| 开关管损耗 | 18.5W | 16.9W |
| **分压电容 ESR** | 0 | **6.2W** ★ |
| 铜损（原边电流大） | 8W | 10W |
| 总损耗（SR） | 40W | 49W |
| **效率（SR）** | **92.6%** | **91.1%** |

> **结论**：半桥效率落后约 **1.5 个百分点**，主要来自分压电容的 ESR 损耗与原边铜损。**在 500W 量级，这个差距尚可接受**（换来省 2 管 + 2 驱动）；但功率越大差距越明显。

### 15.2 效率优化优先级

1. **副边整流** → 同步整流
2. **原边铜损**（原边电流是最大痛点）→ 铜箔、优化窗口
3. **分压电容 ESR** → 选超低 ESR 电容/薄膜电容
4. **开关损耗** → 适度降低频率

## 十八、优缺点与适用场景

### 18.1 优点

1. **开关管最少（2 管）+ 应力低（ $V_g$ ）**——同时实现"省管"与"低应力"
2. **★ 天然隔直、无偏磁风险**——分压电容串在原边回路，全桥/推挽都没有这个机制
3. **控制简单**——互补驱动，无对角同步约束
4. **副边二极管应力低**——只有全桥的一半
5. **中功率性价比最高**

### 18.2 缺点

1. **原边电流翻倍**——原边幅值减半的必然结果
2. **★ 分压电容是大负担**——流过全部原边交流电流（本案例 24.8A RMS），需大量并联，占面积、增成本、加损耗
3. **每管导通损耗约 4 倍**（总损耗约 2 倍）
4. **直通风险与全桥相同**（不要误信"电容限流"）
5. **高边驱动需隔离/自举**；高边管散热器需隔离

### 18.3 适用场景结论

> **在"高压输入 + 中功率（100~500W）+ 成本敏感"的条件下，半桥更合适**——它省了 2 只 MOS 管与 2 路隔离驱动，而且**天然隔直**，是推挽与全桥都没有的优势。
>
> **但功率超过 500W 后，"原边电流翻倍 + 分压电容成本"会迅速压过省管的收益**——此时应改用全桥。

## 二十一、学习总结

### 21.1 一句话记住这个拓扑

> **半桥 = 全桥的右桥臂换成两个分压电容。** 省下 2 只管子与 2 路隔离驱动，还白得一个"天然隔直"；代价是原边电压减半 → 原边电流翻倍 → 多了个要流过全部原边电流的分压电容。

### 21.2 五个必须刻在脑子里的数

| 数 | 值 | 来源 |
|---|---|---|
| 原边激励幅值 | $\pm V_g/2$ | 一端接电容腿中点 |
| **开关管电压应力** | $\mathbf{V_g}$ | 与全桥相同（**省管不等于省耐压**） |
| 电压传输比 | $ndV_g$ | 只有推挽/全桥的一半（同 $n$ 、同 $D_{eff}$ ） |
| 原边电流 | 约为全桥 **2 倍** | 原边电压减半的必然 |
| 分压电容 RMS | **= 开关管 RMS** | 原边电流的必经之路 |

### 21.3 三个"为什么"

**Q1：为什么半桥的管子只承受 $V_g$ ，和全桥一样？**
A：因为**桥臂结构没变**。半桥保留的是"开关腿"（ $Q_1$ 上、 $Q_2$ 下），每只管子仍直接跨接在"母线—中点"之间。关断时中点被另一只管拉到对侧母线，所以管子承受的就是 $V_g$ 。被替换掉的是另一条腿（右桥臂），与管子耐压无关。

**Q2：为什么原边电流要翻倍？**
A：原边电压幅值只有 $\pm V_g/2$ （全桥是 $\pm V_g$ ），**要传同样的功率，电流必须翻倍**（ $P=v\cdot i$ ）。这也是分压电容要承担大电流、每管导通损耗变成 4 倍的根源。设计时通常靠**把 $n$ 加倍**来补回来——所以半桥的 $n$ 约为全桥的 2 倍。

**Q3：为什么半桥不怕偏磁，而全桥与推挽怕？**
A：因为**分压电容串在原边电流的必经之路上**。电容不能通过直流，所以原边不可能有直流分量；反过来，一旦出现直流励磁趋势，它会对两电容差模充放电，把中点电压拉回 $V_g/2$——这是一个**负反馈自平衡机制**。全桥的变压器与母线之间没有隔直元件，推挽更是完全没有，所以它们必须靠外部手段（隔直电容/电流模式控制/严格对称）来保证磁通平衡。

### 21.4 学完之后你应该能

- [ ] 看到"开关腿 + 电容腿"立刻说出半桥，并指出 $v_T=\pm V_g/2$
- [ ] 画出 4 个模态的电流路径与状态表
- [ ] 独立完成伏秒平衡推导 $V_o=ndV_g$
- [ ] 说清"分压电容天然隔直 + 自平衡"的负反馈机理
- [ ] 正确算出**分压电容的 RMS 电流**（这是最易漏的选型项）
- [ ] **纠正"半桥直通会被电容限流"的错误认识**
- [ ] 判断什么场合半桥比全桥/推挽更经济
