## 一、拓扑概述

### 1.1 拓扑名称与归类

**推挽式隔离 Buck 变换器**，亦称**推挽正激**（Push-Pull Forward Converter）。可视为"两个正激变换器反向并联"，或"原边中心抽头的全桥变体"。

| 归类维度 | 结论 |
|---|---|
| 家族 | **Buck 家族**（隔离衍生）——输出侧有滤波电感，本质是隔离 Buck |
| 励磁方式 | **双向励磁**（I/III 象限），磁芯自动复位 |
| 控制变量 | 占空比（**单管占空比** $d$ ） |
| 开关管数量 | 2 |
| 整流结构 | 副边中心抽头**全波整流** |

### 1.2 原理图解读

<img src="拓扑图/Push-pull%20isolated%20buck%20converter.png" width="573">

按原理图逐点确认连接关系：

| 位置 | 连接 |
|---|---|
| 输入源 | $V_g$ ，正端接变压器**原边中心抽头** |
| 原边绕组 | **带中心抽头的双半绕组**；上端接 $Q_1$ 漏极，下端接 $Q_2$ 漏极 |
| $Q_1$ / $Q_2$ | N 沟道 MOSFET，源极均接 $V_g$ 负端（共地） |
| 副边绕组 | **带中心抽头的双半绕组**；中心抽头接输出回线 |
| $D_1$ / $D_2$ | 全波整流： $D_1$ 阳极接副边上端、 $D_2$ 阳极接副边下端；**两管阴极并接**输出正端 |
| 输出滤波 | $L$ 串联在整流输出与负载之间， $C$ 并联在负载两端 |

> **三个必须看清的点**
> 1. $Q_1$ 、 $Q_2$ **不是**上下桥臂，而是**各自把一个半绕组的外端拉到地**——中点（中心抽头）接 $V_g^+$ ；
> 2. 中心抽头原边 = 两半绕组**串联**，中点抽头引出。因此 $Q_1$ 导通时励磁方向与 $Q_2$ 导通时**相反**；
> 3. 副边是**中心抽头全波整流**（不是全桥整流），每个时刻只有一只整流管导通——这是推挽副边压降低的优势来源，也是二极管耐压 $\approx 2nV_g$ 的代价来源。

### 1.3 宏观工作机理

| 环节 | 功能 |
|---|---|
| ① 推挽斩波（ $Q_1$ 、 $Q_2$ ） | 两管**交替**导通，分别把两个半绕组外端接地，使原边获得**双极性**方波激励 $\pm V_g$ |
| ② 高频变压器（中心抽头原边 $1:n$ ） | 电压变换 + 电气隔离；双向对称励磁，磁芯在 I/III 象限交替工作 |
| ③ 全波整流（ $D_1$ 、 $D_2$ ） | 双极性方波 → 单向脉动直流，每半周仅一只二极管导通 |
| ④ LC 滤波（ $L$ 、 $C$ ） | 滤除高频分量，输出平滑直流 $V_o$ |

**控制逻辑**： $Q_1$ 、 $Q_2$ **交替导通（同相驱动？不——是反相/互补驱动）**，各自导通时间 $dT_s$ ，两管之间留死区防直通。由于全波整流，**每个开关周期有两个能量脉冲**，输出侧纹波频率为 $2f_s$ 。

> **本质认知**：原边中心抽头 + 两管交替 = 变压器原边获得 $\pm V_g$ 的双极性激励；副边全波整流后，等效于 Buck 的开关节点输出。**这是"隔离版 Buck"，因此 Buck 的全部结论（CCM/DCM 边界、纹波公式、环路模型）都可以平移。**

### 1.4 优点

1. **磁芯利用率最高**——双向励磁（I/III 象限），可用磁通摆幅 $\Delta B$ 远大于单向励磁的正激，同功率下磁芯体积最小
2. **同样原边电压只需 2 只开关管**——$v_T=\pm V_g$ （与全桥相同），但只用 2 管；半桥虽也是 2 管， $v_T$ 却只有 $\pm V_g/2$
3. **副边整流压降低**——全波整流每时刻只有**一只**二极管在回路中（全桥整流有两只串联）
4. **低压场景应力可控**——$V_g\le48\text{V}$ 时 $2V_g\le96\text{V}$ ，选 150V MOS 即可
5. **天然自动复位**——双向励磁，不需要复位绕组、不需要 RCD

### 1.5 缺点

1. **开关管电压应力高**——$V_{DS}=2V_g$ ，是半桥/全桥的 2 倍；高压输入时不可接受
2. **偏磁风险**——两半绕组/两管/两整流管任何一处不对称 → 正负半周伏秒积不等 → 磁芯单向饱和 → 开关管烧毁。这是推挽的**头号失效模式**（详见 §十四）
3. **变压器需中心抽头**——绕制复杂度增加、漏感增大、两半绕组必须严格对称
4. **驱动必须隔离**——$Q_1$ 、 $Q_2$ 源极虽共地，但两管不能共用一个高边参考……
   > **修正说明**：本拓扑两管**源极共地**（都属于低边），因此驱动**不需要**隔离，这是推挽相对于半桥/全桥的一个实际便利。真正的代价是：**两管驱动信号必须严格对称**（否则偏磁）。
5. **电压应力限制功率上限**——$V_g>100\text{V}$ 后 $2V_g>200\text{V}$ ，高压 MOS 的 $R_{DS(on)}$ 与开关损耗急剧恶化

### 1.6 适用场景

> **结论写法**：不写"推挽最好"，而写"**在什么条件下更合适**"。

| 场景 | 是否合适 | 原因 |
|---|:---:|---|
| 低压输入（12~48V）+ 中功率（100W~1kW） | ✅ **最佳** | $2V_g$ 应力可控；2 管实现 $\pm V_g$ 激励，磁芯利用率最高 |
| 车载 DC-DC、低压隔离模块 | ✅ | 低压大电流正是推挽的舒适区 |
| 高压输入（>200V）+ 任意功率 | ❌ | $2V_g>400\text{V}$ → 用半桥/全桥 |
| 输入 >100V + 大功率（>1kW） | ❌ | 用全桥（应力更低，可 ZVS） |
| 低压 + 小功率（<100W） | △ 可用但不经济 | 反激更简单便宜 |

**选择逻辑**

```
输入电压 < 100V ?
├── 是 → 功率 > 500W ?  → 全桥（4 管但可 ZVS，电流应力低）
│        功率 100~500W → 推挽（2 管、磁芯最小、2Vg 可控）
│        功率 < 100W   → 反激 / 正激
└── 否 → 功率 > 2kW ?  → 全桥
         功率 200W~2kW → 半桥（应力低、成本最低）
```

### 2.2 ★ 占空比定义（本拓扑关键）

| 符号 | 定义 | 范围 | 说明 |
|---|---|---|---|
| $d$ | **单管占空比** $=t_{on}/T_s$ | $0<d<0.5$ | $Q_1$ （或 $Q_2$ ）各自的导通时间占比 |
| $D_{eff}$ | **有效占空比** $=2d$ | $0<D_{eff}<1$ | 每周期两个功率脉冲的合计占比 |

$$\boxed{D_{eff}=2d}$$

> **与原笔记的对应关系**：若你之前读的是把单管占空比记作 $D$ 、有效占空比记作 $2D$ 的版本，那么**本笔记的 $d$ = 原版本的 $D$**。本笔记统一用 $d$/$D_{eff}$ ，目的是与半桥、全桥笔记的 $D_{eff}=2d$ 口径完全一致，便于横向比较（半桥/全桥的 $V_o=nD_{eff}V_g/2$ 与 $nD_{eff}V_g$ 可直接对照）。
>
> **死区**： $t_d=T_s/2-dT_s=(1-2d)T_s/2$ ，每半周一个死区，一周期共两个。

### 2.3 匝比定义

$$n=\frac{N_s}{N_{p,half}}$$

- $N_{p,half}$ ＝**半个原边绕组**的匝数（中心抽头把原边分成两半，两半匝数相同）
- $N_s$ ＝**半个副边绕组**的匝数（副边同样中心抽头）
- $N_p$ （总原边匝数） $=2N_{p,half}$

> 原理图标注 "1 : n"，即半原边 : 半副边 $=1:n$ 。
> **所有公式中的 $n$ 都按此定义**，禁止改用其他口径。

## 三、电路结构完整拆解

### 3.1 输入侧

| 元件 | 功能 | 关键说明 |
|---|---|---|
| $V_g$ | 直流输入 | 接原边**中心抽头** |
| $Q_1$ | 上管 | 导通时把**上半绕组外端**拉到 $V_g^-$ ，激励上半绕组 |
| $Q_2$ | 下管 | 导通时把**下半绕组外端**拉到 $V_g^-$ ，激励下半绕组 |
| 原边绕组 | 中心抽头双半绕组 | 两半**串联**、匝数相同、**绕向相反**（使两管激励的磁通方向相反） |

**同名端与极性**：原理图中原边两个半绕组的打点端（·）位于**外侧两端**（上端、下端），副边打点端（·）位于**外侧两端**。这意味着：

- 当 $Q_1$ 导通（上端接地）时：电流自中心抽头**流入**上半绕组、从上端流出 → 上半绕组电压"中心抽头为正"
- 副边感应：副边**上端为正**（打点端对应打点端） → $D_1$ 阳极正偏 → $D_1$ 导通
- 当 $Q_2$ 导通时，一切极性反转 → 副边**下端为正** → $D_2$ 导通

> **为什么两个半绕组要反向绕制？** 只有反向绕制（打点端分居外侧），才能让"电流都从中心抽头流入"的两半绕组产生**方向相反**的磁通，从而实现双向励磁。若同向绕制，两管激励的磁通会同向叠加 → 磁芯单向饱和。

### 3.2 副边

| 元件 | 功能 | 关键说明 |
|---|---|---|
| $D_1$ | 整流二极管（上半周） | 导通期间向 $L$ 与负载输送能量 |
| $D_2$ | 整流二极管（下半周） | 与 $D_1$ 交替导通 |
| $L$ | 输出滤波电感 | **真正的储能元件**；CCM 下电流连续 |
| $C$ | 输出滤波电容 | 吸收纹波、支撑 $V_o$ |
| $R_o$ | 负载 | |

**死区期间的副边**： $D_1$ 、 $D_2$ 会**同时导通**，共同承担电感续流（各分一半电流），此时副边被两只二极管"正向短路"， $v_s=0$ 。详见 §四 模态 2。

## 四、一个完整开关周期的工作过程

**总览**：CCM 下一个周期分 **4 个阶段**

| 阶段 | 时段 | 时长 | 主开关 | 副边 |
|---|---|---|---|---|
| 模态 1 | $[t_0,t_1]$ | $dT_s$ | $Q_1$ 导通 | $D_1$ 导通 |
| 模态 2 | $[t_1,t_2]$ | $(0.5-d)T_s$ | 全关断（死区） | $D_1$ 、 $D_2$ 同时导通（续流） |
| 模态 3 | $[t_2,t_3]$ | $dT_s$ | $Q_2$ 导通 | $D_2$ 导通 |
| 模态 4 | $[t_3,t_4]$ | $(0.5-d)T_s$ | 全关断（死区） | $D_1$ 、 $D_2$ 同时导通（续流） |

> **模态 3、4 与 1、2 完全对称**（仅极性反转），下面重点展开模态 1、2，模态 3、4 只做对照。

---

### 4.1 模态 1： $Q_1$ 导通（上半周功率传输）——$[t_0,t_1]$

#### （1）状态表

| 元件 | 状态 |
|---|---|
| $Q_1$ | **ON** |
| $Q_2$ | OFF |
| $D_1$ | **ON** |
| $D_2$ | OFF |
| 变压器 | **正向励磁**（磁通增大） |
| $L_m$ | 储能（励磁电流上升） |
| $L$ （输出电感） | **储能**（电流上升） |
| $C$ | 充电（同时向负载放电） |

#### （2）原边：电压极性与电流路径

$Q_1$ 导通 → 上半绕组外端被拉到 $V_g^-$ （0V）；中心抽头固定在 $V_g$ ：

$$v_{T,upper}=V_g\quad(\text{中心抽头为正})$$

下半绕组经磁耦合感应出同名电压，其外端（ $Q_2$ 漏极）被顶到：

$$v_{Q_2,\text{drain}}=V_g+V_g=\boxed{2V_g}$$

> **这就是推挽"$2V_g$ 应力"的来源**——不是某个开关动作产生的，而是**中心抽头电位 + 半绕组感应电压叠加**的必然结果。原理：中心抽头被输入源钳在 $V_g$ ；下半绕组与上半绕组同匝数、同磁通，感应电压大小相等，方向使外端电位在中心抽头之上再抬 $V_g$ 。

**电流路径**（Anode→Cathode 规范描述）：

$$V_g(+) \to \text{中心抽头} \to \text{上半绕组（自打点端流入）} \to Q_1(\text{漏}\to\text{源}) \to V_g(-)$$

- 励磁电流自中心抽头流入打点端 → **磁芯正向励磁，磁通增大**
- 原边电流 = 负载反射电流 + 励磁电流： $i_p=n\,i_L+i_m$

#### （3）副边：二极管为什么这样导通

- 原边打点端（上端）电位高于中心抽头 → 副边打点端（上端）电位也高
- $D_1$ ：**阳极**接副边上端（正电位），**阴极**接输出正端 → 正偏 → **导通**
- $D_2$ ：**阳极**接副边下端（负电位），**阴极**接输出正端 → 反偏 → **截止**，承受反向电压

$$V_{RR}(D_2)=\underbrace{V_o}_{\text{阴极电位}}+\underbrace{nV_g}_{\text{阳极负电位绝对值}}=V_o+nV_g$$

> **注意**：工程上常把全波整流二极管的 PIV 直接写成 $2nV_g$ 。严格式是 $V_o+nV_g$ ；因为恒有 $V_o<nV_g$ （ $D_{eff}<1$ ），所以 $2nV_g$ 是**保守值**。选型时用严格式算，再加漏感振铃裕量。

#### （4）电流与电压

| 量 | 趋势 | 表达式 |
|---|---|---|
| $i_{Q1}$ | 线性上升 | $i_{Q1}=n\,i_L+i_m$ |
| $i_m$ | 线性上升 | $\dfrac{di_m}{dt}=\dfrac{V_g}{L_m}$ |
| $i_{D1}$ | 线性上升 | $i_{D1}=i_L$ |
| $i_{D2}$ | $0$ | 截止 |
| $i_L$ | 线性上升 | $\dfrac{di_L}{dt}=\dfrac{nV_g-V_o}{L}>0$ |
| $v_T$ | $+V_g$ | （上半绕组） |
| $v_s$ | $nV_g$ | 上正下负 |
| $v_L$ | $nV_g-V_o$ | $>0$ ，电感储能 |

---

### 4.2 模态 2：死区（ $Q_1$ 、 $Q_2$ 均关断）——$[t_1,t_2]$

#### （1）状态表

| 元件 | 状态 |
|---|---|
| $Q_1$ / $Q_2$ | **全 OFF** |
| $D_1$ | **ON**（续流） |
| $D_2$ | **ON**（续流） |
| 变压器 | 原边**近似零压**，励磁电流保持 |
| $L_m$ | 保持（两端≈0V） |
| $L$ | **释能**（电流下降） |
| $C$ | 放电（向负载供能） |

#### （2）副边：为什么两只二极管会同时导通

**这是理解死区的关键，按四步推理：**

1. **输出电感电流 $i_L$ 不能突变**——原边已全部关断，没有能量从原边送来，但 $i_L$ 必须继续流。
2. **续流回路强迫 $D_1$ 、 $D_2$ 同时导通**——路径为：
   $$L \to \text{负载/}C \to \text{输出回线} \to \text{副边中心抽头} \to \begin{cases}\text{上半绕组}\to D_1\\\\\text{下半绕组}\to D_2\end{cases} \to \text{汇合} \to L$$
   两管**平分**电感电流： $i_{D1}\approx i_{D2}\approx i_L/2$ 。
3. **两管同时导通 ⇒ 副边被短路 ⇒ $v_s=0$**——两半绕组两端被两只正向导通的二极管钳死，变压器"想感应也抬不起电压"。
4. **KVL 回代**： $v_L=v_s-V_o=0-V_o=-V_o$ 。

> **这本质上就是 Buck 的 off-time**：电感通过二极管续流、两端电压被输出电容反向钳位。

#### （3）原边：换流的真实过程（严谨版）

原边的情况比分边微妙，分两段说清：

**① 换流瞬间（ns 级）**： $Q_1$ 关断瞬间，原边电流 $i_p=n i_L+i_m$ 突然失去沟道通路。这个电流驱动 $Q_1$/$Q_2$ 的 $C_{oss}$ 充放电——给 $Q_1$ 的 $C_{oss}$ 充电、给 $Q_2$ 的 $C_{oss}$ 放电。同时副边在极短时间内完成 $D_2$ 的正偏换流。

**② 稳定死区**：副边两管同时导通把副边**短路**，该短路经变压器折射到原边，使**原边电压被钳位到 $\approx0$**（ $v_T\approx0$ ），因此：

$$v_{L_m}\approx0\;\Rightarrow\;i_m\approx\text{const}$$

即**励磁电流在死区近似保持不变**。

> **⚠️ 常见错误表述**：不要写成"励磁电流通过 $Q_2$ 体二极管续流"。当 $v_T=0$ 时原边两端等电位，体二极管**不具备导通条件**。准确说法是：**副边续流短路折射到原边，把原边电压钳到零，励磁电流由于 $L_m$ 两端零压而保持不变；残余的漏感电流通过 $C_{oss}$ 与体二极管完成衰减振荡（能量部分回馈电源，部分以损耗散掉）。**

> **对输出电压分析而言**，只需记住 $v_T\approx0$ 、 $v_s=0$ 、 $v_L=-V_o$ 三个结论即可——这正是工程上足够精确的模型。

#### （4）电流与电压

| 量 | 趋势 | 说明 |
|---|---|---|
| $i_L$ | 线性下降 | $\dfrac{di_L}{dt}=-\dfrac{V_o}{L}<0$ |
| $i_{D1}$ 、 $i_{D2}$ | 各 $\approx i_L/2$ ，下降 | 同时续流 |
| $i_m$ | 近似不变 | $v_{L_m}\approx0$ |
| $v_s$ | $\approx0$ | 副边短路钳位 |
| $v_L$ | $-V_o$ | 电感释能 |

---

### 4.3 模态 3 / 模态 4

与模态 1 / 模态 2 **完全对称，仅极性反转**：

- 模态 3： $Q_2$ 导通 → 下半绕组外端接地 → 中心抽头仍为 $V_g$ ，故 $v_{T,lower}=-V_g$ （与参考方向相反）； $Q_1$ 漏极被顶到 $2V_g$ ；副边**下端为正** → $D_2$ 导通、 $D_1$ 截止； $v_s$ 经全波整流后**仍为上正下负**（ $nV_g$ ）， $v_L=nV_g-V_o>0$ 。
- 模态 4：与模态 2 对称， $D_1$ 、 $D_2$ 同时续流， $v_L=-V_o$ 。

> **注意**：全波整流的作用就是让"副边极性反转"变成"输出极性不变"。这是推挽副边波形与半桥/全桥相同的根本原因。

## 五、关键波形

### 5.1 一个周期的波形（理想、CCM）

```
             模态1        模态2        模态3        模态4
             Q1导通       死区         Q2导通       死区
             ←  dTs  →   ←(0.5-d)Ts→  ←  dTs  →  ←(0.5-d)Ts→

 v_g(Q1栅)  ┌──────┐              ┌──────┐
            ┘      └──────────────┘      └──────────
 v_g(Q2栅)         ┌──────┐              ┌──────┐
            ───────┘      └──────────────┘      └────

 v_T (原边)  +Vg  │   0    │   -Vg   │   0
            ─────┼────────┼─────────┼────────

 v_s (副边)  nVg  │   0    │   nVg   │   0     ← 整流后极性不变
            ─────┼────────┼─────────┼────────

 v_L        nVg-Vo│  -Vo   │ nVg-Vo  │  -Vo
            ─────┼────────┼─────────┼────────

 i_L (输出)  上升 │  下降   │  上升   │  下降    ← 纹波频率 = 2fs
            ─────┼────────┼─────────┼────────

 i_m (励磁)  正增 │  持平   │  负增   │  持平
            ─────┼────────┼─────────┼────────

 V_DS(Q1)     0   │  ≈Vg   │  2Vg   │  ≈Vg     ← 关断瞬间有漏感振铃
            ─────┼────────┼─────────┼────────

 i_D1        i_L  │ i_L/2  │   0    │ i_L/2
 i_D2         0   │ i_L/2  │  i_L   │ i_L/2
```

### 5.2 波形要点解读

| 观察 | 物理原因 |
|---|---|
| $i_L$ 纹波频率 $=2f_s$ | 每周期两个能量脉冲 → 输出滤波压力小，同等 $L$/$C$ 下纹波更低 |
| $V_{DS}$ 在关断瞬间出现高于 $2V_g$ 的振铃 | 漏感 $L_k$ 与 $C_{oss}$ 、二极管结电容谐振（见 §十四） |
| 死区时 $V_{DS}\approx V_g$ （不是 $2V_g$ ） | 副边续流短路折射回原边，把原边钳到零 → 两管漏极分别被钳在 $\approx V_g$ |
| $v_s$ 在死区为 0 而非负值 | 两只整流管同时导通把副边短路 |

> **与半桥/全桥的波形关系**：形状**完全相同**，唯一区别是幅值——推挽与全桥 $v_T=\pm V_g$ ，半桥 $v_T=\pm V_g/2$ 。

## 六、稳态电压传输关系

### 6.1 物理意义

输出电感 $L$ 是真正的储能元件。稳态下它每周期吸收的伏秒积必须等于放出的伏秒积，否则电流会单向漂移 → 这就是伏秒平衡。

### 6.2 电路状态（一个半周期即可，因半周期对称）

以模态 1 + 模态 2 为半周期 $T_s/2$ ：

| 时段 | 时长 | $v_L$ |
|---|---|---|
| 导通（ $D_1$ 导通） | $d\,T_s$ | $nV_g-V_o$ |
| 自由续流（ $D_1$ 、 $D_2$ 同时导通） | $(0.5-d)T_s$ | $-V_o$ |

### 6.3 推导

$$\underbrace{(nV_g-V_o)\cdot dT_s}_{\text{储能}}+\underbrace{(-V_o)\cdot(0.5-d)T_s}_{\text{释能}}=0$$

展开：

$$nV_g\,dT_s-V_o\,dT_s-0.5V_oT_s+dV_oT_s=0$$

$$nV_g\,d=V_o\cdot0.5$$

$$\boxed{V_o=2n\,d\,V_g}\qquad\Longleftrightarrow\qquad\boxed{\frac{V_o}{V_g}=2n\,d=n\,D_{eff}}$$

### 6.4 变量定义与适用条件

| 符号 | 含义 | 范围 |
|---|---|---|
| $V_g$ | 输入直流电压 | — |
| $n$ | 匝比 $N_s/N_{p,half}$ | — |
| $d$ | **单管**占空比 | $0<d<0.5$ |
| $D_{eff}$ | 有效占空比 $=2d$ | $0<D_{eff}<1$ |
| $V_o$ | 输出直流电压 | — |

**适用条件**：CCM · 理想器件 · 忽略漏感 · 稳态 · 小纹波近似。

### 6.5 三个层次的理解

**① 为什么是 $2n$**：每周期有**两个**能量脉冲（ $Q_1$ 一个、 $Q_2$ 一个），所以等效开关频率翻倍、等效占空比翻倍。这是推挽"2 管顶全桥"的数学来源。

**② 与全桥数学等价**

| 拓扑 | 传输比 | 原边激励幅值 | 开关管数 |
|---|---|---|---|
| 推挽 | $V_o=nD_{eff}V_g$ | $\pm V_g$ | **2** |
| 全桥 | $V_o=nD_{eff}V_g$ | $\pm V_g$ | 4 |
| 半桥 | $V_o=nD_{eff}V_g/2$ | $\pm V_g/2$ | 2 |

> 推挽用 **2 只管子**实现与全桥 4 管相同的传输比与原边激励幅值，**代价是每管承受 $2V_g$ 而非 $V_g$**——这是推挽最核心的 trade-off。

**③ 对设计的含义**： $D_{eff}$ 上限 < 1（因死区），故 $V_o< nV_g$ 。设计时必须保证在**最低输入电压 + 最大占空比**下仍能达到目标 $V_o$ 。

## 七、稳态电流关系

### 7.1 输出侧（与 Buck 完全相同）

| 量 | 表达式 | 说明 |
|---|---|---|
| $I_L$ | $=I_o$ | 电感平均电流 = 负载电流 |
| $\Delta i_L$ | $\dfrac{V_o(0.5-d)T_s}{L}$ | 峰峰纹波（见 §十二 推导） |
| $i_{L,pk}$ | $I_o+\dfrac{\Delta i_L}{2}$ | 峰值 |
| $i_{L,min}$ | $I_o-\dfrac{\Delta i_L}{2}$ | 谷值；CCM 要求 $>0$ |
| $I_{L,rms}$ | $\sqrt{I_o^2+\dfrac{\Delta i_L^2}{12}}$ | 正交分解； $\Delta i_L\ll I_o$ 时 $\approx I_o$ |

### 7.2 原边侧

**反射负载电流**（瞬时值，折算到半原边）：

$$i_{p,\text{load}}=n\,i_L\approx nI_o$$

**峰值（含纹波与励磁）**：

$$i_{p,pk}=n\left(I_o+\frac{\Delta i_L}{2}\right)+i_{m,pk}$$

**每管电流**（每管只在自己那半个周期导通）：

| 量 | 推导 | 结果 |
|---|---|---|
| 平均值 | 导通期电流 $\approx nI_o$ ，占比 $d$ | $I_{Q,avg}=n\,d\,I_o$ |
| 有效值 | $\sqrt{\dfrac{1}{T_s}\displaystyle\int_{on}(n i_L)^2dt}=n\sqrt{d}\sqrt{I_o^2+\tfrac{\Delta i_L^2}{12}}$ | $I_{Q,rms}\approx nI_o\sqrt{d}$ |
| 峰值 | 见上 | $i_{p,pk}$ |

> **效率修正**：实际输入电流要按 $\eta$ 放大，一阶修正为 $i_p\to nI_o/\eta$ 。故工程估算用
> $$I_{Q,avg}=\frac{n\,d\,I_o}{\eta},\qquad I_{Q,rms}=\frac{n\,I_o}{\eta}\sqrt{d}$$
> **功率守恒校验**： $P_{in}=2V_gI_{Q,avg}=2V_g\cdot\dfrac{ndI_o}{\eta}=\dfrac{2ndV_gI_o}{\eta}=\dfrac{V_oI_o}{\eta}=P_o/\eta$ ✓

### 7.3 副边二极管电流

每只二极管在**自己的半周**导通（承担全部 $i_L$ ），在两个死区中各承担 $i_L/2$ ：

$$I_{D,avg}=d\,I_o$$

$$I_{D,rms}^2=\frac{1}{T_s}\left[\int_{on}i_L^2dt+\int_{2\times\text{dead}}\left(\frac{i_L}{2}\right)^2dt\right]\approx I_o^2\left[d+\frac{1-2d}{4}\right]$$

$$\boxed{I_{D,rms}=I_o\sqrt{\frac{1+2d}{4}}=I_o\sqrt{0.25+0.5d}}$$

$$i_{D,pk}=I_o+\frac{\Delta i_L}{2}$$

> **对比全桥整流**：全波整流每只二极管的导通占空比是 $d$ （而非全桥的 $D_{eff}$ ），但每时刻只有 1 只在回路 → **压降低**；代价是耐压翻倍（ $\approx2nV_g$ ）。

## 八、磁芯复位原理

### 8.1 推挽为什么"天然复位"

推挽采用**双向励磁**，不需要任何复位电路：

| 时段 | 磁通变化 | 伏秒积 |
|---|---|---|
| 模态 1（ $Q_1$ ， $dT_s$ ） | 正向增长 | $+V_g\cdot dT_s$ |
| 模态 3（ $Q_2$ ， $dT_s$ ） | 反向增长 | $-V_g\cdot dT_s$ |
| 模态 2 / 4（死区） | 近似不变 | $0$ （ $v_T\approx0$ ） |

一周期净伏秒积：

$$V_g\,dT_s-V_g\,dT_s=0\quad\Rightarrow\quad\text{磁通自动回到起点}$$

**磁芯在 B-H 曲线的 I、III 象限对称工作**，工作点围绕原点对称摆动，因此可用摆幅接近 $2B_{max}$ （单向励磁的正激只能用 $B_{max}-B_r$ 那一段）。

### 8.2 如果没有这个机制会怎样

推挽**没有**"天然复位"的替代路径。一旦正负半周伏秒积不相等（驱动不对称、绕组不对称、管子压降不对称……），净伏秒积不为零：

$$\Delta\Phi_{net}=\int_0^{T_s}v_Tdt\neq0$$

磁通**逐周期累积** → 工作点单向漂移 → 数个周期后进入饱和 → 励磁电感骤降 → 电流尖峰 → 管子烧毁（详见 §十四偏磁）。

> **这一点与双管正激形成鲜明对比**：双管正激靠 $D_1$/$D_2$ 把励磁能量回馈电源，是**强制复位**；推挽靠**对称**实现自然复位，**没有回馈通路，也没有矫正机制**——所以推挽对"对称性"的要求是硬约束，而不是优化项。

## 九、器件电压应力

### 9.1 理论最大应力（理想器件、忽略漏感）

| 器件 | 应力 | 表达式 | 本案例（ $V_{g,max}=32\text{V}$ ） |
|---|---|---|---|
| $Q_1$ / $Q_2$ | $V_{DS}$ | $\boxed{2V_{g,max}}$ | 64V |
| $D_1$ / $D_2$ | $V_{RR}$ | $\boxed{V_o+nV_{g,max}}$ （保守取 $2nV_{g,max}$ ） | $12+24=36\text{V}$ （保守 48V） |
| 原边绕组 | 匝间电压 | $V_g\cdot2$ （半绕组间） | — |

**$2V_g$ 的推导**（见 §四 模态 1）： $Q_1$ 导通时，中心抽头被 $V_g$ 钳位，下半绕组感应出等幅电压，故 $Q_2$ 漏极 $=V_g+V_g=2V_g$ 。

> **为什么不是 $V_g$ ？** 因为 $Q_1$ 、 $Q_2$ 不是桥臂上下管（它们**共地**）。关断管承受的是"中心抽头电位 + 另一半绕组的感应电压"，两者串联叠加。半桥/全桥之所以只有 $V_g$ ，是因为它们的开关管直接跨接在母线上。

### 9.2 寄生参数附加应力

| 来源 | 附加量级 | 机理 |
|---|---|---|
| **漏感尖峰** | $+\Delta V_{spike}$ ，可达 $0.3\sim1\times V_g$ | $L_k$ 与 $C_{oss}$ 谐振，能量无处回馈（推挽无箝位通路） |
| PCB 走线电感 | 数 V ~ 十几 V | 高 di/dt 回路 |
| 二极管反向恢复 | 加剧尖峰 | $D_1$/$D_2$ 的 $Q_{rr}$ 注入原边 |
| 振铃 | 叠加阻尼振荡 | 寄生 LC |

> **推挽的漏感尖峰比双管正激严重**：双管正激的 $D_1$/$D_2$ 提供天然箝位通路，漏感能量可以回馈 $V_g$ ；而推挽**没有这个通路**，漏感能量只能靠 $C_{oss}$ 吸收 + 阻尼耗散，因此尖峰更高。这是推挽需要额外注意的地方（详见 §十四）。

### 9.3 安全裕量与额定值

$$V_{DS,rated}\ge \underbrace{2V_{g,max}}_{\text{理论}}\times\underbrace{1.5}_{\text{尖峰+降额}}$$

本案例： $64\text{V}\times1.5=96\text{V}$ → 选 **150V** 等级。

> **⚠️ 强制要求**：最终必须结合**示波器实测 $V_{DS}$ 波形**确认尖峰不超过额定的 80%。计算值只是起点。

## 十、器件电流应力

### 10.1 理论电流（本案例 $n=0.75$ ， $I_o=25\text{A}$ ， $d_{max}=0.45$ ， $\eta=0.92$ ）

| 器件 | 平均值 | 有效值 | 峰值 |
|---|---|---|---|
| $Q_1$/$Q_2$ | $\dfrac{ndI_o}{\eta}=9.2\text{A}$ | $\dfrac{nI_o}{\eta}\sqrt{d}=13.7\text{A}$ | $n\left(I_o+\tfrac{\Delta i_L}{2}\right)+i_{m,pk}\approx23.4\text{A}$ |
| $D_1$/$D_2$ | $dI_o=11.3\text{A}$ | $I_o\sqrt{0.25+0.5d}=17.2\text{A}$ | $I_o+\tfrac{\Delta i_L}{2}=27.5\text{A}$ |
| 输出电感 $L$ | $I_o=25\text{A}$ | $\approx25\text{A}$ | 27.5A |
| 输出电容 $C$ | 0 | $\approx\tfrac{\Delta i_L}{2\sqrt3}=1.4\text{A}$ | — |
| 输入电容 $C_{in}$ | 0 | $nI_o\sqrt{2d(1-2d)}=5.6\text{A}$ | — |

> **输入电容 RMS 的推导**：输入电流 $i_{in}$ 是每周期**两个**脉冲（各宽 $dT_s$ 、幅值 $nI_o$ ）。
> $$I_{in,avg}=2d\,nI_o,\quad I_{in,rms}=nI_o\sqrt{2d},\quad I_{C_{in},rms}=\sqrt{I_{in,rms}^2-I_{in,avg}^2}=nI_o\sqrt{2d(1-2d)}$$

### 10.2 器件损耗

**MOSFET**

$$P_{Q,cond}=I_{Q,rms}^2R_{DS(on)}(T_j)$$
$$P_{Q,sw}\approx\frac{1}{2}V_{DS}I_{Q,pk}(t_r+t_f)f_s\quad(\text{每管每周期一次的硬开关})$$
$$P_{Q,drive}=Q_gV_{gs}f_s$$

> $R_{DS(on)}$ 随结温上升（硅管 100°C 约为 25°C 标称值的 1.4~1.7 倍），估算时乘 **1.5**。

**二极管**

$$P_D=V_F\cdot I_{D,avg}+\underbrace{\tfrac{1}{2}V_RQ_{rr}f_s}_{\text{反向恢复}}$$

> 用**超快恢复或肖特基/SiC** 可显著降低第二项。低压输出场合优先肖特基（ $V_F$ 低、无反向恢复）。

## 十一、高频变压器设计

### 11.1 匝数比 $n$

**设计原则**：在**最低输入电压、最大占空比**下达到目标输出（留死区与调节余量）。

$$n=\frac{V_o}{2\,d_{max}\,V_{g,min}}$$

本案例： $n=\dfrac{12}{2\times0.45\times18}=\dfrac{12}{16.2}=0.741$ → 取 $n=0.75$ 。

**校验最小占空比**（最高输入时）：

$$d_{min}=\frac{V_o}{2nV_{g,max}}=\frac{12}{2\times0.75\times32}=0.25$$

$d_{min}=0.25$ ：远离 0（控制分辨率足够）、远离 0.5（死区充足）✓

**匝数取整**： $N_{p,half}:N_s=1:0.75=4:3$ → 取 $N_{p,half}=4$ ， $N_s=3$ 。

> 取整后实际 $n=3/4=0.75$ ✓ 无需重算。若不能整除，必须**反算校验** $d_{max}$ 与 $V_o$ （见 §十六 实例中的做法）。

### 11.2 磁芯选择

**选型依据**：

| 因素 | 本案例取值 |
|---|---|
| 工作频率 | 100kHz → 铁氧体 **PC40 / PC44** |
| 传输功率 | 300W → EE42 / PQ3230 量级（ $A_e\approx180\sim230\text{mm}^2$ ） |
| 磁通摆幅 | 双向励磁可用 $\Delta B=0.2\sim0.3\text{T}$ （受铁损限制，100kHz 取 0.2T 偏保守） |
| 温升 | 目标 <40K |

> **推挽的磁芯优势**：双向励磁 → $\Delta B$ 可用摆幅大 → 同功率磁芯体积最小。

### 11.3 原边匝数

由 $v=N A_e\dfrac{dB}{dt}$ 积分得磁通摆幅：

$$\Delta B=\frac{V_g\,d\,T_s}{N_{p,half}A_e}$$

反解得最小匝数：

$$\boxed{N_{p,half}\ge\frac{V_{g,max}\,d_{min}\,T_s}{\Delta B_{allow}A_e}}$$

> **注意：应取 $V_g d$ 的乘积最大值。** 推挽有一个漂亮的性质：
> $$V_g\,d=\frac{V_o}{2n}=\text{const}$$
> ——**伏秒积与输入电压无关**！因此磁通摆幅在整个输入范围内恒定，磁芯工作点不随输入电压变化。这与正激相同，比反激（伏秒积随 $V_g$ 、 $D$ 变化）更好设计。

本案例： $V_g d=12/(2\times0.75)=8\text{V}$ ， $T_s=10\mu s$ → 伏秒积 $=80\text{V}\cdot\mu s$ 。

取 $A_e=200\text{mm}^2$ 、 $\Delta B=0.1\text{T}$ ：

$$N_{p,half}\ge\frac{80\times10^{-6}}{0.1\times200\times10^{-6}}=4\quad\Rightarrow\quad N_{p,half}=4\text{匝}$$

$$N_s=nN_{p,half}=0.75\times4=3\text{匝}$$

### 11.4 磁芯饱和与气隙

- **不需要气隙**：推挽是"传能型"变压器（原副边同时有电流），励磁电流小，无需靠气隙储能
- **但建议留极小气隙或选 $B_{sat}$ 高的材质**：增大偏磁容限（见 §十四），代价是 $L_m$ 下降、励磁电流上升
- 工程折中：气隙使 $L_m$ 下降不超过 20%

### 11.5 励磁电感与励磁电流

$$\boxed{L_m=\frac{\mu_0\mu_e N_{p,half}^2A_e}{l_e}}$$

（ $l_e$ 为有效磁路长度；有气隙时 $\mu_e$ 由气隙主导）

$$i_{m,pk}=\frac{V_g\,d\,T_s}{L_m}=\frac{80\text{V}\cdot\mu s}{L_m}$$

> **设计要求**： $i_{m,pk}$ 一般控制在反射负载电流的 **10~20%**。
> 本案例反射电流 $nI_o=18.75\text{A}$ ，故希望 $i_{m,pk}\approx2\sim4\text{A}$ → $L_m\approx20\sim40\mu H$ 。
> $L_m$ 太小 → 励磁电流大 → 铜损与开关损耗增加；太大 → 匝数多、漏感大、窗口利用率差。

### 11.6 绕组线径

| 绕组 | RMS 电流 | 电流密度 | 所需截面积 |
|---|---|---|---|
| 半原边 ×2 | 13.7A | 4A/mm² | 3.4mm² |
| 副边 ×2 | 17.2A | 4A/mm² | 4.3mm² |

**集肤深度**（100kHz、铜、100°C）： $\delta\approx0.21\text{mm}$ → 单根线径 $<0.4\text{mm}$ 。

> **推荐**：多股并绕（如 $\phi0.1\text{mm}\times$ 数十股）或铜箔。**中心抽头结构必须严格对称**——两半绕组同匝数、同线径、同绕法，否则 DCR 不等 → 偏磁。

### 11.7 漏感控制

| 措施 | 效果 |
|---|---|
| **三明治绕法**（副边夹在原边两半之间） | 显著降低漏感 |
| 减小绕组间绝缘厚度 | 降低漏感 |
| 两半原边**并绕**（双线并绕后串接） | 保证对称、降低漏感 |
| 副边用铜箔 | 降低漏感与集肤损耗 |

> 目标： $L_k\le1\%\sim3\%\cdot L_m$ 。漏感过大 → $V_{DS}$ 尖峰高、EMI 差、效率低。

## 十二、输出滤波电感设计

### 12.1 电感量

**物理意义**： $L$ 决定纹波电流。纹波电流在**死区**（ $v_L=-V_o$ ，时间 $(0.5-d)T_s$ ）内线性下降。

$$\Delta i_L=\frac{V_o\,(0.5-d)\,T_s}{L}$$

> **为什么是 $(0.5-d)T_s$ 而不是 $(1-2d)T_s$ ？** 因为输出侧纹波频率是 $2f_s$ ，一个"电感充放周期"是 $T_s/2$ ；在其中导通 $dT_s$ 、续流 $(0.5-d)T_s$ 。两者数值上 $2(0.5-d)=1-2d$ ，所以用 $(1-2d)T_s/2$ 也等价。

反解：

$$\boxed{L=\frac{V_o\,(0.5-d_{min})\,T_s}{\Delta i_L}=\frac{V_o\,(0.5-d_{min})}{f_s\,\Delta i_L}}$$

> **为什么用 $d_{min}$ ？** 占空比越小 → 续流时间越长 → 纹波越大。 $d_{min}$ 出现在**最高输入电压**处。

**设计取值**：设定 $\Delta i_L=k\,I_o$ ， $k=20\%\sim40\%$ （工程经验范围，非固定规则）。

本案例： $k=0.2\to\Delta i_L=5\text{A}$ ， $d_{min}=0.25$

$$L=\frac{12\times(0.5-0.25)}{10^5\times5}=\frac{3}{5\times10^5}=6\mu H\quad\Rightarrow\quad\text{取标称 }6.8\mu H$$

### 12.2 电流与磁芯

| 参数 | 值 | 说明 |
|---|---|---|
| 平均电流 | 25A | $=I_o$ |
| 峰值电流 | 27.5A | 饱和设计依据 |
| RMS 电流 | ≈25A | 线径设计依据 |
| 储能 | $\tfrac12LI_{pk}^2=2.6\text{mJ}$ | 磁芯尺寸依据 |

**磁芯**：低压大电流 → 优选**铁硅铝（Sendust）**或铁粉芯（软饱和特性好）。

匝数估算（以 KS157-060A 为例， $A_L=44\text{nH/N}^2$ ）：

$$N=\sqrt{\frac{L}{A_L}}=\sqrt{\frac{6800}{44}}\approx12.4\quad\Rightarrow\quad13\text{匝}$$

**饱和校验**： $H=\dfrac{NI_{pk}}{l_e}$ 必须使工作点低于该材质的饱和磁密，且**直流偏置下的电感跌落 ≤30%**。

## 十三、电容设计

### 13.1 输出电容

**① 容值（纹波电压）**

电感纹波电流 $\Delta i_L$ 在电容上产生近似三角波的电压纹波，纹波频率为 $2f_s$ ：

$$\Delta V_{C}=\frac{\Delta i_L}{8\cdot(2f_s)\cdot C}=\frac{\Delta i_L}{16f_sC}\quad\Rightarrow\quad C\ge\frac{\Delta i_L}{16f_s\Delta V_C}$$

> **注意**：分母是 $16f_s$ （＝ $8\times$ 纹波频率），不是 $8f_s$ 。写成 $8f_s$ 相当于多留 2 倍裕量，偏保守但不错。

**② ESR 纹波**

$$\Delta V_{ESR}=\Delta i_L\cdot ESR$$

**③ 总纹波**

$$\Delta V_o\approx\frac{\Delta i_L}{16f_sC}+\Delta i_L\cdot ESR$$

> **实践**：低压大电流输出的电解电容，ESR 项通常远大于容值项，**ESR 是瓶颈**。

本案例（ $\Delta V_o\le120\text{mV}$ ， $\Delta i_L=5\text{A}$ ）：

- ESR 分配一半预算： $ESR\le 60\text{mV}/5\text{A}=12\text{m}\Omega$
- 容值： $C\ge\dfrac{5}{16\times10^5\times0.06}=5.2\mu F$ （容值极易满足）

**方案**：2×100µF/25V 高频低阻电解 + 2×10µF MLCC（MLCC 提供低 ESR 与高频旁路），并联后 ESR < 10mΩ。

**④ 其他校核**：纹波电流额定（ $I_{C,rms}\approx1.4\text{A}$ ，易满足）、耐压 ≥1.5×$V_o$ 、温升与寿命（电解电容寿命按 $10°C$ 减半法则）。

### 13.2 输入电容

**作用**：推挽从输入端**脉冲取电**（每周期两个脉冲），必须由 $C_{in}$ 就近提供脉冲电流，避免脉冲电流污染输入源与产生 EMI。

| 约束 | 公式 | 本案例 |
|---|---|---|
| RMS 纹波电流 | $I_{C_{in},rms}=nI_o\sqrt{2d(1-2d)}$ | 5.6A |
| 电压纹波 | $C_{in}\ge\dfrac{I_{in,avg}\cdot d\,T_s}{\Delta V_g}$ | $\dfrac{16.9\times0.45\times10\mu s}{1.2}=63\mu F$ |

> **RMS 电流是瓶颈**：单只电解的额定 RMS 电流约 1~3A，需多只并联。1.5 倍降额 → 需额定 ≥8A。
>
> **方案**：4×47µF/50V 高频低阻电解并联（+ 1µF MLCC 高频旁路）。
>
> **布局要求**： $C_{in}$ 必须紧贴 $Q_1$/$Q_2$ 与中心抽头，最小化高 di/dt 回路面积。

## 十四、关键工程问题

### 14.1 ★ 偏磁——推挽的头号失效模式

**产生原因**

| 原因 | 机理 |
|---|---|
| 驱动信号不对称 | $d_1\neq d_2$ → 正反向伏秒积 $V_gd_1T_s\neq V_gd_2T_s$ |
| 两半绕组 DCR 不一致 | 绕制偏差 → 铜损不等 → 等效激励电压不对称 |
| $R_{DS(on)}$ 差异 / 温度不均 | 两管导通压降不同 → 实际加在绕组上的电压不等 |
| 副边二极管 $V_F$ 不一致 | 反射到原边的等效负载不对称 |
| 磁芯 $B_r$ 不均匀 | 材料本身的不对称 |

**连锁反应（正反馈恶性循环）**

```
驱动/参数不对称 → 净伏秒积 ≠ 0 → 磁通逐周期累积
→ 磁芯趋向单向饱和 → 该侧励磁电感骤降
→ 该侧开关管电流尖峰 → 过流保护触发（有）/ 管子热击穿（无）
```

**其他表征**：输出纹波出现 $f_s$ 分量（正常应为 $2f_s$ ）、变压器可听噪声、EMI 恶化。

**抑制措施**

| 方法 | 原理 | 代价 |
|---|---|---|
| **峰值电流模式控制** | 逐周期检测原边电流，自动平衡两管占空比 | 控制环路复杂、需斜坡补偿 |
| **隔直电容**（原边串联） | 阻断直流偏磁电流 | 增加电压应力与损耗；推挽中因两半绕组交替，串接位置需谨慎 |
| **变压器加气隙** | 降低 $\mu_e$ → 增大偏磁容限 | 励磁电流增大、铜损增加 |
| **严格对称设计** | PCB 对称、双线并绕、选配 $R_{DS(on)}$ 一致的管子 | 选配成本、layout 约束 |
| **磁通检测保护** | 辅助绕组监测磁通，过偏时保护 | 额外绕组 + 电路 |

> **与半桥/全桥的对比**：半桥靠**分压电容**天然隔直；全桥可**串隔直电容**。推挽**两者都没有**——它依赖"对称"本身。这是推挽的**固有代价**，也是它工程上最常见的失效原因。

### 14.2 漏感尖峰与振铃

- **机理**： $Q_1$ 关断瞬间，漏感电流无沟道通路 → 与 $C_{oss}$ 、二极管结电容谐振 → $V_{DS}$ 上叠加高频振铃
- **推挽的特殊困难**：双管正激有 $D_1$/$D_2$ 天然箝位（漏感能量回馈 $V_g$ ）；推挽**没有这个通路** → 尖峰更高、能量只能靠阻尼耗散
- **应对**：
  - 变压器工艺优先（三明治绕法、铜箔、减小绝缘厚度）→ 从源头降低 $L_k$
  - 必要时加 **RC 吸收**（跨接在半绕组外端与中心抽头之间）
  - 或选 $V_{DS}$ 额定更高的管子（最快、最贵的办法）

### 14.3 直通（同桥臂短路）

本拓扑两管**共地**、各自接半绕组，**不存在半桥/全桥那种"同桥臂直通"** 的固有风险——因为两管之间没有公共的桥臂。

> **但仍需死区**：若 $Q_1$ 、 $Q_2$ **同时**导通，则两个半绕组的外端同时接地 → 原边被完全短路 → 输入源经两管短路、且原边无激励。因此**死区仍然必须保留**，只是风险等级低于半桥/全桥。

### 14.4 PCB 布局

| 要求 | 原因 |
|---|---|
| $C_{in}$ 紧贴原边回路 | 最小化高 di/dt 回路面积 |
| 两管驱动走线**等长等阻** | 保证 $d_1=d_2$ （防偏磁的第一道防线） |
| 中心抽头到两管的走线**对称** | 保证两半绕组回路寄生参数一致 |
| 副边整流回路面积最小 | 降低 EMI 与振铃 |
| 变压器下方**禁止走线** | 避免噪声耦合 |
| 功率地与信号地单点连接 | 避免共模噪声 |

### 14.5 热设计

- 两管**交替**导通 → 发热分散到两只管子，且两管**不同时发热**（有利于散热布局）
- 但两管**共地** → 可共用同一片散热器（半桥/全桥的高边管需隔离）
- 变压器为双向励磁，铁损按 $2f_s$ 的等效频率估算

### 14.6 EMI

| 噪声源 | 应对 |
|---|---|
| 高 di/dt： $Q_1$/$Q_2$ 与中心抽头回路 | 缩面积、加高频旁路 |
| 高 dv/dt： $Q_2$ 漏极摆动 $0\to2V_g$ | 适当增大栅极电阻、必要时加 RC 吸收 |
| 副边整流振铃 | 二极管并联 RC 吸收、用软恢复二极管 |
| 共模噪声（通过变压器寄生电容） | 变压器加静电屏蔽层、Y 电容 |

## 十五、损耗与效率估算

### 15.1 损耗构成

$$P_{loss}=P_{Q,cond}+P_{Q,sw}+P_{Q,drv}+P_D+P_{Cu}+P_{core}+P_{other}$$

| 损耗项 | 公式 | 本案例估算 |
|---|---|---|
| $Q$ 导通 | $2\times I_{Q,rms}^2R_{DS(on)}\times1.5$ | $2\times13.7^2\times0.008\times1.5=4.5\text{W}$ |
| $Q$ 开关 | $2\times\tfrac12V_{DS}I_{pk}(t_r+t_f)f_s$ | $2\times0.5\times64\times23.4\times40n\times10^5=6.0\text{W}$ |
| $Q$ 驱动 | $2\times Q_gV_{gs}f_s$ | ≈0.3W |
| 整流二极管 | $2\times V_FI_{D,avg}$ | $2\times0.5\times11.3=11.3\text{W}$ （或 SR： $2\times17.2^2\times5m=3.0\text{W}$ ） |
| 铜损 | $2I_{P,rms}^2R_{dc,P}+2I_{S,rms}^2R_{dc,S}$ | ≈3.5W |
| 磁芯损耗 | Steinmetz $kf^\alpha B^\beta V_e$ | ≈1.5W |
| 其他（控制、ESR、死区） | — | ≈1.0W |
| **合计** | | **≈28W（二极管）／20W（SR）** |
| **效率** | $\eta=P_o/(P_o+P_{loss})$ | **91.5% ／ 93.7%** |

> **结论**：本案例 300W 推挽，用二极管整流约 91%，用同步整流可到 93%+——与设计目标 92% 相符。

### 15.2 效率优化优先级

1. **副边整流**（占比最大）→ 优先上同步整流
2. **开关损耗**（ $V_{DS}$ 高、电流大）→ 降低开关频率或引入软开关
3. **铜损**（低压大电流， $I^2R$ 显著）→ 增大绕组截面积、优化窗口利用率
4. **磁芯损耗** → 选低损材质（PC95 等）或适度降低 $\Delta B$

## 十六、完整设计实例

> **⚠️ 以下为教学设计案例，所有数值仅用于演示计算过程，不代表任何实际工程参数。器件型号仅为案例，参数以最新 Datasheet 为准。**

### 案例 A：车载 DC-DC 变换器

**为什么选这个场景**：24V 是商用车电气系统标准电压，12V 是车载设备标准供电；300W 处于推挽最佳功率区；低压输入使 $2V_g$ 应力可控。

#### 16.1 设计指标

| 参数 | 符号 | 值 |
|---|---|---|
| 输入电压 | $V_g$ | 24V（范围 **18~32V**） |
| 输出电压 | $V_o$ | 12V |
| 输出功率 | $P_o$ | 300W（ $I_o=25\text{A}$ ， $R_o=0.48\Omega$ ） |
| 开关频率 | $f_s$ | 100kHz |
| 最大单管占空比 | $d_{max}$ | 0.45 |
| 效率目标 | $\eta$ | ≥92% |
| 输出纹波 | $\Delta V_o$ | ≤1%（120mV） |

#### 16.2 变压器匝比

$$n=\frac{V_o}{2d_{max}V_{g,min}}=\frac{12}{2\times0.45\times18}=0.741\to\boxed{n=0.75}$$

校验： $d_{min}=\dfrac{V_o}{2nV_{g,max}}=\dfrac{12}{2\times0.75\times32}=0.25$ ✓

#### 16.3 变压器匝数

伏秒积（与输入电压无关）： $V_gd=\dfrac{V_o}{2n}=8\text{V}$ ， $\times T_s=80\text{V}\cdot\mu s$

取 EE42（ $A_e=200\text{mm}^2$ ）、 $\Delta B=0.1\text{T}$ ：

$$N_{p,half}=\frac{80\times10^{-6}}{0.1\times200\times10^{-6}}=4\text{匝},\qquad N_s=0.75\times4=3\text{匝}$$

**结构**：原边双线并绕 4 匝+4 匝（中心抽头），副边 3 匝+3 匝；三明治绕法。

#### 16.4 各器件应力与选型（四级递进）

**MOSFET $Q_1$/$Q_2$**

| 步骤 | 内容 |
|---|---|
| ① 理论应力 | $V_{DS}=2V_{g,max}=64\text{V}$ ； $I_{Q,rms}=13.7\text{A}$ ； $I_{Q,pk}=23.4\text{A}$ |
| ② 寄生附加 | 漏感尖峰（估 $0.4\times2V_g\approx26\text{V}$ ）→ 峰值 $\approx90\text{V}$ |
| ③ 安全裕量 | 尖峰后取 1.5 倍 → $V_{DSS}\ge135\text{V}$ |
| ④ 额定参数 | $V_{DSS}\ge150\text{V}$ ， $I_D\ge30\text{A}@T_c=100°C$ ， $R_{DS(on)}\le8\text{m}\Omega$ ， $Q_g\le30\text{nC}$ |
| ⑤ 案例型号 | 150V N 沟道 MOS（低压大电流型），**参数以最新 Datasheet 为准** |

**整流二极管 $D_1$/$D_2$**

| 步骤 | 内容 |
|---|---|
| ① 理论应力 | $V_{RR}=V_o+nV_{g,max}=12+24=36\text{V}$ ； $I_{D,avg}=11.3\text{A}$ ； $I_{D,pk}=27.5\text{A}$ |
| ② 寄生附加 | 漏感振铃 → $V_{RR}$ 峰值 $\approx1.5\times36=54\text{V}$ |
| ③ 安全裕量 | ×1.5 → $\ge81\text{V}$ |
| ④ 额定参数 | $V_{RRM}\ge100\text{V}$ ， $I_F\ge20\text{A}@T_c=100°C$ ， $t_{rr}\le35\text{ns}$ |
| ⑤ 案例型号 | 100V/20A 超快恢复二极管；或**同步整流**（推荐，效率更高） |

**输出电感 $L$**

$$L=\frac{V_o(0.5-d_{min})}{f_s\Delta i_L}=\frac{12\times0.25}{10^5\times5}=6\mu H\to\text{取}6.8\mu H$$

要求： $I_{sat}\ge30\text{A}$ ， $I_{rms}\ge25\text{A}$ ，直流偏置下电感跌落 ≤30%。铁硅铝磁芯，13 匝（按所选磁芯的 $A_L$ 重算）。

**输出电容 $C$**

要求： $C\ge10\mu F$ （容值项）、 $ESR\le12\text{m}\Omega$ 、 $I_{ripple}\ge2\text{A}$ 、耐压 ≥25V。
方案：2×100µF/25V 低阻电解 + 2×10µF MLCC。

**输入电容 $C_{in}$**

要求： $I_{C_{in},rms}\ge8\text{A}$ （含 1.5 倍降额）、 $C\ge63\mu F$ 、耐压 ≥50V。
方案：4×47µF/50V 高频低阻电解。

## 十八、优缺点与适用场景

### 18.1 优点

1. **磁芯利用率最高**——双向励磁， $\Delta B$ 可用摆幅大
2. **2 管实现 $\pm V_g$ 原边激励**——与全桥同幅值，管子数减半
3. **副边全波整流压降低**——每时刻仅 1 只二极管在回路
4. **输出纹波频率 $2f_s$**——滤波压力小
5. **两管共地**——驱动电路简单（相对半桥/全桥），可共用散热器
6. **天然复位**——无需复位绕组或 RCD

### 18.2 缺点

1. **$2V_g$ 电压应力**——限制在低压输入场合
2. **偏磁风险高**——头号失效模式，依赖对称性而非机制保障
3. **变压器中心抽头**——绕制复杂、漏感大、对称性要求苛刻
4. **漏感能量无箝位通路**——尖峰比双管正激严重
5. **不适用高压输入**

### 18.3 适用场景结论

> **在"低压输入（<$100\text{V}$ ）+ 中功率（100W~1kW）+ 成本敏感"的条件下，推挽更合适**——因为它用最少的开关管换取了最大的磁芯利用率和最低的副边压降。
>
> **反过来，只要输入电压超过 100V， $2V_g$ 的代价就会压过所有优势**——此时应改用半桥（中功率）或全桥（大功率）。

## 二十、公式速查

### 20.1 电压传输与占空比

| 参数 | 公式 | 备注 |
|---|---|---|
| 电压传输比 | $V_o=2n\,d\,V_g=n\,D_{eff}V_g$ | CCM |
| 有效占空比 | $D_{eff}=2d$ | $d<0.5$ |
| 匝比 | $n=\dfrac{V_o}{2d_{max}V_{g,min}}$ | 设计式 |
| 最大/最小占空比 | $d_{max}=\dfrac{V_o}{2nV_{g,min}}$ ， $d_{min}=\dfrac{V_o}{2nV_{g,max}}$ | |

### 20.2 电压应力

| 器件 | 公式 |
|---|---|
| MOSFET | $V_{DS}=2V_{g,max}$ （+漏感尖峰） |
| 整流二极管 | $V_{RR}=V_o+nV_{g,max}$ （保守 $2nV_{g,max}$ ） |

### 20.3 电流应力

| 器件 | 平均值 | 有效值 | 峰值 |
|---|---|---|---|
| MOSFET | $\dfrac{ndI_o}{\eta}$ | $\dfrac{nI_o}{\eta}\sqrt{d}$ | $n\!\left(I_o+\tfrac{\Delta i_L}{2}\right)+i_{m,pk}$ |
| 整流二极管 | $dI_o$ | $I_o\sqrt{0.25+0.5d}$ | $I_o+\tfrac{\Delta i_L}{2}$ |
| 输出电感 | $I_o$ | $\sqrt{I_o^2+\tfrac{\Delta i_L^2}{12}}$ | $I_o+\tfrac{\Delta i_L}{2}$ |
| 输入电容 | 0 | $nI_o\sqrt{2d(1-2d)}$ | — |

### 20.4 磁元件

| 参数 | 公式 |
|---|---|
| 输出电感 | $L=\dfrac{V_o(0.5-d_{min})}{f_s\Delta i_L}$ |
| 电感纹波 | $\Delta i_L=\dfrac{V_o(0.5-d)T_s}{L}$ （峰峰） |
| 原边匝数 | $N_{p,half}\ge\dfrac{V_gd\,T_s}{\Delta B\,A_e}$ ，其中 $V_gd=\dfrac{V_o}{2n}$ ＝常数 |
| 副边匝数 | $N_s=nN_{p,half}$ |
| 励磁电流峰值 | $i_{m,pk}=\dfrac{V_gd\,T_s}{L_m}$ |
| 励磁电感 | $L_m=\dfrac{\mu_0\mu_eN_{p,half}^2A_e}{l_e}$ |

### 20.5 电容与纹波

| 参数 | 公式 |
|---|---|
| 输出电容 | $C\ge\dfrac{\Delta i_L}{16f_s\Delta V_C}$ |
| ESR 纹波 | $\Delta V_{ESR}=\Delta i_L\cdot ESR$ |
| 总输出纹波 | $\Delta V_o\approx\dfrac{\Delta i_L}{16f_sC}+\Delta i_L\cdot ESR$ |
| 输入电容 | $C_{in}\ge\dfrac{I_{in,avg}\,d\,T_s}{\Delta V_g}$ |

### 20.6 CCM 边界

$$L>L_{crit}=\frac{V_o(0.5-d)T_s}{2I_{o,min}}$$

## 二十一、学习总结

### 21.1 一句话记住这个拓扑

> **推挽 = 用 2 只共地的开关管 + 一个中心抽头变压器，做出 $\pm V_g$ 的双极性原边激励。**
> 代价：管子承受 $2V_g$ ，且必须靠"对称"来保证磁芯不偏磁。

### 21.2 五个必须刻在脑子里的数

| 数 | 值 | 来源 |
|---|---|---|
| 原边激励幅值 | $\pm V_g$ | 中心抽头 + 交替导通 |
| **开关管电压应力** | $\mathbf{2V_g}$ | 中心抽头电位 + 半绕组感应电压 |
| 电压传输比 | $2nd$ （ $=nD_{eff}$ ） | 每周期两个脉冲 |
| 输出纹波频率 | $2f_s$ | 全波整流 |
| 最大占空比 | $d<0.5$ | 防两管重叠 |

### 21.3 三个"为什么"

**Q1：为什么管子要承受 $2V_g$ ，而半桥/全桥只有 $V_g$ ？**
A：因为推挽的两管**不是桥臂上下管**，而是各自把一个半绕组外端接地。导通管把外端拉到地，中心抽头被电源钳在 $V_g$ ；关断管的漏极则被"中心抽头电位 + 另一半绕组的感应电压"顶到 $2V_g$——两个 $V_g$ **串联叠加**。

**Q2：为什么推挽必须靠"对称"，而不能像双管正激那样强制复位？**
A：双管正激的 $D_1/D_2$ 提供了**漏感与励磁能量的回馈通路**，是机制保障。推挽的双向励磁靠的是"正负半周伏秒积天然相等"——一旦不对称，**没有任何机制把它拉回来**，净伏秒积会逐周期累积直到饱和。

**Q3：为什么死区时 $v_s=0$ 而不是负值？**
A：输出电感电流必须连续，续流回路强迫 $D_1$ 、 $D_2$ **同时导通**；两只正向导通的二极管把副边两半绕组短路，所以 $v_s=0$ 、 $v_L=-V_o$ 。这与 Buck 的续流阶段是同一个机理。

- [ ] 看到原理图能指出"中心抽头 + 两管共地 + 全波整流"，并立刻说出 $2V_g$ 应力
- [ ] 画出四个模态的电流路径与状态表
