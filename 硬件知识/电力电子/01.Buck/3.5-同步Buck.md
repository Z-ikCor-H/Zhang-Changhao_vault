# 第三章 Buck DCM原理 第五节：同步Buck

> **本节为补充内容**——应朋友提问而加：把 Buck 的续流二极管换成 MOS 管会怎样？

[[3.4-DCM电流分析与设计|前面各节]]讲的都是"二极管续流"的传统 Buck。本节讨论**同步 Buck（Synchronous Buck）**：**为什么要把二极管换成 MOS 管？电感电流为什么能反向、反向后电路变成什么？为什么它效率更高、动态响应更快？死区时间是干什么的？** 并介绍由此带来的零电压开通（ZVS）。

---

## 一、同步Buck的拓扑

![[3.5-1 基础Buck拓扑.png|460]]

传统 Buck：开关管 $Q$ + **续流二极管** $D$。

![[3.5-2 同步Buck拓扑.png|460]]

**同步 Buck：把续流二极管 $D$ 换成 MOS 管 $Q_2$**（称为**同步整流管**）。

- MOS 管本身带**体二极管**——如果不给 $Q_2$ 驱动信号，电路也能工作（$Q_2$ 当二极管用）
- 但既然专门加了 MOS 管，目的显然不是用它那个体二极管，而是**用它的沟道**（导通电阻 $R_{on}$ 上的压降远小于二极管的正向压降）

---

## 二、互补驱动与死区时间

### 2.1 互补驱动

$Q_1$ 与 $Q_2$ 的驱动信号是**互补**的：

- $Q_1$ 开通时 → $Q_2$ 关断
- $Q_2$ 开通时 → $Q_1$ 关断
- **两者开通时间之和 = 一个开关周期**

### 2.2 死区时间 $T_D$

在驱动信号换向处，会插入一个很短的**死区时间** $t_d$——此时**两个管子都不开通**。

> **为什么必须加死区？**
>
> 开关管的开通/关断**不是瞬时完成**的：无论 MOS、IGBT 还是碳化硅器件，关断都需要**几十纳秒**。
>
> 如果在这个关断过程中就把另一个管子打开：
> - 两个管子会**同时导通**（出现交叉导通区）
> - 输入端被**直接短路** → 产生极大的电流
> - 损耗急剧上升，器件损坏风险剧增
>
> 所以必须留出一段死区，让"先关断的管子彻底关断"之后再"打开另一个"。

> **死区取多大？** 一般 **200ns 左右**即可。Buck 电路多用于**低压**场合，通常用硅器件（不太会用碳化硅），200ns 足够保证两者不同时导通。

## 三、CCM下的工作过程

![[3.5-3 电感电压电流波形（CCM）.png|470]]

同步 Buck 一般**大部分时间（尤其满载）工作在 CCM**。当电感电流最小值 $i_{L1}>0$（不触碰零线）时：

- 电感电流波形与**传统 Buck 完全一样**
- $Q_2$ 仅仅充当**续流管**使用
- 增益同样为 $\dfrac{U_o}{U_{in}}=D$（CCM，见[[1.2-伏秒平衡#三、稳态增益的推导|式(1.2-3)]]）

图中可见：$Q_1$ 在 $DT$ 区间导通（$u_L=U_{in}-U_o$），$Q_2$ 在其余区间导通（$u_L=-U_o$），两段之间夹着死区 $t_d$。

## 四、负载减轻：电感电流反向（FCCM）

![[3.5-4 负载减小时，电感波形变化.png|470]]

### 4.1 与传统 Buck 的分岔点

随着负载减轻（$R_o\uparrow$、$I_o\downarrow$）：电感电流平均值 $I_L=I_o$ 下降、纹波 $\Delta i_L$ 基本不变、$D$ 基本不变 → 波形**整体向下平移**。

- 谷底触零 → **BCM**（对应**临界负载**）
- 若负载继续减轻（$R_o>R_{crit}$）：
  - **传统 Buck**：进入 [[3.2-DCM工作过程|DCM]]，出现 $i_L=0$ 的**零电流平台**
  - **同步 Buck**：$Q_2$ 一直被驱动（与 $Q_1$ 互补），**电感电流可以反向** → 不出现零电流平台，而是出现**负值区域**

> 这就是**强迫连续导通模式（FCCM, Forced CCM）**——无论负载多轻，电感电流始终连续（只是可能为负）。

### 4.2 反向后发生了什么

以 $T_1$ 时刻（电感电流过零）为界：

| 区间 | $i_L$ 方向 | 电流路径 | 能量流向 |
|---|---|---|---|
| $DT$（$Q_1$ 导通） | 正 | 电源 → $Q_1$ → $L$ → 负载 | 电源 → 负载 |
| $Q_1$ 关断 → $T_1$（$Q_2$ 导通） | 正 | 地 → $Q_2$ → $L$ → 负载（$Q_2$ 从 S 到 D 导通） | 电感 → 负载 |
| **$T_1$ → $Q_2$ 关断** | **负** | **$C_o$ → $L$ → $Q_2$ → 地** → 回到 $C_o$ | **输出电容 → 电感（反向充电）** |
| 死区 $t_d$ | 负 | $L$ → **$Q_1$ 的体二极管** → 电源 | **电感 → 电源（能量回馈）** |
| $Q_1$ 开通后 | 负 → 过零 → 正 | $U_{in}$ 加在电感上，反向电流逐渐减小至零后转正 | 电源 → 电感（重新充电） |

**逐步说明：**

1. **$T_1$ 之前**：$Q_2$ 导通，电感电流仍为正，由地经 $Q_2$ 流向负载（对 $Q_2$ 而言是 S→D，即"负方向"）
2. **$T_1$ 时刻**：电感电流过零。若是二极管，此处就截止进入 DCM 了；但 $Q_2$ 一直导通，构成 $C_o\to L\to Q_2\to$ 地 的回路 → **$C_o$ 开始对 $L$ 反向充电**，电感电流变负
3. **$Q_2$ 关断**：通路被切断，但电感电流不能突变，只能改走 **$Q_1$ 的体二极管**（此时正处于死区，$Q_1$ 尚未开通）→ **电感把能量回馈给电源 $C_{in}$**
4. **$Q_1$ 开通**：开关节点电压变为 $U_{in}$，电感电压反向为 $U_{in}-U_o>0$ → 反向电流开始**减小**（往零走）→ 过零后电源重新给电感充电，进入下一个周期的正常 Buck 过程

> **关键洞察：$T_1$ 之后的反向区间，实际上是一个 Boost 电路！**
>
> 把这一段的"输入"看作 $C_o$ 侧、"输出"看作 $C_{in}$ 侧：此时 $Q_2$ 相当于 Boost 的**主管**，$Q_1$ 相当于 Boost 的**二极管**——能量从输出侧（$C_o$）**反向传回**电源侧（$C_{in}$）。
>
> 这正是**非隔离双向 DC-DC** 的雏形（可与 [[4.10-DCM电流分析与设计#十、Boost 与 Buck 的联系：非隔离双向 DC-DC|Boost 4.10 节]]对照）。

### 4.3 那它是靠什么调节输出功率的？

既然电感电流始终连续，**占空比 $D$ 几乎不变**，那输出功率靠什么调？

> 靠**正向传输功率 $P_正$ 与反向传输功率 $P_负$ 之差**来调节：
>
> $$P_o = P_正 - P_负$$
>
> - 满载时没有反向电流 → $P_负=0$
> - 负载越轻，反向区间越长 → $P_负$ 越大 → $P_o$ 越小
>
> 于是**占空比基本不变**，就能维持输出电压恒定。

### 4.4 一个小的差异：拐点位置

- **电感电流为正**时：电流下降的拐点在 **$Q_1$ 开通时刻**（$Q_1$ 开通、电压突变）
- **电感电流为负**时：拐点提前到 **$Q_2$ 关断时刻**（反向电流只能走 $Q_1$ 体二极管，电感电压立刻反向）

> 这个差异会稍微影响一点占空比。但由于**死区时间很小**，计算增益时可以忽略这个影响。

## 五、同步Buck的优势

### 5.1 同步整流：显著降低损耗

传统 Buck 用二极管续流，损耗为

$$P_D = V_F\cdot I_{D\_avg} = V_F(1-D)I_o$$

同步 Buck 用 MOS 管续流，损耗为

$$P_{Q2} = I_o^2\cdot R_{on}$$

**数值对比（$I_o=10\text{A}$）**

| 方案 | 参数 | 损耗 |
|---|---|---|
| 肖特基二极管 | $V_F=0.4\text{V}$ | $0.4\times10\approx\mathbf{4\ W}$ |
| MOS 管 | $R_{on}=10\text{m}\Omega$ | $10^2\times0.01=\mathbf{1\ W}$ |

> 损耗明显下降，而且 **$I_o$ 越大、$R_{on}$ 越小，提升越明显**。这就是我们常说的**同步整流技术**。

### 5.2 可实现高频工作 → 减小体积

效率提高后就可以把开关频率做高（**甚至达到 2MHz**），频率越高 → 电感、电容越小 → **电源体积越小**。

> 这对**便携式设备**（手机、平板、iPad 等）尤其重要——体积小本身就是竞争力。

### 5.3 动态响应非常快

因为电感**始终工作于 CCM**，占空比几乎不变：

| | 传统 Buck | 同步 Buck（FCCM） |
|---|---|---|
| 10% 负载 | 通常已进入 **DCM** | 仍为 CCM |
| 100% 负载 | CCM | CCM |
| 占空比 | 需从 $D_1$（DCM）调到 $D_2$（CCM） | 起点终点**几乎不变** |

> **传统 Buck 的痛点：** DCM 与 CCM 的增益公式**不同**（[[3.3-DCM增益分析#七、DCM增益与CCM增益的比较|DCM 增益 > CCM 增益]]），从 10% 跳到 100% 负载时占空比要"跨越两种模式"去调节，需要时间。
>
> **同步 Buck：** 全程 CCM，理论上**不存在占空比的调节过程**——所以**动态响应非常快**（实际因线路损耗会有极小的变化，但起点与终点不变）。

### 5.4 $Q_1$ 实现零电压开通（ZVS）

当电感电流反向时，$Q_2$ 关断瞬间电流方向是"流向开关节点"的，这个电流会使 $Q_1$ 的**体二极管导通**：

- 体二极管导通后，$Q_1$ 的 $V_{DS}$ **几乎为零**
- 此时再开通 $Q_1$ → **零电压开通（ZVS）**

> 软开关的详细机理将在后续"软开关"部分展开。（顺便一提：**这个问题曾是某公司的入职面试考题**。）

---

## 六、同步Buck的劣势

- 多了一个 $Q_2$，就**多了一路驱动**
- 相比传统 Buck 的单路驱动，**驱动电路更复杂**

---

## 七、本节小结

| 主题 | 核心结论 |
|---|---|
| 拓扑 | 把 Buck 的续流二极管换成 MOS 管 $Q_2$ → 同步 Buck |
| 驱动 | $Q_1/Q_2$ **互补驱动**，换向处插入**死区 $t_d$**（约 200ns）防止直通短路 |
| 死区的作用 | 开关管开/关需几十 ns，避免两管同时导通把输入短路 |
| CCM 工作 | $i_{L1}>0$ 时与传统 Buck **完全一样**，$Q_2$ 仅作续流管，增益仍为 $D$ |
| 负载减轻 | 因 $Q_2$ 一直导通，电感电流**可以反向** → 进入 **FCCM**（无零电流平台） |
| 反向区间 | 实质是 **Boost 电路**，能量从 $C_o$ 回馈到 $C_{in}$（双向流动） |
| 功率调节 | 靠 $P_正-P_负$ 之差调节 → **占空比基本不变** |
| 优势 | ① 同步整流降低损耗（4W→1W）② 可高频化、减小体积 ③ 全程 CCM，**动态响应快** ④ $Q_1$ 实现 **ZVS** |
| 劣势 | 多一路驱动，驱动电路更复杂 |
