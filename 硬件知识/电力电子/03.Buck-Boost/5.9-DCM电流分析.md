# 第五章 Buck-Boost电路 第九节：DCM电流分析

DCM 模式下，**开关管、二极管、电感、电容的电流有效值和平均值如何计算？与 [[5.4-CCM电流分析|CCM]] 公式有何差异？** 本节基于[[5.8-DCM增益分析|上一节]]的 $D_1$、$M$、$i_{LP}$，用"梯形波有效值 + 占比缩放 + 正交分解"给出各元件电流应力公式，并把 CCM 与 DCM 的全部公式汇总为速查表。

---

## 一、分析基础

### 1.1 通用工具公式

![[5.9.1 电感、开关管、二极管电流波形.png|470]]

对于一个最低点为 $i_{L1}$、最高点为 $i_{L2}$、在整个周期中占比为 $\delta$ 的**梯形波**，其有效值为（同[[3.4-DCM电流分析与设计#1.3 通用工具公式|3.4节]]的通用工具式）：

$$I_{rms} = \sqrt{\delta}\cdot\sqrt{\frac{i_{L1}^2 + i_{L2}^2 + i_{L1}i_{L2}}{3}}$$

> **DCM 下 $i_{L1}=0$ 时大幅简化**——后两项都为零，只剩一项：

$$I_{rms} = \sqrt{\delta}\cdot\frac{i_{LP}}{\sqrt{3}}$$

> 也可以从"三角波"角度理解：把三角波**补齐**为完整三角波，其有效值为 $i_{LP}/\sqrt{3}$；而实际波形只占周期的 $\delta$ 比例，故再乘 $\sqrt{\delta}$。两种算法结果完全相同。

### 1.2 峰值电流 $i_{LP}$ 的两种表达

由 $I_o=\dfrac{1}{2}i_{LP}D_1$（[[5.8-DCM增益分析#3.2 三角形面积法|式(5.8-2)]]）：

$$i_{LP} = \frac{2I_o}{D_1} \tag{5.9-1}$$

又由**开关管电流平均值 = 输入电流**（见下节），可得另一种表达，两者等价。

---

## 二、开关管 Q 的电流

### 2.1 平均值 = 输入电流

![[5.9-3 开关管、输入电容电流波形.png|470]]

**所有输入电流都要流过开关管**，故开关管电流的平均值就是输入电流 $I_{in}$。用三角形面积法（底边 $DT$、高 $i_{LP}$）：

$$I_{Q\_avg} = I_{in} = \frac{1}{T}\cdot\frac{1}{2}\cdot i_{LP}\cdot DT = \frac{1}{2}D\,i_{LP} \tag{5.9-2}$$

### 2.2 考虑效率 $\eta$ 的输入电流

实际变换器效率不为 100%。考虑效率后：

$$\eta\cdot U_{in}I_{in} = U_oI_o \;\Rightarrow\; I_{in} = \frac{U_oI_o}{\eta U_{in}} = \frac{M I_o}{\eta} \tag{5.9-3}$$

代入式(5.9-2)，得到峰值电流：

$$i_{LP} = \frac{2I_{in}}{D} = \frac{2MI_o}{\eta D} \tag{5.9-4}$$

> 理想情况 $\eta=1$ 时，$i_{LP}=\dfrac{2MI_o}{D}$，与式(5.9-1) $\dfrac{2I_o}{D_1}$ 等价（因 $M=D/D_1$）。

### 2.3 有效值

开关管电流是"从零升到 $i_{LP}$"的三角波，占比 $D$，由[[4.4-电流有效值计算#一、两个预备结论|4.4节结论二]]：

$$I_{Q\_rms} = \sqrt{D}\cdot\frac{i_{LP}}{\sqrt{3}} = i_{LP}\sqrt{\frac{D}{3}} \tag{5.9-5}$$

代入式(5.9-6)：

$$\boxed{I_{Q\_rms} = \frac{2MI_o}{\eta\sqrt{3D}}} \tag{5.9-6}$$

> **开关管按有效值计算导通损耗**，这是选型与损耗评估的依据。

---

## 三、二极管 D 的电流

![[5.9-2 电感、二极管、输出电容电流波形.png|470]]

### 3.1 有效值

二极管电流是"从 $i_{LP}$ 降到零"的三角波，占比 $D_1$。**只需把开关管公式中的 $D$ 换成 $D_1$**：

$$I_{D\_rms} = \sqrt{D_1}\cdot\frac{i_{LP}}{\sqrt{3}} = i_{LP}\sqrt{\frac{D_1}{3}}$$

代入式(5.9-1) $i_{LP}=\dfrac{2I_o}{D_1}$：

$$\boxed{I_{D\_rms} = \frac{2I_o}{\sqrt{3D_1}}} \tag{5.9-7}$$

### 3.2 平均值

$$\boxed{I_{D\_avg} = I_o}$$

> 二极管电流平均值恒等于负载电流 $I_o$（**与工作模式无关**）——这是[[5.8-DCM增益分析#3.1 关键关系|上一节]]推导 $D_1$ 的出发点，也是选二极管额定平均电流的依据（同[[5.2-电感电流纹波分析#二、直流分量 $I_L$ 的计算|式(5.2-2)]]）。

---

## 四、电感 L 的电流

### 4.1 有效值

**方法一：梯形波公式**

电感电流是完整三角波（模态一 + 模态二），在整个周期中占比为 $D+D_1$：

$$I_{L\_rms} = \sqrt{D+D_1}\cdot\frac{i_{LP}}{\sqrt{3}} = i_{LP}\sqrt{\frac{D+D_1}{3}} \tag{5.9-8}$$

**方法二：正交分解**

电感电流由 $i_Q$ 与 $i_D$ **拼接**而成，二者**不同时存在**（正交）：

$$I_{L\_rms}^2 = I_{Q\_rms}^2 + I_{D\_rms}^2 = i_{LP}^2\cdot\frac{D}{3} + i_{LP}^2\cdot\frac{D_1}{3} = i_{LP}^2\cdot\frac{D+D_1}{3}$$

$$I_{L\_rms} = i_{LP}\sqrt{\frac{D+D_1}{3}}$$

**与式(5.9-8)完全一致** ✓（两种方法只是数学上等价，实际任选其一）

$$I_{L\_avg} = I_{in} = \frac{MI_o}{\eta} \tag{5.9-9}$$

> 电感电流的**平均值与有效值**是**磁元件设计与选线径（铜线）**的依据。

---

## 五、输出电容 $C_o$ 的电流

二极管电流中，平均值 $I_o$ 流入负载，交流分量流入输出电容，由正交分解：

$$I_{Co\_rms}^2 = I_{D\_rms}^2 - I_{D\_avg}^2 = I_{D\_rms}^2 - I_o^2$$

代入式(5.9-7)：

$$\boxed{I_{Co\_rms} = I_o\sqrt{\frac{4}{3D_1} - 1}} \tag{5.9-10}$$

> 该式是输出电容**额定纹波电流**（及温升）选型的依据。

---

## 六、输入电容 $C_{in}$ 的电流

输入电容与**开关管**相连。开关管电流中：

- **直流分量**（平均值）$I_{in}$ —— 由电源提供（电容隔直）
- **交流分量** —— 全部流入输入电容

由正交分解：

$$I_{Cin\_rms}^2 = I_{Q\_rms}^2 - I_{Q\_avg}^2 = I_{Q\_rms}^2 - I_{in}^2 \tag{5.9-11}$$

> **与输出电容完全相同的道理**——只是这次"母波形"换成了开关管电流，直流分量换成了 $I_{in}$。

> **关于"虚拟波形"：** 式(5.9-11) 是通过正交分解**算出来**的，实际示波器上看到的电容电流波形会因寄生参数而不同。这个"波形"是为了计算有效值而构造的数学工具。

---

## 七、CCM vs DCM 全部公式汇总

以下把 Buck-Boost 在 CCM、DCM 两种模式下的核心公式并列，便于速查。

### 7.1 基本关系

| 参数 | CCM | DCM |
|---|---|---|
| 增益 $M=\dfrac{U_o}{U_{in}}$ | $\dfrac{D}{1-D}$ | $D\sqrt{\dfrac{R_oT}{2L}}$ |
| $D_1$ | $1-D$ | $\sqrt{\dfrac{2L}{R_oT}}$（**与 $D$ 无关**） |
| $D+D_1$ | $=1$ | $<1$ |
| 电流纹波率 $\tau$ | $<2$ | $>2$ |

### 7.2 峰值电流 $i_{LP}$

| CCM | DCM |
|---|---|
| $I_L\left(1+\dfrac{\tau}{2}\right)$ | $\dfrac{2I_o}{D_1}=\dfrac{2MI_o}{\eta D}$ |

### 7.3 开关管 Q

| 参数 | CCM | DCM |
|---|---|---|
| 平均值 | $\dfrac{I_oD}{1-D}$ | $\dfrac{1}{2}D\,i_{LP}$（$=I_{in}$） |
| RMS | $\dfrac{I_o\sqrt{D}}{1-D}\sqrt{1+\dfrac{\tau^2}{12}}$ | $i_{LP}\sqrt{\dfrac{D}{3}}$ |

### 7.4 二极管 D

| 参数 | CCM | DCM |
|---|---|---|
| 平均值 | $I_o$ | $I_o$ |
| RMS | $\dfrac{I_o}{\sqrt{1-D}}\sqrt{1+\dfrac{\tau^2}{12}}$ | $i_{LP}\sqrt{\dfrac{D_1}{3}}$ |

### 7.5 电感 L

| 参数 | CCM | DCM |
|---|---|---|
| 平均值 | $\dfrac{I_o}{1-D}$ | $\dfrac{MI_o}{\eta}$ |
| RMS | $\dfrac{I_o}{1-D}\sqrt{1+\dfrac{\tau^2}{12}}$ | $i_{LP}\sqrt{\dfrac{D+D_1}{3}}$ |

### 7.6 电容

| 参数 | CCM | DCM |
|---|---|---|
| 输入电容 RMS | $\dfrac{I_o}{1-D}\sqrt{D\left(1+\dfrac{\tau^2}{12}-D\right)}$ | $\sqrt{I_{Q\_rms}^2-I_{in}^2}$ |
| 输出电容 RMS | $I_o\sqrt{\dfrac{D+\tau^2/12}{1-D}}$ | $\sqrt{I_{D\_rms}^2-I_o^2}$ |

### 7.7 电感设计

| 参数 | CCM | DCM |
|---|---|---|
| 电感值 | $\dfrac{U_o(1-D_{max})^2}{\tau I_of}$（$\tau\approx1.2$） | $<L_{crit}$（确保 DCM） |
| 临界电感 | — | $\dfrac{R_o(1-D)^2T}{2}$ |
| 临界电阻 | — | $\dfrac{2L}{(1-D)^2T}$ |

> **关于效率 $\eta$：** 本节在 DCM 计算中**考虑了效率**（$I_{in}=MI_o/\eta$）；CCM 一节是按理想 $\eta=1$ 处理的。若要考虑 CCM 的效率，只需把 $\eta$ 以同样方式代入（作为练习）。

---

## 八、本节小结

| 主题 | 核心结论 |
|---|---|
| 通用工具 | 梯形波有效值 $\sqrt{\delta}\sqrt{(i_{L1}^2+i_{L2}^2+i_{L1}i_{L2})/3}$，谷底为零时简化为 $\sqrt{\delta}\,i_{LP}/\sqrt{3}$ |
| 开关管 | 平均值 $=I_{in}=\frac{1}{2}Di_{LP}$；RMS $=i_{LP}\sqrt{D/3}$ |
| 二极管 | 平均值 $=I_o$（与模式无关）；RMS $=i_{LP}\sqrt{D_1/3}$ |
| 电感 | RMS $=i_{LP}\sqrt{(D+D_1)/3}$（两种算法等价）；平均值 $=I_{in}$ |
| 输出电容 | $\sqrt{I_{D\_rms}^2-I_o^2}$ |
| 输入电容 | $\sqrt{I_{Q\_rms}^2-I_{in}^2}$ |
| 效率 | DCM 下 $I_{in}=\dfrac{MI_o}{\eta}$ |
| 峰值电流 | $i_{LP}=\dfrac{2I_o}{D_1}=\dfrac{2MI_o}{\eta D}$ |
