# 第五章 Buck-Boost电路 第二节：电感电流纹波分析

[[5.1-CCM增益分析|上一节]]得到 Buck-Boost 的 CCM 增益 $U_o/U_{in}=D/(1-D)$。本节定量分析电感电流：**它的直流分量 $I_L$ 是多少？纹波 $\Delta i_L$ 多大、何时最大？纹波率 $\tau$ 又在什么占空比下最大？** 这是后续电感设计的基础。

---

## 一、电感电流的分解

与分析 Buck、Boost 一样，把电感电流 $i_L$ 分解为直流分量与交流分量（即[[1.3-安秒平衡#1.2 电感电流的分解|式(1.3-1)]]）：

$$i_L = I_L + \Delta i_L$$

- **$I_L$（直流分量）**：电感电流的平均值
- **$\Delta i_L$（交流分量）**：电感电流的纹波（峰峰值三角波）

![[5.2-1 拓扑图电流流向.png|470]]

![[5.2-2 电感电流波形图.png|470]]

### 1.1 交流分量流到哪里去了？

Buck-Boost 的电感**在任一时刻都不会长期挂在某一个电容上**（这是它与 Buck、Boost 最大的区别）：

- **Q 导通时**：电感与 $U_{in}$ 构成回路 → 与**输入电容**交换纹波电流
- **Q 关断时**：电感与输出端构成回路（经二极管）→ 与**输出电容**交换纹波电流

> **对比：** Boost 的电感始终连输入端，全部纹波进输入电容；Buck 的电感始终连输出端，全部纹波进输出电容；**Buck-Boost 的电感在两个电容之间"跳来跳去"**，两边各承担一部分。这一差别在[[5.3-CCM电感设计|电感设计]]中会导致重要结论。

---

## 二、直流分量 $I_L$ 的计算

### 2.1 结论先行

$$\boxed{I_L = \frac{I_o}{1-D}} \tag{5.2-1}$$

> **与 Boost 完全相同**（同[[4.2-电感电流纹波分析#二、直流分量 $I_L$ 的计算|式(4.2-3)]]），与 Buck 的 $I_L=I_o$ 不同。

### 2.2 推导：二极管平均电流 = 负载电流

首先明确一个贯穿全章的关系（与 Boost 的结论一致：[[4.4-电流有效值计算#4.2 平均值|式(4.4-6)]]）：

$$I_{D\_avg} = I_o \tag{5.2-2}$$

> **为什么？** 输出节点上，负载 $R_o$ 所需的全部电流只能由二极管提供（没有别的通路），所以二极管电流的平均值必然等于负载电流 $I_o$。这与工作模式无关，从电路就能看出。

而二极管只在 Q 关断期间（$(1-D)T$）导通，此时 $i_D=i_L$：

$$I_{D\_avg} = \frac{1}{T}\int_{DT}^{T} i_L\,dt$$

用梯形面积法计算（上底 $i_{L1}$、下底 $i_{L2}$、高 $(1-D)T$）：

$$I_{D\_avg} = \frac{1}{T}\cdot\frac{1}{2}\left(i_{L1}+i_{L2}\right)\cdot(1-D)T = \underbrace{\frac{1}{2}\left(i_{L1}+i_{L2}\right)}_{I_L}\cdot(1-D) = I_L(1-D)$$

由 $I_{D\_avg}=I_o$：

$$I_L(1-D) = I_o \;\Rightarrow\; \boxed{I_L = \frac{I_o}{1-D}}$$

> **直观理解：** 电感电流只在 $(1-D)$ 的时间比例里流向负载，所以它的**平均值要放大 $1/(1-D)$ 倍**才能提供足够的负载电流。这一结论与 Boost 形式相同，但原因不同：Boost 来自功率守恒，Buck-Boost 来自"二极管平均电流 = 负载电流"。

## 三、电感电流纹波 $\Delta i_L$

![[5.2-3 电感电压电流波形图.png|470]]

### 3.1 表达式

用**关断时段**（$U_L=-U_o$，持续时间 $(1-D)T$）计算纹波（由纹波公式 [[5.1-CCM增益分析#3.2 状态二：开关管 Q 关断（$t_{off}=(1-D)T$）|式(5.1-2)]]）：

$$\Delta i_L = \frac{U_o}{L}\cdot(1-D)T$$

也可用**导通时段**（$U_L=U_{in}$，持续时间 $DT$）表示（由纹波公式 [[5.1-CCM增益分析#3.1 状态一：开关管 Q 导通（$t_{on}=DT$）|式(5.1-1)]]），二者由增益公式(5.1-4)等价：

$$\Delta i_L = \frac{U_{in}}{L}\cdot DT$$

### 3.2 $\Delta i_L$ 何时最大？—— $D$ 最小（最高输入电压）

$U_o$、$L$、$T$ 固定时，由[[5.1-CCM增益分析#3.2 状态二：开关管 Q 关断（$t_{off}=(1-D)T$）|式(5.1-2)]]：

$$\Delta i_L \propto (1-D)$$

$(1-D)$ 是 $D$ 的单调递减函数，故 $D$ 越小、$\Delta i_L$ 越大：

$$\boxed{D = D_{min}\ (\text{即输入电压最高}) \text{ 时，}\Delta i_L \text{ 最大}}$$

> **与 Buck / Boost 对比：**

| 拓扑 | $\Delta i_L$ 的规律 | 纹波最大处 |
|---|---|---|
| Buck | $\propto (1-D)$ | $D_{min}$（最高输入电压） |
| Boost | $\propto D(1-D)$ | $D=0.5$ |
| **Buck-Boost** | $\propto (1-D)$ | $D_{min}$（**最高输入电压**） |

> **物理原因：** Buck-Boost 的电感在 Q 关断时两端电压是 $U_o$（固定），而关断时间 $(1-D)T$ 在 $D$ 最小时最长 → 放电时间最长，纹波最大。这与 Buck 一致——因为两者关断时电感都"直接面向输出"。

## 四、电感电流纹波率 $\tau$

### 4.1 定义

与 Buck、Boost 完全相同的定义（即[[2.3-Buck电感计算#2.1 定义|式(2.3-1)]]）：

$$\tau = \frac{\Delta i_L}{I_L}$$

### 4.2 $\tau$ 的表达式

代入[[5.1-CCM增益分析#3.2 状态二：开关管 Q 关断（$t_{off}=(1-D)T$）|式(5.1-2)]] $\Delta i_L = \dfrac{U_o(1-D)T}{L}$ 与[[#二、直流分量 $I_L$ 的计算|式(5.2-1)]] $I_L = \dfrac{I_o}{1-D}$：

$$\begin{aligned}
\tau &= \frac{\Delta i_L}{I_L} = \frac{\dfrac{U_o(1-D)T}{L}}{\dfrac{I_o}{1-D}} \\[6pt]
&= \frac{U_o(1-D)^2 T}{I_o L}
\end{aligned}$$

用负载电阻 $R_o=U_o/I_o$ 表示：

$$\boxed{\tau = \frac{(1-D)^2 \cdot R_o \cdot T}{L}} \tag{5.2-3}$$

### 4.3 $\tau$ 何时最大？—— $D$ 最小（最高输入电压）

$R_o$、$T$、$L$ 固定时：

$$\tau \propto (1-D)^2$$

$(1-D)^2$ 随 $D$ 单调递减，故：

$$\boxed{D = D_{min}\ (\text{最高输入电压}) \text{ 时，}\tau \text{ 最大}}$$

> **注意与 Boost 的区别：** Boost 的 $\Delta i_L$ 最大在 $D=0.5$、$\tau$ 最大在 $D\approx0.33$，二者不同；而 **Buck-Boost 的 $\Delta i_L$ 与 $\tau$ 都在 $D_{min}$ 处最大**，与 Buck 一致，不必区分两个极值点。

## 五、本节小结

| 主题 | 核心结论 |
|---|---|
| 电流分解 | 电感电流 = 直流分量 $I_L$ + 交流分量 $\Delta i_L$ |
| 纹波去向 | Q 导通时与输入电容交换、Q 关断时与输出电容交换（**不长期挂在某一侧**） |
| 直流分量 | $I_L = \dfrac{I_o}{1-D}$（由"二极管平均电流 = $I_o$"导出） |
| 纹波 | $\Delta i_L = \dfrac{U_o(1-D)T}{L}$，在 $D_{min}$（最高输入电压）时最大 |
| 纹波率 | $\tau = \dfrac{(1-D)^2 R_o T}{L}$，同样在 $D_{min}$ 时最大 |
| 与 Buck 一致 | 纹波与纹波率的最大点均在**最高输入电压**，不同于 Boost |
