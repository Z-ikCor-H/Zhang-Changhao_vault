# 第五章 Buck-Boost电路 第四节：CCM电流分析

[[5.3-CCM电感设计|上一节]]完成了电感值设计。本节计算 Buck-Boost 各元件电流的**有效值（RMS）**与**平均值**，以及**输出电压纹波**（含电解电容的 ESR 纹波），为开关管、二极管、电容的选型提供依据：**电感、开关管、二极管、输入/输出电容各流过多少电流？**

本节直接引用 Buck、Boost 中已推导的结论（[[硬件知识/电力电子/一、BUCK/2.1-输出电容电流有效值|Buck第二章]]、[[4.4-电流有效值计算|Boost第四章]]），因此讲解更快。

---

## 一、两个预备结论

### 结论一：有效值的正交分解

直流分量与交流分量正交，故总有效值满足：

$$I_{rms}^2 = I_{dc}^2 + I_{ac}^2 \tag{5.4-1}$$

### 结论二：波形占比缩放

若某电流波形是原波形中占比为 $\delta$ 的一段，则：

$$\text{有效值} = \text{原有效值}\times\sqrt{\delta},\qquad \text{平均值} = \text{原平均值}\times\delta$$

![[5.4-1 拓扑图电流流向.png|470]]

> **注意：** 这里的"原波形"指的是**电感电流**——因为开关管电流与二极管电流都是电感电流的"一段"。Buck-Boost 中 Q 占比 $D$，二极管占比 $1-D$。

---

## 二、电感电流有效值

由结论一，电感电流的直流分量 $I_L$ 与交流分量 $\Delta i_L$ 正交：

$$I_{L\_rms} = \sqrt{I_L^2 + \left(\frac{\Delta i_L}{2\sqrt{3}}\right)^2} = \sqrt{I_L^2 + \frac{\Delta i_L^2}{12}}$$

代入 $\Delta i_L=\tau I_L$：

$$\boxed{I_{L\_rms} = I_L\sqrt{1+\frac{\tau^2}{12}} = \frac{I_o}{1-D}\sqrt{1+\frac{\tau^2}{12}}} \tag{5.4-2}$$

> **与 Buck、Boost 完全相同的形式**，只是 $I_L$ 的表达式不同（Buck 为 $I_o$，Boost 与 Buck-Boost 均为 $I_o/(1-D)$）。
>
> **注意：Buck-Boost 的 $\tau$ 很大（推荐 1.2）**，$\tau^2/12=0.12$，开根号约 1.058——比 Boost（$\tau\approx0.4$，约 1.006）明显，**不能再简单近似为 $I_{L\_rms}\approx I_L$**。
>
> 电感电流有效值是**磁元件设计与选线径（铜线）**的依据。

---

## 三、开关管电流（Q）

### 3.1 有效值

![[5.4-2 CCM电压电流波形图-1.png|470]]

开关管电流是电感电流中占比为 $D$ 的一段，故有效值乘 $\sqrt{D}$：

$$I_{Q\_rms} = \sqrt{D}\cdot I_{L\_rms} = \frac{I_o\sqrt{D}}{1-D}\sqrt{1+\frac{\tau^2}{12}} \tag{5.4-3}$$

### 3.2 平均值

平均值乘 $D$：

$$I_{Q\_avg} = D\cdot I_L = \frac{I_o\cdot D}{1-D} \tag{5.4-4}$$

> 也可用面积法验证：$i_Q$ 是梯形（上底 $i_{L1}$、下底 $i_{L2}$、高 $DT$），平均值 $=\frac{1}{T}\cdot\frac{1}{2}(i_{L1}+i_{L2})\cdot DT = D\cdot I_L$ ✓

> **$I_{Q\_avg}$ 就是输入电流平均值 $I_{in}$。** Buck-Boost 中电源经 Q 接入，输入电流就是**脉冲的开关管电流**，故 $I_{in}=I_{Q\_avg}=D I_L$。可用功率守恒验证：$U_{in}I_{in}=U_oI_o\Rightarrow I_{in}=\dfrac{U_o}{U_{in}}I_o=\dfrac{D}{1-D}I_o = D I_L$ ✓
>
> 这一点与 **Buck 相同**（输入电流脉冲、$I_{in}=D I_L$），与 **Boost 相反**（Boost 电感串在输入端，输入电流是连续的电感电流，$I_{in}=I_L$）。

---

## 四、二极管电流（D）

### 4.1 有效值

二极管占比为 $1-D$，只需把开关管公式中的 $D$ 换成 $1-D$：

$$I_{D\_rms} = \sqrt{1-D}\cdot I_{L\_rms} = \frac{I_o\sqrt{1-D}}{1-D}\sqrt{1+\frac{\tau^2}{12}} = \frac{I_o}{\sqrt{1-D}}\sqrt{1+\frac{\tau^2}{12}} \tag{5.4-5}$$

### 4.2 平均值

$$I_{D\_avg} = (1-D)\cdot I_L = (1-D)\cdot\frac{I_o}{1-D} = I_o \tag{5.4-6}$$

> **从电路直接看出：** 负载电流 $I_o$ 要流过负载，只能通过二极管（别无通路），故二极管电流平均值必然等于 $I_o$。看电路就能判断，无需计算——这正是[[5.2-电感电流纹波分析#2.2 推导：二极管平均电流 = 负载电流|上一节]]推导 $I_L$ 的出发点。

---

## 五、输入电容电流有效值

![[5.4-3 CCM电压电流波形图-2.png|470]]

输入电流就是开关管电流 $i_Q$。把它分解为：

- **直流分量 $I_{Q\_avg}$** —— 由电源 $U_{in}$ 提供（电容隔直）
- **交流分量** —— 全部流入输入电容 $C_{in}$

由正交分解：

$$I_{Cin\_rms}^2 = I_{Q\_rms}^2 - I_{Q\_avg}^2$$

代入式(5.4-3)、(5.4-4)：

$$\begin{aligned}
I_{Cin\_rms}^2 &= D\cdot I_L^2\left(1+\frac{\tau^2}{12}\right) - D^2 I_L^2 = D\,I_L^2\left(1+\frac{\tau^2}{12}-D\right)
\end{aligned}$$

$$\boxed{I_{Cin\_rms} = I_L\sqrt{D\left(1+\frac{\tau^2}{12}-D\right)} = \frac{I_o}{1-D}\sqrt{D\left(1+\frac{\tau^2}{12}-D\right)}} \tag{5.4-7}$$

> **与 Buck 输入电容的关系：** 形式**完全一样**——Buck 的输入电容电流有效值为 $I_o\sqrt{D(1+\tau^2/12-D)}$（[[硬件知识/电力电子/一、BUCK/2.2-电感与开关管电流有效值|Buck 2.2节]]），本式只是把 $I_o$ 换成了 $I_L=\dfrac{I_o}{1-D}$。
>
> 这正是[[5.3-CCM电感设计#4.1 原因一：电感不长期挂在某一个电容上|上一节]]所说：Buck-Boost 的输入电容与 **Buck** 的输入电容工况极其相似，而与 Boost 不同。

> **为什么需要虚拟波形？** 实际电容电流波形会因寄生参数而不同。这里用"$i_Q$ 减去其平均值"构造出的波形，是为了**计算有效值**而虚拟出来的，属于数学工具，不代表实际示波器波形。

---

## 六、输出电容电流有效值

![[5.4-4 CCM电压电流波形图-3.png|470]]

二极管电流中，平均值 $I_o$ 全部流入负载，交流分量流入输出电容：

$$I_{Co\_rms}^2 = I_{D\_rms}^2 - I_{D\_avg}^2 = I_{D\_rms}^2 - I_o^2$$

代入式(5.4-5)、(5.4-6)：

$$\begin{aligned}
I_{Co\_rms}^2 &= \frac{I_o^2\left(1+\tau^2/12\right)}{1-D} - I_o^2 = I_o^2\cdot\frac{D+\tau^2/12}{1-D}
\end{aligned}$$

$$\boxed{I_{Co\_rms} = I_o\sqrt{\frac{D+\tau^2/12}{1-D}} \approx I_o\sqrt{\frac{D}{1-D}}} \tag{5.4-8}$$

> **与 Boost 完全一致！** 因为 Buck-Boost 与 Boost 中**二极管都是直接接输出电容**，二者工况完全相同，所以输出电容电流有效值的公式、乃至[[5.3-CCM电感设计#3.1 与 Boost 曲线对比|上一节曲线图中两条曲线重合]]，都是这个原因。

## 七、输出电压纹波

![[5.4-5 CCM电压电流波形图-4.png|470]]

### 7.1 方法一：导通时段（$t_{on}$）计算

Q 导通期间，二极管截止，**输入与输出断开**，负载电流 $I_o$（基本不变）全部由 $C_o$ 提供，电容以 $I_o$ 恒流放电，时长 $DT$：

放出的电荷（矩形面积）：

$$\Delta Q = I_o\cdot DT$$

由 $U=Q/C$：

$$\boxed{\Delta U_o = \frac{I_o\cdot D\cdot T}{C_o} = \frac{I_o\cdot D}{C_o\cdot f}} \tag{5.4-9}$$

> **与 Boost 完全一致**——因为"Q 导通时电容单独对负载放电"这一机理与 Boost 相同（Buck 则不同，其电容充放电发生在整个周期）。

### 7.2 方法二：关断时段（$t_{off}$）验证

关断期间，电感经二极管送出的总电荷（梯形面积 = 平均值 × 时间）：

$$Q_L = I_L\cdot(1-D)T$$

负载在关断期间消耗的电荷：

$$Q_{load} = I_o(1-D)T$$

剩余电荷充入电容：

$$\Delta Q = I_L(1-D)T - I_o(1-D)T = (1-D)T\left(I_L-I_o\right)$$

代入 $I_L=\dfrac{I_o}{1-D}$，得 $I_L-I_o = \dfrac{I_o D}{1-D}$：

$$\Delta Q = (1-D)T\cdot\frac{I_o D}{1-D} = I_o\cdot D\cdot T \quad\Rightarrow\quad \Delta U_o = \frac{I_o D T}{C_o}$$

**与[[#7.1 方法一：导通时段（$t_{on}$）计算|式(5.4-9)]]完全一致。**

## 八、电解电容的ESR纹波

以上只考虑了电容**容值**造成的纹波。若使用**电解电容**，其等效串联电阻 ESR 较大，ESR 上的纹波往往占主导。

### 8.1 ESR纹波

流入电容的电流为 $i_D - I_o$，ESR 上的电压：

$$\Delta U_{o(ESR)} = (i_{D\_max} - I_o)\cdot ESR = (i_{L2} - I_o)\cdot ESR$$

$I_o$ 固定，故 $i_{L2}$ 最大时 ESR 纹波最大。由[[5.3-CCM电感设计#5.1 电感峰值电流随 $D$ 增大而增大|上一节]]，$i_{L2}$ 最大发生在**最低输入电压（$D_{max}$）**：

$$i_{L2\_max} - I_o = \left[\frac{I_o}{1-D_{max}}\left(1+\frac{\tau}{2}\right) - I_o\right] = \frac{I_o\cdot D_{max}}{1-D_{max}} + \frac{U_{in\_min}\cdot D_{max}\cdot T}{2L}$$

$$\boxed{\Delta U_{o(ESR)} = \left[\frac{I_o\,D_{max}}{1-D_{max}} + \frac{U_{in\_min}\,D_{max}\,T}{2L}\right]\cdot ESR \tag{5.4-10}}$$

> 推导要点：$I_L-I_o = I_o\left(\dfrac{1}{1-D}-1\right)=\dfrac{I_o D}{1-D}$；纹波一半用导通时段表示 $\dfrac{\Delta i_L}{2}=\dfrac{U_{in}DT}{2L}$，在 $D_{max}$ 处取值。

### 8.2 相位关系与保守估计

- ESR 电压与流过它的电流**同相位**（$U=I\cdot R$）
- 当电容电流达峰值（$i_L$ 最大）时，ESR 电压也达峰值
- 但此刻电容电压恰为**最小值**（刚放电结束）——两者相位错开，实际总纹波比简单相加更小

> **保守估计：** 由于 ESR 纹波占主导、容值纹波可忽略，工程上常只用 ESR 纹波来估算。这样算得的结果是**保守值**——保守值都能满足要求，实际一定满足。

## 九、本节小结

| 元件 | 电流平均值 | 电流有效值 |
|---|---|---|
| 电感 L | $\dfrac{I_o}{1-D}$ | $\dfrac{I_o}{1-D}\sqrt{1+\dfrac{\tau^2}{12}}$ |
| 开关管 Q | $\dfrac{I_o D}{1-D}$ | $\dfrac{I_o\sqrt{D}}{1-D}\sqrt{1+\dfrac{\tau^2}{12}}$ |
| 二极管 D | $I_o$ | $\dfrac{I_o}{\sqrt{1-D}}\sqrt{1+\dfrac{\tau^2}{12}}$ |
| 输入电容 $C_{in}$ | $0$ | $\dfrac{I_o}{1-D}\sqrt{D\left(1+\dfrac{\tau^2}{12}-D\right)}$ |
| 输出电容 $C_o$ | $0$ | $I_o\sqrt{\dfrac{D+\tau^2/12}{1-D}}$ |

| 纹波 | 公式 |
|---|---|
| 输出电压纹波 | $\Delta U_o = \dfrac{I_o D}{C_o f}$ |
| ESR 纹波（$D_{max}$ 处） | $\Delta U_{o(ESR)} = \left[\dfrac{I_o D_{max}}{1-D_{max}}+\dfrac{U_{in\_min}D_{max}T}{2L}\right]\cdot ESR$ |

> **两条通用结论：** ① 波形占其母波形的比例 $\delta$ → 有效值乘 $\sqrt{\delta}$，平均值乘 $\delta$；② 对称三角波有效值 = 峰值/√3。

> **三条"继承关系"（与 Buck / Boost 的对应）：**

| Buck-Boost 的量 | 对应拓扑 | 关系 |
|---|---|---|
| 输入电容电流有效值 | **Buck** | 形式完全一样，$I_o$ 换成 $I_L$ |
| 输出电容电流有效值 | **Boost** | **完全一致** |
| 输出电压纹波、ESR 纹波 | **Boost** | **完全一致** |
