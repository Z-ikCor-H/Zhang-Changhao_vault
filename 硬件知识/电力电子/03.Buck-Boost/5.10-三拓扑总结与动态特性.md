# 第五章 Buck-Boost电路 第十节：三拓扑总结与动态特性

本节是**三个基本非隔离拓扑（Buck、Boost、Buck-Boost）的收尾总结**。前面九节一直是"逐个拓扑、逐项参数"地分析，本节把它们放到一起横向对比：**三者的增益规律有何共性？为什么 Buck 的输出电容、Boost 的输入电容纹波特别小，而 Buck-Boost 两个都大？为什么 Boost/Buck-Boost 会自激震荡？** 最后引出这类拓扑特有的**右半平面零点**问题。

---

## 一、增益规律的三点共性

### 1.1 增益都随占空比 $D$ 增大而增大

无论是 CCM 还是 DCM，三个拓扑的增益都**随 $D$ 增大而升高**。

> 这不只对三个基本拓扑成立——**所有通过调节占空比 $D$ 来控制输出的拓扑**（正激、反激、推挽、半桥、全桥……）都是如此。

### 1.2 相同占空比下，DCM 增益大于 CCM 增益

在其他条件相同（负载电阻、功率相同）的前提下，一个设计在 CCM、一个设计在 DCM：

$$\boxed{\left.\frac{U_o}{U_{in}}\right|_{DCM} > \left.\frac{U_o}{U_{in}}\right|_{CCM}\quad(\text{三个基本拓扑均成立})}$$

> 三处证明分别见 [[硬件知识/电力电子/一、BUCK/3.3-DCM增益分析#七、DCM增益与CCM增益的比较|Buck]]、[[4.9-DCM增益分析#六、DCM增益 > CCM增益（严格证明）|Boost]]、[[5.8-DCM增益分析#七、DCM增益 > CCM增益（严格证明）|Buck-Boost]]。

### 1.3 CCM 增益理论上与负载、电感、频率无关

理想 CCM 下，三个拓扑的增益**只由 $D$ 决定**，与 $R_o$、$L$、$f$ 无关。

> **实际会有一点点关系：** 变换器效率不可能 100%，存在损耗。负载加重时 $I_o$ 增大 → 内部电流增大 → 损耗升高，所以需要**略微增大 $D$** 来补偿损失的能量。

### 1.4 三拓扑增益速查

| 拓扑 | CCM 增益 | DCM 增益 |
|---|---|---|
| Buck | $D$ | $\dfrac{2D}{D+\sqrt{D^2+8L/(R_oT)}}$ |
| Boost | $\dfrac{1}{1-D}$ | $\dfrac{1+\sqrt{1+2D^2R_oT/L}}{2}$ |
| **Buck-Boost** | $\dfrac{D}{1-D}$ | $D\sqrt{\dfrac{R_oT}{2L}}$ |

## 二、电容电流应力对比

### 2.1 现象：Buck 与 Boost 各有"一个轻松"的电容

| 拓扑 | 电流纹波小的电容 | 原因 |
|---|---|---|
| **Buck** | **输出电容**（$\approx0.12I_o$） | 输出电容与电感**一直相连** |
| **Boost** | **输入电容**（同样很小） | 输入电容与电感**一直相连** |
| **Buck-Boost** | —— **两个电容都不小** | 电感**不与任何一个电容长期相连** |

![[5.10-1 开关管开通时Buck电路状态.png|330]]
![[5.10-2 开关管开通时Boost电路状态.png|330]]
![[5.10-3 开关管开通时Buck-Boost电路状态.png|330]]

> **数值感受：** 把 $\tau\approx0.4$ 代入 Buck 输出电容电流有效值的公式 $I_{Co\_rms}=\dfrac{\Delta i_L}{2\sqrt3}=\dfrac{\tau I_o}{2\sqrt3}$，得 **约 $0.12I_o$**——只有负载电流的 12%，确实很小。Boost 的输入电容同理。

### 2.2 机理：电感与电容的连接方式

- **Buck / Boost**：电感与某一侧的电容**始终相连**。电感具有**平波作用**，纹波被这个电容"就近吸收"，所以该电容的电流纹波小。
- **Buck-Boost**：Q 导通时电感与输入电容成回路、Q 关断时与输出电容成回路——**每个电容都有"与电感不相连"的工作区间**，因此两边电容的纹波电流都比较大。

> 这正是[[5.3-CCM电感设计#4.1 原因一：电感不长期挂在某一个电容上|5.3 节]]中"Buck-Boost 可以取更大 $\tau$"的根本原因：它的电容应力**本来就大**，再增大 $\tau$ 时相对变化反而不明显。

## 三、电感储能对比

三个拓扑都是"开关管导通时把能量存进电感"，但**存多少**差别很大。

![[5.10-1 开关管开通时Buck电路状态.png|330]]
![[5.10-2 开关管开通时Boost电路状态.png|330]]
![[5.10-3 开关管开通时Buck-Boost电路状态.png|330]]

| 拓扑 | Q 导通时 | Q 关断时 | 电感储存的能量 |
|---|---|---|---|
| **Buck** | $U_{in}$ 经电感**直接与负载相连** | 电感续流 | 部分 |
| **Boost** | 输入与输出断开，先给电感储能 | **输入与输出相连**，二者共同给负载供电 | **部分**（输入同时供能） |
| **Buck-Boost** | 输入与输出断开，先给电感储能 | **输入与输出仍不相连**，只有电感给负载供电 | **全部**输出功率能量 |

> **关键区别：** Boost 在二极管导通时**输入与输出是相连的**，输入功率经电感直接流向输出，所以电感只"过手"一部分能量；而 Buck-Boost **无论开关管开通还是二极管导通，输入与输出永远不相连**，负载的能量必须全部由电感"中转"。

### 3.1 结论：同功率下 Buck-Boost 的电感体积更大

在输出功率相同、其他条件相同的情况下：

$$E_{L\_Buck\text{-}Boost} > E_{L\_Boost} > \cdots \quad\Rightarrow\quad \text{Buck-Boost 的电感体积更大}$$

> 这又是[[5.3-CCM电感设计#4.2 原因二：电感要储存"全部"输出功率的能量|5.3 节]]"应当取更大 $\tau$"的第二个理由。磁元件设计章节会详细讨论"储能大 → 体积大"的机理。

## 四、动态过程与右半平面零点

> 前三节讨论的都是**稳态**。这一节从**动态（负载突变）**的角度看 Boost 与 Buck-Boost 的特殊问题。

### 4.1 加载时的反馈过程

假设变换器工作在 CCM，负载**突然加重**（例如从 30% 跳到 100%）：

1. 输出电压 $U_o$ **下降**
2. 反馈回路检测到 → 要补偿电压损失 → **增大占空比 $D$**
3. $D$ 增大 → 二极管导通时间 $(1-D)T$ **缩短**
4. 但**二极管的导通时间正是电感给负载放电的时间**（Boost 与 Buck-Boost 均如此）
5. 放电时间缩短 → 电感释放的能量不足以弥补电容的消耗 → $U_o$ **进一步下降**

![[5.10-4 负载增大时占空比增大.png|470]]

### 4.2 为什么会形成恶性循环

关键在第 5 步的机理：

- Q 导通期间，Boost 与 Buck-Boost 的**输入和电感都与输出脱离**，负载电流完全由输出电容供给 → 电容放电、$U_o$ 下降
- 电容损失的能量，本应由二极管导通期间电感释放的能量来弥补
- 若 $D$ 调节**过快**，放电时间被压得太短 → 弥补不上 → $U_o$ 继续下降
- 反馈系统检测到下降 → **继续增大 $D$** → 放电时间**进一步压缩** →
- **形成恶性循环 → 系统产生严重震荡，甚至不稳定**

### 4.3 本质：右半平面零点（RHP Zero）

在上面看是"反馈越调越糟"，本质上是一个**系统建模**问题：

> **凡是"先把能量存进电感、再释放给输出"的拓扑（Boost、Buck-Boost、反激……），其小信号模型中都存在一个右半平面零点。**

- 注意是**右半平面（RHP）**零点，不是左半平面零点——这是本问题的关键
- RHP 零点会给系统**额外增加 $-90°$ 的相位滞后**
- 相位滞后 → 系统的**相位裕度下降** → 系统容易产生震荡

> 从时域（工作过程）看是"二极管放电时间被压缩"的恶性循环；从频域（传递函数）看就是 RHP 零点带来的相位滞后。**两种视角描述的是同一件事。**
>
> 详细建模与分析将在**系统建模与环路设计**部分展开，本节只需建立"有这么一个事"的认识。

> **注意对比：** Buck 不存在这个问题——因为 Buck 的能量是"经电感连续传递"的（Q 导通时输入直接连负载），不需要"先存后放"。这也是 Buck 补偿网络相对好设计的原因。

## 五、本节小结

| 主题 | 核心结论 |
|---|---|
| 增益共性 | 三拓扑增益均随 $D$ 增大而升高（所有调占空比的拓扑皆然） |
| DCM vs CCM | 相同 $D$ 下 DCM 增益 > CCM 增益 |
| CCM 增益 | 理想下与 $R_o$、$L$、$f$ 无关；实际因损耗需略增 $D$ |
| 电容应力 | Buck 输出电容、Boost 输入电容纹波小（电感长期相连）；**Buck-Boost 两个都大** |
| 电感储能 | Boost 只存部分能量；**Buck-Boost 存全部能量 → 电感体积更大** |
| 动态问题 | 加载 → 增大 $D$ → 二极管导通时间缩短 → 电压继续下降 → 恶性循环 |
| 本质 | Boost / Buck-Boost / 反激存在**右半平面零点**，带来 $-90°$ 相位滞后、降低相位裕度 |
