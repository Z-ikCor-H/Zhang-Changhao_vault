# 第五章 Buck-Boost电路 第六节：BCM工作过程

第五章前五节的分析都默认负载满载、电感电流始终连续（CCM）。实际变换器不可能一直满载工作。本节讨论 **BCM（临界导通模式）**——CCM 与 DCM 的分界线：**Buck-Boost 在什么条件下从 CCM 进入 DCM？临界电阻和临界电感怎么算？如何设计才能保证整个输入电压范围内都工作在 CCM（或 DCM）？** 

---

## 一、从CCM到BCM：两种进入路径

![[5.6-1 电感电流波形图.png|460]]

设变换器已达稳态、设计在 CCM。运行时有两种情况会让它进入临界模式。

### 1.1 路径一：负载减轻（$R_o\uparrow$）

CCM 下分析时一直假设 $R_o$ 是满载（$R_o$ 最小、负载最重）。若负载变轻（$R_o$ 增大）：

- 输出电压 $U_o$ 不变（闭环调节）→ 输出功率 $P_o$ 下降
- 输出电流 $I_o=\dfrac{U_o}{R_o}$ **下降**
- 由 [[5.2-电感电流纹波分析#二、直流分量 $I_L$ 的计算|式(5.2-1)]] $I_L=\dfrac{I_o}{1-D}$，电感电流平均值 **下降**

而占空比 $D$、纹波 $\Delta i_L$ **基本不变**（由纹波公式 [[5.1-CCM增益分析#3.2 状态二：开关管 Q 关断（$t_{off}=(1-D)T$）|式(5.1-2)]]）：

$$\Delta i_L = \frac{U_o(1-D)T}{L}$$

> **原因：** CCM 下 $U_o$ 不变（于是 $D$ 不变）、$L$、$T$ 不变，故 $\Delta i_L$ 不变。

于是电感电流波形发生的是**向下平移**——平均值下降、纹波幅度不变。

![[5.6-2 电感电流随负载减小变化曲线图.png|460]]

随着 $R_o$ 继续增大，波形不断下移，最终**谷底刚好触碰到零点**：

$$i_{L1} = I_L - \frac{\Delta i_L}{2} = 0 \tag{5.6-1}$$

此时变换器进入 **BCM 模式**，对应的负载电阻称为**临界电阻** $R_{crit}$。

> 若 $R_o$ 继续增大，电感电流将出现"断流"，进入 **DCM 模式**（后续章节讨论）。

### 1.2 路径二：电感减小（$L\downarrow$）

保持满载（$R_o$、$I_o$ 不变），减小电感值 $L$。

由 $\Delta i_L=\dfrac{U_{in}DT}{L}$（[[5.1-CCM增益分析#3.1 状态一：开关管 Q 导通（$t_{on}=DT$）|式(5.1-1)]]）：$L\downarrow\Rightarrow$ **斜率 $\dfrac{U_{in}}{L}$ 增大** → 上升、下降斜率都变大 → $\Delta i_L$ 增大。

而电感电流平均值 $I_L=\dfrac{I_o}{1-D}$ **保持不变**（负载未变）。

![[5.6-3 电感电流随电感减小变化曲线图.png|460]]

- 电感电流的**中点（平均值）固定不变**
- 斜率增大 → 峰值升高、谷底降低
- 最终谷底刚好触碰到零点：$i_{L1}=0$

此时对应的电感值称为**临界电感** $L_{crit}$。

> 若 $L$ 继续减小（$L<L_{crit}$），变换器将在全负载范围内进入 DCM 模式。

## 二、BCM模式的核心关系

![[5.6-4 BCM电压电流波形图.png|460]]

在临界点，电感电流谷底为零，波形为**从零开始、以零结束**的三角波（不再是 CCM 下的梯形波）：

- $i_{L1}=0$
- $\Delta i_L = i_{LP}$（峰值即纹波）
- 平均值 $I_L = \dfrac{1}{2}i_{LP} = \dfrac{1}{2}\Delta i_L$

结合 $I_o=(1-D)I_L$（[[5.2-电感电流纹波分析#二、直流分量 $I_L$ 的计算|式(5.2-2)]]）：

$$\boxed{I_L=\frac{1}{2}\Delta i_L,\qquad I_o=\frac{1}{2}(1-D)\Delta i_L} \tag{5.6-2}$$

由纹波率的定义 $\tau=\dfrac{\Delta i_L}{I_L}$：

$$\boxed{\tau = 2} \tag{5.6-3}$$

> **这是一个普适结论，不限于 Buck-Boost。** 对 Buck、Boost、Buck-Boost 等所有基本拓扑，$\tau=2$ 都对应临界导通模式。**CCM 下 $\tau$ 的最大值就是 2**——一旦超过就进入 DCM。

| 模式 | $\tau$ 范围 | 电感电流特征 |
|---|---|---|
| CCM | $\tau<2$ | 谷底 $>0$，始终连续 |
| BCM | $\tau=2$ | 谷底 $=0$，刚好触零 |
| DCM | $\tau>2$ | 出现零电流平台期 |

## 三、临界电阻与临界电感

### 3.1 临界电阻 $R_{crit}$

在临界点，$I_L=\dfrac{1}{2}\Delta i_L$，而 $\Delta i_L$ 用**关断时段**表示（关断时电感电压为 $U_o$，才会出现输出电压，便于得到 $R_o$ 的关系，[[5.1-CCM增益分析#3.2 状态二：开关管 Q 关断（$t_{off}=(1-D)T$）|式(5.1-2)]]）：

$$\Delta i_L = \frac{U_o}{L}(1-D)T$$

由 $I_L=\dfrac{I_o}{1-D}$ 与 $I_L=\dfrac{1}{2}\Delta i_L$：

$$\frac{I_o}{1-D} = \frac{1}{2}\cdot\frac{U_o(1-D)T}{L} \;\Rightarrow\; I_o = \frac{U_o(1-D)^2T}{2L}$$

又 $R_o=\dfrac{U_o}{I_o}$：

$$\boxed{R_{crit} = \frac{2L}{(1-D)^2\,T}} \tag{5.6-4}$$

- $R_o>R_{crit}$（负载更轻）→ 进入 **DCM**
- $R_o=R_{crit}$ → **BCM** 临界模式
- $R_o<R_{crit}$（负载更重）→ **CCM** 模式

### 3.2 临界电感 $L_{crit}$

由上式反解 $L$（$R_o$ 取满载值）：

$$\boxed{L_{crit} = \frac{R_o(1-D)^2\,T}{2}} \tag{5.6-5}$$

- $L<L_{crit}$ → 全范围进入 **DCM**
- $L=L_{crit}$ → **BCM** 临界模式
- $L>L_{crit}$ → 在设计负载范围内可工作于 **CCM**

> **与 Buck / Boost 对比：**

| 拓扑 | 临界电阻 $R_{crit}$ | 临界电感 $L_{crit}$ |
|---|---|---|
| Buck | $\dfrac{2L}{(1-D)T}$ | $\dfrac{R_o(1-D)T}{2}$ |
| Boost | $\dfrac{2L}{D(1-D)^2T}$ | $\dfrac{R_oD(1-D)^2T}{2}$ |
| **Buck-Boost** | $\dfrac{2L}{(1-D)^2T}$ | $\dfrac{R_o(1-D)^2T}{2}$ |

> Buck-Boost 的临界电感与 Buck 只差一个 $(1-D)$ 因子——根源是 $I_L$ 与 $I_o$ 的关系不同（Buck 为 $I_L=I_o$，Buck-Boost 为 $I_L=I_o/(1-D)$），而 $\Delta i_L$ 的规律相同（都 $\propto(1-D)$）。

## 四、全域工作模式的设计条件

$L_{crit}=\dfrac{R_o(1-D)^2T}{2}$ 与占空比 $D$（即输入电压）有关。设 $U_o$ 固定、**输入电压变化**，则 $L_{crit}$ 有一个最大值和一个最小值：

$$(1-D)^2 \text{ 最大} \Leftrightarrow D \text{ 最小}\ (D_{min},\ \text{最高输入电压})$$

### 4.1 全程 CCM 的条件

要让变换器在**整个输入电压范围**内都工作于 CCM，设计的电感必须大于 $L_{crit}$ 的**最大值**：

$$\boxed{L > L_{crit\_max} = \frac{R_o(1-D_{min})^2 T}{2}} \tag{5.6-6}$$

其中 $D_{min}$ 对应**最高输入电压**。

### 4.2 全程 DCM 的条件

要让变换器在**整个输入电压范围**内都工作于 DCM，设计的电感必须小于 $L_{crit}$ 的**最小值**：

$$\boxed{L < L_{crit\_min} = \frac{R_o(1-D_{max})^2 T}{2}} \tag{5.6-7}$$

其中 $D_{max}$ 对应**最低输入电压**。

> **设计要点：** 因为 $L_{crit}\propto(1-D)^2$，而 $(1-D)$ 在**最高输入电压**时最大，所以"要让全程 CCM"必须按**最高输入电压**校核；反过来"要让全程 DCM"必须按**最低输入电压**校核。这与[[5.3-CCM电感设计#五、最恶劣工况：最低输入电压（$D_{max}$）|5.3节]]中"按最低输入电压设计电感"并不矛盾——那个是**饱和/储能**的最恶劣点，这个是**模式边界**的最恶劣点。

## 五、本节小结

| 主题 | 核心结论 |
|---|---|
| 进入 BCM 的两种方式 | ① 负载减轻（$R_o\uparrow$）→ 电流下移；② 电感减小（$L\downarrow$）→ 斜率增大、纹波增大 |
| BCM 电流关系 | $I_L=\frac{1}{2}\Delta i_L$，故 $I_o=\frac{1}{2}(1-D)\Delta i_L$ |
| BCM 特性 | $\tau=2$（适用于所有基本拓扑） |
| 临界电阻 | $R_{crit}=\dfrac{2L}{(1-D)^2T}$，$R_o>R_{crit}$ 则进入 DCM |
| 临界电感 | $L_{crit}=\dfrac{R_o(1-D)^2T}{2}$，$L<L_{crit}$ 则全范围 DCM |
| 全程 CCM | $L>\dfrac{R_o(1-D_{min})^2T}{2}$（按**最高**输入电压校核） |
| 全程 DCM | $L<\dfrac{R_o(1-D_{max})^2T}{2}$（按**最低**输入电压校核） |
