# 第四章 Boost电路 第六节：非理想Boost分析

前面各节均基于理想器件假设。本节放开三个关键非理想因素：**开关管导通压降 $U_{SW}$、二极管正向压降 $U_D$、电感绕线电阻 $R_1$ 各会让Boost增益偏离理想式(4.1-5)多少？为什么理想公式在 $D\to1$ 时给出无穷大、而实际Boost却有一个"最高增益点"？** 本节修正CCM增益公式，说明最大增益的限制来自电感线路的寄生电阻，并汇总全部CCM设计公式与应力曲线。

---

## 一、非理想因素引入

本节考虑的三个非理想因素：

| 器件 | 理想假设 | 实际情况 |
|---|---|---|
| 开关管 Q（MOSFET） | 导通压降 = 0 | 导通压降 $U_{SW}$（或导通电阻 $R_{on}$） |
| 二极管 D | 导通压降 = 0 | 正向导通压降 $U_D$（约 0.7V ~ 1V） |
| 电感 L | 绕线电阻 = 0 | 绕线电阻 $R_1$（还含部分线路电阻） |

> 本节仍在 **CCM 模式**下分析，先单独考虑"Q/D 压降"，再单独考虑"L 寄生电阻"，最后说明它们对增益的共同影响。

---

## 二、考虑开关管与二极管压降的增益

### 2.1 分析方法：电感两端电压平均值相等

仍然使用[[1.2-伏秒平衡#四、伏秒平衡的一种便捷理解|伏秒平衡的便捷形式]]——**电感两端电压的平均值相等**：

$$\overline{U_A} = \overline{U_B}$$

定义电感左端为 **A 点**（始终与输入电源相连），右端为 **B 点**（接 Q 与 D 的交点）。

![[4.6-1 含二极管压降的非理想Boost拓扑.png|470]]

![[4.6-2 电感B点电压电流分析.png|450]]

### 2.2 分状态分析

| 状态 | A 点电压 $U_A$ | B 点电压 $U_B$ |
|---|---|---|
| Q 导通（$t_{on}=DT$） | $U_{in}$（始终连输入） | $U_{SW}$（Q 两端压降） |
| Q 关断（$t_{off}=(1-D)T$） | $U_{in}$ | $U_o + U_D$（二极管导通） |

> **B 点为什么是 $U_o+U_D$？** 关断时电感电流强制二极管导通，B 点是二极管阳极（正），输出端是阴极（负），所以 $U_B = U_o + U_D$。
>
> **与 Buck 的区别：** Buck 的电感接在输出端，A/B 两点都要分状态计算；Boost 的电感一直连输入，**A 点恒为 $U_{in}$**，所以只有 B 点需要分状态——计算更简单。

### 2.3 电压平均值相等

B 点电压由两段构成，其平均值就是"各段电压 × 该段占比"之和：

$$\overline{U_B} = U_{SW}\cdot D + (U_o + U_D)\cdot(1-D)$$

A 点平均值恒为输入电压：

$$\overline{U_A} = U_{in}$$

由 $\overline{U_A}=\overline{U_B}$：

$$U_{in} = U_{SW}\cdot D + (U_o + U_D)\cdot(1-D) \tag{4.6-1}$$

### 2.4 整理结果

解出输出电压：

$$\boxed{U_o = \frac{U_{in} - D\cdot U_{SW}}{1-D} - U_D} \tag{4.6-2}$$

解出占空比：

$$\boxed{D = \frac{U_o + U_D - U_{in}}{U_o + U_D - U_{SW}}} \tag{4.6-3}$$

> **理想情况对照：** 令 $U_{SW}=U_D=0$，式(4.6-2) 退化为 $U_o = \dfrac{U_{in}}{1-D}$，即理想增益[[4.1-CCM工作过程#五、CCM稳态增益（伏秒平衡）|式(4.1-5)]]。

### 2.5 非理想因素对占空比的影响

由于 $U_{SW}$、$U_D$ 的存在，要达到相同的 $U_o$，实际占空比 $D$ 需要比理想值**略大**——损耗占去了一部分"升压能力"，效率 $\eta<1$。

---

## 三、理想公式的"奇异点"：$D\to1$ 与实际电路不符

先把式(4.6-2)和理想式画成增益曲线，会发现一个矛盾。

由 $U_o = \dfrac{U_{in}}{1-D}$（无论是否含压降），**$D\to1$ 时 $U_o\to\infty$**。但在实际电路中：

| 极限 | 理想公式预测 | 实际电路行为 |
|---|---|---|
| $D=1$（Q 常通，管子一直开） | $U_o\to\infty$ | 二极管一直反偏，**输入与输出永远连不起来**，$C_o$ 上的电荷终会放完 → $U_o\to0$，增益 $=0$ |
| $D=0$（Q 常断，管子一直不开） | $U_o=U_{in}$ | 电感被直流短路，最终**饱和**（相当于导线）→ $U_o=U_{in}$，增益 $=1$ |

> **推测：** 实际 Boost 的增益曲线应从 $D=0$ 处的 **1** 开始，随 $D$ 增大而升高，在某个占空比达到**最大值**，然后回落，到 $D=1$ 时回到 **0**。但式(4.6-2)与理想式都表达不出这个"回落到零"的趋势——说明还缺一个限制因素。

> **对比 Buck：** Buck 没有这个奇异点——$D=0\Rightarrow U_o=0$，$D=1\Rightarrow U_o=U_{in}$，与理想公式完全对应。根源在于 Boost 的输入输出之间隔着二极管与开关管，而 Buck 的电感直接串在输入输出回路里。

## 四、考虑电感寄生电阻 $R_1$ 的增益

### 4.1 模型

在电感支路串入寄生的绕线电阻 $R_1$（含线路电阻）。为简化计算，**先不考虑 Q/D 的压降**（考虑后结论相同，只是式子更繁）。

![[4.6-3 电感含有寄生电阻的Boost拓扑分析.png|470]]

### 4.2 A、B 两点电压

- **B 点**：Q 导通时 $U_B = 0$；Q 关断时 $U_B = U_o$。故

$$\overline{U_B} = U_o\cdot(1-D)$$

- **A 点**：$U_A = U_{in} - i_L\cdot R_1$。由于 $i_L$ 是三角波而 $R_1$ 为定值，A 点电压**一直在变**，不能直接写成定值——必须用**平均值的定义**来求：

$$\overline{U_A} = \frac{1}{T}\int_0^T (U_{in} - i_L R_1)\,dt = U_{in} - R_1\cdot\underbrace{\frac{1}{T}\int_0^T i_L\,dt}_{I_L} = U_{in} - R_1 I_L$$

![[4.6-4 含有电感电压电流波形.png|470]]

### 4.3 电压平均值相等

$$\overline{U_A} = \overline{U_B} \;\Rightarrow\; U_{in} - R_1 I_L = U_o(1-D) \tag{4.6-4}$$

代入 [[4.2-电感电流纹波分析#二、直流分量 $I_L$ 的计算|式(4.2-3)]] $I_L=\dfrac{I_o}{1-D}$ 与 $I_o=\dfrac{U_o}{R_o}$：

$$U_{in} = U_o(1-D) + \frac{R_1 U_o}{R_o(1-D)} = U_o\left[(1-D) + \frac{R_1}{R_o(1-D)}\right]$$

### 4.4 增益表达式

$$\boxed{\frac{U_o}{U_{in}} = \frac{1-D}{(1-D)^2 + \dfrac{R_1}{R_o}}} \tag{4.6-5}$$

也可写成"理想增益 × 修正因子"的形式：

$$\frac{U_o}{U_{in}} = \frac{1}{1-D}\cdot\frac{1}{1 + \dfrac{R_1}{R_o(1-D)^2}}$$

> **理想情况对照：** 令 $R_1=0$，修正因子为 1，回到理想增益 $\dfrac{1}{1-D}$。

### 4.5 增益曲线与"最高增益点"

以 $R_1/R_o$ 为参变量，画出增益随占空比 $D$ 的变化（注意 $R_1\ll R_o$）：

![[4.6-5 增益与占空比及其寄生电阻关系曲线图.png|470]]

- **黑色（$R_1/R_o=0$，理想）**：单调上升，$D\to1$ 时增至无穷
- **红/蓝/绿/粉（$R_1/R_o=0.02/0.04/0.06/0.08$）**：出现**峰值**，随后回落，到 $D=1$ 时降为 0
- $R_1/R_o$ 越大 → 峰值越低

对式(4.6-5)求极值（令 $x=1-D$，最大化 $x/(x^2+R_1/R_o)$）：

$$\boxed{D_{peak} = 1 - \sqrt{\dfrac{R_1}{R_o}},\qquad G_{max} = \frac{1}{2}\sqrt{\dfrac{R_o}{R_1}}} \tag{4.6-6}$$

> **恰好解释了开篇的疑问：** Boost 存在一个**最高增益点**，它由寄生电阻 $R_1$ 决定，$R_1$ 越大峰值越低——这正对应第三节中"回落到零"的猜测。当 $R_1=0$ 时峰值趋于无穷，回到理想式。

### 4.6 物理解释：为什么 $R_1$ 限制了最大增益？

设想 Q 一直开通（$D\to1$）：电路变成 $U_{in}\to R_1\to L\to Q$（短路），电感电流会线性上升到稳态值

$$i_{L,max}=\frac{U_{in}}{R_1}$$

对应的最大储能 $E_{max}=\dfrac{1}{2}L\left(\dfrac{U_{in}}{R_1}\right)^2$。

- $R_1$ 越大 → 电流能达到的上限越低 → 储能上限越低 → 每个周期能送到输出的能量越少 → **增益越低**
- 所以 **电感线路中的寄生电阻限制了 Boost 的最大增益，使其无法达到无穷大**

> 至此回答了开篇提出的问题。

## 五、CCM Boost 全部设计公式汇总

以下汇总整合第四章前五节（增益、纹波、电感设计、电流有效值、纹波电压）与非理想修正的核心结论。

### 5.1 基本参数

| 参数 | 公式 | 说明 |
|---|---|---|
| 理想增益 | $U_o = \dfrac{U_{in}}{1-D}$ | 仅由 $D$ 决定 |
| 含压降增益 | $U_o = \dfrac{U_{in}-D U_{SW}}{1-D} - U_D$ | 考虑 $U_{SW}$、$U_D$ |
| 含 $R_1$ 增益 | $\dfrac{U_o}{U_{in}} = \dfrac{1-D}{(1-D)^2+R_1/R_o}$ | 峰值 $G_{max}=\frac{1}{2}\sqrt{R_o/R_1}$ |
| 开关周期 | $T=1/f$ | — |
| 电流纹波率 | $\tau = \dfrac{D(1-D)^2 R_o T}{L}$ | 推荐 0.4，可取 0.3~0.5，可放宽至 0.2~0.6 |

### 5.2 电感电流

| 量 | 公式 |
|---|---|
| 平均值 | $I_L = \dfrac{I_o}{1-D}$ |
| 纹波 | $\Delta i_L = \dfrac{U_o D(1-D)T}{L} = \tau I_L$ |
| 峰值 | $i_{L\_peak} = I_L\left(1+\dfrac{\tau}{2}\right)$ |
| RMS 值 | $I_{L\_rms} = \dfrac{I_o}{1-D}\sqrt{1+\dfrac{\tau^2}{12}}$ |

### 5.3 开关管 Q 与二极管 D

| 元件 | 平均值 | RMS | 电压应力 |
|---|---|---|---|
| Q | $\dfrac{I_o D}{1-D}$ | $\dfrac{I_o\sqrt{D}}{1-D}\sqrt{1+\dfrac{\tau^2}{12}}$ | $U_o$ |
| D | $I_o$ | $\dfrac{I_o}{\sqrt{1-D}}\sqrt{1+\dfrac{\tau^2}{12}}$ | $U_o$ |

### 5.4 电容

| 量 | 公式 |
|---|---|
| 输入电容 RMS | $I_{Cin\_rms} = \dfrac{\tau I_o}{2\sqrt{3}(1-D)}$ |
| 输出电容 RMS | $I_{Co\_rms} = I_o\sqrt{\dfrac{D+\tau^2/12}{1-D}}$ |
| 输出纹波电压 | $\Delta U_o = \dfrac{I_o D}{C_o f}$ |

### 5.5 电感值

$$\boxed{L = \frac{U_o D_{max}(1-D_{max})^2}{\tau \cdot I_o \cdot f}} \qquad (\tau\approx0.4,\ D_{max}=1-U_{in\_min}/U_o)$$

在最恶劣工况（**最低输入电压**、满载）下计算。

## 六、各元件电流应力随占空比 D 的变化曲线

将各元件电流有效值以 **$D=0.5$** 为基准**归一化**，画出应力随 $D$ 的变化：

![[4.6-6 各元件电流有效值与占空比关系曲线（归一化）.png|470]]

图中四条曲线分别对应开关管、二极管、输入电容、输出电容的电流有效值。整体趋势：

- **开关管、二极管的电流应力随 $D$ 增大而上升**——$D$ 越大（低压差、大升压比），管子需承受的电流幅值越高
- **电容类电流应力在中间占空比附近出现峰值**，随 $D$ 继续增大反而下降——其根源是电感纹波 $\Delta i_L\propto D(1-D)$ 在 $D=0.5$ 最大（[[4.2-电感电流纹波分析#3.2 $\Delta i_L$ 何时最大？—— D = 0.5|4.2节]]）

> **核心洞察：各元器件的电流应力不在同一个工作点达到最大。**
> - 开关管、二极管应力最大 → **D 偏大**
> - 电容类应力最大 → **D ≈ 0.5**
>
> 这对电源优化的指导意义：先明确电源**主要工作在哪个 $D$ 区间**，再针对该区间内应力最大的元件重点优化。
>
> 注意：纵轴是**归一化后的比例关系**，不是实际安培值，只用于判断"变换器工作在哪个 $D$ 时哪些器件应力更大"。

## 七、本节小结

| 主题 | 核心结论 |
|---|---|
| 含压降增益 | $U_o = \dfrac{U_{in}-DU_{SW}}{1-D}-U_D$，非理想因素使 $D$ 需略大于理想值 |
| 奇异点 | 理想式在 $D\to1$ 给出无穷增益，与实际电路（$D=1$ 时输出为零）不符 |
| 含 $R_1$ 增益 | $\dfrac{U_o}{U_{in}}=\dfrac{1-D}{(1-D)^2+R_1/R_o}$，存在最高增益点 $G_{max}=\frac{1}{2}\sqrt{R_o/R_1}$ |
| 最大增益的来源 | 寄生电阻 $R_1$ 限制了电感电流上限 $U_{in}/R_1$，从而限制储能与增益 |
| 应力曲线 | 各元件应力峰值不在同一 $D$；电容类在 $D\approx0.5$ 附近最大 |
