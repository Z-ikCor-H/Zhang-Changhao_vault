# 第四章 Boost电路 第九节：DCM增益分析

[[4.8-DCM工作过程|DCM模式]]下，增益不再等于 $U_o=\dfrac{U_{in}}{1-D}$。本节联合**伏秒平衡**与**二极管平均电流 = 负载电流**推导 DCM 增益：**$D_1$ 是多少？增益与哪些参数有关？为什么轻载时占空比会自动减小？如何证明 DCM 增益大于 CCM 增益？** 给出完整的增益公式与严格证明。

---

## 一、推导思路

DCM 下的增益 $U_o/U_{in}$ 与 $L$、$R_o$、$T$ 都有关，不再是单纯的 $D$ 的函数。推导分两步：

1. **伏秒平衡** → 用 $D$ 和 $D_1$ 表示增益
2. **二极管平均电流 = 负载电流** → 求出 $D_1$
3. 联立消元 → 得到只含 $D$、$L$、$R_o$、$T$ 的增益表达式

---

## 二、伏秒平衡

DCM 下电感电压波形：

- **模态一（$DT$）**：$U_L = U_{in}$
- **模态二（$D_1T$）**：$U_L = -(U_o - U_{in})$
- **模态三（$T_D$）**：$U_L = 0$（电流为零且不变）

由伏秒平衡（**正电压伏秒积 = 负电压伏秒积**）：

$$U_{in}\cdot D T = (U_o - U_{in})\cdot D_1 T$$

约去 $T$、整理：

$$U_{in}(D + D_1) = U_o D_1$$

$$\boxed{\frac{U_o}{U_{in}} = \frac{D + D_1}{D_1} = 1 + \frac{D}{D_1}} \tag{4.9-1}$$

> **与 CCM 对比：** CCM 中 $D_1 = 1-D$，代入得 $U_o/U_{in} = 1/(1-D)$；DCM 中 $D_1 < 1-D$（因为 $T_D>0$），故增益表达式不同。
>
> **与 Buck 对偶：** Buck 的 [[3.3-DCM增益分析#二、伏秒平衡|DCM]] 增益为 $\dfrac{D}{D+D_1}$，Boost 恰好把分子分母**对调**为 $\dfrac{D+D_1}{D_1}$。

关键问题：**$D_1$ 是多少？** 需要借助二极管电流的平均值来求解。

---

## 三、用二极管平均电流求 $D_1$

### 3.1 关键关系：二极管平均电流 = 负载电流

$$I_{D\_avg} = I_o = \frac{U_o}{R_o}$$

> **这个结论在 CCM 和 DCM 下都成立**（[[4.4-电流有效值计算#4.2 平均值|4.4节]]已证）：负载电流只能由二极管提供，没有别的通路，故二极管电流平均值必然等于 $I_o$。从电路直接看出，无需再算。

### 3.2 三角形面积法

二极管只在模态二（$D_1T$）导通，其电流是**从 $I_{LP}$ 降为零的三角形**（底边 $D_1T$、高 $I_{LP}$）。平均值 = 三角形面积 ÷ 周期：

$$I_{D\_avg} = \frac{1}{T}\cdot\frac{1}{2}\cdot I_{LP}\cdot D_1 T = \frac{1}{2}I_{LP}D_1$$

### 3.3 用导通阶段表示 $I_{LP}$

$$I_{LP} = \frac{U_{in}}{L}\cdot D T$$

### 3.4 联立

$$I_o = \frac{1}{2}I_{LP}D_1 = \frac{1}{2}\cdot\frac{U_{in}DT}{L}\cdot D_1 = \frac{U_{in}D D_1 T}{2L} \tag{4.9-2}$$

---

## 四、巧妙求解：消去 $D_1$

直接解出 $D_1$ 再代入增益式较为繁琐。用**消元法**更简洁：

设增益 $M = \dfrac{U_o}{U_{in}}$。由 [[#二、伏秒平衡|式(4.9-1)]] $M = 1+\dfrac{D}{D_1}$，反解：

$$D_1 = \frac{D}{M-1} \tag{4.9-3}$$

另一方面，由 $I_o = U_o/R_o$ 与 [[#3.4 联立|式(4.9-2)]]：

$$M = \frac{U_o}{U_{in}} = \frac{I_o R_o}{U_{in}} = \frac{D D_1 T R_o}{2L}$$

代入 $D_1 = \dfrac{D}{M-1}$：

$$M = \frac{D^2 T R_o}{2L(M-1)}$$

整理：

$$\boxed{M^2 - M - \frac{D^2 R_o T}{2L} = 0} \tag{4.9-4}$$

这是关于增益 $M$ 的**一元二次方程**。由求根公式，$a=1$、$b=-1$、$c=-\dfrac{D^2R_oT}{2L}$：

$$M = \frac{1 \pm \sqrt{1 + \dfrac{2D^2 R_o T}{L}}}{2}$$

物理上增益必须为正，舍去负根（取"$+$"号）：

$$\boxed{M = \frac{U_o}{U_{in}} = \frac{1 + \sqrt{1 + \dfrac{2D^2 R_o T}{L}}}{2}} \tag{4.9-5}$$

---

## 五、增益公式解读

DCM 增益取决于**四个参数**：$D$、$L$、$R_o$、$T$（或 $f=1/T$）——几乎与所有元件都有关，而 [[4.1-CCM工作过程#五、CCM稳态增益（伏秒平衡）|CCM 增益只]]与 $D$ 有关。

| 参数变化 | 对增益的影响 | 说明 |
|---|---|---|
| $R_o\uparrow$（负载减轻） | 增益 $\uparrow$ | 根号项增大 |
| $L\downarrow$ | 增益 $\uparrow$ | DCM 效应更强 |
| $D\uparrow$ | 增益 $\uparrow$ | 储能时间变长 |
| $R_o\to\infty$ 或 $L\to L_{crit}$ | 增益 $\to \dfrac{1}{1-D}$ | 回到 CCM |

### 5.1 解释了"占空比为什么会减小"

在 DCM 下，若 $R_o$ 增大（负载减轻），由式(4.9-5) **增益升高**。若要维持 $U_o$ 不变，就必须**减小占空比 $D$** 把增益压回去。

> 这正是 [[4.8-DCM工作过程#3.2 电感减小 $L$ 的情况（$L<L_{crit}$）|第八节]] 中"电感减小后占空比 $D$ 减小"的严格解释——当时无法直接判断，现在由增益公式给出答案。

> **注意：即使设计在 CCM 模式，变换器也不能保证全负载范围 CCM。** 当负载电阻大于临界电阻 $R_{crit}$ 时，它依然会进入 DCM，增益随之按式(4.9-5) 变化。

---

## 六、DCM增益 > CCM增益（严格证明）

### 6.1 结论

> 在**相同占空比 $D$** 下，DCM 模式的增益**大于** CCM 模式的增益：

$$\left.\frac{U_o}{U_{in}}\right|_{DCM} > \left.\frac{U_o}{U_{in}}\right|_{CCM} = \frac{1}{1-D}$$

### 6.2 证明

进入 DCM 的前提是 $L < L_{crit}$ [[4.7-BCM工作过程#2.3 临界电感 $L_{crit}$|式(4.7-4)]] $L_{crit}=\dfrac{R_o D(1-D)^2 T}{2}$：

$$L < L_{crit}=\frac{R_o D(1-D)^2 T}{2} $$

由式[[#四、巧妙求解：消去 $D_1$|(4.9-5)]]，只需比较根号项。把上式右边（$L$ 的**最小**可能值对应根号项的**最小**值）代入：

$$\begin{aligned}
\sqrt{1+\frac{2D^2 R_o T}{L}} &> \sqrt{1+\frac{2D^2 R_o T}{L_{crit}}} \\[6pt]
&= \sqrt{1 + \frac{4D}{(1-D)^2}} = \sqrt{\frac{(1-D)^2 + 4D}{(1-D)^2}} \\[6pt]
&= \sqrt{\frac{(1+D)^2}{(1-D)^2}} = \frac{1+D}{1-D}
\end{aligned}$$

带回DCM增益公式：

$$M > \frac{1 + \dfrac{1+D}{1-D}}{2} = \frac{\dfrac{1-D+1+D}{1-D}}{2} = \frac{1}{1-D}$$

证毕。

> **初学者常见误区：** 很多人凭直觉认为 DCM 增益小于 CCM，这是**反的**。完整的理论推导证明：相同 $D$ 下，DCM 增益 > CCM 增益。

---

## 七、极限验证：BCM 处连续

将 BCM 条件 $L = L_{crit}=\dfrac{R_o D(1-D)^2 T}{2}$ 代入式[[4.9-DCM增益分析#四、巧妙求解：消去 $D_1$|4.9-5]]：

$$\frac{2D^2 R_o T}{L_{crit}} = \frac{4D}{(1-D)^2} \;\Rightarrow\; \sqrt{1+\frac{4D}{(1-D)^2}} = \frac{1+D}{1-D}$$

$$M = \frac{1 + \frac{1+D}{1-D}}{2} = \frac{1}{1-D}$$

结果与 CCM 增益完全一致——说明 **BCM 是 CCM 与 DCM 的无缝衔接点**，两条增益曲线在此点连续。

---

## 八、本节小结

| 主题 | 核心结论 |
|---|---|
| 伏秒平衡 | $\dfrac{U_o}{U_{in}} = 1 + \dfrac{D}{D_1}$ |
| $D_1$ 求解 | 由 $I_{D\_avg}=I_o=\frac{1}{2}I_{LP}D_1$ 与 $I_{LP}=\frac{U_{in}DT}{L}$ 导出 |
| 增益公式 | $M = \dfrac{1+\sqrt{1+2D^2R_oT/L}}{2}$，是 $M$ 的一元二次方程的解 |
| 增益与参数 | 与 $D$、$L$、$R_o$、$T$ 均有关（CCM 只与 $D$ 有关） |
| 占空比 | $R_o\uparrow$ → 增益 $\uparrow$ → 为维持 $U_o$ 需**减小 $D$** |
| DCM vs CCM | 相同 $D$ 下 DCM 增益 **>** CCM 增益（已严格证明） |
| 衔接性 | BCM 条件代入 → 退化为 $U_o/U_{in}=\frac{1}{1-D}$ |
