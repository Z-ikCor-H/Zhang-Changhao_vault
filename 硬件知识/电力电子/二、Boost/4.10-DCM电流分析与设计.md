# 第四章 Boost电路 第十节：DCM电流分析与设计

DCM 模式下，**开关管、二极管、电感、电容的电流有效值和平均值如何计算？与 [[4.4-电流有效值计算|CCM]] 公式有何差异？** 本节基于前几节的 $D_1$、$M$、$I_{LP}$ 等结论，用"占比缩放 + 三角波有效值 + 正交分解"三步给出各元件电流应力公式，并将 CCM 与 DCM 的全部设计公式汇总为速查表，最后讨论 Boost 与 Buck 的联系——非隔离双向 DC-DC 变换器。

---

## 一、分析基础

### 1.1 DCM 电流波形回顾

![[4.10-1 DCM二极管电压电流波形.png|470]]

- 开关管电流 $i_Q$：模态一（$DT$）内为三角波**上升段**（从零升至 $I_{LP}$），其余时间为零
- 二极管电流 $i_D$：模态二（$D_1T$）内为三角波**下降段**（从 $I_{LP}$ 降至零），其余时间为零
- 电感电流 $i_L$：模态一 + 模态二的完整三角波，模态三为零

![[4.10-2DCM L、Q、D电流波形.png|470]]

### 1.2 通用工具公式

本节**不重新推导**理论基础（三角波 RMS、占比缩放、正交分解），这些在 CCM 章节已详细推导（见[[硬件知识/电力电子/一、BUCK/2.2-电感与开关管电流有效值|Buck第二章]]）。直接使用结论。

对于一个最低点为零、最高点为 $I_{LP}$、在整个周期中占比为 $\delta$ 的三角波：

$$I_{rms} = \sqrt{\delta}\cdot\frac{I_{LP}}{\sqrt{3}} \tag{4.10-1}$$

> **三步法的来源：** ① 三角波（峰值 $I_{LP}$）的有效值为 $I_{LP}/\sqrt{3}$；② 该波形只占周期的 $\delta$ 比例 → 乘 $\sqrt{\delta}$。

## 二、开关管 Q 的电流

开关管电流是模态一内从零升到 $I_{LP}$ 的三角波，占比 $D$。

### 2.1 RMS值

$$I_{Q\_rms} = \sqrt{D}\cdot\frac{I_{LP}}{\sqrt{3}} = I_{LP}\sqrt{\frac{D}{3}} \tag{4.10-2}$$

需要把未知的 $I_{LP}$ 换成已知量。由 [[4.9-DCM增益分析#3.2 三角形面积法|第九节]] 的 $I_L=\frac{1}{2}I_{LP}(D+D_1)$：

$$I_{LP} = \frac{2I_L}{D+D_1}$$

又电感电流平均值等于输入电流，由功率守恒 $U_{in}I_{in}=U_oI_o$：

$$I_L = I_{in} = \frac{U_o}{U_{in}}I_o = M\cdot I_o$$

其中 $M$ 为 [[4.9-DCM增益分析#四、巧妙求解：消去 $D_1$|DCM 增益]]。因此：

$$I_{LP} = \frac{2M I_o}{D+D_1} \;\Rightarrow\; \boxed{I_{Q\_rms} = \frac{2M I_o}{D+D_1}\sqrt{\frac{D}{3}}} \tag{4.10-3}$$

### 2.2 平均值

$$I_{Q\_avg} = \frac{1}{2}\cdot D\cdot I_{LP} = \frac{M I_o D}{D+D_1} \tag{4.10-4}$$

> **物理意义：** $I_{Q\_avg}$ 也是电源的**输入电流平均值** $I_{in}$，因为输入电流只在开关管导通时流过。

---

## 三、二极管 D 的电流

### 3.1 RMS值

二极管电流是模态二内从 $I_{LP}$ 降到零的三角波，占比 $D_1$。**只需把开关管公式中的 $D$ 换成 $D_1$**（波形相同，只是位置与占比不同）：

$$I_{D\_rms} = \sqrt{D_1}\cdot\frac{I_{LP}}{\sqrt{3}} = \frac{2M I_o}{D+D_1}\sqrt{\frac{D_1}{3}} \tag{4.10-5}$$

### 3.2 平均值

$$I_{D\_avg} = \frac{1}{2}\cdot D_1\cdot I_{LP} = \frac{M I_o D_1}{D+D_1}$$

由 $M = \dfrac{D+D_1}{D_1}$（[[4.9-DCM增益分析#二、伏秒平衡|式(4.9-1)]]），化简得：

$$\boxed{I_{D\_avg} = I_o} \tag{4.10-6}$$

> 与 CCM 相同的结论：二极管电流平均值恒等于负载电流 $I_o$（**与工作模式无关**）。这是选二极管额定平均电流的依据。

---

## 四、电感 L 的电流

### 4.1 用正交分解求 RMS

电感电流 $i_L$ 由 $i_Q$ 与 $i_D$ **拼接**而成。由于 $i_Q$、$i_D$ **不同时存在**（一个非零时另一个必为零），二者**正交**：

$$I_{L\_rms}^2 = I_{Q\_rms}^2 + I_{D\_rms}^2$$

代入式(4.10-2)、(4.10-5)：

$$I_{L\_rms} = I_{LP}\sqrt{\frac{D+D_1}{3}} = \frac{2M I_o}{\sqrt{3(D+D_1)}} \tag{4.10-7}$$

### 4.2 平均值

$$I_{L\_avg} = I_{in} = M\cdot I_o \tag{4.10-8}$$

> 电感电流平均/有效值是**磁元件设计与选线径（铜线）**的依据。

---

## 五、输出电容 $C_o$ 的电流

![[4.10-3 DCM D、C_o、I_o电流波形.png|470]]

二极管电流中，平均值 $I_o$ 流入负载，交流分量流入输出电容：

$$I_{Co\_rms}^2 = I_{D\_rms}^2 - I_{D\_avg}^2 = I_{D\_rms}^2 - I_o^2$$

代入 $I_{D\_rms}=\dfrac{2I_o}{\sqrt{3D_1}}$（由式(4.10-5) 与 $M=(D+D_1)/D_1$ 化简）：

$$\boxed{I_{Co\_rms} = I_o\sqrt{\frac{4}{3D_1} - 1}} \tag{4.10-9}$$

> 该式是输出电容**额定纹波电流**选型的依据。需要把 $D_1$ [[4.9-DCM增益分析#四、巧妙求解：消去 $D_1$|式(4.9-3)]]、[[4.9-DCM增益分析#四、巧妙求解：消去 $D_1$|式(4.9-5)]]代入，才能化为仅含 $D$、$L$、$R_o$、$T$ 的形式。

---

## 六、输入电容 $C_{in}$ 的电流

Boost 电感连在输入端。电感电流 $i_L$ 中：

- **直流分量 $I_{in}$**（来自电源）
- **交流分量**（纹波）→ 全部由**输入电容**提供

由正交分解：

$$I_{Cin\_rms}^2 = I_{L\_rms}^2 - I_{in}^2$$

代入式(4.10-7)、(4.10-8)：

$$\boxed{I_{Cin\_rms} = M I_o\sqrt{\frac{4}{3(D+D_1)} - 1}} \tag{4.10-10}$$

> **与 Buck 的对偶：** Boost 电感连输入端 → 交流纹波进输入电容；Buck 电感连输出端 → 纹波进输出电容。两者公式形式对偶，只是 $I_{in}$ 与 $I_o$ 的角色互换。

---

## 七、DCM 电感设计

DCM 下电感设计的目标与 CCM 相反——**确保**进入 DCM：

$$L < L_{crit} = \frac{R_o D(1-D)^2 T}{2}$$

或按纹波率目标（DCM 下 $\tau>2$，例如 $\tau=3\sim5$）：

$$L = \frac{U_o D(1-D)}{\tau\cdot I_o\cdot f}$$

---

## 八、CCM vs DCM 全部公式汇总

以下把 Boost 在 CCM、DCM 两种模式下的核心公式并列，便于速查。

### 8.1 基本关系

| 参数 | CCM | DCM |
|---|---|---|
| 增益 $\dfrac{U_o}{U_{in}}$ | $\dfrac{1}{1-D}$ | $\dfrac{1+\sqrt{1+2D^2R_oT/L}}{2}$ |
| $D_1$ | $1-D$ | $\dfrac{D}{M-1}$ |
| $D+D_1$ | $=1$ | $<1$ |
| 电流纹波率 $\tau$ | $<2$ | $>2$ |

### 8.2 峰值电流 $I_{LP}$

| CCM | DCM |
|---|---|
| $I_L\left(1+\dfrac{\tau}{2}\right)$ | $\dfrac{2M I_o}{D+D_1}$ |

### 8.3 开关管 Q

| 参数 | CCM | DCM |
|---|---|---|
| 平均值 | $\dfrac{I_o D}{1-D}$ | $\dfrac{M I_o D}{D+D_1}$ |
| RMS | $\dfrac{I_o\sqrt{D}}{1-D}\sqrt{1+\dfrac{\tau^2}{12}}$ | $\dfrac{2M I_o}{D+D_1}\sqrt{\dfrac{D}{3}}$ |

### 8.4 二极管 D

| 参数 | CCM | DCM |
|---|---|---|
| 平均值 | $I_o$ | $I_o$ |
| RMS | $\dfrac{I_o}{\sqrt{1-D}}\sqrt{1+\dfrac{\tau^2}{12}}$ | $\dfrac{2M I_o}{D+D_1}\sqrt{\dfrac{D_1}{3}}$ |

### 8.5 电感 L

| 参数 | CCM | DCM |
|---|---|---|
| 平均值 | $\dfrac{I_o}{1-D}$ | $M I_o$ |
| RMS | $\dfrac{I_o}{1-D}\sqrt{1+\dfrac{\tau^2}{12}}$ | $\dfrac{2M I_o}{\sqrt{3(D+D_1)}}$ |

### 8.6 电容

| 参数 | CCM | DCM |
|---|---|---|
| 输入电容 RMS | $\dfrac{\tau I_o}{2\sqrt{3}(1-D)}$ | $M I_o\sqrt{\dfrac{4}{3(D+D_1)}-1}$ |
| 输出电容 RMS | $I_o\sqrt{\dfrac{D+\tau^2/12}{1-D}}$ | $I_o\sqrt{\dfrac{4}{3D_1}-1}$ |

### 8.7 电感设计

| 参数 | CCM | DCM |
|---|---|---|
| 电感值 | $\dfrac{U_o D_{max}(1-D_{max})^2}{\tau I_o f}$（$\tau\approx0.4$） | $<L_{crit}$（确保 DCM） |
| 临界电感 | — | $\dfrac{R_o D(1-D)^2 T}{2}$ |
| 临界电阻 | — | $\dfrac{2L}{D(1-D)^2 T}$ |

## 九、选型指导

| 器件 | 选型依据 | 关键参数 |
|---|---|---|
| 开关管 Q | $I_{Q\_rms}$（损耗）、$I_{LP}$（峰值）、$U_o$（耐压） | $R_{DS(on)}$、$V_{DS}$、$I_D$ |
| 二极管 D | $I_{D\_avg}$（损耗）、$I_{LP}$（峰值）、$U_o$（耐压） | $V_F$、$V_R$、$I_F$ |
| 电感 L | $I_{L\_rms}$（线径/发热）、$I_{LP}$（饱和） | $L$ 值、$I_{sat}$、磁芯 |
| 输出电容 $C_o$ | $I_{Co\_rms}$（发热/ESR）、$\Delta U_o$（纹波） | 容量、ESR、耐压 |
| 输入电容 $C_{in}$ | $I_{Cin\_rms}$（发热/ESR） | 容量、ESR、耐压 |

> **MOS 管按有效值算导通损耗，二极管按平均值算损耗**——这是选型的核心区别。

## 十、Boost 与 Buck 的联系：非隔离双向 DC-DC

![[4.10-4 Boost基础拓扑.png|340]]
![[4.10-5 Buck基础拓扑.png|340]]

观察 Boost 与 Buck 的拓扑：**把 Boost 中的二极管 D 换成开关管 $Q_2$**，就得到一个"背靠背"的电路：

![[4.10-6 双向DC-DC基础拓扑.png|470]]

- **从左往右看**（左端为输入 $U_{in}$、右端为输出 $U_o$）：$Q_1$ 作主管、$Q_2$ 兼作"二极管" → 升压（Boost）
- **从右往左看**（右端为输入 $U_o$、左端为输出 $U_{in}$）：$Q_2$ 作主管、$Q_1$ 兼作"二极管" → 降压（Buck）

两种方向都自洽，因为 Boost 中 $U_o>U_{in}$、Buck 中 $U_{in}<U_o$，正好对应同一拓扑的两个方向。

> 这就是**非隔离型双向 DC-DC 变换器**，常用于**电池充放电**（充电时降压、放电时升压）。

## 十一、本节小结

| 主题 | 核心结论 |
|---|---|
| 开关管 RMS | $I_{LP}\sqrt{D/3}$ |
| 二极管 RMS | $I_{LP}\sqrt{D_1/3}$（把 Q 公式中 $D$ 换 $D_1$） |
| 二极管平均值 | $I_o$（与模式无关） |
| 电感 RMS | $\sqrt{I_{Q\_rms}^2+I_{D\_rms}^2}$（正交叠加） |
| 输出电容 RMS | $\sqrt{I_{D\_rms}^2-I_o^2}=I_o\sqrt{4/(3D_1)-1}$ |
| 输入电容 RMS | $\sqrt{I_{L\_rms}^2-I_{in}^2}$ |
| 峰值电流 | $I_{LP}=\dfrac{2M I_o}{D+D_1}$ |
| 双向 DC-DC | Boost 的二极管换开关管 → 非隔离双向变换器 |

> 至此，Boost 电路（CCM + DCM）的原理分析与参数计算全部完成，与 [[硬件知识/电力电子/一、BUCK/2.4-非理想Buck分析|Buck 电路]] 形成完整的对偶体系。
