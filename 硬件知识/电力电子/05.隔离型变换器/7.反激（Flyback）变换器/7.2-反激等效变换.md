# 第七章 反激变换器 第二节：反激等效变换与BCM

[上一节](7.1-反激CCM工作过程.md)说明反激是从 Buck-Boost 演变来的。既然是同一个拓扑，就可以**反过来**把反激等效变换回 Buck-Boost——**去掉变压器之后，Buck-Boost 的全部结论都可以直接套用。** 本节给出两种等效方式，并据此推出反激的 BCM 临界条件。

---

## 一、两种等效变换

<img src="照片引用/7.2-1%20反激拓扑.png" width="440">

### 1.1 等效到原边（推荐）

利用增益公式 $\dfrac{U_o}{U_{in}}=\dfrac{1}{n}\cdot\dfrac{D}{1-D}$ ，把 $n\cdot U_o$ **看成一个整体**：

$$\frac{n\cdot U_o}{U_{in}}=\frac{D}{1-D}$$

<img src="照片引用/7.2-2%20原边等效Buck-Boost.png" width="470">

这就恰好是**一个输出为 $n\cdot U_o$ 、输入为 $U_{in}$ 的 Buck-Boost 拓扑**。等效时其余量要一并折算：

| 物理量 | 原边等效后的值 |
|---|---|
| 输出电压 | $n\cdot U_o$ |
| 负载电阻 | $n^2R_o$ |
| 负载电流 | $\dfrac{I_o}{n}$ |

> **为什么电阻是 $n^2$ 倍？** 变压器对阻抗的变换是**匝比平方**的关系，这样才保证**功率守恒**： $\dfrac{(nU_o)^2}{n^2R_o}=\dfrac{U_o^2}{R_o}$ ✓。详细推导在磁元件（变压器理论）课程中。

等效后的电路：原边不动，只是开关管位置挪一下，原边的电感依然是 $L_m$ （它同时就是等效 Buck-Boost 的那个电感）。

> **建议采用这种等效方式**——等效到原边后计算最方便，也是最常用的做法。

### 1.2 等效到副边

也可以把 $n$ 移到分母去：

$$\frac{U_o}{U_{in}/n}=\frac{D}{1-D}$$

<img src="照片引用/7.2-3%20折射到副边等效.png" width="470">

这就是**一个输入为 $U_{in}/n$ 、输出仍为 $U_o$ 的 Buck-Boost 拓扑**。同样别忘了折算电感：

$$L_m \;\longrightarrow\; \frac{L_m}{n^2}=L_S$$

（电感量与匝数平方成正比； $\dfrac{L_m}{n^2}$ 就是副边电感 $L_S$ ，可直接用 $L_S$ 替代。）

### 1.3 两种等效的对照

| | 等效到原边 | 等效到副边 |
|---|---|---|
| 等效输入 | $U_{in}$ | $\dfrac{U_{in}}{n}$ |
| 等效输出 | $n\cdot U_o$ | $U_o$ |
| 等效电感 | $L_m$ | $\dfrac{L_m}{n^2}=L_S$ |
| 等效负载 | $n^2R_o$ | $R_o$ |
| 推荐度 | **推荐**（最常用） | 备用 |

> 无论哪种方式，**Buck-Boost 的全部结论都可以直接使用**。

## 二、反激变压器应看成"耦合电感"

反激的这个磁元件，**不能按传统变压器的思路去理解**：

| | 传统变压器 | 反激的"变压器" |
|---|---|---|
| 原边有电流时 | 副边**也有**电流（同时存在） | 副边**没有**电流 |
| 副边有电流时 | 原边也有电流 | 原边**没有**电流 |

$$\boxed{\text{反激变压器应看成一个耦合电感（Coupled Inductor），作用是隔离}}$$

> **验证方法：** 把变压器拿掉、换成一个普通电感，电路**依然可以工作**——说明它本质上就是一个电感，只是多了一个（隔离的）副边绕组。这样理解后，后面的分析会更方便。

## 三、BCM工作过程与临界条件

<img src="照片引用/7.2-4%20波形分析.png" width="390">

<img src="照片引用/7.2-5%20励磁电感电压电流波形.png" width="440">

上一节讨论的是 CCM。让变换器进入 BCM 的方式与前面各章一样，有**两条路径**：

- **负载减轻**（ $R_o\uparrow$ → $I_o\downarrow$ ）→ 励磁电流平均值下降
- **减小励磁电感** $L_m$

两者都使励磁电流的**谷值不断下降**，最终谷值刚好降到零——**恰好在一个周期结束时降为零，下一个周期开关管接着开通**，此时即进入 **BCM（临界连续模式）**。

### 3.1 BCM 下的电流关系

等效到原边后，可直接套用 [Buck-Boost 的结论](../../03.Buck-Boost/5.6-BCM工作过程.md)：电感电流平均值

$$I_{Lm}=\frac{I_o/n}{1-D}=\frac{I_o}{n(1-D)} \quad \text{(7.2-1)}$$

在 BCM 下，励磁电流是从零开始、以零结束的三角波，故：

$$\boxed{I_{Lm}=\frac{1}{2}i_{Lm\_peak}} \quad \text{(7.2-2)}$$

### 3.2 临界电阻 $R_{crit}$

Buck-Boost 的临界电阻为 $R_{crit}=\dfrac{2L}{(1-D)^2T}$ ，其中：

- 电感 $L \to L_m$
- 负载电阻 $R_o \to n^2R_o$

$$n^2R_{crit}=\frac{2L_m}{(1-D)^2T} \quad\Rightarrow\quad \boxed{R_{crit}=\frac{2L_m}{n^2(1-D)^2T}} \quad \text{(7.2-3)}$$

- $R_o > R_{crit}$ （负载更轻）→ 进入 DCM
- $R_o < R_{crit}$ （负载更重）→ CCM

### 3.3 临界励磁电感 $L_{m\_crit}$

同样套用 Buck-Boost 的 $L_{crit}=\dfrac{R_o(1-D)^2T}{2}$ ，把 $R_o\to n^2R_o$ ：

$$\boxed{L_{m\_crit}=\frac{n^2R_o(1-D)^2T}{2}} \quad \text{(7.2-4)}$$

- $L_m < L_{m\_crit}$ → 变换器**全程**进入 DCM
- $L_m > L_{m\_crit}$ → 在设计负载范围内可工作于 CCM

> 这两个临界值正好是让变换器进入 BCM 的**理论值**。实际中由于存在损耗、二极管压降等寄生因素，实际工作点会与理论值略有偏差。

## 四、本节小结

| 主题 | 核心结论 |
|---|---|
| 等效到原边 | 输出 $nU_o$ 、输入 $U_{in}$ 的 Buck-Boost；负载 $n^2R_o$ 、电流 $I_o/n$ （**推荐**） |
| 等效到副边 | 输入 $U_{in}/n$ 、输出 $U_o$ 的 Buck-Boost；电感 $L_m/n^2=L_S$ |
| 阻抗变换 | 变压器对负载的变换是 $n^2$ 倍（保证功率守恒） |
| 本质认识 | 反激变压器是**耦合电感**，不是传统变压器——原副边电流不同时存在 |
| 进入 BCM | 负载减轻（ $R_o\uparrow$ ）或励磁电感减小（ $L_m\downarrow$ ），谷值触零 |
| 临界电阻 | $R_{crit}=\dfrac{2L_m}{n^2(1-D)^2T}$ |
| 临界励磁电感 | $L_{m\_crit}=\dfrac{n^2R_o(1-D)^2T}{2}$ |
| 方法论 | **三大基础拓扑的结论要熟练掌握**——后续章节会反复直接套用 |
