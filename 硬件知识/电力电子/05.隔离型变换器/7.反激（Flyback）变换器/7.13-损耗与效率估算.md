# 第七章 反激变换器 第十三节：损耗与效率估算

前面各节把电路设计完了，但还差一问：**"这台反激的效率大概是多少？"** 本节把六类损耗逐项列出、给出计算公式，并给出**效率预算表**模板。所有电流量都来自 [7.8 节](7.8-稳态电流应力与电容选型.md)。

$$\eta=\frac{P_o}{P_o+P_{loss}},\qquad P_{loss}=P_Q+P_D+P_{Cu}+P_{core}+P_{RCD}+P_{other} \quad \text{(7.13-1)}$$

---

## 一、开关管损耗 $P_Q$

### 1.1 导通损耗

$$P_{Q\_cond}=I_{Q\_rms}^2\cdot R_{DS(on)} \quad \text{(7.13-2)}$$

> 注意 $R_{DS(on)}$ 随结温升高而增大（硅管 100°C 时约为标称值的 1.4~1.7 倍），估算时建议乘 1.5 的温度系数。

### 1.2 开关损耗（硬开关）

开/关过程中 $V_{DS}$ 与 $I_D$ 交叠，近似为：

$$P_{Q\_sw}=\frac{1}{2}V_{DS}\cdot I_D\cdot(t_r+t_f)\cdot f \quad \text{(7.13-3)}$$

- $V_{DS}=U_{in}+U_{or}$ （关断平台电压）
- $t_r/t_f$ ：电流上升/下降时间（数据手册给定测试条件下的值，实际随驱动电阻变化）
- DCM 下开通为零电流，**开通损耗≈0，只剩关断损耗**： $P_{Q\_sw}\approx\frac12 V_{DS}I_{Lmp}t_f f$

> 准谐振谷底开通时，式(7.13-3) 需按实际谷底电压修正（见[7](7.10-有源钳位与准谐振反激.md)）。

### 1.3 驱动损耗

$$P_{g}=Q_g\cdot V_{gs}\cdot f \quad \text{(7.13-4)}$$

（ $Q_g$ 为栅极总电荷，通常很小，60W 级别约 10~50mW。）

---

## 二、副边二极管损耗 $P_D$

$$P_D=V_F\cdot I_o \quad \text{(7.13-5)}$$

> 用同步整流时换为 $P_{SR}=I_{S\_rms}^2R_{DS(on)}$ （[7](7.11-同步整流反激.md)），并加上其驱动损耗。

---

## 三、铜损 $P_{Cu}$

$$P_{Cu}=I_{P\_rms}^2\cdot R_{dc,P}+I_{S\_rms}^2\cdot R_{dc,S} \quad \text{(7.13-6)}$$

- $R_{dc}$ 为绕组直流电阻；高频下需考虑**趋肤/邻近效应**（用多股线或多层细线绕制），详见磁元件章节

---

## 四、磁芯损耗 $P_{core}$

工程上用 **Steinmetz 经验公式**（参数由磁芯厂商提供）：

$$P_{core}=k\cdot f^{\alpha}\cdot B_{pk}^{\beta}\cdot V_e \quad \text{(7.13-7)}$$

- $B_{pk}$ ：峰值磁密（DCM 下 $B_{pk}=\Delta B/2$ ，与电流纹波相关）
- 典型参数：铁氧体 $\alpha\approx1.2\sim1.5$ 、 $\beta\approx2.2\sim2.7$
- 完整计算见磁元件设计章节

---

## 五、RCD钳位损耗 $P_{RCD}$

每个周期漏感储存的能量全部耗在钳位电阻上：

$$P_{RCD}=\frac{1}{2}L_k\cdot i_{Lmp}^2\cdot f \quad \text{(7.13-8)}$$

> **推导：** Q 关断瞬间漏感电流 $=i_{Lmp}$ （漏感与励磁电感串联），储能 $\frac12 L_k i_{Lmp}^2$ ；它无法耦合到副边，全部经钳位回路在 R 上耗散，每秒 $f$ 次。
>
> 例： $L_k=2\mu H$ 、 $i_{Lmp}=3A$ 、 $f=65kHz$ → $P_{RCD}=0.5\times2\mu\times9\times65k=0.585W$——**这就是 60W 时 RCD 白烧的功率**（约 1% 效率）。

---

## 六、其他损耗 $P_{other}$

| 项目 | 典型量级 |
|---|---|
| 母线电容 ESR 损耗 | 随纹波电流，一般 <0.2W |
| 启动电阻 | 若有则需算（ $U^2/R$ ，很多方案用高压启动电路省掉） |
| 控制 IC 及其供电 | 0.2~0.5W |
| 吸收回路（若另有 RC 吸收） | 视设计 |

---

## 七、效率预算表模板

| 损耗项 | 公式 | 满载值（示例占位） |
|---|---|---|
| $P_{Q\_cond}$ | $I_{Q\_rms}^2R_{DS}$×1.5 | |
| $P_{Q\_sw}$ | $\frac12V_{DS}I(t_r+t_f)f$ | |
| $P_D$ / $P_{SR}$ | $V_FI_o$ / $I_{S\_rms}^2R_{DS}$ | |
| $P_{Cu}$ | $I_{P}^2R_P+I_S^2R_S$ | |
| $P_{core}$ | Steinmetz 式 | |
| $P_{RCD}$ | $\frac12L_ki_{Lmp}^2f$ | |
| $P_{other}$ | 控制/ESR/启动 | |
| **合计** | — | $\eta=\dfrac{P_o}{P_o+\sum P}$ |

> **经验占比（60W 级离线反激）：** 开关管总损耗与副边整流损耗往往各占 3~5%，RCD 约 1%，铜损+磁损约 1~2%，控制类约 0.5~1%。RCD 反激总效率 80~85%，符合[7.7 节](7.7-RCD参数计算.md)的结论。

---

## 八、本节小结

| 主题 | 核心结论 |
|---|---|
| 开关管 | 导通 $I^2R_{DS}$ （×1.5 温度系数）+ 开关 $\frac12VI(t_r+t_f)f$ + 驱动 |
| 二极管 | $V_FI_o$ ；SR 换 $I_{rms}^2R_{DS}$ |
| 铜损 | 原副边 $I_{rms}^2R_{dc}$ ，注意趋肤效应 |
| 磁芯 | Steinmetz： $k f^\alpha B^\beta V_e$ |
| RCD | $P_{RCD}=\frac12L_ki_{Lmp}^2f$ （每周期漏感能量全烧掉） |
| 预算表 | 六项加总 → $\eta=P_o/(P_o+P_{loss})$ |
