# 第七章 反激变换器 第十节：有源钳位与准谐振反激

[7.6 节](7.6-RCD参数计算.md)指出：RCD 是耗能型钳位，效率通常到不了 85%。本节介绍两种把效率做到 **90%+** 的反激变形——**有源钳位反激（ACF）**与**准谐振反激（QR）**。二者是目前手机/笔记本充电器的主力拓扑。

> 本节只讲**工作机理与选型要点**，谐振过程的详细分析将在谐振变换器章节展开。

---

## 一、有源钳位反激（Active Clamp Flyback）

### 1.1 拓扑变化

把 RCD 中的**电阻 R 换成辅助开关管 $Q_2$**（钳位电容 $C_c$ 保留、钳位二极管由 $Q_2$ 的体二极管兼任）：

- $Q_1$ ：主管
- $Q_2$ ：辅助管（钳位管），小电流即可
- $C_c$ ：钳位电容

### 1.2 工作过程（每周期四段）

| 阶段 | 状态 | 能量去向 |
|---|---|---|
| ① 储能 | $Q_1$ 导通， $L_m$ 储能 | — |
| ② 钳位 | $Q_1$ 关断，漏感能量经 $Q_2$ **体二极管**充入 $C_c$ | 漏感 → $C_c$ （此时与 RCD 相同） |
| ③ 回馈+谐振 | **$Q_2$ 主动开通**， $C_c$ 与漏感 $L_k$ 谐振半周期 | **$C_c$ 的能量送回电源**，而不是烧掉 |
| ④ 换向 | $Q_2$ 关断，利用谐振电流方向实现 $Q_1$ 的 ZVS | — |

### 1.3 与 RCD 的本质区别

| | RCD（无源钳位） | 有源钳位 |
|---|---|---|
| 漏感能量 | 在 R 上**烧掉** | **回馈电源**，下次再用 |
| 软开关 | 无 | $Q_1$ 、 $Q_2$ 均可实现 **ZVS** |
| 效率 | ~85% 以下 | **90%+**（提高 10 个点很容易） |
| 成本/复杂度 | 最低 | 多一路驱动 + 控制，复杂得多 |

> 有源钳位"一箭双雕"：既解决漏感尖峰，又利用谐振把开关损耗降到接近零。

## 二、准谐振反激（QR Flyback）

### 2.1 思路：谷底开通（Valley Switching）

**前提：工作在 DCM**。DCM 下副边电流放到零之后，出现一个**空档期**——此时 $L_m$ （+$L_k$ ）与开关管输出电容 $C_{oss}$ 构成**自由振荡回路**， $u_{DS}$ 以固有频率做衰减正弦振荡。

准谐振的控制就是：**检测 $u_{DS}$ 的第一个（或第 n 个）谷底，在谷底开通 $Q_1$**。

### 2.2 为什么谷底开通省损耗

开关管开通瞬间的开关损耗 $\propto V_{DS}\times I$ ：

- **硬开通**： $V_{DS}=U_{in}+U_{or}$ （高），损耗大
- **谷底开通**： $V_{DS}$ 已振荡到**最低点**（可远低于 $U_{in}+U_{or}$ ），损耗大幅下降

> 谷底电压越低、开通越"软"，通常取**第一个谷底**（振到最低）；重载时振荡少，也常取第 2、3 个谷底。

### 2.3 实现方式

- **检测**：辅助绕组感应开关节点电压，过零比较器判断谷底
- **控制**：变频控制——**负载越轻，空档期越长，谷底来得越晚 → 开关频率自动降低**（轻载低频率 → 轻载效率高）

### 2.4 特点

| 项目 | 说明 |
|---|---|
| 效率 | 90%+（靠软开通 + 轻载降频） |
| 频率 | **变频**（负载变化时频率变化），EMI 设计需按频率范围处理 |
| 工作模式 | 必须 DCM（才有振荡空档） |
| 复杂度 | 比 RCD 反激高一点（谷底检测），比有源钳位简单 |

## 三、三种反激对比

| 项目 | RCD 反激 | 有源钳位反激 | 准谐振反激 |
|---|---|---|---|
| 漏感能量 | 烧掉（R） | 回馈电源 | 软开通利用 |
| 软开关 | 无 | ZVS（两管） | 准 ZVS（谷底开通） |
| 典型效率 | <85% | 90%+ | 90%+ |
| 频率 | 定频 | 定频 | **变频** |
| 元件/成本 | 最少 | 多管+驱动 | 中等 |
| 控制复杂度 | 最低 | 高 | 中等 |
| 典型应用 | 辅源、低成本小功率 | 大功率反激、宽范围高效 | **手机/笔记本充电器** |

> **一句话选择：** 追求极简可靠 → RCD；追求效率与功率密度 → 有源钳位或准谐振（多数充电器选 QR，因为结构简单且天然轻载高效）。

---

## 四、本节小结

| 主题 | 核心结论 |
|---|---|
| 有源钳位 | R 换成辅助管 $Q_2$ ：漏感能量回馈电源 + 双管 ZVS |
| 准谐振 | DCM 空档期 $L_m$ 与 $C_{oss}$ 振荡，**谷底开通**降低开通损耗 |
| QR 控制 | 辅助绕组检测谷底，**变频控制**，轻载自动降频 |
| 效率 | 两者均 90%+，远高于 RCD |
| 定位 | 谐振细节与软开关理论见谐振变换器章节 |
