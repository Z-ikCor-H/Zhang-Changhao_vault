# 第七章 反激变换器 第八节：稳态电流应力与电容选型

前面各节完成了拓扑、增益、励磁电感与 RCD 的设计。本节补齐**器件选型所需的电流数据**：**开关管、副边二极管、变压器原/副边绕组、输入/输出电容各流过多少电流（平均值 / 有效值 / 峰值）？** 全部由前三章的方法推导——梯形波有效值 + 占比缩放 + 正交分解。

> 本节的推导框架与 [Boost 4.4](../../02.Boost/4.4-电流有效值计算.md)、[Buck-Boost 5.4](../../03.Buck-Boost/5.4-CCM电流分析.md) 完全一致，只是把"电感电流"换成"励磁电流"、并多一道**匝比折算**。

---

## 一、符号约定与波形

| 符号 | 含义 |
|---|---|
| $n=N_P/N_S$ | 变压器匝比 |
| $i_{Lmp}$ / $i_{Lmv}$ | 原边励磁电流**峰值** / **谷值**（CCM） |
| $\Delta i_{Lm}=i_{Lmp}-i_{Lmv}$ | 励磁电流纹波 |
| $I_{Lm}=\dfrac{I_o}{n(1-D)}$ | 励磁电流平均值（折算到原边，7.2节） |
| $\tau=\Delta i_{Lm}/I_{Lm}$ | 电流纹波率（定义在原边） |

- **CCM**：原边电流 $i_P$ 在 $DT$ 内为**梯形**（ $i_{Lmv}\to i_{Lmp}$ ）；副边电流 $i_S$ 在 $(1-D)T$ 内为**梯形**（ $n\,i_{Lmp}\to n\,i_{Lmv}$ ）
- **DCM**：两者都退化为**三角形**（从零开始）

> **安匝平衡决定副边初始电流：** Q 关断瞬间，原边电流 $i_{Lmp}$ 消失、副边电流出现，且 $N_P i_{Lmp}=N_S i_{D\_pk}$ → **副边初始电流 $=n\cdot i_{Lmp}$**（本质是磁通守恒）。

---

## 二、CCM下的电流应力

### 2.1 两个"锚点"平均值

- **副边平均值 = 负载电流**（负载电流只能经二极管）：

$$I_o=(1-D)\cdot\frac{n(i_{Lmp}+i_{Lmv})}{2} \quad \text{(7.8-1)}$$

- **原边平均值 = 输入电流**（考虑效率 $\eta$ ）：

$$I_{Q\_avg}=I_{in}=\frac{P_o}{\eta U_{in}}=\frac{I_oD}{\eta\,n(1-D)} \quad \text{(7.8-2)}$$

### 2.2 峰值 / 谷值用 $\tau$ 表示

$$\boxed{i_{Lmv}=I_{Lm}\left(1-\frac{\tau}{2}\right),\qquad i_{Lmp}=I_{Lm}\left(1+\frac{\tau}{2}\right),\qquad I_{Lm}=\frac{I_o}{n(1-D)}} \quad \text{(7.8-3)}$$

### 2.3 开关管 / 原边绕组

梯形波有效值公式（[5.9节](../../03.Buck-Boost/5.9-DCM电流分析.md)）：对最低 $a$ 、最高 $b$ 、占比 $\delta$ 的梯形波

$$I_{rms}=\sqrt{\delta}\sqrt{\frac{a^2+b^2+ab}{3}} \quad \text{(7.8-4)}$$

开关管电流就是原边电流（占比 $D$ ，谷 $i_{Lmv}$ 、峰 $i_{Lmp}$ ）：

$$I_{Q\_rms}=I_{P\_rms}=\sqrt{D}\sqrt{\frac{i_{Lmv}^2+i_{Lmp}^2+i_{Lmv}i_{Lmp}}{3}}$$

把式(7.8-3)代入，展开平方项：

$$i_{Lmv}^2+i_{Lmp}^2+i_{Lmv}i_{Lmp}=I_{Lm}^2\left[\left(1-\tfrac{\tau}{2}\right)^2+\left(1+\tfrac{\tau}{2}\right)^2+\left(1-\tfrac{\tau}{2}\right)\left(1+\tfrac{\tau}{2}\right)\right]=I_{Lm}^2\left(3+\frac{\tau^2}{4}\right)$$

$$\boxed{I_{Q\_rms}=I_{P\_rms}=\frac{I_o}{n(1-D)}\sqrt{D\left(1+\frac{\tau^2}{12}\right)}} \quad \text{(7.8-5)}$$

> 与 Buck-Boost 的开关管 RMS 同构，只是多了一个 $1/n$ （电流折算到原边）。

### 2.4 副边二极管 / 副边绕组

副边电流是原边电流的 **$n$ 倍**、占比 **$(1-D)$**：

$$I_{D\_rms}=I_{S\_rms}=n\,I_{Lm}\sqrt{(1-D)\left(1+\frac{\tau^2}{12}\right)}$$

$$\boxed{I_{D\_rms}=I_{S\_rms}=\frac{I_o}{\sqrt{1-D}}\sqrt{1+\frac{\tau^2}{12}}} \quad \text{(7.8-6)}$$

> **注意： $n$ 消掉了**——因为 $I_{Lm}=I_o/[n(1-D)]$ 里已含 $1/n$ 。副边电流直接由 $I_o$ 和 $D$ 决定，与匝比无关（合理：副边就在输出回路里）。

副边二极管平均值：

$$I_{D\_avg}=I_o \quad \text{(7.8-7)}$$

### 2.5 输出电容

与 Boost 输出电容的处境完全一样（二极管 → 负载 / 电容）：平均值 $I_o$ 进负载，交流分量进电容：

$$I_{Co\_rms}^2=I_{D\_rms}^2-I_o^2$$

$$\boxed{I_{Co\_rms}=I_o\sqrt{\frac{1+\tau^2/12}{1-D}-1}=I_o\sqrt{\frac{D+\tau^2/12}{1-D}}} \quad \text{(7.8-8)}$$

> 与 [Boost 输出电容式(4.4-11)](../../02.Boost/4.4-电流有效值计算.md)**完全相同**——因为反激的副边在拓扑位置上就是 Boost 的输出端。

### 2.6 输入电容（母线电容）

开关管电流的交流分量由输入电容提供：

$$I_{Cin\_rms}=\sqrt{I_{Q\_rms}^2-I_{in}^2} \quad \text{(7.8-9)}$$

> 离线反激的输入电容还有**母线电容（bulk capacitor）**的角色，其容量往往不由纹波电流、而由**整流纹波与保持时间**决定，见四、离线式母线电容。

## 三、DCM下的电流应力

DCM 下 $i_{Lmv}=0$ ，波形全部退化为三角形。由 $I_o=\frac12D_1\cdot n\,i_{Lmp}$ （副边平均值）：

$$i_{Lmp}=\frac{2I_o}{nD_1},\qquad D_1=\frac{1}{n}\sqrt{\frac{2L_P}{R_oT}}\ (\text{[7.3节](7.3-反激DCM工作过程与增益.md)}) \quad \text{(7.8-10)}$$

| 元件 | 平均值 | 有效值 |
|---|---|---|
| 开关管 Q / 原边绕组 | $I_{in}=\dfrac12 D\,i_{Lmp}=\dfrac{MI_o}{\eta}$ | $i_{Lmp}\sqrt{\dfrac{D}{3}}=\dfrac{2I_o}{nD_1}\sqrt{\dfrac{D}{3}}$ |
| 二极管 D / 副边绕组 | $I_o$ | $n\,i_{Lmp}\sqrt{\dfrac{D_1}{3}}=\dfrac{2I_o}{\sqrt{3D_1}}$ |
| 输出电容 $C_o$ | 0 | $I_o\sqrt{\dfrac{4}{3D_1}-1}$ |
| 输入电容 $C_{in}$ | 0 | $\sqrt{I_{Q\_rms}^2-I_{in}^2}$ |

> **规律：** DCM 下所有电流都可由 **$I_o$ 和 $D_1$** 表示，无需 $D$ 、 $n$ （它们通过 $i_{Lmp}$ 和 $M$ 隐含）。这与 DCM 增益与匝比无关的结论一脉相承。

---

## 四、离线式母线电容

离线反激（AC 输入）在整流桥后有一只大电容 $C_{bulk}$ ，它的选型与拓扑内的"输入电容"是两件事：

### 4.1 保持时间（Hold-up Time）

掉电后， $C_{bulk}$ 上储存的能量要维持变换器继续工作 $t_{hold}$ （典型 **10~20ms**，取决于安规/客户要求）：

$$\frac12 C_{bulk}\left(U_{bulk\_max}^2-U_{bulk\_min}^2\right)=\frac{P_o}{\eta}\cdot t_{hold}$$

$$\boxed{C_{bulk}=\frac{2P_o\,t_{hold}}{\eta\left(U_{bulk\_max}^2-U_{bulk\_min}^2\right)}} \quad \text{(7.8-11)}$$

- $U_{bulk\_max}$ ：输入电压峰值（85VAC 整流后最低谷约 90V；265VAC 峰值约 375V）
- $U_{bulk\_min}$ ：变换器仍能维持输出电压的**最低母线电压**（同时受 $D_{max}$ 限制）

> 通常按**最低交流输入**设计（此时母线谷值最低、放电最快）。

### 4.2 整流纹波经验值

若不要求保持时间，母线电容由整流纹波决定，工程经验值：

$$C_{bulk}\approx 1\sim3\ \mu\text{F/W} \quad \text{(7.8-12)}$$

> 60W 适配器一般取 **100~150μF/450V**；具体设计实例见 [7](7.14-设计实例.md)。

## 五、选型指导

| 器件 | 依据 |
|---|---|
| 开关管 Q | $I_{Q\_rms}$ （导通损耗）、 $i_{Lmp}$ （峰值/饱和）、 $u_{DS}=U_{in}+U_{or}+V_{spike}$ （耐压） |
| 副边二极管 | $I_{D\_avg}=I_o$ （平均发热）、 $n\,i_{Lmp}$ （峰值）、 $\dfrac{U_{in\_max}}{n}+U_o$ （反压） |
| 变压器原边绕组 | $I_{P\_rms}$ （线径/铜损）、 $i_{Lmp}$ （饱和校验） |
| 变压器副边绕组 | $I_{S\_rms}$ （线径/铜损） |
| 输出电容 | $I_{Co\_rms}$ （纹波发热）、 $\Delta U_o$ （纹波要求，见6.1 输出纹波电压） |
| 母线电容 | 保持时间式(7.8-11) / 经验值式(7.8-12) |

## 六、输出纹波电压

### 6.1 容值纹波（理想电容）

Q 导通期间（ $DT$ ），副边无电流， $C_o$ **单独以 $I_o$ 放电**：

$$\Delta U_o=\frac{I_o\cdot DT}{C_o}=\frac{I_oD}{C_of} \quad \text{(7.8-13)}$$

> 与 Boost、Buck-Boost 完全相同（副边在 $t_{on}$ 期间与输出断开）。DCM 下 $D$ 较小，但**副边电流峰值大**，ESR 纹波往往占主导。

### 6.2 ESR纹波（电解电容）

电容电流的峰值出现在副边电流最大值处：

$$\Delta U_{o(ESR)}=\left(n\,i_{Lmp}-I_o\right)\cdot ESR \quad \text{(7.8-14)}$$

CCM 下 $n\,i_{Lmp}=\dfrac{I_o}{1-D}\left(1+\dfrac{\tau}{2}\right)$ ，在 **$D_{max}$ （最低输入电压）** 时最大；DCM 下 $n\,i_{Lmp}=\dfrac{2I_o}{D_1}$ 。

> 低电压大电流输出（5V/12V）时 $n\,i_{Lmp}$ 可达数十安培，**ESR 纹波占绝对主导**——这就是现代充电器普遍采用**低 ESR 固态电容**甚至**同步整流**（见[7](7.11-同步整流反激.md)）的原因。

### 6.3 两种计算方法的互验

与 Boost 4.5 一样，用"关断时段"也可推得同一结果（二极管总电荷 − 负载消耗 = 电容净得电荷），结论仍是式(7.8-13)，此处从略。

## 七、本节小结

| 主题 | 核心结论 |
|---|---|
| 锚点 | $I_o=(1-D)\cdot n(i_{Lmp}+i_{Lmv})/2$ ； $I_{Q\_avg}=I_{in}=P_o/(\eta U_{in})$ |
| 梯形波有效值 | $\sqrt{\delta}\sqrt{(a^2+b^2+ab)/3}$ |
| 开关管/原边 RMS | $\dfrac{I_o}{n(1-D)}\sqrt{D(1+\tau^2/12)}$ |
| 二极管/副边 RMS | $\dfrac{I_o}{\sqrt{1-D}}\sqrt{1+\tau^2/12}$ （**与 $n$ 无关**） |
| 输出电容 RMS | $I_o\sqrt{(D+\tau^2/12)/(1-D)}$ ，与 Boost 输出电容完全相同 |
| DCM | 全部电流由 $I_o$ 、 $D_1$ 表示 |
| 输出纹波 | $\Delta U_o=\dfrac{I_oD}{C_of}$ ；ESR 项 $=(n\,i_{Lmp}-I_o)\cdot ESR$ ，低压大电流时占主导 |
| 母线电容 | $C_{bulk}=\dfrac{2P_ot_{hold}}{\eta(U_{max}^2-U_{min}^2)}$ ；无 hold-up 要求时经验 1~3μF/W |
