# 第七章 反激变换器 第一节：反激CCM工作过程

前面三个基本拓扑（[Buck](../../01.Buck/1.1-CCM工作过程.md)、[Boost](../../02.Boost/4.1-CCM工作过程.md)、[Buck-Boost](../../03.Buck-Boost/5.1-CCM增益分析.md)）已经讲完。本章开始学习**反激（Flyback）变换器**——所有拓扑都是在三个基础拓扑上"堆叠演变"出来的，反激也不例外：**它是从 Buck-Boost 演变来的。** 本节先看这条演变路径，再分析 CCM 工作过程，并用伏秒平衡推出增益。

---

## 一、从Buck-Boost到反激的演变

<img src="照片引用/7.1-1%20Buck-Boost拓扑图.png" width="440">

这是上一章学过的 **Buck-Boost** 拓扑。

<img src="照片引用/7.1-2%20Flyback推演-1.png" width="470">

**第一步：在电感位置串入一个变压器。** 把变压器拆成两部分看：**励磁电感 $L_m$**（画在左边）+ **理想变压器 $T$**（打点端表示同名端）。

这个电路**仍然可以工作**，而且工作方式与 Buck-Boost **完全一样**：

- Q 开通时： $L_m$ 储能，副边二极管承受反压而截止（原边打点端为正 → 副边打点端也为正 → 二极管阴极正、阳极负）
- Q 关断时：极性反转，副边打点端变正 → 二极管导通，能量送出

> **关键认识：** 反激的"变压器"原副边**不同时导通**——这与传统变压器完全不同（详见[下一节](7.2-等效变换与BCM工作过程.md)）。

<img src="照片引用/7.1-3%20Flyback推演-2.png" width="470">

**第二步：既然有了励磁电感 $L_m$ ，原来的电感 $L$ 就是多余的了**——去掉它， $L_m$ 直接充当储能电感。同时把开关管挪到下方（在上面还是下面，本质是同一条回路，没有区别）。

<img src="照片引用/7.1-4%20Flyback推演-3.png" width="470">

**第三步：把副边"拧180°"。** 原副边本是一条回路的上下两端，把副边绕组旋转 180°，同名端就从下端变成了上端，二极管也随之翻到了上面。

这一步之后，得到的就已经是**常见的反激拓扑形式**了。

<img src="照片引用/7.1-5%20反激拓扑.png" width="440">

**第四步：整理成标准画法。** 定义：

- 原边绕组 $N_P$ 、副边绕组 $N_S$
- **匝比** $n = N_P/N_S$
- **打点端是变压器的同名端**（未打点端也是同名端）

> **结论：反激就是从 Buck-Boost 变换器变换过来的。** Buck-Boost 是非隔离的；反激把电感换成变压器，原副边**没有直接联通**（也可以通过"加变压器"的方式理解成：这里故意不让它连通），所以反激是**隔离版本的 Buck-Boost**。

## 二、反激的地位与特点

反激可以说是应用最广的拓扑之一（排头一、二位没有问题）。

**优点：结构简单、成本低、可靠性高**

反激只需要三个元件就构成了完整拓扑：

| 元件 | 数量 |
|---|---|
| 开关管 | 1 个 |
| 二极管 | 1 个 |
| 磁元件（变压器） | 1 个 |

> **对比正激：** 正激同样是"一个开关管 + 一个二极管 + 一个变压器"，但**副边多一个滤波电感**，变压器还多一个**去磁绕组**，元件数量更多。

**器件越少 → 成本越低、可靠性越高**（器件越多，可靠性越低，这是普遍规律）。

**应用场合**

- **小功率领域（100W 以内）几乎由反激统治**：手机充电器、iPad 充电器、消费类电子适配器、LED 驱动、大功率电源中的辅助电源等
- **大功率也在扩展**：多路并联反激、交错并联反激，已有公司将多路并联反激做到 **60kW 交流充电桩**
  > 但大功率场合用的不是传统反激，而是**有源钳位反激**或**准谐振反激**（详见[第七节](7.7-RCD参数计算.md)），整体结构依然是反激拓扑。

## 三、CCM工作过程

反激**只有一个开关管**，所以只有两种状态。

<img src="照片引用/7.1-6%20t_on时电路状态.png" width="440">

### 3.1 状态一：Q导通（ $t_{on}$ ）——变压器储能阶段

- 原边电压：上正下负
- 副边同名端（打点端）也是正电位 → 副边二极管**承受反向电压而截止** → **副边没有电流**（ $i_D=0$ ）
- 输入电压 $U_{in}$ **全部加在原边**上
- 原边有励磁电感 $L_m$ ，由电感方程 $U_{in}=L_m\dfrac{di_{Lm}}{dt}$ ：

$$\frac{di_{Lm}}{dt}=\frac{U_{in}}{L_m} \quad\Rightarrow\quad i_{Lm} \text{ 从 } i_{L1} \text{ 线性上升}$$

- 副边不输出能量 → **能量全部储存在变压器中**： $E=\dfrac{1}{2}L_m i_{Lm}^2$ ，电流在增大 → 储能在增加

> **此阶段是变压器储能阶段。**

<img src="照片引用/7.1-7%20t_on时电压电流波形图.png" width="440">

### 3.2 状态二：Q关断（ $t_{off}$ ）——变压器放能阶段

<img src="照片引用/7.1-8%20t_off时电路状态.png" width="440">

Q 关断后，原边通路断开。**两种理解方式：**

1. **极性反转法：** Q 关断后原边电压极性改变（开关管承受正电位），原边变负、副边同名端变正 → 副边二极管承受正向电压而导通
2. **能量守恒法：** 电感电流不能突变。Q 关断后原边电流没有通路，原先存储的能量"没地方去"，只能通过副边绕组、经二极管释放出去

- 副边电压为 $U_o$ ，**折算（折射）到原边**为 $n\cdot U_o$
- 励磁电流**线性下降**，斜率为 $\dfrac{n\cdot U_o}{L_m}$
- 副边二极管电流也线性下降，斜率为 $\dfrac{U_o}{L_S}$ （ $L_S$ 为副边电感）

> **注意：** 实际电路中在原边是**测不到**这个下降电流的，电流是在**副边侧**下降的。图中画的"原边励磁电流下降段"是把副边电流按匝比**折算回原边**得到的，这样励磁电流才是一个完整的三角波。
>
> 反激的励磁电流"上去了还要回来"，这一点与基础拓扑中"电感电流不能突变、上去还要下来"是同样的道理——本质是**变压器必须退磁**（磁通守恒），详见磁元件课程。

<img src="照片引用/7.1-9%20t_off时电压电流波形图.png" width="440">

**关断期间的电压应力**

- **开关管承受电压**（对原边回路用 KVL）：原边反射电压 + 电源电压

$$u_{DS}=U_{in}+n\cdot U_o \quad \text{(7.1-1)}$$

- **副边二极管承受反压**（在 $t_{on}$ 期间）：

$$u_D=\frac{U_{in}}{n}+U_o \quad \text{(7.1-2)}$$

### 3.3 CCM模式定义

<img src="照片引用/7.1-10%20波形分析.png" width="440">

**CCM（连续导通模式）：** 原边开关管再次开通时，副边电流**还没有降到零**——也就是说能量**没有完全释放完**（副边还储存着 $\frac{1}{2}L_Si_{LS}^2$ ）。此时变压器磁通未复位到零，即为 CCM。

## 四、CCM增益（伏秒平衡）

对变压器（也可看作对励磁电感 $L_m$ ）使用[伏秒平衡](../../01.Buck/1.2-伏秒平衡.md)——其本质是**磁通守恒**：

$$U_{in}\cdot DT = n\cdot U_o\cdot(1-D)T \quad \text{(7.1-3)}$$

> **易错点：关断阶段的电压必须折算回原边！** 不能用副边的 $U_o$ 直接代入——那样就错了。必须先把副边电压按匝比折射到原边，变成 $n\cdot U_o$ ，才能与原边的伏秒积作比较（两边要用**同一个绕组**的电压）。

约去 $T$ ，整理得反激的 CCM 增益：

$$\boxed{\frac{U_o}{U_{in}} = \frac{1}{n}\cdot\frac{D}{1-D}} \quad \text{(7.1-4)}$$

### 4.1 与Buck-Boost的对照——又一次验证演变关系

把匝比 $n$ 移到等式左边：

$$n\cdot\frac{U_o}{U_{in}}=\frac{D}{1-D} \quad\Longleftrightarrow\quad \frac{n\cdot U_o}{U_{in}}=\frac{D}{1-D}$$

右边正是 **Buck-Boost 在 CCM 下的增益**。也就是说：

> **反激可以看成一个"输出电压为 $n\cdot U_o$ 、输入电压为 $U_{in}$"的 Buck-Boost 拓扑**——把副边数据折算到原边（ $n\cdot U_o$ ），就完全对应上了。这是对第一节演变关系的又一次验证。

由此引入一个重要概念——**反射电压（折射电压）**：

$$\boxed{U_{or} = n\cdot U_o} \quad \text{(7.1-5)}$$

> 反射电压定义为**输出对原边的反射电压**（把副边数据电压折算到原边），它会影响**变压器匝比的选择**，后续会详细用到。

## 五、本节小结

| 主题        | 核心结论                                                                                     |
| --------- | ---------------------------------------------------------------------------------------- |
| 演变来源      | 反激 = 把 Buck-Boost 的电感换成变压器 → **隔离版 Buck-Boost**                                          |
| 演变步骤      | ①串入变压器 ②去掉多余电感、挪开关管 ③副边"拧180°" ④整理成标准画法                                                  |
| 器件数量      | 1 开关管 + 1 二极管 + 1 变压器（比正激少滤波电感和去磁绕组）                                                     |
| 优势        | 结构简单、成本低、可靠性高；100W 内几乎统治                                                                 |
| $t_{on}$  | $L_m$ 储能，副边二极管反偏截止， $i_{Lm}$ 斜率 $U_{in}/L_m$                                              |
| $t_{off}$ | 极性反转/能量找出口，副边二极管导通， $i_{Lm}$ 斜率 $nU_o/L_m$                                                |
| 电压应力      | $u_{DS}=U_{in}+nU_o$ ； $u_D=\dfrac{U_{in}}{n}+U_o$                                         |
| CCM 增益    | $\dfrac{U_o}{U_{in}}=\dfrac{1}{n}\cdot\dfrac{D}{1-D}$ ；等价于 $nU_o$ 对 $U_{in}$ 的 Buck-Boost |
| 反射电压      | $U_{or}=n\cdot U_o$ ，影响匝比选择                                                               |
