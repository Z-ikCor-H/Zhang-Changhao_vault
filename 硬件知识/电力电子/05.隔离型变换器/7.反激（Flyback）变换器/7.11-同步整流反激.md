# 第七章 反激变换器 第十一节：同步整流反激

[上一节](7.10-有源钳位与准谐振反激.md)在原边做文章（钳位/软开关）提效率；本节在**副边**做文章——把副边整流二极管换成 **MOS 管（同步整流，SR）**。这是**低压大电流输出**（5V、12V）反激的标配，与 [Buck 的同步整流](../../01.Buck/3.5-同步Buck.md)一脉相承。

---

## 一、为什么低压大电流非用 SR 不可

副边二极管损耗：

$$P_D=V_F\cdot I_o \quad \text{(7.11-1)}$$

SR 管损耗：

$$P_{SR}=I_{S\_rms}^2\cdot R_{DS(on)} \quad \text{(7.11-2)}$$

**数值感受（ $I_o=10A$ ）：**

| 方案 | 参数 | 损耗 |
|---|---|---|
| 肖特基二极管 | $V_F=0.4V$ | $0.4\times10=4\text{W}$ |
| SR MOS 管 | $R_{DS(on)}=10\text{m}\Omega$ | $\approx10^2\times0.01=1\text{W}$ |

> **$I_o$ 越大，SR 优势越大**。对 12V/5A 输出，二极管损耗占输出功率的 4% 左右；对 5V 输出更甚——不用 SR 几乎不可能做出高效率充电器。
>
> **SR 管的电压应力只有二极管的一半思路：** 注意副边位置电压不高（12V 输出侧约 60~100V），可选低压大电流 MOS， $R_{DS(on)}$ 可低至几 mΩ。

---

## 二、SR管的工作时序

SR 管与主管**互补导通**：

| 阶段 | 主管 $Q_1$ | SR 管 $Q_2$ |
|---|---|---|
| $t_{on}$ （储能） | 导通 | **截止**（体二极管反偏） |
| $t_{off}$ （释能） | 截止 | **导通**（电流从源极流向漏极，即"反向"导通） |

- SR 管导通时电流沿 **S→D**（对 MOS 而言是反向），利用的是**沟道双向导电**特性
- 若 $Q_2$ 不导通，其**体二极管**会自动续流（像普通二极管整流一样）——所以 SR 失效时电路仍能工作，只是效率骤降

---

## 三、核心难点：何时关断

CCM 下 $Q_2$ 的导通时间固定为 $(1-D)T$ ，时序简单。但 **DCM 下是难点**：

- 副边电流会在周期内**降到零**
- 若 $Q_2$ 在电流过零后**仍开通** → 输出电容通过 $Q_2$ **反向放电**（能量倒灌回变压器）→ 效率暴跌、甚至异常振荡
- 所以 SR 必须在**电流到零前（或恰在到零时）及时关断**

### 3.1 关断检测方法

| 方法 | 原理 | 特点 |
|---|---|---|
| **V_DS 检测** | 检测 SR 管两端压降：电流减小 → $V_{DS}$ 减小 → 低于阈值（如 −10mV 附近）时关断 | 最常用，专用 SR 控制器（如 MP6908 等）内置 |
| 辅助绕组预测 | 用变压器辅助绕组电压波形推算过零点 | 少用 |
| 定时关断 | 固定导通时间（仅 CCM 适用） | 简单但 DCM 不适用 |

> **工程要点：** 关断阈值要留余量，避免"关得太晚"导致倒灌；也不能"关得太早"——过早关断时电流只能走体二极管（压降大），SR 的意义就没了。这个窗口通常只有几十到几百 ns。

### 3.2 与同步 Buck 的对比

|       | [同步 Buck](../../01.Buck/3.5-同步Buck.md)         | 同步整流反激 |
| ----- | ---------------------- | ----------------- | ------ |
| 电流连续性 | 电感连输出，电流**天然连续**（FCCM） | 副边电流**可能断续**（DCM） |        |
| 难点    | 死区防直通                  | **DCM 过零关断时机**    |        |
| 反向电流  | FCCM 下允许（故意）           | **不允许**（倒灌）       |        |

> Buck 的 SR 是"让电流反向以实现 ZVS"；反激的 SR 是"绝不能让电流反向"——两者对反向电流的态度**正好相反**，注意区分。

---

## 四、SR 的附加好处

1. **体二极管压降小**：低压 MOS 体二极管优于高压肖特基？——不，体二极管压降一般更大；真正的收益在**沟道导通**期间
2. **反向恢复**：体二极管仍有反向恢复，但 SR 控制器让它尽量少"抢活"，恢复电荷远小于大功率二极管
3. **散热**：损耗分散、温升低，利于高功率密度设计

---

## 五、本节小结

| 主题 | 核心结论 |
|---|---|
| 动机 | 低压大电流输出： $V_FI_o$ 损耗不可接受 → 用 $I_{rms}^2R_{DS(on)}$ |
| 时序 | SR 与主管互补；沟道反向（S→D）导通 |
| 失效模式 | SR 不开通时体二极管自动续流（仍能工作、效率降） |
| 核心难点 | **DCM 下电流过零必须及时关断**，防输出电容倒灌 |
| 检测 | V_DS 检测最常用（专用 SR 控制器） |
| 与同步 Buck 区别 | Buck 允许反向（ZVS）；反激**禁止**反向 |
| 应用 | 5V/12V 充电器、适配器的标配 |
