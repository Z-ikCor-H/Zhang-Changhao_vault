## 二、CCM 速查

### 2.1 增益与基本关系

| 量 | 公式 |
|---|---|
| CCM 增益 | $\dfrac{U_o}{U_{in}}=\dfrac{1}{n}\cdot\dfrac{D}{1-D}$ |
| 反射电压 | $U_{or}=nU_o$ |
| 占空比 | $D=\dfrac{U_{or}}{U_{in}+U_{or}}$ |
| 励磁电流平均值 | $I_{Lm}=\dfrac{I_o}{n(1-D)}$ |
| 纹波率 | $\tau=\dfrac{\Delta i_{Lm}}{I_{Lm}}$ （CCM 取 0.4~1.4） |
| 谷值 / 峰值 | $i_{Lmv}=I_{Lm}(1-\tau/2)$ ， $i_{Lmp}=I_{Lm}(1+\tau/2)$ |

### 2.2 电压应力

| 器件 | 公式 |
|---|---|
| 开关管 | $u_{DS}=U_{in}+U_{or}$ （+RCD 钳位余量） |
| 副边二极管 | $u_D=\dfrac{U_{in}}{n}+U_o$ |

### 2.3 电流应力（7.8 节）

| 元件 | 平均值 | 有效值 |
|---|---|---|
| 开关管/原边绕组 | $\dfrac{I_oD}{n(1-D)}=I_{in}$ | $\dfrac{I_o}{n(1-D)}\sqrt{D(1+\tau^2/12)}$ |
| 二极管/副边绕组 | $I_o$ | $\dfrac{I_o}{\sqrt{1-D}}\sqrt{1+\tau^2/12}$ |
| 输出电容 | 0 | $I_o\sqrt{\dfrac{D+\tau^2/12}{1-D}}$ |
| 输入电容 | 0 | $\sqrt{I_{Q\_rms}^2-I_{in}^2}$ |

### 2.4 励磁电感（7.4 节）

$$L_m=\frac{\eta U_{in\_min}^2D_{max}^2}{\tau fP_o},\qquad D_{max}\le0.45\sim0.5$$

## 三、DCM 速查

| 量 | 公式 |
|---|---|
| DCM 增益 | $M=\dfrac{U_o}{U_{in}}=D\sqrt{\dfrac{R_oT}{2L_P}}$ （**与 $n$ 无关**） |
| $D_1$ | $D_1=\dfrac{D\cdot U_{in}}{nU_o}=\dfrac{1}{n}\sqrt{\dfrac{2L_P}{R_oT}}$ （伏秒平衡式 / 理想能量式） |
| 峰值电流 | $i_{Lmp}=\dfrac{U_{in}DT}{L_P}=\dfrac{2I_o}{nD_1}$ （**与输入电压无关**） |
| 励磁电感 | $L_m=\dfrac{\eta U_{in}^2D^2}{2fP_o}$ （即 CCM 式取 $\tau=2$ ） |
| 开关管 RMS | $i_{Lmp}\sqrt{D/3}$ |
| 二极管 RMS | $n\,i_{Lmp}\sqrt{D_1/3}=\dfrac{2I_o}{\sqrt{3D_1}}$ |
| 输出电容 RMS | $I_o\sqrt{4/(3D_1)-1}$ |
| 输出纹波 | $\Delta U_o=\dfrac{I_oD}{C_of}$ ；ESR 项 $(n\,i_{Lmp}-I_o)\cdot ESR$ |
| 全程 DCM 条件 | $L_m<L_{m\_crit}$ 最小值（最低输入处） |

---

## 四、临界条件（7.2 节）

| 量 | 公式 |
|---|---|
| 临界电阻 | $R_{crit}=\dfrac{2L_m}{n^2(1-D)^2T}$ |
| 临界励磁电感 | $L_{m\_crit}=\dfrac{n^2R_o(1-D)^2T}{2}$ |
| 模式判据 | $R_o>R_{crit}$ 或 $L_m<L_{m\_crit}$ → DCM； $\tau=2$ → BCM |

---

## 五、RCD 速查（7.7 节）

| 量 | 公式 |
|---|---|
| 电压上限 | $u_{C\_max}=0.8V_{DS(\text{额定})}-U_{in\_max}$ |
| 电压下限 | $u_{C\_min}=U_{or}=nU_o$ |
| 钳位电容 | $C=\dfrac{L_k i_{Lmp}^2}{u_{C\_max}^2-u_{C\_min}^2}$ （经验 1~10nF） |
| 钳位电阻 | $R=\dfrac{1}{fC\ln(u_{C\_max}/u_{C\_min})}$ |
| 钳位损耗 | $P_{RCD}=\dfrac12L_ki_{Lmp}^2f$ |

## 六、效率估算（7.13 节）

$$P_{loss}=\underbrace{I_{Q}^2R_{DS}\times1.5+\tfrac12V_{DS}I(t_r+t_f)f}_{开关管}+\underbrace{V_FI_o\ \text{或}\ I_S^2R_{DS}}_{整流}+\underbrace{I_P^2R_P+I_S^2R_S}_{铜损}+\underbrace{k f^\alpha B^\beta V_e}_{磁芯}+\underbrace{\tfrac12L_ki_{Lmp}^2f}_{RCD}+\underbrace{0.2\sim0.5W}_{控制}$$

## 八、与其他拓扑的定位对比

| 拓扑 | 隔离 | 升降压 | 功率范围 | 特点 |
|---|---|---|---|---|
| Buck | 否 | 降压 | 宽 | 动态最好，无 RHP 零点 |
| Boost | 否 | 升压 | 宽 | 输入电流连续 |
| Buck-Boost | 否 | 升降压 | 宽 | 反极性 |
| **反激** | **是** | **升降压** | **≤100W 统治级** | 器件最少、成本最低；隔离版 Buck-Boost |
