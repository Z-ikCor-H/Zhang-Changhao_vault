# 第七章 反激变换器 第十二节：右半平面零点与稳定性

[7.3 节](7.3-反激励磁电感计算.md)提过一句："DCM 更容易稳定，CCM 不易稳定"。本节把机理和**工程判据**补齐：**为什么反激 CCM 存在右半平面零点（RHP Zero）？它怎么限制环路带宽？DCM 为什么把它"推走"了？**

> 完整的小信号建模（开关平均法、状态空间平均、传递函数推导）将在**反馈环路分析与稳定性**章节展开，本节只取结论与设计判据。

---

## 一、RHP零点的物理解释

[5.10 节](../../03.Buck-Boost/5.10-三拓扑总结与动态特性.md)已经讲过 Boost/Buck-Boost 的"越调越糟"现象，反激**完全同源**：

1. 负载突然加重 → $U_o$ 下降 → 环路**增大 $D$**
2. $D$ 增大 → **副边二极管导通时间 $(1-D)T$ 缩短**
3. 而副边导通时间正是**变压器给负载输送能量的唯一窗口**
4. 窗口变短 → 本周期送出的能量**先减少** → $U_o$ 进一步下降（**先降后升**）
5. 若环路响应太快，就会在这段"先降"里继续加 $D$ → 恶性循环 → 震荡

$$\boxed{\text{反激 CCM 是"先储能、后释放"拓扑} \Rightarrow \text{控制量增大反而先使输出朝反方向走} \Rightarrow \text{RHP 零点}}$$

> **反激为什么比 Buck 多这个麻烦？** Buck 的输入通过电感**直接**向输出传递能量（Q 导通时输入连负载），调节 $D$ 立即见效；反激则必须先存进 $L_m$ 、再放出来，中间隔了"半个周期"的时延。

---

## 二、RHP零点的频率

反激等效到原边就是 Buck-Boost（[7](7.2-反激等效变换.md)），故 RHP 零点频率可直接套用 Buck-Boost 的结果（ $R_o\to n^2R_o$ 、 $L\to L_m$ ）：

$$\boxed{f_{RHPZ}=\frac{R_o(1-D)^2}{2\pi\,n^2L_m\,D}} \quad \text{(7.12-1)}$$

| 参数变化 | $f_{RHPZ}$ | 说明 |
|---|---|---|
| $D\uparrow$ （重载/低输入） | **下降** | 最恶劣工况 |
| $R_o\downarrow$ （重载） | 下降 | 重载最难稳 |
| $L_m\downarrow$ | 升高 | 电感小更易稳 |
| $n$ 更大 | 下降 | 折算电阻 $n^2R_o$ 更大 |

> **最恶劣点：最低输入电压 + 满载**（ $D_{max}$ ）时 $f_{RHPZ}$ 最低，环路必须按此点设计。

---

## 三、工程判据：穿越频率的约束

RHP 零点带来额外的 **−90° 相位滞后**（与左半平面零点的 +90° 相反），且**无法被补偿抵消**——只能"躲开"。

$$\boxed{f_c \le \frac{f_{RHPZ}}{5}\quad(\text{工程常用};\ \text{保守取}\ f_c\le\frac{f_{RHPZ}}{10})} \quad \text{(7.12-2)}$$

> **含义：** CCM 反激的**环路带宽被 RHP 零点卡死**，通常只有几 kHz（而 Buck 可以做到几十 kHz）。带宽低 → 动态响应慢，这是 CCM 反激的固有代价。

---

## 四、DCM为什么"更容易稳定"

DCM 下，电感（励磁）电流**每个周期都从零开始**——上一个周期不"记住"任何信息：

- 副边电流的续流时间 $D_1T$ **只由电路参数决定，与控制量无关**（[Buck-Boost 5.8 节](../../03.Buck-Boost/5.8-DCM增益分析.md)： $D_1=\sqrt{2L/R_oT}$ ，反激为 $\sqrt{2L_S/(R_oT)}$ ）
- 能量每周期"存多少放多少"，不存在"增加 $D$ 反而压缩放电窗口"的机制
- 小信号模型里 RHP 零点被推到**远高于开关频率**的位置 → 对环路无影响

$$\boxed{\text{DCM：RHP 零点消失（推到高频）} \Rightarrow \text{环路好设计、系统稳定}}$$

> **代价：** DCM 峰值电流大（[7.3 节](7.3-反激励磁电感计算.md)），大功率时 CCM 更划算。**大功率 CCM 反激必须直面 RHP 零点**：压低穿越频率 + 峰值电流控制 + 斜坡补偿（[7.9 节](7.9-匝比与反射电压设计.md)）。

## 五、控制方式的初步介绍

| 控制方式 | 与反激的关系 |
|---|---|
| **电压模式** | 环路需补偿 LC 双极点；CCM 反激仍受 RHP 零点约束 |
| **峰值电流模式** | 内环把电感电流变成受控电流源 → 外环降为一阶；**必须加斜坡补偿**（ $D>0.5$ ） |
| **QR/变频控制** | DCM 下无 RHP 问题，频率随负载变化 |

> 每种方式的环路建模、补偿网络设计（Type II / Type III）在反馈环路章节详述。

## 六、本节小结

| 主题 | 核心结论 |
|---|---|
| RHP 零点来源 | 先储能后释放 → 增 $D$ 先压缩放电窗口 → 输出先降后升 |
| 零点频率 | $f_{RHPZ}=\dfrac{R_o(1-D)^2}{2\pi n^2L_mD}$ ，最低输入+满载时最低 |
| 相位影响 | 额外 −90° 滞后，无法补偿，只能躲开 |
| 工程判据 | $f_c\le f_{RHPZ}/5$ （保守 /10）→ CCM 反激带宽仅几 kHz |
| DCM 为何好稳 | 电流每周期归零、 $D_1$ 与控制无关 → RHP 零点被推到高频 |
| 应对手段 | 低带宽设计 + 峰值电流控制 + 斜坡补偿 |
