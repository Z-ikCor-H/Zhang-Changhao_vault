# 第五章 Buck-Boost电路 第五节：非理想Buck-Boost分析

前面各节均基于理想器件假设。本节放开三个关键非理想因素：**开关管导通压降 $U_{SW}$、二极管正向压降 $U_D$、电感绕线电阻 $R_1$ 各会让 Buck-Boost 增益偏离理想式(5.1-4)多少？为什么理想公式在 $D\to1$ 时给出无穷大、而实际电路增益会回到零？最大的电压增益由什么决定？** 本节修正 CCM 增益公式，说明最大增益的限制，并汇总全部 CCM 设计公式与应力曲线。

---

## 一、非理想因素引入

| 器件 | 理想假设 | 实际情况 |
|---|---|---|
| 开关管 Q（MOSFET） | 导通压降 = 0 | 导通压降 $U_{SW}$（或导通电阻 $R_{on}$） |
| 二极管 D | 导通压降 = 0 | 正向导通压降 $U_D$（约 0.7V ~ 1V） |
| 电感 L | 绕线电阻 = 0 | 绕线电阻 $R_1$（还含部分线路电阻） |

> 本节仍在 **CCM 模式**下分析，先单独考虑"Q/D 压降"，再单独考虑"L 寄生电阻"。

---

## 二、考虑开关管与二极管压降的增益

### 2.1 分析方法：电感两端电压平均值相等

仍用[[1.2-伏秒平衡#四、伏秒平衡的一种便捷理解|伏秒平衡的便捷形式]]——**电感两端电压的平均值相等**。定义电感**上端为 A 点**、**下端为 B 点（接地）**。

![[5.5-1 非理想Q、D Buck-Boost拓扑.png|470]]

### 2.2 分状态分析

| 状态 | A 点电压 $U_A$ |
|---|---|
| Q 导通（$t_{on}=DT$） | $U_{in} - U_{SW}$ |
| Q 关断（$t_{off}=(1-D)T$） | $-(U_o + U_D)$ |

B 点直接接地，故：

$$\overline{U_B} = 0$$

![[5.5-2 电感电压电流波形图.png|460]]

> **关断时为什么是 $-(U_o+U_D)$？** 二极管导通后，A 点与输出端连通。输出端是**负电位** $-U_o$，再经过二极管压降（阳极接输出端、阴极接 A 点，故 A 点比输出端还低 $U_D$），所以 $U_A=-(U_o+U_D)$——**比零还要低**。

### 2.3 电压平均值相等

$$\overline{U_A} = (U_{in}-U_{SW})\cdot D + \left[-(U_o+U_D)\right]\cdot(1-D) = 0$$

$$(U_{in}-U_{SW})\cdot D = (U_o+U_D)\cdot(1-D)$$

### 2.4 整理结果

$$\boxed{U_o = \frac{D}{1-D}\left(U_{in}-U_{SW}\right) - U_D} \tag{5.5-1}$$

> **理想情况对照：** 令 $U_{SW}=U_D=0$，退化为 $U_o=\dfrac{D}{1-D}U_{in}$，即理想增益[[5.1-CCM增益分析#四、CCM稳态增益（伏秒平衡）|式(5.1-4)]]。

> **与 Buck / Boost 对比：**

| 拓扑 | 含 $U_{SW}$、$U_D$ 的输出电压 |
|---|---|
| Buck | $U_o = D(U_{in}-U_{SW}+U_D) - U_D$ |
| Boost | $U_o = \dfrac{U_{in}-D\,U_{SW}}{1-D} - U_D$ |
| **Buck-Boost** | $U_o = \dfrac{D}{1-D}(U_{in}-U_{SW}) - U_D$ |

> 非理想因素使实际占空比 $D$ 需要比理想值**略大**，效率 $\eta<1$。

---

## 三、理想公式的"奇异点"：$D\to1$ 与实际电路不符

### 3.1 实际电路的行为

| 极限 | 理想/非理想公式预测 | 实际电路行为 |
|---|---|---|
| $D=1$（Q 恒导通） | $U_o\to\infty$ | 二极管一直**导通不了**，输入与输出彻底脱离；负载哪怕有电容，电荷终会放完 → $U_o\to0$，**增益 = 0** |
| $D=0$（Q 恒关断） | $U_o=0$ | Q 一直不开，电感不能被充电，负载无能量来源 → $U_o=0$，**增益 = 0** |

### 3.2 推测：中间必有最大值

既然两端都是零，而中间增益不为零，那么：

> **Buck-Boost 的增益曲线应从 0 开始、升到某个最大值、再回落到 0**——但式(5.5-1)与理想式都表达不出"回落到零"的趋势，说明还缺一个限制因素。

> **与 Boost 一样存在奇异点。** Boost 在 $D\to1$ 时同样给出无穷增益、而实际输出为零，也是同样的问题。（Buck 没有这个问题：$D=0\Rightarrow U_o=0$、$D=1\Rightarrow U_o=U_{in}$，与理想公式完全对应。）

## 四、考虑电感寄生电阻 $R_1$ 的增益

### 4.1 模型

在电感支路串入寄生的绕线电阻 $R_1$。为简化计算，**先不考虑 Q/D 的压降**（考虑后结论相同，只是式子更繁）。

![[5.5-3 非理想L Buck-Boost拓扑.png|470]]

### 4.2 A 点电压

由于 $R_1$ 上的压降 $U_{R1}=i_LR_1$ 随电感电流**一直在变**，A 点电压不能写成定值，必须用**平均值的定义**（积分）来求：

| 状态 | $U_A$ |
|---|---|
| Q 导通（$DT$） | $U_{in} - i_LR_1$ |
| Q 关断（$(1-D)T$） | $-U_o - i_LR_1$ |

$$\overline{U_A} = \frac{1}{T}\left[\int_0^{DT}\left(U_{in}-i_LR_1\right)dt + \int_{DT}^{T}\left(-U_o-i_LR_1\right)dt\right]$$

其中 $U_{in}$、$U_o$、$R_1$ 都是常数，可以提到积分号外；两个时段的积分上下限正好拼成整个周期：

$$\overline{U_A} = U_{in}\cdot D - U_o\cdot(1-D) - R_1\cdot\underbrace{\frac{1}{T}\int_0^{T} i_L\,dt}_{I_L}$$

### 4.3 电压平均值相等

由 $\overline{U_A}=\overline{U_B}=0$：

$$U_{in}\cdot D - U_o\cdot(1-D) - R_1I_L = 0 \tag{5.5-2}$$

代入 [[5.2-电感电流纹波分析#二、直流分量 $I_L$ 的计算|式(5.2-2)]] $I_L=\dfrac{I_o}{1-D}$ 与 $I_o=\dfrac{U_o}{R_o}$：

$$U_{in}D = U_o(1-D) + \frac{R_1U_o}{R_o(1-D)} = U_o\left[(1-D)+\frac{R_1}{R_o(1-D)}\right]$$

### 4.4 增益表达式

$$\boxed{\frac{U_o}{U_{in}} = \frac{D(1-D)}{(1-D)^2 + \dfrac{R_1}{R_o}}} \tag{5.5-3}$$

也可写成"理想增益 × 修正因子"的形式：

$$\frac{U_o}{U_{in}} = \underbrace{\frac{D}{1-D}}_{\text{理想增益}}\cdot\frac{1}{1 + \dfrac{R_1}{R_o(1-D)^2}}$$

> **理想情况对照：** 令 $R_1=0$，修正因子为 1，回到理想增益 $\dfrac{D}{1-D}$——**奇异点消失了**，增益函数在整个 $D\in(0,1)$ 上连续。

## 五、增益曲线与"最高增益点"

以 $R_1/R_o$ 为参变量，画出增益随占空比 $D$ 的变化：

![[5.5-4 Buck-Boost增益与占空比关系曲线图.png|470]]

| 曲线 | $R_1/R_o$ | 表现 |
|---|---|---|
| 黑 | $0$（理想） | 单调上升，$D\to1$ 时增至无穷 |
| 红 | $0.02$ | 峰值约 $3.1$，出现在 $D\approx0.88$ |
| 蓝 | $0.04$ | 峰值约 $2.05$，$D\approx0.84$ |
| 绿 | $0.06$ | 峰值约 $1.60$，$D\approx0.81$ |
| 粉 | $0.08$ | 峰值约 $1.34$，$D\approx0.79$ |

可见：**曲线确实存在一个最大增益点，之后随 $D$ 增大而下降，到 $D=1$ 时回到零**——与第三节的推测一致。而且 $R_1/R_o$ 越大，最大增益点就越低。

### 5.1 极值公式

记 $k=\dfrac{R_1}{R_o}$，对式(5.5-3)求极值（令 $y=1-D$，最大化 $\dfrac{(1-y)y}{y^2+k}$）：

$$\boxed{D_{peak} = 1 + k - \sqrt{k^2+k},\qquad G_{max} = \frac{1}{2}\left(\sqrt{1+\frac{R_o}{R_1}} - 1\right)} \tag{5.5-4}$$

> 与 Boost 对照：Boost 的极值为 $D_{peak}=1-\sqrt{k}$、$G_{max}=\dfrac{1}{2}\sqrt{\dfrac{R_o}{R_1}}$。两者形式相近——因为寄生电阻限制最大增益的**机理完全相同**。

### 5.2 物理解释：$R_1$ 限制了最大增益

设想 Q 一直开通（$D\to1$）：电路变成 $U_{in}\to Q\to R_1\to L\to$ 地，电感电流会上升到一个稳态上限

$$i_{L,max} = \frac{U_{in}}{R_1}$$

对应的最大储能 $E_{max}=\dfrac{1}{2}L\left(\dfrac{U_{in}}{R_1}\right)^2$。

- $R_1$ 越大 → 电流能达到的上限越低 → 储能上限越低 → 每周期能送到输出的能量越少 → **增益越低**
- 所以 **电感线路中的寄生电阻限制了 Buck-Boost 的最大电压增益，使其无法达到无穷大**

## 六、CCM Buck-Boost 全部设计公式汇总

以下汇总整合第五章前四节与本节非理想修正的核心结论。

### 6.1 基本参数

| 参数 | 公式 | 说明 |
|---|---|---|
| 理想增益 | $\dfrac{U_o}{U_{in}} = \dfrac{D}{1-D}$ | 输出**反极性** |
| 含压降增益 | $U_o = \dfrac{D}{1-D}(U_{in}-U_{SW}) - U_D$ | 考虑 $U_{SW}$、$U_D$ |
| 含 $R_1$ 增益 | $\dfrac{U_o}{U_{in}}=\dfrac{D(1-D)}{(1-D)^2+R_1/R_o}$ | 峰值见式(5.5-4) |
| 占空比 | $D = \dfrac{\lvert U_o\rvert}{\lvert U_o\rvert+U_{in}}$ | 设计时反解 |
| 开关周期 | $T=1/f$ | — |
| 电流纹波率 | $\tau=\dfrac{(1-D)^2R_oT}{L}$ | **推荐 1.2**（可达 1.4） |

### 6.2 电感电流

| 量 | 公式 |
|---|---|
| 平均值 | $I_L = \dfrac{I_o}{1-D}$ |
| 纹波 | $\Delta i_L = \dfrac{U_o(1-D)T}{L}=\tau I_L$ |
| 峰值 | $i_{L2} = I_L\left(1+\dfrac{\tau}{2}\right)$ |
| RMS 值 | $I_{L\_rms} = \dfrac{I_o}{1-D}\sqrt{1+\dfrac{\tau^2}{12}}$ |

### 6.3 开关管 Q 与二极管 D

| 元件 | 平均值 | RMS | 峰值 |
|---|---|---|---|
| Q | $\dfrac{I_oD}{1-D}$ | $\dfrac{I_o\sqrt{D}}{1-D}\sqrt{1+\dfrac{\tau^2}{12}}$ | $i_{L2}$ |
| D | $I_o$ | $\dfrac{I_o}{\sqrt{1-D}}\sqrt{1+\dfrac{\tau^2}{12}}$ | $i_{L2}$ |

### 6.4 电容

| 量 | 公式 |
|---|---|
| 输入电容 RMS | $I_{Cin\_rms}=\dfrac{I_o}{1-D}\sqrt{D\left(1+\dfrac{\tau^2}{12}-D\right)}$ |
| 输出电容 RMS | $I_{Co\_rms}=I_o\sqrt{\dfrac{D+\tau^2/12}{1-D}}$ |
| 输出纹波电压 | $\Delta U_o=\dfrac{I_oD}{C_of}$ |
| ESR 纹波 | $\Delta U_{o(ESR)}=(i_{L2\_max}-I_o)\cdot ESR$ |

### 6.5 电感值

$$\boxed{L=\frac{U_o(1-D_{max})^2}{\tau\cdot I_o\cdot f}}\qquad(\tau\approx1.2,\ D_{max}=\frac{\lvert U_o\rvert}{\lvert U_o\rvert+U_{in\_min}})$$

在最恶劣工况（**最低输入电压**、满载）下计算。

## 七、各元件电流应力随占空比 D 的变化曲线

将各元件电流应力以 **$D=0.5$** 归一化：

![[5.5-5 Buck-Boost各元件电流与占空比关系曲线图.png|470]]

| 曲线 | 趋势 |
|---|---|
| 电感纹波 $\Delta i_L$（棕） | 随 $D$ 增大**线性下降**（$\propto 1-D$） |
| 开关管 RMS（红） | 随 $D$ 增大而上升 |
| 二极管 RMS（蓝） | 随 $D$ 增大而上升 |
| 输入电容 RMS（绿） | 随 $D$ 增大而上升 |
| 输出电容 RMS（粉虚线） | 随 $D$ 增大而上升 |
| 电感 RMS（青） | 随 $D$ 增大而上升 |

> **核心结论：除了电感纹波 $\Delta i_L$ 之外，其余各电流应力都随 $D$ 增大而增大。** 所以要让变换器工作在**应力最小的 $D$ 区间**，并针对最恶劣工作点去设计器件。

> 注意：纵轴是**归一化后的比例关系**（以 $D=0.5$ 为基准），不是实际安培值，只用于判断"工作在哪一点时哪些器件应力更大"。

## 八、本节小结

| 主题 | 核心结论 |
|---|---|
| 含压降增益 | $U_o=\dfrac{D}{1-D}(U_{in}-U_{SW})-U_D$ |
| 奇异点 | 理想式在 $D\to1$ 给出无穷增益；实际 $D\to1$ 与 $D\to0$ 时增益都为零 |
| 含 $R_1$ 增益 | $\dfrac{U_o}{U_{in}}=\dfrac{D(1-D)}{(1-D)^2+R_1/R_o}$，存在最高增益点 |
| 最大增益 | $G_{max}=\frac{1}{2}\left(\sqrt{1+R_o/R_1}-1\right)$，由寄生电阻 $R_1$ 限制 |
| 应力曲线 | 除 $\Delta i_L$ 随 $D$ 下降外，各电流应力均随 $D$ 上升 |
