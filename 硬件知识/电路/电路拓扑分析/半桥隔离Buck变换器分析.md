# 半桥隔离型DC-DC变换器——拓扑、模态与选型分析

---

## 一、拓扑概述

### 1.1 拓扑名称

**半桥隔离型 DC-DC 变换器**（Half-Bridge Isolated DC-DC Converter），亦称 **半桥正激变换器**。

### 1.2 电路结构与宏观工作机理

半桥是全桥的"减半"版本：将 $Q_3$、$Q_4$ 替换为两个等值分压电容 $C_1$、$C_2$，仅保留 $Q_1$、$Q_2$ 两只开关管。

| 环节 | 功能 |
|------|------|
| ① 分压电容（$C_1$、$C_2$）| 将 $V_{in}$ 一分为二，中点提供 $V_{in}/2$ 直流电位，作为变压器原边一端 |
| ② 半桥斩波（$Q_1$、$Q_2$）| $Q_1$ 导通 → $v_T = +V_{in}/2$；$Q_2$ 导通 → $v_T = -V_{in}/2$；双极性方波激励变压器 |
| ③ 高频变压器（1:n）| 电压变换 + 电气隔离；双极性对称励磁，自动复位 |
| ④ 全波整流（$D_5$、$D_6$）| 双极性→单向脉动，每个半周仅一个二极管导通 |
| ⑤ LC 滤波 | 滤除高频分量，输出平滑直流 |

**控制逻辑**：$Q_1$、$Q_2$ 互补导通（各 < 50% 留死区），调节占空比控制输出。与全桥的本质区别：变压器原边电压恒为 **$V_{in}/2$**。

> **▎为什么电容中点电压 = $V_{in}/2$？**
>
> **① 静态分压。** $C_1 = C_2$ 串联跨接 $V_{in}$，中点对地 $= V_{in}/2$。
>
> **② 动态自平衡（真正的保证）。** 即使容值不完全相等，稳态自动回到 $V_{in}/2$：
> - 模态 1（$Q_1$ 导通）：$C_1$ 放电，$C_2$ 充电 → $V_{C1}$ ↓，$V_{C2}$ ↑
> - 模态 3（$Q_2$ 导通）：$C_2$ 放电，$C_1$ 充电 → $V_{C2}$ ↓，$V_{C1}$ ↑
> - 一周期净充放电为零 → 中点稳定。
>
> 若中点偏离（比如 > $V_{in}/2$），则正负半周伏秒积不对称 → 变压器产生直流偏磁电流 → 偏磁电流自动纠正电容充放电不平衡，把中点拉回 $V_{in}/2$。**这是半桥的自平衡机制。**

### 1.3 优点

1. **开关管少**——仅需 2 个 MOS 管 + 2 路驱动（1 高边 + 1 低边），成本约为全桥的 50%
2. **自带隔直**——$C_1$、$C_2$ 串联在变压器回路中，直流分量被电容天然阻断，变压器无偏磁饱和风险（全桥需额外串隔直电容）
3. **控制简单**——$Q_1$、$Q_2$ 互补，无对角同步约束，死区逻辑容易实现
4. **容错性好**——同桥臂直通时电流被 $C_1$（或 $C_2$）限制，不会立即短路 $V_{in}$，硬故障容错优于全桥
5. **中功率性价比高**——100~500W 范围内，全桥多出的两个管子 + 驱动 = 额外成本，半桥刚好够用

### 1.4 缺点

1. **原边电压减半**——$v_T = \pm V_{in}/2$，相同功率下原边电流是全桥的 2 倍 → 导通损耗是全桥的 4 倍（$I^2R$）
2. **需要大容量分压电容**——$C_1$、$C_2$ 流过全部原边交流电流，ESR 损耗不可忽略，电容体积和成本抵消一部分省管的收益
3. **中点电压漂移**——$C_1 \neq C_2$ 容值偏差或充放电不等 → 中点偏离 $V_{in}/2$ → 正负半周伏秒积不对称 → 偏磁
4. **功率上限受限**——电流应力 + 电容纹波瓶颈，通常 ≤ 500W，大功率不如全桥
5. **MOS 管电压应力不变**——虽然 $v_T$ 减半，但 $Q_1$、$Q_2$ 关断时仍承受 $V_{in}$（漏源电压），选型时电压等级跟全桥一样

### 1.5 适用场景

| 场景                         | 是否适合 | 原因                          |
| -------------------------- | :--: | --------------------------- |
| ATX 电脑电源（400V→12V/5V/3.3V） | ✅ 最佳 | 半桥的经典应用，功率适中（200~500W）、成本敏感 |
| 通信电源（48V→12V/200~500W）     |  ✅   | 功率在半桥范围内，比全桥省 2 管 + 2 驱动    |
| 工业辅助电源（100~300W）           |  ✅   | 可靠性要求高 + 成本可控 + 自带隔直        |
| 大功率（>500W）                 |  ❌   | 原边电流翻倍 → 导通损耗 ×4 → 用全桥      |
| 超低成本/小功率（<100W）            |  △   | 分压电容占据 PCB 面积，不如反激简单便宜      |

## 二、高频开关周期模态分析

开关周期 $T_s$，$Q_1$ 导通时间 = $Q_2$ 导通时间 = $t_{on}$，死区 $t_d = T_s/2 - t_{on}$。CCM 下一个完整周期分 4 个阶段。

---

### 2.1 模态 1：$Q_1$ 导通（正半周功率传输）——$[t_0, t_1]$

**(1) 开关管状态**
- $Q_1$ **导通**，$Q_2$ **关断**

**(2) 变压器原边**
- 电容中点电压 = $V_{in}/2$，$Q_1$ 导通将桥臂中点拉到 $V_{in}^+$
- $v_T = V_{in} - V_{in}/2 = +V_{in}/2$（原边上端 +，下端 −，与参考方向一致）

> **电流路径**：$C_1$ 正极 → $Q_1$（漏→源）→ 变压器原边绕组（左→右）→ 电容中点 → $C_1$ 负极。$C_1$ 放电，$C_2$ 充电。

- $L_M$ **充电**：$\frac{di_M}{dt} = \frac{V_{in}/2}{L_M}$，$i_M$ 正向线性增大
- 磁通 $\phi$ **增大**

**(3) 副边二极管**
- $D_5$ **导通**（上绕组打点端为正）
- $D_6$ **截止**（反向电压 ≈ $2 \cdot n \cdot V_{in}/2 = nV_{in}$）

**(4) 电流变化**

| 电流 | 趋势 | 说明 |
|------|------|------|
| $i_1'$ | 线性增大 | $i_1' = n \cdot i$ |
| $i_M$ | 线性增大 | $i_M(t) = i_M(0) + \frac{V_{in}/2}{L_M}t$ |
| $i_1$ | 线性增大 | $i_1 = i_1' + i_M$ |
| $i_{D5}$ | 线性增大 | $i_{D5} = i$ |
| $i_{D6}$ | $0$ | 截止 |
| $i$ | 线性增大 | $\frac{di}{dt} = \frac{nV_{in}/2 - V_O}{L}$ |

**(5) 电压**
- $v_T = +V_{in}/2$
- $v_S = n \cdot V_{in}/2$
- $v_L = nV_{in}/2 - V_O > 0$（电感储能）
- $v_O \approx$ 恒定

---

### 2.2 模态 2：死区（$Q_1$、$Q_2$ 均关断）——$[t_1, t_2]$

**(1) 开关管状态**
- $Q_1$、$Q_2$ **全部关断**

**(2) 变压器原边**
- 原边无主动激励，励磁电流通过 $Q_2$ 体二极管续流
- $v_T \approx 0$（副边续流反射回原边，箝位）
- $L_M$ 两端电压 ≈ 0 → $i_M$ **近似不变**（保持峰值）

**(3) 副边二极管**
- $D_5$ **导通**（续流），$D_6$ **导通**（续流）
- 两管平分输出电感电流：$i_{D5} \approx i_{D6} \approx i/2$

**(4) 电流变化**

| 电流 | 趋势 | 说明 |
|------|------|------|
| $i$ | 线性下降 | $\frac{di}{dt} = -\frac{V_O}{L}$ |
| $i_{D5}$、$i_{D6}$ | 下降 | 各分一半，同时续流 |

**(5) 电压**
- $v_S \approx 0$（$D_5$、$D_6$ 同时导通，箝位副边）
- $v_T \approx 0$（副边短路反射）
- $v_L = v_S - V_O = -V_O$（电感释能）

> **▎关键理解：为什么 $v_L = -V_O$？——死区 = Buck 的 off-time**
>
> ① 电感电流 $i$ 不能突变，死区必须续流。
> ② 续流路径：$L$ → 负载 → 地 → 中心抽头 → 上绕组+$D_5$ // 下绕组+$D_6$ → 回到 $L$。两管同时导通。
> ③ 两管导通 = 副边被二极管正向阻抗短路 → $v_S \approx 0$。
> ④ KVL：$v_L + V_O = v_S$ → $v_L = 0 - V_O = -V_O$。
>
> 变压器副边感应电压不是"没有"，而是被两只导通的二极管**强制箝位**到零——跟 Buck 变换器 off-time 电感通过续流二极管放电的机理完全一致。

**(6) 半桥特有的换流路径**

$Q_1$ 关断后，变压器原边漏感电流通过 $Q_2$ 体二极管续流，回路为：原边绕组下端 → 电容中点 → $C_2$ → $V_{in}^-$ → $Q_2$ 体二极管 → 原边绕组上端。$C_2$ 充电，$C_1$ 电压被保持。分压电容在此起到"吸收无功、稳定中点"的作用。

---

### 2.3 模态 3：$Q_2$ 导通（负半周功率传输）——$[t_2, t_3]$

**(1) 开关管状态**
- $Q_2$ **导通**，$Q_1$ **关断**

**(2) 变压器原边**
- $Q_2$ 导通将桥臂中点拉到 $V_{in}^-$
- $v_T = 0 - V_{in}/2 = -V_{in}/2$（原边上端 −，下端 +，与参考方向相反）

> **电流路径**：$C_2$ 正极（电容中点）→ 变压器原边绕组（右→左）→ $Q_2$（漏→源）→ $C_2$ 负极（$V_{in}^-$）。$C_2$ 放电，$C_1$ 在此半周被充电。

- $L_M$ **反向充电**：$\frac{di_M}{dt} = -\frac{V_{in}/2}{L_M}$，$i_M$ 负向线性增大
- 磁通 $\phi$ **反向增大**（磁芯双极性对称励磁，自动复位）

**(3) 副边二极管**
- $D_6$ **导通**（下绕组下端为正）
- $D_5$ **截止**（反向电压 ≈ $nV_{in}$）

**(4) 电流变化**

| 电流 | 趋势 | 说明 |
|------|------|------|
| $i_1'$ | 负向线性增大 | $i_1' = -n \cdot i$ |
| $i_M$ | 负向线性增大 | 反向励磁 |
| $i_{D6}$ | 线性增大 | $i_{D6} = i$ |
| $i_{D5}$ | $0$ | 截止 |
| $i$ | 线性增大 | $\frac{di}{dt} = \frac{nV_{in}/2 - V_O}{L}$ |

**(5) 电压**
- $v_T = -V_{in}/2$
- $v_S = n \cdot V_{in}/2$（全波整流，输出极性不变，上正下负）
- $v_L = nV_{in}/2 - V_O > 0$

---

### 2.4 模态 4：死区（$Q_1$、$Q_2$ 均关断）——$[t_3, t_4]$

与模态 2 对称。$Q_1$ 体二极管续流，$D_5$、$D_6$ 同时续流，$v_S = 0$，$v_L = -V_O$，$i$ 线性下降。原边通过 $Q_1$ 体二极管续流，$C_1$ 充电。

---

### 2.5 关键波形汇总（一个周期）

```
        模态1   模态2   模态3   模态4
         Q1    死区     Q2    死区
vT:   +Vin/2    0    -Vin/2    0
vS:   nVin/2    0    nVin/2    0
vL: nVin/2-Vo -Vo  nVin/2-Vo  -Vo
 i:   上升    下降    上升    下降
 iM:  正增    持平    负增    持平
```

**与全桥的关键区别**：全桥 $v_T = \pm V_{in}$；半桥 $v_T = \pm V_{in}/2$。波形形状相同，幅值减半。

## 三、输入-输出电压关系推导

**方法**：电感 $L$ 伏秒平衡（半个开关周期内）。

模态 1 或 3（导通，$t_{on}$）：$v_L = \dfrac{nV_{in}}{2} - V_O$

模态 2 或 4（死区，$T_s/2 - t_{on}$）：$v_L = -V_O$

$$\left(\frac{nV_{in}}{2} - V_O\right) \cdot t_{on} + (-V_O) \cdot \left(\frac{T_s}{2} - t_{on}\right) = 0$$

$$\frac{nV_{in}}{2} \cdot t_{on} = V_O \cdot \frac{T_s}{2}$$

定义有效占空比 $D = \dfrac{2 t_{on}}{T_s}$（$0 < D < 1$）：

$$\boxed{V_O = n \cdot D \cdot \frac{V_{in}}{2}}$$

| 对比 | 全桥 | 半桥 |
|------|------|------|
| 输出电压 | $V_O = n \cdot D \cdot V_{in}$ | $V_O = n \cdot D \cdot \dfrac{V_{in}}{2}$ |
| 同等 $V_O$ | $D$ 小或 $n$ 小 | $D$ 需翻倍或 $n$ 需翻倍 |
| 含义 | 变压器原边吃满 $V_{in}$ | 变压器原边只能吃到一半 |

> **补充**：单管占空比 $d = t_{on}/T_s < 0.5$，有效占空比 $D = 2d$。

## 四、励磁电感 $L_M$ 的作用及其对电路的影响

### 4.1 $L_M$ 的本质

$L_M$ 是变压器磁芯磁化特性的等效电感，并联在原边绕组两端。表征：**为了在磁芯中建立交变磁通，需要从电源吸收励磁电流**。

### 4.2 作用（与全桥一致）

| 作用 | 说明 |
|------|------|
| **建立磁通** | $\phi \propto i_M$，提供磁化安匝，使变压器能传递功率 |
| **能量暂存** | 每半周储存 $W = \frac{1}{2}L_M i_{M,pk}^2$，换相时释放 |
| **死区续流** | $i_M$ 通过体二极管续流，维持原边回路连续性 |
| **辅助软开关** | 漏感 + $L_M$ 储能可辅助实现 ZVS |

### 4.3 励磁电流幅值（半桥特有）

$$i_{M,pk} = \frac{(V_{in}/2) \cdot t_{on}}{L_M} = \frac{V_{in} \cdot D}{4 L_M f_s}$$

全桥对应值：$i_{M,pk} = \dfrac{V_{in} \cdot D}{2 L_M f_s}$。

**半桥的 $i_{M,pk}$ 是全桥的一半**——因为 $v_T$ 减半，励磁电流斜率减半。同等 $L_M$ 下，励磁损耗更小。这是半桥的一个意外好处。

### 4.4 半桥 vs 全桥：$L_M$ 相关差异

| 影响 | 全桥 | 半桥 |
|------|------|------|
| 不参与功率传输 | ✓ | ✓ |
| 增加导通损耗 | $i_M$ 流过 2 个 MOS/每半周 | $i_M$ 流过 1 个 MOS/每半周（电流路径更短）|
| 磁芯饱和风险 | 有（需隔直电容或电流模式）| **无**（分压电容天然隔直）|
| 励磁电流峰值 | $V_{in}D/(2L_Mf_s)$ | $V_{in}D/(4L_Mf_s)$，**减半** |

## 五、元件选型依据与计算

> **▎为什么选这个场景？**
>
> 以下沿用与全桥相同的 **通信电源模块**（48V → 12V / 500W / 100kHz）设计指标。这是有意为之——**相同场景、不同拓扑**，选型数字的差异直接反映半桥和全桥的 trade-off：
>
> - 半桥原边电压只有 $V_{in}/2$ → 电流翻倍 → MOS 管 RMS 电流 ×2.8、导通损耗 ×4
> - 多了分压电容这个全桥没有的选型项，且其 RMS 电流需求极大
> - 副边反而受益（二极管电压应力更低）
>
> 所有公式保留符号形式，可直接代入其他设计指标复用。

### 5.1 设计指标

| 参数     | 符号        | 值              |
| ------ | --------- | -------------- |
| 输入电压   | $V_{in}$  | 48V（范围 36~60V） |
| 输出电压   | $V_O$     | 12V            |
| 额定输出功率 | $P_O$     | 500W           |
| 开关频率   | $f_s$     | 100kHz         |
| 最大占空比  | $D_{max}$ | 0.8            |
| 效率目标   | $\eta$    | ≥ 92%          |

### 5.2 公式速查卡

| 元件 | 核心公式 | 关键决定因素 |
|------|----------|-------------|
| 输入电容 | $C_{in}$：RMS 纹波电流约束 | $I_{pri,rms}$ 翻倍（vs 全桥）|
| MOS 管 | $V_{DSS} \geq 1.5 \cdot V_{in,max}$ | 电压应力同全桥，电流 ×2.8 |
| 分压电容 | $C_1=C_2 \geq \dfrac{I_{pri,avg}/(2f_s)}{\Delta V_{mid}}$ | **RMS 电流 ~24A 是瓶颈** |
| 变压器匝比 | $n = \dfrac{2V_O}{D_{max} \cdot V_{in,min}}$ | 分子多一个 ×2 |
| 整流二极管 | $V_{RRM} \geq n \cdot V_{in,max}$（×1.5 裕量）| 电压应力比全桥低 |
| 滤波电感 | $L = \dfrac{V_O(1-D_{min})}{2f_s \Delta i_L}$ | 同全桥 |
| 滤波电容 | $C \geq \dfrac{\Delta i_L}{8 f_s \Delta V_O}$ | 同全桥，ESR 是瓶颈 |

---

### 5.3 输入滤波电容 $C_{in}$

> **功率流位置**：输入侧第一级，吸收半桥斩波产生的脉冲电流。

原边电流有效值（$v_T = V_{in}/2$，电流翻倍）：

$$I_{pri,rms} \approx \frac{P_O}{\eta \cdot V_{in,min}/2} \cdot \sqrt{D_{max}} = \frac{500}{0.92 \times 18} \times \sqrt{0.8} \approx 27.0\text{A}$$

输入电容 RMS 纹波电流：

$$I_{Cin,rms} \approx I_{pri,rms} \cdot \sqrt{D_{max}(1 - D_{max})} = 27.0 \times \sqrt{0.8 \times 0.2} \approx 10.8\text{A}$$

> 全桥对应值 ~5.4A。半桥输入电容 RMS 电流翻倍。

计入 1.5 倍温升降额 → 需额定 RMS ≥ 16A。方案：**6 × 47µF/100V 高频低阻电解**并联。

电容量校核（纹波 ≤ 5%·$V_{in}$ = 2.4V）：

$$C_{in} \geq \frac{P_O/(\eta V_{in}) \cdot D_{max}/f_s}{\Delta V_{in}} \approx 39\mu\text{F}$$

电容量不是瓶颈，RMS 电流才是。

---

### 5.4 功率 MOS 管（$Q_1$、$Q_2$）

> **功率流位置**：输入电容之后，与分压电容共同构成半桥桥臂。

#### 电压应力

$$V_{DS,max} = V_{in,max} = 60\text{V}$$

1.5 倍裕量：$V_{DSS,rated} \geq 90\text{V}$，选 **100V** 等级。

> 电压应力与全桥完全相同——半桥省了两个开关管，但每个管子的耐压要求没有降低。

#### 电流应力

原边电流有效值：

$$I_{pri,rms} \approx \frac{P_O}{\eta \cdot V_{in,min}/2} \cdot \sqrt{D_{max}} = \frac{500}{0.92 \times 18} \times \sqrt{0.8} \approx 27.0\text{A}$$

每个 MOS 通态 RMS 电流：

$$I_{DS,rms} = I_{pri,rms} \cdot \sqrt{D_{max}} = 27.0 \times \sqrt{0.8} \approx 24.1\text{A}$$

峰值电流：

$$I_{DS,peak} \approx 1.3 \times \frac{P_O}{\eta \cdot V_{in,min}/2 \cdot D_{max}} = 1.3 \times \frac{500}{0.92 \times 18 \times 0.8} \approx 49.0\text{A}$$

#### 选型汇总（半桥 vs 全桥）

| 参数 | 全桥 | 半桥 | 变化 |
|------|------|------|------|
| $V_{DSS}$ | ≥100V | ≥100V | **相同** |
| $I_{DS,rms}$ | ~8.5A | ~24A | **×2.8** |
| $I_{DS,peak}$ | ~24.5A | ~49A | **×2** |
| $R_{DS(on)}$ | ≤10mΩ | **≤5mΩ**（损耗翻 4 倍需更低 $R_{on}$ 补偿）| 更苛刻 |
| 数量 | 4 | 2 | 省一半 |

**推荐**：Infineon **IRFP4468**（$V_{DSS}=100\text{V}$，$R_{DS(on)}=2.6\text{m}\Omega$，$I_D=95\text{A}$）或同等级低 $R_{on}$ 器件。

> 半桥虽然管子数量少，但**每个管子要更贵**（更低 $R_{DS(on)}$ 才能控制导通损耗），两管总成本不一定比全桥四管低。

---

### 5.5 分压电容 $C_1$、$C_2$

> **功率流位置**：与 MOS 管共同构成半桥桥臂——这是半桥**特有的选型项**，也是核心设计约束。

#### 电容量

电容中点电压纹波 $\Delta V_{mid} \leq 5\% \cdot V_{in}/2 = 1.2\text{V}$：

$$C_1 = C_2 \geq \frac{I_{pri,avg} \cdot T_s/2}{\Delta V_{mid}} = \frac{(P_O/(\eta \cdot V_{in}/2)) \cdot 1/(2f_s)}{\Delta V_{mid}}$$

$$C_1 = C_2 \geq \frac{500/(0.92 \times 24) \times 1/(2\times10^5)}{1.2} \approx 94\mu\text{F}$$

#### RMS 纹波电流（**选型瓶颈**）

$$I_{C,rms} \approx I_{pri,rms} \cdot \sqrt{D_{max}} \approx 27.0 \times \sqrt{0.8} \approx 24.1\text{A}$$

普通电解电容单只 RMS 电流额定值 ~1-3A，需要大量并联：

| 方案 | 配置 | 总 RMS 电流 |
|------|------|------------|
| 电解并联 | 10 × 100µF/100V 高频低阻型 | ~25A |
| 薄膜+电解混合 | 2 × 10µF 薄膜 + 6 × 100µF 电解 | ~25A |

> **这是半桥的重大弱点**：分压电容的 RMS 电流需求极大（~24A），需要多只电容并联，占用大量 PCB 面积和成本。全桥没有这个要求——这是省了两个 MOS 管的代价。

#### 均压电阻

在 $C_1$、$C_2$ 上各并联一只 **47kΩ~100kΩ / 1W** 电阻，强制静态均压，防止中点漂移。

---

### 5.6 变压器匝比 $n$

> **功率流位置**：半桥桥臂之后，整流之前——电压变换 + 隔离的核心。

$$V_O = n \cdot D_{max} \cdot \frac{V_{in,min}}{2} \quad\Rightarrow\quad n = \frac{2V_O}{D_{max} \cdot V_{in,min}} = \frac{2 \times 12}{0.8 \times 36} \approx 0.833$$

取整 $n = 0.85$（原边 : 副边 ≈ 1 : 0.85）。

校验最高输入时最小占空比：$D_{min} = \dfrac{2V_O}{n \cdot V_{in,max}} = \dfrac{24}{0.85 \times 60} \approx 0.47$，合理。

> **对比全桥**：全桥 $n = 0.5$。半桥的 $n$ 约是全桥的 **1.7 倍**——原边电压只有一半，需要更高的匝比来补偿。

---

### 5.7 副边整流二极管（$D_5$、$D_6$）

> **功率流位置**：变压器副边之后，滤波电感之前——全波整流。

#### 电压应力

$$V_{RRM} \geq 2 \cdot n \cdot \frac{V_{in,max}}{2} = n \cdot V_{in,max} = 0.85 \times 60 = 51\text{V}$$

2 倍裕量：$V_{RRM,rated} \geq 102\text{V}$，选 **150V**。

> 全桥的 $V_{RRM} = 2nV_{in,max} = 60\text{V}$。半桥的二极管反向电压**更低**——$v_T$ 减半 → $v_S$ 减半 → 二极管耐压需求降低。这是半桥对副边的意外好处。

#### 电流应力

与全桥完全相同（负载侧不变）：

| 参数 | 值 |
|------|-----|
| $I_{D,avg}$ | ~21A |
| $I_{D,peak}$ | ~46A |
| 推荐 | 150V/30A 超快恢复或 SiC |

---

### 5.8 输出滤波电感 $L$

> **功率流位置**：整流之后，输出电容之前——LC 滤波的 L 环节。

电感设计与全桥**基本一致**——$V_O$、$I_O$、纹波要求相同，且续流期间 $v_L = -V_O$ 不变。

$$L = \frac{V_O \cdot (1 - D_{min})}{2 f_s \cdot \Delta i_L} = \frac{12 \times (1 - 0.47)}{2 \times 10^5 \times 8.3} \approx 3.8\mu\text{H}$$

取标称值 **$L = 4.7\mu\text{H}$**。

> 注意 $D_{min}$ 值和全桥不同（半桥 $D_{min}=0.47$ vs 全桥 $D_{min}=0.4$），但计算结果在同一量级。磁芯选型与全桥相同（铁硅铝 KS157-060A）。

---

### 5.9 输出滤波电容 $C$

> **功率流位置**：滤波电感之后，负载之前——功率流的最后一环。

与全桥**完全相同**——输出电压、输出电流、纹波指标一样。

$$C_{min} = \frac{\Delta i_L}{8 f_s \cdot \Delta V_{O,pp}} = \frac{8.3}{8 \times 10^5 \times 0.12} \approx 86\mu\text{F}$$

取 2~3 倍裕量：$C \geq 220\mu\text{F}$。ESR ≤ 7.2mΩ。方案：3×100µF 电解 + 2×10µF MLCC。

---

### 5.10 选型汇总表（半桥 vs 全桥对照）

| 位置 | 元件 | 全桥 | 半桥 | 半桥变化 |
|------|------|------|------|----------|

## 六、快速小结

| 项目 | 全桥 | 半桥 |
|------|------|------|
| 拓扑名称 | 全桥隔离型 DC-DC | 半桥隔离型 DC-DC |
| 开关管 | 4 | **2** |
| 原边电压 $v_T$ | $\pm V_{in}$ | $\pm V_{in}/2$ |
| $V_O$ 公式 | $V_O = nDV_{in}$ | $V_O = nDV_{in}/2$ |
| 匝比（同工况）| 0.5 | **0.85** |
| 原边电流（同功率）| $I$ | **$2I$** |
| 开关管电流 RMS | ~8.5A | **~24A（×2.8）** |
| 隔直 | 需额外电容 | 分压电容天然隔直 |
| 分压电容 | 无 | 2×≥94µF，RMS≥24A（**选型瓶颈**）|
| 适用功率 | 500W~数kW | **100~500W** |
| 核心代价 | 4 管 + 4 驱动，成本高 | 电流翻倍，分压电容体积大 |
