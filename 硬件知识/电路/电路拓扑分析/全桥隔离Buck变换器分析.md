# 全桥隔离型DC-DC变换器——拓扑、模态与选型分析

---

## 一、拓扑概述

### 1.1 拓扑名称

**全桥隔离型 DC-DC 变换器**（Full-Bridge Isolated DC-DC Converter），亦称 **隔离型全桥 Buck 变换器** 或 **全桥正激变换器**。

### 1.2 电路结构与宏观工作机理

完整的功率链路分为四个环节：

| 环节 | 功能 |
|------|------|
| ① 全桥逆变（$Q_1$~$Q_4$）| 将直流 $V_{in}$ 逆变为高频方波交流，施加于变压器原边 |
| ② 高频变压器（1:n）| 电压变换 + 电气隔离；双极性励磁，磁芯自动复位 |
| ③ 全波整流（$D_5$、$D_6$）| 将双极性方波整流为单向脉动直流，每个半周仅一个二极管导通 |
| ④ LC 低通滤波 | 滤除高频分量，输出平滑直流 $V_O$ |

**控制逻辑**：对角管交替导通（$Q_1+Q_4$ ↔ $Q_2+Q_3$），中间插入死区防止直通。调节占空比 $D$ 控制输出电压。

> **本质认知**：全桥隔离型 DC-DC 是 **Buck 变换器的隔离衍生拓扑**——全桥逆变 + 变压器 + 全波整流等效于 Buck 的开关管，后面的 LC 滤波和 Buck 完全一致。死区 = Buck 的 off-time。

### 1.3 优点

1. **高功率密度**——变压器磁芯双向利用，利用率是正激的两倍
2. **功率容量大**——开关管电压应力 $=V_{in}$，电流应力分摊到两桥臂，适合 500W~数kW
3. **磁芯自动复位**——对称双极性工作，无直流偏磁，无需额外复位绕组
4. **输出纹波频率高**——等效频率 $=2f_s$，滤波器体积小
5. **灵活控制**——支持 PWM、移相控制，后者可实现 ZVS 软开关

### 1.4 缺点

1. **开关数量多**——4 个 MOS 管 + 驱动电路，成本高于正激/反激
2. **高边驱动复杂**——$Q_1$、$Q_3$ 需自举或隔离栅极驱动
3. **直通风险**——同桥臂上下管若同时导通，$V_{in}$ 直接短路，必须设死区
4. **占空比丢失**——死区时间内能量不传输，最大有效 $D < 1$
5. **变压器偏磁隐患**——若正负半周伏秒积不对称，磁芯逐步偏磁饱和

### 1.5 适用场景

| 场景                    | 是否适合 | 原因                                     |
| --------------------- | :--: | -------------------------------------- |
| 通信电源（48V→12V/500W+）   | ✅ 最佳 | 全桥的主流落地场景，功率等级与电压应力完美匹配                |
| 服务器电源（400V→48V/1~3kW） |  ✅   | PFC 后级，高输入电压 + 大功率，MOS 管 $V_{in}$ 应力可控 |
| 电动汽车车载充电机             |  ✅   | 宽范围输入 + 隔离 + 大功率 + 支持移相 ZVS            |
| 大功率工业电源（>数kW）         |  ✅   | 唯一支持大功率 + 软开关的隔离 Buck                  |
| 小功率（<200W）            |  ❌   | 4 管 + 4 驱动成本过高，用正激/反激更经济               |
| 极度成本敏感（如消费电子）         |  △   | 可考虑半桥（省 2 管）或推挽（低压输入时）                 |

## 二、高频开关周期模态分析

设开关周期为 $T_s$，对角管 $Q_1+Q_4$ 导通时间为 $t_{on}$，$Q_2+Q_3$ 导通时间同样为 $t_{on}$，死区时间 $t_d = T_s/2 - t_{on}$。

电路工作在 **CCM（电感电流连续模式）** 下，一个完整周期分为 **4 个阶段**：2 个导通模态 + 2 个换相死区模态。

---

### 2.1 模态 1：$Q_1+Q_4$ 导通（正半周功率传输）——$[t_0, t_1]$

**(1) MOS 管状态**
- $Q_1$、$Q_4$ **导通**（栅极高电平）
- $Q_2$、$Q_3$ **关断**

**(2) 变压器原边电压与励磁电感状态**
- $v_T = +V_{in}$（原边上端 +，下端 -，与参考方向一致）
- 励磁电感 $L_M$ **充电**，$i_M$ 线性增大：$\frac{di_M}{dt} = \frac{V_{in}}{L_M}$
- 磁芯磁通 $\phi$ **增大**

**(3) 副边二极管状态**
- $D_5$：**导通**（正向偏置）——上绕组打点端为正，$D_5$ 阳极电位高于阴极
- $D_6$：**截止**（反向偏置）——承受反向电压约 $2nV_{in}$

**(4) 电流变化**

| 电流 | 变化趋势 | 说明 |
|------|----------|------|
| $i_1'$ | 线性增大 | $i_1' = n \cdot i$，反射负载电流 |
| $i_M$ | 线性增大 | 励磁电流，$i_M(t) = i_M(0) + \frac{V_{in}}{L_M}t$ |
| $i_1$ | 线性增大 | $i_1 = i_1' + i_M$ |
| $i_{D5}$ | 线性增大 | $i_{D5} = i$（全部电感电流流过 $D_5$）|
| $i_{D6}$ | $0$ | 截止 |
| $i$ | 线性增大 | $\frac{di}{dt} = \frac{nV_{in} - V_o}{L}$ |

**(5) 电压**
- $v_T = +V_{in}$
- $v_S = n \cdot V_{in}$（上正下负）
- $v_L = n V_{in} - V_O > 0$
- $v_O \approx$ 恒定（大电容近似恒压）

---

### 2.2 模态 2：死区换相（全部 MOS 关断）——$[t_1, t_2]$

**(1) MOS 管状态**
- $Q_1$、$Q_2$、$Q_3$、$Q_4$ **全部关断**

**(2) 变压器原边电压与励磁电感状态**
- 原边电流通过 $Q_2$、$Q_3$ 的体二极管续流
- $v_T \approx -V_{in}$（体二极管箝位），或 $v_T \approx 0$（取决于副边续流状态）
- $L_M$ **开始放电**，$i_M$ 线性下降
- 磁通 $\phi$ 开始**减小**

> **精确分析**：若副边 $D_5$、$D_6$ 同时续流（平分 $i$），则 $v_S = 0$，反射到原边 $v_T = 0$，$L_M$ 两端电压为 0，$i_M$ 保持不变直至下一模态。若体二极管先导通，则 $v_T = -V_{in}$，$i_M$ 快速下降。

**(3) 副边二极管状态**
- $D_5$ **导通**（续流）
- $D_6$ **导通**（续流）
- 两管同时导通，平分输出电感电流：$i_{D5} \approx i_{D6} \approx i/2$

**(4) 电流变化**

| 电流 | 变化趋势 | 说明 |
|------|----------|------|
| $i_1'$ | 快速下降 | 反射负载电流减小 |
| $i_M$ | 近似不变或下降 | 取决于 $v_T$ 实际值 |
| $i_1$ | 下降 | 原边总电流减小 |
| $i_{D5}$ | 下降（≈$i/2$）| 续流 |
| $i_{D6}$ | 下降（≈$i/2$）| 续流 |
| $i$ | 线性下降 | $\frac{di}{dt} = -\frac{V_O}{L}$ |

**(5) 电压**
- $v_S \approx 0$（两二极管同时续流箝位）
- $v_T \approx 0$（副边续流反射）
- $v_L = -V_O$（电感释能）
- $v_O \approx$ 恒定

> **▎关键理解：为什么 $v_L = -V_O$？——死区 = Buck 的 off-time**
>
> 分四步走：
>
> **① 输出电感电流 $i$ 不能突变。** 死区期间原边全部关断，没有能量从原边传过来，但 $i$ 必须继续流。
>
> **② $i$ 的续流回路迫使 $D_5$、$D_6$ 同时导通。** 电流路径：$L$ 右端 → 负载 → 地 → 中心抽头 → 分成两路，一路经上绕组 + $D_5$，一路经下绕组 + $D_6$ → 汇合回到 $L$ 左端。两管平分 $i$：$i_{D5} \approx i_{D6} \approx i/2$。
>
> **③ 两管同时导通 → 副边被"短路" → $v_S = 0$。** $D_5$ 和 $D_6$ 正向导通阻抗极低（毫欧级），变压器副边绕组两端被两只导通的二极管钳死，变压器想感应电压但根本抬不起来——就像推一扇已经打开的门，使不上劲。
>
> **④ KVL 回代：$v_L + V_O = v_S$，即 $v_L = v_S - V_O = 0 - V_O = -V_O$。**
>
> 这本质上就是 **Buck 变换器开关管关断时的续流阶段**——全桥隔离型 DC-DC 是 Buck 的衍生拓扑，死区 = Buck 的 off-time，电感通过二极管续流、两端电压被输出电容反向钳位。

---

### 2.3 模态 3：$Q_2+Q_3$ 导通（负半周功率传输）——$[t_2, t_3]$

与模态 1 对称，但电压/电流极性反转。

**(1) MOS 管状态**
- $Q_2$、$Q_3$ **导通**
- $Q_1$、$Q_4$ **关断**

**(2) 变压器原边电压与励磁电感状态**
- $v_T = -V_{in}$（原边上端 -，下端 +，与参考方向相反）
- $L_M$ **反向充电**，$i_M$ 负向线性增大（或从正值减小到负值）
- $\frac{di_M}{dt} = -\frac{V_{in}}{L_M}$
- 磁通 $\phi$ **反向增大**

**(3) 副边二极管状态**
- $D_6$ **导通**——下绕组下端为正，$D_6$ 阳极电位高于阴极
- $D_5$ **截止**——承受反向电压约 $2nV_{in}$

**(4) 电流变化**

| 电流 | 变化趋势 | 说明 |
|------|----------|------|
| $i_1'$ | 负向线性增大 | $i_1' = -n \cdot i$，电流反向流入原边 |
| $i_M$ | 负向线性增大 | 反向励磁 |
| $i_1$ | 负向线性增大 | $i_1 = i_1' + i_M$（均为负值）|
| $i_{D5}$ | $0$ | 截止 |
| $i_{D6}$ | 线性增大 | $i_{D6} = i$ |
| $i$ | 线性增大 | $\frac{di}{dt} = \frac{nV_{in} - V_O}{L}$ |

**(5) 电压**
- $v_T = -V_{in}$
- $v_S = n \cdot V_{in}$（整流后仍上正下负，全波整流的效果）
- $v_L = nV_{in} - V_O > 0$

---

### 2.4 模态 4：死区换相（全部 MOS 关断）——$[t_3, t_4]$

与模态 2 对称。

**(1) MOS 管状态**——全部关断

**(2) ~ (5)**——同模态 2，原边电流通过 $Q_1$、$Q_4$ 体二极管续流；$D_5$、$D_6$ 同时续流，$v_S = 0$，$i$ 线性下降。

---

### 2.5 关键波形汇总（一个周期）

```
        模态1   模态2   模态3   模态4
        Q1+Q4  死区    Q2+Q3  死区
vT:    +Vin     0     -Vin     0
vS:    nVin     0     nVin     0
vL:  nVin-Vo  -Vo   nVin-Vo  -Vo
 i:   上升     下降    上升    下降
 iM:  正增     持平   负增    持平
```

## 三、输入-输出电压关系推导

**方法**：电感 $L$ 伏秒平衡原理。

在半个开关周期 $T_s/2$ 内：
- 导通时间 $t_{on}$（模态 1 或 3）：$v_L = nV_{in} - V_O$
- 死区时间 $T_s/2 - t_{on}$（模态 2 或 4）：$v_L = -V_O$

**伏秒积分为零**：

$$(nV_{in} - V_O) \cdot t_{on} + (-V_O) \cdot \left(\frac{T_s}{2} - t_{on}\right) = 0$$

展开：

$$n V_{in} \cdot t_{on} - V_O \cdot t_{on} - V_O \cdot \frac{T_s}{2} + V_O \cdot t_{on} = 0$$

$$n V_{in} \cdot t_{on} = V_O \cdot \frac{T_s}{2}$$

$$V_O = n V_{in} \cdot \frac{2 t_{on}}{T_s}$$

**定义有效占空比** $D = \dfrac{2 t_{on}}{T_s}$，$0 < D < 1$（死区 $t_d > 0$，故 $D$ 严格 < 1）：

$$\boxed{V_O = n \cdot D \cdot V_{in}}$$

| 符号 | 含义 | 范围 |
|------|------|------|
| $V_{in}$ | 直流输入电压 | — |
| $n$ | 变压器匝比（副边/原边） | — |
| $D$ | 有效占空比，$D = 2t_{on}/T_s$ | $0 < D < 1$ |
| $V_O$ | 输出直流电压 | — |

> **补充**：单管占空比 $d = t_{on}/T_s$，范围 $0 < d < 0.5$。它与有效占空比的关系为 $D = 2d$。输出电压公式用有效占空比更为自然。

**结论**：该变换器本质是 **Buck 型变换器**，输出电压等于输入电压 × 匝比 × 占空比。通过调节 $D$ 或 $n$ 可实现降压/升压。

## 四、励磁电感 $L_M$ 的作用及其对电路的影响

### 4.1 $L_M$ 的本质

$L_M$ 是变压器磁芯磁化特性的等效电感，并联在原边绕组两端。它表征：**为了在磁芯中建立交变磁通，需要从电源吸收励磁电流**。

### 4.2 作用

| 作用 | 说明 |
|------|------|
| **建立磁通** | 磁芯中 $\phi \propto i_M$，$L_M$ 提供磁化安匝，使变压器能传递功率 |
| **能量暂存** | 每个半周储存磁场能量 $W = \frac{1}{2}L_M i_{M,pk}^2$，换相时释放 |
| **软开关辅助** | 在移相全桥中，$L_M$ 的储能帮助实现滞后桥臂 ZVS |
| **等效模型** | 在电路分析中，$L_M$ 将"理想变压器 + 磁化支路"解耦，便于计算 |

### 4.3 励磁电流 $i_M$ 对电路的影响

**1. 不参与功率传输**

$i_M$ 是纯无功电流，在原边循环流动，不耦合到副边。原边总电流 $i_1 = i_1' + i_M$，其中只有 $i_1' = n \cdot i$ 传递功率。

**2. 增加导通损耗**

$i_M$ 流过导通 MOS 管的沟道，产生额外的 $I^2 R_{DS(on)}$ 损耗。$L_M$ 越小 → $i_M$ 越大 → 损耗越大。

**3. 励磁电流峰值与设计约束**

$$i_{M,pk} = \frac{V_{in} \cdot t_{on}}{L_M} = \frac{V_{in} \cdot D}{2 L_M f_s}$$

- $L_M$ **过小**：$i_{M,pk}$ 大 → 损耗大、可能磁芯饱和
- $L_M$ **过大**：需要更多匝数或更大磁芯 → 体积/成本增加

**4. 死区期间的行为**

$i_M$ 在死区期间通过 MOS 管体二极管续流。若 $i_M$ 峰值够大，可为开关管结电容充放电提供能量，有助于实现 ZVS（零电压开关）。

**5. 磁芯饱和风险**

若正负半周不对称（占空比不等、开关速度差异），$i_M$ 出现直流分量 → 磁芯单向偏磁 → 累计饱和 → MOS 管过流失效。实际中需加隔直电容或电流模式控制抑制偏磁。

## 五、元件选型依据与计算

> **▎为什么选这个场景？**
>
> 以下选用 **通信电源模块**（48V 总线 → 12V 中间总线 / 板级负载）作为设计场景，这是全桥隔离 DC-DC 最典型的落地领域之一：
>
> - **48V 输入**是 ETSI / ITU-T 标准的通信设备直流供电电压，36~60V 为正常工作范围；
> - **12V 输出**是服务器板卡、路由线卡等最常见的中间总线电压；
> - **500W** 恰好处于正激/反激做不到、LLC 又嫌贵的区间——全桥是功率等级与成本的最佳折中；
> - **100kHz** 是 MOSFET 时代兼顾效率与磁元件体积的甜点频率。
>
> 所有公式保留符号形式，代入其他场景（车载 DC-DC / 充电桩模块等）时只需替换设计指标，推导流程完全复用。

### 5.1 设计指标

| 参数 | 符号 | 示例值 |
|------|------|--------|
| 输入电压 | $V_{in}$ | 48V（范围 36~60V）|
| 输出电压 | $V_O$ | 12V |
| 额定输出功率 | $P_O$ | 500W |
| 开关频率 | $f_s$ | 100kHz |
| 最大占空比 | $D_{max}$ | 0.8 |
| 效率目标 | $\eta$ | ≥ 92% |

### 5.2 公式速查卡

| 元件 | 核心公式 | 关键决定因素 |
|------|----------|-------------|
| 输入电容 | $C_{in} \geq \dfrac{P_O/(\eta V_{in}) \cdot D/f_s}{\Delta V_{in}}$ | RMS 纹波电流是瓶颈 |
| MOS 管 | $V_{DSS} \geq 1.5 \cdot V_{in,max}$ | 漏感尖峰裕量 |
| 变压器匝比 | $n = \dfrac{V_O}{D_{max} \cdot V_{in,min}}$ | 最低输入 + 最大占空比 |
| 整流二极管 | $V_{RRM} \geq 2 \cdot n \cdot V_{in,max}$ | 全波整流 ×2 系数 |
| 滤波电感 | $L = \dfrac{V_O(1-D_{min})}{2f_s \Delta i_L}$ | 最恶劣续流时间（$D_{min}$ 工况）|
| 滤波电容 | $C \geq \dfrac{\Delta i_L}{8 f_s \Delta V_O}$ | ESR 是瓶颈，非纯容抗 |

---

### 5.3 输入滤波电容 $C_{in}$

> **功率流位置**：输入侧第一级，吸收全桥斩波产生的脉冲电流。

#### RMS 电流约束（**选型瓶颈**）

原边全桥逆变以斩波方式从输入取电，输入电容承担脉冲纹波电流。等效 RMS 电流：

$$I_{Cin,rms} \approx I_{pri,rms} \cdot \sqrt{D_{max}(1 - D_{max})} = 13.5 \times \sqrt{0.8 \times 0.2} \approx 5.4\text{A}$$

**选型核心依据**：电容的 **额定 RMS 纹波电流**（datasheet 中的 Ripple Current Rating）≥ 5.4A，且考虑温升降额（×1.5 裕量 → ≥ 8A）。

#### 电容量校核

输入电压纹波 $\Delta V_{in} \leq 5\% \cdot V_{in} = 2.4\text{V}$：

$$C_{in} \geq \frac{I_{pri,avg} \cdot t_{on}}{\Delta V_{in}} = \frac{P_O/(\eta V_{in}) \cdot D_{max}/f_s}{\Delta V_{in}}$$

$$C_{in} \geq \frac{500/(0.92 \times 48) \times 0.8 / 100\times10^3}{2.4} \approx 39\mu\text{F}$$

RMS 电流是瓶颈，需并联低 ESR 电容。方案：**4 × 47µF/100V 高频低阻电解** 并联，总 ESR ≈ 10mΩ。

---

### 5.4 功率 MOS 管（$Q_1 \sim Q_4$）

> **功率流位置**：输入电容之后，变压器原边，构成全桥逆变桥臂。

#### 电压应力

任意 MOS 管截止时承受的最大漏源电压：

$$V_{DS,max} = V_{in,max} = 60\text{V}$$

计入 **1.5 倍安全裕量**（考虑漏感尖峰）：

$$V_{DSS,rated} \geq 1.5 \times 60 = 90\text{V} \quad\Rightarrow\quad \text{选 100V 或 150V 等级}$$

#### 电流应力

原边电流有效值（忽略 $i_M$ 纹波，近似估算）：

$$I_{pri,rms} \approx \frac{P_O}{\eta \cdot V_{in,min}} \cdot \sqrt{D_{max}} = \frac{500}{0.92 \times 36} \times \sqrt{0.8} \approx 13.5\text{A}$$

每个 MOS 管只在半个周期导通，其通态 RMS 电流：

$$I_{DS,rms} = I_{pri,rms} \cdot \sqrt{\frac{D_{max}}{2}} = 13.5 \times \sqrt{0.4} \approx 8.5\text{A}$$

峰值电流（计及 20% 电感纹波 + 励磁电流）：

$$I_{DS,peak} \approx 1.3 \times \frac{P_O}{\eta \cdot V_{in,min} \cdot D_{max}} = 1.3 \times \frac{500}{0.92 \times 36 \times 0.8} \approx 24.5\text{A}$$

#### 选型依据汇总

| 参数 | 计算值 | 选型要求 |
|------|--------|----------|
| $V_{DSS}$ | 60V（max）| ≥ 100V |
| $I_D$（连续）| ~13.5A | ≥ 40A @ $T_c=100^\circ\text{C}$ |
| $I_{D,pulse}$ | ~24.5A | ≥ 80A（脉宽受 $R_{DS(on)}$ 限制）|
| $R_{DS(on)}$ | — | ≤ 10mΩ（控制导通损耗 < 2W/管）|
| $Q_g$（总栅荷）| — | ≤ 50nC（保证 100kHz 下驱动损耗可接受）|

**推荐型号参考**：Infineon **IRFP4310Z**（$V_{DSS}=100\text{V}$，$R_{DS(on)}=6\text{m}\Omega$，$Q_g=50\text{nC}$）或同等级器件。

### 5.5 变压器匝比 $n$

> **功率流位置**：全桥逆变之后，整流之前——电压变换 + 隔离的核心。

由 $V_O = n \cdot D \cdot V_{in}$，在最恶劣工况（最低 $V_{in}$、最大 $D$）下仍能输出额定 $V_O$：

$$n = \frac{V_O}{D_{max} \cdot V_{in,min}} = \frac{12}{0.8 \times 36} \approx 0.417$$

取整 $n = 0.5$（原边 : 副边 = 1 : 0.5，即 2:1 降压）。校验最高输入时最小占空比：

$$D_{min} = \frac{V_O}{n \cdot V_{in,max}} = \frac{12}{0.5 \times 60} = 0.4$$

$D_{min} = 0.4$ 合理，变压器匝比 **$n = 0.5$**（或写成 $N_P : N_S = 1 : n = 2 : 1$）。

> 变压器励磁电感 $L_M$ 的深入分析见第四章——$L_M$ 的设计值直接影响励磁电流峰值、导通损耗和 ZVS 实现条件。

### 5.6 副边整流二极管（$D_5$、$D_6$）

> **功率流位置**：变压器副边之后，滤波电感之前——全波整流。

#### 电压应力

每个二极管截止时承受的反向峰值电压：

$$V_{RRM} \geq 2 \cdot n \cdot V_{in,max} = 2 \times 0.5 \times 60 = 60\text{V}$$

计入 **2 倍安全裕量**（考虑变压器漏感振荡）：

$$V_{RRM,rated} \geq 120\text{V} \quad\Rightarrow\quad \text{选 150V 或 200V 等级}$$

#### 电流应力

每个二极管仅在半个周期导通，平均电流：

$$I_{D,avg} = \frac{I_O}{2} = \frac{P_O / V_O}{2} = \frac{41.7}{2} \approx 20.8\text{A}$$

峰值电流（含纹波）：

$$I_{D,peak} \approx I_O + \frac{\Delta i_L}{2} \approx 41.7 + 4.2 = 45.9\text{A}$$

#### 选型依据汇总

| 参数 | 计算值 | 选型要求 |
|------|--------|----------|
| $V_{RRM}$ | 60V（理论）| ≥ 150V |
| $I_{F,avg}$ | ~21A | ≥ 30A（散热器条件下）|
| $I_{FSM}$ | — | ≥ 150A（浪涌）|
| $t_{rr}$ | — | ≤ 35ns（100kHz 快恢复）|
| $V_F$ | — | 越低越好（影响效率）|

**推荐类型**：**超快恢复二极管** 或 **SiC 肖特基二极管**（$V_{RRM}=200\text{V}$，无反向恢复，100kHz 以上首选 SiC）。

### 5.7 输出滤波电感 $L$

> **功率流位置**：整流之后，输出电容之前——LC 滤波的 L 环节。

#### 电感量计算

CCM 模式下，设定电流纹波率 $\Delta i_L \leq 20\% \cdot I_O$（典型 20%~40%）：

$$\Delta i_L = 0.2 \times I_O = 0.2 \times 41.7 \approx 8.3\text{A}$$

在模态 2/4（死区）期间，$v_L = -V_O$，电感放电。最恶劣工况为 $D_{min}$（续流时间最长）——详见第 2.2 节"死区 = Buck off-time"的分析：

$$L = \frac{V_O \cdot (T_s/2 - t_{on,max})}{\Delta i_L} = \frac{V_O \cdot (1 - D_{min})}{2 f_s \cdot \Delta i_L}$$

代入：$V_O = 12\text{V}$，$D_{min} = 0.4$，$f_s = 100\text{kHz}$，$\Delta i_L = 8.3\text{A}$

$$L = \frac{12 \times (1 - 0.4)}{2 \times 100 \times 10^3 \times 8.3} \approx 4.3\mu\text{H}$$

取标称值 **$L = 5\mu\text{H}$**（或 $4.7\mu\text{H}$）。

#### 磁芯与绕组

| 参数 | 值 |
|------|-----|
| 电感量 | $5\mu\text{H}$ |
| 峰值电流 | $I_{L,pk} = I_O + \Delta i_L/2 \approx 45.9\text{A}$ |
| RMS 电流 | $I_{L,rms} \approx I_O = 41.7\text{A}$ |
| 推荐磁芯 | 铁硅铝（Sendust）或铁氧体（加气隙），如 KS157-060A |
| 储能校验 | $E = \frac{1}{2}LI_{pk}^2 = \frac{1}{2} \times 5\times10^{-6} \times 45.9^2 \approx 5.3\text{mJ}$ |

**匝数估算**（铁硅铝 KS157-060A，$A_L = 44\text{nH}/N^2$）：

$$N_L = \sqrt{\frac{L}{A_L}} = \sqrt{\frac{5000}{44}} \approx 10.7 \Rightarrow 11\text{ 匝}$$

### 5.8 输出滤波电容 $C$

> **功率流位置**：滤波电感之后，负载之前——LC 滤波的 C 环节，也是功率流的最后一环。

#### 电容量计算

由输出电压纹波 $\Delta V_O \leq 1\% \cdot V_O = 120\text{mV}$（峰峰值），纹波主要由电容 ESR 和容抗共同决定。

由电荷守恒（电感纹波电流全部由电容吸收）：

$$C_{min} = \frac{\Delta i_L}{8 f_s \cdot \Delta V_{O,pp}} = \frac{8.3}{8 \times 100\times10^3 \times 0.12} \approx 86\mu\text{F}$$

计入 ESR 效应和降额，取 **2~3 倍裕量**：$C \geq 220\mu\text{F}$。

#### ESR 约束

ESR 引起的纹波分量 $\Delta V_{O,ESR} = \Delta i_L \cdot R_{ESR}$。若要求 ESR 纹波不超过 60mV：

$$R_{ESR} \leq \frac{60\text{mV}}{8.3\text{A}} \approx 7.2\text{m}\Omega$$

**实现方式**：多只低 ESR 电解电容并联，或使用 MLCC + 电解混合滤波。

| 方案 | 配置 | ESR |
|------|------|-----|
| 电解并联 | 3 × 100µF/25V 高频低阻型 | ~15mΩ |
| 混合 | 2 × 100µF 电解 + 2 × 10µF MLCC | < 5mΩ |

## 六、快速小结

| 项目 | 结论 |
|------|------|
| 拓扑名称 | 全桥隔离型 DC-DC 变换器（隔离型 Buck） |
| 电路本质 | 全桥逆变 → 变压器隔离/变压 → 全波整流 → LC 滤波 |
| 模态数 | 4 个/周期（2 导通 + 2 死区） |
| 核心公式 | $V_O = n \cdot D \cdot V_{in}$ |
| 有效占空比 | $D = 2t_{on}/T_s$，工程范围 0.1~0.85 |
| 单管占空比 | $d = t_{on}/T_s < 0.5$ |
| $L_M$ 作用 | 励磁储能、无功电流、辅助软开关 |
| 变压器匝比 | $n = 0.5$（2:1 降压） |
| MOS 管 | 100V/40A, Rds(on)≤10mΩ（4 只） |
| 整流二极管 | 150V/30A 超快恢复或 SiC（2 只） |
| 滤波电感 | $5\mu\text{H}$ / 46A 铁硅铝 |
| 滤波电容 | ≥220µF / 25V 低 ESR |
| 输入电容 | 4×47µF / 100V（RMS 电流是瓶颈） |
