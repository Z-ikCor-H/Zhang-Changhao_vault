# 推挽式隔离 Buck 变换器——拓扑、模态与选型分析

---

## 一、拓扑概述

### 1.1 拓扑名称

**推挽式隔离 Buck 变换器**（Push-Pull Isolated Buck Converter），亦称 **推挽正激变换器**。可视为"两个正激变换器的反向并联"或"原边中心抽头的全桥变体"。

### 1.2 电路结构与宏观工作机理

| 环节 | 功能 |
|------|------|
| ① 推挽开关（$Q_1$、$Q_2$）| 两管交替导通，分别激励变压器原边上下两个半绕组，将直流 $V_g$ 斩波为双极性方波 |
| ② 高频变压器（中心抽头原边，1:n）| 电压变换 + 电气隔离；双极性对称励磁，磁芯在 I/III 象限交替工作 |
| ③ 全波整流（$D_1$、$D_2$）| 将双极性方波整流为单向脉动直流，每半周仅一个二极管导通 |
| ④ LC 滤波 | 滤除高频分量，输出平滑直流 $V$ |

**控制逻辑**：$Q_1$、$Q_2$ 交替导通，单管占空比 $D < 0.5$（必须留死区防直通）。由于全波整流，每个开关周期有两个能量传输脉冲，等效频率 $= 2f_s$。

> **本质认知**：推挽同样是 Buck 的隔离衍生拓扑。原边中心抽头 + 两管交替 = 变压器原边获得双极性 ±$V_g$ 激励，副边全波整流后等效于 Buck 的开关管输出。

### 1.3 优点

1. **磁芯利用率最高**——双向励磁（I/III 象限），$\Delta B$ 摆幅为正激的 2 倍，同等功率磁芯体积最小
2. **电流自然分担**——两管交替导通，电流应力分散到两个开关管和两个半绕组
3. **开关管数量少**——仅 2 个 MOS 管，驱动只需两路（均需隔离）
4. **低压场景电压应力可控**——$V_g \leq 48\text{V}$ 时，$2V_g \leq 96\text{V}$，选 150V MOS 即可
5. **全波整流效率高**——每个时刻仅一个二极管压降在回路中（全桥整流有 2 个）

### 1.4 缺点

1. **开关管电压应力高**——$V_{DS} = 2V_g$，是半桥/全桥的 2 倍，高压输入时不可接受
2. **变压器需中心抽头**——绕制复杂度增加，漏感增大，两个半绕组需严格对称
3. **偏磁风险**——驱动不对称 → 正负半周伏秒积不等 → 磁芯单向饱和 → 开关管烧毁（推挽的头号失效模式）
4. **驱动需隔离**——$Q_1$、$Q_2$ 源极电位不同，需两路隔离驱动（变压器驱动或光耦 + 自举）
5. **电压应力限制功率上限**——输入电压 > 100V 后 $2V_g > 200\text{V}$，高压 MOS 的 $R_{DS(on)}$ 和开关损耗急剧恶化

### 1.5 适用场景与选型逻辑

| 场景 | 是否适合推挽 | 原因 |
|------|:---------:|------|
| 低压输入（12~48V）+ 中功率（100W~1kW）| ✅ 最佳 | $2V_g$ 应力可控，磁芯利用率最高 |
| 高压输入（>200V）+ 任意功率 | ❌ | $2V_g$ 过高 → 用半桥/全桥 |
| 输入 >100V + 大功率（>1kW）| ❌ | 用全桥，电压应力低 + 可 ZVS |
| 低压 + 小功率（<100W）| △ 可但不经济 | 反激更简单便宜 |

**选择逻辑**：低压（<100V）+ 中大功率 → 推挽；高压（>200V）+ 中功率 → 半桥；高压 + 大功率 → 全桥。

## 二、高频开关周期模态分析

开关周期 $T_s$，$Q_1$ 导通时间 = $Q_2$ 导通时间 = $DT_s$（$D$ 为单管占空比），死区 $t_d = T_s/2 - DT_s$。CCM 下一个完整周期分 4 个阶段。

> **注意**：推挽的 $D$ 指单管占空比（导通时间 / $T_s$），$D < 0.5$。有效占空比 $D_{eff} = 2D$（每周期两个功率脉冲）。

设定参考地：$V_g$ 负端 = 0V，中心抽头 = $+V_g$。原边上下半绕组匝数相同。

---

### 2.1 模态 1：$Q_1$ 导通（上半周功率传输）——$[t_0, t_1]$

**(1) 开关管状态**
- $Q_1$ **导通**，$Q_2$ **关断**

**(2) 变压器原边**
- $Q_1$ 导通将上半绕组顶端拉到 0V，中心抽头固定为 $+V_g$
- 上半绕组：下端（打点端，中心抽头）= $+V_g$，上端 = 0V → $v_{T,upper} = V_g$（下正上负，与参考方向一致）
- 下半绕组：同名端感应，$v_{T,lower} = V_g$（下正上负），$Q_2$ 漏极 = 中心抽头 + $V_g = 2V_g$
- 激磁电流从中心抽头流入打点端 → 磁芯正向激磁，磁通 $\phi$ **正向增大**

> **电流路径**：$V_g(+) \to$ 中心抽头 $\to$ 上半绕组（打点端入）$\to Q_1 \to V_g(-)$

**(3) 副边二极管**
- 同名端规则：原边打点端（下端）为正 → 副边打点端（上端）也为正
- $D_1$：阳极接打点端（正电位）→ **导通**，$i_{D1}(t) > 0$
- $D_2$：阳极接非打点端（负电位）→ **截止**，反向电压 ≈ $2nV_g$

**(4) 电流变化**

| 电流 | 趋势 | 说明 |
|------|------|------|
| $i_{Q1}$ | 线性增大 | 包含反射负载电流 + 激磁电流 |
| $i_M$ | 正向线性增大 | $\frac{di_M}{dt} = \frac{V_g}{L_M}$ |
| $i_{D1}$ | 线性增大 | $i_{D1} = i$ |
| $i_{D2}$ | $0$ | 截止 |
| $i$ | 线性增大 | $\frac{di}{dt} = \frac{nV_g - V}{L}$ |

**(5) 电压**
- $v_T = V_g$（上半绕组）
- $v_S = nV_g$（上正下负）
- $v_L = nV_g - V > 0$（电感储能）
- $v_O \approx$ 恒定

---

### 2.2 模态 2：死区（$Q_1$、$Q_2$ 均关断）——$[t_1, t_2]$

**(1) 开关管状态**
- $Q_1$、$Q_2$ **全部关断**

**(2) 变压器原边**
- 原边无主动激励，激磁电流通过 $Q_2$ 体二极管续流
- $v_T \approx 0$（副边续流反射回原边，箝位）
- $L_M$ 两端电压 ≈ 0 → $i_M$ **近似不变**

**(3) 副边二极管**
- $D_1$ **导通**（续流），$D_2$ **导通**（续流）
- 两管平分输出电感电流：$i_{D1} \approx i_{D2} \approx i/2$

**(4) 电流变化**

| 电流 | 趋势 | 说明 |
|------|------|------|
| $i$ | 线性下降 | $\frac{di}{dt} = -\frac{V}{L}$ |
| $i_{D1}$、$i_{D2}$ | 下降 | 各分一半，同时续流 |

**(5) 电压**
- $v_S \approx 0$（$D_1$、$D_2$ 同时导通，箝位副边）
- $v_T \approx 0$（副边短路反射）
- $v_L = v_S - V = -V$（电感释能）

> **▎关键理解：为什么 $v_L = -V$？**
>
> 与全桥/半桥完全相同的机理——死区期间副边两只二极管同时续流，$v_S$ 被箝位到 0，KVL 给出 $v_L = -V$。推挽的特别之处在于：**每个周期有两次死区**，电感放电时间 = $T_s - 2DT_s = (1-2D)T_s$，比全桥/半桥的放电时间更长（后者为 $(1-D)T_s/2$ 每半周）。详见第三节伏秒推导。

---

### 2.3 模态 3：$Q_2$ 导通（下半周功率传输）——$[t_2, t_3]$

**(1) 开关管状态**
- $Q_2$ **导通**，$Q_1$ **关断**

**(2) 变压器原边**
- $Q_2$ 导通将下半绕组底端拉到 0V，中心抽头 = $+V_g$
- 下半绕组：上端（中心抽头，非打点端）= $+V_g$，下端（打点端）= 0V
- 电压方向：上正下负，与 $v_T$ 参考方向（下正上负）**相反** → $v_{T,lower} = -V_g$
- 上半绕组：同名端感应，$v_{T,upper} = -V_g$
- 激磁电流反向 → 磁芯反向激磁，磁通 $\phi$ **反向增大**

> **电流路径**：$V_g(+) \to$ 中心抽头 $\to$ 下半绕组（非打点端入，打点端出）$\to Q_2 \to V_g(-)$

**(3) 副边二极管**
- 同名端规则：原边打点端（下端）= 0V（相对为负）→ 副边打点端（上端）也为负
- $D_1$：阳极接打点端（负电位）→ **截止**，反向电压 ≈ $2nV_g$
- $D_2$：阳极接非打点端（正电位）→ **导通**，$i_{D2}(t) > 0$

**(4) 电流变化**

| 电流 | 趋势 | 说明 |
|------|------|------|
| $i_{Q2}$ | 负向线性增大 | 反射负载电流 + 反向激磁电流 |
| $i_M$ | 负向线性增大 | $\frac{di_M}{dt} = -\frac{V_g}{L_M}$ |
| $i_{D2}$ | 线性增大 | $i_{D2} = i$ |
| $i_{D1}$ | $0$ | 截止 |
| $i$ | 线性增大 | $\frac{di}{dt} = \frac{nV_g - V}{L}$ |

**(5) 电压**
- $v_T = -V_g$（下半绕组，与参考方向相反）
- $v_S = nV_g$（全波整流，输出极性不变，仍上正下负）
- $v_L = nV_g - V > 0$

---

### 2.4 模态 4：死区（$Q_1$、$Q_2$ 均关断）——$[t_3, t_4]$

与模态 2 对称。$Q_1$ 体二极管续流，$D_1$、$D_2$ 同时续流，$v_S = 0$，$v_L = -V$，$i$ 线性下降。

---

### 2.5 关键波形汇总（一个周期）

```
        模态1   模态2   模态3   模态4
         Q1    死区     Q2    死区
         DTs    Td      DTs    Td
vT:     +Vg     0      -Vg     0
vS:     nVg     0      nVg     0
vL:   nVg-V    -V    nVg-V    -V
 i:    上升    下降    上升    下降
 iM:   正增    持平    负增    持平
```

**与全桥/半桥的关键区别**：
- 推挽 $v_T = \pm V_g$（与全桥幅值相同，但仅需 2 个开关管）
- 半桥 $v_T = \pm V_{in}/2$（幅值减半）
- 推挽每周期 **2 个功率脉冲** + **2 段死区**，等效滤波频率 $= 2f_s$

### 2.6 磁通双向平衡原理

- 模态 1：磁通正向增长 $\Delta\Phi_1 \propto V_g \cdot DT_s$
- 模态 3：磁通反向增长 $\Delta\Phi_3 \propto V_g \cdot DT_s$（大小相等、方向相反）
- 一个完整周期净磁通变化为零 → **磁芯在 B-H 曲线的 I/III 象限对称工作**
- $\Delta B$ 摆幅为单向励磁拓扑（正激）的 2 倍，磁芯利用率更高
- **若 $D_1 \neq D_2$**（驱动不对称），则正反向伏秒积不等 → 直流偏磁 → 磁芯逐步饱和（详见第四章）

## 三、输入-输出电压关系推导

**方法**：电感 $L$ 伏秒平衡（一个完整开关周期内）。

模态 1 或 3（导通，合计 $2DT_s$）：$v_L = nV_g - V$

模态 2 或 4（死区，合计 $(1-2D)T_s$）：$v_L = -V$

$$(nV_g - V) \cdot 2DT_s + (-V) \cdot (1-2D)T_s = 0$$

$$2D nV_g - 2DV - V + 2DV = 0$$

$$2D nV_g = V$$

$$\boxed{V = 2nD V_g}$$

| 符号 | 含义 | 范围 |
|------|------|------|
| $V_g$ | 直流输入电压 | — |
| $n$ | 变压器匝比（副边/半原边） | — |
| $D$ | 单管占空比（$t_{on}/T_s$）| $0 < D < 0.5$ |
| $2D$ | 有效占空比（每周期两个脉冲）| $0 < 2D < 1$ |
| $V$ | 输出电压 | — |

### 关键约束

- **$D < 0.5$**：两管不能重叠导通，单管最大占空比 50%
- 实际 $D_{\max} \approx 0.45$，留死区防止直通
- 匝比 $n$ 的设计需在最恶劣工况（最低 $V_g$、最大 $D$）下仍能达到目标输出电压

### 推挽 vs 全桥 vs 半桥：电压传输比对比

| 拓扑 | $V_O$ 公式 | 单管 $D$ 范围 | 每周期功率脉冲数 |
|------|-----------|:----------:|:------------:|
| 推挽 | $V = 2nDV_g$ | $0 < D < 0.5$ | 2 |
| 全桥 | $V_O = nDV_{in}$ | $0 < D_{eff} < 1$ | 2 |
| 半桥 | $V_O = nDV_{in}/2$ | $0 < D_{eff} < 1$ | 2 |

> 推挽 $V = 2nDV_g$ 和全桥 $V_O = nD_{eff}V_{in}$ 数学上等价（令 $D_{eff}=2D$ 即 $V = nD_{eff}V_g$）——推挽用 2 个开关管实现了跟全桥 4 个开关管相同的电压传输比。代价是开关管承受 $2V_g$。

## 四、偏磁问题——推挽的头号失效模式

偏磁是推挽电路最核心的可靠性问题，也是它区别于半桥/全桥的最显著弱点。

### 4.1 产生原因

| 原因 | 机理 |
|------|------|
| 驱动信号不对称 | $Q_1$ 与 $Q_2$ 导通时间不等 → 正反向伏秒积 $V_g D_1T_s \neq V_g D_2T_s$ |
| 两半绕组 DCR 不一致 | 绕制工艺偏差 → 铜损不等 → 等效激励电压不对称 |
| $R_{DS(on)}$ 差异或温度不均 | $Q_1$ 与 $Q_2$ 导通压降不同 → 实际施加在绕组上的电压不等 |
| 副边二极管 $V_F$ 不一致 | $D_1$ 与 $D_2$ 正向压降差异 → 反射到原边的等效负载不对称 |

以上任一因素导致正反向伏秒积不等 → 每个周期净磁通增量 > 0 → 数个周期后磁芯进入饱和。

### 4.2 连锁反应（正反馈恶性循环）

```
驱动不对称 → 偏磁累积 → 磁芯趋向饱和
→ 饱和侧激磁电感骤降 → 该侧开关管电流尖峰
→ 电流采样触发过流保护（若有）/ 开关管过热烧毁（若无）
```

**其他效应**：
- 输出电压纹波出现 $f_s$ 分量（正常为 $2f_s$）
- 变压器可听噪声（磁致伸缩不对称）
- EMI 恶化（差模和共模噪声增加）

### 4.3 抑制思路

| 方法 | 原理 | 代价 |
|------|------|------|
| **峰值电流模式控制** | 逐周期检测原边电流，自动平衡占空比 | 控制环路复杂度增加 |
| **隔直电容** | 在变压器原边串联电容，阻断直流偏磁电流 | 增加电压应力、额外损耗 |
| **变压器气隙** | 降低有效磁导率 $\mu_e$，增大偏磁容限 | 激磁电流增大 → 铜损增加 |
| **严格对称设计** | PCB layout 对称、选配 $R_{DS(on)}$ 一致的 MOS 管 | 选配成本、layout 约束 |
| **磁通复位检测** | 辅助绕组监测磁通，过偏时强制保护 | 额外绕组 + 检测电路 |

> **对比**：半桥通过分压电容天然隔直，全桥可通过串联隔直电容解决——推挽没有这个天然机制，偏磁抑制需要主动控制或精心设计。这是推挽拓扑的**固有代价**。

## 五、元件选型依据与计算

> **▎为什么选这个场景？**
>
> 以下选用 **车载 DC-DC 转换器**（24V 商用车电气系统 → 12V 设备供电）作为设计场景，这是推挽拓扑最经典的落地领域：
>
> - **24V 输入**是商用车（卡车/客车）标准电气系统电压，18~32V 为正常波动范围；
> - **12V 输出**为车载电子设备（行车记录仪、导航、音响等）的标准供电电压；
> - **300W** 处于推挽的最佳功率区间（100W~1kW），电流适中（25A 输出）；
> - **推挽的天然优势在此场景最大化**：低压输入 → $2V_g \leq 64\text{V}$ 应力可控；大电流 → 两管分流 + 磁芯利用率高；
> - 对比全桥的 48V→12V/500W 场景，体会"**场景决定拓扑选择**"。
>
> 所有公式保留符号形式，可直接代入其他设计指标复用。

### 5.1 设计指标

| 参数 | 符号 | 示例值 |
|------|------|--------|
| 输入电压 | $V_g$ | 24V（范围 18~32V）|
| 输出电压 | $V$ | 12V |
| 额定输出功率 | $P_O$ | 300W |
| 开关频率 | $f_s$ | 100kHz |
| 最大单管占空比 | $D_{max}$ | 0.45（$D < 0.5$，留死区）|
| 效率目标 | $\eta$ | ≥ 92% |

### 5.2 公式速查卡

| 元件    | 核心公式                                         | 关键决定因素              |
| ----- | -------------------------------------------- | ------------------- |
| MOS 管 | $V_{DSS} \geq 2 \cdot V_{g,max} \times 1.5$  | **$2V_g$ 应力是推挽的标签** |
| 变压器匝比 | $n = \dfrac{V}{2D_{max} \cdot V_{g,min}}$    | 最低输入 + 最大占空比        |
| 整流二极管 | $V_{RRM} \geq 2n \cdot V_{g,max} \times 1.5$ | 全波中心抽头 ×2 系数        |
| 滤波电感  | $L = \dfrac{V(1-2D_{min})}{2f_s \Delta i_L}$ | 死区时间 $= (1-2D)T_s$  |
| 滤波电容  | $C \geq \dfrac{\Delta i_L}{8 f_s \Delta V}$  | ESR 是瓶颈             |
| 输入电容  | $I_{Cin,rms}$ 约束                             | 两管交替斩波              |

---

### 5.3 输入滤波电容 $C_{in}$

> **功率流位置**：输入侧第一级，吸收推挽斩波产生的脉冲电流。

输入平均电流：

$$I_{in,avg} = \frac{P_O}{\eta \cdot V_{g,min}} = \frac{300}{0.92 \times 18} \approx 18.1\text{A}$$

推挽的输入电流纹波频率为 $2f_s$（每周期两次取电），RMS 纹波电流估算：

$$I_{Cin,rms} \approx I_{in,avg} \cdot \sqrt{2D_{max}(1 - 2D_{max})} = 18.1 \times \sqrt{0.9 \times 0.1} \approx 5.4\text{A}$$

1.5 倍温升降额 → 需额定 RMS ≥ 8A。输入电压纹波 ≤ 5%·$V_g$ = 1.2V：

$$C_{in} \geq \frac{I_{in,avg} \cdot D_{max} / f_s}{\Delta V_g} = \frac{18.1 \times 0.45 / 10^5}{1.2} \approx 68\mu\text{F}$$

RMS 电流是瓶颈。方案：**4 × 47µF/50V 高频低阻电解**并联。

---

### 5.4 功率 MOS 管（$Q_1$、$Q_2$）

> **功率流位置**：输入电容之后，变压器原边——推挽斩波，两管交替导通。

#### 电压应力（推挽的标志性特征）

$Q_1$ 导通时，$Q_2$ 漏极电压 = 中心抽头 $V_g$ + 下半绕组感应电压 $V_g = 2V_g$：

$$V_{DS,max} = 2 \cdot V_{g,max} = 2 \times 32 = 64\text{V}$$

计入 **1.5 倍安全裕量**：$V_{DSS,rated} \geq 96\text{V}$ → 选 **150V** 等级。

> **这是推挽的标签**——2 倍输入电压应力。$V_g=24\text{V}$ 时 $2V_g=48\text{V}$ 还很安全；但若 $V_g=200\text{V}$ 则需 600V MOS——这就是为什么推挽只适合低压输入。

#### 电流应力

反射负载电流峰值（忽略纹波和激磁电流，近似估算）：

$$I_{refl,pk} = n \cdot I_O = n \cdot \frac{P_O}{V} = 0.75 \times 25 = 18.75\text{A}$$

每管 RMS 电流（单管导通占空比 $D$）：

$$I_{DS,rms} \approx I_{refl,pk} \cdot \sqrt{D_{max}} = 18.75 \times \sqrt{0.45} \approx 12.6\text{A}$$

峰值电流（计及 20% 电感纹波 + 激磁电流裕量）：

$$I_{DS,peak} \approx 1.3 \times \left( nI_O + \frac{\Delta i_L}{2} \right) = 1.3 \times (18.75 + 2.5) \approx 27.6\text{A}$$

#### 选型汇总

| 参数 | 计算值 | 选型要求 |
|------|--------|----------|
| $V_{DSS}$ | 64V（max）| ≥ 150V（**×2 系数 + 裕量**）|
| $I_D$（连续）| ~12.6A | ≥ 30A @ $T_c=100^\circ\text{C}$ |
| $I_{D,pulse}$ | ~27.6A | ≥ 60A |
| $R_{DS(on)}$ | — | ≤ 15mΩ（控制导通损耗）|
| $Q_g$ | — | ≤ 30nC（100kHz，驱动损耗可控）|

**推荐**：Infineon **IRFP4368**（$V_{DSS}=150\text{V}$，$R_{DS(on)}=1.85\text{m}\Omega$，$I_D=93\text{A}$）或同等级低压大电流 MOS。

> **对比全桥**（48V→12V/500W）：全桥 MOS 选 100V，推挽选 150V——输入电压更低，MOS 耐压反而更高，这就是 $2V_g$ 的代价。

---

### 5.5 变压器匝比 $n$

> **功率流位置**：推挽开关之后，整流之前——电压变换 + 隔离的核心。原边为带中心抽头的双半绕组结构。

在最恶劣工况（最低 $V_g$、最大 $D$）下满足输出电压：

$$V = 2n D_{max} V_{g,min} \quad\Rightarrow\quad n = \frac{V}{2 D_{max} \cdot V_{g,min}} = \frac{12}{2 \times 0.45 \times 18} \approx 0.74$$

取整 $n = 0.75$。校验最高输入时最小占空比：

$$D_{min} = \frac{V}{2n \cdot V_{g,max}} = \frac{12}{2 \times 0.75 \times 32} = 0.25$$

$D_{min} = 0.25$ 合理（远离 0，控制分辨率足够）。

> $n = 0.75$ 意味着副边匝数 / 半原边匝数 = 0.75:1。若半原边取 4 匝，则副边取 3 匝。

#### 磁芯选型要点

- 双向励磁 → $\Delta B = 2B_{max}$，铁氧体 $B_{max}$ 取 0.15~0.2T（高频受限于铁损）
- 推荐 AP 法估算磁芯尺寸，材质 PC40/PC44（100kHz）
- **必须加气隙**：增大偏磁容限（见第四章），代价是 $L_M$ 减小、激磁电流增大
- 工程折中：气隙使 $L_M$ 下降不超过 20%

---

### 5.6 副边整流二极管（$D_1$、$D_2$）

> **功率流位置**：变压器副边之后，滤波电感之前——全波整流，中心抽头结构。

#### 电压应力

全波整流中心抽头结构，二极管承受 2 倍副边绕组电压峰值：

$$V_{RRM} \geq 2 \cdot n \cdot V_{g,max} = 2 \times 0.75 \times 32 = 48\text{V}$$

计入 **2 倍安全裕量**（考虑变压器漏感振荡）：

$$V_{RRM,rated} \geq 96\text{V} \quad\Rightarrow\quad \text{选 150V 等级}$$

#### 电流应力

每个二极管仅在半个周期导通（对应一个开关管导通），平均电流：

$$I_{D,avg} = I_O \cdot D_{max} = 25 \times 0.45 \approx 11.3\text{A}$$

死区期间两管同时续流，各承担 $I_O/2$。峰值电流（含纹波）：

$$I_{D,peak} = I_O + \frac{\Delta i_L}{2} = 25 + 2.5 = 27.5\text{A}$$

#### 选型汇总

| 参数 | 计算值 | 选型要求 |
|------|--------|----------|
| $V_{RRM}$ | 48V（理论）| ≥ 150V |
| $I_{F,avg}$ | ~11.3A | ≥ 20A |
| $I_{FSM}$ | — | ≥ 100A（浪涌）|
| $t_{rr}$ | — | ≤ 35ns（100kHz 快恢复）|

**推荐**：150V/20A 超快恢复二极管（STTH2002C 或同等），或 SiC 肖特基（$V_{RRM}=200\text{V}$，零反向恢复）。

---

### 5.7 输出滤波电感 $L$

> **功率流位置**：整流之后，输出电容之前——LC 滤波的 L 环节。

#### 电感量计算

CCM 模式下，设定电流纹波率 $\Delta i_L \leq 20\% \cdot I_O$：

$$\Delta i_L = 0.2 \times 25 = 5.0\text{A}$$

在死区（模态 2/4）期间，$v_L = -V$，电感放电。**推挽每周期有两次死区**，电感放电总时间 $= (1-2D)T_s$。最恶劣工况为 $D_{min}$（放电时间最长）：

$$L = \frac{V \cdot (1 - 2D_{min}) \cdot T_s}{2 \cdot \Delta i_L} = \frac{V \cdot (1 - 2D_{min})}{2 f_s \cdot \Delta i_L}$$

代入：$V = 12\text{V}$，$D_{min} = 0.25$，$f_s = 100\text{kHz}$，$\Delta i_L = 5.0\text{A}$

$$L = \frac{12 \times (1 - 0.5)}{2 \times 10^5 \times 5.0} = \frac{12 \times 0.5}{10^6} = 6.0\mu\text{H}$$

取标称值 **$L = 6.8\mu\text{H}$**。

> **与全桥的关键差异**：推挽的电感公式分母中有 $(1-2D)$ 而非 $(1-D)$——因为推挽的死区是以 $T_s$ 为周期计算的（全桥以 $T_s/2$ 为周期）。

#### 磁芯与绕组

| 参数 | 值 |
|------|-----|
| 电感量 | $6.8\mu\text{H}$ |
| 峰值电流 | $I_{L,pk} = I_O + \Delta i_L/2 = 27.5\text{A}$ |
| RMS 电流 | $I_{L,rms} \approx I_O = 25\text{A}$ |
| 推荐磁芯 | 铁硅铝（Sendust），如 KS157-060A |
| 储能校验 | $E = \frac{1}{2}LI_{pk}^2 = \frac{1}{2} \times 6.8\times10^{-6} \times 27.5^2 \approx 2.6\text{mJ}$ |

**匝数估算**（铁硅铝 KS157-060A，$A_L = 44\text{nH}/N^2$）：

$$N_L = \sqrt{\frac{L}{A_L}} = \sqrt{\frac{6800}{44}} \approx 12.4 \Rightarrow 13\text{ 匝}$$

---

### 5.8 输出滤波电容 $C$

> **功率流位置**：滤波电感之后，负载之前——功率流的最后一环。

#### 电容量计算

输出电压纹波 $\Delta V \leq 1\% \cdot V = 120\text{mV}$（峰峰值）：

$$C_{min} = \frac{\Delta i_L}{8 f_s \cdot \Delta V_{pp}} = \frac{5.0}{8 \times 10^5 \times 0.12} \approx 52\mu\text{F}$$

计入 ESR 效应和降额，取 **2~3 倍裕量**：$C \geq 150\mu\text{F}$。

#### ESR 约束

$$R_{ESR} \leq \frac{60\text{mV}}{5.0\text{A}} \approx 12\text{m}\Omega$$

**方案**：2 × 100µF/25V 高频低阻电解 + 2 × 10µF MLCC，ESR < 10mΩ。

## 六、拓扑对比：推挽 vs 半桥 vs 全桥

| 特性 | 推挽 | 半桥 | 全桥 |
|------|------|------|------|
| 开关管数量 | 2 | 2 | 4 |
| 开关管电压应力 | **$2V_g$** | $V_g$ | $V_g$ |
| 变压器结构 | 中心抽头原边 | 简单原边 | 简单原边 |
| 原边电压幅值 | $\pm V_g$ | $\pm V_g/2$ | $\pm V_g$ |
| 电压传输比 | $V = 2nDV_g$ | $V_O = nDV_{in}/2$ | $V_O = nDV_{in}$ |
| 磁芯利用率 | ★★★（I/III 象限）| ★★★（I/III 象限）| ★★★（I/III 象限）|
| 隔直机制 | 无（需主动控制）| **分压电容天然隔直** | 需外串隔直电容 |
| 偏磁风险 | **高（头号失效模式）**| 低 | 中 |
| 功率范围 | 100W~1kW | 100~500W | 500W~10kW+ |
| 最佳场景 | 低压大电流 | 中压中功率 | 高压大功率 |
| 核心代价 | $2V_g$ 应力 + 偏磁 | 电流翻倍 + 分压电容 | 4 管 + 4 驱动成本 |

### 选择逻辑

```
输入电压 < 100V ?
├── 是 → 功率 > 500W ? → 全桥
│       功率 100~500W → 推挽（磁芯最小，2Vg 应力可控）
│       功率 < 100W  → 反激/正激
└── 否 → 功率 > 2kW ? → 全桥（可 ZVS）
         功率 200W~2kW → 半桥（开关管应力低，成本最低）
```

## 七、快速小结

| 项目 | 结论 |
|------|------|
| 拓扑名称 | 推挽式隔离 Buck 变换器（Push-Pull） |
| 电路本质 | 中心抽头原边 + 两管交替 + 全波整流 + LC 滤波 |
| 模态数 | 4 个/周期（2 导通 + 2 死区）|
| 核心公式 | $V = 2nDV_g$（$D$ 为单管占空比，$D < 0.5$）|
| 有效占空比 | $D_{eff} = 2D$，工程范围 0.1~0.9 |
| 单管占空比 | $D < 0.5$，典型 $D_{max} = 0.45$ |
| MOS 管电压应力 | **$2V_g$**（推挽的标签，限制了高压应用）|
| 头号失效模式 | **偏磁**→ 磁芯饱和 → 开关管烧毁 |
| 变压器匝比 | $n = 0.75$（车载 24V→12V 设计值）|
| MOS 管 | 150V/30A（2 只）|
| 整流二极管 | 150V/20A 超快恢复或 SiC（2 只）|
| 滤波电感 | $6.8\mu\text{H}$ / 28A 铁硅铝 |
| 滤波电容 | ≥150µF / 25V 低 ESR |
| 最佳场景 | 低压输入（<100V）+ 中大功率（100W~1kW）|
